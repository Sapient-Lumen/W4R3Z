# IoTox

IoTox is maintained here as the supplied single-file Linux x86-64 Datacube. It carries its source and other project materials inside the executable.

- [Download IoTox v0.52.0](iotox-v0.52.0-x86_64-linux-17cca7b22e64)
- [SHA-256 checksums](IoTox-v0.52.0-SHA256SUMS)

The earlier source tree is retained in this repository's Git history. This release has been checked for byte integrity; the executable has not been run as part of this update.

For the design of the earlier source-tree edition, read its [historical introduction](https://github.com/Sapient-Lumen/W4R3Z/blob/93209be83d8e3f0bad511b6d0060a050dbfe88d8/Maintained%20Tools/IoTox/W4R3Z.md): it follows device authority, synchronization and durable command evidence. Its old release links are historical; the current download is above. The historical account is not by itself a verification of every feature in v0.52.0.
