# Entry 113 — SDK release-promise drift and public-API readiness bundles

This pass pushed the archive away from another run of Cargo-only workflow proposals and toward two sharper release-review seams:
**cross-language consumer-promise drift** and **joined public-contract readiness**.

New proposals:

- P-0482 SDK Release Promise Drift Kit
- P-0483 Public API Readiness Bundle Kit

Why these rose:

- **P-0482** rose because Rust already has credible foreign-shipping substrate in Python and Apple ecosystems — PyO3/maturin for wheels, UniFFI/XCFramework/SwiftPM for Apple bundles — so the sharper missing layer is now a **consumer-promise snapshot / drift / impact receipt**, not another builder.
- **P-0483** rose because semver checks, public-API diffing, public/private dependency work, rustdoc coverage JSON, and docs build message streams now make a joined **public-contract release-review bundle** more valuable than one more standalone analyzer.

What changed in archive judgment:

- The archive now treats **foreign-SDK release drift** as distinct from ship tooling. A worthy crate contribution here may be a **promise snapshot**, **drift diff**, **consumer-impact report**, or **manual-review ledger** rather than another uploader.
- The archive now treats **public API readiness** as distinct from broad compatibility gating. A worthy crate contribution here may be a **joined review bundle** over semver/public-API/docs/dependency-boundary facts rather than a giant “test everything” platform.
- The repo keeps converging on a sharper heuristic: when Rust already has builders and analyzers, the next missing crate is often the **boring review artifact that joins their output into a release contract**.

Archive hygiene added in this pass:

- Added an amnesia resistor warning future revisions not to mistake PyO3/maturin or XCFramework/SwiftPM substrate for a boring release-review workflow.
- Added an amnesia resistor warning future revisions not to mistake semver/public-API analyzers for a boring public-contract readiness workflow.
