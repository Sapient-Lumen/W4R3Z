# Entry 75 — frontier pass: scholarly deposits, preservation packaging, music metadata exchange, autonomous-driving scenarios, and space file delivery

Added five proposals after a new pass focused on standards ecosystems where Rust now has at least *some* substrate, but still lacks the **missing middle**: profile lockfiles, semantic diffs, replay, and portable evidence bundles.

New proposals:

- P-0327 Crossref 5.4.0 + JATS 1.4 Deposit & Validation Workbench Kit
- P-0328 OCFL 1.1 + BagIt Profiles Preservation Interop & Evidence Kit
- P-0329 DDEX ERN 4.3 + MEAD Interop & Evidence Kit
- P-0330 ASAM OpenDRIVE 1.8.1 + OpenSCENARIO Replay & Conformance Kit
- P-0331 CCSDS CFDP Interop & Evidence Kit

Pass notes:

- **Crossref + JATS** rose because Crossref 5.4.0 and JATS 1.4 are both active, machine-checkable surfaces, and Rust now has fresh XML-generation substrate; the missing layer is replayable transform/debug evidence.
- **OCFL + BagIt** rose because repository teams still live at the transfer/storage seam, while Rust’s existing tools do not yet give a boring default for profile-pinned ingest evidence.
- **DDEX ERN + MEAD** was promoted because new Rust parser/builder work exists, but partner onboarding and profile-specific debugging are still too bespoke and opaque.
- **OpenDRIVE + OpenSCENARIO** rose because ASAM now has official checker infrastructure, while Rust lacks a neutral replay/diff layer around road/scenario interoperability.
- **CFDP** was promoted because Rust now has meaningful space-protocol substrate, but transaction evidence and mission-profile replay are still missing from the ecosystem.
