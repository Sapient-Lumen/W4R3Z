# 2026-03-05 (36): Text layout conformance + network cassette/impairment kit + MessageFormat 2 localization kit

This entry pushes into two under-served “integration layers” where Rust has strong primitives but lacks shared, ecosystem-grade defaults:

- **Text is a system**: GUIs repeatedly reimplement bidi/segment/linebreak/shaping glue, and debugging layout issues is notoriously non-reproducible.
- **Network failures need artifacts**: teams can capture traffic and script impairments, but there’s no redaction-first, portable workflow for capture→replay→regression triage.
- **Localization is shifting standards**: Unicode MessageFormat 2 (MF2) is stabilizing in CLDR/TR35, but Rust lacks a conformance-driven MF2 implementation that composes with ICU4X.

## Added proposals

- **P-0197 — Text Layout & Shaping Conformance Kit** — a deterministic pipeline (bidi/segmentation/linebreak/shaping) with `*.textlayoutbundle.zip` bug artifacts and golden layout outputs, designed to be adopted by multiple Rust GUI stacks.  
  Sources: https://github.com/harfbuzz/rustybuzz ; https://crates.io/crates/unicode-bidi ; https://www.unicode.org/reports/tr14/ ; https://github.com/unicode-org/icu4x

- **P-0198 — Network Cassette & Impairment Kit** — pcap/pcapng normalization plus redacted `*.netbundle.zip` capture/replay artifacts and `tc netem` impairment profiles, with Cargo-native `doctor/capture/replay/diff` workflows.  
  Sources: https://datatracker.ietf.org/doc/draft-ietf-opsawg-pcapng/ ; https://ietf-opsawg-wg.github.io/draft-ietf-opsawg-pcap/draft-ietf-opsawg-pcap.html ; https://man7.org/linux/man-pages/man8/tc-netem.8.html

- **P-0199 — MessageFormat 2 Localization Kit** — MF2 parser/runtime + ICU4X-backed formatting hooks and a conformance fixture runner aligned with TR35; supports migration/interop with existing Rust localization stacks (e.g., Fluent).  
  Sources: https://www.unicode.org/reports/tr35/tr35-messageFormat.html ; https://messageformat.unicode.org/ ; https://blog.unicode.org/2025/03/unicode-cldr-47-release-messageformat-2.html
