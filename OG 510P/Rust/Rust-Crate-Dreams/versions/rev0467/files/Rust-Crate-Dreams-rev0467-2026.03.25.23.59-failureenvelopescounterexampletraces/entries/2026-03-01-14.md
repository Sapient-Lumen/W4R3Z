# 2026-03-01 (14): Synthesis — “tooling substrates” that compound

## Theme: build once, reuse everywhere
Several of the highest-leverage missing crates are *substrates* rather than end-user apps:
- structured events (P-0042 cargo-event-stream)
- build signatures (P-0045 cargo-input-manifest)
- run artifacts (P-0057 run-record-kit)
- install policy (P-0056 cargo-install-policy)

These enable downstream tools (profilers, auditors, CI replay, supply-chain gates) to exist without bespoke parsing and “pipeline glue.”

## Next incubation candidates (smallest epic)
1) **run-record-kit + cargo-event-stream**: standardize events and run artifacts, then let tools plug in.
2) **cargo-install-policy + cargo-toolchain-manifest**: make tool installs fast, repeatable, and explainable.
3) **cargo-doc-portal**: a pure UX win that makes local docs usable without docs.rs.
