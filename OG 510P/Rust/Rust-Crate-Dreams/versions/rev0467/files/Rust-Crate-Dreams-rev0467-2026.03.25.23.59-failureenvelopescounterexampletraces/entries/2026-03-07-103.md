# Entry 103 — Async dyn, lint profiles, unsafe-field ledgers, and edition witnesses

Added four proposals after a pass focused on a thinner seam the archive was still under-serving: **maintainer-facing artifacts for active Rust transitions**.

New proposals:

- P-0458 Async Dyn Transition Kit
- P-0459 Clippy Safety Profile & Waiver Kit
- P-0460 Unsafe Field Invariant Ledger Kit
- P-0461 Edition Drift Witness Kit

Why these rose:

- **P-0458** rose because the official async roadmap now explicitly spans `async fn in dyn Trait`, return type notation, and Dynosaur, while real libraries still have to choose among `async-trait`, `trait-variant`, `dynosaur`, and future native paths without a **shared migration receipt**.
- **P-0459** rose because Rust’s 2026 safety-critical story now explicitly mentions a home for safety-critical lints in Clippy, while current Clippy configuration and lint groups still do not give teams a **versioned profile + waiver + feature-matrix artifact**.
- **P-0460** rose because the unsafe-fields goal identifies field-level invariants as a language problem and the std-contracts work is making safety assumptions more machine-readable, yet maintainers still lack a **field-level invariant ledger and mutation witness** today.
- **P-0461** rose because Rust 2024 is now stable and edition migration is real, but large workspaces still do not have a **rehearsal bundle** that records compatibility lints, `cargo fix --edition` previews, and macro-heavy manual-review hotspots.

What changed in archive judgment:

- The archive now remembers a sharper pattern: when Rust offers a migration lint, proc macro, config file, or guide, that does **not** mean maintainers already have a boring workflow artifact.
- A worthy crate contribution may be the **profile**, **waiver bundle**, **migration receipt**, or **rehearsal witness** that sits above existing knobs and official docs.
- This pass also deliberately broadened the internal-Rust seam beyond compiler flags and IR work into **async dispatch**, **lint posture**, **field invariants**, and **edition upgrades**.

Archive hygiene added in this pass:

- Added an amnesia resistor reminding future passes not to mistake a proc-macro shim or a compatibility guide for a maintainer-grade transition workflow.
- Added known-existing notes so later revisions do not confuse `cargo fix`, Clippy config, `async-trait`, Dynosaur, or the unsafe-fields goal itself with proof that the reviewable artifact layer already exists.
