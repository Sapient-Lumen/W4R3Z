# 2026-03-05 (11) — QUIC interop bundles + energy regression + schema compatibility

This update adds three proposals that emphasize **artifact-first, CI-native workflows**:

- **P-0122 QUIC + HTTP/3 Interop & Capture Kit** — standard `*.quicbundle.zip` artifacts plus a cargo workflow to run scenarios and (optionally) interop matrices.
- **P-0123 Energy & Carbon Observability Kit** — reproducible energy measurement bundles to make joules/op a regression metric (Linux-first).
- **P-0124 Schema Compatibility Workbench Kit** — a unified, policy-driven schema diff report for OpenAPI + JSON Schema + Protobuf, exposed via `cargo schema`.

New proposals:
- `proposals/quic-http3-interop-capture-kit.md`
- `proposals/energy-carbon-observability-kit.md`
- `proposals/schema-compatibility-workbench-kit.md`
