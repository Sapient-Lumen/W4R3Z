# Entry 79 — frontier pass: runtime 3D assets, web-archive packaging, seismology exchange, robotics log replay, and DASH conformance

Added five proposals after a fresh pass focused on ecosystems where the specs and validators are already real, Rust has at least some substrate, and the missing value still looks like the **boring middle layer**: profile lockfiles, semantic diffs, replay, and portable evidence bundles.

New proposals:

- P-0347 glTF 2.0 + KTX 2.0 Asset Conformance & Evidence Kit
- P-0348 WARC 1.1 + CDXJ + WACZ Web-Archive Interop & Evidence Kit
- P-0349 FDSN miniSEED 3 + StationXML + SeedLink Interop & Evidence Kit
- P-0350 MCAP + rosbag2 Replay & Evidence Kit
- P-0351 MPEG-DASH + DASH-IF Conformance & Evidence Kit

Pass notes:

- **glTF / KTX2** rose because the official Khronos validator plus current Rust crate substrate makes the real gap **profile-pinned validator normalization + texture/package evidence**, not another runtime loader.
- **WARC / CDXJ / WACZ** rose because web-archive failures often live between **payload records, indexes, and distributable packages**, and Rust still lacks a compact bundle-first audit layer across all three.
- **miniSEED / StationXML / SeedLink** was promoted because scientific-data failures regularly cross the **waveform / inventory / realtime transport** boundary, which is still under-served in Rust despite new format/protocol crates.
- **MCAP / rosbag2** rose because the operational seam is **schema/channel/clock drift and conversion auditing**, not basic file I/O.
- **MPEG-DASH / DASH-IF** made the cut because Rust has meaningful MPD tooling and the official conformance surface exists, but there is still no boring-default **conformance-result normalizer + segment-aware evidence bundle**.
