# Entry 281 — crate upgrade support sharpened around review provenance and maker/checker separation

This pass came from noticing that the upgrade pack had become unusually exact about source lineage, scope, readiness, export posture, public surface, redaction, warnings, freshness, and public cues while still leaving one ordinary bluff available:

> a frozen or public-facing pack could still read like a reviewed migration contract even when it remained maker-authored material with no explicit independent checker.

## What moved this time

One donor pattern kept surviving scrutiny:

- **Radical-Governance** made the strongest case that consequential public AI/support surfaces should not rely on silent self-review; maker-checker separation, explicit fallback review, and visible challenge posture belong in the trust contract rather than in hallway memory.

## Main planning move

The previous passes already established:

- exact lineage/source-head truth,
- exact package/lane/capture/matrix truth,
- exact readiness/queue/consistency truth,
- exact export/publication/trace/cue/redaction truth,
- and exact warning/freshness/summary-claim truth.

This pass adds one sharper review object above them:

1. **review-provenance truth** — the pack can now say whether a public or frozen surface remains maker-only, passed an independent checker, or moved only under fallback review.

## Why this matters

Without **review-provenance truth**, the lane still permits an ordinary lie:

- a pack can be richly evidenced and beautifully organized while still sounding like a reviewed public contract even though nobody independent checked the exact surface being frozen.

That is not a cosmetic governance extra.
It is the difference between “the archive is careful” and “this exact public/frozen migration contract crossed a visible review boundary.”

## Main judgment after the pass

A worthy upgrade-support crate should now provide more than exact receipts and exact public surfaces.
It should also provide:

- one compact **review-provenance report** for whether the public/frozen surface stayed maker-only or crossed an explicit checker boundary,
- one bounded distinction between **mechanical exactness** and **independently checked trust**,
- and one explicit failure state for frozen/public claims that still rely only on same-author self-review.

That keeps the lane from quietly turning careful authorship into unearned review authority.
