# Entry 89 — frontier pass: living overlays, capability matrices, certification receipts, and schema-evolution evidence

Added five proposals after a pass aimed at ecosystems where the missing Rust value is **not a fresh parser or SDK**, but a boring default for **pins, diffs, replay, and explainable compatibility findings** above already-real standards or substrate.

New proposals:

- P-0397 LoRaWAN 1.0.4 / 1.1 + Regional Parameters + Certification Replay Kit
- P-0398 MIDI 2.0 + MIDI-CI + Profiles + Property Exchange Interop Kit
- P-0399 WebExtensions MV3 Capability Portability Kit
- P-0400 VDA 5050 Master-Control ↔ AGV Interop & Evidence Kit
- P-0401 FIX SBE Schema-Evolution Interop Kit

Pass notes:

- **LoRaWAN** rose because Rust already has serious device/radio substrate, while the sharper missing artifact is a **version/region/certification replay bundle** that can connect field incidents back to formal requirements.
- **MIDI 2.0** made the cut because the real problem is now at the **negotiation/profile/property seam**, not merely UMP message representation.
- **WebExtensions** rose because MV3 adoption and WECG common-core work have made portability more structured, but still not boring; the missing Rust crate is a **manifest/capability evidence layer**.
- **VDA 5050** made the cut because mixed-vendor fleet onboarding still lacks a **portable order/state/factsheet receipt**, even though Rust now has typed protocol substrate.
- **FIX SBE** rose because Rust now has enough codegen/runtime activity that the sharper missing layer is **schema-evolution and acting-version evidence**, not one more codec.

Archive hygiene added in this pass:

- Added a reminder that many ecosystems are really **formal core + living overlay catalogs** (regional packs, browser matrices, certification flows, profile packs, dialect overlays). Future passes should pin those layers separately instead of pretending there is one frozen standard number that settles everything.
- Strengthened the “known existing” notes so future revisions are less likely to confuse **available substrate** with **closed coordination gaps**.
