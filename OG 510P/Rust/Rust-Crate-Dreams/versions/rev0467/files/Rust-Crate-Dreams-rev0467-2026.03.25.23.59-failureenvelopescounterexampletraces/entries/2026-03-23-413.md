# Entry 413 — crate-knowledge deepened around citation-grade locators, target-aware pins, and answer-citation ceilings

This pass chose to **deepen P-0536 Crate Knowledge Pack Kit** rather than opening another docs bot, retrieval layer, or offline-mirror proposal.

The sharper question was:

> if a crate maintainer exports a compact support/search/assistant pack, what exactly should another engineer be able to cite from it without bluffing about versions, targets, redirects, or anchor stability?

## Why this deepening pass earned a full revision

Fresh primary sources made the gap concrete:

- the 2025 State of Rust survey says online documentation remains the preferred canonical reference while some learning/support traffic appears to be moving toward LLM tooling;
- docs.rs now documents floating shorthand URLs (`latest`, semver ranges, and `*`), target-aware hosted builds, README rules, and downloadable rustdoc archives;
- docs.rs rustdoc JSON hosting started only on **2025-05-23**, older releases may still lack downloads until rebuilds catch up, and redirects can point at static download routes that may not exist yet;
- docs.rs download archives are useful import materials but carry static-root and invocation-specific asset caveats;
- `cargo rustdoc` keeps target/example/bin selection explicit;
- and `cargo metadata` still tells consumers to pin `--format-version` for compatibility.

That means the next worthy product move for **P-0536** is not “answer more questions.”
It is to make the pack’s **citations and locators** reviewable.

## Main judgment after this pass

The top frontier still begins:

1. **P-0537 Compile Iteration Feedback Kit**
2. **P-0509 Crate Ecosystem Pathfinder & Decision-Pack Kit**
3. **P-0535 Dependency Lifecycle Transition Kit**
4. **P-0536 Crate Knowledge Pack Kit**
5. **P-0538 Concurrency Contract Kit**

But **P-0536** is now stronger because the archive no longer stops at material basis, excerpt lineage, answerability, and claim traces.
It now has a clearer product shape for:

- **citation locator resolution**
- **pin status versus floating shorthand**
- **target-aware citation fidelity**
- **citation-ready versus manual-review-only query classes**
- and compact support bundles that can stay helpful without pretending every answer has item-level anchors.

## What should count as a worthy crate contribution in this lane now

A worthy crate-knowledge pack should provide other people:

1. **one citation-locator receipt** that resolves convenient docs.rs shorthand into pinned, target-aware, reviewable locators;
2. **one citation-capability report** that says which query classes can cite item anchors, page anchors, package pages, or only manual-review routes;
3. **one fallback story** when hosted anchors are unstable, target-specific, or absent;
4. **one export rule** that forbids silent use of floating `latest` or semver redirects as if they were frozen review surfaces;
5. **one doctor path** that warns when a compact answer pack claims support without citation-ready locator coverage.

That is much closer to an ecosystem-worthy crate than a generic “chat with your crate” wrapper.
