# Entry 277 — crate upgrade support sharpened around public trace paths and typed fragment-route misses

This pass came from noticing that the upgrade pack had become honest about readiness, export posture, publication surface, warnings, freshness, summary-claim traceability, capture context, and sparse coverage while still carrying one quiet bluff:

> a public summary claim could still sound inspectable even when no public reader could actually follow the promised route and land on a real exported target.

## What moved this time

Two donor patterns kept surviving scrutiny:

- **Micromax** kept insisting that failed jumps should keep their own surface visible on failure instead of degrading into one generic miss.
- **EvidenceVault + The Election Stack** kept insisting that public surfaces need durable, reviewable reader paths rather than implied inspectability.

## Main planning move

The previous passes already established:

- exact public export posture and publication-surface manifests,
- warnings, deviations, freshness/supersession, and summary-claim traceability,
- exact capture contexts and sparse coverage matrices.

This pass adds one sharper review object above them:

1. **public-trace-path truth** — each public or downstream-facing claim can now say which public route a reader should actually follow, whether it resolves, and which typed miss kind applies when it does not.

## Why this matters

Without **public-trace-path truth**, the lane still permits an ordinary lie:

- a frozen/public summary can name evidence refs and exported files while still sending real readers into a private receipt, a missing fragment, or a fallback route that never lands anywhere public.

That is not cosmetic.
It is the difference between “this public claim sounds well sourced” and “this public claim is actually inspectable by someone who only has the exported surface.”

## Main judgment after the pass

A worthy upgrade-support crate should now provide more than exact receipts, exact summaries, and an exact exported file surface.
It should also provide:

- one compact **public trace-path report** for what a public reader can actually follow,
- one typed miss vocabulary so broken anchors and private-only routes stay visibly public-trace failures,
- and one bounded rule that a frozen/public claim may not pretend to be inspectable unless the route actually resolves on the exported surface.

That keeps the lane from quietly turning exported prose into public inspectability theater.
