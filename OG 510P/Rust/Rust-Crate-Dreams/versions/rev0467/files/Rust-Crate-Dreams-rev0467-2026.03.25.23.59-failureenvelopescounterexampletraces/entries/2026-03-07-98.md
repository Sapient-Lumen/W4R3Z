# Entry 98 — Rust future-substrate bridges: relink witnesses, reflection bridges, projection semantics, and C++ boundary evidence

Added four proposals after another pass over places where Rust is creating meaningful future substrate but ordinary ecosystem users still lack a compact artifact layer.

New proposals:

- P-0438 Relink Witness Kit
- P-0439 Comptime Reflection Bridge Kit
- P-0440 Projection & Reborrow Semantics Kit
- P-0441 C++ Boundary Evidence Kit

Why these rose:

- **P-0438** rose because Rust now has an explicit “relink, don't rebuild” direction, while existing public-API tools still do not give teams a small **private-change / interface-change witness** they can use in everyday review and CI.
- **P-0439** rose because reflection/comptime is becoming a live language-design topic and reflection-like crates already exist, but the sharper missing layer is a **schema IR and migration bridge**, not a premature universal reflection framework.
- **P-0440** rose because field projections, reborrows, pinning, and pinned initialization are converging on a family of subtle invariants that still lack a shared **contract/fixture/receipt kit** for library authors.
- **P-0441** rose because Rust/C++ interop is now explicitly being mapped as a strategic problem space, but ordinary teams still lack a **boundary receipt / ownership matrix / replay bundle** above today's interop tools.

What changed in archive judgment:

- The archive now has a stronger pattern for crates that help people **live through** Rust ecosystem transitions rather than waiting until every upstream mechanism is finished.
- A worthy crate contribution may be a **witness**, **bridge**, **semantics testkit**, or **boundary evidence kit** rather than a parser, runtime, or giant framework.
- This pass sharpens the distinction between “helper crate exists” and “portable, reviewable artifact story exists.”

Archive hygiene added in this pass:

- Added an amnesia resistor reminding future passes not to treat official Rust experimentation as the end of crate opportunity.
- Added notes pushing future revisions to look for bridge/witness/testkit layers when the language or compiler is in motion, while staying honest about uncertainty and incomplete coverage.
