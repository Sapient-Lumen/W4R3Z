# Entry 148 — cargo contention needs root-sharing topology and wrapper-context truth

This pass again did **not** add another top-level proposal.

Instead, it sharpened **P-0490 Cargo Lock Contention Witness Kit** where the archive still had the most leverage left: the crate now has a clearer plan for **root-sharing reports and wrapper-context receipts** above live lock waits.

## Main judgment

The important missing crate is not a lock killer and not a generic performance dashboard.
It is a **receiver-facing contention bundle** that can tell another person:

- which root class was involved (`target_dir`, `build_dir`, or Cargo package/index cache),
- which roles actually shared that root,
- whether wrapper/cache-mode drift makes reuse expectations different,
- and which mitigation isolates the right lane rather than a neighboring one.
