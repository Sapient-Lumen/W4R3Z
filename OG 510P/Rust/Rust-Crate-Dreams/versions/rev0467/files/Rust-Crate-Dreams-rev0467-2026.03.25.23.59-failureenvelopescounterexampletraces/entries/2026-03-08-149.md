# Entry 149 — compile-time-deps parity needs comparison baselines and override-command truth

This pass again did **not** add another top-level proposal.

Instead, it sharpened **P-0494 Cargo Compile-Time-Deps Workflow Kit** where the archive still had the most leverage left: the crate now has a clearer plan for **comparison-baseline locks and override-command receipts** above tool-only or check-like runs.

## Main judgment

The important missing crate is not another editor integration.
It is a **receiver-facing tool-workflow bundle** that can tell another person:

- what command actually ran,
- whether check/build-script override lanes were paired,
- whether `{label}` or other interpolation narrowed selection scope,
- what this run is being compared against,
- and whether a full build is still required.
