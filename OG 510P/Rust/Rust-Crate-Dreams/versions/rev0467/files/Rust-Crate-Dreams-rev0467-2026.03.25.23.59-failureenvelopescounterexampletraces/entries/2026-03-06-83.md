# Entry 83 — frontier pass: SARIF portability, process-mining semantics, advisory crosswalks, OTA trust paths, and document-package evidence

Added five proposals after a fresh pass aimed at **wide ecosystem variety** while keeping the archive honest about what is already present in Rust. This pass deliberately favored places where the missing value is **not** “yet another parser/runtime/SDK”, but instead:

- subset locks,
- semantic diffing,
- loss accounting,
- validator normalization,
- replayable evidence bundles,
- and profile-aware artifacts that other people can actually exchange.

New proposals:

- P-0367 SARIF 2.1.0 Subset + Baseline + Evidence Kit
- P-0368 XES + OCEL 2.0 + PNML Process-Mining Interop Workbench Kit
- P-0369 CSAF 2.0 + OpenVEX + OSV Advisory Workbench Kit
- P-0370 Uptane 2.1 + TUF / SUIT Deployment & Evidence Kit
- P-0371 OOXML + OPC Conformance & Evidence Workbench Kit

Pass notes:

- **SARIF** was added partly as a correction of archive drift: the previous archive filename highlighted SARIF, but the repo itself had not yet turned that into a proposal. The sharper framing is **subset locks + fingerprint/baseline diffs + replayable bundles**, not another scanner.
- **Process mining** made the cut because Rust already has real format substrate, which means the next missing crate is the **semantic boundary workbench** for XES / OCEL / PNML loss accounting and replay, not a greenfield mining engine.
- **CSAF + OpenVEX + OSV** rose because the real pain is at **product/package matching and cross-format status translation**, which is adjacent to SBOM/VEX work but not the same thing.
- **Uptane / TUF / SUIT** was promoted because the costly failures are operational and policy-shaped: delegations, thresholds, expiries, ECU policy, and campaign replay. The missing crate should be a **deployment evidence kit**, not another updater.
- **OOXML / OPC** stayed because it is both highly practical and easy to underestimate. Rust has footholds, but what is still missing is a **validator-normalizing, redactable package evidence layer** for real document interoperability failures.

Considered but not promoted in this pass:

- **OpenFeature / OFREP** — real Rust substrate and behavioral-test momentum already exist; still promising, but the “missing epic crate” case felt less neglected than the five promoted here.
- **Another generic advisory or office parser** — repeatedly downgraded. In both spaces the sharper opportunity is evidence, crosswalks, and profile locks above existing substrate.

Archive hygiene added in this pass:

- Added an LLM-hygiene rule that **zip-file codenames/highlights must correspond to an actual proposal addition or material revision in the pass, or the entry must explicitly explain the mismatch**. This is an amnesia resistor for future archive maintenance.
