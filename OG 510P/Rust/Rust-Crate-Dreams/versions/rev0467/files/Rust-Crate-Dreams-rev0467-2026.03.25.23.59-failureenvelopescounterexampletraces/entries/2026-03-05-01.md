# 2026-03-05 (01): GUI test harness + DP app kit + hermetic build capsule

This entry adds three proposals focused on **making Rust systems easier to ship and trust**:
1) A cross-GUI **visual regression / event playback harness** with standardized CI artifacts.
2) An **application-layer differential privacy** kit built on Rust DP primitives (OpenDP), focused on budgets/policies/doctor tooling.
3) A **hermetic build capsule** format to move reproducible Rust builds across CI and airgapped environments.

## Added proposals

- **P-0092 — GUI Testing & Snapshot Harness Kit (cross-GUI)**  
  Evidence: ecosystem fragmentation and existing framework-scoped snapshot tooling (e.g., egui helpers).  
  Sources: https://www.boringcactus.com/2025/04/13/2025-survey-of-rust-gui-libraries.html , https://lib.rs/crates/egui_kittest  
  See: `proposals/gui-testing-harness-kit.md`.

- **P-0093 — Differential Privacy Application Kit (OpenDP-powered)**  
  Evidence: OpenDP provides a Rust DP core; the “Commons/tools” layer highlights demand for end-to-end tooling.  
  Sources: https://github.com/opendp/opendp , https://opendp.org/tools/  
  See: `proposals/differential-privacy-application-kit.md`.

- **P-0094 — Hermetic Build Capsule Kit (Cargo-focused)**  
  Evidence: Cargo’s `vendor`, `--offline`, and `--locked` features exist, but there’s no standardized portable “frozen build” capsule.  
  Sources: https://doc.rust-lang.org/cargo/commands/cargo-vendor.html , https://doc.rust-lang.org/cargo/commands/cargo.html  
  See: `proposals/hermetic-build-capsule-kit.md`.
