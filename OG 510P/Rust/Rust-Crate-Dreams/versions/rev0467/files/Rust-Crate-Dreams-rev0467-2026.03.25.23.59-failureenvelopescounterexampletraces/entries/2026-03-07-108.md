# Entry 108 — Docs.rs parity bundles and Cargo lint-adoption receipts

This pass deliberately shifted a little away from pure Cargo release-surface work and toward two adjacent workflow seams where Rust now has real substrate but still lacks a boring artifact layer.

New proposals:

- P-0472 Docs.rs Build Parity & Evidence Kit
- P-0473 Cargo Lints Adoption Receipt Kit

Why these rose:

- **P-0472** rose because docs.rs now documents enough of its build environment, metadata knobs, target behavior, and resource limits to make the remaining gap much clearer. The docs.rs build page even recommends `cargo docs-rs` in CI while explicitly noting that it does not perfectly replicate the hosted environment. That makes the sharper missing layer a **preflight / drift / issue-bundle receipt**, not another docs runner.
- **P-0473** rose because Cargo finally has real lint-policy substrate: manifest `[lints]`, stable `workspace.lints`, and an emerging nightly Cargo-lint surface. But teams still mostly manage rollout, inheritance, and exceptions by reading manifests and CI logs manually. The sharper missing layer is an **inheritance / waiver / rollout artifact**, not another lint engine.

What changed in archive judgment:

- The archive now treats “official helper that catches many issues” as a **substrate signal**, not proof that the workflow is already boring.
- The archive also now treats “stable config table exists” as a **policy-surface opening**, not proof that rollout and exception management are solved.
- A worthy crate contribution in these areas may be a **receipt, diff, matrix, or waiver ledger** rather than another executor or analyzer.

Archive hygiene added in this pass:

- Added an amnesia resistor warning future revisions not to confuse docs.rs helper commands and reproduction guides with a compact parity workflow.
- Added an amnesia resistor warning future revisions not to confuse stable Cargo policy tables with an already-solved adoption workflow.
- Added known-existing notes for docs.rs docs/build pages, `cargo-docs-rs`, and Cargo lint-policy surfaces so later passes do not rediscover the same false gap.
