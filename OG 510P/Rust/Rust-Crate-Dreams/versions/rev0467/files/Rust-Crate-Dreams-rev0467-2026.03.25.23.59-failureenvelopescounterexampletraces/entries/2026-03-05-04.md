# 2026-03-05 (04): crash bundle + SBOM/VEX workbench + Wasm component warmstart

This entry adds three proposals centered on **making hard, cross-team workflows reproducible** via:
- standard, shareable artifacts (bundles)
- cargo-native UX
- conformance/verification harnesses

## Added proposals

1) **P-0101 — Crash Artifact & Symbolication Workbench Kit**
   - What it gives others: a standard `*.crashbundle.zip` that can be attached to issues, re-processed deterministically, and validated in CI.
   - Why now: minidump ecosystems are maturing in Rust (e.g., `rust-minidump`), and real-world experience emphasizes robustness + fuzz-resistance.  
   - File: `proposals/crash-symbolication-workbench-kit.md`
   - Key sources: Mozilla’s `rust-minidump` writeup; `breakpad-symbols`; Sentry `symbolic`.  
     - https://hacks.mozilla.org/2022/06/everything-is-broken-shipping-rust-minidump-at-mozilla/  
     - https://crates.io/crates/breakpad-symbols  
     - https://github.com/getsentry/symbolic  

2) **P-0102 — SBOM + VEX Workbench Kit**
   - What it gives others: cargo-native generation + stable diff + triage that emits portable VEX, so teams can keep “not affected / mitigated” decisions consistent.
   - Why now: Cargo SBOM generation exists, but the missing layer is **reviewable diffs + triage artifacts** that survive tool changes.
   - File: `proposals/sbom-vex-workbench-kit.md`
   - Key sources: `cargo-sbom`; CycloneDX Cargo plugin; CycloneDX VEX capability docs.  
     - https://crates.io/crates/cargo-sbom  
     - https://github.com/CycloneDX/cyclonedx-rust-cargo  
     - https://cyclonedx.org/capabilities/vex/  

3) **P-0103 — Wasm Component Warmstart Kit**
   - What it gives others: a standard `*.warmstart.zip` + verification tooling so warmstarting is reproducible and policy-auditable.
   - Why now: module warmstart (Wizer) is proven; component warmstart is emerging (`component-init`), but still lacks packaging + conformance.
   - File: `proposals/wasm-component-warmstart-kit.md`
   - Key sources: Wizer; `component-init`; Wasmtime Component API docs.  
     - https://crates.io/crates/wizer  
     - https://github.com/dicej/component-init  
     - https://docs.wasmtime.dev/api/wasmtime/component/struct.Component.html
