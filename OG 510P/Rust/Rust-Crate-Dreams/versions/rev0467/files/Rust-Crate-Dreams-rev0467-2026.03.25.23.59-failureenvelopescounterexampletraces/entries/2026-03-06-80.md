# Entry 80 — frontier pass: payment messaging, bioimaging datasets, meteorology code forms, astronomy archives, and editor/debugger interop

Added five proposals after a fresh pass focused on ecosystems where the base specs already exist, some Rust substrate already exists, and the missing value still looks like the **boring middle layer**: versioned profiles, semantic diffs, replay, validator normalization, and portable evidence bundles.

New proposals:

- P-0352 ISO 20022 + CBPR+ / HVPS+ / SEPA Conformance & Evidence Kit
- P-0353 OME-Zarr / NGFF 0.5 Conformance & Dataset Evidence Kit
- P-0354 WMO GRIB2 + BUFR Interop & Evidence Kit
- P-0355 FITS 4.0 + WCS + VOTable Interop & Evidence Kit
- P-0356 LSP 3.17 + DAP + LSIF Interop & Replay Kit

Pass notes:

- **ISO 20022** rose because schemas alone do not solve real interop: market-practice overlays and code-list drift make profile locks and privacy-aware evidence unusually valuable.
- **OME-Zarr** rose because the official validator and conformance-test surfaces now exist, while Rust has enough metadata/Zarr substrate to justify a validator-first workbench instead of another reader.
- **GRIB2 / BUFR** rose because table/version churn and local definitions are still the real source of operational pain, and Rust lacks a stable, shareable artifact for those failures.
- **FITS / WCS / VOTable** was promoted because astronomy bugs often cross the image/header/table/export seam, and Rust still lacks a coordinate-aware evidence layer.
- **LSP / DAP / LSIF** rose because Rust can already speak these protocols, but capability negotiation and replayable interop testing are still too editor-specific and fragile.
