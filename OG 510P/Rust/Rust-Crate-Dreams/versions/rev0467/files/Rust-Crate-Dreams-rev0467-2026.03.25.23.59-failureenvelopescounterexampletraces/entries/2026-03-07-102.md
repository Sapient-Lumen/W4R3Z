# Entry 102 — Rust compiler-edge workflow kits: ABI coherence, doctest extraction, formality witnesses, and external build handshakes

Added four proposals after another pass over places where Rust is clearly adding compiler/rustdoc/build-system substrate, but ordinary maintainers and tool authors still lack compact artifacts for reviewing and adopting it.

New proposals:

- P-0454 ABI Coherence Profile Kit
- P-0455 Doctest Extraction & Pipeline Kit
- P-0456 Formality Counterexample Bridge Kit
- P-0457 External Toolchain Handshake Kit

Why these rose:

- **P-0454** rose because RFC 3716, the Rust-for-Linux tooling goals, and build-std work now make ABI-affecting flag coherence a first-class problem, but ordinary teams still lack a **profile / exemption-ledger / sysroot-coherence receipt** for whole-program builds.
- **P-0455** rose because rustdoc is now exposing doctest extraction as machine-readable JSON and also changing doctest execution strategies, but maintainers still do not have a **manifest / rewrite / runner receipt** they can carry into custom pipelines.
- **P-0456** rose because a-mir-formality is becoming a real official bridge between Rust semantics and compiler reality, especially with MiniRust integration on the roadmap, yet contributors still lack a **portable counterexample bundle** for rustc-vs-model divergence.
- **P-0457** rose because the Rust-for-Linux tooling goals explicitly call out externally configured `no_std` and dependency extraction, while Cargo and rustc already expose dep-info, binary-dep tracking, injected crate attributes, and rustdoc dep-info — but there is still no **single handshake artifact** for non-Cargo orchestrators.

What changed in archive judgment:

- The archive now remembers a sharper pattern: when official Rust work exposes a new low-level surface, the missing crate may be the thing that turns it into a **reviewable contract artifact** rather than another wrapper or framework.
- A worthy crate contribution here may be a **coherence profile**, **doctest pipeline bundle**, **formality witness**, or **external-build handshake**, all sitting above raw compiler features.
- This pass also sharpens a useful distinction from older archive proposals: these are not primarily about new protocols or new engines, but about making Rust’s own evolving substrate usable by normal teams.

Archive hygiene added in this pass:

- Added an amnesia resistor reminding future passes not to confuse “the toolchain exposes a knob or JSON mode” with “there is already a boring workflow around it.”
- Added known-existing notes so later revisions do not mistake RFC/flag work, rustdoc extraction, a-mir-formality repos, or dep-info surfaces for proof that the maintainer-facing coordination layer already exists.
