# 2026-03-01: deterministic simulation harnesses + Kubernetes black-box testing + safe Markdown pipelines

This entry captures three territories where Rust has **building blocks**, but lacks a widely-adopted, low-friction *golden path* crate/toolkit.

## Signals & gaps

### Deterministic simulation support for rollback / prediction networking
- Rust has multiple rollback networking stacks and Bevy integrations (e.g., `bevy_ggrs`, `fortress-rollback`, `backroll`, `lightyear`), but building a correct rollback/prediction game still repeatedly hits the same hard requirements:
  - deterministic simulation (inputs-only replication),
  - canonical state hashing,
  - snapshot/restore ergonomics and fuzzable “desync” repro artifacts.
- The missing piece is a **determinism + state model kit** that can be reused across engines and networking libraries, not “yet another rollback transport.”

Sources:
- https://crates.io/crates/bevy_ggrs
- https://crates.io/crates/fortress-rollback
- https://github.com/cBournhonesque/lightyear
- https://github.com/bevyengine/bevy/discussions/1176

### Kubernetes operator black-box integration testing for Rust controllers
- kube-rs documents testing patterns, but explicitly notes that the common reconcile-driven pattern is not truly black-box integration testing.
- Practitioners still build bespoke Kind/Terraform harnesses and cleanup strategies to get “real” integration tests for Rust services/controllers in Kubernetes.
- The missing piece is a **standard harness + fixtures** crate that makes black-box testing repeatable, fast-ish, and CI-friendly.

Sources:
- https://kube.rs/controllers/testing/
- https://www.reddit.com/r/rust/comments/1pgsls0/rust_kubernetes_integration_testing_setup_with/

### Safe Markdown rendering as a turnkey pipeline (server + WASM)
- `pulldown-cmark` is a popular CommonMark parser, but users still ask how to make the rendered HTML safe (XSS, unsafe attributes), especially in WASM/browser contexts.
- Guidance often involves composing multiple crates (parser + syntax highlighting + sanitizer) with careful allow-lists.
- The missing piece is a **safe-by-default Markdown pipeline kit** with clear threat model, sensible defaults, and conformance tests (XSS corpus).
