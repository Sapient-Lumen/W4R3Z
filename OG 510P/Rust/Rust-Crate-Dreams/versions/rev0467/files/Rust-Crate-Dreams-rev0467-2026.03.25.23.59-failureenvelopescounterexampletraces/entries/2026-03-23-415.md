# Entry 415 — pathfinder deepened around freeze timeboxes, as-of replay, and knowability honesty

This pass chose to **deepen P-0509 Crate Ecosystem Pathfinder & Decision-Pack Kit** instead of opening another ranking UI, registry search tweak, or blessed-crates list.

The sharper question was:

> once a team freezes a starter-set decision, what exactly was knowable at that moment, and how do we compare that frozen basis with today's crate ecosystem without silently rewriting history?

## Why this deepening pass earned a full revision

Fresh sources made the next missing layer concrete:

- the March 2026 challenges post again says ecosystem navigation is still shaped by **choice paralysis**, **undiscoverable crates**, and tacit knowledge;
- the 2025 State of Rust survey still says online documentation is the preferred canonical reference and still reports compile/resource pain as a productivity limit;
- the January 2026 crates.io update says the index now carries **`pubtime`**, explicitly naming future cooldown periods and replay-as-of-date use cases;
- the active crates.io search discussion says search ordering remains non-trivial and current relevance ordering still uses weighted text ranking plus lexical tie-breaking when ranks match;
- Cargo `add` still does best-effort source selection, but that is not task-specific decision authority;
- Cargo `info` still gives a human-readable package snapshot and may choose a version based on the declared MSRV when none is specified;
- and docs.rs metadata plus the October 2025 default-target change show that a crate's **visible support story** can drift even when a team's frozen starter set has not changed.

That means the next worthy move for **P-0509** is not only “freeze a starter set” or “watch for later triggers.”
It is to make the pack's **freeze-time knowability** and **as-of replay** reviewable.

## Main judgment after this pass

The top frontier still begins:

1. **P-0537 Compile Iteration Feedback Kit**
2. **P-0509 Crate Ecosystem Pathfinder & Decision-Pack Kit**
3. **P-0535 Dependency Lifecycle Transition Kit**
4. **P-0536 Crate Knowledge Pack Kit**
5. **P-0538 Concurrency Contract Kit**

But **P-0509** is stronger now because the archive no longer stops at:

- task profiles,
- candidate imports,
- basis receipts,
- support-visibility reports,
- starter-set locks,
- and watch/revisit policies.

It now has a clearer product shape for:

- **decision-timebox receipts**,
- **as-of replay reports**,
- **freeze-basis versus current-view separation**,
- **cooldown-aware knowability ceilings**,
- and doctor rules that reject fake “we obviously should have picked the current winner” stories.

## What should count as a worthy crate contribution in this lane now

A worthy pathfinder crate should provide other people:

1. **one decision-timebox receipt** that says exactly what evidence window the frozen answer relied on and what it did not know yet;
2. **one as-of replay report** that compares freeze-time basis with today's view without pretending the current ecosystem automatically rewrites the old decision;
3. **one separation between visibility drift and task-fit drift** so docs.rs target/default changes can trigger review without silently crowning a different crate;
4. **one cooldown-aware knowability rule** so a very fresh release does not get treated as if it was part of the original basis;
5. **one doctor path** that warns when teams over-read `cargo add`, `cargo info`, search ordering, or current registry surfaces as historical decision authority.

That is closer to an ecosystem-worthy crate than another recommendation blog in cargo form.
