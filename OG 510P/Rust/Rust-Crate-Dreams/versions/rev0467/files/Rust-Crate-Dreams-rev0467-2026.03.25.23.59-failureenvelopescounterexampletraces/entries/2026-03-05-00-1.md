# 2026-03-05 (00-1): semver gate + deterministic rollback + observability workbench

This entry adds three proposals that try to reduce *ecosystem friction* by standardizing workflows and artifacts:
1) **Compatibility & semver regression gating** for library publishers.
2) **Deterministic simulation + rollback + replay bundles** for latency-tolerant networking and reproducible bugs.
3) **Drop-in observability/profiling UX** that unifies `tracing`, Tokio Console, and modern profilers into a consistent “cargo-native” experience.

## Added proposals

- **P-0089 — Compatibility Gate Kit (SemVer + ABI/behavioral guardrails for library releases)**  
  Evidence: `cargo-semver-checks` tool + roadmap toward Cargo integration.  
  See: `proposals/compatibility-gate-kit.md`.

- **P-0090 — Deterministic Rollback + Replay Kit (simulation snapshots + netcode glue + bug bundles)**  
  Evidence: GGRS “rollback networking” and its docs; real-world rollback example writeups.  
  See: `proposals/deterministic-rollback-replay-kit.md`.

- **P-0091 — Observability Workbench Kit (cargo obs doctor + tracing/console/profiler wiring)**  
  Evidence: Tokio Console; `tracing` guidance; Rust profilers like `pprof`, Pyroscope agent integration.  
  See: `proposals/observability-workbench-kit.md`.
