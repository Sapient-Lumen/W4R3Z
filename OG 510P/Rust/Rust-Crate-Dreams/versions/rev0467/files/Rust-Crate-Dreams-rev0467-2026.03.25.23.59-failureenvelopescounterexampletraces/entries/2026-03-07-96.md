# Entry 96 — Rust substrate follow-on: build-std workflows, dependency boundaries, Cargo plumbing, and MC/DC evidence

Added four proposals after a second pass over the “Rust’s own seams” cluster, this time focusing on cases where official Rust work is creating **substrate**, but the ecosystem still lacks the boring crates that make that substrate citizen-usable.

New proposals:

- P-0430 Build-Std Workbench Kit
- P-0431 Public Dependency Boundary Kit
- P-0432 Cargo Plumbing Interop Kit
- P-0433 MC/DC Coverage Workbench Kit

Why these rose:

- **P-0430** rose because `build-std` is no longer a purely hypothetical dream: Cargo and adjacent Rust-project work now clearly treat sysroot rebuilding as a real need. The sharper missing crate is not a new builder, but a **recipe/lock/receipt layer** for custom sysroot workflows.
- **P-0431** rose because public/private dependencies are becoming a real Rust/Cargo concept, yet maintainers still lack a standard **inspection/migration/explanation kit** that turns the concept into a boring release-review workflow.
- **P-0432** rose because Cargo itself has publicly identified the need for better plumbing commands and more phase-oriented outputs. The missing crate is a **schema/adapter/receipt layer** that lets tools consume those phases without every tool hand-rolling its own unstable integration stack.
- **P-0433** rose because safety-critical Rust work now explicitly includes MC/DC, while coverage tooling and compiler support are still caveat-heavy. The missing crate is a **decision-map and caveat-aware evidence bundle**, not a new coverage engine.

What changed in archive judgment:

- The archive now has a stronger model for a very particular class of worthy crate: one that sits **just above** official Rust progress and turns it into a reusable social/engineering artifact.
- These proposals are all intentionally framed as **coordination layers**:
  1. sysroot recipes and receipts,
  2. dependency-boundary explanations and migrations,
  3. Cargo phase locks and normalized snapshots,
  4. MC/DC caveat-aware evidence bundles.
- That is a useful correction against a common failure mode: imagining that the only epic contribution is either an upstream compiler feature or a giant replacement framework.

Archive hygiene added in this pass:

- Added an amnesia resistor reminding future passes that when Rust itself is adding substrate, the archive should ask what **boring ecosystem default** is still missing for ordinary users.
- Added stronger notes against collapsing “upstream work exists” into “there is no crate opportunity left.”
