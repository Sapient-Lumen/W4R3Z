# Entry 73 — frontier pass: digital twins, geospatial IoT, digital libraries, streaming media, and research-object packaging

Added five proposals after a new cross-domain pass focused on places where Rust now has enough substrate to stop asking for “one more parser” and start demanding the **missing middle**: profile pinning, semantic diffs, replay, deterministic packaging, and portable evidence.

New proposals:

- P-0317 Asset Administration Shell (AAS) + AASX Conformance & Evidence Kit
- P-0318 OGC SensorThings API + MQTT Conformance & Replay Kit
- P-0319 IIIF Image + Presentation Interop & Evidence Kit
- P-0320 HLS + Low-Latency HLS + CMAF Interop & Evidence Kit
- P-0321 RO-Crate Conformance & Packaging Kit

Pass notes:

- **AAS** was promoted because IDTA now publishes current, machine-readable, multi-part AAS releases and Rust has credible substrate; the leverage point is semantic/package conformance, not another “digital twin platform”.
- **SensorThings** was kept narrowly on **sensing + MQTT replay** because the expensive interoperability failures are usually observation semantics, paging/query drift, and pub/sub behavior rather than generic IoT plumbing.
- **IIIF** was promoted because the ecosystem already has explicit compliance and validator surfaces; that makes a Rust **interop/evidence** workbench more valuable than yet another viewer or raw image tool.
- **HLS / LL-HLS** was framed as a **timeline and profile** problem, not a playlist-parser race.
- **RO-Crate** was added because recent Rust momentum and the stable 1.2 recommendation make conformance-grade packaging/diff tooling suddenly more plausible.
