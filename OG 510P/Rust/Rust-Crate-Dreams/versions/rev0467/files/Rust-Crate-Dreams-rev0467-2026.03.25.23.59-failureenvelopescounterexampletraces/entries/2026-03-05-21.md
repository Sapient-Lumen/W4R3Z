# 2026-03-05 (21) — WebRTC SFU kit + GitOps secrets interop + Wasm portability evidence

This entry pushes three “missing middle layers” where Rust has strong primitives, but teams still struggle to *ship reliably*:

- WebRTC has a capable stack, but production teams still reinvent SFU/router cores and debugging workflows.
- GitOps secrets rely on SOPS conventions, but Rust lacks a compatibility- and policy-first library/workbench layer.
- Wasm “portability” is real, yet teams lack standardized evidence artifacts to prove and debug portability across targets and policy profiles.
