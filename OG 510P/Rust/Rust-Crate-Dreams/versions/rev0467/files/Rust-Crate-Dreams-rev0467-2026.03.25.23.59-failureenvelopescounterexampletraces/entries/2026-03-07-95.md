# Entry 95 — Rust substrate pass: spec witnesses, workspace impact planning, and public-IR tooling

Added three proposals after a pass aimed at a part of the archive that was becoming relatively under-covered: **crates that improve Rust’s own substrate**, not just crates that wrap outside standards.

New proposals:

- P-0427 Rust Specification Witness Kit
- P-0428 Cargo Impact Planner Kit
- P-0429 rustc_public Analysis Workbench Kit

Why these rose:

- **P-0427** rose because Rust now has both specification momentum (FLS adoption and explicit upkeep work) and mature compile-fail/UI-test substrate, but still lacks a standard **clause-linked witness artifact** that can tie prose claims to executable evidence.
- **P-0428** rose because workspace teams still repeatedly reinvent “what is actually affected by this diff?” planning, even while Cargo and compiler teams publicly acknowledge build-performance, locking, and cache-shape pain.
- **P-0429** rose because `rustc_public` / StableMIR has crossed the threshold from “the compiler might expose something someday” to “there is now a real public-analysis substrate”, but the ecosystem still lacks a **shared lockfile/fixture/evidence layer** above it.

What changed in archive judgment:

- The archive had become very strong on **external contracts and evidence workbenches**, but that success risked hiding another class of epic contributions: crates that help Rust itself become more **specifiable, explainable, and toolable**.
- This pass deliberately favored crates that sit at three internal seams:
  1. **spec text ↔ executable witness**,
  2. **workspace diff ↔ affected build/test plan**,
  3. **public compiler IR ↔ reusable analysis fixture/evidence bundle**.

Archive hygiene added in this pass:

- Added an amnesia resistor reminding future passes to periodically check for high-value opportunities at **Rust’s own seams**, not only at the boundaries between Rust and outside standards.
- Added a note that when official Rust surveys or project goals create new substrate, the archive should prefer **boring coordination artifacts** (witnesses, receipts, lockfiles, planners, fixture bundles) over giant “platform rewrite” fantasies.
