# Entry 99 — Rust transition ledgers: solver drift, open namespaces, Rust-for-Linux readiness, and const capability

Added four proposals after another pass over places where Rust is actively changing language, compiler, packaging, and systems substrate, but ordinary maintainers still lack a compact coordination artifact.

New proposals:

- P-0442 Trait Solver Drift Witness Kit
- P-0443 Open Namespace Migration Planner Kit
- P-0444 Rust-for-Linux Stable Readiness Kit
- P-0445 Const Capability Ledger Kit

Why these rose:

- **P-0442** rose because the next-generation trait solver is now a stabilization-track effort, while today’s harnesses still do not give maintainers a small **old/new solver drift witness** they can review or attach upstream.
- **P-0443** rose because optional namespaces are no longer just a naming debate: RFC 3243 is accepted, implementation work is active, and crate families will need a **migration-plan / alias-receipt / import-diff layer**.
- **P-0444** rose because Rust-for-Linux stable support now spans multiple official workstreams plus kernel docs/policy pages, but maintainers still lack a **stable-readiness profile and evidence bundle** that combines `rustavailable`, version policy, waivers, and subsystem state.
- **P-0445** rose because const traits are moving toward stabilization and rustdoc/public-API tooling already exists, but there is still no **const-capability ledger** for saying what is public *and const-usable* under which assumptions.

What changed in archive judgment:

- The archive now has a stronger pattern for crates that turn **transition state into explicit ledgers** rather than waiting for every upstream surface to become boring first.
- A worthy crate contribution may be a **drift witness**, **migration planner**, **stable-readiness bundle**, or **capability ledger** rather than a parser, wrapper, or replacement framework.
- This pass sharpens the distinction between “official progress exists” and “ordinary maintainers have a reviewable workflow.”

Archive hygiene added in this pass:

- Added an amnesia resistor reminding future passes to look for ledger/planner/waiver artifacts whenever Rust introduces a new naming, capability, or readiness transition.
- Added known-existing notes to prevent future revisions from misreading namespace work, Rust-for-Linux docs, solver harnesses, or rustdoc/public-API tooling as proof that the ecosystem-layer coordination problem is already solved.
