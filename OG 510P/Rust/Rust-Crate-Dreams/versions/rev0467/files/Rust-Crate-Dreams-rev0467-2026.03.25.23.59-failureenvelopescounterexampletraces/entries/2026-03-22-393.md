# Entry 393 — ecosystem-navigation deepening turned crate pathfinder into an imported-evidence honesty lane

This pass stayed focused.
It did **not** add another fresh proposal ID or another broad rerank.
Instead it deepened one of the repo’s highest-salience lanes:

**P-0509 Crate Ecosystem Pathfinder & Decision-Pack Kit**.

## Why this lane earned another serious refresh now

Fresh primary signals make the ecosystem-navigation seam sharper than it used to be:

- the March 2026 Rust challenges write-up explicitly says crate choice is still affected by **choice paralysis**, **undiscoverable crates**, and a layer of **tacit knowledge** that newcomers do not have;
- the December 2025 vision-doc write-up explicitly recommends helping users navigate crates.io and says there is still no obvious place to get a good “starter set” of crates;
- the January 2026 crates.io update means registry surfaces now expose more machine-usable facts such as the **Security tab**, **Trusted Publishing Only mode**, **SLOC**, `pubtime`, and a docs.rs browse-source link;
- the October 2025 docs.rs target change proved that a crate’s **visible support story** can move without a local architectural decision changing;
- Cargo’s current `cargo add` docs still say a best-effort source choice may come from an existing dependency, a workspace member, or the latest registry release;
- Cargo’s current `cargo info` docs say version selection without an explicit version is influenced by **MSRV**.

Together those sources say the missing value is no longer “better crate ranking” in the abstract.
The missing value is a stable crate-level handoff for:

1. imported candidate basis,
2. visible registry/docs support surfaces,
3. portable starter-set decision bundles,
4. and explicit limits on what those imported signals do **not** prove.

## Main judgment after the refresh

**P-0509** is now stronger as an **imported-evidence honesty lane** than as a generic search/ranking tool.

That means the proposal should own:

- candidate-basis receipts,
- support-visibility reports,
- portable pathfinder bundles,
- and conservative source/basis language for crates.io, Cargo, docs.rs, and imported health/trust evidence.

It should **not** try to own:

- global crate blessing,
- registry ranking policy,
- health/trust scoring by itself,
- or silent auto-replacement when imported signals move.

## What should count as a worthy crate contribution in this lane now

A worthy ecosystem-navigation crate should hand other people:

1. **one candidate-basis receipt** that says which facts came from Cargo, crates.io, docs.rs, crate-authored docs, imported receipts, or human judgment,
2. **one support-visibility report** that says what public surfaces are visible without pretending that visibility settles task fit,
3. **one decision pack** that keeps hard constraints, role coverage, interop fit, lock-in cost, and scope split separate,
4. **one portable bundle** that another team can review later,
5. **one explicit uncertainty story** instead of fake confidence.

If a candidate crate cannot do those things, the archive should usually treat it as a search helper, ranking UI, or internal policy note — not an epic ecosystem contribution.
