# Entry 87 — frontier pass: lineage evidence, DIDComm routing receipts, financial-desktop interop, browser-protocol replay, and storage portability contracts

Added five proposals after a pass aimed at **coordination-layer crates** rather than more substrate wrappers. The pattern sharpened again: some of the most valuable missing Rust crates are **lockfiles, semantic diffs, replay bundles, and explainable receipts** above mature or maturing ecosystems.

New proposals:

- P-0387 OpenLineage + Marquez + Facet Evidence Kit
- P-0388 DIDComm v2 + Out-of-Band + Mediation Interop & Evidence Kit
- P-0389 FDC3 2.2 + Desktop Agent Bridging Interop Kit
- P-0390 WebDriver BiDi + CDP Replay & Diagnostics Kit
- P-0391 OpenDAL + object_store Capability Portability Kit

Pass notes:

- **OpenLineage** made the cut because the spec/backends are real, but the sharper missing Rust value is a **facet-discipline and incident-bundle layer** above emitters and catalogs.
- **DIDComm** rose because Rust already has message-packing substrate, while the operational gap is still **profile locks, routing receipts, and redactable interop bundles**.
- **FDC3** made the cut even with thinner Rust substrate because the standard surface is now broad enough that a **vendor-neutral receipt/diff tool** could be unusually helpful.
- **WebDriver BiDi + CDP** rose because browser automation in Rust now spans multiple protocol surfaces, but the missing crate is a **fallback-aware replay and flake-evidence kit**, not another framework.
- **OpenDAL + object_store** made the cut because Rust infrastructure teams repeatedly need **semantics probes and backend portability contracts**, not one more abstraction layer.

Archive hygiene added in this pass:

- Added a reminder to distinguish **standards maturity** from **Rust-substrate maturity**. A spec can be mature while the Rust ecosystem around it is still thin; that must affect feasibility scoring.
- Added a reminder that **living standards and vendor overlays** should keep normative, optional, and vendor-specific surfaces separated in the proposal and evidence bundle design.
