# Entry 92 — profile collections, semantic trees, metadata family mappings, OCI handoff, and filter receipts

Added five proposals after a pass aimed at ecosystems where the missing Rust value is **not another runner, server, parser, or SDK**, but a boring default for **profile locks, capability matrices, loss receipts, relocation artifacts, and replayable evidence** above already-real standards or substrate.

New proposals:

- P-0412 CWL + Workflow Run RO-Crate Conformance & Evidence Kit
- P-0413 VSS + VISS v2 Capability & Replay Kit
- P-0414 Exif 3.0 + XMP + IPTC Photo Metadata Interop Workbench Kit
- P-0415 CNAB + OCI Relocation & Evidence Kit
- P-0416 CloudEvents + CESQL + CDEvents Interop Workbench Kit

Pass notes:

- **CWL + Workflow Run RO-Crate** rose because Rust now has enough CWL substrate that the sharper missing layer is a **portable run/provenance receipt**, not a fresh runner.
- **VSS + VISS v2** made the cut because connected-vehicle stacks still suffer from **tree/version/capability drift** much more than from raw type generation alone.
- **Exif + XMP + IPTC** rose because photo metadata failures are usually **mapping and loss-accounting failures**, not parser absence.
- **CNAB + OCI relocation** made the cut because the hard operational problem is still **artifact movement and registry reality**, not inventing a new deployment package format.
- **CloudEvents + CESQL + CDEvents** rose because the ecosystem now has enough live standard and Rust substrate that the sharper gap is **filter/family/routing evidence**, not one more event SDK.

Archive hygiene added in this pass:

- Added a reminder that some of the best crate opportunities sit in ecosystems with a **mature external contract but intentionally thin Rust substrate**, where the right crate is often a coordination artifact rather than a greenfield reimplementation.
- Strengthened the archive’s memory that a single ecosystem label may hide **multiple contract layers**: family profiles, mapping packs, filter semantics, tree subsets, registry quirks, or provenance profile collections.
