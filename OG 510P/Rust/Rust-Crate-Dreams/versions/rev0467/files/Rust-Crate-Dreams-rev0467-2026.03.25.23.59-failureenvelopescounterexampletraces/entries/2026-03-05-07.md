# 2026-03-05 (07) — passkeys integration, DB drift/migration conformance, TPM safe flows

This entry adds three proposals where the ecosystem has strong building blocks, but still lacks a **coherent integration contract**:
artifact formats, “doctor” UX, and conformance corpora that make the workflows repeatable.

## Added proposals

- **P-0110 Passkey Platform Kit** — a storage-agnostic WebAuthn/Passkeys integration layer with backend adapters (`passkey-rs` / `webauthn-rs`), framework glue, and a redacted `*.passkeybundle.zip` format for reproducible bug reports.  
  Sources: 1Password `passkey-rs`; `webauthn-rs` docs; Microsoft “tools and libraries for passkeys” list.  
  - https://github.com/1Password/passkey-rs
  - https://docs.rs/webauthn-rs/latest/webauthn_rs/
  - https://learn.microsoft.com/en-us/windows/apps/develop/security/tools-libraries
  - https://crates.io/crates/passkey

- **P-0111 DB Drift & Migration Conformance Kit** — cargo-native drift detection + deterministic migration replay that emits a portable `*.dbkit.zip` artifact (plan, normalized schema, diffs, replay logs) across sqlx/diesel/sea-orm backends.  
  Sources: sqlx embedded migrations macro; sqlx issue on “Rust migration scripts”; rust-users thread on adopting migrations into an existing schema.  
  - https://docs.rs/sqlx/latest/sqlx/macro.migrate.html
  - https://github.com/launchbadge/sqlx/issues/1105
  - https://users.rust-lang.org/t/how-to-deal-with-sqlx-migrate-and-schema-that-already-exists/123292

- **P-0112 TPM KeyStore & Attestation Flows Kit** — opinionated, profile-driven high-level TPM2 flows (seal/unseal, AK/quote, verification) with `*.tpmflow.zip` transcripts and conformance vectors; built atop `tss-esapi` / TPM2-TSS ESAPI.  
  Sources: `tss-esapi` crate; rust-tss-esapi repo; TPM2-TSS ESAPI docs.  
  - https://crates.io/crates/tss-esapi
  - https://github.com/parallaxsecond/rust-tss-esapi
  - https://tpm2-tss.readthedocs.io/en/4.1.x/group__esys.html

## Notes

These three proposals should be evaluated together as a pattern: **integration kits win** when they ship:
1) a versioned artifact format for collaboration,  
2) a `cargo … doctor` workflow for fast diagnosis, and  
3) a small conformance corpus that prevents regressions and encourages interop.
