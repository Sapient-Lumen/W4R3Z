# Entry 110 — API-aware docs review bundles and post-publish release receipts

This pass kept pushing on a pattern that has become unusually strong in the archive:
**Rust often has the substrate already, but maintainers still lack a compact artifact that turns that substrate into an ordinary workflow.**

New proposals:

- P-0476 Rustdoc Coverage Review Bundle Kit
- P-0477 Cargo Publish Receipt Join Kit

Why these rose:

- **P-0476** rose because rustdoc now has machine-readable coverage output and an increasingly toolable JSON surface, but maintainers still lack an **API-aware docs debt / regression / review bundle**. File-level percentages and lint spam are not yet a boring docs-maintenance workflow.
- **P-0477** rose because Rust’s release surface now spans local packaging review, registry index checksums, trusted publishing, trusted-publishing-only mode, and even index `pubtime` facts. But maintainers still lack one **post-publish receipt** that joins those facts into a durable release artifact.

What changed in archive judgment:

- The archive now treats **documentation maintenance artifacts** as distinct from docs hosting, docs.rs parity, or `doc.parts` handoff. The missing value can be a **coverage diff and public-API docs ledger**, not another docs portal.
- The archive now treats **post-publish release joins** as distinct from package review, provenance attestations, or trusted-publishing orchestration. The missing value can be a **local-review + registry-confirmation + publish-identity receipt**, not another publisher.
- A worthy crate contribution here may be a **review bundle**, **release receipt**, **identity report**, or **hotspot ledger** rather than a new executor.

Archive hygiene added in this pass:

- Added an amnesia resistor warning future revisions not to confuse rustdoc coverage JSON or lints with an already-boring docs review workflow.
- Added an amnesia resistor warning future revisions not to confuse trusted publishing or registry index metadata with a ready-made post-publish audit artifact.
