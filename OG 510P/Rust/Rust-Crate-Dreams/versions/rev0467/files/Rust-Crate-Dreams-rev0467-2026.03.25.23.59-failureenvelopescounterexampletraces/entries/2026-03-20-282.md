# Entry 282 — crate upgrade support sharpened around session honesty and mixed-capture disclosure

This pass came from noticing that the upgrade pack had become unusually exact about source lineage, capture context, lane selection, coverage matrices, readiness, export posture, public traceability, durable cues, freshness, and review provenance while still leaving one ordinary bluff available:

> several imported receipts could still be presented as if they came from one coherent review moment even when they were captured in different sessions.

## What moved this time

One donor pattern kept surviving scrutiny:

- **Rust-Needs-and-Dreams** kept treating Cargo-native session identity and replay posture as their own seam rather than a side note inside import metadata.
- **DelayBasin** kept showing that adjacent witnesses should not be silently fused just because they point in the same direction.

## Main planning move

The previous passes already established:

- exact source/head/import truth,
- exact capture/scope/matrix/lane-selection truth,
- exact readiness/queue/consistency/export/public-surface truth,
- and exact warning/freshness/review/public-cue truth.

This pass adds one sharper review object above them:

1. **session-honesty truth** — the pack can now say whether several receipts belong to one native session, one explicit capture family, a cross-session comparison, or a mixed-session synthesis that owes the reader visible warning/disclosure.

## Why this matters

Without **session-honesty truth**, the lane still permits an ordinary lie:

- a beautifully traceable public summary can still sound like one atomic reviewed lane even when it compresses receipts captured at different times, under different lockfile states, or across separate review runs.

That is not a cosmetic provenance extra.
It is the difference between "all relevant evidence is linked" and "this evidence can honestly be read as one review moment".

## Main judgment after the pass

A worthy upgrade-support crate should now provide more than exact receipts and exact traceability.
It should also provide:

- one compact **session-honesty report** for whether several receipts can honestly be read as one review moment,
- one bounded distinction between **same-session evidence**, **cross-session comparison**, and **mixed-session synthesis**,
- and one explicit disclosure path for public summaries that join several review moments into one usable downstream contract.

That keeps the lane from quietly turning several nearby truths into one unearned atomic witness.
