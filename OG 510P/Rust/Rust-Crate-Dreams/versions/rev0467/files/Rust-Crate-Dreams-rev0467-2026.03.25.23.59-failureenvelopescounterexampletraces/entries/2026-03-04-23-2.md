# 2026-03-04 (late-2): fuzz/property workbench + ABI-stable plugin kit + real-time audio graph standard

This update pushes into three very different “missing batteries” zones:

1) **Unified generative testing workflows** (property tests + fuzzing + shareable failure artifacts).  
2) **Pragmatic Rust plugin systems** (ABI-stable where possible, serialized fallback).  
3) **Real-time audio graphs** as a standard foundation with conformance.

## New epic proposals

- **P-0080 Fuzz + Property Testing Workbench** (`proposals/fuzz-workbench.md`)  
  A unified harness + stable bug-bundle format, building on `cargo-fuzz` and `proptest`.

- **P-0081 Stable Plugin Host Kit** (`proposals/stable-plugin-host.md`)  
  A “productized” plugin pattern for Rust apps using ABI-stable interfaces (e.g. `abi_stable`) + compatibility harness.

- **P-0082 Realtime Audio Graph Standard Kit** (`proposals/realtime-audiograph-kit.md`)  
  A shared RT-safe node/graph model + offline deterministic rendering + conformance suite, integrating with `cpal`.
