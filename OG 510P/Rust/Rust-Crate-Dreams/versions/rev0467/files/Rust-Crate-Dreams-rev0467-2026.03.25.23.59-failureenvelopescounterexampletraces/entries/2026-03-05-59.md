# 2026-03-05 (59): WebTransport + RDP + Kubernetes CRI evidence kits

Added three proposals that extend the archive’s **interop/conformance + evidence bundle** pattern into high-leverage networking/platform domains:

- **P-0265** WebTransport Interop & Evidence Kit (`*.wtbundle.zip`) — canonical WebTransport session IR + capture/replay/diff across browsers and Rust servers.
  - Specs/refs: https://www.w3.org/TR/webtransport/ ; https://datatracker.ietf.org/doc/draft-ietf-webtrans-http3/ ; https://github.com/w3c/webtransport/blob/main/explainer.md

- **P-0266** RDP Interop & Evidence Kit (`*.rdpbundle.zip`) — negotiation/security/capability trace canonicalization + redaction-first evidence bundles.
