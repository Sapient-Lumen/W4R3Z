# Entry 286 — crate upgrade support sharpened around surface-authorship truth and trust-plane separation

This pass came from noticing that the upgrade pack had become exact about source lineage, summary-claim traceability, review provenance, replay bridges, and public traces while still leaving one ordinary bluff available:

> a lane could still make Cargo-native reports, maintainer-authored migration guidance, reviewer-authored freeze decisions, and archive-derived summaries feel more interchangeable than they really are.

## What moved this time

One donor pattern kept surviving scrutiny:

- **SlopOS** kept insisting that **who authored the bytes** is often the fastest trust-plane discriminator when nearby surfaces look temptingly mergeable.

## Main planning move

The previous passes already established:

- exact source, session, replay, and baseline truth,
- exact public/export/trace truth,
- and exact review provenance.

This pass adds one sharper review object above them:

1. **surface-authorship truth** — the pack can now say whether a surfaced artifact is Cargo-native generated evidence, maintainer-authored guidance, reviewer-authored governance, archive-derived presentation, or mixed context, and whether that surface belongs to native observation, project guidance, review governance, derived presentation, or advisory context.

## Why this matters

Without **surface-authorship truth**, the lane still permits one ordinary lie:

- a summary claim can be perfectly traceable,
- a replay route can be explicit,
- a review surface can be clearly recorded,
- yet the bundle can still omit that the cited bytes came from very different authorship buckets with different trust meanings.

That is not cosmetic.
It is the difference between “these receipts all point the same way” and “these receipts are actually interchangeable kinds of truth.”

## Main judgment after the pass

A worthy upgrade-support crate should now provide more than exact evidence refs and replay routes.
It should also provide:

- one compact **surface-authorship report** for who authored each surfaced artifact,
- one explicit distinction between **native observation**, **project guidance**, **review governance**, and **derived presentation**,
- and one consistency failure when a summary sentence markets maintainer-authored guidance as if it were a native import.

That keeps the lane from quietly turning “nearby exact receipts” into “one homogeneous trust surface.”
