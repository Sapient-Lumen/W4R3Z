# latest_or_semver_docsrs_url_requires_resolved_material_basis

A support slice was assembled from `docs.rs/mycrate/latest` and `docs.rs/mycrate/~2/json`.
The pack must record that those were floating selectors first and only later resolved to an exact version.

The point is not to ban shorthand browsing.
The point is to stop a floating convenience URL from masquerading as a frozen review surface.
