# Scenario — mixed-session synthesis requires warning and summary disclosure

A pack may need to synthesize one public answer from receipts captured at different times.
This scenario keeps that synthesis honest:

- one lane joins evidence from separate sessions,
- the pack records that the join is mixed-session rather than pretending it is one coherent capture,
- and both the warning surface and the exported summary keep that disclosure visible.

That way the pack can still be useful without laundering cross-session synthesis into fake single-session certainty.
