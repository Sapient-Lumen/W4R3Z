# Scenario: trusted publishing and audit import do not erase effect review debt

This scenario protects against another ordinary lie:

- the graph imports reassuring signals such as Trusted Publishing and a shared audit record,
- but a dependency still carries dangerous or context-sensitive effects that another team has not actually reviewed in their own setting.

The fixture keeps signal provenance, assumptions, and review debt distinct so “some trust signals exist” does not become “the graph is fully reviewed.”
