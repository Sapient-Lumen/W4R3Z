# Scenario — public frozen pack exports summary and exact supporting receipts only

This scenario captures a pack whose internal working materials remain larger than the public contract surface.
The pack is already frozen for downstream users, but the public surface still exports only the summary, checked recipe, scope statement, and exact supporting receipts.

It proves that:
- a public surface should list what is actually exported rather than implying the whole working tree is the contract,
- floating or advisory-only sources should stay off the public surface,
- and warning labels should travel with the public entry points instead of staying buried in internal review notes.
