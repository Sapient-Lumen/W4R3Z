# Scenario: public claim routes resolve to exported receipts

This scenario captures a pack that is already public and frozen.
The summary-claim register and publication-surface manifest are both present, but the pack still needs one compact proof that each public claim has a reachable public trace path rather than a merely plausible evidence story.

The example shows two distinct good routes:

- one claim routes directly from the public summary into an exported supporting receipt,
- one warning-bearing claim routes through the public warning register with an exported fallback receipt.

The point is not more prose.
The point is to make “publicly traceable” mean “a reader can actually follow this route on the exported surface and land somewhere real.”
