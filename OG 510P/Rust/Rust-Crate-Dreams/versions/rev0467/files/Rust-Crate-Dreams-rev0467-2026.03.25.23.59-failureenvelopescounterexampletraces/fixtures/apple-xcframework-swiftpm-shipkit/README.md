# Apple XCFramework & SwiftPM ShipKit fixtures

These fixtures exist to keep the archive honest about what the Apple shipkit is actually checking.

The core review objects are:
- **slice coverage**
- **package alignment**
- **trust posture**

They exist so the archive does not flatten:
- “the XCFramework exists”,
- “the wrapper imported once in Xcode”,
- and “the bundle is signed or zipped somehow”

into one fake “Apple support” result.
