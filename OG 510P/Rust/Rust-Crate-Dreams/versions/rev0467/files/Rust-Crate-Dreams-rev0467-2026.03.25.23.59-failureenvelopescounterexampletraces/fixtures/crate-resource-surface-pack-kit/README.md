# Crate Resource Surface Pack Kit fixtures

These fixtures exist to keep **P-0521** honest about five questions:

1. where admission happens first,
2. who owns backlog,
3. what can shrink effective capacity,
4. what callers experience at the boundary,
5. which signals or receipts actually support the claim,
6. where a bound lives and whether clones share it or multiply it.

The point is not to prove exact memory usage for every crate.
The point is to make resource-support claims reviewable instead of reconstructing them from builder docs, layer order, and incidents.
