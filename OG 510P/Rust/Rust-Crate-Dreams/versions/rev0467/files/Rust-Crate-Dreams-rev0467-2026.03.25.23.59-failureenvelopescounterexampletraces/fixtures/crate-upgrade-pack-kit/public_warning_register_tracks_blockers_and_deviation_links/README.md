# Scenario — public warning register tracks blockers and deviation links

A public candidate pack already exports a summary and exact receipts, but the warning surface still needs one compact register that says:

- which warnings are active,
- whether each warning is advisory or blocking,
- whether it is maintainer-only or part of the public contract,
- and whether an active deviation temporarily carries that warning forward.

This scenario demonstrates that compact warning labels should be backed by a bounded register instead of scattering warning meaning across source-head, readiness, and publication files.
