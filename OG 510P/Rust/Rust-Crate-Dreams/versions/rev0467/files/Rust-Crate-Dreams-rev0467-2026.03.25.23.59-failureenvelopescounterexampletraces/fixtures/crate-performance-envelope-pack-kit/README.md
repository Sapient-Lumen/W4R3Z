# Crate Performance Envelope Pack Kit fixtures

These fixtures exist to keep **P-0517** honest about five questions:

1. which metric actually rules a scenario,
2. what kind of run produced the evidence,
3. where the workload came from,
4. which profile / harness / environment story the claim actually rode on,
5. what trust class another team should assign to the result.

The point is not to prove absolute performance for every crate.
The point is to make performance claims reviewable instead of reconstructing them from charts, CI screenshots, and benchmark folklore.
