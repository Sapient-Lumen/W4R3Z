# Scenario — portable bundle keeps basis, rewrites, execution mode, support class, and imports separate

This scenario models the handoff bundle another maintainer would receive after a docs-support incident.
The point is not to compress everything into one “doctests passed” verdict.
It is to package the receipts needed to answer:
- what authority produced the manifest,
- how examples were rewritten,
- how they ran,
- what support class was observed,
- and which adjacent imports (runner/docs.rs parity) still need separate reading.
