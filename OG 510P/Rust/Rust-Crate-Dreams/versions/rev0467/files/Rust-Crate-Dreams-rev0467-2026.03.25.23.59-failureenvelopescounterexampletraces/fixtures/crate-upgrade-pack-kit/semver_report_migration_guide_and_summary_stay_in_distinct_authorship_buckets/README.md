# Scenario — semver report, migration guide, and summary stay in distinct authorship buckets

A useful upgrade pack often joins several kinds of bytes that should not silently inherit the same trust surface.

This scenario keeps that split explicit:

- one SemVer report stays **Cargo-native generated** evidence,
- one migration guide stays **maintainer-authored guidance**,
- one freeze/readiness note stays **reviewer-authored governance**,
- and the human-facing summary stays **archive-derived presentation** instead of pretending to be one more native import.
