# Scenario — freeze gap temporarily allowed under expiring public deviation

A maintainer wants to circulate a candidate public upgrade pack even though the current lane still lacks a citation-ready head and therefore is not honestly `freeze_ready` yet.

This scenario demonstrates that:

- the pack must keep the blocking warning visible instead of smoothing it away,
- a temporary override should become a numbered, expiring deviation record rather than a prose exception,
- compensating controls and approval authority should be explicit,
- and the public summary of the deviation should travel with the pack instead of staying buried in internal notes.
