# Frontier delivery card template

Use this when a proposal needs to be translated from archive idea to first buildable release.

## Proposal
- **ID / title:**
- **Status:** idea / research / plan / proving-ground / build-ready
- **Last reviewed:**
- **Primary receiver(s):**

## One-line promise
What concrete value does this crate provide other people?

## Recurring pain
What repeated workflow, ambiguity, or failure does it remove?

## Why now
What changed in the substrate, ecosystem, or demand map that makes this worth building now?

## First useful release
Name the smallest honest release.
Prefer 2–5 artifacts, not a grand platform.

## Core artifacts
List the exact files / packet types / receipts / reports / locks / bundles.

## Command surface
If this is a Cargo tool or CLI, what are the first commands?

## Inputs it should import
What existing official surfaces, adjacent crates, or prior archive lanes should it reuse?

## Refusal boundary
What does this crate explicitly not do?

## Example scenario
Describe one scenario where the first release is clearly useful.

## Claim ceiling
What still requires manual review or future work?

## 90-day success test
How will we know the first release is actually useful to another team?

## Adjacent proposals
What proposals does this deepen, consume, or depend on?

## Sources
List the current sources that justify the card.
