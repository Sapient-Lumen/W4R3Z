# Archive amnesia resistance — 2026-03-25

This file is about repo hygiene, not crate design.
It exists because the archive is now large enough that future LLM-assisted passes can easily lose the plot.

## Main judgment

The most common failure mode is no longer “forgetting a proposal exists”.
It is:
- re-inflating a weak mega-lane,
- forgetting the current frontier already converged on a practical control-plane core,
- and rewriting archive memory as if every new session were greenfield.

## First-read stack for thin-context sessions

When reopening the repo, read in this order:
1. `INDEX.md`
2. the latest `entries/...` file
3. the latest `meta/frontier-salience-...md`
4. `meta/missing-crate-territory-map-2026-03-25.md`
5. `meta/epic-crate-worthiness-framework-2026-03-25.md`
6. `meta/archive-memory-anchor-2026-03-22.md`
7. `meta/llm-hygiene.md`

If context is still thin after that, stop widening and summarize before inventing.

## Files that must stay aligned

When a pass materially changes direction, update all of these together:
- `README.md`
- `INDEX.md`
- latest `entries/...`
- latest `meta/frontier-salience-...`
- `meta/prioritization.md`
- `meta/roadmap.md`
- `meta/research-ledger.md`
- `meta/decision-log.md`
- `meta/archive-memory-anchor-2026-03-22.md`
- `meta/llm-hygiene.md`

If they disagree, the archive will hallucinate its own priorities.

## Durable memory the repo should preserve

Future passes should remember:
- the current front door is **P-0509 + P-0536**;
- the strongest adjacent ring is **P-0486 / P-0538 / P-0472 / P-0535 / P-0484 / P-0537 / P-0431**;
- sector scans so far mostly strengthen **control-plane**, **boundary**, **evidence**, and **transition** crates;
- broad sector umbrellas are usually weaker than sharper seam kits.

## Do-not-reinflate list

Do not reopen these as frontier lanes without new evidence:
- generic web mega-chooser;
- one-true GUI stack;
- monolithic ML umbrella;
- generic local-first umbrella;
- enterprise platform meta-crate;
- science/data mega-toolkit.

A future pass may still mine them for sub-seams.
But it should say what the sharpened seam is before reviving them.

## Small-rerank discipline

When a pass changes salience, prefer a small rerank with a reason.
Do not replace the whole board unless the evidence truly changes the practical build order.

## Sector-breadth discipline

A broad scan should compare sectors against a mature baseline.
It should not confuse “many ideas” with “many worthy crate shapes”.

## Session discipline for LLM-assisted work

Every substantial session should explicitly record:
- what sources were rechecked,
- what changed,
- what did not change,
- what was eliminated or deferred,
- and which files were updated.

## Refusal discipline

The archive should prefer a crisp refusal over a blurry promotion.
If a proposal is still only a mood board, say so.
