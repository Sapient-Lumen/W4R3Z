# Evidence snapshots

This archive links to online sources, but links rot and interpretations drift.

To reduce “LLM amnesia” and ensure future readers can verify claims, **every high-impact proposal should include short evidence snapshots**.

## Format (recommended)
For each proposal, add a section (or separate file) with:

- `source_url`
- `date_captured`
- `claim_supported`
- `verbatim_excerpt` (<= 25 words; keep it short to respect copyright)
- `notes` (why this matters)

## When to capture
Capture snapshots for:
- recurring pain points (offline mirrors, auditing burden, etc.)
- claims about new platform features (Trusted Publishing)
- claims about research results (e.g. measured reductions in audit effort)

## Hygiene rules
- Distinguish **facts** (supported by sources) from **hypotheses** (ideas to test).
- Prefer primary sources (official docs, RFCs, papers, issue threads).
- If you can't find evidence, keep the idea in `meta/territory-map.md` as a candidate rather than an “epic proposal”.
