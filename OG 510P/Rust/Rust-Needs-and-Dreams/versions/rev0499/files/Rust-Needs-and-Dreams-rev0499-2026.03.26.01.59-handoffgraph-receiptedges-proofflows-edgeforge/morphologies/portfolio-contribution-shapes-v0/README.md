# Portfolio Contribution Shapes v0

This corpus is the archive's first thin maintained map of recurring **contribution shapes**.

It exists so future revisions can answer:
- what kind of thing this worthy seam should become first,
- what artifacts make that shape real,
- and what category mistake should be avoided before overbuilding.

Files:
- `shapes.json` — first shared set of contribution-shape cards

Non-goals:
- not a ranking of seams
- not a proof that one shape is always optimal
- not a replacement for pilot evaluation or portfolio sequencing
