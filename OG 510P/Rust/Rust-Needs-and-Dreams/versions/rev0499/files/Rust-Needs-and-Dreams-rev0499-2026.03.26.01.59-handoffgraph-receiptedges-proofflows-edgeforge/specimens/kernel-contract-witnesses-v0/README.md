
# Kernel contract witness corpus (rev0486)

This directory holds the archive's **contract witness packs** for the top-band kernels that already earned:
- a live decision packet,
- a kernel brief,
- a slice-0 note,
- and a contract0 note.

These files are **illustrative examples of exercised contract shape**.
They are not live proving-ground evidence and they are not stable ecosystem standards.
