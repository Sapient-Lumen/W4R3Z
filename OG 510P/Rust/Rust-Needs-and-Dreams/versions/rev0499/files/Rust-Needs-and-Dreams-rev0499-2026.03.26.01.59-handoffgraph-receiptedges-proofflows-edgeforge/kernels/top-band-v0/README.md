# Top-band kernel briefs (rev0483)

This corpus holds the archive's **first-build briefs** for top-band candidates that have earned kernelization.
These are not universal roadmaps and not promises that Cargo or the Rust Project will upstream them.
They are bounded starting shapes.

Current kernel briefs:
- `build-state-pack.v0.md`
- `debug-acceptance-matrix.v0.md`
- `package-intake-review-kit.v0.md`
- `safety-critical-readiness-cards.v0.md`

Intentionally absent for now:
- **Navigation / Defaults / Claims Commons** — still `hold`; kernelization would create renewal debt before reviewer cadence is proven.

Default use:
- start here when a candidate already has a packet and the next question is “what exactly should a first repo contain?”;
- return to the live packet when verdict posture changes;
- refuse widening when the brief itself says the first shape is still intentionally narrow.
