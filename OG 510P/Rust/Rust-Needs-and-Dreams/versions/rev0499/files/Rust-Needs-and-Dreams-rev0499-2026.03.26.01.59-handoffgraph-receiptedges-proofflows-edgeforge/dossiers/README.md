# Dossiers

This directory holds **current working dossiers** for the archive's strongest live candidates.
A dossier is not a broad synthesis note and not a final live review packet.
It is the archive's current-operating card for one real candidate.

Read with:
- `design/epic-contribution-candidate-dossiers-2026Q1.md`
- `meta/CANDIDATE_DOSSIER_PROTOCOL.md`
- `design/epic-contribution-review-packets-2026Q1.md`
- `design/epic-contribution-review-packet-specimens-2026Q1.md`


Default relation:
- dossiers are current working cards;
- live decision packets are the current verdict artifacts;
- specimen packets are packet-grammar examples.
