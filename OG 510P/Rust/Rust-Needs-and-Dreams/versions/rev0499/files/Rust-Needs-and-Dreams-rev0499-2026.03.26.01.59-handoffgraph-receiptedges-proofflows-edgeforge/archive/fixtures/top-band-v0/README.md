Reading rule:
- start from the live packet if the question is verdict posture,
- start from the kernel brief if the question is repo shape,
- start from the slice if the question is what lands first,
- start from the contract if the question is surface,
- start from the witness if the question is output shape,
- and start from these fixtures if the question is **what scenario and expected checks should drive the output**.
