# Portfolio hypothesis ledger v0

This corpus names a small set of **present-tense strategic claims** the archive repeatedly relies on.
It exists so future revisions can say which canon claims are currently live, what still supports them, what would narrow them, what would falsify them, and which repo loops should move if they do.

It is not a prediction market and not a KPI dashboard.
