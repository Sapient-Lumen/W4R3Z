rev0041 reasoning note — law-to-door no-service-capacity

I chose the Nauru / Palau / FSM law-to-door lane because rev0034 left it open in the sprint matrix and because it is a classic false-door risk: legal protections are easy to praise and dangerous to overstate. The new research supports a source-promotion pass, but only if the promotion increases caution.

Nauru Judiciary supports the existence and public description of the legal procedure, while also surfacing compulsory-counselling / relationship-repair language. UNDP Justice Pathways supports regional legal-capacity and implementation-gap context across FSM, Palau, and RMI, including protective-order frameworks and barriers to enforcement/access. Together, these sources make the cube more accurate only if public release remains blocked.

Therefore rev0041 adds rule 39, re-anchors the law-to-door cluster to no-service-capacity language, records a new negative case and promotion transaction, and releases no public claim.
