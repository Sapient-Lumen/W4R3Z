## Standing controls

- Actual artifact tests happen after packaging and target the exact path delivered to the user.
- Current prose may contain an older revision token only inside an explicitly marked history section.
- “Current package revision” and “last substantive revision” are separate metadata fields.
- A working revision cannot carry “gate-pass” in its filename or status.
- Public availability is never treated as permission; closed classification is never treated as access control.
- Candidate growth remains frozen until authority planning and access-tier separation are addressed.
- More research is not always safer; some debts must become permanent boundaries.
