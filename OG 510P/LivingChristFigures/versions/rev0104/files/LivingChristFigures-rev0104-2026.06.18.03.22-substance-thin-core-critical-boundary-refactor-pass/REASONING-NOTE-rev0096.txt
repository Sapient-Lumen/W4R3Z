Reasoning note for rev0096

Priority chosen: convert the oldest concrete normalization debt into row-level audit coverage instead of adding more doctrine.

The riskiest unfinished issue was not another missing policy statement; it was that several release-critical meanings still lived in prose or mixed free-text fields while the normalized-code layer only described desired future fields. This pass creates a companion overlay rather than changing core ledger headers, because a direct header migration would be higher-risk and would force changes across candidate, claim, source, public, and governance reports.

The new overlay derives conservative codes from existing ledgers, checks coverage counts, checks vocabulary membership, and blocks the release if high findings appear. It also exposed and corrected one real vocabulary drift: `requires_family_community_or_governance_confirmation` was present in governance rows but absent from the controlled vocabulary.

The change is intentionally non-public and non-expansive. It improves handoff and auditability without adding sources, people, routes, referrals, services, capacity claims, images, testimony, or public release permission.
