# rev0051 — public-lint / sensitive-surface / governance-snapshot pass

CENTRAL SENTENCE: A public surface must be linted, not merely trusted; a governance snapshot is a release gate, not release permission.

## Why this pass exists

rev0050 created candidate-level public-export eligibility and per-source public-link review, but two handoff gaps remained. First, the public export manifest still had a stale `package_revision` value even though its top-level `revision` matched. Second, the public renderer did not yet treat short helpline/lifeline digits as contact data when the number was fewer than the older phone-number threshold.

rev0051 fixes both gaps and adds deeper release instrumentation: a public-layer lint, a working-cube sensitive-surface inventory, and a candidate governance snapshot with a review queue.

## Changes made

- Added `tools/public_release_lint.py` and `META/Public-Release-Lint-current.*`.
- Added `tools/sensitive_surface_inventory.py` and `META/Sensitive-Surface-Inventory-current.*`.
- Added `tools/candidate_governance_snapshot.py`, `META/Candidate-Governance-Snapshot-current.*`, and `META/Governance-Review-Queue-current.*`.
- Added `GOVERNANCE/Public-Release-Lint-and-Sensitive-Surface-Protocol-current.md`.
- Added field contracts for the new meta reports.
- Updated the public renderer to redact hotline/helpline/lifeline contact shortcodes in public fields.
- Tightened schema validation so `PUBLIC/PUBLIC-EXPORT-MANIFEST-current.json` must match manifest `revision` and `package_revision`.
- Added rules 51 and 52.
- Removed `__pycache__` artifacts from the package and added a no-bytecode-cache QA check.

## Public release effect

No new public prose, URL, live referral, case detail, testimony, image, route, support path, current-capacity claim, or implementation-safety claim is released. The public layer remains a renderer-generated, linted, boundary-first, non-referral index/policy/template layer only.
