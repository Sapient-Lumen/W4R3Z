# rev0053 — dependency / public-index parity / governance-consistency hardening pass

CENTRAL SENTENCE: A gate is not trusted until its dependencies, mirrors, and governance cross-checks agree.

## Why this pass exists

rev0052 proved that rows, revision surfaces, generated artifacts, and release gates could be checked. The remaining handoff risk was cross-report agreement: a public index could be regenerated from safe inputs but drift across CSV/JSON/Markdown; governance rows could each be valid but semantically disagree; generated reports could be present without a visible dependency map.

rev0053 adds those missing joins. It does not release new public prose. It makes the public/non-release posture harder to bypass by adding parity checks, governance-consistency checks, and a dependency graph.

## Changes made

- Added `tools/public_index_parity.py` and `META/Public-Index-Parity-current.*`.
- Added `tools/governance_consistency_audit.py` and `META/Governance-Consistency-Audit-current.*`.
- Added `tools/package_dependency_graph.py` and `META/Package-Dependency-Graph-current.*`.
- Added field schemas and row-validation coverage for the new reports.
- Updated generated-artifact provenance to track the new generated reports.
- Updated release-gate attestation to include public-index parity, governance-consistency, and dependency-graph gates.
- Updated the public-safe renderer so Markdown cells are no longer arbitrarily cut mid-boundary phrase.
- Added rules 57-60 and coverage rows for public-index parity, governance consistency, package dependency graph, and dependency-aware release gating.
- Updated the governance decision ledger with explicit manual-review and dependency-gate decisions.

## Public release effect

No new public prose, public URL, live referral, case detail, testimony, image, route, support path, current-capacity claim, or implementation-as-safety claim is released. The public layer remains a scrubbed index/policy/template/manifest layer only.

## What this pass blocks

- Treating CSV/JSON/Markdown public-index disagreement as harmless.
- Treating a governance queue row as advisory when eligibility or consent rows make it blocking.
- Treating a source-link policy as separate from its generated link-review decision.
- Treating a generated report as handoff-safe when its generator/input/public-contract/ledger-mirror edges are invisible or missing.
