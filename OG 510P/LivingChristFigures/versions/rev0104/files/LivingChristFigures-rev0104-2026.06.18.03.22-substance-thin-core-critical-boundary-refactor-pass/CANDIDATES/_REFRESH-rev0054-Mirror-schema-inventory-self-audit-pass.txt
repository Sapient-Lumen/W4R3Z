# rev0054 — mirror / schema-coverage / package-inventory self-audit pass

CENTRAL SENTENCE: A mirror is not trusted until its cells agree; a schema is not mature until its backlog is visible; an archive is not ready until its surfaces are inventoried.

## Why this pass exists

rev0053 added parity, governance-consistency, and dependency graph checks. The next remaining handoff risk was quieter: a CSV and JSON mirror could disagree in values while basic row-count checks passed; current tables could remain outside explicit field coverage without being listed as backlog; and the package could carry many files without a machine-readable inventory of what each file is.

rev0054 adds these three deeper self-audits. It does not add candidates and does not loosen any public-release gate.

## Changes made

- Added `tools/csv_json_mirror_audit.py` and `META/CSV-JSON-Mirror-Audit-current.*` for exact CSV/JSON row, key, order, and value comparison.
- Added `tools/schema_coverage_audit.py` and `META/Schema-Coverage-Audit-current.*` for blocking mirror/companion failures plus visible non-blocking schema backlog.
- Added `tools/package_file_inventory.py` and `META/Package-File-Inventory-current.*` for stable file classification by zone, role, currentness, generator, and public-release scope.
- Added field schemas for the three new reports.
- Added rules 61-63 and release-gate checks 16-18.
- Updated QA and schema validation so the new reports are enforced.
- Updated generated-artifact provenance and package-dependency graph coverage.

## Public release effect

No new public prose, public URL, live referral, case detail, testimony, image, route, support path, current-capacity claim, or implementation-as-safety claim is released. The public layer remains a scrubbed index/policy/template/manifest layer only.

## What this pass blocks

- Treating CSV/JSON mirrors as safe when only row count and keys match.
- Treating schema debt as invisible because legacy tables still work.
- Shipping stable files without a machine-readable zone/role/currentness classification.
