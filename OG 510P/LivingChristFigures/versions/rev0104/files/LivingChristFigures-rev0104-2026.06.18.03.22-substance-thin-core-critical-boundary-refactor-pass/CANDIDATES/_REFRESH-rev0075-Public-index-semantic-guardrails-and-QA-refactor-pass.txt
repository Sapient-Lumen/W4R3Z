# rev0075 refresh note — public-index semantic guardrails and QA refactor

This pass converts the rev0074 diagnostic finding into a release-blocking fix.
The public-safe index renderer now uses a shared template policy module so that
an explicit governance quarantine remains a no-expansion tier rather than a
claim that every quarantined candidate belongs to the Bridget Tolley / MMIWG
Canada domain.

The public layer remains closed. The revised templates preserve only broad,
non-referral boundary shapes for identity restitution, migrant-threshold
accompaniment, forensic return of names/remains, genocide-memory accountability,
and MMIWG family-led search. They do not release URLs, contacts, routes, DNA or
sample paths, case lists, testimony, images, public intake guidance, or current
capacity claims.

The pass adds `tools/public_template_policy.py`,
`tools/public_index_semantic_audit.py`, a semantic release gate, a mutation
selftest canary, and a field schema for the semantic audit. This is a small QA
refactor rather than another doctrine-only registry layer: template dispatch is
now centralized and the public index must fail if a non-MMIWG row inherits the
MMIWG/Canada public shape.
