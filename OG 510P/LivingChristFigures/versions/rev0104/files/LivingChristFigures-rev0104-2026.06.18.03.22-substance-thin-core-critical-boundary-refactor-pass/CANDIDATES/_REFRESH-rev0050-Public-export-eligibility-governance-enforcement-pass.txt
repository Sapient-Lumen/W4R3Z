# rev0050 — public-export eligibility / governance-enforcement pass

CENTRAL SENTENCE: Public visibility is not public eligibility; eligibility is not release; release is not referral.

## Why this pass exists

rev0049 added governance protocols and a safe renderer, but the public index still needed an explicit candidate-level eligibility object. Without that object, a reader or future tool could treat the existence of a public row, a public source, or a public template as release permission.

rev0050 adds a machine-readable eligibility gate between the working cube and public surfaces. The gate classifies every candidate by public tier and template, derives source-link and harm-proximity cautions, and keeps public prose expansion separate from index generation.

## Changes made

- Added `tools/public_export_eligibility.py`.
- Added `META/Public-Export-Eligibility-current.*` with one row per candidate.
- Updated `tools/render_public_safe_index.py` so the public index depends on the eligibility ledger.
- Added `GOVERNANCE/Public-Export-Eligibility-Protocol-current.md`.
- Added `GOVERNANCE/Governance-Decision-and-Review-Protocol-current.md`.
- Added `GOVERNANCE/Governance-Decision-Ledger-current.*`.
- Added `GOVERNANCE/CARE-OCAP-UNDRIP-Crosswalk-current.*` as a cautionary crosswalk, not a compliance claim.
- Added field schemas for public-export eligibility and governance decisions.
- Expanded public-safe claim-shape templates.
- Added rule 50 and QA/schema validation for eligibility coverage and allowed tier/template values.

## Public release effect

No new public prose, public URL release, live referral, case detail, testimony, image, route, support path, or current-capacity claim is released. The public index remains a renderer-generated, boundary-first, non-referral index.

## Next review

Add a source-link review ledger before exposing any public URL in a public-only export. Public URL exposure should fail closed when the linked source is contact-rich, case-extractable, testimony-rich, image-sensitive, event/map-adjacent, route-adjacent, or otherwise near harm.

## Deepening within rev0050

A per-source public-link review ledger was added after the first eligibility pass. `META/Public-Source-Link-Review-current.*` now covers every Source Registry row and classifies public URL exposure as blocked, blocked-until-review, boundary-note-only-after-review, or context-link-after-review.
