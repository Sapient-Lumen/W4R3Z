# rev0049 — governance spine / public contract / lifecycle pass

CENTRAL SENTENCE: Public availability is not public permission; a source is not a consent record; a public link is not a release.

CARRIED MMIWG2S+ SENTENCE: A family-led search is not a case list; a vigil is not a map; an inquiry scorecard is not safety.

## Why this pass exists

rev0048 made the right substantive refusal around MMIWG2S+ family-led search, but the cube still had an implementation problem: older front-door files carried older revision labels, the public layer had a contract mismatch, evidence-lifecycle boundary classification depended on a stale hardcoded set, and Indigenous data governance existed mainly as prose caution rather than as a concrete package layer.

rev0049 treats those as safety problems, not housekeeping. In this cube, metadata, public files, schema contracts, and source links are release surfaces. A stale spine invites stale behavior; an uncontracted public file invites accidental handoff; a public link can function as a contact path or case-list route; and a family story can be over-extracted even when a source is public.

## Changes made

- Added `CURRENT-SPINE.md` as the current package orientation.
- Added `GOVERNANCE/` protocol files for Indigenous data governance, family consent/case-name use, and takedown/reclassification.
- Added schema vocabularies for Indigenous data-governance fields, harm proximity, public-link policy, and public-allowed claim shapes.
- Added public-safe prose templates and a renderer for the public candidate index.
- Added harm-proximity and public-link-policy fields to Source Registry rows.
- Updated Source-Type controlled vocabulary with evidence weight, refresh sensitivity, contact/testimony/case-extraction risk, and default public-link policy.
- Updated the claim-type taxonomy with lifecycle boundary hints and public-release posture.
- Rewrote evidence lifecycle classification so boundary-like claims are detected from taxonomy and text rather than only a fixed set.
- Added `rule46_scan.py`, `public_contract_check.py`, and `render_public_safe_index.py`.
- Upgraded schema validation and QA around public contract drift.
- Repaired a clean-extraction Unicode filename mismatch for the Sonia Bermúdez candidate.

## Public release effect

No new public claim is released. The public index remains scrubbed and non-referral. Public prose now has templates and allowed-shape constraints, but those are gates, not publication approval.

## Next review

Before adding more MMIWG2S+ candidates or expanding public prose, complete a manual governance review of family/community consent posture, public-link exposure, image/testimony risk, and takedown readiness.
