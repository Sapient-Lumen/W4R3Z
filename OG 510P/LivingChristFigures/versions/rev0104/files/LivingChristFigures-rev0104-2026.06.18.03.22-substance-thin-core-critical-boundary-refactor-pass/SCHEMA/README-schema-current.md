# SCHEMA / CONTRACT LAYER — current

This directory was added in rev0031.

The cube had already gained strong human-readable rules, redaction scanning, and
ledger QA. The next failure class is contract drift: a file can look morally
careful while its machine-readable fields, public export manifest, JSON mirrors,
or source-role labels quietly diverge.

Files:

- `Frontmatter-Contract-current.json` — required fields and invariants for
  candidate, office-card, and refresh-note front matter.
- `Ledger-Contract-current.json` — exact CSV header contracts and JSON mirror
  expectations for current ledgers.
- `Source-Type-Controlled-Vocabulary-current.*` — controlled mapping for
  `Source-Registry-current.csv.source_type`.
- `Package-Release-Contract-current.json` — package-level invariants that should
  hold before a cube revision is treated as handoff-safe.
- `Schema-Validation-Report-current.*` — last validation report generated by
  `tools/schema_validate.py`.

This layer is deliberately boring. Mercy needs boring infrastructure.
