REASONING NOTE rev0050

The deepest remaining weakness after rev0049 was not a missing caution sentence but a missing decision object between the working cube and public surfaces. A public row, public source, or allowed template could still be mistaken for release permission.

rev0050 turns that gap into a machine-readable gate: every candidate now receives a public-export tier, a public-shape template, a URL-release posture, and review blocks for capacity, images, case details, source links, and governance. The renderer now consumes that gate rather than only reading candidate rows.

Speculative next direction: the next high-value layer is a source-link release ledger. Candidate eligibility can say a public URL is blocked or review-required, but each URL exposure decision should eventually have its own reversible record.
