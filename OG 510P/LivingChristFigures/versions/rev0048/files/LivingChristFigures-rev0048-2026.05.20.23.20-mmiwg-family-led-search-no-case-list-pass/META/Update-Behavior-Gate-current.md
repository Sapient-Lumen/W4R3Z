# Update Behavior Gate — current

A critique has not corrected the cube merely because the critique was quoted, praised, loved, or aesthetically preserved.

For a dissent, boundary essay, or evidence-debt finding to count as a behavioral update, at least one of the following must change:

1. A rule in `CUBE-RULES.txt`.
2. A QA check in `tools/qa_cube.py`.
3. A candidate file, office card, refresh note, or longform seed.
4. A current ledger row: candidate, claim, source, evidence debt, refresh, longform, or meta.
5. The public redaction policy or public export manifest.
6. A source standard or claim-status standard.
7. A future-pass priority with an explicit review target.

If none of those changes, the update is `literary_update_only` until proven otherwise.

Core warning:

> A beautiful dissent registry is not yet a veto mechanism.

## rev0034 behavior-gate application

A veto-like behavior change now counts when the cube records an attractive source but blocks it from Source-Registry, claim, candidate prose, or public wording. `opreceipt_0004` applies this to `opdist_0001`: the operator cannot close the critique merely by admiring it; the package now has a promotion ledger and a quarantine ledger that make non-promotion auditable.


## rev0035 behavior-gate application

A promotion is not a behavioral update merely because a source moved into `Source-Registry-current.*`. In rev0035, the update counts only because the promotion was atomic: source rows, claim rows, evidence debt, lifecycle classification, quarantine removal, release ledger, transaction audit, operator-update audit, and QA all changed together. The official project.ME pages stayed held, proving that a candidate-specific promotion can still preserve a veto.


## rev0038 behavior-gate application

A counterpressure source is not a behavioral update if it merely makes the archive more vivid. In rev0038, the update counts because HRO material is promoted only with a no-route rule, claim edits, source/debt/quarantine updates, a transaction receipt, and no public claim release. Documentation of harm cannot become a guide to where harmed people are.


## rev0039 behavior-gate application

A standards or funding source is not a behavioral update if it merely lets the cube sound more current. In rev0039, the update counts because current regional sources are used to block directory-like crisis-centre prose: contact-rich pages remain held, claims/debts/quarantine rows are updated, rule 37 is added, and no public claim is released.
