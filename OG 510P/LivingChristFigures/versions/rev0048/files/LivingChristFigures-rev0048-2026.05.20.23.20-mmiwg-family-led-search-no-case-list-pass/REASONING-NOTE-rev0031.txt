REASONING NOTE — rev0031 schema / source-role contract pass

No new candidate was added in this revision.

After rev0030 removed exact contact digits and made redaction risk scanner-backed,
the next failure class was handoff drift: a future reader, script, or model could
trust front matter, ledger headers, public export metadata, JSON mirrors, or
source_type labels before reading the prose. Rev0031 therefore adds a schema
contract layer.

Why this matters:
- A hash can prove bytes did not change while the schema still permits bad
  meaning.
- A public profile, critical article, government page, academic paper, and
  nonprofit self-description should not silently carry the same evidentiary role.
- JSON mirrors are likely to be used by future tools first; they must stay in
  lockstep with CSV ledgers.
- Public export manifests are handoff objects and should match the package
  revision.

This pass intentionally did not perform outward fact refresh. It makes the cube
more auditable, not more complete.
