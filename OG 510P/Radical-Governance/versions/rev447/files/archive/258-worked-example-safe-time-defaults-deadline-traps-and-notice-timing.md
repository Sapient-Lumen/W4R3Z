# Worked Example Safe-Time Defaults, Deadline Traps & Notice Timing


**Purpose:** make the example system explicit about when a deadline is not actually usable and what should happen when timing is fake.

**Person served:** clerks, hearing officers, advocates, operators, engineers, and auditors dealing with “the deadline passed” claims where real access to time was broken.

---

## Safe-time defaults
Generated time is not always usable time. Weekends, closures, outages, translation or accessibility delays, hospitalization, detention, and state-caused delivery failure should reopen or pause clocks instead of being recoded as waiver.
