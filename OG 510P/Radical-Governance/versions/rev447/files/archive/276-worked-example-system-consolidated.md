
# Worked Example System (Consolidated Architecture)

This memo consolidates the previously fragmented worked-example layer
(237–247) into a single coherent architecture.

## Core Functions
1. Evidence packets and review views
2. Comparison cuts and starter packets
3. Retrieval atlas and indexing
4. Sequence builders and themed reading packs
5. Role-based field manuals
6. Implementation bridge / retrofit sequences
7. Counterfactuals and minimum-viable fixes
8. Training drills and quick-reference sheets

## Architectural Model
Worked examples should function as an operational layer that translates
theoretical governance designs into:

- decision-support artifacts
- training materials
- policy retrofit pathways
- diagnostic comparison tools

## Canonical Workflow
Problem → Evidence Packet → Comparison Cuts → Counterfactuals →
Implementation Bridge → Role Manuals → Training Drills

## Archive Policy
The earlier memos remain for historical continuity but should be treated
as component modules of this system.
