# Future Guardianship & Standing (Make “future people” legally contestable)

**Problem:** long-horizon harms (climate, biodiversity loss, debt, irreversible infrastructure, AI lock‑in) often have **no plaintiff, no deadline, and no “decision point”**—so they slip past contestation.

**Design goal:** create **standing + triggers + remedies** for future‑oriented claims, while avoiding “priesthood” technocracy.

---

## Minimal primitives (portable across scopes)

### 1) Standing-by-default for defined future interests
Create a **standing class** for:
- **Minors + next‑generation cohorts** (e.g., next 25 years).
- **Ecological trusteeship interests** (watersheds, habitats) as *rights/obligations objects*.
- **Intergenerational fiscal exposure** (debt/service burdens transferred beyond current term).

Standing holders can include:
- an **independent Future Generations Commissioner / Guardian** (public interest litigant),
- **civil society “intervenor” accreditation** (bounded, rotating),
- **randomly selected citizen counsel panels** (jury-like) for escalation gating.

(Real-world anchors: Wales Future Generations architecture; Hungary’s future generations ombuds role; UN’s emerging “future generations” commitments.) ### 2) Trigger list for “irreversibility review”
Certain acts require a **Future Impact Review (FIR)** and a **contest window**:
- **Irreversible / hard-to-reverse** infrastructure decisions (lock‑in > 20y).
- **High option value loss** (biodiversity, aquifers, land conversion).
- **Long-tail liability** (nuclear waste, hazardous waste siting).
- **Intergenerational fiscal commitments** (pensions, debt, off‑balance-sheet obligations).
- **High systemic risk tech** adoption (critical AI, identity rails, payments utilities).

The trigger list must be:
- **short**, scope‑fit, and updated via **change control** (see `118-*`).

### 3) “Burden-shifting” evidentiary rule
When triggers apply, shift burden:
- proponent must show **(a)** less‑locking alternative considered, **(b)** reversibility plan, **(c)** monitoring + exit ramps, **(d)** who bears costs and when.

### 4) Remedies that don’t require perfect forecasting
Prefer **option-preserving** remedies:
- **pause + redesign** (not “ban forever”),
- **design constraints** (reversibility, modularity),
- **bond/escrow** for tail risks,
- **sunset + mandatory reevaluation**,
- **compensation/repair** obligations with enforceable funding.

## Institutional patterns (avoid technocracy)

### A) Guardian as “procedural referee”, not “policy czar”
Guardian powers:
- demand FIR,
- publish “future docket” summaries,
- intervene in court/tribunal,
- refer to auditor/ethics bodies,
- trigger citizen counsel review.

Guardrails:
- **term limits**, conflict rules, transparency,
- **no unilateral veto**; only delay + contestation unless hard legal thresholds met,
- **appeal path** and **performance audit**.

### B) Citizen counsel escalation gate
Use sortition to form a small panel that:
- reviews FIR,
- can authorize escalation (litigation / referendum / legislative override),
- provides legitimacy against capture.

(See `119-*` and `111-*` for binding pathways.)

## Implementation checklist (copy/paste)

1. Define standing class + authorized representatives  
2. Publish irreversibility triggers + contest windows  
3. Create FIR template + minimum evidence fields  
4. Specify burden-shifting rule + default remedies menu  
5. Assign guardian authority + audit + appeal mechanics  
6. Add budget/escrow rails for tail risks  
7. Link to change-control + emergency-derogation rules (`118-*`, `112-*`)
