## How to read examples without losing the theory

### Start with examples when:
- the failure is vivid but the institutional cause is not;
- you need a tabletop, training, or audit drill;
- you are testing whether a proposed rail is actually humane in a bad-day scenario.

### Start with thematic memos when:
- you are designing institutions or legal structure;
- you need artifact definitions, registers, or threshold rules;
- you are deciding scope assignment or implementation sequencing.

### Best practice
Use the path:
**symptom → worked example → artifact failure → domain memo → implementation rail**.

That sequence keeps the archive from drifting into theory without person-path proof.
