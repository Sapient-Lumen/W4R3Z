
# 279 — Governance Systems Map (Canonical Architecture)

This memo defines the high‑level architecture organizing the Radical Governance archive.
Earlier revisions accumulated many memos describing governance mechanisms, diagnostics,
and worked examples. Rev444 introduces a canonical systems map to reduce semantic
duplication and improve navigability.

## Core Governance Systems

1. Legitimacy System
   - consent, trust, mandate formation
   - electoral and participatory legitimacy
   - constitutional guardrails

2. Decision System
   - agenda formation
   - deliberation structures
   - decision authorities
   - emergency powers

3. Implementation System
   - administrative execution
   - procurement and contracting
   - regulatory deployment
   - service delivery pipelines

4. Oversight System
   - auditing
   - transparency
   - anti‑corruption systems
   - watchdog institutions

5. Justice and Redress System
   - grievance mechanisms
   - appeals
   - remedies and restitution
   - procedural fairness

6. Crisis Governance System
   - emergency authorities
   - disaster response
   - public‑health governance
   - wartime command structures

7. Inter‑Jurisdiction Coordination
   - federalism
   - treaty systems
   - regional cooperation
   - multi‑level governance

8. Evidence and Metrics System
   - measurement infrastructure
   - evaluation and impact assessment
   - policy experiments
   - public data systems

9. Institutional Learning System
   - post‑mortems
   - worked examples
   - institutional memory
   - training systems

10. Institutional Reform / Retrofit System
   - governance transition pathways
   - constitutional amendments
   - institutional redesign
   - reform sequencing

## Worked‑Example Subsystem

The worked‑example documents (239–247) are now treated as modules of the
Institutional Learning System.

Modules include:

• evidence packets  
• comparison cuts  
• retrieval atlas  
• sequence builders  
• role‑based manuals  
• implementation bridges  

Operational learning pipeline:

Problem
→ Evidence Packet
→ Comparison
→ Counterfactuals
→ Implementation Bridge
→ Institutional Retrofit

## Archive Principle

When future documents overlap conceptually, they should:

1. Attach to one of the ten systems above
2. Extend the subsystem rather than duplicating explanations
3. Reference canonical memos instead of repeating them
