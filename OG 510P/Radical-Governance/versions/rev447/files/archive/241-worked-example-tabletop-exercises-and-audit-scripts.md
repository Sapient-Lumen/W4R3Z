# Worked Example Tabletop Exercises & Audit Scripts


**Purpose:** turn the examples into rehearsal material for teams that need to test whether their workflow behaves safely under stress.

**Person served:** training teams, auditors, supervisors, engineers, and field operators.

---

## Tabletop prompts

1) **Live harm in motion:** run `WX-36` or `WX-37` and identify the last harmful edge, the halt owner, and the portable proof the person can carry.
2) **Proof under contest:** run `WX-43` and ask what happens when the institution cannot produce the packet it says it used.
3) **Transfer seam:** run `WX-32`, `WX-47`, or `WX-50` and ask which facts must survive the handoff and what pauses automatically if they do not.
4) **Shadow finality:** run `WX-49` or `WX-51` and ask which supposedly preliminary layer is already acting as the real gate.

## Audit script spine
- What artifact should exist here?
- Can the person inspect it without insider status?
- What protects the person while the dispute is unresolved?
- If the system says it is fixed, who can independently replay that claim?
