# Bibliography (Citation Keys — Extended)

**Purpose:** act as the archive’s evidence docket—traceability without forcing every memo to grow long.

**Person served:** Practitioners and researchers who need a deeper evidence docket to trace claims while keeping the main archive tight.

**From-below:** This expands the source trail so you can go deeper, verify contested claims, and replace weak evidence without bloating the memos.

This file holds the **extended** citation keys (`[BIB-*]`) that are referenced less frequently.

It is the archive’s **evidence docket**: each key makes a recommendation traceable, contextualizable, and contestable without inflating every memo.
(See `101-claude-rev142-normative-requirements.md` (NR-20).)

Policy:
- Do not create duplicate keys for the same source.
- Prefer adding one-off sources directly in the memo that uses them; promote here only when reused.

## Kernel anchors (do not repeat)
- Core citation keys and policy: `90-bibliography.md` (foundational), `96-archive-governance.md` (density rule).
- Where citations land in operational artifacts: `51-release-registry.md`, `31-records-foi-and-government-memory.md`.

## Named tensions (design must surface these)
- Traceability vs bloat (citations must support contestation without inflating memos).
- Link rot vs durable reference (prefer stable publication hubs; keep keys even if URLs change).
