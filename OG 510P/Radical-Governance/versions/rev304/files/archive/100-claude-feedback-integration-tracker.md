# Claude rev142 Integration Tracker (rev304, compact)

**Purpose:** keep Claude rev142 integration systematic *without inflating the archive*.

**Person served:** Maintainers who need a one-screen map of which Claude rev142 constraints are enforced, where, and what remains.

**From-below:** This prevents “integration drift” by making the from‑below constraints auditable and easy to apply.

**How to use:**
- Definitions and citations for each requirement live in `101-claude-rev142-normative-requirements.md`.
- When touching a memo, update it to cite `101` (NR-xx) (or the canonical internal anchor listed there) and mark progress here.
- The previous, detailed tracker is preserved temporarily at `../sources/claude-feedback/rev142/integration-tracker-detailed.md` for migration work (it is not an archive artifact and will be deleted when `sources/claude-feedback/rev142/` is retired per `96` / `NR-19`).

**Legend:** DONE / PARTIAL / PENDING (DONE = enforcement points exist and the constraint is consistently applied in the canonical anchors; per-file migration may still be ongoing).
