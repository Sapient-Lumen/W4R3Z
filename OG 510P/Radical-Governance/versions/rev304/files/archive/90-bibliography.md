# Bibliography (Citation Keys — Core)

**Purpose:** provide the core evidence base and references without inflating the archive’s prose.

**Person served:** Readers trying to verify, implement, or contest this archive who need credible sources without link‑rot or bloat.

**From-below:** This gives you the source trail to verify claims and challenge them without hunting through link‑rot or inflated prose.

This is the **core** set of reusable citation keys (`[BIB-*]`) referenced across many memos.

- Keep keys stable. If a URL changes, update it **without** changing the key.
- Prefer citing keys inline (e.g., `see [BIB-UDHR]`) so links remain stable.
- The **extended** key list lives in `91-bibliography-extended.md` (same key format; nothing breaks if a key is defined there).

## Kernel anchors (do not repeat)
- Evidence docket + extended keys: `91-bibliography-extended.md`.
- Archive density policy / key stability rule: `96-archive-governance.md`.

## Named tensions
- Traceability vs archive bloat (cite keys; don’t paste large bodies of text).
- Link rot vs stable keys (update URLs without changing keys).
