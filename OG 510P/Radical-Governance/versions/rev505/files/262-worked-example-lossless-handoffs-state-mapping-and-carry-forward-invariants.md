# Worked Example Lossless Handoffs, State Mapping & Carry-Forward Invariants


**Purpose:** define what must survive a transfer so language access, disability accommodations, confidentiality markers, representative contacts, and similar support states do not vanish when the file moves.

**Person served:** transfer coordinators, accessibility leads, intake teams, engineers, auditors, advocates, and supervisors.

---

## Handoff invariants

| State that should survive | Protective default if the receiving side cannot prove it survived |
|---|---|
| language / interpretation need | pause adverse clocks and provide assisted contact |
| disability / accessibility accommodation | keep the last accommodation live until equivalent support is ready |
| confidentiality / safety marker | preserve the higher-protection state during transfer |
| representative / counsel / advocate contact | no hearing / closure / deadline hardening until notice reaches the recognized representative path |
| continuity-critical service state | bridge or continuation stays live until receiving readiness is proved |
