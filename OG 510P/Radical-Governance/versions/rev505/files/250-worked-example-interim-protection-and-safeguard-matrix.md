# Worked Example Interim Protection & Safeguard Matrix


**Purpose:** make the first protective move explicit so the archive answers “what keeps the person safe while review runs?”

**Person served:** intake staff, advocates, supervisors, operators, and implementers.

---

## Safeguard matrix

| Situation | Immediate safeguard |
|---|---|
| cutoff / debt / extraction | hold the next adverse financial pull |
| transfer / queue / renewal seam | preserve the last safe state or queue position |
| live coercive or housing harm | stop the last harmful edge and issue portable proof |
| access or notice failure | reopen the clock and freeze derivative penalties |
| support-state loss at handoff | pause adverse clocks until the receiving side acknowledges the support state |
| invalid authority or shadow finality | suspend execution until the valid binding owner is visible |
