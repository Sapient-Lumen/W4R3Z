# Worked Example Compound-Harm Chains & Cascade Maps


**Purpose:** show how one administrative failure can propagate into several linked harms so the archive can interrupt cascades rather than only single incidents.

**Person served:** implementers, advocates, auditors, and organizers trying to see where one break should stop several downstream harms.

---

## Rule of thumb
Do not close the originating case while derivatives are still live elsewhere.
