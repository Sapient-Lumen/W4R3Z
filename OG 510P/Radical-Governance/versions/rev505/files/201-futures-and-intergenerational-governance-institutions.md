# Futures & intergenerational governance institutions

**Problem:** Democratic systems over‑weight the present. Long‑horizon harms (climate, infrastructure decay, debt traps, irreversible tech risk) accumulate because near‑term incentives dominate.

**Design goal:** Add *future‑orientation* without creating an unaccountable “guardian caste”. Futures institutions must be **advisory + auditable + joinable** to ordinary decision flows, and **reversible** if captured.

## Minimum viable pattern: a Futures Node

A Futures Node is an institution that produces **Foresight Receipts** that must be explicitly addressed in major decisions (budget, regulation, large programs).

### Core outputs (joinable artifacts)

- **FRR‑*** — *Foresight Review Receipt*: scenario set, key assumptions, sign‑off chain, uncertainty bounds, dissent log.
- **LIR‑*** — *Long‑Impact Register entry*: a maintained list of long‑tail risks/opportunities with triggers and owners.
- **FAR‑*** — *Future Audit Response*: when government rejects/overrides futures warnings, it must publish reasons and mitigation.

## Guardrails (anti‑capture)

1. **No veto by default.** Futures Nodes influence via *obligation to respond*, not unilateral blockage. (Exception: narrowly defined “irreversibility triggers”, below.)
2. **Method transparency.** Assumptions, models, evidence sources, and uncertainty ranges must be public by default (bounded national-security redactions with receipts).
3. **Rotation + diversity.** Use mixed membership: elected officials, civil service analysts, and a rotating citizen panel (sortition) for legitimacy.
4. **Conflict firebreaks.** Interests are disclosed; direct beneficiaries of outcomes cannot serve on relevant reviews.
5. **Sunset discipline.** The Futures Node has renewal clocks and periodic independent evaluation (see `178-institutional-lifecycle-sunsets-and-scrutiny.md`).

## Optional: irreversibility triggers (rare)

For a small class of decisions that are *hard to unwind* (e.g., constitutional entrenchment, irreversible ecosystem loss, high‑risk tech deployment), define **Irreversibility Trigger Receipts (ITR‑*)**:

- trigger condition and why reversibility is low
- time‑bounded pause window
- escalation path: independent review + court + legislature
- “safe‑harbor” alternative action the government can take during pause

This is a *speed bump*, not a permanent brake.

## Where to place this by scope

- **Municipal / regional:** infrastructure resilience, land-use path dependency, water/energy planning, local climate risk.
- **National:** fiscal sustainability, defense posture, long-run industrial policy, AI/biotech risk governance.
- **Supranational / global:** shared risks (climate, pandemics, AI safety), treaty compliance, cross-border spillovers.

## Real-world inspiration (do not copy; adapt)

- OECD’s evidence on **representative deliberative processes** and their design/evaluation provides an empirical base for citizen panels attached to futures work.
- Finland’s parliamentary **Committee for the Future** illustrates an institutional “think tank” inside a legislature that works on foresight + tech policy.
- UN University and IPU note a broader movement of **committees for the future** as a response to political myopia.

## Tests (add to `107`)

- **Futures joinability:** Any major decision includes a pointer to relevant `FRR/LIR` items (or a signed “none applicable” statement).
- **Obligation to respond:** If an `FRR` flags material long-horizon risk, the decision record includes a `FAR` response or a time-bounded deferment.
- **Capture tripwires:** funding dependence, revolving door, opaque assumptions, repeated non-response, or suppressed dissent triggers an automatic audit.
