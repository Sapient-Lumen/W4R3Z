# 306 — Scope Design / Ideal Government / Reference Bundles Guide

**Purpose:** turn the archive’s scope-design family into a readable stack so the ladder, assignment test, quick cards, cross-scope synthesis, reference bundles, tempo defaults, epistemic defaults, accountability defaults, coercion defaults, finance defaults, capacity defaults, artifact defaults, constituency defaults, decision-rule defaults, selection defaults, tenure defaults, office-status defaults, remedy defaults, geometry defaults, participation defaults, and scope-specific memos stop competing for the same conceptual role.

**Why this memo exists:** `14`, `54`, `103`, `176`, `285`, `327`, `328`, `329`, `330`, `331`, `332`, `333`, `334`, `335`, `336`, `337`, `338`, `339`, `340`, `341`, `342`, `343`, `71`, and the scope-specific memos (`10`, `20`, `87`, `16`, `30`, `40`, `50`, `60`) all surface for queries like “what should ideal government look like at each scope”, “which level should own this function”, “what is the minimum viable government for a city or region”, “how should local and national roles differ”, “what institutional form should this scale default to”, “what legitimacy channel should this scale mainly use”, “what tempo should this scale run on”, “what evidence mode should this scale mainly govern with”, “what accountability mode should this scale mainly rely on”, “which scale should directly hold coercive powers”, “what finance model should this scale mainly rely on”, “what kind of operator or staffing pattern should this scale usually have”, “what public records, journals, or registries should this scale usually expose”, “who should count as the relevant public at this scale”, “what decision rule should this scale usually rely on”, “how should offices at this scale usually be filled”, “how long should authority at this scale usually last”, “should office here be volunteer, part-time, salaried, or full-time?”, “what review or remedy path should fit this scale?”, “what map or boundary logic should this scale actually use?”, or “what should global governance actually be if it is not a world state?”, or “how should people actually get into the process at each scale between elections and court cases?”. They are not duplicates, but they are dense enough to deserve an explicit family router.

**Evidence anchors:** OECD’s current multi-level-governance hub still frames good policy as coordination across national, regional, and local levels rather than siloed decentralisation [BIB-OECD-MLG-HUB-2026]. OECD’s 2025 stocktake on the Principles on Urban Policy reports that 69% of respondent countries have already used the Principles to guide policy, which is useful evidence that place-adapted scope design is not a purely theoretical concern [BIB-OECD-URBAN-POLICY-5Y-2025]. OECD’s 2024 regions-and-cities overview keeps stressing that governments need to tailor solutions to the needs and opportunities of different places rather than govern only from national averages [BIB-OECD-RCAG-2024]. UNDP’s 2025 community-based resilience guidance is a useful reminder that micro-local and local-government design matters because resilience, adaptation, and recovery often depend on community-facing capacity rather than distant formal authority alone [BIB-UNDP-CBRB-2025].
