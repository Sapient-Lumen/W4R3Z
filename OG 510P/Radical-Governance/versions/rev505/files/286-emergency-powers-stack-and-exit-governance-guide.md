# 286 — Emergency Powers Stack and Exit Governance Guide

**Purpose:** turn the archive’s emergency / exception cluster into a readable stack so constitutional emergency theory, generic exception control, receipted emergency rails, and public-health-specific operations stop looking like accidental duplicates.

**Why this memo exists:** `23`, `112`, `165`, `186`, and `234` all govern exceptional state action under time pressure. They overlap because they are meant to compose. The archive should name the handoffs explicitly instead of inviting flattening.

**Evidence anchors:** legality / necessity / oversight / duration benchmarks [BIB-VENICE-EMERGENCY-DEM-HR-ROL-2020-014] [BIB-VENICE-COVID-EMERGENCY-2020]; emergency-powers standards access point [BIB-COE-EMERGENCY-STANDARDS-2026].

## Canonical reading order

### 1. Start with `23-emergency-governance-and-exceptions.md`
Use `23` when the question is:
- what emergency government is for,
- what the broad legitimacy and rights floor is,
- and how crisis powers fit into the wider architecture of rule-of-law governance.

`23` is the **broad system frame and front door**.

### 2. Move to `112-exception-control-and-emergency-powers.md`
Use `112` when the issue becomes:
- how an exception should be structured as an override,
- what generic locks should prevent drift,
- and how to make deviations visible even outside a formally declared emergency.

`112` is the **generic exception-control kernel**.

### 3. Use `165-emergency-powers-derogation-sunsets-rails.md`
Use `165` when you need:
- proclamation packets,
- renewal hearings,
- rights-impact rails,
- emergency procurement discipline,
- and a full receipted emergency-powers operating lane.

`165` is the **canonical emergency-powers rails layer**.

### 4. Use `186-emergency-powers-derogations-and-sunset-discipline.md`
Use `186` when the core question is narrower:
- what an Emergency Declaration Receipt must contain,
- how renewal thresholds work,
- how derogations are itemized,
- and how rollback / repair discipline is made explicit.

`186` is the **declaration, renewal, and sunset-discipline companion**.

### 5. Use `234-public-health-preparedness-and-response-rails.md`
Use `234` when the issue is:
- outbreak and pandemic operations,
- public-health threat registers,
- scarcity allocation,
- cross-border health coordination,
- or public-health-specific powers that need tighter operating artifacts.

`234` is the **public-health preparedness and response specialization**.

## Confusion boundaries

### `23` vs `112`
- `23` explains the **whole emergency-governance frame**.
- `112` explains the **portable exception-control kernel** that can be reused across domains.

### `112` vs `165`
- `112` is about **generic locks and exception visibility**.
- `165` is about **the full receipted emergency-powers operating sequence**.

### `165` vs `186`
- `165` is the **wider rails memo** for proclamation, review, procurement, rights, and exit.
- `186` is the **narrower declaration / renewal / sunset discipline memo**.

### `165` / `186` vs `234`
- `165` and `186` apply across emergency domains.
- `234` is the **public-health operating specialization** and should not silently become the general emergency memo.
