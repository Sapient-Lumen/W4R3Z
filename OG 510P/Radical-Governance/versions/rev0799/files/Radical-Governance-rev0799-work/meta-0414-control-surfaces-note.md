# 0414 — Control-surface crosswalk note

This revision adds `CONTROL_SURFACES.json`, a small generated crosswalk that groups the archive by higher-level governance surfaces rather than only by note number or theme tag.

Why this helps:

- thread tags are useful, but they are increasingly granular;
- merge work benefits from a second view that answers **where** a note acts in the operating model;
- review passes can now ask whether the archive is thin on boundary-setting, predeployment evidence, live operations, user interaction, evidence and redress, or supplier/ecosystem governance.

The surface map is intentionally heuristic rather than canonical. It is meant to make the continuation snapshot easier to compare and merge, not to freeze one true taxonomy for the full archive.
