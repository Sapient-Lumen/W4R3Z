# Meta 0420 — Regulatory and treaty case-packets note

This continuation adds the two applied packets that the rev0718 matrix explicitly left open: a pure regulatory/enforcement packet for `824` and a treaty / global narrow-waist packet for upper-tier coordination.

`854` uses a regional port-state-control inspection regime because it is coercive without being asset-led or contract-led. It shows that inspection authority, officer qualification, ship-risk profile, deficiency evidence, detention, refusal of access, appeal, data correction, and regional audit are first-class governance fields.

`855` uses the International Health Regulations because it is a legally meaningful global coordination waist without being a world government. It shows that notification, verification, WHO contact routes, emergency-committee advice, PHEIC / pandemic-emergency alerting, temporary recommendations, amendment applicability, capacity review, and domestic-rights boundaries can be strong and narrow at the same time.

The point of this revision is not to enlarge the doctrine. It is to finish the applied pressure set so the next pass can audit consolidation of `812`–`824` using actual case recurrence rather than intuition.
