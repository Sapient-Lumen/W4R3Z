# Meta 0425 — Municipal distress handback note

This release adds the archive's first fiscal-distress handback packet. The new `868` lens and `869` Detroit Financial Review Commission case are meant to keep emergency oversight from becoming permanent shadow government while also keeping local-control claims from erasing live waiver, reactivation, pension, contract, record, and final-release conditions.

The new `metadata/handback_tests.json` surface should be run whenever a case involves emergency management, state fiscal review, receivership, bankruptcy exit, waiver, devolution, final release, or sunset. The key rule is that a past emergency is not present authority, and a waiver is not final release.
