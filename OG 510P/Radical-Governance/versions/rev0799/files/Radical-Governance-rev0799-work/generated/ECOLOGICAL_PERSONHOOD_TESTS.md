## Use rule

Run ecological-personhood tests whenever a river, lagoon, forest, mountain, basin, wetland, glacier, reef, aquifer, catchment, or other ecosystem is recognized as a legal person, living entity, rights-bearing subject, protected biocultural entity, or represented by guardians. Separate recognition from representation, implementation, capacity, ecological effect, rights boundaries, liability, and failure routes.
