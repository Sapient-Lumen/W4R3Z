## Use rule

Run service-home tests whenever a metropolitan, regional, joint-powers, shared-service, functional-authority, concession, operator-chain, or cross-boundary service arrangement is cited as proof that a territory has an honest service home. Separate service map, authority, operator, regulator, commissioner, contractor, front door, complaint handoff, continuity, source boundary, and route-absorption parity before treating the arrangement as service government.
