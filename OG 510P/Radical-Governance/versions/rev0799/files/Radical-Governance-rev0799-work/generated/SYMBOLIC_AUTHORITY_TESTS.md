## Use rule

Run symbolic-authority tests whenever a visible authority, partnership, board, JPA, commission, secretariat, hub, or department is credited, blamed, abolished, absorbed, or rechartered for a public outcome whose legal, fiscal, land, data, contract, workforce, or remedy levers sit across multiple principals. The core discipline is to separate mission, mandate, means, record, recourse, attribution, and transition receipt before issuing a success, failure, or repair holding.
