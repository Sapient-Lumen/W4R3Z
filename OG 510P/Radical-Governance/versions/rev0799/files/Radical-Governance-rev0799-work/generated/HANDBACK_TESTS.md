## Use rule

Run handback tests whenever emergency oversight, fiscal review, receivership, state control, devolution, waiver, sunset, or final release is live. A past emergency is not present authority; a waiver is not final release; and handback is not complete until active powers, residual obligations, reactivation triggers, local capacity, service continuity, records, and final-release conditions are public.
