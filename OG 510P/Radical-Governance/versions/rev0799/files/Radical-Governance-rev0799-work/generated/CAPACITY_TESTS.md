## Use rule

Run capacity-floor tests whenever a fragile-jurisdiction, emergency-support, donor-dependent, peace-support, stabilization, technical-assistance, or security-support arrangement is credited as operative public authority. The core discipline is to separate mandate from deployed capacity; pledges from usable resources; access from coverage; support from shadow sovereignty; humanitarian service from security legitimacy; and exit dates from handback receipts.
