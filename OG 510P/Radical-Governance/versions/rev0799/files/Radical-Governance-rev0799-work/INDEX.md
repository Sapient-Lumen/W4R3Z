- explanation without a live recourse path is only partial transparency,
- a log that cannot be turned into a packet is still too internal to govern,
- evidence preservation needs to start before the first formal complaint,
- accessible formats and equivalent alternatives are governance primitives, not support add-ons,
- fallback channels should be measured for parity, not merely listed in guidance,
- thematic tags help continuation bundles remain mergeable as archive threads multiply,
- third-party dependencies are part of the governed system, not backstage implementation noise,
- safe outside reporting is a governance primitive, not a public-relations risk,
- a changed system needs refreshed notice, not just fresh code.
- a public card should state no-use conditions, not only intended use.
- a preview that helps recognition should still refuse approval, authority, or rights inferences it cannot support.
- compact layouts should lose chrome before they lose provenance, blocker truth, or consequence.
- a stale deep link should fail honestly rather than dropping people onto a generic page and hoping they will infer the rest.

- a crowded assurance table may still be one monoculture repeating itself,
- last use and last review are different governance facts and should stay different.
- data provenance is part of the governed system, not backstage analytics plumbing.
- benchmark success is never the whole deployment case.
- a tool approval that is not scoped to a named use case is still too broad to govern,
- disagreement with AI output is a governance signal, not operator noise,

- drills reveal oversight quality that slide decks cannot,
