The core rule is: **no governance repair by disappearance**. A system can be ended, made optional, converted, absorbed, or rebranded without being repaired. The archive now asks for terminal status, successor ownership, affected-user and remedy tail, record preservation, data closeout, procurement / contract closeout, incident learning, cost / benefit separation, residual dependency, and relaunch gates.
