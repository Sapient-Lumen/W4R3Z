# Nicotine+DEV

## A test model can accidentally describe the behavior you wanted

Nicotine+DEV studies correctness through small source-backed research packets. Its selected revision is especially readable as an epistemic lesson: a downstream model encoded the intended disabled policy and thereby concealed behavior in the source path it was supposed to illuminate.

The correction described by the archive separates scheduler eligibility from downstream delivery and demands explicit model/source agreement. This is more interesting than a test count alone. A green model can be reassuring precisely because it has left out the disputed behavior.
