# Native promotion policy: shadow only

`nativepromotionpolicy.py` records the current local policy: GCC-native leaves may remain shadow-observed evidence, but not selected as protocol authority.

The policy denies native load, native dispatch, native result authority, and any ownership of parser, crypto, transport, persistence, policy, moderation, or mutable-truth surfaces.

This is intentionally conservative. A future promotion design would need a new branch and new proof obligations.
