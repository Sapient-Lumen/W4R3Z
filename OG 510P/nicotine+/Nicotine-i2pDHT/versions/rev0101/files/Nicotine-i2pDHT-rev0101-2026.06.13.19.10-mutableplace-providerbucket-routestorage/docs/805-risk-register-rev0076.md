Remaining risks:

- No live I2P/SAM transport.
- No production delivery acknowledgement protocol.
- No real remote witness model.
- No production persistence database.

- Treating canary readiness as delivery.
- Treating useful refusal as delivery success.
- Treating missing ACK as failure instead of watch pressure.
- Dropping redaction or contradiction memory between drain and settlement.
