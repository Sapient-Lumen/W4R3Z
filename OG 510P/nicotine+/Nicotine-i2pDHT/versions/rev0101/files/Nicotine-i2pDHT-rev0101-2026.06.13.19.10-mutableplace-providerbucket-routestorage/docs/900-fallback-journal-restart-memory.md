# Fallback journal restart memory

Fallback is not an invisible implementation detail. When native is not selected, fallback selection becomes previous-linked restart memory.

`fallbackjournal.py` records why the Python path is active: quarantine, watch, operator/policy profile, or native-readiness failure. It binds selection digest, quarantine digest, corpus digest, fallback digest, sequence, previous digest, family, and path family.

The important design pressure is restart safety. A later process must not rediscover a quarantined artifact as fresh merely because the bad decision lived only in RAM.
