# Delivery witness after send

Delivery witness receipts are local evidence, not global truth.  They bind the live-send gate digest, payload digest, idempotency key, session, Destination, endpoint, family, and path family.

The model rejects replay, same-sequence forks, previous-link mismatch, boundary drift, acknowledgement digest drift, hard negatives, and one-family delivery monoculture.

The phrase delivery witness is intentionally repeated for audit needles.
