# Native promotion archive

`nativepromotearchive.py` turns a held promotion-review report into restart-sticky local evidence. It accepts only when the upstream review was accepted, review-held, promotion-denied, and Python-fallback active.

It quarantines native call permission, native result authority, digest drift, replay/rollback, previous-link mismatch, same-sequence fork, low diversity, and required-memory drops.

The archive is not a promotion lane. It is a record that a human/operator review happened and still denied promotion.
