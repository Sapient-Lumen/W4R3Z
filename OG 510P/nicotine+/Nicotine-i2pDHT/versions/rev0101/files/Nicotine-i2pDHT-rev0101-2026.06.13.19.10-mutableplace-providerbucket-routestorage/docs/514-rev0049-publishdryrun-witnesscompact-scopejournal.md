# rev0049 — publishdryrun-witnesscompact-scopejournal

rev0049 treats the post-rev0048 public edge as another no-network protocol boundary.

rev0048 could say: bridge shadow, audit quorum, and redress GC accepted locally.  rev0049 asks the next harder question: **what local evidence is needed before a node even stages a public write attempt?**

New surfaces:

- `publishdryrun.py` — signed dry-run attempts for public bridge records, mutable heads, seed portfolios, or garden catalog edges.
- `witnesscompact.py` — witness/audit compaction that may drop soft convenience evidence but must preserve live refutations, redress gaps, and fork evidence.
- `scopejournal.py` — signed previous-linked restart memory for scoped public side-effect attempts.
- `publishdryrunfold.py` — current-path audit/refactor fold preserving rev0048 `shadowauditfold` as predecessor.

Strong sentence:

> Staging a public edge write is itself a side effect, even before the network sees it.

Nonclaims remain: no live I2P/SAM transport, no production DHT, no production public publication protocol, no global ban list, no global reputation, no private retrieval guarantee, no mutable-head consensus, no Sybil/anonymity guarantee, and no Nicotine+ patch.
