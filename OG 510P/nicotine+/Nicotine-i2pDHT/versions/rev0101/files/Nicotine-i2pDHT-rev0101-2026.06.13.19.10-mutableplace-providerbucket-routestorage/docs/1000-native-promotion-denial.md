# Native promotion denial

`nativepromotiondeny.py` names a subtle social/technical trap: repeated matching native shadow evidence will create pressure to promote the C path.

rev0096 records that such a request was considered and denied locally. That denial is useful evidence, not a final forever-ban on future native work. A future revision may define a real promotion process, but this lane prevents accidental promotion by shadow-match accumulation.

Accepted denial requires:

- archived Python-route call evidence,
- exact component/profile/operation/request binding,
- no native call permission request,
- no native result authority request,
- no operator override shortcut,
- Python fallback still active,
- preserved archive, call-ledger, admission, settlement, oracle, fallback, tombstone, quarantine, and crash memory.
