# Cross-case memo: structural load-path and legibility

The promoted structural records deliberately span different grains: connection design/change, gusset-plate design and load rating, node/joint design and crack interpretation, corrosion/maintenance action-lag, and open federal investigation. The shared research question is not whether these are the same failure. It is whether the decisive structural state became visible to the institutions that could act before collapse.

The cube should now ask for each structural record: Who knew or could have known the critical state? Which review, inspection, maintenance, records, reporting, or closure threshold should have translated that state into action? Which rail existed, and did it produce correction infusion?
