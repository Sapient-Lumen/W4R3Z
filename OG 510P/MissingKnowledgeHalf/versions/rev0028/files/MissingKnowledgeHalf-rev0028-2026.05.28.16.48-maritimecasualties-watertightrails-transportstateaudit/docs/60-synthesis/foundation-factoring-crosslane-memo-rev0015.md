# Foundation factoring cross-lane memo — rev0015

The cube has now accumulated enough real records to reveal its own shape. The most important lesson is that record types are not the deep structure.

Engineering failures taught warning governance, proof burden, numeric assumptions, software control planes, and attribution traps. Negative-result records taught hard endpoints, practice lag, sham controls, and de-adoption. Replication records taught boundary maps and effect shrinkage. Infrastructure records taught denominator and correction rails. Meta-research records taught audit pairs. Genealogy records taught transmission, scene, and anti-genealogy.

These are not separate kingdoms. They are cross-cutting axes.

The cube should therefore become a correction-memory commons with readable case records on the surface and factor axes underneath. The future graph should be able to answer questions like:

- Which claims were published, adopted, challenged, narrowed, but not de-adopted?
- Which correction surfaces made hidden denominators visible?
- Which warning signals existed before harm, and which institutions weakened them?
- Which pattern candidates are supported only by memorable examples and lack controls?
- Which ideas or corrections travelled through people, conferences, labs, regulators, journals, textbooks, or products?

The next danger is adding records faster than the factor model can absorb them. The next opportunity is to make every record more queryable without draining away narrative intelligibility.
