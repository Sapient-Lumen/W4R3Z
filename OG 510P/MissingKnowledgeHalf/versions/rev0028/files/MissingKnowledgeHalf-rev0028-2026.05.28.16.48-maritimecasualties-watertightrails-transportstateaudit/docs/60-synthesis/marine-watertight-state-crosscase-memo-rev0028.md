# Crosscase memo: marine watertight-state and correction rails

The first marine lane pattern is deliberately broad and deliberately immature. Herald and Estonia stress ro-ro watertight/vehicle-deck vulnerabilities; Costa Concordia stresses navigation, hull breach, damage stability, blackout, list and evacuation; El Faro stresses weather routing, BRM/SMS, downflooding, propulsion and survival craft; Viking Sky stress-tests the pattern with a near-miss where state divergence became an emergency but not a mass-casualty loss.

The rail records are equally important. MAIB, IMO casualty-investigation code, EMCIP, and NTSB marine surfaces make casualty knowledge visible, but visibility is not infusion. The next layer must ask which recommendations closed, which codes changed, which drills or designs changed, and whether later incidents recur.
