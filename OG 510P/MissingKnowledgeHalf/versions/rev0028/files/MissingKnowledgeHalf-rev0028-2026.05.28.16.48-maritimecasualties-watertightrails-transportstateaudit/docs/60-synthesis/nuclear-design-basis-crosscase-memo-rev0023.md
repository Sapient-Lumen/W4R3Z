# Nuclear design-basis crosscase memo — rev0023

The three promoted accidents are deliberately not treated as the same story.

Three Mile Island is an instrumentation/human-factors/OPEX correction case. The system state that mattered was not legible enough, and post-event correction surfaces were broad.

Chornobyl/Chernobyl is a causal-status-history case. Later analysis did not simply add details; it changed the shape of the causal explanation by putting reactor/control-system design, low-power state, procedure, and safety/regulatory framework into one record.

Fukushima Daiichi is an external-hazard/design-basis and common-mode case. The realized tsunami and flooding defeated power and heat-sink assumptions at a multi-unit site.

The shared candidate pattern is therefore not “nuclear accidents happen because of X.” It is: severe nuclear accidents are especially revealing when the cube asks what hazard envelope was assumed, what system state was legible, what prior operating experience existed, what emergency information rail activated, and whether correction moved from memory to infusion.
