# GW150914 as anomaly-control memo

GW150914 is now encoded as a positive control for `MKH-PAT-0017`. It shows that disciplined anomaly handling should preserve the possibility of true discovery.

The cube should not say: OPERA and BICEP2 corrected, cold fusion did not reproduce, therefore extraordinary physical anomalies tend to fail. That is an overfit. The better pattern asks what status motion occurred:

- Was there a signal surface?
- Were instrument, foreground, and local-environment alternatives tested?
- Was there an independent or networked control?
- Did public provenance and data release allow outside reanalysis?
- What exact part of the original workflow remained unreproducible or inaccessible?

In this frame, GW150914 is not a victory poster. It is a control case for how surprise can be earned into knowledge while retaining provenance humility.
