# Audit-pair file-drawer crosscase memo — rev0009

The rev0009 records support one provisional synthesis: the hidden denominator is most trustworthy when approached through paired sources.

## What recurs

- FDA/regulator surfaces can reveal trials absent or reframed in journals.
- Protocol surfaces can reveal measured outcomes absent or changed in articles.
- Review-level evidence shows both study-level and outcome-level reporting bias.
- Method reviews warn that statistical publication-bias diagnostics can be over-simple without source-acquisition discipline.

## Why this matters for the cube

The cube should not merely collect negative results that happen to be famous. It should learn where the invisible results are likely to be hiding and which source surfaces can expose them.

## Nonclaim

This memo does not estimate the prevalence of publication bias across science. It does not say all positive results are suspect. It says: when a denominator surface exists, compare it with the visible numerator before trusting the literature as complete.
