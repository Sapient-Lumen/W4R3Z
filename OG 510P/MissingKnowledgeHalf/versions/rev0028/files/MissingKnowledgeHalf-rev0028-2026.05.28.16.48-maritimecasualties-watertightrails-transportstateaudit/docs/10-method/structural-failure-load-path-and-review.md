# Structural failure: load path, review, inspection, and correction rails

Structural failures should not be compressed into a single phrase like design error, overload, corrosion, or operator mistake. The first-pass grain in this cube separates:

1. physical failure mode;
2. intended versus as-built load path;
3. original design and independent review;
4. construction-stage change control;
5. inspection and load rating;
6. maintenance-action lag;
7. records, quality control, and quality assurance;
8. investigation status;
9. recommendation/code-change/correction rail.

This lets Hyatt, I-35W, FIU, Fern Hollow, and Champlain sit in the same lane without pretending they are the same accident.
