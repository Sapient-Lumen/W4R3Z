# Maritime watertight, stability, and evacuation state

Marine casualty records should not be reduced to seamanship blame or vessel-type shorthand. The minimum factor split for this lane is: watertight integrity, damage stability/free-surface state, navigation or weather-routing state, propulsion/engineering state, bridge/team/safety-management state, alarm/display/state legibility, evacuation/muster/survival-craft state, safety-investigation versus legal status, and recommendation/code infusion.

A casualty report is a correction-memory surface. A changed code, closed recommendation, modified design, drilled crew, or demonstrably safer operating practice is a different surface and needs child records.
