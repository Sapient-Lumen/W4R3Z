# Evidence severity and status

## Why status is temporal

A record can be true as history and unstable as current science. A study may have found a null result that was later shown underpowered. A replication failure may reveal a boundary condition rather than kill a claim. An engineering investigation may name a proximate cause while later analysis reframes the root cause.

Therefore the archive tracks status history rather than one final verdict.

## Core status distinctions

- **Null finding** — predicted effect not observed; method adequate enough to matter.
- **Underpowered null** — no detection but insufficient power; not evidence of absence.
- **Method failure** — instrument, protocol, model, or implementation failed.
- **Counter-finding** — observed result opposed the expected claim.
- **Smaller-than-predicted effect** — effect exists but magnitude shrank materially.
- **Boundary condition** — effect exists only in narrower conditions.
- **Failed replication** — replication attempt did not recover original effect as expected.
- **Contested** — material disagreement remains.
- **Superseded** — later work changes current interpretation while preserving historical relevance.
- **Practice-lagged** — literature changed but practice/textbooks/policy did not.

## Defeaters

A defeater is evidence or reasoning that reduces authority. Examples:

- source custody problem,
- measurement error,
- underpowered design,
- p-hacking / analytic flexibility,
- conflict of interest,
- failed direct replication,
- reanalysis disconfirmation,
- alternative explanation,
- official correction/retraction,
- ethical/legal restriction on source use.

## Severe test heuristic

A record is stronger when the evidence could realistically have shown the opposite. The archive should note whether a test had enough power, source independence, design relevance, and adversarial exposure to matter.
