# Earning before scaling

This method note exists because the cube can fail by succeeding too quickly.

A failure archive is naturally tempting: famous cases are plentiful, narratives are memorable, and many domains have source material. But raw accumulation can create false confidence. Before scaling, each revision should state what it earns.

## Revision questions

Before a future revision begins, ask:

1. Is this an accretion, review, dream, consolidation, red-team, source-acquisition, or handoff pass?
2. Which earned capability does it advance?
3. What would make the work misleading despite being factually interesting?
4. What source, claim, status, practice, genealogy, or pattern distinction must be protected?
5. What future session should be able to do more easily because this revision exists?

## Earned-capability tags

Future records and ledgers may tag work against:

- `case_integrity`
- `denominator_visibility`
- `status_history_memory`
- `practice_lag_visibility`
- `warning_governance_memory`
- `correction_surface_inventory`
- `cross_domain_pattern_discovery`
- `genealogy_of_correction`
- `pedagogical_failure_literacy`
- `machine_usable_epistemic_training`
- `public_trust_through_honesty`
- `funding_and_research_triage`

## When not to add records

Do not add records if:

- existing records have not been reviewed enough to trust their claim granularity;
- the new record merely repeats an already-demonstrated pattern;
- source permanence is weak and interpretation is outrunning provenance;
- the user is asking for telos, ethics, handoff, query design, or review;
- the case is famous but its evidence base is not ready;
- the record would harm living people or affected families without sufficient public-interest justification and sensitivity.

## When to add records anyway

Add records when a new case:

- tests a new record shape;
- supplies a negative control;
- challenges a pattern;
- opens a missing lane;
- improves denominator visibility;
- links literature to practice;
- reveals a source infrastructure;
- strengthens genealogy of transmission;
- converts a vague dream into an auditable surface.
