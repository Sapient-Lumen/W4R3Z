# Seed candidate queue

The authoritative queue is `CANDIDATE-CASE-QUEUE.json`. This prose file explains how to read it.

Every row in rev0001 is `seed_mention`. That means:

- it is a memory target,
- it may guide source acquisition,
- it is not a verified record,
- it cannot yet be cited as corpus content,
- it should not be used to teach a factual summary from this archive.

Candidate rows are intentionally mixed: some are cases, some subcorpora, some patterns, and some infrastructure/genealogy targets. Future revisions should split them into full records only when sources are acquired.
