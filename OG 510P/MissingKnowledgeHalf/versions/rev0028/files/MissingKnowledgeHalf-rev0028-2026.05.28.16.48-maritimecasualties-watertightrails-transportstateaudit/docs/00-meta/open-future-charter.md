# Open future charter

This cube should be difficult to corrupt but easy to enlarge.

That means distinguishing hard constraints from current conveniences.

## Hard constraints

These should survive most future schema changes:

1. Separate source, claim, record, pattern, and interpretation.
2. Preserve provenance, permanence, and retrieval memory.
3. Track status over time where possible.
4. Treat practice status as separate from literature status.
5. Treat genealogy as evidence-graded, not intuitive.
6. Keep ethical posture explicit: no wall of shame, no survivor-trauma extraction, no hindsight flattening.
7. Keep pattern candidates provisional until supported by cases and controls.
8. Leave handoff surfaces for future sessions.

## Soft constraints

These may change:

- record type names;
- folder structure;
- schema fields;
- lane names;
- pattern identifiers;
- counts and dashboards;
- how records become graph edges;
- which domains are prioritized;
- which surface becomes primary for a user.

## Future sessions have permission to

- add a record type if current types distort the evidence;
- split large records into child records;
- create non-case revisions for review, glossary, ethics, source permanence, query design, or public interface;
- demote earlier claims when sources are weaker than expected;
- add success controls, negative controls, false-negative cases, and revival cases;
- open adjacent corpora if they clarify the missing half of knowledge;
- refuse a famous case if it cannot be sourced or ethically handled;
- interrupt accumulation to make the cube easier to resume.

## Future sessions should resist

- schema obedience when the schema is wrong;
- breadth-first case hoarding;
- overfitting patterns to famous failures;
- treating all negative results as equal;
- treating all replications as debunkings;
- treating all engineering failures as human error;
- treating all genealogy edges as influence;
- treating a correction surface as proof of correction.

The cube should mature by learning what its own structures hide.
