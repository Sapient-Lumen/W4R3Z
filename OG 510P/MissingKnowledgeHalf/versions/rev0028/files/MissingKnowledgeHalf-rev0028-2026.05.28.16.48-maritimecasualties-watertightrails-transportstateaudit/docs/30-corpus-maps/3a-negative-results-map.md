# Corpus 3A map: negative results / file drawer

## First taxonomy

- true null,
- underpowered null,
- methodologically failed study,
- inconsistent finding,
- opposite finding,
- smaller effect,
- boundary condition,
- heterogeneity where homogeneity was assumed,
- abandoned study,
- failed pilot,
- confidential negative result,
- thesis negative,
- conference-poster negative.

## First source families

- registries and preregistrations,
- negative-result journals,
- theses and dissertations,
- trial registries,
- retraction/correction/post-publication review databases,
- lab notebook/open notebook sources,
- conference archives,
- blog/repository informal records.

## Immediate danger

The phrase “negative result” is too broad. This lane must not enshrine false negatives or failed methods as facts about the world.
