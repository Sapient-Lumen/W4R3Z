# Rev0011 pilot lane — software accountability / machine testimony

The pilot lane promotes three incident records and three visibility rails.

Therac-25 shows that medical-device software can produce lethal system states that ordinary operator feedback does not reveal. Horizon shows that accounting software can become legal/evidentiary infrastructure, with shortfalls attributed to people while decisive logs, defects, and institutional knowledge are inaccessible or denied. Dieselgate shows state-sensitive software that performs compliance toward a test while violating the public/regulatory expectation of field behavior.

The rails differ. FDA MDR/MAUDE captures suspected medical-device adverse events but is explicitly not a causality or event-rate denominator. The Horizon Inquiry is late correction memory, not real-time prevention. EPA/CARB in-use testing is regulator detection against lab-field divergence, not a general software incident board.

The lane’s first pattern, `MKH-PAT-0011`, remains candidate-level.
