# Practice-lag / de-adoption lane — rev0013

Rev0013 promotes four first-pass medical reversal records and five infrastructure records. The selected cases intentionally span different evidence-turning surfaces:

- high-dose chemotherapy for breast cancer: randomized and pooled survival/toxicity evidence after adoption;
- knee arthroscopy for osteoarthritis: placebo-surgery and optimized-care comparators;
- vertebroplasty: paired sham-controlled trials and later boundary disputes;
- renal-artery stenting: hard clinical endpoints overriding physiologic/procedural plausibility.

The infrastructure records are correction rails, not primary evidence records. They help answer how the literature can become practice change.
