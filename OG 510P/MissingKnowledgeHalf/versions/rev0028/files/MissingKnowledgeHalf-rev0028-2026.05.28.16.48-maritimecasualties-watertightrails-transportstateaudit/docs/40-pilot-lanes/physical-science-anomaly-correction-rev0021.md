# Physical-science anomaly/correction lane — rev0021

This pilot lane opens with three different correction trajectories:

- `MKH-NEG-0019` OPERA: apparent superluminal neutrino timing result resolved through timing-chain audit and independent retest.
- `MKH-NEG-0020` BICEP2: extraordinary CMB B-mode interpretation narrowed by foreground dust modeling and joint analysis.
- `MKH-REP-0011` cold fusion reevaluation: historical replication failure revisited by a high-rigor program that had not yielded evidence while still preserving materials-science learning.

Two infrastructures support the lane:

- `MKH-INF-0035` arXiv: versioned preprint/correction-memory rail.
- `MKH-INF-0036` ADS: astronomy/physics literature-index and source-discovery rail.

The lane deliberately uses existing record types rather than inventing an anomaly record type. If the lane grows, a future refactor may add explicit anomaly-trajectory fields across NEG, REP, MET, INF, and PAT records.
