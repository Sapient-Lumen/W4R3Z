# Reporting-bias audit pairs — rev0009 pilot lane

Rev0009 opens the meta-research audit lane. The reason is simple: the seed asks for the file drawer, but the file drawer is not directly visible. It becomes visible through **audit pairs**.

Promoted records:

- `MKH-MET-0001` — Turner 2008 FDA/journal antidepressant audit.
- `MKH-MET-0002` — Turner 2022 FDA/journal update for newer antidepressants.
- `MKH-MET-0003` — Chan 2004 protocol/publication outcome-reporting audit.
- `MKH-MET-0004` — Dwan 2013 systematic review of empirical reporting-bias evidence.
- `MKH-MET-0005` — Song 2010 HTA/method review plus early clinical-trial publication-bias signals.
- `MKH-PAT-0009` — audit pairs reveal the file drawer by comparing hidden denominators with published numerators.

This lane is upstream of individual negative-result records. It tells the cube how to find them without pretending the visible literature is the whole evidence base.
