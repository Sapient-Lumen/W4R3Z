# Pilot lane: genealogy / anti-genealogy

## Why useful

A genealogy pilot tests interpretive caution. Influence is not the same as citation; advisor relation is not the same as conceptual descent; reaction against is not the same as ignorance.

## Minimum structure

- bounded scene/event/person/work,
- relation types,
- source of relation,
- confidence,
- dates,
- missing or erased lineages,
- links to claims or failures where appropriate.
