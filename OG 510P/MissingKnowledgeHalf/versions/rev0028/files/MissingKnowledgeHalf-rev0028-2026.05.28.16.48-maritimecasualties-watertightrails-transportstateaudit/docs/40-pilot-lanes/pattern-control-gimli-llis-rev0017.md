# Rev0017 pilot lane: pattern controls and lesson-infusion infrastructure

Revision: rev0017

This revision grows in two linked ways.

First, it adds `MKH-ENG-0020`, Air Canada Flight 143 / Gimli Glider, as a pattern-control engineering record. The report-backed mechanism is not encoded as a simple joke about metric conversion. It is encoded as an abnormal manual-fueling workflow in a mixed-unit transition environment, with inoperative fuel gauges, ambiguous responsibility, inadequate training/manual/cross-check support, and a wrong litres-to-kilograms conversion pathway. The record is a positive control for `MKH-PAT-0001` because it should fit the numeric-representation pattern even though it was not used to create the pattern.

Second, it promotes NASA LLIS as `MKH-INF-0029`, then immediately pairs it with `MKH-MET-0007`, the GAO 2001 lessons-learned audit. This prevents a naive infrastructure claim. A repository can preserve correction memory; it does not automatically prove that the lesson is retrieved, trusted, applied, or engineered into later work.

The resulting new pattern candidate is `MKH-PAT-0014`: correction memory does not equal correction infusion.
