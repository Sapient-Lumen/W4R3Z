# Structural factor axes overlay

This revision does not create a hard structural schema. It creates an overlay that can later be migrated into schema form.

Axes:

- `physical_failure_mode`
- `load_path_legibility`
- `design_review_surface`
- `construction_change_surface`
- `inspection_load_rating_surface`
- `maintenance_action_surface`
- `records_qc_qa_surface`
- `investigation_status`
- `correction_rail`
- `control_status`

The goal is to preserve causal grain while keeping future sessions free to revise the ontology.
