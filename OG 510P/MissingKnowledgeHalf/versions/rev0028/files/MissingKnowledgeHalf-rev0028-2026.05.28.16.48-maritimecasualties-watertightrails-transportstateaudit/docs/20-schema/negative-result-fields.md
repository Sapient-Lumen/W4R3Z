# Negative-result fields

A negative-result record should distinguish:

- true null,
- underpowered null,
- method failure,
- smaller-than-predicted effect,
- opposite effect,
- boundary condition,
- abandoned/pilot/unpublished result,
- confidential or unavailable result.

Minimum payload:

- hypothesis,
- prediction,
- study design,
- sample/dataset,
- power or sensitivity,
- method validity,
- result with uncertainty,
- author interpretation,
- field response,
- positive claim qualified,
- practice consequence,
- false-negative risk.
