# Engineering-failure fields

Minimum payload:

- incident name,
- date/time,
- location,
- system/object,
- fatalities/injuries/cost where sourced,
- organizations involved,
- regulators,
- timeline,
- proximate cause,
- contributing factors,
- root/organizational causes,
- latent conditions,
- warnings and near-misses,
- recommendations,
- subsequent action,
- recurrence links,
- survivor/family/person-account sensitivity.

Do not over-reduce engineering failures to “operator error.” Operator action is often the last visible move in a deeper system path.
