# Maritime factor axes

This is an overlay, not a hard schema migration.

- `watertight_integrity`: doors, ramps, scuttles, vents, hull breaches, closures.
- `damage_stability_and_free_surface`: flooding extent, free-surface effect, list, compartment assumptions.
- `navigation_route_or_weather_state`: route planning, close approaches, storm avoidance, current weather use.
- `propulsion_engineering_state`: blackout, steering, lube-oil pressure, generators, recovery.
- `bridge_team_or_safety_management_state`: BRM, SMS, command/communication, risk assessment.
- `alarm_display_or_state_legibility`: indicators, alarms, VDR/inclinometer/monitoring surfaces.
- `evacuation_muster_survival_craft`: muster timing, abandon-ship order, lifeboats/rafts, launch constraints.
- `investigation_code_or_database_rail`: MAIB, NTSB, IMO Code, EMCIP, national bodies.
- `recommendation_or_code_infusion`: closure, compliance, training, code changes, audits.
