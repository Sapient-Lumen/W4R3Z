# Ithkuil translation project archive

This folder contains the evolving documents for translating the provided English text into Ithkuil.

## Files
- `ithkuil_translation.md` — main running translation (ordered by source text).
- `ithkuil_glossary.md` — evolving English → Ithkuil mapping (roots/affixes + usage notes).
- `ithkuil_notes.md` — open questions, unresolved placeholders, style decisions.
- `ithkuil_sources.md` — quick notes on which Ithkuil references/versions we are following.
- `legacy_worklog.md` — earlier scratch output preserved verbatim (messy but retained for traceability).
