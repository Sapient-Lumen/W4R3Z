# Ithkuil glossary (evolving)

This is the current mapping from the source text’s key concepts into the Ithkuil resources we’re using.

Conventions
- Roots are written in the project’s working root notation (e.g., `NZ`).
- Committed stems appear as subscripts (e.g., `NZ₁`).
- `S«…»` marks a *carrier* / foreign / technical phrase we are not yet lexicalizing.
Migration note
- Earlier archives briefly used `RTR₂` and (incorrectly) `ŢY₁` for “goodwill-love”. The New Ithkuil Lexicon v1.0 lists `NZ` explicitly as **GOODWILL / BEING NICE / BEING DECENT**, and `RKW` for affective love. This glossary (and the translation file) now standardize on `NZ₂` for ethical love.


Core semantic anchors
- **LOVE (ethical; goodwill/benevolence)** → `NZ₂` (feeling/display of goodwill; benevolent intent/kindness; moralized as needed)
- **LOVE (affective; affection/bond)** → `RKW₁/₂/₃` depending on whether romantic / filial / love-for-abstraction is intended (avoid conflating with ethical goodwill)
- **ROMANTIC “being in love”** → `RKW₁` (romantic love) *(used only when the source clearly means that state)*
- **AGAPE / altruistic self-giving** → `VÇ₃` (charitableness / altruism / self-sacrifice; best "agape" analogue)
- **PHILIA / friendship** → `LTW₃` (feeling of friendship/bond; best “philia” analogue)
- **ATTRACTION (mere attraction / being drawn toward)** → `VK` (use `VK₂` for psychological/philosophical attraction to an abstract entity; see stems)
  - optionally contrast with `VZK₁` (craving) when the source implies compulsive desire rather than attraction.
- **LIKE / FONDNESS (mere liking; not ethical love)** → `LTW₁` (friendly affection) or `FFX₁` (dislike) by contrast
- **IMPRESSION / APPEARANCE / “LOOK” / SEMBLANCE / ASPECT** → `ÇD₂`
- **HEART (lit. heart; used metaphorically for affect/will in A.0)** → `ḐL₁`
- **SOUL / psyche / “all that you are” (biblical A.0 stopgap)** → `N-CTE` (use the appropriate 2nd‑person stem in context)
- **MIND (biblical A.0 stopgap)** → `VZ₁` (brain/cognitive organ) *(later: replace with a cleaner “cognition/understanding” root)*
- **NEIGHBOR (ethical “those in your sphere”)** → `N-OBJ` (use 2nd‑person stem: “someone in your life/niche/environment”)
- **COMMANDMENT / precept / rule (moral law)** → `RZ-OBJ` (a rule/edict/law which is to be obeyed)
- **HATE / HATRED / ENMITY** → `FFX₃` *(emotion-root stem 3)*
- **MUTILATE / MAIM** → `XTŘ₂` *(crime/violence root stem 2)*

- **EUDAIMONIA / flourishing / serene life-stance** → `SKY₁`

Grammatical anchors (cases)
- **Case PUR** = Purposive (“for the purpose of / toward the purpose of …”)
- **Case ASI** = Assimilative (“like / as” in the sense of analogy/comparison)
- **Case EFF** = Effectuative (the enabler initiating a causal chain leading to an event)
- **Case RSL** = Resultative (result/consequence: “resulting in X / with X as a consequence / X results from …”)

Grammatical anchors (VXCS quantifying affixes)
- **Affix PTW** (Contiguous Portion of the Whole) — we use **PTW/9** for “every / all (of) / whole; entirely / in its entirety”
- **Affix PTT** (Noncontiguous Portion of the Whole) — we use **PTT/4** for “some of / a portion / partially / to some extent”
