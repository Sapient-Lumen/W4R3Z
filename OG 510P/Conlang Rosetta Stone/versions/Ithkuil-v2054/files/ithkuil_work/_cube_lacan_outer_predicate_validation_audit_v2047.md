## 1. Summary decision

v2047 promotes the opening predicate from compact/default verbal force to explicit intuitive assertive validation:

```text
rkwal li sëi  →  rkwalû li sëi
```

Active line:

```text
rkwalû li sëi ; evvralácboa sou li hlušh-otilöehëi sue hlu’u «objet petit a» hü ; alo extřudá lo že
```

The cube goal is to prevent a hidden mismatch between the two outer predicates:

```text
opening love-predicate      explicit ASR/ITU
final maiming-predicate     explicit ASR/OBS bridge default
middle affective frame      framed SIT case, no direct VK
```

## 4. Final predicate validation still marked bridge-default

The final predicate remains:

```text
extřudá lo že
```

Current interpretation:

```text
XTŘ₂ + DYN/BSC + PRX + ASR/OBS
```

This is still a bridge default, not a final philosophical validation policy. The live alternate remains:

```text
extřudêi lo že
```

if the project later chooses global `USP` for the quoted/philosophical status of the entire Lacan sentence.

Why v2047 does **not** change it now:

1. the current task was to repair the opener’s hidden `VK` asymmetry;
2. the final violence is still the clause most compatible with observational validation;
3. changing both outer predicates at once would blur which decision was being tested.

## 5. Middle frame validation policy

The middle frame head remains:

```text
evvralácboa
```

It should not receive a direct final `VK` vowel because its Slot IX is already:

```text
VC = SIT / Situative
```

and its relation is:

```text
FRAMED = antepenultimate stress
```

If a future pass needs to mark illocution/validation inside the frame, it should use the appropriate illocution/validation affix strategy rather than stealing the Slot-IX case slot.

Cube label added:

```text
framed-vk-pressure
```

Definition:

> A tempting but usually wrong pressure to add ordinary unframed verbal `VK` marking to a framed clause whose Slot IX is already occupied by case.

## 7. Cube hygiene changes

### 7.1 New audit label: `hidden-vk-risk`

A predicate receives this label when it is an active unframed verbal formative but its illocution/validation value is only recoverable by default/economy rather than visibly present.

Affected retired active form:

```text
rkwal
```

### 7.2 New audit label: `validation-lane-split`

A line receives this label when multiple unframed predicates intentionally carry different validations.

Current active split:

```text
rkwalû   = ASR/ITU, first-person affective self-report
extřudá  = ASR/OBS, bridge-default assertion of violent act
```

### 7.3 Rule for future passes

Any future pass that changes an active unframed predicate must record its `VK` value explicitly in the cube, even if the running surface uses a compact form.

Minimum record format:

```text
FORM       ROOT/STEM       RELATION       VK          RATIONALE
rkwalû     RKW₁            unframed       ASR/ITU     affective self-report
extřudá    XTŘ₂            unframed       ASR/OBS     bridge default for act
```

## 8. Remaining high-priority audit queue

### Priority A — host nucleus Perspective

```text
hlušh-otilöehëi sue
```

Still the most important semantic grammar fork. The project must decide whether default Monadic remains adequate or whether Lacan’s object-cause demands Abstract or Agglomerative perspective.

### Priority B — quotation-wide validation policy

The line now makes local validation choices. A later pass should decide whether the quotation as a whole should override local choices with `USP` or another globally appropriate validation.

### Priority C — contrast adjunct `alo`

`alo` currently scopes as a whole-formative contrastive adjunct before the final predicate. A later audit should verify whether its scope is only the final predicate or the whole consequence clause following the framed situation.
