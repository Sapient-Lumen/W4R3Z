## 2. Why v2046 reopens `aixtřas`

The old final predicate came from v2032–v2034:

```text
aixtřas
```

That form was useful as an exploratory bridge, but it still encoded a pre-recanonicalization slot model where the leading vowel cluster `ai-` was treated as a combined Pattern/Stem/Function exponent and final `-s` was treated as the simple PRX `Ca` value.

After v2043 restored the New-Ithkuil branch, this should have been audited.  v2046 does that audit.

Under the New-Ithkuil formative spine:

```text
Slot II   VV  = Stem + Version
Slot III  CR  = root
Slot IV   VR  = Function + Specification + Context
Slot VI   Ca  = Configuration + Extension + Affiliation + Perspective + Essence
Slot IX   VK  = Illocution + Validation for unframed verbal formatives
Slot X    stress = relation and VC/VK distinction
```

So the final predicate must be rebuilt by slots, not by the older `ai-` skeleton.

## 3. Final predicate rebuilt as `extřudá`

### 3.1 Root and stem remain unchanged

The lexeme remains:

```text
-XTŘ-  BATTERY / AGGRAVATED ASSAULT / MAIMING / TORTURE
BSC Stem 2: state/act of maiming another; to maim another
```

So the lexical decision stays:

```text
Root = XTŘ
Stem = 2
Specification = BSC
```

What changes is the visible New-Ithkuil morphology around that root.

### 3.2 Slot II: Stem 2 PRC is `e`, not `ai`

For a non-concatenated formative without a Slot IV/VI shortcut, New Ithkuil gives:

```text
Stem 2 + PRC  →  e
```

Therefore the final predicate begins:

```text
e- + xtř
```

not:

```text
ai- + xtř
```

### 3.3 Slot IV: DYN + BSC + EXS is `u`

The final clause is not a mere state of being maimed; it is the active, damaging act of maiming performed by the speaker upon the addressee.  Therefore the Function stays **DYN**, and the Specification stays **BSC** because the official Stem-2 BSC value already means “maiming another.”

New-Ithkuil Slot IV gives:

```text
DYN + BSC + EXS  →  u
```

So:

```text
e + xtř + u  →  extřu-
```

### 3.4 Slot VI: PRX with default UPX context gives `d`

v2034’s semantic decision remains good: the Lacan line is not narrating a completed maiming from start to finish.  It exposes the locally relevant mutilating violence generated by the preceding desire-frame.  That is still **PRX / Proximal** rather than **DEL / Delimitive**.

But the New-Ithkuil `Ca` table does not let the archive keep the old `-s` for this bundle.  With the otherwise default `Ca` values:

```text
Affiliation   CSL   default
Configuration UPX   default
Extension     PRX   t / d, with the alternate form used for UPX
Perspective   M     default
Essence       NRM   default
```

So the active New-Ithkuil `Ca` value is:

```text
d
```

and the stem reaches:

```text
e + xtř + u + d  →  extřud-
```

### 3.5 Slot IX/Slot X: explicit default assertive-observational VK gives final `á`

The final predicate is an unframed verbal formative.  In New Ithkuil, unframed verbal formatives use Slot IX as `VK` for Illocution + Validation, and ultimate stress marks the `VK` interpretation.

For this bridge line, v2046 makes the default visible rather than silently relying on stress-only elision:

```text
ASR + OBS  →  á
```

Thus:

```text
extřud- + á  →  extřudá
```

This `á` is not meant to settle the deeper evidentiality question for the whole Lacan quotation.  It is a bridge-line default.  A later validation pass may prefer `USP` if the project wants to avoid observational validation in a philosophical quotation.

## 4. Frame-head stress correction: `evvrálacboa` → `evvralácboa`

v2044 fixed the middle predicate’s slot order:

```text
e-vvr-a-l-acb-oa
```

but v2044/v2045 placed the visible stress too far left:

```text
evvrálacboa
```

The issue is the final Situative case vowel-form:

```text
oa
```

In New Ithkuil, `oa` is a disyllabic vocalic conjunct, not one of the falling diphthongs.  Therefore it contributes two syllables at the end of the word.  Since the middle predicate is a framed formative, Slot X must show **antepenultimate stress**.  Counting the final disyllabic `oa`, the stress falls on the suffix vowel `a` in `-acb-`, not on the Slot-IV `a`.

So:

```text
evvrálacboa   rejected: stress too far left

evvralácboa   active: FRAMED relation + SIT case with antepenultimate stress
```

The semantic build does not change:

```text
e-vvr-a-l-acb-oa
Stem 2 VVR + STA/BSC + default Ca + RSN/1 “for no reason” + SIT
```

Only the relation-bearing stress is corrected.

## 6. What v2046 does not yet fix

### 6.1 Opening predicate `rkwal`

`rkwal` remains active.  It is probably defensible as a compressed monosyllabic unframed verbal formative under the default/implicit VK policy, but v2046 does not pretend that the opening clause has received the same full Slot-IX explicitness as the final predicate.

Future audit question:

```text
Should rkwal stay compressed, or should the bridge line surface an explicit opening VK as rkwalá / related form?
```

### 6.2 Validation of the final predicate

`extřudá` uses the default ASR/OBS bridge value.  A more philosophical or quotation-aware pass may change the final VK to deliberate unspecified validation:

```text
extřudêi
```

That is not frozen here.  The v2046 goal is to put the final predicate into the correct New-Ithkuil slot spine.

### 6.3 Host nucleus remains next major semantic audit

The host remains:

```text
hlušh-otilöehëi sue
```

v2046 confirms that its unmarked penultimate-stress policy remains plausible, but it does not resolve the deeper Perspective question:

```text
M  monadic salient something
G  agglomerative/some unspecific amount or instance
A  abstract conceptual object
```

That is now the most important remaining semantic fork in the local cube.
