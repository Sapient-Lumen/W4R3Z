## Why the next surface element is `Vc`, not `Ca`

The project had been tempted to move straight from:

```text
aixtř-
```

to a fully Ca-bearing shape such as:

```text
aixtřal-
```

That would be premature. In the official formative architecture used by this archive, the minimum formative spine is:

```text
Vr + Cr + Vc + Ca + tone + stress
```

So after v2032 froze `Vr + Cr` as `aixtř-`, the next structural slot is `Vc`, the case vowel. `Ca` cannot honestly be frozen until the case shell is placed.

This matters because v2032’s apparent continuation question, “what is the final predicate’s Ca?”, was slightly too far ahead. v2033 corrects the sequence:

```text
aixtř-       = Vr + Cr
aixtřa-      = Vr + Cr + Vc
aixtřa- + Ca = next pass
```

---

## Why `a` / OBL for this predicate shell

For ordinary unframed verbal formatives, the predicate still carries a `Vc` slot. The final maiming word here is not itself being declined as a semantic participant like `ABS`, `ERG`, `STM`, `SIT`, `RLT`, etc. Those roles are already carried by surrounding referentials and framed material:

```text
lo  = 1m ERG, final physical agent
že  = detrimental 2m patient/undergoer
FRAMED:SIT[...] = situative/circumstantial cause-wrapper
```

The final predicate therefore receives the ordinary oblique shell vowel:

```text
Vc: OBL = a
```

So:

```text
ai- + xtř + a  →  aixtřa-
```

This is not meant as “the mutilation is oblique” semantically; it is the default case shell for an unframed head formative at this point in the build.

## Why Slot IX `Ci+Vi` is still not inserted

The grammar has a Mood/Illocution slot after `Vc`, but Mood and Illocution have default forms and are usually left unfilled when default. Nothing in the Lacan clause yet demands a non-default interrogative, admonitive, imperative, inferential, or other overt illocution/mood package.

So v2033 does **not** insert an overt `Ci+Vi` after `aixtřa-`.

Current working chain:

```text
aixtřa- + [default Ci+Vi omitted] + [Ca unresolved]
```

This keeps the line lean and avoids fabricating a modal/illocutional value that the source sentence does not require.

## Why `Ca` is still unresolved

`Ca` will encode a five-way bundle:

```text
Configuration + Affiliation + Perspective + Extension + Essence
```

Several parts are probably low-risk:

```text
Configuration: likely UNIPLEX / one maiming act-event
Affiliation:   likely CONSOLIDATIVE / naturally integrated event
Perspective:   likely MONADIC / one bounded contextual event
Essence:       likely NORMAL / actual, not representative
```

The difficult part is **Extension**.

### DELIMITIVE reading

`DEL` would construe the maiming as a whole bounded event from beginning to end. This fits the English lexical verb “mutilate/maim,” whose result-state is telic and outcome-heavy.

Control gloss:

```text
I perform the maiming as a whole bounded violent act.
```

### PROXIMAL reading

`PRX` would construe only the contextually relevant portion/duration/aspect of the maiming as foregrounded. This may fit the Lacanian present-tense shock of “I mutilate you,” where the point is not narrating a completed event from start to finish but exposing the violent local structure of desire.

Control gloss:

```text
I am engaged in / enact the relevant mutilating violence toward you.
```

### v2033 policy

Do not freeze this yet. The next pass should decide whether the line wants the blunt telic result-whole of `DEL` or the local phenomenological violence of `PRX`.

## Rejected / demoted alternatives

### 1. `aixtřal-` now

Rejected as too quick. It likely smuggles in a default-looking `Ca` before the archive has audited the five-part `Ca` bundle.

```text
aixtřal-  = tempting, but premature
```

### 2. `aixtře-`, `aixtřo-`, `aixtřëi-`, etc.

Rejected. Those would push a semantic participant case into the predicate shell itself. The participant roles are already separately marked by `lo`, `že`, and the situative frame.

### 3. Add overt Mood/Illocution now

Rejected. Default Mood/Illocution is unmarked unless a non-default value is required. The English sentence is a declarative theoretical statement, not a question, warning, command, hearsay claim, or explicit epistemic/illocutional modulation.

### 4. Reopen `lo` / `že`

Not reopened here. v2031 already froze the final participants as an ERG speaker and a detrimental second-person patient. This remains the right local grammar for “I mutilate you.”

### 5. Reopen `aixtř-`

Not reopened here. v2032 already froze DYNAMIC Function + Stem 2 of `-XTŘ-` as the best visible skeleton for the final physical maiming act.
