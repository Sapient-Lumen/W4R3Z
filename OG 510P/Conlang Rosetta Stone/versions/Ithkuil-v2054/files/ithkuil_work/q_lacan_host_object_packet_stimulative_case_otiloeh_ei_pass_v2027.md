# Lacan host object-packet STIMULATIVE case `hlušh-otilöehëi` pass v2027 — 2026-05-21

## English target span

This checkpoint continues directly from v2026.

Target sentence:

> **I love you, but, because inexplicably I love in you something more than you—the objet petit a—I mutilate you.**

The v2026 local packet was:

```text
hlušh-otilöeh- sue esälu’u «objet petit a» hü
```

where v2026 had just frozen:

```text
<2m:CMP>  →  sue
```

The deliberate unresolved point left at the end of v2026 was the final Slot-IX case of the host word:

```text
hlušh-otilöeh-
```

This checkpoint answers that question for the middle framed predicate headed by `VVR₂`.

## What this checkpoint now freezes

### 1. the host is not a syntactic direct object in the English sense; it is the affective stimulus of `VVR₂`

The English phrase under local audit is:

```text
I love in you something more than you—the objet petit a
```

Earlier passes already refused to make this the same kind of direct interpersonal love as the opening clause:

```text
I love you
```

That split remains correct.
The middle predicate is not simply `RKW₁` again.
It is the object-cathexic/fractured affective predicate led by:

```text
VVR₂ = feel(ing of) infatuation / obsessiveness
```

Once the predicate is affective, the internal “something more than you” is not best treated as a neutral direct object.
It is the item which sets off, hooks, or fixes the speaker’s affective state.
In New Ithkuil semantic-role terms, that is a **STIMULUS**.

So the host packet should now take:

```text
STM = STIMULATIVE case
```

not merely an archive label `OBJ:[...]`.

### 2. official case semantics make STM the canonical choice

The decisive case contrast is:

```text
THM = content/theme that does not undergo tangible change
ABS = patient/target undergoing tangible impact or change
AFF = experiencer of an affective state
STM = trigger/stimulus of an unwilled affective response or existential state
```

The Lacan host is not the patient of a tangible action.
It is not what is physically changed by the speaker’s love.
Nor is it the experiencer of the state.
The experiencer is the speaker.

The “something more than you” is instead the affective trigger of the speaker’s obsessive/infatuated state.
That is exactly what `STM` is for.

### 3. `VVR` itself strongly confirms the STM reading

The grammar’s own example for `VVR` is decisive enough to promote this from “likely” to “frozen”:

```text
Vvralá mi wurçpëi.
```

with the control translation:

```text
Her passion is dance / She feels passionate about dance.
```

The relevant tail is:

```text
wurçpëi
```

where final:

```text
-ëi = STM
```

A nearby official example also glosses a `feel.fascination` framed clause with the fascinated-about entity in `STM`:

```text
FRAMED:'feel.fascination' ... 'clown'-...-STM
```

Those examples support a simple rule of thumb for this sentence:

```text
with feeling/passion/fascination roots,
the experiencer takes AFF-like participant marking,
and the about-object / trigger takes STM.
```

So the local Lacan host should no longer be carried as a bare object placeholder.
It should be cased as the stimulus of the infatuated/obsessive attachment.

### 4. the Slot-IX `STM` value is `ëi`

From the case table:

```text
STM / STIMULATIVE = ëi
```

Therefore:

```text
hlušh-otilöeh- + ëi  →  hlušh-otilöehëi
```

The v2026 host stem:

```text
hlušh-otilöeh-
```

already contains:

```text
hlušh-   Type-1 salience/prominence prehead
otil-    Stem-0 OBJ demonstrative parent head
öe       relative SURPASSIVE Level
h        natural Case-Scope
```

v2027 now adds only:

```text
ëi       STM case
```

giving the frozen host word:

```text
hlušh-otilöehëi
```

This is now the archive’s preferred local surface for:

> **the salient something-more-than-you as the stimulus of the speaker’s obsessive attachment.**

### 5. `STM` is especially apt because `objet petit a` is cause-like, not merely object-like

This pass also gains a conceptual fit that the earlier `OBJ:[...]` label could not show.

The source says “the objet petit a,” and the middle predicate was already read as fractured love/cathexis rather than ordinary whole-person love.
In that context, the excess-object functions less like a neutral object selected by the subject and more like the cause or lure that sets the subject’s desire/attachment in motion.

That is exactly the translation pressure STM handles better than THM or ABS:

```text
not: a neutral content of my love
not: a patient altered by my love
but: the stimulus/cause-hook of my affective fixation
```

This is one of the rare places where New Ithkuil’s semantic-role precision is not merely decorative.
It lets the sentence preserve the Lacanian asymmetry:

```text
I love you,
but through you I am seized by / fixed upon the object-cause-like excess,
and therefore I mutilate you.
```

### 6. why THM is demoted

Thematic case would give:

```text
hlušh-otilöeha
```

or, if elided under some later economy, an even lighter surface.

That would read the host as the neutral content/theme of the predicate.
This is too weak for the middle clause.

The predicate is not simply:

```text
I have as content/theme: something more than you
```

It is:

```text
I undergo an obsessive/infatuated state whose trigger is this excess-object.
```

Therefore THM under-translates the affective causality.
It is retained as a possible fallback only if a later full-clause pass demotes `VVR₂` and returns the middle predicate to a neutral relation.
As long as `VVR₂` leads, STM leads.

### 7. why ABS is rejected

Absolutive case would mark a patient or target undergoing tangible effect/impact/change.
That is wrong here.

The item that undergoes tangible mutilating impact is the final addressee of `XTŘ₂`, not the middle “something more than you.”
The excess-object is not being cut, damaged, moved, transformed, or physically acted on in the middle clause.

So ABS would drag the violence from the final clause into the wrong noun.
Rejected.

### 8. why AFF is rejected for the host

Affective case belongs to the experiencer of an unwilled affective state.
The host is not the experiencer.
The host is what the speaker experiences obsession/infatuation **about** or **because of**.

The speaker, still represented in the middle clause by `<1m>`, is the participant that would eventually need an AFF-like referential surface.
The host must not steal that role.

So AFF is rejected for:

```text
hlušh-otilöeh-
```

and remains a future pressure point for the inner first-person referential.

### 9. why ATT, ITP, RLT, or GEN should not be loaded onto the host

Several non-transrelative cases might look tempting from the English wording, but each would solve the wrong problem.

#### ATT

`ATT` would read the excess as an attribute/characteristic borne by another noun.
That risks turning the excess-object into a property of the beloved.
Earlier passes deliberately avoided reducing the objet petit a to a simple attribute of “you.”

#### ITP

`ITP` belongs to the “in/through you” relation.
That relation is already carried by the separate `<2m:ITP>` slot.
Putting ITP on the host would confuse the medium/beloved with the stimulus/object-cause.

#### RLT

`RLT` is already used on the carrier:

```text
esälu’u «objet petit a» hü
```

That is the label/apposition relation.
It should not replace the host’s semantic role in the `VVR₂` clause.

#### GEN

GEN would possessivize the relation too strongly, as though the excess were an inalienable possession of the beloved or of the speaker.
The sentence says the object is encountered “in you,” not that it is simply owned by you.

All four are therefore demoted for the host’s Slot IX.

### 10. `sue` remains adjacent and unchanged

Adding STM to the host does **not** alter the second-person Comparative referential from v2026.

The comparison still reads:

```text
hlušh-otilöehëi sue
```

where:

```text
hlušh-otilöehëi = the STM-cased X-term bearing SUR
sue              = the Y-term in Comparative case, “than you”
```

The comparison relation is internal to the host packet.
The new STM case belongs to the host’s external role in the `VVR₂` predicate.

So the two relations are layered:

```text
internal nominal comparison:
  X more-than Y
  hlušh-otilöehëi sue

external predicate role:
  X is the affective stimulus of VVR₂
  host-X takes STM
```

This layering is exactly why v2025-v2026 had to freeze SUR and `sue` before choosing the host’s final case.

### 11. the carrier apposition also remains unchanged

The foreign carrier label stays:

```text
esälu’u «objet petit a» hü
```

Its RLT case still says, in effect:

```text
this adjacent carrier phrase identifies/names the preceding host packet
```

The carrier does not need to copy STM.
The host takes STM because it is the clause participant.
The carrier takes RLT because it labels that participant.

So the local sequence becomes:

```text
hlušh-otilöehëi sue esälu’u «objet petit a» hü
```

not:

```text
hlušh-otilöehëi sue esälëi «objet petit a» hü
```

and not:

```text
hlušh-otilöehëi sue esälu’u «objet petit a»
```

The RLT carrier and `hü` boundary remain frozen from v2022-v2023.

### 12. the archive notation should now replace `OBJ:[...]` with `STM:[...]` for this local packet

The older readable line used:

```text
OBJ:[hlušh-otilöeh- sue esälu’u «objet petit a» hü]
```

That was acceptable while the final host case was still open.
But it has become misleading now that the host case is frozen.

The middle packet should now be cited as:

```text
STM:[hlušh-otilöehëi sue esälu’u «objet petit a» hü]
```

or, in a more overt line, simply as the cased sequence:

```text
hlušh-otilöehëi sue esälu’u «objet petit a» hü
```

The label `STM:[...]` is only an archive convenience.
The actual Ithkuil marking is the final `-ëi` on the host.

## Rejected or demoted alternatives

### A. keep the trailing hyphen

Rejected.
The archive now has enough grammatical support to close the host word.

```text
hlušh-otilöeh-
```

should no longer be the preferred running surface.

### B. keep `OBJ:[...]` as the primary label

Demoted.
It remains understandable as an English control label, but it hides the New Ithkuil semantic-role choice.
The preferred archive label is now:

```text
STM:[...]
```

### C. use THM

Demoted for the reasons above.
It is too neutral for `VVR₂`.

### D. use ABS

Rejected.
It wrongly patientizes the excess-object.

### E. use AFF

Rejected for the host.
It belongs to the experiencer side, not the stimulus side.

### F. make the carrier copy STM

Rejected.
The carrier labels the host and stays RLT.
The host alone carries the predicate role.

## What this checkpoint still does not claim

This checkpoint still does **not** claim:

- that `<2m:ITP>` has been realized as a final Referential;
- that the inner `<1m>` has been realized as a final Referential;
- that the framed predicate `hleňfó-évvroal-` has received its final case-frame surface and stress audit;
- that the final `XTŘ₂` clause has been surfaced;
- or that the full Lacan sentence is now final Ithkuil.

The gain is narrower and cleaner:

```text
hlušh-otilöeh-  →  hlušh-otilöehëi
```

and therefore:

```text
hlušh-otilöeh- sue esälu’u «objet petit a» hü

→

hlušh-otilöehëi sue esälu’u «objet petit a» hü
```

## Provisional takeaway

The host packet should now be carried forward as:

```text
hlušh-otilöehëi sue esälu’u «objet petit a» hü
```

The middle-clause archive label should now be:

```text
STM:[hlušh-otilöehëi sue esälu’u «objet petit a» hü]
```

The next deep pass should turn to the remaining middle-clause participants:

```text
<2m:ITP> <1m>
```

The especially live question is whether the speaker in the `VVR₂` clause should now be realized as a bare first-person **AFFECTIVE** referential, since `VVR₂` describes an affective state whose stimulus is now frozen as `STM`.
