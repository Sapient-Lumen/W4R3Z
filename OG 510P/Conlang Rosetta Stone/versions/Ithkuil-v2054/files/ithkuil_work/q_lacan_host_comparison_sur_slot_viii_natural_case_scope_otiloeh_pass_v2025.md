# Lacan host comparison SUR Slot-VIII natural case-scope pass v2025 — 2026-05-21

## English target span

This checkpoint continues directly from v2024.

Target sentence:

> **I love you, but, because inexplicably I love in you something more than you—the objet petit a—I mutilate you.**

The v2024 local packet was:

```text
<hlušh-otil->{LVL:SUR CMP:<2m>} esälu’u «objet petit a» hü
```

The host nucleus itself had just become more concrete:

```text
hlušh-otil-
```

where:

```text
hlušh-   = Type-1 concatenated salience/prominence prehead
otil-    = Stem-0 demonstrative OBJ parent head
```

The next live question named by v2024 was:

```text
how should the SURPASSIVE “more-than” Level be surfaced on this host pair?
```

This checkpoint answers only that question.
It does not yet fully surface the second-person Comparative term, and it does not yet choose the final noun case of the whole object packet relative to the middle predicate.

## What this checkpoint now freezes

### 1. the comparison remains ordinary relative `SUR`, not an absolute `LVL` affix

The source says:

```text
something more than you
```

It does not say:

```text
something absolutely beyond you
something maximally beyond you
something exceeding an external standard of otherness
something more-than-you according to a stated cosmic norm
```

So the archive should not inflate the comparison into an absolute Level, an external-standard comparison, or a special Lacanian degree affix.

The control morphology remains:

```text
SUR + CMP:<2m>
```

where:

```text
SUR       = the X-term is more M than Y
CMP:<2m>  = the addressee is the “than-Y” term
```

This keeps the translation source-near: the host is simply **more than you**.

### 2. the `SUR` Level belongs on the parent head, not on the salience prehead

The v2024 packet has a Type-1 prehead followed by a parent head:

```text
hlušh-otil-
```

The comparison must not be attached as:

```text
hlušh-{SUR} otil-
```

That would make the salience/prominence burden the direct comparison target and would drift toward:

> the salience is more than you

But the sentence says:

> something more than you

So the comparison should be surfaced on the parent-headed object, with the parent head carrying the Slot-VIII Level material:

```text
hlušh-otil-{SUR}
```

This still lets the whole concatenated pair be read as the X-term, because the parent is the head of the local nominal unit. The prehead keeps sharpening the object; it does not become the grammatical entity that exceeds the beloved.

### 3. Slot VIII is the correct home for the relative `SUR` value

For New Ithkuil formatives, Slot VIII Pattern 1 carries:

```text
VN + CN
```

with `VN` able to express Level and `CN` expressing Mood or Case-Scope depending on the formative’s relation/status.

For this nominal host, `CN` is read as Case-Scope rather than Mood.
The relevant Slot-VIII pair is therefore:

```text
VN = Level
CN = Case-Scope
```

Since the desired level is relative “more than Y,” the vowel value is:

```text
SUR = öe
```

Notably, this is the regular relative Slot-VIII Level lane, not the absolute `LVL` VXCS lane.

### 4. default natural Case-Scope is retained as diagnostic `h`

The parent head has no reason yet to mark special case-scope over adjacent nouns.
The local object packet is still being built, and the `CMP:<2m>` term will be explicit enough to govern the comparison relation in the next pass.

So the Case-Scope value remains default/natural:

```text
CCN = natural case-scope = (h)
```

For a zero Slot VIII, the archive can simply omit the whole `VNCN` complex.
But here Slot VIII is not zero, because `SUR` is present.
Therefore the diagnostic overt form should carry the default `h` after the `SUR` vowel:

```text
öe + h = öeh
```

This is the narrow but important new freeze of v2025:

```text
{LVL:SUR}  →  öeh
```

### 5. the parent-head lead advances from `otil-` to `otilöeh-`

The parent head from v2024 was:

```text
Slot II   VV = o     Stem 0 + PRC
Slot III  CR = t     General Demonstrative Root
Slot IV   VR = i     STA + OBJ + EXS
Slot VI   CA = l     default CSL/UPX/DEL/M/NRM
```

which yielded:

```text
otil-
```

Adding the Slot-VIII Level and natural Case-Scope gives:

```text
o + t + i + l + öe + h
```

and therefore the new diagnostic parent-head lead is:

```text
otilöeh-
```

This is not yet the final full word, because Slot IX case remains deliberately open.
It is, however, now the archive’s preferred running parent-head lead once the relative “more than” operator has been included.

### 6. the local host packet advances to `hlušh-otilöeh-`

Putting the Type-1 prehead back in front of the parent gives:

```text
hlušh-otilöeh-
```

This replaces the v2024 host packet:

```text
hlušh-otil-{LVL:SUR}
```

with the more overt v2025 packet:

```text
hlušh-otilöeh-
```

The archive should read this as:

```text
[salient/prominent] + [Stem-0 OBJ demonstrative] + [relative SURPASSIVE Level]
```

English-facing diagnostic:

> a salient something more-than

with the than-term still to be realized beside it.

### 7. the Comparative addressee should now be pulled out as a separate semi-overt term

Before this pass, the comparison was written compactly as:

```text
<hlušh-otil->{LVL:SUR CMP:<2m>}
```

Now that `SUR` has been surfaced on the parent head, the remaining comparison burden should no longer stay hidden inside the same braces.
The next cleaner notation is:

```text
hlušh-otilöeh- <2m:CMP>
```

This does two things:

1. it shows that the Level now belongs to the host formative itself;
2. it keeps the second-person “than-you” term visibly adjacent but not yet fully surface-derived.

This is better than continuing to write:

```text
hlušh-otilöeh-{CMP:<2m>}
```

because the addressee is not a suffix on the host.
It is the comparison’s Y-term, to be carried by its own Referential or equivalent nominal expression in Comparative case.

### 8. do not yet freeze the second-person CMP surface as `sue`

The next pass is now strongly pointed toward:

```text
<2m:CMP>  →  sue
```

The reason is straightforward:

```text
2m neutral monadic addressee = s
CMP case                    = ue / ië
```

With no immediately preceding `w-` trigger, the likely first-choice surface is:

```text
s + ue = sue
```

But v2025 deliberately does not freeze this yet.
There are still two reasons to keep one pass of caution:

1. the archive should confirm whether this than-term should be a bare Referential or a specialized personal-reference root in this exact local environment;
2. the host packet’s final Slot-IX case may affect the most legible case-scope presentation around the adjacent `sue` term.

So v2025 advances the notation only to:

```text
hlušh-otilöeh- <2m:CMP>
```

and leaves `sue` as the next expected but still unratified surface candidate.

## Alternatives now rejected or demoted

### A. keep `SUR` only as a brace-level gloss

Demoted.
The archive has now surfaced the relative Level as `öeh`, so the older notation:

```text
{LVL:SUR}
```

should not remain the primary working form for this packet.

### B. attach `SUR` to the salience prehead

Rejected.
It would falsely imply that salience itself is what is more than the addressee.

### C. use absolute `LVL` morphology

Rejected for now.
The source gives a simple relative comparison, not an absolute scalar claim.

### D. add the external-standard comparison affix now

Rejected.
The line does not say whether the object exceeds the beloved by some external standard of objecthood, desirability, symbolic lack, or moral salience.
Adding that now would overinterpret Lacan’s line.

### E. freeze `sue` in the same pass

Demoted, not rejected.
`<2m:CMP> → sue` is now the most likely next move, but this checkpoint keeps the archive’s incremental discipline and freezes only the Slot-VIII host-side comparison.

## What this checkpoint still does not claim

This checkpoint still does **not** claim:

- that the second-person Comparative term has been fully realized;
- that the final Slot-IX case of `otilöeh-` has been chosen;
- that `hlušh-otilöeh-` is the final stress-audited whole object word;
