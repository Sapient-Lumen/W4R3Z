
```text

        ↓

```

The working middle-clause head is no longer old `évvroal`; it is now current-grammar **`évvroîl`**.

## 3. Why `évvroal` must change

Earlier passes derived the parent head as:

```text
Vr  = e       Pattern 1 + Stem 2 + STATIVE for VVR₂
Cr  = vvr     VVR root
Vc  = oa      old/design-document SIT
Ca  = l       default NRM/DEL/M/CSL/UPX bundle
stress = FRAMED + IFL → antepenultimate
```

This yielded the older working packet:

```text
hleňfó-évvroal-
```

v2037 already found the problem: current public Ithkuil no longer gives `SIT = oa` in the ordinary case table. The current public case table gives:

```text
SIT / Situative = oi
```

and defines SIT as the case for the background context of a clause without implying a direct causative relationship. That is still exactly the archive’s reading of the Lacan clause:

> given the inexplicable background fact that through/in you I undergo obsessive attachment to the salient something-more-than-you, I mutilate you.

So the semantic case is retained, but the surface vowel must migrate:

```text
old Vc: oa
new Vc: oi
```

Therefore the parent head core becomes:

```text
e + vvr + oi + l  →  evvroil
```

---

## 4. Why the correct stressed citation is `évvroîl`, not simply `evvroil`

Current public syntax says a case-frame is made by placing the embedded sentence where a noun in that case would go; the case of the frame is shown on the verbal formative by the normal `Vc` case affix, and the embedded verbal formative takes **FRAMED relation**.

For an **INFORMAL** framed verbal formative, FRAMED relation is shown by **antepenultimate stress**. The archive has not found a reason to promote the middle VVR₂ head to FORMAL designation, so the v2003 IFL lead still stands.

The problem is phonological: `oi` is a diphthong, normally one syllable. If written simply as:

```text
evvroil
```

there may not be enough syllabic material for clean antepenultimate stress.

Current phonology explicitly permits a Slot-Vc case diphthong to be separated into two syllables in words requiring antepenultimate or preantepenultimate stress. The second character of the diphthong then takes a circumflex to show the separation:

```text
oi  →  oî
```

Now the parent head can support the required FRAMED stress:

```text
e-vvr-o-î-l
```

and the antepenultimate stress falls on the initial `e`.

Frozen stressed form:

```text
évvroîl
```

Therefore the full burden-parent packet becomes:

```text
hleňfó-évvroîl
```

This is not an optional prettification. It is the first current-grammar form in this local chain where `SIT` and `FRAMED` are both actually visible in the head.

---

## 5. Why `SIT` remains semantically correct despite English “because”

The source says:

```text
because inexplicably I love in you something more than you—the objet petit a—
```

A stronger direct-cause case would over-rationalize the sentence. Lacan’s line is not merely:

> I mutilate you because X directly causes my action.

It is closer to:

> Given the puzzling background condition that my love is caught in you by something beyond you, I mutilate you.

That is why v2030, v2037, and v2038 kept the wrapper as `SIT` rather than upgrading it to a more forceful direct-causal frame. v2039 does not reopen that semantic choice. It only gives it the current surface:

```text
SIT = oi
```

## 6. What happens to the old analytic wrapper

v2038 used:

```text
<FRAMED:SIT[ ... ]>
```

v2039 replaces that as the **grammatical claim**. The active string no longer needs to say `FRAMED:SIT` before the clause, because the information is now in the head:

```text
évvroîl
```

However, the archive may still use brackets in notes for human readability:

```text
[SIT-FRAME: hleňfó-évvroîl köi ti hlušh-otilöehui kè upeal «objet petit a»]
```

This is now editorial notation, not a missing Ithkuil morpheme.
