## 5. Scope of the AGGLOMERATIVE change

The AGGLOMERATIVE change applies only to the parent host:

```text
otir-
```

It does **not** apply to:

```text
hlušh-       salience prehead
sue          than-term
hlu’u        carrier adjunct
«objet petit a» foreign phrase
hü           phrase boundary
```

Reason:

- the salience prehead modifies the host but is not itself the indeterminate object;
- the than-term is a separate referential participant;
- the carrier adjunct names the host but is not the host;
- the foreign phrase remains foreign and unchanged.
