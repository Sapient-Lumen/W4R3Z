## 1. Scope of this revision

v2043 restored the active branch to New Ithkuil and corrected the `RSN` affix from the quarantined v2037–v2042 migration. It deliberately left the framed middle predicate as an unproven inherited shell:

```text
évvroalacb
```

v2044 rederives that word from the New Ithkuil formative slots. The result is a real surface correction, not a stylistic respelling.

The active change is:

```text
évvroalacb  →  evvrálacboa
```

The replacement fixes three problems at once:

1. it moves `SIT` into Slot IX, where case belongs;
2. it places `RSN/1` in Slot VII, before case;
3. it removes the inherited `oa` ambiguity inside `évvroal-`, where `oa` was being treated as if it were Situative even though, in that slot, it parses as a Slot-IV `VR` value.

## 3. Why `évvroalacb` is retired

The old word looked attractive because it visibly contained `VVR₂` and `RSN/1`, but it hid a slot-order error.

Under New Ithkuil’s standard formative order, the relevant sequence is:

```text
Slot II   Slot III  Slot IV  Slot VI  Slot VII  Slot IX  Slot X
Vv        Cr        Vr       Ca       VxCs      Vc       stress
```

So if the sequence immediately after the root is `oa`, that `oa` is not a Slot-IX case marker. It is in Slot IV and therefore reads as:

```text
Vr = oa = DYN + BSC + AMG
```

That is not what this clause needs. The middle clause needs `oa` as:

```text
Vc = oa = SIT / Situative
```

and Slot IX comes later, after `Ca` and any Slot-VII suffixes.

Thus:

```text
évvroalacb
```

is retired as an ambiguous inherited form whose visible `oa` occupies the wrong morphological slot for the project’s intended `SIT` frame value.

## 4. Rebuilding the word from slots

Target burden:

```text
“because / given that, inexplicably, I love-in-you...”
```

More precisely for the framed predicate:

```text
FRAMED:SIT + VVR₂ + STA/BSC/EXS + default Ca + RSN/1
```

### 4.1 Slot II — `Vv = e`

The lexicon gives:

```text
-VVR-
Stem 1: feel(ing of) passion
Stem 2: feel(ing of) infatuation/obsessiveness
Stem 3: feel(ing of) worship/adoration
```

For Stem 2, PRC version, Slot II is:

```text
e
```

This gives the `e-` of:

```text
e-vvr-...
```

### 4.2 Slot III — `Cr = vvr`

The root remains:

```text
-vvr-
```

This is not the opening ordinary love root `RKW₁`. It is the inner Lacanian cathexis root, chosen because the source says “I love in you something more than you,” not merely “I love you.”

### 4.3 Slot IV — `Vr = a`, not `oa`

The framed middle predicate is an affective state, not a tangible dynamic process. The New Ithkuil grammar’s own example distinguishes:

```text
Vvralá mi wurçpëi.   “Her passion is dance / She feels passionate about dance.”
```

This confirms the stative emotional-state lane for `VVR`.

So v2044 chooses:

```text
Vr = a = STA + BSC + EXS
```

not:

```text
Vr = oa = DYN + BSC + AMG
```

The inherited `oa` in `évvroal-` is therefore removed from Slot IV.

### 4.4 Slot VI — `Ca = l`

The middle predicate keeps default `Ca`:

```text
-l = CSL + UPX + DEL + M + NRM
```

This gives the transparent base:

```text
e + vvr + a + l  →  evvral-
```

### 4.5 Slot VII — `RSN/1 = -acb`

v2043 correctly chose `RSN/1` semantically. v2044 keeps the choice but places it in the correct slot.

The affix list gives:

```text
RSN = -cb
Degree 1 = “for no reason”
```

The standard Type-1 Degree-1 vowel is:

```text
a
```

so:

```text
RSN/1 Type-1 = -acb
```

This is placed after `Ca` as Slot VII:

```text
e-vvr-a-l-acb-
```

I choose Slot VII rather than Slot V because `RSN` should describe the configured emotional-state predicate as a whole, not merely the lexical stem before its `Ca` configuration. Slot VII affixes have scope over the stem plus `Ca`, and they do not require `Ca` gemination.

### 4.6 Slot IX — `Vc = oa` for SIT

Now `SIT` is finally placed where case belongs:

```text
Vc = oa = SIT / Situative
```

This yields:

```text
e-vvr-a-l-acb-oa
```

or:

```text
evvralacboa
```

### 4.7 Slot X — FRAMED stress

Because the middle clause is a case-frame, the formative needs FRAMED relation. New Ithkuil marks FRAMED relation through antepenultimate stress when Slot IX is a `Vc` case value.

The vowel nuclei of the new word are:

```text
e / a / a / oa
```

Antepenultimate stress therefore falls on the second nucleus:

```text
evvrálacboa
```

So the active word becomes:

```text
evvrálacboa
```

## 5. What this fixes semantically

The old active middle predicate was doing too much by historical inertia:

```text
évvroalacb
```

It made the bridge line look like it had a `SIT` frame, but the visible `oa` was not actually in the case position. The new predicate says the intended thing more honestly:

```text
evvrálacboa
```

slot-by-slot:

```text
e        VVR₂ / Stem 2 / PRC
vvr      infatuation-obsessiveness root
a        STA/BSC/EXS
l        default Ca
acb      RSN/1 “for no reason”
oa       SIT “given that / in view of the fact that”
stress   FRAMED relation
```

This is a better match for the English burden:

```text
because inexplicably [I love in you something more than you...]
```

where “inexplicably” modifies the emotional state and “because / given that” embeds the whole state as the background context for the final violence.

## 8. Remaining open problems after v2044

### 8.1 Carrier case: RLT vs ESS

```text
esälu’u «objet petit a» hü
```

Still unresolved. RLT is inherited and defensible; ESS still has conceptual pull if the French phrase is the name/role under which the surplus object is identified.

### 8.2 Host nucleus

```text
hlušh-otilöehëi sue
```

Still dense. The root/prehead analysis and the Level machinery need an audit similar in seriousness to this frame-head pass.

### 8.3 CTR surface

```text
alo
```

Semantically still good as a contrastive/concessive bridge, but spelling and scope need a New-Ithkuil affixual-adjunct audit.

### 8.4 `evvrálacboa` phonotactics

The new word is slot-correct. A later phonotactic pass should still confirm whether the `-cb-oa` transition ever wants an epenthetic repair in careful pronunciation. I have not inserted one here because `-cb` is the official CS form of the suffix and Slot VII naturally precedes Slot IX.
