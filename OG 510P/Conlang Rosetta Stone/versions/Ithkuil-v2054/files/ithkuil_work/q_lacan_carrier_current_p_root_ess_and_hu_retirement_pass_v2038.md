## 1. Scope of this revision

v2037 corrected the personal referentials, DER stimulus/cause lane, ITP, CMP, and CTR under the current public Ithkuil grammar. It deliberately left the foreign-name carrier as an older unresolved pocket:

```text
esälu’u «objet petit a» hü
```

v2038 resolves that pocket. It retires the old New-Ithkuil `-S-` carrier-root analysis and the old explicit `hü` carrier-end word from the **working current-grammar line**, replacing them with the current public grammar’s `-P-` carrier root and its tone/pause boundary policy for non-Ithkuil material.

The main result is:

```text
esälu’u «objet petit a» hü  →  upeal «objet petit a»
```

with the spoken boundary carried by high/rising tone on the last syllable of the foreign phrase, or by a pause if a reciter needs disambiguation.

## 3. Why the carrier root changes: `-S-` → `-P-`

The older passes used the New-Ithkuil carrier root `-S-`, surfaced locally as `esäl-...`. The current public grammar and current lexicon instead identify the carrier root as:

```text
-P-
```

and define its informal stems as:

```text
Stem 1: carrier stem representing animate being
Stem 2: carrier stem representing inanimate entity
Stem 3: carrier stem representing abstract referent
```

For Lacan’s `objet petit a`, the target is not a literal person, nor a concrete physical object. It is a theoretical psychoanalytic object/construct — an abstract referent. So the current-grammar carrier must use **informal Stem 3** of `-P-`, i.e. the `up-` stem.

Frozen replacement:

```text
old: esäl-...  // older -S- carrier lane
new: up-...    // current -P- carrier, informal Stem 3, abstract referent
```

## 4. Why ESS wins over the older RLT/COR-like appositive lane

v2022 selected RLT-like relative/appositive marking because the foreign phrase identifies/distinguishes the preceding host packet. That was a defensible old-system reading, but current public Ithkuil gives a sharper case: **ESS / Essive**.

ESS is the case for the role or name by which a noun is known or contextually identified. That is exactly what `objet petit a` is doing here. It is not a fresh argument of the love-predicate; the real stimulus argument is already the host packet:

```text
hlušh-otilöehui
```

The carrier phrase is a naming/identifying apposition to that DER host:

```text
hlušh-otilöehui kè upeal «objet petit a»
≈ the salient something-more-than-you, identified by the name “objet petit a”
```

So the case logic is:

```text
host packet: DER / stimulus-cause of the affective state
carrier label: ESS / identifying name of that host packet
```

This avoids falsely making the foreign name itself the only stimulus while preserving the source’s appositional dash.

## 5. Surface derivation of `upeal`

Current formative spine, using only the needed overt pieces:

```text
Vr + Cr + Vc + Ca
```

Derivation:

```text
Vr  = u      Pattern 1 + Stem 3 + STATIVE
Cr  = p      current carrier root -P-
Vc  = ea     ESS / Essive case
Ca  = l      default NRM/DEL/M/CSL/UNI
```

Therefore:

```text
u + p + ea + l  →  upeal
```

Local gloss:

```text
upeal «objet petit a»
carrier.abstract-ESS “objet petit a”
≈ by/under the identifying name “objet petit a”
```

No derivational suffix is added in this pass. The point is not to coin an Ithkuil lexicalization of Lacan’s term; the point is to leave the technical phrase foreign while giving it the right case behavior in the surrounding Ithkuil syntax.

## 6. Why `hü` is retired in the current working line

The older New-Ithkuil carrier-end convention used `hü` to mark the end of a foreign/proper phrase governed by a carrier. Current public grammar instead says that the non-Ithkuil word or phrase is left unchanged and pronounced with high or rising tone on its last syllable to clue the listener that the following material returns to Ithkuil. If the foreign phrase natively has grammatical tone, the boundary can be signaled by a pause or by repetition of the carrier-stem after the phrase; the repeated carrier-stem is not indicated in writing.

For `objet petit a`, which is not a grammatical-tone phrase in the relevant way, the clean current-grammar choice is:

```text
upeal «objet petit a»
```

with the boundary handled by tone/pause, not by an extra written `hü`.

This means v2038 prospectively supersedes:

```text
v2023: ... «objet petit a» hü
v2038: ... «objet petit a»  // final foreign-phrase tone or pause in performance
```

## 7. Frame-end hostability audit

v2030 and v2037 both asked whether the end of the embedded Situative frame should be overtly marked. Current syntax says a case-frame inserted at the beginning or middle of a main sentence will usually put a `-Vt’` suffix on the last noun in degree 2, 6, 7, or 9 to signal frame-end if needed. Chapter 7 gives `TPF -t’`, with Degree 2 specifically meaning `[end of frame]`.

The present frame ends after a foreign phrase:

```text
<FRAMED:SIT[ ... upeal «objet petit a» ]> iňň aixtřas to ke
```

v2038 does **not** attach TPF/2 directly to the foreign words. Reasons:

1. `objet petit a` is deliberately left unchanged as a foreign phrase, so regular Ithkuil suffixation should not be put on it.
2. The carrier `upeal` precedes the foreign phrase. The final word of the frame, in linear speech, is therefore the foreign phrase itself, not `upeal`.
3. Current carrier-root syntax already has a phrase-exit mechanism: high/rising tone on the foreign phrase’s last syllable, or a pause/repeated carrier-stem for hard cases.
4. In the working written line, the frame is already bracketed, and the main predicate resumes with the contrastive adjunct `iňň`, so forced TPF would be solving a presentation problem more than a grammatical one.

Frozen v2038 policy:

```text
No TPF/2 suffix in the working line.
No suffix on the foreign phrase.
No reintroduced hü.
Use current carrier tone/pause boundary and bracketed frame notation for now.
```

If a future all-surface recitation demands a no-brackets/no-punctuation version, the best candidate is not `objet petit a` + suffix. It would be a separate spoken boundary strategy: pause, or possibly a repeated carrier-stem after the phrase per the carrier-root rule. That needs its own pass.
