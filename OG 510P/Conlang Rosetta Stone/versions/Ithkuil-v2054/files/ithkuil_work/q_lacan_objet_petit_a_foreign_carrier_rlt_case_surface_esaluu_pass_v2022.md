## What this checkpoint now freezes

### 1. the next defensible move is the carrier’s final case, not yet the host nucleus

The archive should now choose the foreign carrier’s Slot-IX case before trying to overtly realize the preceding host nucleus.

The reason is local dependency.
The carrier is already immediately adjacent to the still-abstract host:

```text
<T-OBJ + ŠH₃>{LVL:SUR CMP:<2m>} esäl- «objet petit a»
```

and its entire job is to say how the named French theoretical phrase attaches to that host.
If the case is left open, any attempt to flatten the host nucleus risks ambiguity about whether the named phrase is:

- a second object,
- a loose topic,
- a mere description,
- or an identifying appositive.

The smallest way to prevent that ambiguity is to freeze the carrier’s case now.

### 2. the carrier should not take ABS, THM, PRN, DSP, or COR as its final case

This checkpoint explicitly rejects five tempting alternatives for the carrier.

It should not take **ABS** because the carrier is not a second patient of either the middle-clause loving or the final mutilating.
The whole object packet is the semantic burden; the carrier merely identifies the right edge of that packet.

It should not take **THM** because the named phrase is not simply the content-theme of the predicate.
Again, the predicate-level content is larger: “something more than you — the objet petit a.”

It should not take **PRN** because “pertaining to / about / in reference to” is too weak.
The French phrase is not merely a topic regarding the host.
It names what the host is being identified as.

It should not take **DSP** because the French phrase is not being used as a mere adjectival descriptor of the host.
The dash-apposition is not saying merely “an objet-petit-a-like something.”
It is saying, in the archive’s current reading, “that more-than-you something, namely the objet petit a.”

It should not take **COR** because the relation is not just abstract association or correlation.
The line is not pointing to a symbolic relation between the host and `objet petit a`; it is using the French phrase as the identifying technical label.

### 3. the carrier should take **RLT** as its final Slot-IX case

The best final case for the carrier is:

```text
RLT = RELATIVE
```

This is not because the carrier is a full English-style relative clause.
It is because the official RLT lane does exactly the appositive-identificatory work needed here:

```text
that which identifies or distinguishes X from other parties
```

The carrier follows the host immediately and identifies/distinguishes that host by means of the succeeding foreign phrase.
So the local relation is:

```text
host:     <T-OBJ + ŠH₃>{LVL:SUR CMP:<2m>}
carrier:  esäl- «objet petit a»  = that which identifies/distinguishes the host
```

This preserves the archive’s long-standing decision that `objet petit a` should remain a tight post-host technical apposition rather than replacing the host itself.

### 4. default case-scope is enough because the carrier is the second member of an adjacent relational pair

This checkpoint also freezes that no overt Slot-VIII case-scope marker is needed on the carrier.

The carrier is a relational-case formative immediately following the noun-like host it identifies.
For this configuration, the ordinary adjacent-pair behavior already supplies the intended scope:


So the archive should not add an overt `CCV` marker just to say what adjacency already says.
The carrier can remain morphologically cleaner:


```text

```

That matters because the local packet is already difficult.
Adding overt case-scope here would make the line heavier without adding a semantic distinction.

### 5. RLT gives the carrier the Slot-IX case value `u’u`

RLT is case 44.
Its ordinary Slot-IX `VC` value is:

```text
u + glottal stop
```

Because the glottal stop cannot simply remain word-final after a single-vowel case marker, the transparent full surface form is:

```text

```

So the carrier advances from:

```text
esäl-
```

to:

```text

```

This checkpoint therefore freezes the preferred full transparent carrier form as:

```text

```

ASCII fallback, if needed in tooling:

```text

```

### 6. why the archive should prefer the transparent full `u’u` form rather than relocating the glottal stop

The grammar allows certain shortening strategies for cases in the 37–52 range by moving the glottal stop into an earlier post-Slot-II vowel.
But this checkpoint rejects that shortcut for the current archive state.

The reason is not that the shorter form would be impossible.
The reason is that the archive is still using this pass to make the case relation visible.
A compressed glottal relocation would hide the very point being frozen here: the carrier is now overtly **RLT**.

So the preferred archive form should remain the maximally legible one:

```text

```

not a shortened or glottal-relocated variant.
