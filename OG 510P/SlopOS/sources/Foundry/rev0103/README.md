# Foundry

Foundry is the embryonic datacube for **off-native realization and projection honesty** in the SlopOS ecology: how artifacts stay semantically honest when execution, storage, query, interaction, grouping, rollup, materialization, reuse, aggregate release, adjusted observation, reconciliation, classification, rendering, export, dashboard projection, refusal, revision-to-revision regression, bounded semantic exception, cross-consumer interpretation, delegated semantic acts, revocation, recall, remediation, distribution, surface inventory, exposure, obligations, fulfillment, verification, recheck/drift, escalation/routing, disposition/resolution, precedent-driven rule promotion, promoted-rule collision/precedence, rule evaluation/application, and now rule-effect binding happen on foreign ground.

`rev0103` keeps the cube intentionally small while making **application-is-not-effect** machine-checkable. This pass promotes specimen 97 around rule-effect ledgers, effect witnesses, and bypass fences so a rule-evaluation output cannot be displayed as having changed a carrier, export, projection, warning, quarantine, or no-op state without scoped residue. It also audits/refactors cross-specimen id hygiene with a machine-readable reference-integrity index.

## Current focus

This revision focus is **rule-effect ledgers, effect witnesses, and bypass fences**.

This revision is about making rule effects falsifiable:
- a **rule-effect ledger** links source rule-evaluation traces, applicability witnesses, misapplication fences, effect context, intended effects, bound effects, required effect witnesses, bypass fences, blocked inferences, and authority boundaries;
- an **effect witness** records whether the specific effect was applied, partial, refused, missing, bypassed, quarantined, or superseded for the exact subject/context; and
- a **bypass fence** blocks selected-rule-as-effect, weak-result laundering, wrong context, stale/default/deprecated/shadow application, reference drift, public-release/authorization/audit laundering, repair/lifecycle laundering, and sibling-verdict laundering.
