
# Helm-rev0010-2026.03.21.04.18-rehearsalcards-capsulediffs

Helm is a desktop shell/compositor product for SlopOS-style capability systems.

This revision keeps Helm's pillar set stable and uses another SlopOS + Schell + DelayBasin pass plus more outside research to pressure three especially promising cross-cutting moves:
- action rehearsal / route cards,
- capsule diffs,
- and shell-owned layout templates with rebinding.

## What this revision locks in

- Helm still benefits more from better shell-owned luxuries and honesty surfaces than from adding more pillars
- SlopOS continues to pressure exactness, shell ownership, anti-ambient discipline, and route/reveal honesty
- Schell continues to pressure packets, witnesses, restore honesty, and shell-facing compact action objects
- DelayBasin now directly pressures rehearsal as a way to make strong actions more legible before commit
- Helm should keep stealing rich action cards, timeline cues, preview, workspace capture, and visual templates from current tools without inheriting their helper-sprawl substrate
- the most promising new candidate moves are now rehearsal cards, capsule diffs, and layout templates with rebinding
