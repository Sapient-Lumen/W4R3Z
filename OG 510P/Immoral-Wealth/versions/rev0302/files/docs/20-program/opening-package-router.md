# Opening package router

## What this note is for

This note gives the archive a **thin routing rule for first serious packages**.
It sits between diagnosis and implementation.
Its job is to answer a practical question that future case memos would otherwise keep re-solving from scratch:
**given the dominant breach, the fastest washout channel, the governing mode, and the current rails, what should the opening package actually contain?**

The archive's answer is that an opening package should be built as a **small four-slot composition** rather than as one favorite instrument or one undifferentiated shopping list:
1. a **lead lane** that hits the dominant mass breach,
2. a **mandatory closure lane** that shuts the fastest washout channel,
3. a **durability / anti-capture lane** that makes the gain harder to reverse,
4. and a **rail / gating lane** that says what can begin now, what should build while moving, and what must wait.[S04][S15][S18][S19][S20][S21][S22][S23][S31][S32][S33][S54]

## Minimum operating rule

Before using this router, the case should already have chosen its dominant breach and fastest washout channel using [`dominant-breach-and-fastest-washout-selection.md`](dominant-breach-and-fastest-washout-selection.md) rather than by instrument preference or diagnostic sprawl.

A serious opening package should usually do **five things at once**:

1. **Name one lead lane from the dominant breach.** Do not start with the most rhetorical instrument.[S15][S18][S19][S20][S21][S22][S23]
2. **Add one mandatory closure lane from the fastest washout channel.** Gains count for less when the main reabsorption path stays open.[S07][S10][S17][S20][S31][S32][S33][S36]
3. **Add one durability or anti-capture element.** A first package should not assume later politics will stay friendly on their own.[S15][S20][S23][S31][S32][S33][S54]
4. **State the rail position honestly.** Say what can begin now, what should build while moving, and what remains gated.[S04][S15][S23][S31]
5. **Keep the opening package small enough to govern.** The default opening answer is usually three or four compact moves, not ten ambitions wearing one heading.[S20][S23][S31][S32][S33]

So the standing rule is:
**pick the lead lane from the breach, force in the washout closure, harden the package for the current mode, and keep the package inside real rails.**

## The six main false passes

### 1. The opening package starts from a favorite instrument rather than the dominant breach

A package fails when the writer reaches first for a preferred tax, fund, ownership vehicle, or service expansion without first saying where ordinary people are constitutionally failing.[S15][S18][S19][S20][S21][S22][S23]

### 2. The package helps on one side while leaving the fastest washout channel open

Starter assets, wage gains, or floor repair count for less when land, debt, monopoly tolls, or opacity are still positioned to pull the same gains back upward.[S07][S10][S17][S20][S23][S31][S32][S33][S36]

### 3. The package is long enough to sound serious but too long to govern

A case memo fails when its opening answer is really a whole platform.
The archive wants an opening package small enough to sequence, defend, monitor, and revise.[S20][S23][S31][S32][S33]

### 4. Mode is ignored

A prevention case, a correction case, and an anti-oligarchy case do not open at the same speed or with the same tolerance for soft measures.
Ignoring mode makes packages either too timid or theatrically hard.[S15][S20][S23][S31][S32][S33]

### 5. High-complexity top-tail tools lead before the rails exist

A package counts less when it opens with valuation-heavy or visibility-heavy promises the state cannot yet execute, while easier floor, tenant, wage, or registry moves are left waiting.[S04][S15][S23][S31]

### 6. The package broadens in the aggregate while the blocked groups or persons still wait

A package fails when the first gains stay household-masked, insider-biased, or place-closed.
Opening packages should be read from entrant passage, person-level control, and excluded-group movement, not only from average reach.[S18][S19][S27][S28][S29][S30]

## The standing opening-package router

### 1. Build every opening package out of four slots

Treat the opening package as a small composition:

- **lead lane:** the lane that hits the dominant breach,
- **washout closure:** the lane that blocks the fastest reabsorption path,
- **durability / anti-capture:** the lane that makes reversal harder,
- **rail / gating note:** what can begin now, what should build while moving, what stays gated.[S15][S20][S23][S31][S32][S33]

Lane 1 in the archive fixes the target.
Opening packages usually route through **lanes 2-7**.[S18][S19][S20][S21][S22][S23]

### 2. Choose the lead lane from the dominant breach

#### A. Floor-failure cases

Lead with **lane 2**: lower forced private exposure, strengthen claimability, protect modest buffers, and stop punitive spend-down or seizure from hollowing out the floor.
Add **lane 3** early when weak earnings are part of why the floor never stabilises.[S17][S21][S22][S39][S40][S41][S45][S50]

Default opening shape:
- **lead lane:** 2,
- **washout closure:** usually 5 when housing, debt, or fees are reabsorbing gains,
- **durability lane:** 7 when anti-capture or public counterweight is thin,
- **early support lane:** 3 and sometimes 4 if the floor problem is also a timing problem.[S07][S17][S18][S19][S20][S21][S22][S23][S31][S36][S39][S40][S45][S50]

#### B. Weak-earnings and no-saveable-room cases

Lead with **lane 3**: bargaining power, wage floors, hours stability, worker-side protection, and lower extraction from ordinary earnings.
Do not ask households to save their way out of weak pay and forced self-insurance alone.[S08][S09][S10][S11][S14][S17][S21][S22]

Default opening shape:
- **lead lane:** 3,
- **washout closure:** 5 when rents, markups, transport, health, care, or debt are eating the gains,
- **durability lane:** 7 when public provision is too weak to keep earnings gains from being privately re-insured,
- **support lane:** 2 when the current floor is too thin to let labor gains hold.[S08][S09][S10][S17][S20][S21][S22][S31][S36]

#### C. Late-entry and dynastic-closure cases

Lead with **lane 4**: move footholds earlier, make them person-level, portable, and hard to appropriate away.
These cases usually need earlier starter capital, less household masking, and less dependence on inherited timing luck.[S18][S19][S27][S28][S29][S30][S41][S47][S52]

Default opening shape:
- **lead lane:** 4,
- **washout closure:** 5 when housing, land, or education-adjacent gatekeeping will capitalise the gain,
- **durability lane:** 6 when inheritance or dynastic insulation is the real blocker,
- **support lane:** 2 when the lower half cannot hold the foothold once received.[S07][S12][S18][S19][S20][S23][S27][S28][S29][S30][S34][S35][S36][S52][S53]

#### D. Rent-washout and closed-opportunity cases

Lead with **lane 5**: housing, land, rent, markup, fee, and chokepoint closure.
These are the cases where visible broadening mostly gets capitalised into prices or private tolls unless the closure channel is hit directly.[S07][S10][S17][S20][S31][S34][S35][S36][S53]

Default opening shape:
- **lead lane:** 5,
- **support lane:** usually 2 and 3 so households can survive while closure is being forced,
- **durability lane:** 7 when public/common capture of the reopened value is still weak,
- **hardening lane:** 6 when rent extraction is protected by dynastic or political concentration.[S07][S10][S12][S17][S20][S21][S22][S23][S31][S34][S35][S36][S53][S54]

#### E. Top-tail-rule and oligarchic-conversion cases

Lead with **lane 6** together with **lane 7** earlier and harder than usual.
Once concentrated wealth is buying rule, access, rescue, agenda power, or dynastic insulation, soft broadening alone will usually be vetoed or clawed back.[S04][S05][S06][S15][S18][S19][S23][S31][S38][S54]

Default opening shape:
- **lead lanes:** 6 and 7,
- **washout closure:** whatever opacity, procurement, monopoly, or crisis-laundering channel is protecting the top tail,
- **support lane:** 2 or 3 when mass legitimacy and ordinary security need to move at the same time,
- **rail note:** lead with instruments the state can really see and enforce, while building visibility for harder tools.[S04][S15][S20][S23][S31][S32][S33][S38][S54]

#### F. Thin-public-counterweight cases

Lead with **lane 7**: build public/social wealth, common capture, and anti-capture durability strong enough to lower forced private dependence.
But do not mistake public wealth alone for citizen-side security.[S02][S12][S20][S21][S22][S23][S31]

Default opening shape:
- **lead lane:** 7,
- **support lane:** whichever of 2-4 most directly lowers forced dependence now,
- **washout closure:** 5 when public effort is otherwise being capitalised into private land or monopoly gains,
- **hardening lane:** 6 when incumbents are positioned to privatize the uplift.[S07][S12][S18][S20][S21][S22][S23][S31][S34][S36][S54]

#### G. Mixed cases

When several breaches are live, keep one rule:
**lead with the breach doing the most mass constitutional damage, force in the washout closure, and add the smallest durability lane that stops quick reversal.**
Do not let mixed diagnosis become permission for an incoherent list.[S15][S18][S19][S20][S21][S22][S23][S31][S32][S33]

### 3. Add the mandatory closure lane from the fastest washout channel

Whatever the lead lane, force in the closure move that blocks the fastest reabsorption path:

- **housing and land washout** -> add housing supply, anti-speculation, tenure, land-value capture, or public-entry measures from lane 5,[S07][S12][S20][S34][S35][S36][S53]
- **debt and carrying-cost washout** -> add anti-seizure, anti-fee, debt-quality, or restart-capable protection from lanes 2 and 5,[S17][S39][S40][S45][S50]
- **monopoly or fee extraction** -> add competition, rate, procurement, or anti-chokepoint discipline from lane 5,[S10][S20][S31][S36]
- **opacity and controller invisibility** -> add legibility, registries, beneficial ownership, and enforcement rails from lanes 6 and 7,[S15][S23][S31][S38]
- **public downside absorption or crisis laundering** -> add repair duty, downside discipline, and anti-soft-landing measures from lanes 6 and 7.[S20][S31][S32][S33][S48]

A package should usually be judged weaker when this closure lane is absent, even if the lead lane is morally attractive.

### 4. Harden or soften the package by mode

- **Prevention:** open earlier and lighter, with more emphasis on keeping ordinary broadening real before capture hardens.
- **Correction:** pair the lead lane with more explicit washout closure and one clear durability lane.
- **Anti-oligarchy response:** move faster on control, visibility, political firewalls, anti-blackmail rules, and top-tail compression; softer broadening alone is not enough here.[S15][S20][S23][S31][S32][S33][S54]

Mode does not change the target.
It changes how much patience the archive should have for partial or softly governed tools.

### 5. Keep the package inside real rails

The opening package should finish with a short rail note:
- **begin now** -> simple floor, tenant, wage, subsidy-cleanup, registry-linking, disclosure, or claimability moves that current rails can carry,
- **build while moving** -> measures that can start in partial form while delivery, visibility, or enforcement improve,
- **gated for now** -> tools that depend on valuation quality, controller visibility, or integrity that the case does not yet have.[S04][S15][S23][S31]

The archive's bias is neither maximal delay nor false readiness.
It is **begin what is real, build what is near, gate what would otherwise be theater**.

## Fast use rule

When writing a case memo, fill the opening-package section in five lines:

1. **Lead lane:** name the lane that hits the dominant breach.
2. **Mandatory closure:** name the washout channel that must be closed at the same time.
3. **Durability / anti-capture:** name the smallest extra lane that stops quick reversal.
4. **Mode adjustment:** say how prevention, correction, or anti-oligarchy changes speed and hardness.
5. **Rail note:** say what begins now, builds while moving, and stays gated.

Default shortcut:
- **one dominant breach + one obvious washout** -> use one lead lane, one closure lane, one durability lane, and a short rail note;
- **several live breaches** -> still choose one lead lane and one mandatory closure first;
- **capture-heavy case** -> move 6 and 7 earlier;
- **entry-heavy case** -> move 4 earlier but force in 5 if access will capitalise away;
- **floor-heavy case** -> move 2 first, but do not leave 5 open.[S07][S15][S17][S18][S19][S20][S21][S22][S23][S31][S32][S33][S36][S54]

## Bottom line

The archive does not want future case work to rediscover the same routing logic every time.
The standing rule is simple:
**one lead lane from the dominant breach, one mandatory closure lane from the fastest washout channel, one durability or anti-capture lane sized to the mode, and one honest rail note.**
That is the archive's smallest reusable answer to the question of how a near-ideal distribution should actually be approached from a live case. When several serious opening packages still remain after this step, hand off to [`package-choice-and-tie-break-rules.md`](package-choice-and-tie-break-rules.md) rather than letting the memo drift into a shopping list.
