# Local land-use democracy and entry router

Use this router when housing, land, or place closure is politically maintained by local owner veto rather than only by physical scarcity or construction cost.

## Decision path

1. **Who benefits from scarcity?** Identify incumbent owners, fiscal beneficiaries, landlords, local governments, preservation coalitions, and developers with land banks.
2. **Who lacks voice?** Identify renters, would-be residents, young households, migrants, workers, displaced groups, and future residents.
3. **Where are veto points?** Map discretionary approvals, appeals, environmental or historic review, parking/minimum-lot rules, height limits, council votes, referenda, litigation, and utility-grid constraints.
4. **What is the entry effect?** Link veto points to rent burden, purchase delay, commuting burden, school/place exclusion, and parent-backed threshold dependence.
5. **What level can repair it?** Decide whether local reform, regional review, state pre-emption, fiscal incentives, or national funding conditions are needed.

## Routing rules

- If local veto mainly preserves exclusion in high-opportunity places, route to place-closure and early-foothold lanes.
- If local veto mainly inflates rents and drains starter assets, route to washout and renter-security lanes.
- If local veto blocks public or social housing siting, route to public/common counterweight and anti-averaging lanes.
- If the main blockage is voter misunderstanding of supply, add public-evidence and deliberation design; do not mislabel all opposition as corruption.[S202]
- If the main blockage is incumbent property value protection, add regional/state constraint on local veto points.[S195]

## Evidence pack

Use OECD affordable-housing indicators for cross-country comparability, and local/national supply data for jurisdictional cases.[S196][S197]
