# Sovereign wealth and public-asset governance router

Use this router when a case treats sovereign wealth, public land, public equity stakes, reserves, stabilization funds, resource revenue, or state investment funds as public/common wealth.

## Governance test

- legal mandate and owner clearly named;
- deposit and withdrawal rules public and durable;
- professional investment management separated from day-to-day political allocation;
- benchmark, costs, returns, and risk published;
- exclusions/stewardship policies transparent;
- intergenerational rule stated;
- domestic spending link or dividend/claim link explicit;
- emergency-use rule hard to abuse;
- audit and parliamentary/public reporting available.[S369][S370][S371]

A public fund can be a strong counterweight, but only if it does not become an off-budget patronage pool or a prestige-investment machine.
