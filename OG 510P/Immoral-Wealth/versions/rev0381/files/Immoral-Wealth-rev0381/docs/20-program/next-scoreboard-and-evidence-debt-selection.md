# Next scoreboard and evidence-debt selection

## What this note is for

This note gives the archive a **thin rule for choosing the next scoreboard and the main evidence debt** after a real-case memo has already reached a verdict, breach choice, package call, confidence labels, and watch posture.
Its purpose is simple:
future case work should not end by pasting the whole archive's measurement stack back into one memo.
It should end with the **smallest watch set** that can still tell whether the case is building, missing, hardening, or slipping back.[S05][S06][S15][S20][S23][S31][S32][S33]

## Minimum operating rule

Every serious case memo should end with **two short lists and only two**:

1. the **next scoreboard** — the smallest set of live surfaces that can tell whether the current package or posture is actually landing,
2. the **evidence debt** — the smallest set of missing facts that could still change the verdict, package choice, rail reading, or softer-certification claim.

The archive should not confuse those two things.
A scoreboard watches **movement on live surfaces**.
Evidence debt names **missing proof that still matters**.
The first is about what to keep watching.
The second is about what must still be learned.
When they collapse into each other, future memos either bloat into a general dashboard or drift into fake certainty.[S15][S23][S31][S32][S33]

## What the next scoreboard is supposed to do

The next scoreboard is not the whole archive's five-axis stack repeated one more time.
It is a **watch set** for the next durability window.
Use [`review-cadence-and-durability-window-selection.md`](review-cadence-and-durability-window-selection.md) after this note to decide how often that watch set should actually be read, when continued miss should force reroute, and what time burden still blocks softer certification.
Its job is to answer one practical question:
**what are the fewest surfaces we need to watch next to know whether the current reading is improving, missing, hardening, or reopening?**

In most cases the next scoreboard should be **three to six lines**, not twenty.
It should usually include:

1. **the dominant-breach surface** — the main harm the package is meant to hit,
2. **the fastest-washout surface** — the main channel that could reabsorb gains first,
3. **the main entrant / lower-half incidence surface** — where the next durable gains are actually landing,
4. **one rail or capture surface** if delivery integrity or political neutralisation is a live risk,
5. **one softer-reading trigger** if the case is being watched for ratchet, provisional pass, or de-escalation.

That is enough for most memos.
If a case needs much more than that, the memo usually has not yet chosen its dominant breach, fastest washout, watch posture, or confidence labels tightly enough.[S05][S06][S15][S20][S23][S31][S32][S33]

## What evidence debt is supposed to do

Evidence debt is not a wishlist of interesting future research.
It is the short list of missing facts that still block a cleaner judgment.
A good evidence-debt list should usually answer one of four questions:

1. **What missing evidence could change the verdict?**
2. **What missing evidence could change the package choice?**
3. **What missing evidence could change the rail / gating judgment?**
4. **What missing evidence could justify or block softer certification?**

If a missing fact would not move one of those four questions, it usually does not belong in the case memo's evidence debt.
It may still belong in the archive's broader research ledger.
But it does not earn bytes in the case close.[S15][S23][S31]

## The five-part selection rule for the next scoreboard

### 1. Start from the dominant breach, not from metric completeness

The first scoreboard line should track the main constitutional failure the package is supposed to reduce.
If the case is mainly failing on floor integrity, the first line should watch floor passage, resilient footholds, or claimant reality.
If it is mainly failing on dynastic closure, the first line should watch entrant footholds, timing, or transfer concentration.
If it is mainly failing on wealth-to-rule conversion, the first line should watch visibility, controller concentration, or rule-conversion channels.

### 2. Add the fastest washout line even when it overlaps

The next scoreboard should almost always include the fastest reabsorption channel even when it is closely related to the dominant breach.
A package can show progress on the main breach while still leaking badly through housing, debt, fees, opacity, or bailout asymmetry.
That is why the washout line earns its own place.[S07][S10][S17][S20][S23][S31][S32][S33][S36][S42]

### 3. Force one line about who the next gains are reaching

The archive should usually reserve one scoreboard line for **where the next durable gains are landing**.
That can be lower-half footholds, under-40 entry, excluded-group access, person-level title, or public/common counterweight.
Without that line, a package can look active while mainly deepening incumbent position.[S05][S12][S19][S20][S31][S34][S35][S36]

### 4. Add one integrity line when rails or neutralisation are live risks

If administrative delivery, registry visibility, legal defensibility, enforcement, fiscal scoring, or elite neutralisation are live risks, add one explicit integrity line.
This is often the difference between a governed package and a paper package.[S04][S15][S23][S31][S32][S33]

### 5. Add one reopen or ratchet line when the case is being read more softly

When the case is in **ratchet** or **reopen** posture—or is being spoken of as a provisional near-pass—the next scoreboard should include the exact surface that would justify either harder confidence or renewed correction.
Do not let softer language float without a named trigger.[S05][S06][S15][S23][S31][S32][S33]

## The four-part selection rule for evidence debt

### 1. Prefer verdict-moving missingness

Put first the missing fact that could still move the case from failing to softer, or from softer back to failing.
This is often top-tail opacity, hidden controller structure, missing group disaggregation, or missing person-level access.[S15][S23][S31]

### 2. Then package-moving missingness

Next list the missing fact that could make the current package call non-robust.
That is often the missing comparison between two rival washout channels, or missing evidence about where the next durable gains are actually landing.

### 3. Then rail-moving missingness

If the package assumes rails the case may not yet have, name the single missing fact most likely to change the begin-now / build-while-moving / gated reading.
That often means visibility, delivery capacity, valuation integrity, or recovery / clawback enforceability.[S04][S23][S31][S32][S33]

### 4. Put pass-moving missingness last and name it sharply

If the case is being discussed in softer terms, end with the one missing fact that still blocks comfort.
Do not bury it in a long list.
Name it cleanly.
That is the archive's anti-premature-pass discipline.

## Default shapes by watch posture

### A. Build

For **build** posture, the next scoreboard should usually watch:
- delivery / take-up on the opening package,
- the dominant breach surface,
- the fastest washout surface,
- and the first lower-half or entrant incidence surface.

Evidence debt should usually focus on the main rail gap and the most important unresolved top-tail or excluded-group visibility gap.

### B. Reroute

For **reroute** posture, the next scoreboard should usually watch:
- the live miss that triggered concern,
- the washout channel,
- one skew or claimant-burden line,
- and one rail-strain or neutralisation line.

Evidence debt should focus on the missing fact that could distinguish package failure from rail failure.

### C. Ratchet

For **ratchet** posture, the next scoreboard should usually watch:
- retention and non-forfeiture,
- person-level claim or portability,
- washout closure,
- and one anti-capture or durability line.

Evidence debt should focus on the missing fact that still blocks confidence that the gain has become harder to reverse rather than merely easier to narrate.[S05][S06][S31][S32][S33]

### D. Reopen

For **reopen** posture, the next scoreboard should usually watch:
- the exact trigger surface named in the softer reading,
- the dominant breach surface,
- the main opacity or control line if that is unresolved,
- and one durability line.

Evidence debt should focus on the single missing proof that still makes the softer reading feel kinder than the archive has actually earned.

## The main false moves this note is meant to stop

### 1. Ending with the whole dashboard again

A case memo should not close by pasting the full measurement stack into a watch list.
That defeats the point of choosing a dominant breach, fastest washout, and watch posture.

### 2. Treating evidence debt as a research wishlist

Evidence debt should be the missing proof that still matters for the next judgment, not everything that would be interesting to know.

### 3. Watching only delivery and forgetting incidence

A package can be administratively active while the next durable gains are still landing mainly with incumbents, controllers, or protected places.
A serious next scoreboard should usually track who is actually receiving the gains.

### 4. Letting opacity disappear at the end of the memo

If top-tail structure, controller identity, excluded-group access, or person-level claim remain unclear, that missingness should still appear explicitly in the evidence debt rather than vanishing in the conclusion.[S15][S23][S31]

### 5. Naming a soft watch posture without a hard trigger

A case should not be placed in ratchet, reopen, or provisional near-pass language without one named surface that would either harden the softer reading or automatically reopen correction.

## Minimal reusable template

A thin case close can often stay inside these two blocks:

### Next scoreboard

- **dominant-breach line**
- **fastest-washout line**
- **incidence line**
- **integrity / capture line** (if live)
- **ratchet or reopen trigger line** (if live)

### Evidence debt

- **verdict-moving missingness**
- **package-moving missingness**
- **rail-moving missingness**
- **pass-moving missingness** (only if softer language is live)

If those lists become long, the memo usually has not yet compressed its diagnosis enough.

## Fast use rule

Use this note in five moves:

1. **Choose three to six next-scoreboard lines, not a general dashboard.**
2. **Start the scoreboard from dominant breach and fastest washout.**
3. **Force one line about where the next durable gains are landing.**
4. **Keep evidence debt to the missing proof that could still move the judgment.**
5. **When softer language is live, name the exact trigger that would harden or reopen the reading.**

## Bottom line

The archive now has a thinner rule for one of the places case memos most often regrow into sprawl:
how to end.
A good ending does not restate the whole archive.
It names the **smallest next scoreboard** that can still catch improvement, miss, ratchet, or relapse, and it names the **smallest evidence debt** that still blocks a cleaner judgment.
That is how a case memo stays thin without becoming vague.[S15][S23][S31][S32][S33]
