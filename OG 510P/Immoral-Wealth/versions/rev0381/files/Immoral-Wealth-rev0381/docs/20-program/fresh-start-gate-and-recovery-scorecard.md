# Fresh-start gate and recovery scorecard

## Gate 18 — fresh-start capacity, asset protection, and post-shock recovery

A case cannot pass when ordinary shocks create a legal, financial, or data afterlife that blocks recovery. Bankruptcy, exemptions, wage protection, bank-account protection, debt-collection courts, foreclosure/loss mitigation, eviction record sealing, reentry clearance, and collateral-consequence repair must be scored together.

Gate 18 asks: **After a serious but ordinary shock, can the person keep enough tools to rebuild and regain access to housing, work, accounts, credit, licenses, and claims?**

## Scorecard fields

| Field | Pass | Warning | Fail |
|---|---|---|---|
| bankruptcy access and discharge | affordable access; broad usable discharge | access/debt exclusions uncertain | relief unavailable, unaffordable, or too narrow |
| exemption floor adequacy | wages, account, car, tools, home equity, household goods protected at realistic values | uneven state/product coverage | exemptions too low or nonclaimable |
| wage garnishment protection | earnings floor preserves ordinary life and work | legal floor only | garnishment destabilizes rent, care, food, transport, or savings |
| bank-account levy protection | self-executing protected balance | claim required | account freeze drains subsistence or triggers cascading fees |
| judgment lien and property seizure | modest home equity and tools are secure | partial protection | one judgment can destroy recovery assets |
| debt-collection litigation due process | proof, notice, counsel/assistance, low default | court access uneven | mass default judgments create garnishment/levy pipeline |
| post-judgment interest and renewal | debt does not grow faster than recovery | state variation | judgment tail becomes permanent |
| foreclosure loss mitigation | meaningful pre-foreclosure review | servicer/fee risk | avoidable foreclosure or fee snowball |
| eviction/foreclosure record sealing | automatic, fast, vendor-enforced cleanup | petition-based or narrow | old/dismissed records block future housing |
| criminal record clearance | automatic and implemented with vendor compliance | petition/backlog | record keeps blocking work, housing, licenses |
| collateral consequence repair | individualized review and narrow exclusions | partial | old legal status blocks ordinary wealth routes |
| protected recovery floor | transport, tools, account, documents, communication, and liquidity protected | thin amounts | recovery requires sacrificing recovery tools |

## Certification effects

- Gate 18 blocks `near_ideal` and `acceptable` when shock recovery depends on expert-heavy procedures, unprotected wages/accounts, or durable records.
- Gate 18 hardens Gate 2 because a floor that can be seized is not a real floor.
- Gate 18 hardens Gate 3 because threshold moments after a shock require clean records, usable accounts, and protected tools.
- Gate 18 hardens Gate 5 because collection, fees, and judgments are reconcentration routes.
- Gate 18 hardens Gate 8 because liabilities become more damaging when recovery assets are unprotected.
- Gate 18 hardens Gate 17 because old debt, eviction, foreclosure, and criminal records travel through scores and screens.

## Opening package

Start with self-executing protected minima, high enough exemptions, wage and bank-account anti-seizure rules, proof requirements in collection suits, default-judgment repair, post-judgment interest limits, affordable bankruptcy access, loss-mitigation timing, automatic eviction/foreclosure/criminal-record sealing, vendor deletion, occupational-license review, and transaction-preserving reinstatement.
