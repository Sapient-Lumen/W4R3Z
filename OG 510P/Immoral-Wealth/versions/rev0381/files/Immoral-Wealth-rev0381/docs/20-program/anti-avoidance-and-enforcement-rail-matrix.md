# Anti-avoidance and enforcement-rail matrix

| Avoidance channel | Minimum rail | Warning sign | Package effect |
|---|---|---|---|
| Offshore financial accounts | CRS/AEOI participation, compliance framework, peer review | legal framework exists but practical effectiveness weak | add exchange-of-information rail before top-tail comfort |
| Shell/entity ownership | beneficial-owner registry, verification, penalties | domestic entities exempt or unverified | block owner-control pass |
| Trust/foundation layering | trust/legal-arrangement reporting and controller tests | settlor/protector/beneficiary data absent | apply opacity penalty |
| Private-business valuation | standard valuation rules, audit expertise, penalties for misstatement | case-by-case expert warfare | use conservative intervals and valuation courts |
| Partnership/private-fund complexity | information returns, specialized teams, entity audit rules | ordinary audit staff face complex structures | fund specialist enforcement |
| Residence/exit planning | exit tax, treaty coordination, anti-fragmentation | mobility threat defeats tax design | route to anti-blackmail rules |
| Charitable/philanthropic wrappers | payout, control, donor-benefit, and timing rules | deduction now, public benefit later or never | route to dynastic infrastructure screen |
| Procurement opacity | BO disclosure for bidders, conflict checks, open contracts | common owners or official relationships hidden | route to public-value leakage |

## Source order

1. Domestic law and administrative data.
2. Registry and beneficial-owner verification.
3. Cross-border exchange-of-information sources.[S178][S180][S181]
4. Peer reviews and implementation assessments.[S179][S180]
5. Independent audits, investigative journalism, civil-society data, and court records.
6. Rich-list/private-market triangulation where official visibility is weak.

The matrix does not require perfect enforcement before action. It requires that expected avoidance be named and that the package include the rail most likely to close it.
