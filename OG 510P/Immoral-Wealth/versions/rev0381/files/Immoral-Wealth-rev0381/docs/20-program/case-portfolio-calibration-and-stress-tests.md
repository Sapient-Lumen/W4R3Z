# Case portfolio calibration and stress tests

## Purpose

This note tells future operators how to use the rev0304 case portfolio without overfitting the archive to any single country. It is a guardrail against two errors:

1. **U.S.-overfitting:** treating family-gated entry plus private-risk exposure as the universal dominant breach.
2. **public-floor complacency:** treating strong public provision or public housing as automatic wealth-order certification.

Use this note with [`../../cases/case-portfolio-summary.md`](../../cases/case-portfolio-summary.md), [`scoreboard-calibration-matrix.md`](scoreboard-calibration-matrix.md), and [`threshold-moment-registry.md`](threshold-moment-registry.md).

## Minimum portfolio slots

A usable archive portfolio should always contain at least one case in each slot:

| Slot | Current rev0304 case | Why the slot exists |
|---|---|---|
| rich asset-price democracy | United States | tests high private wealth, asset-price politics, parent-backed entry, and top-tail rule |
| social-democratic housing-constrained | Netherlands | tests public/social substitution and housing-tenure divides |
| public-housing / public-land asset state | Singapore | tests state-shaped broad ownership and assetization |
| middle-income land/legibility case | South Africa | tests group closure, land, informality, state capacity, and rails-first sequencing |
| resource-dividend public wealth | Alaska Permanent Fund | tests common-wealth claims, cash dividends, and floor insufficiency |
| climate-insurance stress surface | U.S. climate-insurance | tests self-eroding housing footholds and hazard-exposed assets |

## Stress tests each new case must run

### 1. Share-table humility

Do not stop at bottom/top shares. Ask whether the numbers hide pension accounting, public provision, household masking, entity opacity, non-citizen exclusion, climate risk, or local housing closure.

### 2. Threshold-moment test

Name the three moments at which ordinary people need an asset or claim to function: deposit, repair, care, title, relocation, legal defense, first business stake, first house, or first safe place. Score whether those moments are open, family-gated, gatekeeper-dependent, self-eroding, or missing.

### 3. Public-substitution test

Where the public floor is strong, ask what it actually substitutes for. It may reduce the need for medical savings or retirement wealth; it does not automatically create first deposits, title, place access, or business collateral.[S21][S22][S139]

### 4. Group/person veto test

Averages cannot certify when historically subordinated groups remain on later, thinner, less defensible asset paths. Use race, caste, Indigenous status, migrant status, gender, household form, and region as relevant to the case.[S57][S58][S67][S76]

### 5. Washout test

Ask what reabsorbs gains fastest: rent, debt, fees, asset prices, insurance, repairs, climate risk, monopoly markups, exchange-rate shocks, corruption, or state-service failure.

### 6. Rails test

Ask which instruments are unavailable until ownership, valuation, registry, beneficial-owner, procurement, administrative, or court capacity exists. In a rails-poor case, ambitious top-tail policy without rails is often rhetoric or selective enforcement.[S15][S23][S54]

## When to promote a pattern

A case-driven observation can be promoted only when it meets all of these tests:

1. observed in at least three materially different cases;
2. changes verdict, route, proof debt, or instrument sequencing;
3. not already covered by a narrower existing rule;
4. supported by at least one direct or high-quality proxy source;
5. does not create a new synonym for an existing false pass.
