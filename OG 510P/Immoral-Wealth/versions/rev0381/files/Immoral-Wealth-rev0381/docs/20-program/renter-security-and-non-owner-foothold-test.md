# Renter security and non-owner foothold test

## Purpose

The archive should not treat homeownership as the only morally legible foothold. A secure rental, cooperative, public, nonprofit, or social-housing claim can substitute for ownership when it gives durable use, savings room, safe exit, and rule-bound protection.

But non-ownership is a false pass when it means permanent exposure to rent spikes, landlord discretion, rationed waiting lists, poor quality, eviction risk, or inability to build any transferable buffer.

## Seven-part substitution test

A renter/non-owner system can substitute for private ownership only if it passes all seven tests:

1. **Tenure stability** — ordinary households can remain without arbitrary eviction or reprisal.
2. **Affordability** — rent and utilities leave savings room after ordinary expenses.
3. **Quality and repair** — habitability, crowding, accessibility, and maintenance are enforceable.
4. **Access breadth** — lower and middle households can enter without years-long rationing or insider status.
5. **Portability** — moving for work, care, separation, disability, or family size does not restart security from zero.
6. **Non-stigma and mix** — the system is not a residual poor-law track that concentrates disadvantage.
7. **Wealth-substitute capacity** — the household can still build liquid buffers, pension claims, cooperative stakes, or other transferable assets.

## Germany/Vienna calibration lesson

Germany is a useful stress case because it combines high rentership, tenant-protection institutions, wealth inequality, and renewed shortage pressure. Brookings describes Germany as a majority-renter housing system with strong federal tenant protections.[S117] Current German policy debate and evidence also show rising rents, construction shortfalls, social-housing limits, and particular pressure on low-income households and single parents.[S116][S118][S119]

Vienna supplies the sharper subsystem contrast: broad, mixed, long-term municipal/subsidized housing can convert non-ownership into a real anti-washout institution when access remains wide and rents are capped.[S95][S96][S116]

## Verdict implications

- A country with low homeownership is not automatically worse than a country with high homeownership.
- A country with high homeownership is not automatically better if entry is family-gated or climate/insurance-exposed.
- Secure renting can support `acceptable_but_vulnerable` when it preserves savings room and safe exit.
- Secure renting cannot support `acceptable` if social housing is residual, rationed, under-maintained, or too narrow to discipline the private rental market.

## Evidence order

1. owner/renter shares by age, income, wealth, migrant status, disability, household type, and region;
2. rent-to-income and residual-income-after-rent measures;
3. waiting lists, eligibility rules, portability, and actual take-up of public/social housing;
4. eviction, rent-increase, maintenance, and repair enforcement data;
5. whether renters can accumulate non-housing wealth;
6. whether secure rental status survives family change, care/disability interruption, unemployment, and relocation.

The OECD Affordable Housing Database should be used as a cross-country first pass, but case memos must add local institutional evidence.[S196]
