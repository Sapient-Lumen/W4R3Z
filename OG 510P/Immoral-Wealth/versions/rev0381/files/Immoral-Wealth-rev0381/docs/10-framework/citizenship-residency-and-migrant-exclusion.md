# Citizenship, residency, and migrant exclusion

Public and social wealth can be morally powerful. But it can also create a false pass when access depends on citizenship, residency duration, employment category, household sponsorship, or discretionary administrative status.

## The false pass

A country may have:

- large public wealth;
- generous housing or pensions for qualifying citizens;
- strong official household wealth statistics;
- low visible poverty among permanent residents.

It still fails or remains vulnerable if migrants, temporary workers, refugees, informal residents, domestic workers, or non-citizen family members are structurally excluded from the wealth floor.

## Certification question

Ask not only “does public wealth exist?” but:

1. who has a claim;
2. what status proves the claim;
3. whether the claim is portable;
4. whether it survives job loss, divorce, age, disability, care work, or migration;
5. whether household members have person-level control;
6. whether noncitizens build wealth or merely service citizen wealth.

## Case use

The Singapore, Norway, Vienna, and future Gulf/rentier cases need this screen. A sovereign fund or social housing system can be a counterweight, but only if the archive records the claimant boundary and names exclusions.[S77][S78][S86][S93][S95][S96]

## Rule

A public counterweight can improve the verdict only to the extent that it creates rule-bound claimant security for the people whose labor and residence sustain the economy.
