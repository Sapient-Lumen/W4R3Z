# Worker ownership, profit sharing, and governance claims

Worker ownership can turn enterprise growth into broad wealth formation. It can also become a rhetorical pass if the claim is narrow, illiquid, over-concentrated, non-voting, backloaded, or exposed to firm-specific collapse.[S235][S236]

## Four-part test

A worker-ownership claim counts only to the extent that it is:

1. **Broad** — ordinary workers participate, not only executives or scarce skilled employees.
2. **Real** — the claim has measurable value, vesting, and enforceable fiduciary protection.
3. **Convertible** — workers can eventually use the value for housing, retirement, business formation, care, or exit without punitive leakage.
4. **Protected** — the claim is not the worker's only retirement asset and is not destroyed by concentrated employer risk.

## Governance question

Ownership without voice can still build wealth, but it does not fully answer workplace rule. Score separately:

- profit-sharing/equity breadth;
- worker governance rights;
- information rights;
- diversification rights;
- distribution timing;
- fiduciary enforcement;
- treatment of low-wage, part-time, immigrant, temporary, and contract workers.[S235][S236]

## Certification consequence

Broad-based equity can substitute for some missing private asset formation only when it passes the breadth/real/convertible/protected test. It cannot substitute for wage floors, remedy access, or bargaining rights when ordinary workers still carry the downside without enough control over enterprise decisions.
