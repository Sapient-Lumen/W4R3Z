# Research notes — rev0044

This turn did not add external protocol claims.  The working intuition remains local and conservative: helpful supernode/garden services become capture surfaces when their operator keys, router identity, service signer, public announcements, control intent, and receipt memory are allowed to blur together.

The useful direction is still not “remove powerful nodes.”  It is to make every powerful node boundary explicit, scoped, signed, replay-aware, and auditable after restart.
