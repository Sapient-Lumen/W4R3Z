# Risk register rev0049

Known risks deliberately left open:

- dry-run attempts are not real publication semantics;
- family/path labels are local hints, not independence proof;
- witness compaction is toy memory policy, not a database or consensus layer;
- scope journals are signed local objects, not a crash-safe storage engine;
- component reports can still be overfit to toy tests.

The point of rev0049 is to make these risks executable before a live I2P/SAM transport hides them behind latency and churn.
