# Python first, native leaf boundary

Python first does not mean Python forever.  It means Python owns the control plane while the control plane is still being discovered.

Keep in Python:

- Mutable-head acceptance and fork/rollback pressure.
- Witness, garden, redress, moderation, policy, and subjective authority lanes.
- SAM/router lifecycle assumptions.
- Persistence, replay, cleanup, and exact-boundary joining.
- Public-edge semantics.

Candidate native leaves:

- XOR distance compare/sort kernels.
- Region/range sketch primitives.
- Set-reconciliation adapters.
- Vetted cryptographic library bindings.

The dangerous temptation is to move a whole subsystem into C because it feels more serious.  That would make wake-from-amnesia harder, not easier.  A native kernel may accelerate a known pure function; it may not decide DHT truth.
