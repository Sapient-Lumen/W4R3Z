# Summary export fence

`summaryexportfence.py` prepares a no-network redacted-summary export fence after ACK closure.

Export fence is not publication and not live send. It is a local side-effect boundary before a future operator, garden, or public-summary export path.

The fence binds:

```text
ACK closure
summary replay
delivery archive
summary prune fence
redacted summary digest
contradiction memory
redaction memory
export channel
```

Raw boundary or raw payload exposure quarantines. Mixed export channels quarantine. Low family/path diversity holds.
