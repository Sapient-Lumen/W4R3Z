# Witness compact hard evidence

`witnesscompact.py` compacts local audit/witness memory without turning compaction into amnesia.

Soft observations may expire or be capped by family/byte budget.  Hard pressure should remain:

- payload mismatch;
- stale public record evidence;
- explicit audit refutation;
- same-sequence fork evidence;
- redress gap evidence.

The important distinction is not "keep everything" versus "forget everything."  The rule is: forget convenience first; preserve evidence that prevents stale public exposure or false health from resurrecting.
