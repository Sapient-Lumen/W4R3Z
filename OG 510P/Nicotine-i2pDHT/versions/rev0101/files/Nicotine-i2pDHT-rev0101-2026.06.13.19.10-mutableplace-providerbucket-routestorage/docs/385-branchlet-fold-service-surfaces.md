# Folded service branchlet surfaces

rev0038 preserves useful alternate rev0037 branchlets instead of deleting them:

| Surface | Local question |
|---|---|
| `catalogwire.py` | Is this catalog advertisement/withdrawal frame canonical, fresh, role-bound, and report-bound? |
| `serviceprobe.py` | Can service health be probed without unbounded raw-key or metadata leakage? |
| `servicewithdrawal.py` | Has a catalog or service been locally withdrawn, suspended, or pointed to a successor? |
| `servicerelay.py` | Do relay observations give diverse local evidence without becoming reputation? |
| `serviceusegate.py` | Does one service-use intent bind to the exact reports that permitted it? |
| `handofflane.py` | Can accepted load/capability/egress become concrete work without scope drift? |
| `receiptveil.py` | Can contribution receipts be locally useful without raw labels or global scoring? |

These surfaces are intentionally small. They are pressure tests for future garden-service mechanics, not protocol finality.
