# Publication guard final side effect

A publication capsule is a local no-network record for a future public bridge side effect. It binds bridge-ledger report, policy-portfolio report, egress report, public payload digest, exposure class, TTL, sequence, previous digest, family, and path family.

The guard rejects raw/public hints unless explicitly allowed, catches replay, sequence forks, previous-link mismatch, action drift, digest drift, bad signatures, and low diversity. This keeps final publication separate from earlier local acceptance.
