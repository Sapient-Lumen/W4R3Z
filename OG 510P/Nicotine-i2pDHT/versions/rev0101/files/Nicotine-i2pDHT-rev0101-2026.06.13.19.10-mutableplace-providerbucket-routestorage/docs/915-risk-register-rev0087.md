# Risk register rev0087

Risks attacked:

- selected native artifact becomes loadable by accident;
- native crash becomes a transient log rather than sticky fallback pressure;
- speed measurements become authority over selection;
- raw profiling labels leak request/scope/payload fragments;
- native lifecycle state forks or replays after restart.

Remaining risks: no production native loader, no sanitizer runtime, no native parser/crypto, no live I2P/SAM transport, no production DHT.
