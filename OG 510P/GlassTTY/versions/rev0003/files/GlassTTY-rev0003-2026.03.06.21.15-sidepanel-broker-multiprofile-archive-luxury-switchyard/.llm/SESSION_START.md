# Session start

Before making changes:

1. Read `README.md`.
2. Read `STATUS.md`.
3. Read `MEMORY.md`.
4. Read `DECISIONS.md`.
5. Read `PROJECT_MAP.md`.
6. Skim any adapter README relevant to the active task.
7. Identify the single most important unproven path for this session.

Then write down, in your own scratchpad, these five things:
- what already works
- what is unverified
- what the user actually cares about next
- which files are most likely to change
- which claims need fresh web verification
