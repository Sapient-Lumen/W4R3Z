# Session end

Before packaging a new archive revision:

1. Update `STATUS.md`.
2. Update `MEMORY.md`.
3. Append to `CHANGELOG.md`.
4. Add or update any architecture note in `DECISIONS.md` if the design changed.
5. Make sure the latest archive filename matches the actual revision and summary.
6. State clearly what was actually tested versus merely scaffolded.
7. Leave 1–3 sharp next tasks in `TASK_QUEUE.md`.
