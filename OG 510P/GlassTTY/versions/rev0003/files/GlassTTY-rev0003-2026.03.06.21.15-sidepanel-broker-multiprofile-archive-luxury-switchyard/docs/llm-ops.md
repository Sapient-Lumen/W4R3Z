# LLM ops

## Purpose

This repo is meant to be comfortable for future LLM sessions.

## Minimum read set

1. `README.md`
2. `STATUS.md`
3. `MEMORY.md`
4. `DECISIONS.md`
5. `TASKS.md`
6. relevant adapter docs

## Session output discipline

A useful session should usually leave behind all of these:
- code or docs changed in the repo
- `CHANGELOG.md` updated
- `STATUS.md` updated
- `TASKS.md` updated
- any new brittle assumptions documented

## Good repo behaviors

- prefer concrete files over chat-only conclusions
- include command examples that a later session can run directly
- keep generated caches out of the archive
- make release zips reproducible from scripts where practical
