# Handoff — rev0126

rev0126 repairs a quiet but important integrity problem in GlassTTY's frozen truth surfaces: several `validation/latest/*` bundles could look recent while still pointing at older archive roots.

This revision adds three operator-facing controls around that problem:

- `check-opening-contract` declares and verifies the minimum cold-open path instead of leaving startup order as folklore.
- `truth-surface-register` separates the latest operational head from the latest current-root head and the latest citation-ready head.
- `refresh-truth-surfaces` rebuilds the opening, readiness, control-plane, install, support, and handoff surfaces for the current archive in one pass.

The intended behavior change is simple: before trusting a frozen surface, check whether it is current-root and citation-ready, not merely the newest file in `validation/latest/`.
