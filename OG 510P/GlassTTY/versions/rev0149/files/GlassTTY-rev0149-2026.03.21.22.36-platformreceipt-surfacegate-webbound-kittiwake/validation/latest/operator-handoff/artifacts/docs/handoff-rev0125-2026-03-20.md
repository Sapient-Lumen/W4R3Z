# Handoff — rev0125

rev0125 adds two substrate tools that make GlassTTY easier to operate honestly:

- `install-receipt` turns extension/native-host bootstrap into one typed receipt instead of a scattered inference problem.
- `support-surface-snapshot` turns support-record prose into one frozen machine-readable support surface plus a contract check.

The most important intended behavior change is simple: before arguing about runtime bugs, freeze bootstrap truth; before changing support claims, freeze support truth.
