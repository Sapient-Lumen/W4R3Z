usage: mv3-worker-resume.py [-h] --output OUTPUT [--timeout TIMEOUT]
                            [--write-text WRITE_TEXT]
                            [--extension-id EXTENSION_ID] [--include-doctor]
                            [--cdp-endpoint CDP_ENDPOINT] [--profile PROFILE]
                            [--profile-dir PROFILE_DIR]
                            [--profile-host PROFILE_HOST] [--trace]

Launch GlassTTY in a disposable Chromium profile, terminate the MV3 service
worker, and capture a before/after resume proof bundle.

options:
  -h, --help            show this help message and exit
  --output OUTPUT
  --timeout TIMEOUT
  --write-text WRITE_TEXT
  --extension-id EXTENSION_ID
                        Extension id to use. Defaults to computing it from
                        extension/manifest.json instead of running doctor.
  --include-doctor      Also capture scripts/doctor.py output before launch.
  --cdp-endpoint CDP_ENDPOINT
                        Attach to an already-running Chromium instance over
                        CDP instead of launching a fresh temporary browser
                        context.
  --profile PROFILE     Attach through a GlassTTY-managed profile name by
                        reading its launch metadata and DevToolsActivePort
                        file.
  --profile-dir PROFILE_DIR
                        Attach through a specific Chromium profile directory
                        instead of resolving a managed profile name.
  --profile-host PROFILE_HOST
                        Host to use when constructing a CDP endpoint from
                        profile metadata (default: 127.0.0.1).
  --trace               Capture a Playwright trace in the temp workspace.
