# Handoff rev0139 — composer witness receipt, writability gate, and honest readback

## What changed

- added `CHATGPT-COMPOSER-WITNESS-RECEIPT.json` with a machine-readable quality rubric for composer witnesses so ChatGPT textbox discovery no longer overclaims writability
- added `scripts/chatgpt-composer-witness-receipt.py` plus `scripts/chatgpt_composer_witness_receipt.py` and focused tests for `ready`, `blocked`, and `hold-for-recapture` outcomes
- integrated the new receipt into `refresh-truth-surfaces`, the ChatGPT first-proof kit, the ChatGPT candidate bundle, and living support docs
- extended the support-source lock with current Playwright input and assertion references so write/readback guidance rests on named external anchors

## Why this revision exists

rev0138 closed the route-quality gap, but it still left one honest failure mode: a run could discover something textbox-like and still over-trust it as a usable composer even when writability or post-write readback had not been preserved.

rev0139 closes that gap by separating **found a candidate** from **proved a writable prompt lane**.

## New behavior

- composer witnesses can now be graded as `strong`, `usable`, `fragile`, or `insufficient`
- composer continuation can now land on `ready`, `ready-with-caution`, `hold-for-recapture`, `blocked`, `blocked-by-route`, `insufficient`, or `stop`
- missing post-write readback now hard-caps the quality result so a lucky candidate cannot skip straight to “usable”
- route readiness remains a prerequisite, so composer evidence cannot independently rescue a weak or misrouted shell

## Remaining limits

- there is still no live official-surface ChatGPT compose/submit/readback bundle in this archive
- the composer receipt is only as good as the captured main-region scope, actionability, and post-write readback evidence it is given

## Recommended next move

Capture one real ChatGPT route witness, require the route witness receipt to say `ready` or `ready-with-caution`, capture one concrete composer witness on that same pass, require the composer witness receipt to say `ready` or `ready-with-caution`, and only then spend proof budget on submit/read-latest artifacts.
