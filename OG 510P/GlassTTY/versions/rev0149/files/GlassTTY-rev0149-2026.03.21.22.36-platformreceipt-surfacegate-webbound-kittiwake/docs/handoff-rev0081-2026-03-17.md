## Why this matters

Current Playwright does not discover browser installs by scanning the cache directory alone. It traverses `.links` references for the current package and uses that package's `browsers.json` to decide which install directories should exist. That means GlassTTY must register imported installs in the format upstream expects, or `install --list` will misleadingly report an empty cache.
