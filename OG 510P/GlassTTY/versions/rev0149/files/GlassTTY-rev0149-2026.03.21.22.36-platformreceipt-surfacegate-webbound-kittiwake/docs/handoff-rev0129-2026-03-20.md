# Handoff rev0129 — published support surface and bundle transition

## What changed

- added a **published support surface** separate from the broader support-bundle queue
- added explicit **support-bundle transition** tooling so `published` is an action, not just a directory name
- rooted the citable snapshot in `SUPPORT-PUBLIC-SURFACE.json`
- extended control-plane, doctor, refresh-truth-surfaces, and operator-handoff so published support posture travels with other truth surfaces

## Why it was worth doing

The support queue from rev0128 was useful, but it still mixed “named evidence exists” with “safe to cite now.” The strongest pattern left from EvidenceVault was to keep queue state and public/citable surface distinct.

- GlassTTY still has **zero published support bundles**
- Claude still has a held bundle, not a citable published one
- the new published-support surface exists mainly to prevent future overclaiming once more bundles appear
