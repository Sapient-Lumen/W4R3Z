# Support records

This directory holds the living support truth for official surfaces.

## Rule

Each file here should describe support at the level of:
- one surface
- one or more browser lanes
- shared workflow rows
- current tier per workflow
- evidence refs or evidence posture
- caveats, blockers, and next promotion requirements

## Current posture

The records in rev0122 are seeded records. They are intentionally conservative. They exist to make the support model concrete and to give future implementers a place to record truth without overclaiming.
