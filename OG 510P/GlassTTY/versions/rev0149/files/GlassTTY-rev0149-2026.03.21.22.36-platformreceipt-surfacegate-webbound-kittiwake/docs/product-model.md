# Product model

GlassTTY is a local-first shell and control plane for browser-native AI systems.

## The product is not just

- an extension
- a Claude helper
- a test harness
- a browser bot

## The product is

- a bridge between terminal tools and visible browser AI surfaces
- a structured state API over browser-native AI interactions
- a support and evidence system for those interactions
- a drift-detection and adaptation workbench
- an execution layer for human operators and local/private LLMs

## Core product promise

A user should be able to keep using the official browser UI while GlassTTY provides:
- local programmability
- inspectable actions
- structured reads
- durable evidence
- support truth about what currently works
