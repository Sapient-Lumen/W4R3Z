## Why it mattered

rev0081-rev0083 made GlassTTY-imported browsers visible to upstream `python -m playwright install --list`, but that was not enough. Local validation in this container showed that a later raw `python -m playwright install chromium` still deleted an imported `chromium-1208` because the directory lacked `INSTALLATION_COMPLETE`. After rev0084 restored the marker, the imported browser survived the later raw install attempt and remained visible to `install --list`.

This means future sessions should treat marker repair as part of Playwright ownership truth, not as optional polish.
