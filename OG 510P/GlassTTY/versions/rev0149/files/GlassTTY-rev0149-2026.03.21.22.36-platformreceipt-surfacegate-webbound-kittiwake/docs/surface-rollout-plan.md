# Surface rollout plan

## Official surfaces

1. Claude
2. ChatGPT
3. Google AI Studio
4. Grok
5. Kimi
6. Z.ai

## Recommended rollout order

### Phase 1
- Claude as reference adapter
- ChatGPT as second concrete adapter

Reason:
- best chance to prove generic core quickly

### Phase 2
- Google AI Studio

Reason:
- likely to stress route, tool, and generation-state differences without being completely alien

### Phase 3
- Grok, Kimi, Z.ai

Reason:
- broaden coverage after shared workflows and state families are stable enough

## Rollout rule

A surface should not be marked “ahead” just because it was named in the docs. It moves through the support tiers only when workflows and evidence justify that move.
