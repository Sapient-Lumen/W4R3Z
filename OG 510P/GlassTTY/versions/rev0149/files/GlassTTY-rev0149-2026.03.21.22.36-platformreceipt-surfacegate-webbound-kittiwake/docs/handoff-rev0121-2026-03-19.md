## What changed

This revision is a full-repo docs-and-planning overhaul built on top of rev0119.

The important correction from earlier draft bundles is that rev0121 is a **full repo revision**, not a tiny docs-only overlay zip.

## Main direction changes now recorded in the canon

- GlassTTY is framed as a local-first control plane for browser-native AI systems.
- Claude, ChatGPT, Google AI Studio, Grok, Kimi, and Z.ai are now official first-class browser surfaces.
- Structured browser state is promoted to a first-class product surface.
- Drift detection, evidence ledgers, support truth, and release gates are now part of the core architecture.
- Human-piloted visible operation remains the default, but agent-capable operation is now an official design target.
- Canonical docs now carry strategy; handoff docs are historical memory rather than the only place where big direction changes live.
