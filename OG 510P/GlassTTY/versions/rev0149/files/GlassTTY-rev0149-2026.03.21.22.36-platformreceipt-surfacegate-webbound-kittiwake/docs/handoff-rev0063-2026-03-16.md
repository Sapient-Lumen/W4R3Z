## Why it matters

rev0062 could run a dynamic coverage experiment, but it still left two expensive gaps. First, future operators had to judge before/after probe evidence by hand even though GlassTTY already had a saved experiment plan. Second, the package helper could silently emit a zip without `extension/dist`, which meant a “release” archive could fail the repo's own unpacked-extension workflow. rev0063 closes both gaps: it turns saved experiment plans into an explicit comparison tool and it makes package integrity verifiable instead of assumed.

## Recommended next move

On a real supported tab, save `before-probe.json` from `glassttyd probe --wait`, run one focused experiment, reload the tab, save `after-probe.json`, then run:

```bash
python -m glassttyd.cli compare-coverage-experiments before-probe.json after-probe.json --pretty
```

Keep that report beside the raw probe artifacts and the trace slice from the same run. That should become the default evidence packet before any future manifest-policy widening.
