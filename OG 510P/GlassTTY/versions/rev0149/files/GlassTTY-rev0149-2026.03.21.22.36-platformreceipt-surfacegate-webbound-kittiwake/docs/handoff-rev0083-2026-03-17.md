### Why this was worth doing

Upstream Playwright still treats `install --list` plus stale-browser removal as the truth about browser ownership. That means a manual/offline browser directory that merely exists on disk is not enough; it has to live under a package-owned install name and behind a valid `.links` registry reference. rev0082 could explain that. rev0083 can now repair it when the metadata is strong enough.
