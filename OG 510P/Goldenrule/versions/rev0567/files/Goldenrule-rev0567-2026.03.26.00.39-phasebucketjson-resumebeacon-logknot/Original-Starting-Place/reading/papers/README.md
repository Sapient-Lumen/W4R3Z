# Reading Pack Blob Policy

This directory intentionally does **not** store PDF blobs in the compact long-term archive.

Why:
- the archive should cite rather than hoard bulky source files,
- URLs and bibliographic metadata already live in `../links.yaml` and `../bibliography.bib`,
- temporary reacquisition is cheaper than permanent archive bloat for background reading.

If a future session needs a paper locally for short-term work, keep it temporarily and remove it again before producing the next long-term bundle.
