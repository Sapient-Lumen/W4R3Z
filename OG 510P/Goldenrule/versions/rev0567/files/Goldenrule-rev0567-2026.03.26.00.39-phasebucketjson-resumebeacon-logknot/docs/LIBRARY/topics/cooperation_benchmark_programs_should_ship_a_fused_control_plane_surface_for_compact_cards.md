# Cooperation benchmark programs should ship a fused control-plane surface for compact cards

Once the archive already has compact-card inventory, lineage heads, an actionable review queue, a fail-closed citation surface, and a minimal handoff pack, future inheritors should not have to reassemble those five surfaces mentally just to answer the ordinary question “what is current, citable, repairable, and ready right now?”

A tiny generated control-plane surface should therefore:

1. fuse the current verdict, lineage counts, review pressure, citation readiness, and handoff readiness into one typed object;
2. bind that summary to the exact underlying report files with hashes, so it is a stable reentry surface rather than a loose prose dashboard;
3. list per-lineage operational head, citation head, review-item kinds, and unresolved reason codes so the next action is visible without helper chaining;
4. point to a small preferred set of entrypoint commands instead of making inheritors rediscover the report builders by memory.

This keeps the compact-card stack operationally legible for inheritors and private tooling without widening the cards, receipts, or handoff basis themselves.
