# Rematch benchmark programs should publish risk review cadence as a governance surface

Benchmark governance is not exhausted by artifact validity.
If a program carries known interpretation, misuse, or deployment risks, later inheritors need to know whether those risks were reviewed recently, deferred intentionally, or simply left to drift.

The compact rule is to publish risk-review cadence and current unresolved risk posture as governance metadata rather than leave that state implicit in scattered meeting residue.
