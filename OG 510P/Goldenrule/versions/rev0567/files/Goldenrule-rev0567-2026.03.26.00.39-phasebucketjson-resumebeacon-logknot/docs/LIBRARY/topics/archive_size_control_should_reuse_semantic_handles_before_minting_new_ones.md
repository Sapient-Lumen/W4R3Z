# Archive size control should reuse semantic handles before minting new ones

When archive-shaping work flags a large report family as lacking a durable handle, the next move should not automatically be “write another topic note.” Literal family-name search can miss handles that already exist under a more interpretable claim name.

## Rule

Before minting any new durable note for a hotspot family:

1. check whether an existing library topic already states the same claim in inheritor-facing language,
2. record that bridge in one compact semantic-handle receipt,
3. and only mint a new topic when both literal search and semantic-handle reuse still leave a true gap.
