# Rematch worlds should treat exact-uncertainty weakening as a chain with holes in two-bundle space

## Claim

The current exact-uncertainty weakening menu is not an independent chooser over middle-band precision relief and relaxed-suffix release. It is a monotone chain through that 2D basis, so many apparently natural primitive-demand pairs are impossible to buy exactly and instead require hitchhiking overshoot.

## Why it matters

- The six budget levels occupy only six exact coordinates in the natural `3x5` primitive box: `(0,0)`, `(0,1)`, `(1,1)`, `(1,2)`, `(1,3)`, `(2,4)`.
- That leaves nine audited holes. Any request for one of those coordinates is really a request for the least dominating reachable chain point.
- This makes scalar weakening policy visibly less expressive than a true two-axis controller.

## Immediate operator guidance

- Ask first whether the desired primitive bundle lies on the current chain. If yes, select its matching budget directly.
- If the desired bundle lies in a hole, record the forced overshoot explicitly instead of pretending the scalar threshold matched the request cleanly.
- Deep suffix-only demands beyond one unit and second-precision demands below the final suffix level are the two main impossible families in the current menu.
- Future redesigns that fill any current hole should be treated as meaningful expressiveness changes, not cosmetic threshold retuning.
