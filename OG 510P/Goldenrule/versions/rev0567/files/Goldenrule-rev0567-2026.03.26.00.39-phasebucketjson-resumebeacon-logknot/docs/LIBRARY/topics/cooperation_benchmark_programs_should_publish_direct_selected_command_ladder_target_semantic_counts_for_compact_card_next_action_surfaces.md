# Cooperation benchmark programs should publish direct selected command ladder target semantic counts for compact-card next-action surfaces

When compact-card next-action surfaces publish a selected command ladder, each step should carry the target report's typed semantic counts alongside bytes, sha256, and prose scale summary.

1. publish role-appropriate direct target semantic counts on every `selected_command_ladder[]` step;
2. mirror the same step objects onto `primary_action.command_ladder`; and
3. prefer direct counts over prose-only interpretation so inheritors can compare fallback steps mechanically.

This keeps step-by-step reentry locally auditable without reopening retained report JSON or parsing English summaries.
