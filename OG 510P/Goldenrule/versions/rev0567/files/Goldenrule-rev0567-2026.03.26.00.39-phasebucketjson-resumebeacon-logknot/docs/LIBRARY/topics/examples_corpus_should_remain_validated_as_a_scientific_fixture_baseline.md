# Example corpus should remain validated as a scientific fixture baseline

The archive should treat the standing `examples/` corpus as a compact scientific fixture baseline, not as a bulky recurring report family.
A few canonical fixtures already show the point:

- `examples/gauntlet/gauntlet_v1.json`
- `examples/probes/registry_smoke.json`
- `examples/worlds/ipd_core.json`

If those anchors and their neighboring example specs stop validating, the inheritor loses a cheap baseline for whether the archive still carries runnable worlds, probes, and orchestration surfaces.

## Implementor consequence

Keep example-corpus validation on the standing gate path and cite the validated fixture baseline rather than retaining repeated wide example-inventory reports.

## Archive consequence

One tiny topic is enough.
Future sessions can cite the validated example baseline directly instead of carrying another report family whose only job is to restate that the canonical fixtures still exist and parse.
