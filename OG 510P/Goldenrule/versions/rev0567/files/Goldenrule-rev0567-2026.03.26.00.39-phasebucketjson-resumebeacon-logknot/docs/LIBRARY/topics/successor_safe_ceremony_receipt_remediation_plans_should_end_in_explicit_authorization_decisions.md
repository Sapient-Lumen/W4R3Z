# Successor-safe ceremony receipt remediation plans should end in explicit authorization decisions

Once the archive already has a successor-safe ceremony receipt, a content-addressed locator, an assessment, a disposition, and a remediation plan, one final compact custody gap still remains: the archive can describe the evidence and the repairs without yet saying **whether the current package is actually authorized for claim-ready citation**.

This archive should therefore keep one tiny authorization companion beside each current receipt package. The authorization should not restate protocol prose. It should point at the receipt locator, preserve the current assessment/disposition/remediation state, emit the small set of basis checks that decide claim-ready citation, and record the terms and conditions that govern future copy-forward use.

The practical standard is simple: if a future steward cannot tell from one small machine-checkable object whether a receipt is authorized for claim-ready citation right now and under what conditions that authorization remains valid, the archive still leaves the final admission decision implicit.
