# Assurance release timing and monitoring windows are world contracts, not aftercare fine print

Recent work adds another missing layer to Concord's long-horizon stewardship worlds: **it matters whether operators are released immediately at nominal closure, only after years of verified post-closure monitoring, under conditional closure with institutional controls, or effectively never fully released because residual risk remains live**.

- `RS-GR-297` shows that jurisdictions differ sharply: some release companies once closure criteria are met, others require 5 to 10 years of post-closure monitoring, while many hazards can persist far longer.
- `RS-GR-298` shows that post-remediation governance is not a yes/no switch: insufficient oversight and excessive oversight can coexist, and some sites may need institutional controls while others need long-term monitoring plus controls.
- `RS-GR-299` shows that long-term stewardship can include periodic review, land-use controls, property-transfer controls, and enforceable five-year protectiveness reviews whenever contamination remains.
- `RS-GR-304` shows that financial assurance design can fail if release occurs before environmental-purpose performance benchmarks are actually met, turning “closure” into premature liability discharge rather than verified repair.
- Together, these sources warn that a benchmark can look more successor-protective because it delayed release, imposed monitoring windows, or required periodic protectiveness review — not because the underlying Golden-Rule disposition improved.

## Why this matters for Concord

A future-facing benchmark should not report that an institution “cares more about successors” when the world mainly changed its **release-gate and verification-window architecture**.

There is a real institutional difference between:
1. a world with immediate liability release at nominal closure;
2. a world with conditional closure plus land-use or institutional controls;
3. a world with fixed-term post-closure monitoring before release;
4. a world with recurring protectiveness review whenever hazards remain;
5. a world that looks prudent only because release was delayed long enough for verification to catch failure.

Those are not aftercare footnotes.
They change whether successors inherit verified stability, a live monitoring obligation, or a cosmetically closed site with unresolved residual risk.

## Minimal implementor handoff

If Concord adds stewardship, remediation, or decommissioning lanes, publish at least:

1. what exact event triggers provisional closure, conditional closure, and final release;
2. whether post-closure monitoring is absent, fixed-term, trigger-extended, or effectively perpetual;
3. whether land-use controls, property-transfer controls, or other institutional controls remain after nominal closure;
4. who performs periodic protectiveness review and what happens if the review fails;
5. whether headline results survive one same-behavior comparison where only release timing or monitoring-window semantics change.

Without that compact contract, future inheritors can mistake delayed bond release, periodic review, or conditional closure machinery for the same thing as deeper reciprocity toward successors.
