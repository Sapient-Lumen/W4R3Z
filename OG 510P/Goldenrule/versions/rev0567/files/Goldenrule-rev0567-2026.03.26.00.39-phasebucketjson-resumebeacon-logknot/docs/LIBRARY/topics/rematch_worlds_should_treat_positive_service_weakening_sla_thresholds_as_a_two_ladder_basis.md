# Rematch worlds should treat positive-service weakening SLA thresholds as a two-ladder basis

The recent weakening SLA passes already established three useful facts:

- width-conditioned service is a choose-ratio law,
- positive-service schedules form one audited staircase,
- and there is only one shared diagonal event at `1/91`.

The remaining nuisance for an inheritor was still this:

> where do the actual staircase thresholds come from, and how small is the generating basis?

The new provenance law answers that directly.

Every positive-service weakening SLA threshold comes from one of only two descending ladders:

- exact-only ladder: `C(6,w)/C(15,w)` for `w = 1..6`
- suffix-only ladder: `C(11,w)/C(15,w)` for `w = 1..11`

So there are only `17` source threshold events in total.
But those `17` events collapse to only **16 unique positive thresholds**, because there is exactly one collision:

- `1/91 = C(6,4)/C(15,4) = C(11,9)/C(15,9)`

That lone collision is precisely the earlier shared diagonal step.

This gives a much tighter mental model than the raw SLA band table. The whole positive-service staircase can now be reconstructed by:

1. starting at signature `E0_S0`
2. scanning the descending provenance word
3. adding one exact unit for `E`, one suffix unit for `S`, and one of each for the lone `D`

The provenance word is:

`SSESSSESSESDSESE`

and it matches the staircase path word exactly.

So the positive-service weakening SLA geometry is not just a staircase. It is a staircase generated by a **two-ladder threshold basis with one shared rung**.

Future redesign signal: any second collision, any missing ladder source, or any future disagreement between the threshold provenance word and the staircase path word means the service geometry has substantively changed.
