# Cooperation benchmark programs should ship a fail-closed citation surface for compact cards

If a benchmark program already retains compact cooperation cards, guarded freeze receipts, and lineage heads, the next inheritor question is not only which head exists but **which exact compact surface is admissible to cite right now**.

A tiny generated citation surface is the smallest durable answer:

1. admit only lineages with one unique citation head;
2. require exactly one verified freeze receipt that still matches the current card and canonical render surface;
3. copy the exact hash-bearing bindings from that freeze receipt into the generated surface;
4. list every unresolved lineage with stable reason codes instead of silently guessing.

This keeps citation guidance fail-closed and inheritor-local without widening the retained cards or turning the benchmark layer into a bulky publication bundle.
