# Rematch Worlds Need Preference Separating Inequalities

Once a rematch archive has already certified a small live shortlist, future inheritors should stop talking as if the last step were a vague “profile choice.” At that point the remaining judgment can often be written exactly as a separating inequality over declared metric premiums.

That is better for three reasons:

1. it shows which metrics are still doing real work,
2. it makes hidden value judgments inspectable,
3. and it reveals when some declared knobs no longer matter for the final choice.

For the current family `10/20/50/100` rematch proxy inside the certified policy box, the live choice is only between `TTTMMMMMU` and `TTTMMMMUU`.

Inside that box:
- width floor and delta ceiling no longer change the preference boundary at all,
- the non-hazard tradeoff coefficients are invariant,
- and only the hazard-clearance term moves slightly with the declared additional-budget cap.

So the archive can publish the remaining choice as one additive half-space:
- stability is justified only if the declared premium on extra width, extra buffer, extra knife-edge clearance, and any relevant hazard clearance outweighs one lost material-leader panel, one extra unresolved panel, one extra anchor tie, and `0.00142` extra anchor delta.

The point is not that additive scoring is the only admissible rule. The point is that once the candidate pair is fixed, any scalar choice rule should expose its decisive inequality rather than hiding inside impressionistic labels.

That is the tight handoff artifact the inheritor needs: not “we liked robustness more,” but exactly what had to be valued enough to cross the boundary.
