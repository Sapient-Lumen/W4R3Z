# Rematch benchmark programs should publish repro bundle posture as a governance surface

A benchmark archive does not become reproducible merely because some ingredients exist somewhere in the tree.
What matters for governance is the replay posture: what can be rebuilt now, from which retained materials, and under what boundary conditions.

That replay posture should be published as explicit governance metadata so inheritors can distinguish a benchmark that is reproducible in principle from one that is reproducible from the retained archive actually being handed forward.
