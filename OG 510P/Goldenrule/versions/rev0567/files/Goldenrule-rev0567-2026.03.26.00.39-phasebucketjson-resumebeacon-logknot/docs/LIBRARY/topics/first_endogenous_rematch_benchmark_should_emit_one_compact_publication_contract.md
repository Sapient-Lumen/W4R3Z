# The first endogenous rematch benchmark should emit one compact publication contract

The archive now has a cleaner inheritance boundary for the post-canonicalization rematch backlog.

Instead of treating `SQ-012` through `SQ-026` as fifteen separate prompts for more notes, the next implementor can treat them as one benchmark-emission target with six sections:

1. world semantics,
2. matching state,
3. occupancy accounting,
4. turnover / tempo,
5. paired ranking views,
6. the existing compact decision bundle.

That does two useful things at once.

First, it finally turns the earlier world-semantics / comparability questions (`SQ-012` through `SQ-016`) into a machine-checkable publication target rather than an oral tradition spread across topic notes.

Second, it prevents the phase-3 decision work from exploding back outward. The benchmark should not publish one delay report, one winner report, and one delta report as separate retained artifacts. It should emit the standing compact decision bundle unchanged inside the same benchmark publication contract.

So the inheritor-facing rule becomes simple: after canonicalization lands, do **one** endogenous rematch-world benchmark emission and judge progress by emitted sections, not by how many new rematch memos appear.
