# Cooperation benchmark programs should publish a primary focus-open path for compact-card reentry

When a compact-card stack already publishes a deterministic focus lineage, one more small inheritor aid is worth keeping explicit: **publish the exact first file path to open for that focus lineage**.

Why this belongs in the archive:

- a lineage id tells the inheritor *what won*, but not yet *which file to open*;
- making the first-open path explicit removes one more scavenger-hunt step from reentry;
- the path should be derived from already-retained lineage artifacts rather than introducing a new narrative report.

Operational rule:

1. prefer a rendered citation-head markdown path when present, because it is the smallest human-first reading surface;
2. otherwise fall back to the citation-head card json path;
3. otherwise fall back to the operational-head card json path;
4. keep the result tiny and typed on the top-level reentry surfaces only.

This keeps the compact-card stack locally legible for inheritors without widening cards, receipts, or the handoff pack.
