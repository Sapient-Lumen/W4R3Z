# Cooperation benchmark programs should publish remaining focus primary verify and refresh target semantic counts for compact-card reentry

If the fused compact-card reentry surfaces already publish direct first focus verify and first focus refresh target summaries, they should also publish the remaining typed report counts that those summaries are derived from.

The goal is to keep first-pass reentry locally machine-readable: inheritors and tools should not have to parse scale-summary prose or reopen retained report JSON just to recover the rest of the focus-lineage machine-target counts.

For the canonical compact-card control plane, witness, and next-action surfaces, that means publishing `focus_primary_verify_target_citation_lineage_count`, `focus_primary_verify_target_unresolved_lineage_count`, `focus_primary_refresh_target_verified_delta_receipt_count`, and `focus_primary_refresh_target_latest_known_card_count` as strict aliases of the lineage-local handoff-pack counts already retained for the chosen focus lineage.
