# Claim-class validation should collapse to the claim taxonomy contract

The retained validation summary for claim classes is only a compact machine-checkable view of the standing claim taxonomy.
The durable object should stay the taxonomy itself plus the rule that validation tracks `evidence_classes`, `ids`, `strict_required`, and `total`.

## Archive consequence

Cite this topic and `docs/CLAIM_TAXONOMY.md` instead of preserving another validation-summary family when the only durable question is whether the class taxonomy remains populated and strict-gate aware.
