## Claim

The current exact-uncertainty weakening holes do not force messy mixed compromises. Every impossible primitive-demand coordinate is approximated by overbuying exactly one primitive axis — either extra middle-band precision relief or extra relaxed-suffix release — while preserving the other requested axis exactly.

## Why it matters

- This makes approximation error legible: the current menu misses requests by a one-axis tax, not by an arbitrary two-axis distortion.
