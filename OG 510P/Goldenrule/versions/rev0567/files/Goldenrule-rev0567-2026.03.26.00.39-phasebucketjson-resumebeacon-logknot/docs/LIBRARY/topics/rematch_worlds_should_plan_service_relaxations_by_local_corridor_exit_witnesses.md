# Rematch worlds should plan service relaxations by local corridor exit witnesses

If a future inheritor already knows the current positive-service weakening signature, the next practical question is not only which axis unlocks next or how many total relaxations remain. The nearest operator horizon is: how long does the present unlock corridor persist, and what kind of corridor takes over after it ends?

The local corridor-exit witness law answers that with one tiny card per current SLA target:
- current signature and current corridor kind,
- current corridor steps remaining,
- the signature at which the current corridor terminates,
- the boundary transition kind at that termination,
- and the next corridor kind that takes over after the handoff.

In the current archive geometry, the resulting transition grammar is small and audited:
- suffix corridors usually end by handing off to an exact singleton bridge,
- exact singleton bridges hand back to suffix corridors,
- there is exactly one suffix-to-shared kink at `E3_S8`,
- and the shared diagonal is itself only a one-step bridge back to suffix.

That means future inheritors can treat exact-only and shared-diagonal local leadership as boundary devices rather than persistent regimes. The only durable local corridors are suffix-only, and any future archive revision that adds extra kinks, exact-to-shared handoffs, or multi-step non-suffix successor corridors should be read as a substantive redesign of the current service-relaxation grammar.
