# Archive size control should trim exact report paths from one manifest

When the hotspot surface is already handle-covered, the next byte-saving step should not start from a family name alone.

Carry one compact compaction-manifest receipt that lists the exact retained report paths, the bytes they occupy, and the durable handles that justify citing rather than rekeeping them.

This keeps future archive shaping procedural instead of archaeological:
- cite the durable handle,
- remove the exact retained report paths in the manifest,
- and avoid reopening the same bulky report family by hand in a later session.
