# Agent Claims (Multi-Agent Coordination)

When multiple agents are working in this repo (e.g., you + Gemini + me), avoid collisions by “claiming” a task/file area here before making big edits.

Rules of thumb:
- Claim small and specific (one subsystem / a few files).
- Prefer “brick” changes that land cleanly and can be reviewed quickly.
- Run `tools/check.sh` before handing off if you touched code.
