# Statistical Practice

## Principles

- Prefer deterministic replication over single-run anecdotes.
- Use distributions (not lone points) for timing and behavioral claims.
- Maintain adversarial and holdout evaluations to avoid overfitting.

## Timing

- Compare measured runtime against baseline p95 thresholds.
- Treat baseline bumps as explicit governance changes.

## Behavioral Claims

- Always report context: world, seed, opponents, and scoring definitions.
- Distinguish in-distribution gauntlet passes from holdout robustness.
