# Cloudtainer userspace rustup plan

Generated by `scripts/report/build_cloudtainer_userspace_rustup_plan.py`. This turns the standing userspace-rustup detour into one replayable command surface for the *next* HTTPS-capable machine while keeping the transient toolchain roots explicit and easy to prune before the next archive cut.

## Summary

- current cloudtainer state: `junest_binary_missing`
- current bridge mode: `stay_static_here`
- repo toolchain channel: `stable`
- requested profile: `minimal`
- additive components: `rustfmt`
- additive targets: `none`
- `Cargo.lock` present: `true`
- transient roots: `.local/cargo, .local/rustup, .local/target`
- phase ids: `env, bootstrap, toolchain, warm_cache, first_proof, cleanup`

## Why keep this surface

- It converts the prose detour into a deterministic command sequence that can be emitted again without reopening multiple docs.
- It keeps all heavy userspace Rust state under three explicit scratch roots so the next inheritor knows exactly what to delete before packaging.
- It stages dependency fetch before the first real Rust witness, which is the best use of a brief egress window on a later machine.

## Phases

### `env` — export repo-local toolchain roots

```bash
export CARGO_HOME="$PWD/.local/cargo"
export RUSTUP_HOME="$PWD/.local/rustup"
export CARGO_TARGET_DIR="$PWD/.local/target"
export PATH="$CARGO_HOME/bin:$PATH"
```

### `bootstrap` — install rustup without selecting a default toolchain yet

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- --default-toolchain none -y
```

### `toolchain` — select minimal profile and install the repo-pinned toolchain plus additive components

```bash
rustup set profile minimal
rustup toolchain install stable --profile minimal --component rustfmt
```

### `warm_cache` — stage dependency cache while network exists

```bash
cargo fetch --locked
```

### `first_proof` — take the smallest existing Rust comeback witness

```bash
rustup show
make doctor
make update-rust-comeback-execution-card
git apply artifacts/patches/rust_external_test_shards/01_fsm_grim_trigger_probe.patch
cargo test -p gr_engine --test probe_run lift_fsm_strategy_family_lift_first_seed -- --exact
cargo test -p gr_engine --test probe_run
```

### `cleanup` — prune transient userspace toolchain roots before the next archive cut

```bash
rm -rf .local/cargo .local/rustup .local/target
```
