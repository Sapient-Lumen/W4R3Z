# bzip4: the bundled literary fixture notice

The rev0034 source bundle includes a Shakespeare electronic-text fixture. Its carried World Library / Project Gutenberg terms are separate from the codec’s [LGPLv3 document](versions/rev0034/contents/bzip4-rev0034/LICENSE) and the retained [libsais Apache 2.0 document](versions/rev0034/contents/bzip4-rev0034/upstream/bzip3-1.5.3-53984ef/3rdparty/libsais-LICENSE). GitHub cannot display the 5,458,199-byte fixture in its file viewer.
