# Decision-Grade Rubric

The archive began as a speculation bank. It is now large enough that the user needs to know which speculations are merely interesting and which are decision-grade.

A dossier is **decision-grade** when it can change how someone designs a product, writes a contract, allocates capital, runs diligence, chooses a research program, or watches a policy frontier.

## Six scoring axes

Each dossier can be scored from 0 to 3 on six axes.

| Axis | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| Salience | narrow curiosity | sectoral trend | cross-sector pattern | changes bottleneck map |
| Bottleneck hardness | vague friction | plausible constraint | named gate | gate controls money/permission/liability |
| Evidence | evocative | signal cluster | named artifact | enforcement or registry surface |
| Adversary | none | generic abuse | named abuse mode | abuse changes design of artifact |
| Distribution | absent | generic burden | named affected group | burden changes legitimacy or adoption |
| Actionability | no action | watch only | contract/product/design implication | immediate decision or diligence checklist |

A total score above 13 is decision-grade. A score of 10–13 is watchlist-grade. A score below 10 should either remain a seed or be merged into a broader model unless it has exceptional conceptual value.

## Four editorial classes

| Class | Meaning | Action |
|---|---|---|
| DG-A | Decision-grade, high leverage | Keep as standalone dossier; update sources regularly. |
| DG-B | Strong watchlist | Keep but sharpen enforcement and falsifiers. |
| DG-C | Interesting but under-institutionalized | Merge, seed, or require stronger source path. |
| DG-D | Trend label | Remove or rewrite around a state transition. |

## What rev0183 changes

rev0183 adds `INDEX/decision-grade-scores.csv` and `INDEX/decision-grade-scores.json`. The scores are heuristic, not authoritative. They are meant to sort the archive for future reading and revision.

The highest-scoring dossiers are not always the newest or flashiest. They tend to have:

- a named artifact;
- a relying actor;
- a maintenance or status-afterlife problem;
- a source or policy signal;
- an adversarial pressure;
- a small-actor or civil-rights burden;
- a clear falsifier.

## How to use the scores

Use DG-A dossiers as the archive's current strategic core. Use DG-B as the next research queue. Use DG-C as candidates for consolidation. Use DG-D as warnings that the archive is drifting back toward trend naming.

Do not treat the score as truth. Treat it as a reading order.
