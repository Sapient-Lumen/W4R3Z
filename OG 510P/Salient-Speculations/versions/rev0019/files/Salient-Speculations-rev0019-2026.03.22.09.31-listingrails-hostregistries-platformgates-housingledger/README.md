# Salient Speculations

**North star:** build a compact, cumulative archive of surprising speculations that are broad, salient, and worth serious attention.

This archive is not a prediction contest and not a vibes notebook. It is a **research program for disciplined speculation**.
Each note must do five things:

1. surprise without becoming decorative,
2. matter across more than one domain,
3. name a plausible mechanism,
4. expose watchpoints that would strengthen or weaken it,
5. stay small enough to survive reopening.

## Current archive shape

The archive now spans infrastructure, climate, care, biology, media trust, airspace, education, administrative interoperability, payments, borders, labour, construction, healthcare, trade paperwork, goods passports, natural-resource governance, and housing-finance collateral governance.

The synthesis stays deliberately compact:

> Cheap cognition raises the strategic value of scarce complements, gatekeepers, allocation surfaces, proof surfaces, status surfaces, query surfaces, observability layers, transaction rails, relay surfaces, and software-governed rights surfaces such as legally effective originals and organisational authority credentials.

## Design lineage

This archive was structured after studying the provided reference datacubes, especially their strengths in:

- tight constitutional shells,
- compact indexes and release surfaces,
- one-idea-per-note discipline,
- quarantine lanes for bold moves,
- and machine-readable continuity objects.

It remains intentionally lighter than those exemplars.
The archive should stay portable enough to reopen in one sitting.
