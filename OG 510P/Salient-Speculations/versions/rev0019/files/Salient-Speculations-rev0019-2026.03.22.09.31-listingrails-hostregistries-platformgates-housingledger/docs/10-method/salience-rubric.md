# Salience rubric

A note is worth adding only if it scores well on most of the following:

## 1. Surprise

The claim should feel non-obvious to an informed reader.
Not contrarian for its own sake; genuinely perspective-shifting.

## 2. Consequence

If true, the claim would alter how serious people allocate attention, resources, or institutional design effort.

## 3. Breadth

The claim should spill across more than one domain.
A good note usually connects at least two of: technology, governance, economics, demography, infrastructure, culture, education, biology, security.

## 4. Mechanism

There must be a causal story, even if incomplete.
The archive should resist beautiful slogans with no machinery.

## 5. Watchability

A future session should be able to check whether the note is getting warmer or colder.
That requires watchpoints and weakening conditions.

## 6. Compression value

A note should help compress a large frontier into one portable insight.
If it only adds detail without changing the map, it probably does not belong.

## Admission rule

A note enters `canon` only if it has:

- at least two source anchors or source families,
- an explicit mechanism section,
- at least three concrete watchpoints,
- an explicit weakening section,
- and a credible claim to cross-domain relevance.

Otherwise it goes to `quarantine` or stays unwritten.
