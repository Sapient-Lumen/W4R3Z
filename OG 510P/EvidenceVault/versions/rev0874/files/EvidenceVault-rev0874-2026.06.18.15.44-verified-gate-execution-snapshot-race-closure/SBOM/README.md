# SPDX file inventory

`EvidenceVault-file-inventory.spdx.json` is a deterministic SPDX 2.3 JSON file inventory generated by `scripts/build_spdx_inventory.py` and checked by `scripts/validate_spdx_inventory.py`.

The document records SHA-1 and SHA-256 checksums for shipped files, excluding only `SBOM/EvidenceVault-file-inventory.spdx.json`, `MANIFEST.sha256`, `INDEX/files.json`, and `INDEX/files.csv`. These exclusions are necessary because the manifest/index surfaces describe the SPDX document itself; including them inside the SPDX digest closure would require an impossible hash fixed point during normal release refresh.

All file license conclusions are `NOASSERTION` pending the owner/upstream rights review tracked under `RIGHTS/`.
