# Rights and publication readiness

This directory makes the release-rights blocker explicit. It does not grant reuse rights.

- `component_license_ledger.json` / `.md` are generated by `scripts/build_rights_readiness.py` and validated by `scripts/validate_rights_readiness.py`.
- `LICENSE_DECISION_BLOCKER.md` records why publication or redistribution must not be inferred from mechanical archive validity.
- `NOTICE.draft` is a placeholder for an owner-approved root NOTICE.

The intended next canonical repair is to add root `LICENSE` and `NOTICE`, then replace `NOASSERTION` entries with reviewed component-level license conclusions.
