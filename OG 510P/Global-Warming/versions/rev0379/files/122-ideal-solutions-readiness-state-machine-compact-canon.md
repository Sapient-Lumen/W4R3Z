# 122 — Ideal Solutions, Compact Canon: Readiness State Machine in One Place

## Claim

The archive now has a substantial readiness cluster:
- a standing-readiness note (`111`)
- a live-discipline note (`112`)
- a rehearsal note (`113`)
- a readiness-assurance note (`114`)
- a partial-readiness note (`115`)
- an unknown-readiness note (`116`)

- a promotion note (`118`)
- a demotion note (`119`)
- an anti-churn note (`120`)
- and a dispute-resolution note (`121`)

That is now enough material that the archive benefits more from **compression** than from another narrow readiness rule.

So one more compact note now belongs in the canon:

**a serious climate state should treat readiness as a small operating state machine: keep readiness live before stress, classify the current state honestly, govern by that state rather than by inherited labels, move status only on current proof, resist churn, and default conservatively when the status is disputed.**

This note does not replace the underlying files.
It gathers the readiness cluster into one small ordered sequence so the archive can stay dense without becoming cumbersome [S34][S55][S73][S83][S102][S103][S108][S109][S111][S112][S113][S114][S115][S116][S117][S118][S119][S120][S145][S147].

## Fast rule

**Keep readiness live, classify it honestly, route operation by the current state, allow promotion only on current proof, force demotion quickly when the stronger claim no longer governs, suppress flapping, and govern any unresolved dispute under the more conservative state until the evidence path closes it.**

## The compact canon

### 1. Keep base readiness live before the bad day
Readiness is not a ceremonial plan on a shelf.
A serious climate state keeps the pre-incident chain alive:
- standing duties in place
- rehearsals on a live cadence
- assurance strong enough that readiness claims are earned rather than inherited [S55][S73][S83][S111][S113][S114][S145]

### 2. Classify the current state honestly
The smallest honest readiness ladder is:
- **proven ready**
- **partial readiness**
- **unknown readiness**
- **live detour**

Do not ask first what label feels best.
Ask which state actually governs right now [S83][S103][S112][S114][S115][S116][S117].

Best next file:
- `117-ideal-solutions-four-readiness-states-and-the-routing-rule-between-them.md`

### 3. Govern by the current state, not by the previous label
Once the current state is known, operate under that state rather than under the last flattering label.

What this means:
- if the state is **partial readiness**, govern by bounded gaps plus compensations
- if the state is **unknown readiness**, govern by conservative defaults until proof is rebuilt
- if the state is **live detour**, govern the detour directly instead of talking around it [S83][S103][S108][S112][S115][S116][S117]

### 4. Move upward only on current proof
Promotion is earned, not assumed.
A stronger readiness claim should only be granted when current evidence shows the weaker state no longer governs [S73][S83][S114][S117][S118][S145].

Best next file:

### 5. Move downward quickly when the stronger claim no longer governs
Demotion is not failure theatre.
It is the honesty rule that keeps the state machine aligned with reality.
Downgrade as soon as proof has gone stale, the chain is broken, meaningful gaps now govern, compensations are carrying the mission, or a live detour is already open [S83][S103][S112][S114][S115][S116][S117][S119].

Best next file:

### 6. Prevent ceremonial oscillation
Do not let readiness status become a reputational scoreboard.
Suppress cosmetic upgrades, resist delayed downgrades, and hold the more conservative status when reality is still moving or not yet well evidenced [S83][S102][S114][S117][S118][S119][S120][S147].

Best next file:
- `120-ideal-solutions-five-anti-churn-rules-so-readiness-status-does-not-flap.md`

### 7. Resolve disputes conservatively and quickly
If actors disagree about the current status, do not let ambiguity preserve the stronger claim.
Protection outranks reputation, the stronger claim carries the burden, current end-to-end evidence outranks stale paperwork, and the system runs under the more conservative state until the dispute is closed through a named path [S83][S102][S107][S108][S114][S117][S118][S119][S120][S147].
