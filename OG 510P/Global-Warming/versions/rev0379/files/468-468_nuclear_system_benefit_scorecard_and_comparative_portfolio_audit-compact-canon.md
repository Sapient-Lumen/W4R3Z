# 468 — Nuclear system-benefit scorecard and comparative portfolio audit

## Refactor rule

The cube now treats nuclear preference as a comparative system-benefit claim. The preference is still explicit, but it must travel through transparent scorecards for avoided emissions, reliability, public health, lifecycle footprint, system cost, complementarity, and counterfactual displacement.

## Audit rule

The audit rejects both anti-nuclear blind spots and pro-nuclear overclaim. Nuclear gets default inclusion in relevant portfolios, but claimed benefits must be traceable, localized when appropriate, and open to red-team challenge.

## Rev0297 nuclear geopolitical-resilience overlay

The nuclear-positive orientation now includes an explicit geopolitical-resilience burden of proof. Clean-firm nuclear preference is strengthened when it reduces fossil/import/coercion exposure, but maturity is capped by unresolved fuel-cycle concentration, vendor lock-in, sanctions exposure, export-finance/debt risk, safeguards capacity, export-control boundaries, and sensitive-publication controls.
