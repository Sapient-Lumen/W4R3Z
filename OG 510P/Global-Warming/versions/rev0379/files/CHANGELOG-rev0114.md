## Why
The archive already had compact notes for readiness before a bad day, rehearsal so readiness stays real, readiness assurance so claims require current proof, compensating duties for partial readiness, and conservative defaults for unknown or stale readiness. What it still lacked was the shortest way to classify the current status and route immediately to the governing note. Rev0114 closes that gap by adding a four-state readiness ladder: proven ready, partial readiness, unknown readiness, and live detour — with an explicit conservative rule to choose the more protective state when classification is blurry.
