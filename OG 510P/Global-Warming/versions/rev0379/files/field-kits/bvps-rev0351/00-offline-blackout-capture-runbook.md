
# BVPS rev0351 offline blackout capture runbook

Use this kit if the live console, network, printer, identity provider, shared drive, scanner, timestamp source, or public website is unavailable.

1. Select the packet ID from the rev0343/rev0348 60-packet cutline.
2. Use the packet-specific offline form.
3. Record observed time, device clock state, owner, backup owner, custody handoff, and deferred hash reason.
4. Preserve original artifact or physical evidence envelope.
5. Do not write ready/green/passed/closed/safe/sufficient/certified language.
6. After outage, run the rehydration scan and validator. A repaired packet can become only a candidate for adjudication.
