# BVPS rev0332 dose assessment, field monitoring, and PAR/PAD runbook

Use this runbook to capture a local or anonymized evidence packet. Do not include public-sensitive plant, security, exact field-route, or personal data in the public surrogate.

## Minute-zero packet list

1. EAL/classification workpaper with authority and timestamp.
2. Plant/source-term packet with release path, rate basis, isotope assumption, containment/filtration state, and uncertainty.
3. Meteorology input manifest with raw/extract hash, gap flags, backup source, and clock sync.
4. Dose-model run log with model/version, input manifest, output hash, sensitivity runs, PAG thresholds, and reviewer.
5. Field-team dispatch, instrument QA, dosimetry, route/survey point list, readings, sample custody, and worker dose return.
6. Dose-to-PAR/PAD decision trace with offsite consultation, public official decision, message linkage, update/retraction path, and verifier.
7. Counterevidence/reopen ledger for field, lab, hospital, CRC, public behavior, and meteorology contradictions.

## Default cap

Missing raw inputs, hashes, custody, verifier, or CAP/retest evidence caps public claims. A complete packet is a candidate for adjudication only.
