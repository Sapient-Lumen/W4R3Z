# BVPS rev0343 event-day evidence packout runbook

Purpose: keep the June 2026 exercise evidence from being lost, unlabeled, unhashable, over-redacted, or overclaimed.

Rules:

1. Label before collection when possible.
2. Hash originals before editing.
3. Pair every sensitive original with either a redacted surrogate or a sensitive-annex exception.
4. Use paper custody if systems fail.
5. Missing packets trigger loss caps; missing evidence is not neutral.
6. A public meeting statement, AAR paragraph, dashboard, schedule, MSEL event, source ID, or folder skeleton is never closure evidence.
7. Candidate packets go to adjudication only; there is no auto-close state.

Minimum intake fields: artifact ID, packet ID, branch gate, owner, backup, capture time, source clock, original hash, redacted surrogate hash or annex reason, custody event, counterevidence path, CAP/retest/verifier reference where relevant.
