# BVPS rev0361 live watchdog runbook

Run the watchdog as a **one-shot check** at shift start, shift handoff, after any first-drop payload, after any public-meeting/public-source update, and before any public-facing statement.

Correct result: **capture-ready / claim-frozen**.

Forbidden interpretation: ready, green, passed, safe, sufficient, certified, demonstrated, released, or closed.

Inputs:
- rev0360 one-command go/no-go baseline
- packet folders and quarantine lanes
- receipt chain and first-drop sentinel
- public-meeting lockbox
- claim-freeze board

Outputs:
- watchdog run result
- drift alarm board
- P0 workorders
- safe public statement remains restricted to process status only.
