# BVPS rev0344 warroom packout shift-ops runbook

Use this after the rev0343 packet skeletons are staged. Each packet must be assigned to a primary and backup owner, checked against hash/redaction/custody requirements, and either checked in or explicitly capped. A public meeting statement, AAR paragraph, owner ACK drill, folder skeleton, MSEL event, dashboard, or public source can never close a readiness row.

1. Open the 60-packet cutline.
2. Confirm owner and backup owner acknowledgement.
3. Confirm hash tool and sensitive-annex route.
4. At each shift handoff, mark unresolved P0 packets and active loss caps.
5. Route exceptions to the escalation board.
6. Treat every complete-looking packet as candidate-for-adjudication, not closure.
