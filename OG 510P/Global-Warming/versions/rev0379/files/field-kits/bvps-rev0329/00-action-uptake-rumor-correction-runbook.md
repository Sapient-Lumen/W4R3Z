# BVPS Rev0329 Action-Uptake and Rumor-Correction Runbook

Purpose: collect privacy-safe evidence that people understood and acted on protective-action messages without turning raw personal data into a public artifact.

Minimum capture sequence:

1. Identify the message hash, channel, target area, and protective action.
2. Record receipt/comprehension/action status by approved sentinel stratum.
3. Preserve route/reception/shelter/AFN/school/farmer/CRC action packets as separate artifacts.
4. Capture hotline/911/JIC/social-listening confusion signals and correction timestamps.
5. Split sensitive annexes from public-safe surrogate rows before import.
6. Run `tools/validate_nuclear_emergency_bvps_action_uptake_rev0329.py`.
7. Send candidate packets to adjudication; do not mark any packet closed from import alone.

Default: missing raw evidence is a cap, not a neutral condition.
