# 482 — Nuclear liability counterargument, exception, and public-value safeguard

## Audit function

This file is the red-team layer for liability and financial assurance. It does not reverse the cube's pro-nuclear orientation. It makes that orientation stronger by forcing liability-subsidy, accident-cost, decommissioning-shortfall, insurance-market, modular-reactor, and public-backstop objections into an explicit exception ledger.

## Nuclear-positive rule

Nuclear is favored when it provides clean firm public value that survives counterfactual dispatch, finance, delivery, safety, fuel, workforce, and now liability/financial-assurance scrutiny. A liability objection is not an automatic veto, but it is a mandatory maturity cap until answered with public evidence.
