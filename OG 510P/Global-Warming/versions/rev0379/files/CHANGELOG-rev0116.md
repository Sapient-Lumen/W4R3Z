## Why
The archive already had compact notes for readiness duties, rehearsal, readiness assurance, compensating duties for partial readiness, conservative defaults for unknown readiness, a four-state readiness ladder, and a promotion rule for moving upward on that ladder. What it still lacked was the equal-and-opposite rule for **when a stronger status must be surrendered**. Rev0116 closes that gap by adding five demotion tests so downgrades happen when current evidence shows the stronger state no longer governs, instead of waiting for embarrassment, blame assignment, or a full incident.
