# 473 — Nuclear geopolitical-resilience scorecard and source-authority refactor audit

## Audit function

This file closes the rev0297 refactor by making geopolitical resilience queryable. It introduces scorecards, gap backlogs, source authority classes and sensitive-publication controls so the cube can favor nuclear without becoming vendor-blind or geopolitically naive.

## Nuclear-positive rule

Nuclear receives a favorable default in energy-security contexts when it reduces fossil, import, volatility or coercion exposure. The favor is capped when the path creates unscored fuel-cycle, vendor, sanctions, export-finance, safeguards or sensitive-publication risk.


## Rev0298 nuclear human-capital refactor note

The cube's pro-nuclear orientation is now explicitly conditioned by workforce depth, operator licensing, regulator capacity, safety/quality culture, knowledge retention, craft labor, and public training pathways. Nuclear remains favored for clean firm power and system benefit, but human-capital and institutional-capacity gaps are binding maturity caps rather than implementation footnotes. Sources: [S864], [S868], [S871], [S873], [S875].
