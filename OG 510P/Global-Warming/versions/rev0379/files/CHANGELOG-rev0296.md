# Changelog — rev0296

Created: 2026-05-30T12:00:00-04:00

## Orientation

Rev0296 keeps the cube explicitly nuclear-positive, but refactors the preference into comparative system-benefit accounting. Nuclear is favored in relevant clean-firm, reliability, industrial, water, heat, data-center and public-service contexts only when avoided-emissions, counterfactual dispatch, capacity value, lifecycle footprint, public-health benefit and anti-greenwash gates are traceable.

## Major additions

- Added canon files 464–468 for nuclear system-benefit accounting.
- Added sources S842–S851.
- Added 27 nuclear system-benefit service floors.
- Expanded nuclear assurance gates from 84 to 100.
- Added system-benefit tables for avoided emissions, counterfactual dispatch, capacity value, lifecycle footprint, fossil displacement/public health, portfolio comparison, comparative safety, benefit attribution, gap backlog and traceability.
- Rebuilt normalized file/source/route/service-floor/tag edges, maturity scorecards, nuclear gate evaluations, SQLite and validation outputs.

## Audit/refactor

The main audit target was benefit overclaim. Rev0296 turns avoided-harm, reliability and fossil-displacement language into explicit counterfactual, lifecycle and public-value proof burdens.
