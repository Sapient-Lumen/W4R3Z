# 150 — Ideal Solutions, Compact Canon: Whole-System Correction Cycle in One Place

## Claim

The archive now has a substantial whole-system correction cluster:
- a diagnosis map (`142`)
- a remedy map (`143`)
- a verification map (`144`)
- a second-pass map (`145`)
- a stabilization map (`146`)
- a propagation map (`147`)
- a retirement map (`148`)
- and a regression-prevention map (`149`)

That is now enough mature operator logic that the next clean gain is **compression** rather than another narrow note.

So one more compact note now belongs in the canon:

**a serious climate programme should treat correction as a joined cycle: diagnose the likely weak layer, launch the smallest fitting first correction, verify against the targeted signal, escalate or redirect if it fails, bank the gain if it works, spread it without reopening bespoke design, retire the inferior path once the better one can carry continuity safely, and keep the retired path from quietly returning.**

This note does not replace the underlying files.
It gathers the correction cluster into one small ordered sequence so the archive can stay dense without becoming harder to operate [S34][S46][S75][S84][S85][S86][S124][S133][S138][S141][S142][S143][S144][S145][S146][S147][S148][S149][S150][S151][S180][S181][S182][S183].

## Fast rule

**When the scoreboard weakens, diagnose the likely weak layer, apply the smallest fitting first correction, verify against the targeted signal, do a stronger second pass if it still does not work, bank the gain into governed routine if it does, spread the better pattern without restarting from zero, retire the inferior path once the replacement is ready, and keep the retired path from quietly returning.**

## The compact correction cycle

### 1. Start with the weak signal, not the favourite fix
When the mature programme weakens, the first job is not to defend a prior intervention.
The first job is to locate the most likely weak layer behind the weak signal [S138][S141][S142].

### 2. Launch the smallest fitting first correction
Once the likely weak layer is identified, pick the smallest correction that actually matches that layer.
Do not answer a delivery failure with a speech problem, or a truth failure with a subsidy increase, or a protection failure with a mere target refresh [S124][S133][S141][S143].

### 3. Verify against the targeted weak signal
A correction is not working merely because effort increased or activity looks impressive.
Verify against the weak signal that justified the correction in the first place, and keep truth strict enough that noise, optics, and delay do not masquerade as recovery [S133][S138][S141][S144].

### 4. If the signal still is not improving, run a second pass instead of repeating the first move ceremonially
When the first correction does not clearly improve the targeted signal, the programme should not celebrate early, drift, or simply do more of the same.
It should decide whether to redirect, strengthen, widen scope, or escalate [S103][S104][S123][S145].

### 5. If the correction works, bank the gain into routine
A working correction is still fragile until it becomes normal governed operation.
The programme should lock in staffing, continuity, ordinary monitoring, and protection against immediate fade-out [S75][S82][S124][S146].

Best next files:

### 6. Spread the better pattern without reopening bespoke design from zero
Once the gain is banked, the next job is replication.
Copy what is transferable, adapt only what is place-specific, and resist restarting full custom design in every similar setting [S47][S53][S55][S128][S147].

### 7. Remove the inferior path once the better one can carry continuity safely
Do not pay indefinitely for two parallel paths once the better path is real enough to carry service and reliability.
Retire the inferior path deliberately rather than waiting for it to decay on paper while staying live in practice [S84][S85][S86][S141][S148].

### 8. Keep the retired path from quietly returning
Retirement is not the end of the correction cycle.
Once the inferior path is gone from the centre, it often tries to return through waivers, fallback habits, subsidy relapse, contract reset, procurement drift, or institutional amnesia [S46][S75][S84][S85][S123][S148][S149].
