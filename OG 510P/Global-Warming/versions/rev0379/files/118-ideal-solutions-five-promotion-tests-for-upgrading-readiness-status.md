# 118 — Ideal Solutions: Five Promotion Tests for Upgrading Readiness Status

## Claim

The archive now has:
- a readiness note (`111`)
- a live-discipline note (`112`)
- a rehearsal note (`113`)
- a readiness-assurance note (`114`)
- a partial-readiness note (`115`)
- an unknown-readiness note (`116`)
- and a readiness-status ladder (`117`)

What it still lacked was the shortest **promotion rule** for the next practical question:

**When may a serious climate state actually upgrade its readiness status?**

That gap matters because institutions often downgrade reluctantly and upgrade too early.
They treat calendar time, paperwork completion, or one successful meeting as enough to climb back up the ladder.
But a compact archive needed the opposite rule: **promotion is earned only by current proof that the weaker state no longer governs.**
Without that bridge, the readiness cluster can classify status honestly but still leave too much discretion around when a status claim may be strengthened again.

This note is a **compression note**, not a new doctrinal branch.
Its job is to make upward movement on the readiness ladder conservative, legible, and evidence-bound [S34][S55][S73][S83][S102][S103][S108][S109][S111][S112][S113][S114][S115][S116][S117][S145][S147].

## Fast rule

**Do not upgrade readiness status because time passed, a plan was written, or confidence returned. Upgrade only when current evidence shows that the weaker state no longer governs. If uncertainty remains material, stay in the lower state.**

## The five promotion tests

### 1. Fresh proof replaces inherited confidence
A status upgrade is not earned by memory, policy intent, or last season’s drill.
It requires current evidence on the critical joins, tools, contacts, data paths, and protection routes that justify the stronger claim [S73][S83][S111][S114][S116][S145].

Ask:
- is the proof current enough to describe the system now rather than historically?
- have recent changes in personnel, suppliers, software, assets, geography, or threat conditions been re-tested?
- are we upgrading because evidence improved, or because discomfort with the lower status grew?

### 2. The critical path works end to end
Readiness status should not be upgraded because components look healthy in isolation.
The whole mission-critical path must work across the real handoffs that fail under stress: detection, decision, dispatch, protection, communication, fallback discipline, and proof capture [S34][S55][S83][S111][S112][S113][S114].

Ask:
- did the chain work from trigger to protected outcome?
- were the slowest or weakest joins actually exercised?
- did the system succeed under realistic load, timing, and coordination conditions rather than idealized tabletop assumptions?

### 3. Material gaps are closed, bounded, or honestly reclassified
A system should not be promoted while meaningful gaps are still being carried by wishful language.
If the gaps remain material, the correct state is still partial readiness.
If the proof remains missing, the correct state is still unknown readiness [S83][S103][S114][S115][S116].

Ask:
- were the identified gaps actually repaired?
- if not repaired, were they reduced below the threshold where they still govern mission safety or continuity?
- has the scope been honestly narrowed so the upgraded claim matches what is truly covered?

### 4. Compensations and borrowed support are no longer carrying the core mission
It is common to appear ready only because exceptional effort, external help, heroic staff behavior, or temporary compensations are still propping up the system.
That can justify temporary operation, but not a full status upgrade [S39][S55][S83][S103][S111][S115].

Ask:
- would the claimed stronger state still hold without extraordinary workarounds?
- are borrowed teams, informal favors, manual patches, or temporary waivers still doing core work?
- have compensations been retired, reduced, or clearly moved to the edge rather than the center of performance?

### 5. The stronger claim survives adversarial review and realistic rehearsal
A serious status upgrade should survive two kinds of challenge: a skeptical assurance review and a realistic rehearsal that tries to break the claim.
If either fails materially, the archive should keep the lower state [S73][S83][S103][S113][S114][S145][S147].

Ask:
- has someone with permission to say “not yet” tested the claim?
- did the latest realistic rehearsal confirm the stronger state rather than expose hidden fragility?
- if an outsider saw the evidence pack, would the upgrade look earned or convenient?

## Minimal promotion map

The smallest serious upgrade map is:

- **unknown → partial** when missing proof is replaced by specific knowledge of the real gaps, even if those gaps are not yet closed
- **unknown → proven ready** only when current proof supports the stronger claim and all five promotion tests are met
- **partial → proven ready** only when the material gaps no longer govern, compensations stop carrying the core mission, and current proof plus rehearsal support the upgrade
- **live detour → not automatically proven ready**; first close the detour through `109`, perform the learning and hardening duties in `110`, and then re-enter the readiness ladder under current proof rather than incident relief [S103][S104][S109][S110][S112][S114][S117]

## Conservative default

If a team can describe why it wants the upgrade more easily than it can show why the lower state no longer governs, the upgrade is premature.
The archive should prefer:
- **unknown over assumed ready**
- **partial over overclaimed ready**
- **recent proof over inherited assurance**
- **real rehearsal over ceremonial confidence** [S83][S102][S114][S115][S116][S117][S147]

**The archive now has a shortest promotion rule for the readiness ladder: do not upgrade status because time passed, the paperwork improved, or confidence returned. Upgrade only when current proof shows the weaker state no longer governs — the critical path works end to end, material gaps are closed or honestly bounded, compensations are no longer carrying the core mission, and the stronger claim survives skeptical review plus realistic rehearsal. If doubt remains material, stay in the lower state.**
