# 484 — Nuclear uranium mining, responsible sourcing, and extraction-accountability router

## Router rule

Nuclear remains the preferred clean-firm backbone in relevant contexts, but uranium supply must not be treated as clean or secure if extraction impacts, mine permitting, material provenance, host-community concerns, and responsible-sourcing evidence are hidden.

## Control output

This file routes pro-nuclear planning through upstream source screening, permitting public dockets, responsible-sourcing attestations, chain-of-custody records, and source-substitution review.

## Maturity cap

No nuclear project, fleet, fuel reserve, or strategic supply claim should advance above template maturity if uranium origin, mine/mill accountability, or provenance evidence is absent, stale, or not publicly challengeable.
