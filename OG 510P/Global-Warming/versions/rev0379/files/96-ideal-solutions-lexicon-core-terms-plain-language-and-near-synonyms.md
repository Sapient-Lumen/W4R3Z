# 96 — Ideal Solutions Lexicon: Core Terms, Plain Language, and Near Synonyms

## Claim

The archive now has a front door, a topology note, a question router, and an operator card.
What it still lacked was the shortest bridge from the archive's own shorthand to plain-language meaning.

That gap matters because the archive now uses compact terms that are useful once learned but can slow first contact:
- service floors
- waste ceilings
- concentrated control points
- pathway
- offer quality
- assurance stack
- edge conditions
- routing
- admission rule

This note is a navigation / compression note, not a new doctrinal branch.
Its job is to decode the archive's recurring terms, give near-synonyms, and point to the best first deeper file.

## Fast rule

**When the archive uses a compact term, translate it into plain language first. If the plain-language meaning already tells you what is being judged, you usually do not need the whole deeper note immediately.**

## Routing rule

- if the term is about **what climate solutions should do**, go next to the compact canon or the relevant design-rule note
- if the term is about **how users experience the clean path**, go next to the pathway and form notes
- if the term is about **how the archive itself should decide**, go next to the operator layer

## One-paragraph compression

**The archive now has a shortest lexicon note: translate the archive's shorthand into plain language, match it to near synonyms a normal reader might already use, and only then descend into the deeper rule note if needed. That lowers terminology friction without adding any new substantive climate doctrine.**
