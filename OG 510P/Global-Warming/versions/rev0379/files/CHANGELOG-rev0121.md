## Rationale
The governance cluster had grown strong enough that the next gain came from compression rather than another narrow operating rule. This revision adds one joined compact canon that gathers the whole state operating kernel into a single first stop: shape the programme into a few execution lanes, steer it through a few public levers, keep it live on a few clocks, make a few roles visibly accountable, split decision rights cleanly, and settle collisions through explicit precedence rather than improvised politics.
