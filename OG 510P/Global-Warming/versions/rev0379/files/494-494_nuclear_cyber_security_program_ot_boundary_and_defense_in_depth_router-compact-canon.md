# 494 — Nuclear cyber security program, OT boundary, and defense-in-depth router

## Function

This router makes the cube's pro-nuclear preference conditional on a defensive nuclear cyber security programme. It converts cyber into service-floor gates rather than a generic security note: critical digital asset inventory, OT/IT boundary, network-zone defense in depth, logging, monitoring, media controls, incident response, and security-safe publication all become maturity conditions.

## Nuclear-positive rule

Prefer nuclear for clean firm capacity where safety, reliability, and public-service continuity can be defended digitally. Do not count nuclear capacity as mature if safety, security, emergency preparedness, or support systems depend on undocumented or untested digital controls.

## Control-plane effect

Rev0302 adds nuclear cyber service floors, cyber gates, sensitive-publication controls, OT/data-quality records, and red-team exceptions. The audit surface is public at the framework level while site-specific network details, vulnerabilities, diagrams, credentials, exploit indicators, and compensating controls remain controlled.

## Evidence burden

Minimum evidence includes a regulator-visible cyber security programme, critical digital asset inventory, defense-in-depth architecture, access/session logging, removable-media controls, incident-response exercises, and security-safe publication review.
