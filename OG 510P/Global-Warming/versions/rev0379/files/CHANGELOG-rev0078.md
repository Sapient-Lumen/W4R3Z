## Why

The archive had already become clear about interface, enrolment, eligibility, payment, contract, delivery, verification, remedy, continuity, burden shape, pathway integrity, and offer quality. But it still lacked the shortest rule for **who should own the joins** when the real delivery chain spans many agencies, financiers, contractors, and support channels.

This revision adds that missing compact rule: ideal climate solutions should usually keep **one clearly accountable lead for pathway integrity**, even when many actors perform different pieces. The intended user should not have to become the system integrator.

The new note tightens the archive’s service-first and no-heroics doctrine without expanding the source register. It complements the offer-quality note by saying not only that the user should receive one coherent clean offer, but also that **one actor should remain accountable for making that coherence real in practice**.
