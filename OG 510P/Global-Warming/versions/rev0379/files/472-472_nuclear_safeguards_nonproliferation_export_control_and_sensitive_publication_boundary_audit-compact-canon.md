# 472 — Nuclear safeguards, nonproliferation, export-control, and sensitive-publication boundary audit

## Nuclear-positive rule

A pro-nuclear cube must be public and auditable without publishing proliferation-sensitive, safeguards-sensitive, export-controlled or security-sensitive details.

## Publication boundary

Rev0297 separates public assurance claims from restricted implementation detail: publish the existence, owner, status, maturity cap and challenge path; redact exact material quantities, sensitive technologies, safeguards methods, security vulnerabilities and transport/critical-spares exposure if localized.
