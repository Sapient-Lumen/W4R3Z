# 547 — Nuclear emergency preparedness: integrated readiness claim kernel, cross-branch critical cutsets and public-claim firebreak

Revision: **rev0340**

## Problem addressed

The cube has built many strong branch proof spines: local evidence, public-source firebreaks, alerting, field receipt, action uptake, CRC/decon, first receivers, dose/PAR, ingestion controls, recovery, sustainment, cyber/data continuity, lifelines, COP/handoff, and exercise realism. The remaining high-risk failure is aggregation: a public narrative, dashboard, AAR paragraph, score, PI row, or exercise summary can make the whole emergency-preparedness system look ready while a hard branch remains unproven.

Rev0340 creates an integrated readiness-claim kernel. A readiness claim is no longer an average of branch scores. It must pass hard cross-branch cutsets, source-canonical independence checks, stale-clock checks, no-credit exercise rules, CAP/retest/verifier state, counterevidence handling, redaction review, and a forbidden-claim scan.

## Hard rule

A public source, schedule, AAR paragraph, dashboard, scorecard, PI value, action-matrix row, MSEL event, EOPA scope statement, source ID, duplicate URL, local candidate packet, or redacted surrogate can demand, cap, route, contradict, or reopen a claim. It cannot auto-close local readiness evidence.

## Integrated route

`branch evidence -> branch candidate state -> cross-branch cutset -> no-credit aggregation rule -> counterevidence/stale-clock overlay -> claim release packet -> public-safe statement`

There is deliberately no `auto_closed` state.

## Practical result

This revision compresses the sprawling BVPS proof debt into a 24-branch claim kernel, 18 hard cutsets, a 20-field claim-release packet, an open-P0 burden scan, and 18 owner-actionable workorders. It also records the rev0339 branch ambiguity so future package selection is explicit rather than timestamp-based.

`REAL_BVPS_PUBLIC_ONLY` remains public-context-only. No real readiness, unreadiness, pass, fail, green, closed, safe, sufficient, certified, reasonable-assurance, or demonstrated claim is made.
