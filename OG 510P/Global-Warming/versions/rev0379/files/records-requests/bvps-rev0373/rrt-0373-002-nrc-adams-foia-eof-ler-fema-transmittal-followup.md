## Request purpose

This packet is designed to acquire public or releasable records needed to adjudicate two open Beaver Valley evidence gaps: the NRC Event Notification 58200 EOF power-loss follow-up, and the FEMA-to-NRC record path for the June 2026 REP exercise.

## Draft request language

Please identify or provide releasable records concerning Beaver Valley Power Station Event Notification 58200 and the June 2026 Beaver Valley REP exercise record path.

Requested records include:

1. ADAMS accession numbers, public document links, or releasable records for Event Notification 58200 follow-up, including reportability determination, Licensee Event Report if applicable, correspondence, inspection follow-up, corrective actions, restoration/retest evidence, and records describing compensatory measures for Emergency Operations Facility power, alternate facility activation, and communications capability.
2. Any NRC correspondence, inspection notes, public meeting materials, or public docket records connecting the EN58200 EOF event to emergency preparedness readiness, exercise scope, corrective action, or closure.
3. Any FEMA transmittal, NRC receipt, final report, preliminary-finding record, or public accession path for the June 2026 Beaver Valley Radiological Emergency Preparedness exercise when available.
4. If records are not yet available, records identifying expected docket, ADAMS, PDR, or tracking routes for future availability.

Search terms: Beaver Valley; BVPS; Event Notification 58200; EN58200; Emergency Operations Facility; EOF; alternate generator; alternate facility; emergency preparedness; REP exercise; FEMA transmittal; June 2026; ADAMS.

## Format and release preferences

Electronic production is preferred. ADAMS accession identifiers are acceptable where full documents are already public. Rolling release is acceptable. Redactions are acceptable for protected details; please release segregable portions.

## Cube use rule

EN58200 is a trigger, not a readiness conclusion. Compensatory measures, route pages, and docket search paths cannot close the EOF proofcut without imported repair/retest or adjudicated corrective-action evidence.
