# 128 — Ideal Solutions, Design Kernel: Compact Canon

## Claim

The archive now has separate first-stop notes for the **answer** (`58`), the **reference package** (`57`), the **acceptance tests** (`97`), the **positive design directives** (`98`), and the **action verbs** (`99`).
That is useful, but it still leaves one front-door gap:

**there is no single shortest joined note for how to design a serious climate package before deeper governance, readiness, or archive-operation questions begin.**

This note compresses that design layer into one place.
It does not replace the underlying files.
It joins them so future use can start with one design kernel rather than several adjacent notes.
For the archive's shortest joined reading spine, see `125-ideal-solutions-whole-archive-minimal-spine.md`.
For the archive's shortest joined operating-loop note, see `126-ideal-solutions-whole-archive-operating-loop-from-design-to-detour-and-back.md`.
For the archive's shortest joined intake-and-admission canon, see `127-ideal-solutions-intake-and-admission-compact-canon.md`.

## The design kernel

### 1. Start from the right object: a physical-first package, not a clever singleton
The ideal solution is not one technology, one tax, one market instrument, one heroic behaviour change campaign, or one future cleanup machine.
It is a **physical-first package** that cuts emissions fast, lowers energy and material waste, reduces direct exposure, protects essential service floors, and minimizes dependence on later massive removals or overshoot management [S4][S8][S9][S11][S14][S15][S16][S17][S19][S20][S21][S22][S57][S100][S101][S102][S103][S104][S106].

### 2. Build the package around the real jobs
A serious package usually has a recognisable spine:
- clean electricity, grids, storage, flexibility, and selected firm clean capacity where needed
- efficiency first, then electrification of the remaining demand
- rapid methane abatement across oil and gas, waste, and agrifood systems
- managed fossil decline rather than unmanaged persistence
- ecosystem protection, water security, cooling safety, and adaptation as civil protection
- residual tools, scarce clean molecules, and removals held mainly for genuinely hard remainder uses [S4][S8][S9][S11][S12][S14][S15][S16][S17][S18][S19][S20][S21][S22][S23][S24][S25][S26][S27][S28][S29][S30][S31][S32][S33][S34][S35][S36][S37][S38][S39][S57][S102][S103][S104][S105][S106].

### 3. Put the burden where the leverage is
Serious design pushes hardest at concentrated control points, defaults, standards, regulated backbones, procurement, finance, permitting, and turnover moments.
It does **not** rely mainly on atomised consumer heroics, reimbursement mazes, or endless bespoke coordination [S13][S40][S55][S56][S57][S59][S60][S61][S62][S63][S64][S65][S66][S67][S68][S69][S76][S80][S81][S82][S83][S84][S85][S86][S87][S88][S89][S90][S97][S98][S104][S105][S106].

### 4. Use the action verbs as a design check
If the package is serious, its main verbs usually look familiar:
- **electrify** what can be cleanly electrified
- **connect** clean supply, grids, storage, and users
- **retrofit** wasteful buildings, equipment, and systems
- **abate** fast gases and obvious waste
- **protect** people, ecosystems, and water systems directly
- **retire** dirty assets deliberately rather than wait for accidental decline
- **reserve** scarce clean molecules, scarce biomass, scarce land, and scarce removals for the hard remainder [S8][S9][S11][S12][S14][S15][S16][S17][S19][S20][S21][S22][S26][S27][S28][S29][S30][S31][S32][S33][S34][S35][S57][S99][S103][S104][S105][S106].

### 5. Make the package pass the serious-package tests
Before the archive treats a package as genuinely ideal-solution material, it should usually pass the hard tests already named elsewhere:
- early physical effect, not mainly late or paper effect
- denominator reduction as well as numerator cleaning
- delivery realism under real permitting, workforce, capital, and grid constraints
- measurability through physical and service outcomes rather than narration
- validity in poorer and capacity-constrained settings, not only in unusually rich ones
- fiscal and political durability
- copyability across many jurisdictions rather than one unusually capable place [S57][S59][S65][S66][S67][S68][S69][S70][S71][S91][S92][S93][S94][S95][S96][S97][S98][S103][S104][S105][S106].

### 6. Refuse the common design distortions
The archive should distrust packages that mainly do one or more of the following:
- treat removals, offsets, or overshoot as the main plan rather than the residual backstop
- preserve avoidable fossil dependence under the language of realism or transition pragmatism
- spend scarce clean molecules, scarce biomass, or scarce removals on easy uses that already have better substitutes
- hide user burden, affordability problems, or coordination risk under elegant top-level claims
- substitute paper compliance, disclosure, or promised finance for physical delivery [S9][S23][S24][S33][S34][S35][S42][S43][S44][S45][S46][S57][S65][S68][S88][S89][S97][S102][S103][S104][S105][S106][S112][S113][S123][S135][S136].

## Ordered use

When designing from scratch, the archive can now use one compact order:
1. open `58-ideal-solutions-one-page-answer.md` for the shortest answer
2. open `57-ideal-solutions-reference-portfolio-2026-2035.md` for the package spine
3. use this file for the joined design kernel
4. open `97-ideal-solutions-design-spec-ten-acceptance-tests-for-a-serious-climate-package.md` if the proposal still needs a harsher screen
5. open `124-ideal-solutions-governing-kernel-compact-canon.md`, `122-ideal-solutions-readiness-state-machine-compact-canon.md`, or `123-ideal-solutions-off-normal-state-machine-compact-canon.md` only once the package survives design and must actually be governed [S57][S58][S97][S98][S99][S124][S125][S126][S127].

## Compression

The shortest joined design answer in the archive is now this:

**design a climate package as a physical-first portfolio of real jobs; place the burden at leverage points and clean defaults; make it pass hard tests for speed, measurability, delivery, justice, and copyability; and refuse packages that survive only through paper claims, residual-tool inflation, or fossil-preserving exceptions.**
