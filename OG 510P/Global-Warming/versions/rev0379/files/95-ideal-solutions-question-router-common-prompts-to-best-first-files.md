# 95 — Ideal Solutions: Question Router — Common Prompts to Best-First Files

## Claim

The archive needed a bridge from ordinary-language questions to the right first file.
But the bridge became too long.
So this revision keeps the purpose of `95` while materially shrinking it.
It is now a **grouped prompt router**, not a giant prompt encyclopedia.
Its job is to translate the most common question forms into the smallest useful opening move, then hand off to `129` or deeper files only when needed [S57][S58][S88][S95][S100][S101][S102][S103][S104][S105][S106].

## Fast rule

**Start from the question you actually have. Open the smallest note that matches it. If that note answers the question, stop. If not, descend one layer.**
