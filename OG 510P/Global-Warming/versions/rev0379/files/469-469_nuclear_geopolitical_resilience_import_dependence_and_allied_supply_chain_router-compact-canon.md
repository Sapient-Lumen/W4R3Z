# 469 — Nuclear geopolitical resilience, import-dependence, and allied supply-chain router

## Nuclear-positive rule

The cube now favors nuclear where it strengthens clean-firm energy security and reduces fossil exposure, but it no longer treats any nuclear pathway as geopolitically resilient by default. Uranium, conversion, enrichment, HALEU, fabrication, qualified suppliers, spares and strategic inventory are explicit proof burdens.

## Assurance implication

A nuclear project or program can be pro-nuclear and still immature if it replaces fossil dependence with brittle vendor, fuel or sanctions dependence. This router sends those claims to allied supply-chain and strategic-fuel-reserve gates.
