# CHANGELOG — rev0212

## Summary

This revision adds one small front-door canon on **burden shape**.
The archive already said that the clean path should be easy, that the transition should arrive as a coherent offer, and that ordinary necessity should be protected through turnover.
What it still lacked was the shortest explicit rule for **who should carry the administrative, financial, coordination, and risk burden when the clean transition actually happens**.

So rev0212 adds `215`, which says a serious climate programme should move search, proof, cash, coordination, and performance risk upstream as far as honesty allows rather than exporting them to the weaker party.

## Why this belongs

The archive already had deeper doctrine for burden shape (`79`), complete clean offers (`80`), accountable orchestration (`81`), payment form (`70`), and remedy (`74`).
But the front door did not yet state the smallest joined rule plainly enough: **a programme is still weak if the weaker actor must search, front the money, assemble the proof, coordinate the chain, and absorb the miss**.
This revision repairs that gap without creating a new subtree.
