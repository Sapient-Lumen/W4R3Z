# 94 — Ideal Solutions: Archive Topology — Layers, Best First Stops, and Preferred Reading Order

## Claim

The archive now has a strong climate canon, a strong negative canon, and a strong operator layer.
What it still lacked was the shortest explicit map of **where to start** for different tasks.
Rev0092 adds the matching question-router note for readers who arrive with ordinary-language prompts rather than task labels.
That matters because a dense archive can stay small in file count yet still become costly to navigate.

This note adds the shortest topology map in the archive.
It is a **navigation / compression** note, not a new doctrinal branch.
Its job is to lower decision friction for future readers and keep the canon legible without flattening it.

## Fast rule

**Do not start from the deepest note that seems relevant. Start from the smallest layer that can answer the question.**

If the question is already answered by the front door, stop there.
If the task is evaluation, go to the screening layer.
If the task is archive operation, go to the operator layer.
Only then descend into deeper doctrine.
