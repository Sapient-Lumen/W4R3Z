## Claim

The riskiest unfinished work after rev0314 was not another doctrine register. It was the practical operating seam where public feeds, public offsite plans, a scheduled evaluated exercise, and a real public event could be accidentally over-read as local readiness proof.

rev0315 changes that path to:

`public source -> source clock -> endpoint correction -> fetch/hash/parser requirement -> cross-border interface demand -> local packet -> AAR/IP/CAP/retest -> independent verification -> public claim gate`.

A public page, public dataset, future exercise notice, public brochure, raw feed target, or parsed public event can create only a watch, cap, reopen trigger, contradiction, evidence demand, or source-freshness state. It cannot close a local emergency-readiness evidence row.

## Priority corrections

1. **Source-clock and endpoint correction.** Performance-indicator, action-matrix, event-notification, and evaluated-exercise endpoints are separated into canonical targets, legacy aliases, and source-clock holds.
2. **No fake raw-feed import.** The fetch harness records failed raw-feed acquisition attempts as blockers. No feed hash, byte count, or parsed machine row is fabricated.
3. **EN58200 field lock.** The Beaver Valley EOF power-loss public event remains a red-hold public signal until restoration, root-cause, retest, corrective-action closure, independent verification, and redaction evidence are loaded.
4. **Tri-state offsite seam.** Beaver Valley cannot be modeled as a Pennsylvania-only evidence problem. Pennsylvania, Ohio, West Virginia, county, state, FEMA-region, licensee, public-information, route, reception, CRC/decon, ingestion-pathway, medical/AFN, and shadow-evacuation seams are explicit open evidence demands.
5. **ETE and capacity no-upgrade rule.** Public ETE and mass-care numbers are normalized into queryable rows. They remain context and load cases, not route-capacity or shelter-readiness proof.
6. **Future exercise firebreak.** A scheduled exercise is a watch item until official results, AAR/IP, findings, corrective actions, retests, and closures are imported.

## Public claim rule

Allowed claim: "A real public source was imported or registered and mapped to evidence demands."  
Blocked claims: "ready", "green", "certified", "safe", "sufficient", "passed exercise", "current offsite capability proven", "route capacity proven", "reception center capacity proven", or "public source closed the local row".

## Remaining P0 work

The next real closure step is a packet import: EN58200 EOF closure evidence; raw NRC PI/action-matrix/event/exercise feeds fetched and hashed in a networked environment; current PA/OH/WV county/state offsite packets; and post-exercise AAR/IP/CAP/retest evidence after the scheduled exercise window.
