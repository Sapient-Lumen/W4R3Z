# BVPS response intake lockbox rev0371

Use this lockbox for records responses, public-meeting artifacts, ADAMS/PDR releases, and official no-records/nonresponsive replies. Do not edit original received files. Copy originals into an intake drop, complete sidecars, run `tools/intake_bvps_records_response_rev0371.py`, then adjudicate using the contract and proofcut map.

A response is not readiness evidence until it is hashed, sidecar-described, mapped to a request/dispatch and proofcut class, and adjudicated with explicit claim limits.
