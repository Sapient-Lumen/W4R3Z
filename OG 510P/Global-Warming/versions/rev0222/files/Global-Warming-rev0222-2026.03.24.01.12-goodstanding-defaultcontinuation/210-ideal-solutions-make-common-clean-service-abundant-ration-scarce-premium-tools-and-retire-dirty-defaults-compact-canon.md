# 210 — Ideal Solutions: Make Common Clean Service Abundant, Ration Scarce Premium Tools, and Retire Dirty Defaults Compact Canon

## Claim

The archive already has a shortest whole answer (`195`), a physical-jobs note (`208`), a grow/shrink/stop note (`209`), a first-moves note (`193`), a burden-allocation note (`194`), and deeper files on scarcity, industrial residuals, and removals (`29`, `14`, `10`, `11`, `17`).
That is enough doctrine.
But the front door still lacked one tiny substantive bridge:

**what is the archive's resource strategy for the transition itself?**

A serious climate program cannot treat all clean things as equally abundant, all dirty things as equally negotiable, or all hard sectors as excuses for delay.
It needs a clearer front-door rule about what should become common, what should be rationed carefully, and what should be retired on purpose.
This note supplies that rule as a compression note, not a new doctrinal branch [S1][S4][S6][S13][S16][S17][S20][S24][S26][S29].

## Fast rule

**Make common clean service abundant for ordinary uses, ration scarce premium tools to genuine hard cases, and retire dirty defaults instead of protecting them behind delay stories.**

## The three-part resource strategy

### 1. Make common clean service abundant
For ordinary electricity, cooling, heat, mobility, and many building or light-industry uses, the archive's answer is not scarcity theatre.
It is abundant clean electricity, stronger grids, storage, flexibility, efficient buildings and cooling, heat pumps, public and shared mobility where suitable, and financing structures that make these options easy to take up at scale [S4][S5][S6][S13][S14][S16][S17].

House rule: **for common uses, prefer the path that can become cheap, standard, boring, and widely available.**

### 2. Ration scarce premium tools to genuine hard cases
Some tools are scarce, costly, immature, or burdened with major competing claims: sustainable biomass, clean hydrogen and derived fuels, carbon capture, some long-duration balancing assets, and carbon removals.
The archive's rule is to reserve these for uses that remain genuinely hard after efficiency, electrification, demand shaping, material efficiency, and ordinary clean-service substitution have already done their work [S1][S14][S20][S26][S29].

House rule: **do not spend premium tools on tasks that ordinary clean service can do well enough.**

### 3. Retire dirty defaults on purpose
The archive does not treat the dirty system as a neutral incumbent waiting to fade away politely.
Coal, unabated fossil combustion in ordinary uses, wasteful cooling, persistent methane leakage, and repeated lock-in through long-lived dirty assets have to lose institutional protection over time through retirement schedules, stricter standards, subsidy reform, liability, and no-new-lock-in rules [S4][S9][S11][S16][S23][S24].

House rule: **clean growth is not the whole answer if the dirty default stays protected, subsidized, or quietly reproducible.**

## What this note clarifies

This note separates three ideas that are often blurred together:
- **abundance** for the common clean backbone
- **rationing** for scarce premium tools and true residuals
- **retirement** for dirty defaults that should no longer reproduce themselves

If these are blurred, climate programs usually get weaker in one of three ways:
- they ration ordinary clean service and make uptake harder than necessary
- they overspend scarce premium tools on jobs that cheaper and simpler clean options could do
- they keep adding clean assets without closing the door on the inferior dirty path [S4][S6][S13][S20][S24][S29].

Open this note first when the live question is any of the following:
- what the archive means by abundance versus scarcity in climate strategy

Then reopen `29`, `14`, `10`, `17`, `24`, `26`, or `156` if the surviving question is mainly about scarcity allocation, removals boundaries, hard-industry tools, grid and firmness details, coal-retirement design, or burden allocation.

## Compression rule

**The archive's resource strategy is simple: make the common clean backbone abundant, ration scarce premium tools to genuine hard cases, and retire dirty defaults instead of sheltering them behind delay, subsidy, or lock-in.**
