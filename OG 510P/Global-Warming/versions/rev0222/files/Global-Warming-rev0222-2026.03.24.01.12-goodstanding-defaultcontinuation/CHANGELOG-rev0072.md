## Summary
This revision adds a compact **continuity-form** note.
It states the archive’s shortest rule for how clean or safer states should usually survive ordinary handoffs: once a cleaner or safer state has been reached, ordinary moves, tenancy changes, account switches, ownership changes, provider retenders, and rebuilds should preserve it unless material facts changed.

The note is meant to close a real gap between the recent compact notes on eligibility, verification, and remedy. Those notes explained how people get through the door, how routine claims should be proved, and how ordinary failures should be corrected. This revision adds the next rule: **how the gain should usually persist so the user or asset does not keep falling back to the dirty baseline at each handoff.**
