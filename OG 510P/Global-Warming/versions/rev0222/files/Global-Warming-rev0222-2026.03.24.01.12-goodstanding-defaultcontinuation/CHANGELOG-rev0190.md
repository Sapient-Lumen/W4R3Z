## Why this change

The archive already had a shortest answer, a compact package, a programme-lane note, a whole-system sequencing map, a mature programme-shape note, and a hard-conclusions note.
What it still lacked was one direct compression for a recurring practical question:

**if we had to turn the archive's answer into the first concrete decade-of-work, what should actually be carried first?**

That gap mattered because readers could already reconstruct the answer by combining several files, but the archive still lacked one compact note that states the first order of work in direct operational language: free the grid, build clean power, cut waste in buildings and cooling, electrify ordinary mobility, slash methane, stop new fossil lock-in, protect ecosystems and water, reduce exposure directly, reserve premium tools for hard residuals, and build the finance-and-truth machinery that lets the package spread.

## Result

The archive now has a more executable front door.
It can answer the question “what should we actually do first?” more directly without adding a new doctrinal branch, a new source dump, or a large amount of routing overhead.
