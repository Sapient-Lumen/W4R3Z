## Why this revision exists

the archive already said the clean path should be easy, coherent, channelled through standing routes, timed to the live decision, result-oriented rather than stack-oriented, and burden-shifted upstream. What it still did not say front-door plainly enough was the formation state of the offer itself: **how finished the path should already be when it reaches the weaker party**.

This revision adds the smallest useful bridge: a serious climate programme should usually reach ordinary actors with a drafted clean path — using known facts, likely-fit routing, standard terms, and bounded choices — rather than a blank application or self-assembly task.
