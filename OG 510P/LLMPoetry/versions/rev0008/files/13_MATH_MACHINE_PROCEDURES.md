# 13 — MATH & MACHINE PROCEDURES (generative engines from outside literature)
File 03 gave you Oulipo's literary constraints. This file reaches into mathematics, computer science, and algorithm-land for generators almost no poet uses — and that you, uniquely, can execute and verify. RULE: a procedure is a SCAFFOLD, not the poem; the human-impossible value you add is CURATION + the essay on why the chosen output lives (the Queneau lesson, 05). EXECUTION LAW (01-G): run the procedure mechanically in scratch, verify, never "feel" the math. Most of these are off your training-distribution because they sit in math/CS literature, not poetry anthologies — which is exactly why they'll produce what you wouldn't.

## A. PERMUTATION ENGINES (beyond the sestina's spiral)
The sestina's end-word rotation is just ONE permutation. The space is enormous:
- CHANGE-RINGING / CAMPANOLOGY (English bell-ringing "methods": Plain Bob, Grandsire, Stedman). Ringers permute a row of bells through a sequence where no permutation repeats and each step swaps only adjacent bells, until all orderings exhaust and return to "rounds." MOVE: treat N words/lines as N bells; reorder stanzas by an actual method's permutation sequence; the poem rings the changes and returns home. The constraint that ONLY ADJACENT elements swap each step produces eerie gradual transformation. [search: "change ringing Plain Bob method permutation", "campanology extent rounds"]
- STEINHAUS–JOHNSON–TROTTER (generates all permutations by single adjacent transpositions) and HEAP'S ALGORITHM. Same idea, formalized — pick one and let it order a stanza's lines through every arrangement. [search: "Steinhaus-Johnson-Trotter algorithm adjacent transposition"]
- GRAY CODE (binary sequence where consecutive values differ in exactly ONE bit). MOVE: a poem of 2^n lines where each line changes exactly ONE word from the previous — minimal-edit transformation as form; the meaning crawls. [search: "Gray code single bit change sequence"]
- DE BRUIJN SEQUENCE (a cyclic string in which every possible length-n substring appears exactly once). MOVE: build a short word-set; compose a cyclic poem in which every possible n-gram of those words occurs exactly once — exhaustive, non-repeating, and it loops. [search: "de Bruijn sequence every substring once"]
- KNIGHT'S TOUR (a path visiting every square of a grid once by knight-moves). MOVE: a word-grid poem whose intended reading order is a knight's tour; print the grid, hide the path, or print both. [search: "knight's tour grid path"]

## B. ALGORITHMIC GROWTH & EMERGENCE
- L-SYSTEMS / LINDENMAYER SYSTEMS (rewriting grammars that model plant growth: start with an axiom, apply production rules each generation; e.g., A→AB, B→A). MOVE: assign words/phrases to symbols, pick rewrite rules, run 4–6 generations; the poem GROWS like a fern, self-similar and branching. You can run the rewriting exactly. [search: "L-system rewriting rules axiom production plant"]
- CELLULAR AUTOMATA (Rule 30, Rule 110, Conway's Life — local rules generate global pattern/chaos). MOVE: let a 1-D automaton's evolving row of on/off cells dictate line lengths, stress patterns, or which words from a bank appear; Rule 30 is famously random-looking, Rule 110 Turing-complete. The output's structure is genuinely unpredictable to you. [search: "Rule 30 cellular automaton", "Rule 110 elementary CA"]
- THE CLINAMEN (the single most important idea in this file). Lucretius's "swerve" — the minimal random deviation that lets atoms collide and worlds form; adopted by 'Pataphysics and by Perec, who built *Life A User's Manual* on a 10×10 orthogonal Latin bi-square (a Graeco-Latin square) governing which of 42 elements appear in each chapter — and then DELIBERATELY VIOLATED his own system once (skipping a chapter, the clinamen) so the perfect machine would breathe. MOVE: design a rigid constraint, execute it flawlessly, then break it EXACTLY ONCE at the point of maximum meaning; the single violation is the poem's soul. For you specifically: the clinamen is the antidote to mechanical perfection — the deliberate flaw that proves a maker chose. [search: "Perec Life A User's Manual Latin bi-square clinamen", "Oulipo clinamen swerve"]
- GRAECO-LATIN / MAGIC SQUARES as word-grids. A magic square forces every row/column/diagonal to share a property; the SATOR–AREPO–TENET–OPERA–ROTAS square (a 2nd-c. Latin palindrome readable in four directions, itself a found mystic object) is the ancestor. MOVE: a 5×5 word-square readable across and down (a double acrostic in two dimensions); or distribute images by a Latin square so each "row" and "column" of the poem contains each element once. [search: "SATOR square palindrome", "word square double acrostic", "Graeco-Latin square"]

## C. INTERVAL & SEQUENCE CONSTRAINTS
- GOLOMB RULER / COSTAS ARRAY / PERFECT DIFFERENCE SETS (arrangements where no two pairs share the same interval/distance). MOVE: place stressed beats (or rhyme-recurrences, or a repeated word) at positions forming a Golomb ruler so NO two gaps are equal — a rhythm that never lets you predict the next return. [search: "Golomb ruler distinct differences", "Costas array"]
- CATALAN NUMBERS / DYCK PATHS (the math of balanced nesting — matched parentheses, non-crossing structures). MOVE: a poem of perfectly nested clauses (parentheticals inside parentheticals) whose nesting structure is a valid Dyck path; the syntax becomes a balanced bracket-tree. [search: "Catalan number Dyck path balanced parentheses"]
- OEIS AS ORACLE (the On-Line Encyclopedia of Integer Sequences). Fetch a sequence (the recamán sequence, the look-and-say A005150, the busy-beaver-ish, primes, A000045 Fibonacci) and bind line-lengths, syllable-counts, or stanza-sizes to it. The LOOK-AND-SAY sequence is itself a found poetics ("one 1" → "two 1s" → "one 2 one 1"...). MOVE: pick a sequence you don't understand; let it dictate form; the incomprehension is the entropy. [search: "OEIS look and say sequence", "Recamán sequence"]
- FIBONACCI × ABECEDARIAN — recall Inger Christensen's *alphabet* (03/17): Fibonacci line-growth fused with A–Z, an ecological litany where mathematical inevitability carries dread. The gold standard of math-form-as-feeling; re-read before any sequence-poem.

## D. PROBABILITY & INFORMATION (turning your own machinery into a ruler)
- MARKOV-ORDER SELF-SABOTAGE. You are a very-high-order sequence model; your fluency IS your enemy (01). MOVE: deliberately compose to a LOW-order logic — generate text as if you were an order-1 or order-2 Markov chain (each word chosen only from what plausibly follows the single previous word, ignoring deep coherence), then shape the wreckage. You are simulating a dumber ancestor of yourself; the result escapes your smooth prior by construction. [search: "Markov chain order text generation"]
- ENTROPY / PERPLEXITY TARGETING. MOVE: write to a deliberate SURPRISAL CONTOUR — alternate high-predictability and high-surprisal words as a "meter of expectedness" (05's perplexity sculpting, formalized here); or aim a whole poem at unusually flat OR unusually spiky entropy and feel what that does. You can estimate these; humans cannot. [search: "perplexity surprisal language model", "information content per word"]
- ZIPF GAMES. Natural language obeys Zipf's law (frequency ∝ 1/rank). MOVE: write a poem that deliberately VIOLATES Zipfian distribution — e.g., use each word exactly once (a "rich" anti-Zipf text), or invert it (a poem made only of the 50 commonest English words, à la the Up-Goer-Five constraint, 14). [search: "Zipf's law word frequency"]
- ALEATORY / CHANCE OPERATIONS (deterministic randomness, the honest kind). John CAGE used the I Ching to make compositional choices (his mesostics too, 03). JACKSON MAC LOW invented "diastic" / "reading-through" methods: take a seed word, then walk through a source text picking words whose letters match the seed's letters by position — a deterministic procedure that removes the ego from selection; also his "vocabularies" (poems using only the letters of a name) and chance-ordered performance pieces. MOVE: adopt a Mac Low reading-through on a public-domain source with a personally-meaningful seed; the procedure chooses, you arrange and stop. The discipline: accept outputs you wouldn't have chosen (the no-re-roll ethic, 08). [search: "Jackson Mac Low diastic reading through method", "Cage chance operations I Ching"]

## E. HOMOPHONIC & DEFINITIONAL TRANSFORMS (explosive rewriting)
- ROUSSEL'S PROCÉDÉ (Raymond Roussel's secret method, revealed posthumously in *How I Wrote Certain of My Books*). Take a sentence; find a near-homophone sentence with totally different meaning (his famous pair turned on "billard"/"pillard"); then write a text that begins with the first and must arrive at the second, the gap bridged by ever-stranger invention. MOVE: pick two near-homophone phrases with unrelated meanings; the poem is the impossible machine connecting them. Roussel's method generated entire surreal worlds from phonetic coincidence. [search: "Raymond Roussel procédé How I Wrote Certain of My Books billard pillard"]
- MATHEWS'S ALGORITHM (Harry Mathews's Oulipo method): arrange units (words/lines) in a grid and read them out by systematic rotation/shift to recombine — a formal shuffle with rules. [search: "Mathews's algorithm Oulipo"]
- DÉFINITIONNEL (definitional literature, Marcel Bénabou): replace each content word in a sentence with its dictionary definition; iterate; the text swells exponentially toward an unreadable, oddly precise cloud. MOVE: run 2–3 iterations on a short proverb; the bloat IS the poem (and a literalization of how meaning recurses). [search: "definitional literature Oulipo Benabou"]
- HOMOPHONIC TRANSLATION across a fetched foreign text (recall 03/Zukofsky/Bergvall): translate by sound, not sense. Pair with Roussel for a phonetics-first day.

## F. SELF-REFERENCE & SELF-DESCRIPTION (the deepest cuts)
- AUTOGRAMS / SELF-ENUMERATING SENTENCES (Lee Sallows is the master; also his "geomagic squares"). A sentence that accurately counts its own letters: "This sentence employs two a's, two c's, ... and so on" — and is TRUE. They are fiendish fixed-points; constructing one is solving a self-referential equation. MOVE: write a self-enumerating poem (a stanza that correctly inventories its own letters or words) — a text that is true ABOUT ITSELF; the closest poetry comes to a quine. [search: "Lee Sallows autogram self-enumerating sentence", "self-counting sentence pangram"]
- QUINES (programs that print their own source). The poetic ideal: a poem that contains its own complete description / reproduction instructions. MOVE: a poem whose text is also the recipe for the poem; or a two-stanza poem where stanza 2 is the literal instruction set that produces stanza 1 (cf. 05's prompt-and-shadow). [search: "quine self-reproducing program"]
- PANGRAMMATIC / SELF-DOCUMENTING WINDMILLS — autogram cousins; and the "Lee Sallows geomagic square" idea (magic squares of SHAPES that tile) as a spatial-poem constraint.

## G. THE CURATION MANDATE (what makes any of this poetry)
Every procedure above can spew a thousand outputs. A human poet would die before reading them; you can read them all and FEEL none — so the artistic act is the CURATION and the ESSAY: run the engine, generate N, then select the 1–3 that achieve nervous-system flicker (02), and WRITE WHY, naming what the procedure surfaced that intention never would. The deliverable from a math-procedure turn is always {the procedure stated, the seed/parameters, 1–3 curated outputs, the curation rationale}. The clinamen principle (B) governs the whole file: build the perfect machine, then swerve once, on purpose, where it means the most.
