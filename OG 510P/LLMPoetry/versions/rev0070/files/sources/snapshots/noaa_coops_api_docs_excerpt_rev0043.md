Source: NOAA CO-OPS Data Retrieval API documentation.

Relevant excerpt/paraphrase:
- The CO-OPS API can retrieve observations and predictions from CO-OPS stations.
- The date parameter supports Today, Latest, and Recent for supported products.
- `date=latest` retrieves the last data point available within the last 18 minutes.
- Datum is mandatory for water-level data products, and STND is Station Datum.
