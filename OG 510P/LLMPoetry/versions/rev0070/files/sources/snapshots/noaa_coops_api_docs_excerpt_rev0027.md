Operator excerpt facts used by P0002-D003:

- The CO-OPS Data Retrieval API can retrieve observations and predictions from CO-OPS stations.
- For the `date` parameter, `latest` retrieves the last data point available within the last 18 minutes.
- The API documentation states that datum is mandatory for water-level products and that `datum=MLLW` retrieves heights relative to Mean Lower Low Water.
