# Cold review — P0002-D021 on D021 — rev0053

## Judgment

D021 was useful because it stopped giving a body-level datum lesson. It found a real absence in the NOAA benchmark table: the official table has columns for datum water, while rain crossing the dock has no column and leaves no height behind.

But the draft softened the pressure too much. Rain let the poem become weather; `official weather`, `darkened / the stamped no`, and `water arrived / without a name / that would hold still` turned the benchmark object into a graceful metaphor rather than making the NOAA table language stranger. The lower-boards echo also pulled the poem backward into an older P0002 motif instead of forcing a new pressure.

The stronger source feature is closer to the table itself: `Stamping or Designation`. NOAA's sheet gives the primary benchmark both a stamped mark and a designation. That split is materially stranger than rain: one name is hammered into the object, the other lives in the table/office system.

## Required consequence

Do not promote D021. A successor may be justified only if it cuts rain/weather as the central conceit, preserves the official benchmark table and datum/elevation facts in packet/disclosure context, and tests the source language `Stamping or Designation` without turning the body into another table dump.
