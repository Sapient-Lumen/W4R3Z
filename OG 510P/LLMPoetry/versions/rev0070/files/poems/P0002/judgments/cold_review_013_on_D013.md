# Cold review — P0002-D013 on D013 — rev0045

Target: `P0002-D013`, “The Disk in the Loading Dock”  
Review revision: `rev0045`  
Verdict: `revise_not_promote`

## Finding

D013 is a real advance over D012. It stops trying to make the route itself carry the poem and finds a smaller source object: the tidal disk set in the concrete loading dock near the blue brick guard house. The body also preserves the useful no-value hinge:

```text
No value came back.

Water did.
```

But D013 still turns too quickly from object to thesis. The ending explains the benchmark as an argument:

```text
Because water
needs something
it can be wrong against.
```

That is intelligent, but it closes the poem as a concept. The disk becomes a philosophical instrument rather than a marked thing in concrete. The opening also still inherits D012's route pressure, and `does not look up` / `stillness wins` gives the disk too much ready-made allegory.

## What should change

The next revision should keep the object and cut the thesis. Use the source's stamped-mark facts instead of abstract closure: `NO 7 1975`, tidal station disk, loading dock, above ground, blue brick guard house. Let the stamped name and dock carry the pressure. Allow a tiny numeric exception for the stamped object name if the body stays otherwise non-table-like.

## Boundary

This is not a reader response and not evidence. No poem is admitted. No live NOAA water-level value is claimed. D013 should remain preserved as a useful failed object reanchor, not promoted.
