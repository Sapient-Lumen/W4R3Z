# Machine-native form pilots

Candidate pilots for early LLMPoetry work:

1. **Semantic-meter poem**: lineation controlled by meaning-distance rather than syllable count.
2. **Prompt-reply diptych**: the prompt is visible and formally necessary; answer and prompt revise each other.
3. **Branch poem**: multiple continuations kept as a visible tree with a chosen path and rejected ghosts.
4. **Tokenizer lineation**: BPE/token boundaries are used as line or stanza pressure, with a tokenizer receipt.
5. **Surprisal contour poem**: draft variants are selected to shape predictability over time.
6. **Retroactive delta poem**: ending forces measurable reinterpretation of beginning; revision note records the delta.

Each pilot needs a verification plan before it is called machine-native.
