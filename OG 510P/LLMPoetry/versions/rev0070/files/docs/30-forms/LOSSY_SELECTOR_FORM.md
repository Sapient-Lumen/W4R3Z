# Form: lossy selector-vector branch lattice

A lossy selector-vector branch lattice is a branch poem whose visible selected path is deliberately compressed. The discarded candidates are not merely process notes: their final words recover a shadow sentence. Exact selected-line spans then map to fixed shadow slices.

Minimum record:

1. branch packet with equal candidate counts per layer;
2. one selected candidate per layer;
3. selected path acrostic claim;
4. unselected-final-word shadow sentence;
5. rendered draft surface;
6. selector map with exact/start/end spans;
7. selector vector mapping selected spans to shadow slices;
8. loss-budget receipt measuring how much explanatory machinery remains on the selected surface;
9. same-turn judgment firewall.

D005 variant:

- selected initials: `LOSSY`;
- five selected lines;
- twenty candidates total;
- fifteen omitted candidates;
- fifteen-word shadow sentence;
- five three-word shadow slices;
- zero selected-surface meta-term hits by `tools/build_loss_budget.py`.

Risk: the surface can become too slight or cryptic. The loss budget must not be mistaken for literary value.
