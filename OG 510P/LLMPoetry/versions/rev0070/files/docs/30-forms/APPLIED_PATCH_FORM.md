# Applied Patch State-Switch Branch Lattice

Status: pilot form introduced in `rev0021` for `P0001-D010`.

The applied-patch form exists because earlier branch-lattice drafts could validate routes, selector vectors, state switches, and changed returns while leaving the word `patch` as a metaphor. This form requires the route to mutate text.

## Required parts

1. A selected closed surface whose line initials spell a declared word.
2. An omitted-branch shadow sentence recovered from final words.
3. A selector-vector open state that appends fixed shadow slices to selected lines.
4. An ergodic traversal sentence generated by selected final-word lengths.
5. A patch table in which each route word authorizes one replacement against one selected line.
6. A patched surface rendered into the draft.
7. A `patch_application_####.json` receipt proving the replacements.

## P0001-D010 instance

Selected initials: `PATCHED`.

Traversal / patch sentence:

```text
splice vowel until syntax learns another surface
```

The seven route words become seven replacement operations. Validation proves only that the transform occurred as declared. It does not prove that the result is a good poem.

## Risk

This form can easily become procedural theater: the patch may be real but aesthetically inert. The next cold review must ask whether the patched state creates new pressure or merely performs a bookkeeping trick.
