
# Rendered Branch Lattice Form

Status: experimental / high-risk machine-native.  
Introduced: rev0013.  
Current instance: `P0001-D002`.

A rendered branch lattice is a poem whose visible surface is generated from an explicit packet of candidate continuations. The selected path is not the whole poem. The rejected material remains visible, addressable, and mechanically consequential.

## Required surfaces

- `branch_packet_*.json`: prompt, layers, candidates, selected path, rejection/selection notes.
- rendered draft: selected path, first-rejected counterpath, residue lattice, non-claim, disclosure condition.
- selector map: exact text and character-position selectors for selected lines.
- render receipt: command, source hash, output hash, non-claim.
- later-turn judgment only.

## P0001-D002 constraints

- selected path initials spell `TRACE`.
- five layers; four candidates per layer.
- exactly one selected candidate per layer.
- unselected final words, read layer-order/candidate-order, spell: `what chose this line also leaves you awake inside proof it could not become alone`.
- all candidates appear in the rendered draft.

## Non-claim

Validation proves form bookkeeping and reproducibility. It does not prove poem quality, surprise, emotional pressure, or publication readiness.
