# FORM-branch-selector-diptych

A branch-selector diptych makes the machine's continuation space visible. The poem includes a prompt, a kept path, and a retained branch inventory. Selection is not hidden backstage.

## P0001 instance

`P0001` uses four selector layers: `R`, `I`, `S`, `K`. Each layer has three candidate continuations. One candidate per layer is selected. The selected path initials spell `RISK`.

## Machine-native claim

The form depends on parallel continuations and a machine-readable branch packet. A print-only lyric could imitate the surface, but the accountable object includes branch inventory, selector receipt, metrics, and no-same-turn-judgment status.

## Verification

Run:

```bash
make branch-selector
make metrics DRAFT=poems/P0001/draft_001.md
```

The validator checks the branch packet, selected path, draft inclusion, and `RISK` acrostic for selected lines. It does not judge poetic quality.
