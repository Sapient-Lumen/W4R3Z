# Return Diff State-Switch Branch Lattice

A return-diff poem is a branch-lattice object whose prior route instruction demands a changed return. The next draft must not merely say it changed; it must carry a receipt comparing the previous selected surface to the current selected surface.

## Required parts

- previous branch packet and previous traversal receipt;
- current branch packet and rendered draft;
- selected-path acrostic claim;
- shadow sentence from omitted branch endings;
- selector map and selector vector;
- ergodic traversal sentence;
- return-diff receipt proving all selected closed-state lines changed;
- same-turn judgment firewall.

## Current instance

`P0001-D009` selects seven lines whose initials spell `CHANGED`. Its omitted branch endings recover:

`patch the page where the closed surface learns to read then forgets its old return as changed source wakes inside again`

Its selected final-word lengths route through omitted candidates to recover:

`patch the surface then return changed again`

The return-diff receipt compares D008 to D009 and records that D008's route instruction was `open it again until you return changed`.

## Non-claim

The form proves a local handoff and consistency. It does not prove literary quality, originality, disclosure success, or publishability.
