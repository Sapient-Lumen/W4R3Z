# Reentry runbook

A future operator can resume from this archive without private memory.

- Use `START_HERE.md` for the entrypoint.
- Use `STATE.json` for current phase and turn.
- Use `registries/research_pulse_index.json` to verify the research-every-turn law.
- Use `FRONTIER_TICKET.json` and `HUMAN_QUESTIONS.json` to decide the next fork.
- Use `poems/P0001/metadata.json` if beginning the first poem.

If any surface disagrees, trust the latest packaged `REVISION_RECEIPT.json` and validation report, then repair the mismatch explicitly.
