## Cold review of D007

Verdict: revise-not-promote.

D007 made a real advance: selected line-end words routed into omitted branch candidates, which meant the closed surface could produce a traversed state rather than merely receive appended loss triplets. The formal mechanism worked.

The failure was poetic pressure. The surface still leaned on familiar P0001 machinery words and digital atmospherics: glass, hinge, cursor, screen, keys, gate, signal, engine, route, selected, branches, display, machine, disclosure. The traversal sentence, `route enacted when branches make reader cross elsewhere`, confirmed the mechanism but sounded like a caption for the receipt. The reader did work, but the work mostly proved the bookkeeping.

## Revision principle

D008 keeps the machine-native route but compresses it into a recursive instruction. The selected surface becomes a seven-line closed state. Every selected final word is exactly three letters long. Because each layer has three omitted candidates, the existing traversal rule produces route index `0` in every layer.

That zero-route state yields:

```text
open it again until you return changed
```

The route sentence is no longer a description of the form; it is an instruction produced by the form.

## New pressure

D008 tests whether a formally trivial route vector — all zeroes — can be poetically less trivial than a more varied route. The wager is that a repeated `0` path can become recursion: the selected surface keeps closing, the omitted first path says to reopen, and the reader/LLM returns to the surface altered by the route.
