# Accessible machine-native surfaces

High-risk machine-native forms may be complex, but avoidable inaccessibility is not the same as difficulty.

For LLMPoetry, every machine-native poem should eventually provide:

- a canonical text view;
- a machine-readable packet;
- a human-readable explanation of what the machine layer changes;
- a fallback route that preserves the core act of reading when code, animation, or interactivity is unavailable.

This does not require flattening the work. It requires identifying which mechanics are essential and making their meaning available through more than one path when possible.
