# P0001 D004 cold review and D005 revision

D004 was eligible for cold review because it was created in the previous project turn. It was marked revise-not-promote.

The useful discovery in D004 was selector-vector addressability: selected-line spans can fetch shadow-sentence slices. The failure was surface contamination. The selected path still said `coordinate`, `address`, `characters`, `selector`, `metaphor`, `omitted branches`, and `disclosure`; these were accurate, but too explanatory.

D005 therefore keeps the machinery and changes the surface-pressure rule:

- selected path initials must spell `LOSSY`;
- the selected surface should contain zero loss-budget meta terms;
- omitted branch endings must spell a 15-word shadow sentence;
- selected-line spans must fetch the shadow in five three-word slices;
- the loss budget must record visible selected-word count, omitted candidate count, shadow count, and selected meta-term hits.

D005 is same-turn unjudged. The loss budget is a craft-pressure receipt, not a quality proof.
