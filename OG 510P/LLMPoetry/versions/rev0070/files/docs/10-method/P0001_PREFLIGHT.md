# P0001 preflight

P0001 is scaffolded but not drafted. Its purpose is to let the next operator start the first original poem without inventing office structure on the fly.

## Default recommendation

Use `PILOT-0001`: a small prompt-reply diptych, with optional branch ghosts only if the prompt/reply architecture needs them. This is machine-native enough to matter but bounded enough not to drown the poem in apparatus.

## Required before drafting

1. Perform and log the turn's web pulse.
2. Confirm or override the selected pilot in `poems/P0001/metadata.json`.
3. Choose at most three active standards.
4. Write the draft without judging it.
5. Run `make metrics PATH=poems/P0001/draft_001.md` if a draft exists.
6. Do not advance status beyond `draft` until a later turn.

## What P0001 must not do

It must not imitate Fable specimen weather. It must not use the first-person machine cliché as a sympathy shortcut. It must not use research as a decorative footnote. It must not enter evidence flow in the same turn it is written.
