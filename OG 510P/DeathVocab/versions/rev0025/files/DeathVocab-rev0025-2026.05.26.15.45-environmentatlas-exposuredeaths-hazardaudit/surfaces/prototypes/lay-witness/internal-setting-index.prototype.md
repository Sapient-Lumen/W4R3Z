# Internal prototype: setting index

This is not public. It demonstrates how a lay index might ask: Where did this happen?

- At home: `DV-REC-000130`, `DV-REC-000131`
- In a hospice facility: `DV-REC-000132`
- In hospital/ICU/ED: `DV-REC-000133`, `DV-REC-000134`, `DV-REC-000135`
- In an ambulance or doorway: `DV-REC-000136`
- In a nursing home or residential facility: `DV-REC-000137`, `DV-REC-000138`
- Alone or unwitnessed: `DV-REC-000139`
- In custody, street, shelter, overdose, suicide, or violent setting: high-gate only
- Disaster/war/no-body: high-gate only
- Maternal/perinatal/pediatric: highest-gate only
- Funeral home/morgue/cemetery/crematory: professional-review only

No record here is public-facing.
