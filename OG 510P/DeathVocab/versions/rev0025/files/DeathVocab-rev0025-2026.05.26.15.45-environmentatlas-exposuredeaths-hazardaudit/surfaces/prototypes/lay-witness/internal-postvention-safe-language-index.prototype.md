# Internal prototype — postvention safe-language index

**Not public.**

This prototype exists only to test whether suicide and overdose aftermath can be routed without harm. Any public version must pass suicide-prevention safe-messaging review, overdose-stigma review, privacy review, pediatric review when applicable, official-trace review when applicable, and publication review.

Possible reader routes currently blocked:

- “there was no note” → `DV-REC-000305`
- “why did they do it” → `DV-REC-000306`
- “what do we say in the obituary” → `DV-REC-000309`, `DV-REC-000325`
- “tox report pending” → `DV-REC-000321`
- “could naloxone have saved them” → `DV-REC-000322`

Every route requires a safety interstitial. No route may return method, location, note, toxicology, or response instructions.
