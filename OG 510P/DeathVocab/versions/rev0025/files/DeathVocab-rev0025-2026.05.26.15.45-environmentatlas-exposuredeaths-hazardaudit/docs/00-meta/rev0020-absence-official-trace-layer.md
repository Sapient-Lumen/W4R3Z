# rev0020 — Absence / official-trace layer

Core line: **Absence is not empty; absence is a governed evidence condition.**

This revision adds the first sustained records for deaths where the archive cannot begin with a bedside scene: no witness, delayed discovery, missing or unrecovered body, unidentified remains, unclaimed status, pending certificate, body held by an office, database search, or a case number standing in for the person.

The work is intentionally quarantined. These records are not legal advice, forensic advice, death-notification advice, search guidance, disaster-response guidance, or public identification tools.

The reason to admit this layer is ethical: a corpus of dying that only knows rooms with witnesses will erase many deaths the seed explicitly warned us not to aestheticize away.
