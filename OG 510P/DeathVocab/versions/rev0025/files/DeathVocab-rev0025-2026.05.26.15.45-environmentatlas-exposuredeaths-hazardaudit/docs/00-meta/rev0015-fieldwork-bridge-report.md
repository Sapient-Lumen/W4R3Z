# Rev0015 fieldwork bridge report

Rev0015 deliberately adds no records. The cube had just been audited; the next danger was to mistake auditability for readiness. It is not ready to receive private grief.

The seed asks for a corpus of bedside knowledge that is mostly oral, role-distributed, culturally fragmented, and underwritten. That means DeathVocab eventually has to learn from living witnesses. But the archive must not begin by harvesting the most vulnerable stories.

## What changed

This revision adds the machinery for a future consent dry run:

- fieldwork charter
- contributor consent state machine
- testimony intake schema
- role-specific interview protocols
- quote and paraphrase gate
- de-identification and recontextualization standard
- distress and stop protocol
- compensation and credit ledger
- data custody/access control ledger
- fieldwork review board charter
- source acquisition triage matrix
- pilot interview dry-run packet
- contributor form drafts
- fieldwork review packets
- six fieldwork-process source cards

## The core distinction

**A protocol is not permission.**

Rev0015 creates enough structure to simulate the journey from invitation to withdrawal using fictional or harmless material. It does not authorize real recruitment, real testimony collection, public quotes, or public records.

## Why no new records

Record growth is easy. Ethical fieldwork is not. DeathVocab should earn the right to ask before it asks.

## Suggested next move

Run `PILOT-INTERVIEW-DRYRUN-PACKET.json` with fictional non-death material. Force the dry run to include one stop request, one quote rejection, one de-identification failure, and one withdrawal. Update the cube with what breaks.
