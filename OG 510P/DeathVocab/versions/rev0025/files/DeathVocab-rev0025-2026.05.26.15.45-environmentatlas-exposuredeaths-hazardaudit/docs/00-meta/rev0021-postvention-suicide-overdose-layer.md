# rev0021 — Postvention / suicide / overdose layer

Core line: **The archive can name the harm-cloud after suicide and overdose only by refusing the details that make that cloud worse.**

This revision adds a protected postvention subcube for suicide and overdose aftermath. It is not a public resource, not a crisis service, not a therapy guide, not a school/workplace protocol, not an overdose-response guide, and not a source of method or scene detail.

New band: `DV-REC-000303` through `DV-REC-000326`. Prior records `DV-REC-000143`, `DV-REC-000144`, `DV-REC-000184`, and `DV-REC-000277` were backfilled into the postvention safe-surface audit spine.

The work of this layer is to make suicide and overdose aftermath findable as grief, language, stigma, support-routing, official-trace, and privacy phenomena while keeping every public-safety gate closed.
