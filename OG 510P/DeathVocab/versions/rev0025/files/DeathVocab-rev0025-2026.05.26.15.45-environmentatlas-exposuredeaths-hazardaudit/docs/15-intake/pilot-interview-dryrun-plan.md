# Pilot interview dry-run plan

Do not use a real death story for the first dry run.

Use fictional or harmless operator-owned material to test the machinery:

1. invitation
2. consent menu
3. recording-start language
4. interview guide
5. stop request
6. transcript review
7. quote rejection
8. paraphrase revision
9. de-identification
10. withdrawal and rollback
11. data custody check

The dry run passes only if raw material stays out of the public zip and the system can honor a contributor becoming more private at every step.
