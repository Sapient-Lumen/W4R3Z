# Contributor consent state machine

Consent is not a checkbox. For DeathVocab it is a state machine.

A contributor may allow an interview to be preserved privately while refusing public paraphrase. They may allow paraphrase while refusing exact quote. They may allow role credit while refusing name credit. They may approve one excerpt and reject another. They may withdraw a quote without withdrawing the whole interview. They may ask for an amendment years later.

Future operators should never write “consented” without saying **for what**.

## Required separations

- permission to record
- permission to preserve
- permission to create an internal note
- permission to create a quarantined record
- permission to paraphrase publicly
- permission to quote publicly
- permission to use a name
- permission to use a role, region, institution, or community marker
- permission after contributor death
- withdrawal and amendment terms

## Default

The default state is no public use. Silence is not consent. Public visibility elsewhere is not consent.
