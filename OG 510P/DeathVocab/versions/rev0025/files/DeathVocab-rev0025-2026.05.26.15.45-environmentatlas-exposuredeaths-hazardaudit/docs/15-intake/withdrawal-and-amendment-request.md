# Withdrawal and amendment request path

A contributor can ask to amend, contextualize, restrict, or withdraw a contribution.

## Request minimum

The archive should ask only enough to identify the contribution and the requester’s relationship to it. It should not demand a detailed justification.

## Actions

1. Freeze the record.
2. Remove public surfaces if any exist.
3. Mark derived records, glossary entries, search aliases, and teaching pages as affected.
4. Decide whether the record becomes withdrawn, restricted, amended, or retracted.
5. Record the action in the rollback ledger.
6. Confirm when possible.

## Principle

A withdrawal is not a failure of the archive. It is proof that the archive has not mistaken access for ownership.
