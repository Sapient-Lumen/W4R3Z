# Held-source triage

Some sources are tempting precisely because they are vivid. Rev0004 records why several source classes are not yet mined.

Public grief posts are not consent. Social media virality is not permission. PDF leaflets need a disciplined PDF extraction workflow. Death-clock material is structurally dangerous for this corpus. High-gate domains need policy and review before extraction.

See `HELD-SOURCE-TRIAGE.json`.
