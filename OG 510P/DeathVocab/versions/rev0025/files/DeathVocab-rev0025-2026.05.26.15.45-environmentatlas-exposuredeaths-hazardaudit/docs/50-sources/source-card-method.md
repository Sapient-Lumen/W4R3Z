# Source-card method

Revision: rev0005

A source card states how a source may and may not be used. This matters because family-facing sources, professional guidelines, and after-death checklists can all be misrendered if collapsed into advice.

A source card records:

- source ID;
- source title and organization;
- ladder level;
- usable claims;
- forbidden uses;
- dependent records;
- review notes.

Rev0005 creates source cards for the sources that anchor the new practice layer.
