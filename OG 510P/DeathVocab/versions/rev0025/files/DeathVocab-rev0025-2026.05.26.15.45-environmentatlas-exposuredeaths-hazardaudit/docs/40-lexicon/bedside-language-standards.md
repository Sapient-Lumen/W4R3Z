# Bedside language standards

Revision: rev0005

DeathVocab should sound like an experienced hospice worker speaking to a colleague: precise, kind, unsentimental, specific, and unafraid. Rev0005 adds draft language standards for practice records.

The current standards are:

- possibility language before certainty;
- no guilt syntax;
- no instruction by implication;
- body dignity before body detail;
- jurisdiction humility after death.

These are blocking standards for any future lay surface.
