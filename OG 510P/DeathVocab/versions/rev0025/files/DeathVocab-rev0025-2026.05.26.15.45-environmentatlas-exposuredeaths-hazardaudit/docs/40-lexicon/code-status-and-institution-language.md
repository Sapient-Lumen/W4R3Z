# Code status and institution language

Terms admitted in rev0007 include advance directive, health care proxy, surrogate, code status, full code, DNR, DNACPR, DNI, allow natural death, POLST, MOLST, comfort measures only, withholding, withdrawing, palliative extubation, palliative sedation, anticipatory medicines, VSED, MAID, brain death, death by neurologic criteria, DCD, OPO, honor walk, heroic measures, and ethics consult.

These are glossary handles into witnessed moments. They are not stable universal definitions. Many are jurisdiction-specific, institution-specific, or professionally defined. Any future public glossary must carry source IDs, review gates, and “what this is not” cautions beside the term.
