# Review packet protocol

Revision: rev0005

The archive now separates drafting from review. A review packet is a bounded bundle of records plus questions for the relevant reviewer. Packets are designed to produce review deltas, not invisible rewrites.

Packet outputs should be stored as future review artifacts with:

- reviewer role and scope;
- records reviewed;
- source claims accepted, narrowed, or rejected;
- language changes requested;
- publication state changes proposed;
- unresolved debts.

No record may leave quarantine because it “sounds right.”
