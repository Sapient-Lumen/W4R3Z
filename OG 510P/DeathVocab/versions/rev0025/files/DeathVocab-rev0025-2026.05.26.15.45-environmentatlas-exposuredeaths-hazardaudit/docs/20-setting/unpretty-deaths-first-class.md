# Unpretty deaths are first-class in quarantine

The seed warns against an archive that becomes an aesthetic of peaceful hospice rooms. Rev0011 responds by admitting custody, street, overdose, suicide aftermath, violent, disaster, war, unrecovered-body, maternal, perinatal, pediatric, and after-body professional settings as first-class records — but only in quarantine.

Naming a lane is not permission to publish scenes from it. These records exist so future work must build review, consent, anti-spectacle, safe-messaging, legal, humanitarian, and child-safeguarding gates before any public rendering is considered.
