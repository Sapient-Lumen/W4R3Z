# Open question registry

## OQ-0001 — Which parts of the course grammar should be standardized across institutions, and which should stay local?

The archive now has a small syntax for task mode, disclosure, and proof, but it remains unclear how much of that grammar should become schoolwide or sector-wide convention rather than staying teacher- or program-specific.

## OQ-0002 — What teacher visibility is enough without becoming surveillance?

Institutions need legibility into AI-mediated learning, but too much logging or monitoring could become developmentally harmful or politically corrosive.

## OQ-0003 — Which proof-of-learning bundles are labor-plausible at scale?

The archive now names default bundle patterns, but more work is needed on labor cost, sampling frequency, and which bundles should be reserved for major outcomes rather than ordinary practice.

## OQ-0004 — When do general-purpose models suffice, and when are purpose-built tools necessary?

The archive leans toward pedagogy-shaped tools, but institutions will often start with general-purpose systems. The boundary conditions need refinement.

## OQ-0005 — Which access-support categories can be presumed allowed across most courses without artifact-level disclosure?

The archive now has a two-channel rule, but it still needs a sharper map of which supports should be institutionally pre-cleared across most courses and which need local override because the construct being assessed changes by discipline, age band, or sector.

## OQ-0006 — What should count as scale-worthy evidence after a pilot succeeds?

The archive now specifies a minimum package by stake level, but the threshold for district-, state-, or university-wide rollout remains underspecified.

## OQ-0008 — When a system-caused route change still requires a bridge, challenge, or substitute-equivalent step, which fees and support costs must the system absorb?

The archive now has a documented-reliance and burden grammar, but it still lacks a sharper cross-sector rule for when bridge modules, reassessment, fee waivers, transcript movement, travel, accessibility support, or lost-cycle costs should be borne by the receiving/public system rather than pushed back onto the learner.
