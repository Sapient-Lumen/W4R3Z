# rev0325 mission kernel

The mission remains pedagogy first: help education systems use AI to strengthen learning, teacher/tutor judgment, access, contestability, and institutional truth without turning absence of evidence into automation authority.

The current live work is not policy expansion. It is field execution:

1. cross or honestly block the `FT-0181` accountable-owner boundary;
2. run one bounded teacher/tutor augmentation micro-cycle with aggregate-only capture;
3. preserve the distinction between local operator support, local descriptive result receipts, and accepted evidence.

## rev0325 center of gravity

Rev0325 adds a single scratch-local field handoff bundle command:

```bash
make field-handoff-bundle OVERWRITE=1
```

This command prepares the owner request packet and the equality-one-step teacher/tutor micro-pilot packet in one local bundle. It is meant to make the next human action obvious without requiring the operator to reassemble surfaces from registries, release examples, or branch history.

## Current no-expansion rule

Do not add a new doctrine surface, validator, schema, branch family, or public-claim rule until one of these things happens:

- a human sends the bounded owner request;
- a route block is recorded;
- an owner-attested packet returns;
- a real aggregate micro-pilot packet is completed locally;
- owner review or result receipt records are created from a real packet;
- a release check finds a reproducible source-truth defect.

## Boundary

Rev0325 does not contact an owner, send a message, run a pilot, accept evidence, record human review, record a real local result, change service authority, support a public claim, or close `FT-0181`.
