# Mission kernel — rev0330

The mission remains learner independence through better teacher/tutor judgment. AI may suggest a
probing question, misconception check, or smallest-useful hint after a learner attempt, but the human
owner chooses, edits, or rejects every move.

1. Find one real teacher/tutor owner.
2. Select one local instructional problem and concept.
3. Complete the owner plan, including tool/version, participation/fallback, protected local review,
   and a numeric small-cell threshold of at least three.
4. Run at most one locally approved feasibility/usability cycle.
5. Record only aggregate rows, then stop for human owner review.
6. If a local result receipt is recorded, mask counts/rates below threshold and keep exact small-cell
   values local.

## What rev0330 changes

Rev0329 made the first cycle possible. Rev0330 makes the first result safer: exact tiny counts and
transfer-minus-baseline rates must not become the next fake proof object. The receipt can support a
local stop, redesign, or narrower repeat decision only.
