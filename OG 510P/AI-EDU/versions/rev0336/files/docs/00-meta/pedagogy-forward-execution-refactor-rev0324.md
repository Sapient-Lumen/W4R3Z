# rev0324 pedagogy-forward execution refactor

## Refactor target

The cube's bad habit is to turn absence of field action into more registry
language. Rev0324 trims that impulse by extending the teacher/tutor path only at
the point where a real local cycle would otherwise lose its result boundary.

## Hot path after rev0324

1. `make micro-pilot-next` tells the operator whether to prepare, complete,
   discard synthetic rehearsal, record owner review, record result, or stop.
2. `make micro-pilot-pack` creates the scratch packet.
3. `make micro-pilot-readiness` blocks blank or unsafe packets.
4. `make micro-pilot-owner-review` records the human owner-review stop.
5. `make micro-pilot-result` records the local aggregate result receipt.

No new schema is introduced. No service authority changes. No evidence claim is
upgraded.

## What moved out of the hot path

The operator should not open branch-family history, broad governance profiles,
release-control examples, or public-claim lexicons to finish one micro-cycle.
Those surfaces remain cold retrieval unless a real result or validator failure
requires them.

## Boundary

The result receipt is a local descriptive artifact. It does not prove learning or
workload improvement, does not accept `SRC2+`, and does not close `FT-0181`.
