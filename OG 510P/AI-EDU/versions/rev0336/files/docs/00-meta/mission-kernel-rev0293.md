# rev0293 mission kernel

The mission remains: protect learning, learner agency, access, teacher capacity,
contestability, source provenance, and public-claim humility before AI systems
gain quiet authority in education.

## rev0293 kernel change

`rev0293` moves the live rail one seam closer to real owner evidence without
pretending the archive can perform field action. `rev0292` made clean local
packet prep executable. `rev0293` compresses the next fragile seam: after a real
human send/adaptation, one guarded helper now records both the minimal local
send log and the sourced `SENT_AWAITING_REPLY` contact clock.

The new target is:

```bash
make owner-after-human-send \
  PACKET=scratch/owner-request-packets/aiedu-sr-003-first-contact/packet-manifest.json \
  CONFIRM=human-sent-bounded-owner-request
```

It may be run only after the human send/adaptation actually happened. It does
not send mail, infer an owner, store recipient details, import owner answers,
create evidence, upgrade source truth, start custody, support public claims,
move lifecycle state, or close `FT-0181`.

## Heart of the mission

The heart is still not a broader AI policy apparatus. It is an education system
where AI support remains answerable to learning, access, teacher capacity,
source truth, and human contestability. The cube should make the honest field
move easier than adding another rule, while keeping every local artifact below
the evidence line until accountable owner material exists.

## Current live rail

1. Run `make owner-field-work OUT=scratch/ft0181-field-work/aiedu-sr-003`.
2. Use the generated packet outside the archive only if a real accountable owner
   route exists; otherwise record the route block.
3. After the human send/adaptation actually happened, run the router and execute
   the emitted `make owner-after-human-send ... CONFIRM=human-sent-bounded-owner-request` command.
4. Wait for a real returned owner CSV/source packet, or let the router handle the
   bounded clock and one re-ask.
5. Intake only a real returned owner CSV/source packet through the router.
6. Keep all workbench, decision, activation, ticket, live-window, readout,
   post-readout, recheck, context receipt, custody, acceptance, public claim, and
   closure movement behind their existing gates.

## What stays forbidden

No field-work session, after-human-send session, field-next docket, prepared
packet, send-now brief, field-texture memo, send log, contact-status note, intake
bundle, workbench seed or review, first-packet decision, activation receipt,
post-decision ticket, live-window card, readout, post-readout action, recheck,
context receipt, audit, release example, schema, registry, or lint result may
become real evidence, service-record mutation, lifecycle movement, public-claim
support, custody, acceptance, or closure. `FT-0181` remains live until real owner
evidence and closure signoff exist.
