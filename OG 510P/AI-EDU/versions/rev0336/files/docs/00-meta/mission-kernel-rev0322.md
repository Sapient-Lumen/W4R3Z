# rev0322 mission kernel

The mission remains education-first: use AI to strengthen human teaching, learner agency, proof of
understanding, and equitable access without converting the archive into a surveillance, answer-giving,
or compliance-theatre machine.

## Current priority

rev0322 treats the riskiest unfinished work as the operator gap after readiness: the cube can now
prepare, score, and rehearse the first teacher/tutor packet, but the next maintainer still needs a
single command that says whether to prepare, complete, discard a synthetic rehearsal, or stop for local
owner review.

The next real work remains:

1. cross the `FT-0181` human owner boundary by sending the bounded owner request or recording a real
   route block;
2. run one fresh teacher/tutor move-coach cycle on one concept with an ordinary non-AI fallback and a
   no-AI transfer check;
3. use the new micro-pilot next-action router to prevent packet-prep, dry-run, and scorecard states
   from being mistaken for real progress;
4. keep governance proportional by using the hot path before opening the branch-history tail.

## Pedagogical center

The active learning hypothesis is narrow: AI may help a teacher or tutor choose better next moves
after a learner attempt. It must not become a learner answer machine, grading tool, durable learner
profile, discipline aid, disability/risk inference surface, or public claim generator.

rev0322 adds a scratch-only next-action router for the equality-one-step teacher/tutor packet. It can
say `PREPARE_PACKET`, `COMPLETE_LOCAL_PACKET_OR_OPTIONAL_DRY_RUN`,
`DISCARD_SYNTHETIC_AND_REGENERATE`, or `LOCAL_OWNER_REVIEW_STOP`. None of those statuses is evidence.

## What still blocks progress

No owner has been contacted. No route block has been recorded. No real owner CSV or `SRC2+` packet
has been accepted. No teacher/tutor micro-pilot has been run. No learning, access, workload, safety,
compliance, effectiveness, custody, service-authority, public-claim, or closure state has been
upgraded.

## Rule for the next maintainer

Do not add another registry, schema, validator, or governance branch to compensate for missing human
execution. Run the owner router and the micro-pilot next-action router; then either make the human
send, record the route block, run a fresh local cycle, or state which human boundary stopped the work.
