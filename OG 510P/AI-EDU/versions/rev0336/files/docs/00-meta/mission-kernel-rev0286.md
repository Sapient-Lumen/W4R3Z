# rev0286 mission kernel

The mission is to let AI-in-education work earn trust only through bounded,
owner-attested, human-reviewable evidence. The archive should protect learning,
access, contestability, construct validity, teacher capacity, provenance, and
claim humility before any service record, lifecycle state, public summary, or
closure language changes.

## Current live rail

`FT-0181` remains live. The only useful posture is field execution, not more
registry growth:

1. run `make owner-field-next`;
2. prepare the bounded owner packet if no scratch state exists;
3. send/adapt externally only through a real accountable owner route;
4. record the send log and contact clock;
5. intake only a real returned owner CSV;
6. preserve candidate/not-accepted status through review and decision;
7. activate only with the same real source packet hash;
8. write live-window cards only from guarded active-change tickets;
9. write terminal readouts only from terminal live-window cards;
10. stop at post-readout dispatch and closure gates.

## rev0286 kernel change

Terminal live-window cards now route to `owner-live-window-readout`. This keeps
the end-of-window step executable and prevents a card from becoming action
dispatch, service-record mutation, public language, lifecycle movement, or
closure.

## Non-negotiable boundary

No local scratch artifact is owner evidence by itself. Prepared packets, route
blocks, send logs, contact statuses, intake bundles, seeds, reviews, decisions,
activation receipts, post-decision tickets, live-window cards, readouts, release
examples, and audits remain below `SRC2+` acceptance, custody, public claim, and
closure.
