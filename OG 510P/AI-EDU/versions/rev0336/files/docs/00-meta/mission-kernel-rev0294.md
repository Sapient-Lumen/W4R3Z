# rev0294 mission kernel

The mission remains: keep AI-in-education work answerable to learning, agency,
access, teacher capacity, source truth, and public-claim humility after local AI
systems become ordinary infrastructure.

The live mission inside this cube is narrower and more operational:

> Move `FT-0181` toward real owner-reviewed evidence while preventing local
> receipts, packets, lints, examples, audits, and helper sessions from becoming
> fake evidence, public proof, custody, acceptance, or closure.

## Current live rail

`rev0294` keeps the execution-first sequence compact:

1. `make owner-field-work OUT=scratch/ft0181-field-work/aiedu-sr-003`
2. A human sends/adapts the bounded packet, or records no accountable route.
3. `make owner-after-human-send ...` only after the human send actually happened.
4. `make owner-field-next CSV=/path/to/returned-owner-reply.csv ...` when a real
   owner CSV/source packet returns.
5. Execute the emitted `owner-returned-reply-work` command.
6. If and only if a NOT_ACCEPTED workbench seed is created, a human performs the
   minimized workbench review.

This is still not closure. It is a shorter bridge from real field material to
human review.

## Main anti-waste rule

Do not add doctrine, schemas, registries, examples, or branch surfaces because
field contact is uncomfortable. Add them only when a real returned owner packet
breaks an existing gate or exposes a risk the current lane cannot safely route.

The next scarce input is still a real owner-returned packet. The new helper only
keeps that packet from being lost in local command choreography.
