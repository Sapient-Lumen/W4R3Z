# Profile hardening application rows

This surface applies the reusable `PH0-PH6` grammar to the remaining
starter-profile families. It deliberately uses short decision rows instead of
one new prose shell per family.

The rule is:

> harden only the part of a starter profile whose actor, stakes, authority,
> memory, proof, security, and fallback evidence are stable; split the rest.

A row may therefore contain one hardened center and several explicit branches.
That is not indecision. It is the archive refusing to let a safe low-stakes
center launder a hotter edge case.

## Priority family decisions

| Family | Starter center that may harden | First split / cool / retreat decision |
|---|---|---|
| proof intensity | low-stakes practice proof where the construct tolerates hints, process notes, and independent transfer checks | split official assessment, gateway, protected-route, and certification proof by construct family; cool detector-led suspicion; retreat from AI-only authenticity judgment |
| student-facing support | optional explanation, hinting, translation, and practice support with no record consequence and a human route | split minors, required use, persistent memory, companion-like framing, wellbeing adjacency, and credit-bearing work; retreat from answer-engine defaults |
| teacher-facing support | `AA2` draft-for-review planning, adaptation, translation, and rubric-drafting support where the teacher remains accountable | split grading, parent/family messaging, discipline, accommodations, and official records; retreat if review labor or authority silently shifts |
| institution-facing support | read-only navigation, service triage, and queue-preserving help where a named owner controls the record | split aid, eligibility, discipline, disability support, public-benefit, and cross-agency cases; retreat from route-changing advice without appeal |
| observability | aggregate service health, no-penalty fallback proof, and bounded incident reconstruction | split by protected records, assessment, minors, agentic tools, and official action; retreat from routine full-trace capture |
| failure | safe degradation with named owner, no learner fault, and no missed consequence window | split by timing-critical service, official record effect, and scarce owner capacity; quarantine orphaned queues and false uptime promises |
| change | patch-level changes that do not alter model behavior, prompts, retrieval corpus, tools, authority, record effect, or construct fit | split model/RAG/tool/authority/memory/security changes; presume fresh review when educational or record effect changes |
| coverage | truthful service window with no silent penalty and a named substitute path | split after-hours, cohort peak, queue-integrity, minors, public-route, and formal gatekeeping contexts; cool to optional use when coverage cannot be staffed |

## Proof-intensity rows

| Starter row | State | Decision |
|---|---|---|
| practice artifact plus short learner explanation | `PH1-HARDEN` inside low-stakes learning support | can travel as a starter default when the claim is formative learning, not certification |
| writing, coding, data, or design work with substantial AI assistance | `PH2-SPLIT` by construct family | require construct map, disclosure, and independent transfer / defense proof before making learning claims |
| gateway exam, qualification, licensure, or public credential proof | `PH4-RETREAT` from generic starter inheritance | use assessment-owner rules, human examiner responsibility, and official validity / contestability floors |
| protected accommodation or accessibility evidence | `PH2-SPLIT` into protected route | ordinary misconduct metadata may not absorb assistive-technology or disability-support facts |
| AI detector, authorship score, or suspicion trace as proof | `PH5-QUARANTINE` | may trigger human review only under separate policy; cannot be the proof profile itself |

Proof starter profiles therefore close with a narrow hardening center and a hot
assessment split. This answers the `FT-0022` pressure without pretending one
proof table can travel into every official assessment context.

## Student-facing support rows

| Starter row | State | Decision |
|---|---|---|
| optional low-stakes hinting after learner attempt | `PH1-HARDEN` | portable starter default if `CE1-CE2`, no grade action, no hidden learner model, and no required use |
| required course support or default-path tutor | `PH2-SPLIT` | split by age, subject, credit stakes, accessibility route, and opt-out burden |
| persistent personalised coach | `PH3-COOL` or `PH4-RETREAT` | keep preference/course continuity only; retreat from relational memory or predictive nudging without new review |
| minor-facing support with wellbeing or family-duty proximity | `PH2-SPLIT` with safeguarding owner | cannot inherit ordinary adult study-help assumptions |
| answer engine for graded work | `PH4-RETREAT` | allowed use must move back to construct map, disclosure, and independent proof rather than ordinary tutoring defaults |

This closes the starter-profile pressure in `FT-0025`: student-facing defaults
harden only while they remain optional, bounded, and learning-first.

## Teacher-facing support rows

| Starter row | State | Decision |
|---|---|---|
| lesson planning, examples, translations, and accessible-format drafts | `PH1-HARDEN` at `AA2` | teacher remains accountable; copyright/source, bias, and workload review are counted |
| feedback comments drafted for teacher review | `PH2-SPLIT` | split by stakes, class size, appeal risk, language/accessibility route, and rubric sensitivity |
| grading, discipline, parent/family communication, or formal accommodation action | `PH4-RETREAT` from generic teacher support | human judgment and official owner signoff remain controlling |
| teacher-evaluation or productivity monitoring use | `PH5-QUARANTINE` | do not reuse instructional-support traces for staff surveillance without separate labor governance |
| AI planning service that increases correction/review burden | `PH3-COOL` | narrow or pause until total workload evidence improves |

This answers `FT-0026`: teacher-facing tools may harden as reviewed drafting
support, not as official judgment delegation.

## Institution-facing support rows

| Starter row | State | Decision |
|---|---|---|
| read-only FAQ, orientation, or service navigation | `PH1-HARDEN` | publish limits, source freshness, fallback, and no-record-consequence language |
| advising, transfer, aid, disability, or public-route navigation | `PH2-SPLIT` | name record owner, appeal route, queue preservation, and stale-answer handling |
| eligibility, discipline, standing, benefits, or formal route change | `PH4-RETREAT` from generic AI support | AI may draft or summarize, but final accountable action is human-owned |
| cross-agency or vendor-mediated case movement | `PH2-SPLIT` with handoff packet | recipient duties, data boundary, and no-loss fallback must be explicit |
| opaque ranking, risk score, or queue movement | `PH5-QUARANTINE` | do not treat institutional convenience as navigational support |

This closes `FT-0027`: institution-facing defaults harden only for bounded
navigation; consequence-bearing offices split immediately.

## Observability rows

| Starter row | State | Decision |
|---|---|---|
| aggregate uptime, error, and access monitoring | `PH1-HARDEN` | acceptable when not used to profile individual learners or staff |
| no-penalty fallback proof | `PH1-HARDEN` | collect minimum evidence needed to preserve standing after service failure |
| incident reconstruction for safety/security | `PH2-SPLIT` | keep scoped, owner-named, time-limited traces with deletion / challenge route |
| routine full conversation or screen trace capture | `PH4-RETREAT` | not an ordinary proof or safety default |
| protected-route, wellbeing, discipline, or assessment traces | `PH2-SPLIT` or `PH5-QUARANTINE` | stronger owner, minimisation, and non-misuse rules are required |

This resolves `FT-0029`: observability hardens only around service truth,
fallback, and bounded incident need, not ambient surveillance.

## Failure rows

| Starter row | State | Decision |
|---|---|---|
| low-stakes service failure with ordinary human fallback | `PH1-HARDEN` | publish fallback and no-penalty language |
| live class, credit window, access promise, or public-route timing failure | `PH2-SPLIT` | same-cycle owner, substitute path, and no-deadline-loss rule required |
| unsupported accommodation, safeguarding, or formal decision failure | `PH4-RETREAT` to human-primary handling | AI service availability cannot become the only route |
| orphaned queue or false uptime promise | `PH5-QUARANTINE` | pause or narrow until failure ownership is real |
| repeated failure after repair | `PH3-COOL` or `PH6-RETIRE` | stop publishing the stronger service posture if reliability cannot be sustained |

This answers `FT-0030`: failure defaults harden around named fallback, then
split by consequence timing and owner scarcity.

## Change rows

| Starter row | State | Decision |
|---|---|---|
| cosmetic interface, typo, or documentation fix | `PH1-HARDEN` | no fresh deployment if no model, prompt, data, tool, authority, memory, or policy effect changes |
| prompt, retrieval corpus, model, tool, memory, or output-routing change | `PH2-SPLIT` | run bounded fresh review keyed to changed effect, not vendor label |
| action-authority expansion | `PH4-RETREAT` until signoff | draft/recommend/write powers are different deployments |
| assessment, eligibility, discipline, protected-route, or public-benefit change | `PH2-SPLIT` with legal / owner review | small technical changes can be large consequence changes |
| repeated micro-changes on the same path | route to cluster-reset rule | do not let drift hide behind individually minor release notes |

This closes `FT-0032`: bounded maintenance hardens, but effect-changing updates
split and may become fresh deployment.

## Coverage rows

| Starter row | State | Decision |
|---|---|---|
| optional reference or self-study surface outside consequence windows | `PH1-HARDEN` at `HC1-HC2` | delayed owner-backed fallback may be truthful |
| teacher-runtime dependency during same-cycle class delivery | `PH2-SPLIT` | publish same-day substitute path; cool if staffing cannot support it |
| repeated minor-facing support | `PH2-SPLIT` | same-day owner and safeguarding route are part of the profile, not an add-on |
| higher-education credit / aid / registration window | `PH2-SPLIT` | same-cycle human route and no-deadline-loss rule are required |
| professional practice, public-route, or scarce-slot navigation | `PH2-SPLIT` or `PH4-RETREAT` | route truth depends on owner capacity and deadline protection |
| after-hours promise with no staffed owner | `PH3-COOL` or `PH4-RETREAT` | publish as optional reference, not consequence-bearing service |

This closes `FT-0058` and the after-hours parts of `OQ-0047`: coverage
profiles harden only where the service window is true; otherwise the governance
action is visible cooling.
