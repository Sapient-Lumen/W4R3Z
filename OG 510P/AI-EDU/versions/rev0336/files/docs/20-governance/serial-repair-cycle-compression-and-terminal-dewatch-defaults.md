# Serial repair-cycle compression and terminal-dewatch defaults

The archive can now answer `FT-0161` without creating another ordinary hot-exam followup shell.

It can already say how a route reaches first watch, first dewatch, renewed watch, second dewatch,
third watch, third dewatch, fourth watch, third-repair refresh, and fourth dewatch. That work is
valuable, but it also exposed a structural risk: if every later recurrence automatically creates the
next smaller field set, the archive will prove the same anti-pattern forever.

This document adds a **compression rule**. After fourth rewatch / fourth dewatch, later relapse is
not treated as automatic fifth rewatch or as a prompt to publish
`first-post-fourth-dewatch-relapse-and-fourth-repair-memory-defaults...`. The default is now
terminal disposition, route-native handling, protected local treatment, retirement, or compressed
cycle grammar unless a genuinely new material pattern appears.

The archive still refuses fresh-start amnesia. It also refuses permanent serial surveillance.

## Why this is now the right next move

The fourth-rewatch layer already named the important field families: run-state, affected scope,
owner, cadence, current repair-refresh proof, learner-safe action, exit, minimization, and reopen
triggers. A fifth ordinary shell would mostly rename those fields around one more recurrence count.

That is not a portability gain. It is recurrence inflation.

So the archive now asks a different question:

> Has the later event after fourth dewatch introduced a new material actor, owner, route, protected
dependency, official-record effect, action authority, or evidence family — or is it another instance
of the same serial repair loop?

Only the first case may justify a new surface. The second case must compress.

## Terminal-dewatch field set

| Code | Meaning | Default archive action |
|---|---|---|
| `SC0-NO-AUTOMATIC-FIFTH-REWATCH-PUBLIC-SERIAL-DOSSIER-DUPLICATE-FILING-OR-FRESH-START-AMNESIA` | fourth dewatch neither erases memory nor authorizes an automatic fifth watch | require a current material dependency, named owner, proof-age label, and learner-safe action before any memory recall or reopened route work |
| `SC1-PUBLISH-CURRENT-MATERIAL-DEPENDENCY-BEFORE-FOURTH-REPAIR-MEMORY-RECALL` | minimized fourth-rewatch proof may be recalled only for a present need | publish whether the current dependency is source, search, archive, recipient, protected route, official record, clock, redesign handoff, retired route, no-active-route residue, split surface, successor owner, or learner remedy |
| `SC2-CHOOSE-TERMINAL-DISPOSITION-BEFORE-NEW-CYCLE` | repeated relapse after fourth dewatch should force a disposition, not just another watch | choose one of: ordinary lag, route-native refresh, protected local handling, owner redesign, split route, successor migration, official-record correction, retired-route residue, no-active-route residue, local-only memory, or no-current-action closure |
| `SC3-USE-COMPRESSED-CYCLE-GRAMMAR-WHEN-THE-PATTERN-IS-THE-SAME` | same-pattern serial recurrence should not create fifth, sixth, and seventh ordinary shells | publish recurrence count only inside a compressed local or branch-level cycle grammar; do not create a public learner serial-repair label or route-pair stigma |
| `SC4-GATE-ANY-FIFTH-CYCLE-SURFACE-ON-NEW-MATERIAL-PATTERN-AND-EXTERNAL-EVIDENCE` | a fifth-cycle document requires more than recurrence | require a new actor / stakes / authority / proof / memory / owner pattern, a reason the existing grammar cannot handle it, and at least one evidence source or implementation fact that changes the default |

## Values that may travel

When a fourth-dewatched route later relapses, the shell may publish only these fields unless a new
surface passes `SC4`.

1. `post_fourth_dewatch_material_dependency_token` — `none`, `ordinary downstream lag`, `current
   source dependency`, `current search dependency`, `current archive dependency`, `recipient-record
   dependency`, `official-record dependency`, `protected-route dependency`, `clock or deadline
   dependency`, `redesign handoff dependency`, `successor-owner dependency`, `retired-route
   residue`, `no-active-route residue`, `split-surface dependency`, `learner-remedy dependency`,
   `unknown current owner`, or `not published`.
2. `fourth_repair_memory_recall_token` — `no recall`, `local-only recall`, `protected local recall`,
   `current proof-age label only`, `route-native proof pointer`, `owner-facing repair pointer`,
   `official-record proof pointer`, `redacted recalled proof`, `recalled proof unavailable`, `recall
   blocked because no current dependency`, or `not published`.
3. `terminal_disposition_token` — `ordinary reset`, `route-native refresh`, `owner redesign`, `split
   retained`, `successor migration`, `official-record correction`, `protected route retained`,
   `retired-route residue`, `no-active-route residue`, `closed without learner action`, `local-only
   monitoring`, `compressed cycle grammar`, `exceptional fifth-surface gate opened`, or `not
   published`.
4. `learner_safe_action_after_fourth_dewatch_token` — `no action`, `wait for named owner`, `single
   safe route`, `dual-route recognition`, `clock hold`, `longer current window`, `protected local
   submission`, `manual support`, `route-native optional refile`, `route-native required refile with
   no penalty`, `formal appeal only`, `owner-only repair`, or `not published`.
5. `new_surface_gate_token` — `not eligible`, `handled by SC0-SC3`, `new actor`, `new stakes`, `new
   authority`, `new memory state`, `new proof state`, `new owner`, `new jurisdictional duty`, `new
   implementation evidence`, `quarantine only`, or `not published`.

## Default decision tree

1. If there is no current material dependency, publish ordinary reset or no-current-action closure
   and reminimize.
2. If there is a current dependency but it is route-native, use the route-native owner, clock, and
   proof path before archive-level publication.
3. If the dependency is protected, disability-related, wellbeing-related, or sensitive, keep proof
   local/protected and publish only the safe action or owner pointer.
4. If the owner path keeps failing in the same way, choose redesign, split, successor migration,
   retired-route residue, or no-active-route residue before opening another watch.
5. If the same pattern repeats again, use compressed cycle grammar and aggregate owner learning, not
   public learner labeling.
6. If a genuinely new pattern appears, open a new surface only after `SC4` is satisfied.

## What this closes

This closes the ordinary form of `OQ-0092` and resolves `FT-0161` by refusing the expected next
filename as the default next move.

The archive may still quarantine a fifth-cycle speculation if future evidence shows that
fourth-dewatch relapse creates a new, recurring governance problem not covered here. But canon now
starts from compression.

See `B274` and `B275`.
