# Agent instructions

`rev0336` treats source-result continuity as the hot-path repair. The first valuable field outcome is still a real local teacher/tutor conversation and one bounded cycle, but the next operational risk was letting a `repeat-narrower` or `continue-bounded` result produce a generic fresh packet with no hash link to the prior non-evidence result.

## Revision gate

Do not create a new branch, schema, validator, recorder, registry, or public-claim rule unless a real field event exposes a need or a reproducible source-truth defect requires repair. Deletion, merging, and small refactors of existing hot-path tools are preferred to control-plane expansion.

## Start

```bash
make field-handoff-bundle OVERWRITE=1
```

Open the generated `FIELD-HANDOFF.md`, then `DISCOVERY-FIRST-CONTACT.md`, `OWNER-PLAN.md`, `CYCLE-RUN-SHEET.md`, and `OWNER-DECISION-MEMO.md`. Do not open branch history, public-claim lexicons, release examples, or the FT-0181 owner rail first.

## Pedagogical boundary

- The local owner selects the problem and concept.
- The first cycle is `FEASIBILITY_AND_USABILITY_ONLY`, not an efficacy trial.
- `READY_FOR_LOCAL_CYCLE_NOT_EVIDENCE` permits exactly one locally approved cycle using `CYCLE-RUN-SHEET.md`; it is not owner-review readiness.
- Entry readiness checks generated run-definition hashes and any optional prior-result source link.
- If a run-defining file or source-result hash link changes, regenerate the packet; do not locally patch it.
- `READY_FOR_LOCAL_OWNER_REVIEW_NOT_EVIDENCE` requires actual aggregate post-cycle rows, valid chronology, one bounded decision, and completed follow-through seed fields.
- Record tool/model/version/configuration and prompt-card hash before use.
- Confirm learner notice/participation, aggregate learner voice, ordinary non-AI fallback, numeric small-cell threshold, protected local equity review, and post-cycle attestation route before use.
- Mask exact counts/rates below the local threshold in any result receipt; exact small cells stay local only.
- Redact numeric/small-cell-sensitive `FINAL-READOUT.csv` free text from the result receipt.
- Non-retire repeat/continue work must use `make micro-pilot-followthrough-pack SOURCE_RESULT=... CONFIRM=source-result-read-for-local-followthrough-not-evidence ...`.
- Never infer learning from smoother task completion alone.
- Never record names, raw work, small cells, protected facts, transcripts, screenshots, gradebook rows, credentials, contact routes, or security payloads in the release archive.
