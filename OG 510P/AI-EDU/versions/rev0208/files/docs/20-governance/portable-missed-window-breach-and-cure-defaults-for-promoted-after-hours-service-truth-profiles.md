# Portable missed-window / breach / cure defaults for promoted after-hours service-truth profiles

This document closes the archive's next after-hours governance gap: **once a promoted after-hours branch carries a shared callback band such as `CB-1BD`, what happens if that callback band is actually missed?**

The archive's answer is narrower than the already narrow quantitative portability rule:

> only a very small class of low-consequence, callback-only `OV1 + AQT-CALLBACK` branches may usually inherit one shared missed-window / breach / cure package. Owner-window, queue-preserving, rights-preserving, licensure-sensitive, public-route, and protected-support slip handling remains local.

That asymmetry is deliberate. The archive is trying to avoid four opposite errors at once:

- **silence laundering** — a published callback band is missed, but the service acts as though the miss never happened because the branch was only "informational";
- **rights laundering** — a miss is cured with vague courtesy language that obscures whether queue place, complaint position, funding opportunity, or other live consequences were actually preserved;
- **over-portability** — one cross-sector apology/escalation script gets pasted onto contexts where a missed window has materially different effects;
- **fake-live substitution** — an ordinary callback shell treats a miss as permission to impersonate a genuinely live urgent or protected route.

Current public signals support that thinner move. HLC's current teach-out policy still requires student-facing communications to specify scope, timing, credits, fees, records handling, and discharge/refund information. OIA says providers keep their own timelines, should update students if timeframes extend, should tell students what they need to do to preserve their position while matters remain live, and should issue a Completion of Procedures Letter promptly once internal processes are complete. Federal Student Aid still says FAFSA Submission Summary amounts are estimates while each school's aid offer is the final source of truth. WIOA still joins employment, education, training, and support services without collapsing them into one office rhythm. ALA still frames libraries as low-barrier access infrastructure. SAMHSA still treats 988 as a genuinely live 24/7 protected route. Together those signals support a small archive rule: **a missed portable callback may sometimes trigger one shared low-stakes repair package, but consequence-bearing slip handling should usually remain local.** See `B188`.

## Three breach/cure portability tiers

The archive now distinguishes three after-hours breach/cure portability tiers.

| Tier | Meaning | What travels | What stays local |
|---|---|---|---|
| `ABP-LOCAL` | no shared missed-window package travels | only the promoted state and any quantitative band | the miss definition, apology language, cure steps, queue effects, and escalation |
| `ABP-BREACH` | one shared miss family may travel | the basic miss definition | cure steps, queue effects, rights effects, and escalation |
| `ABP-BOTH` | one shared miss family plus one shared low-stakes cure package may travel | the miss definition and minimal cure package | any rights effect, queue protection, owner-window substitute, or protected/live-route treatment |

The starter canon grants only `ABP-LOCAL` and `ABP-BOTH`. `ABP-BREACH` is reserved for a future case where the archive might decide that one family of misses travels more easily than the cure semantics do.

## Five tests before a missed-window package travels

A promoted after-hours branch may harden above `ABP-LOCAL` only when all five tests substantially hold.

### 1. Same-miss-semantics test

The same practical event must count as the miss across the reuse scope. If one office treats a missed callback as mere courtesy failure while another treats it as queue loss, owner non-compliance, or rights jeopardy, the package stays local.

### 2. No-rights-loss-obscurity test

The shared package must not hide whether any live position, deadline, queue place, funding opportunity, or complaint path was actually affected. If a miss changes consequence-bearing status, the slip handling stays local.

### 3. Same-minimal-cure test

The same minimum repair must still be truthful across the reuse scope. A portable cure is easier to justify where the truthful repair is simply to acknowledge the miss, restate the branch's limited scope, publish the next staffed route, and issue one fresh local callback target.

### 4. No-queue-laundering test

The cure package must not quietly convert an ordinary callback miss into implied queue preservation, appointment holding, or same-owner review priority if those protections were never really in force.

### 5. Live-route-separation test

The portable repair must not turn an ordinary missed callback into a substitute for a genuinely live urgent or protected route. If the honest response is "use the live route now," the miss package must point there rather than simulate it.

## The starter shared miss and cure families

The archive now names one shared miss family and one shared low-stakes cure family.

| Code | Meaning |
|---|---|
| `MW-CB1BD-CORE` | the published `CB-1BD` callback did not occur by the end of the next published business day and no earlier published local exception or re-timing notice truthfully displaced that band |
| `CU-CB1BD-RESET` | acknowledge the miss, apologise or take responsibility, restate that no extra queue / rights effect should be inferred unless separately published, give one fresh local callback target or staffed owner route, and visibly point to any genuinely live urgent / protected route if relevant |

The archive deliberately keeps the shared cure family thin. In the starter canon `CU-CB1BD-RESET` does **not** include:

- automatic queue preservation;
- automatic deadline extension;
- automatic owner-window substitution;
- automatic compensation, waiver, or complaint-right preservation;
- automatic conversion into a live protected route.

Those consequences remain local unless a separate local regime already publishes them truthfully.

## The archive's starter missed-window answers

### `ST-HE-TEACHOUT` may sometimes harden as `ABP-BOTH`

Where a teach-out branch has already earned only a **callback-only** `OV1 + AQT-CALLBACK` promise, the archive will usually allow one shared missed-window package.

The starter default is therefore:

> when `ST-HE-TEACHOUT` has already truthfully hardened only to `OV1 + AQT-CALLBACK` with `CB-1BD`, it may usually also inherit `ABP-BOTH` with `MW-CB1BD-CORE + CU-CB1BD-RESET`.

Why the archive allows this:

- the miss usually still means the same thing across the reusable scope — the learner did not receive the promised human comparison / orientation callback on time;
- the truthful shared repair is still small — admit the miss, restate the limited scope of the branch, and provide one fresh local callback target or staffed next-owner route;
- the branch is still not claiming that aid, complaint, discharge, or regulator-facing consequences were preserved merely because the callback was promised.

What still stays local:

- any effect on complaint, discharge, refund, or aid timing;
- any stronger compensation or waiver;
- any rights-preserving remedy beyond the branch's already published scope.

### `ST-LIB-CIVIC-FIRST` may sometimes harden as `ABP-BOTH`

Where a civic or library first-contact branch has already truthfully hardened only to `OV1 + AQT-CALLBACK`, the archive will usually allow the same small missed-window package.

Why the archive allows this:

- the shared callback usually still means only navigator contact, orientation, warm-transfer follow-up, or digital-access help;
- the shared cure may remain thin without misrepresenting downstream office ownership;
- the cure package helps prevent silent drop-off without turning the civic front door into a fake benefits, aid, complaint, or licensure office.

What still stays local:

- any downstream eligibility, seat, aid, or complaint effects;
- any stronger promise about when the accountable downstream office will act;
- any live urgent/protected support handling.

### `ST-HE-AID-CREDIT` stays `ABP-LOCAL`

Aid, credit, registration, transfer, progression, and complaint-adjacent branches keep missed-window handling local.

Why the archive stops there:

- even a seemingly simple callback miss may interact with deadlines, queue place, evidence submission, or external-review position;
- the truthful cure may need case-specific explanation about whether anything was preserved or lost;
- a shared apology / reset script would too easily blur the difference between courtesy follow-up and consequence-bearing office failure.

### `ST-WF-PUBLIC-ROUTE` stays `ABP-LOCAL`

Public-route routing keeps missed-window handling local because queue integrity, funded inventory, partner coordination, and priority rules vary too much for one portable cure package.

Even where a route had a published callback band, a miss may have different practical meanings across one-stop centers, partner agencies, training inventory, and support-service routing.

### `ST-PRO-LICENSURE` stays `ABP-LOCAL`

Licensure-sensitive routes keep missed-window handling local because external-board timing, state variation, and practice-entry consequences make even the cure semantics too regime-bound to travel.

### `ST-PROTECTED-SUPPORT` never uses the shared package in the starter canon

Protected support does not use the portable missed-window package in the starter canon. If a visible branch has to speak to urgent or protected need, the honest response is still route separation or the genuinely live protected route itself.

## What `CU-CB1BD-RESET` minimally requires

Where `ABP-BOTH` applies, the shared cure package must do five things visibly.

1. **Name the miss** — say that the published callback band was not met.
2. **Take responsibility** — apologise or otherwise acknowledge provider-side failure without vague passive phrasing.
3. **Restate scope truth** — say explicitly that no additional queue, rights, or owner-window effect should be inferred unless separately published.
4. **Give one next actionable path** — either one fresh local callback target or one staffed owner/contact route with current timing truth.
5. **Separate live routes** — where urgent or protected help might now be relevant, point visibly to the genuine live route rather than broadening the ordinary branch.

The package is intentionally repair-oriented, not merits-oriented. It repairs the truth of the service promise without pretending to repair every downstream consequence automatically.

## What portable missed-window packages still may not do

Even under `ABP-BOTH`, a promoted after-hours branch may not use the shared package to:

1. imply that a missed callback automatically preserves queue place or legal position;
2. imply that the accountable owner has already begun same-day review;
3. conceal whether the learner should still take a time-sensitive local action;
4. substitute for compensation, waiver, or deadline relief that belongs to a local regime;
5. stand in for a genuinely live urgent or protected route.

| `ST-LIB-CIVIC-FIRST` | `OV1 + AQT-CALLBACK` | `ABP-BOTH` | `MW-CB1BD-CORE + CU-CB1BD-RESET` | warm-transfer / navigator callback miss usually supports the same small repair package |

## Why this move belongs in an education-with-AI archive

This may look like a tiny customer-service refinement. It matters because the archive is trying to make **institutional AI surfaces operationally honest**. Once educational systems publish official AI-mediated continuity, routing, or orientation branches, even a low-stakes callback promise becomes part of the learner's practical planning. The archive therefore needs a disciplined answer not only about which callback numbers may travel, but about whether a missed callback can be repaired with one reusable package or whether the service must immediately fall back into local regime truth.

That answer is now narrower and clearer: only some low-consequence callback-only branches may carry one shared missed-window plus minimal cure package; anything consequence-bearing keeps missed-window handling local.
