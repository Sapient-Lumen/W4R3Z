# First protected-exposure boundary and incident-routing defaults for hot exam-modality children

This document closes the archive's next narrower governance gap about **which of the new hot exam-modality minima now deserve a shared same-day phase boundary, and which still do not deserve one portable minute-band or substitute-owner rule**.

Three failure modes matter here:

- **prestart/poststart blur** — route failure before a scored or protected event begins gets treated as if the learner has already started the live event, or vice versa;
- **same-route recovery skipping** — staff jump too quickly from a temporarily broken approved route to rescheduling, substitute labor, or a different mode even when the official platform still supports recovery inside the same route;
- **defense-reset leakage** — interruption of assisted presentation / oral-defense work gets handled as ordinary logistics even after defense-question exposure, weakening the no-preview/authenticity boundary.

Current official signals point to a deliberately narrow answer. NCEO still says accessibility policy is state-determined, often content-area specific, and may rely on embedded technology or a human provider. WIDA still says state-specific policy governs, valid results are the point, only the listed supports/accommodations should be used, and modifications can invalidate results. College Board's current digital AP materials now add a sharper operational seam: the AP Coordinator's Manual says a digital exam starts when the proctor provides the start code, and the Proctor Exam Day Guide says each student's timer starts when they enter that code. Bluebook Help then says that before timed testing a crashed or powerless device can be replaced with a backup device, while during timed testing staff should exit Bluebook, restart the device, and use device swap only as a last resort while time remains. Bluebook Alerts add the stronger routing distinction: if students cannot start or continue, schools should reschedule or retest later as needed, but the reporting path differs depending on whether the student entered the start code. Meanwhile AP Seminar / AP Research accommodation policy keeps assistant authenticity and no-preview oral-defense boundaries live. Together those signals support a tighter archive rule: **the first portable same-day layer here is a protected-exposure boundary, not one universal rescue timer** — unresolved prestart route failure can still live in owner-reset space, official same-route recovery should be used first only where the platform clearly supports it, unresolved poststart failure should move into owner interruption / irregularity handling, and once defense questions are exposed the no-preview seal must survive any pause, substitute, or restart decision. See `B205`.

## Small grammar for protected-exposure boundaries

| Code | Meaning | Default archive action |
|---|---|---|
| `EX1-PRESTART-OWNER-RESET` | before timed/protected start or before protected question exposure, unresolved route failure may remain a setup / owner-reset issue rather than a live scored-event interruption | publish that prestart correction, backup-device use, or later sitting can still happen without pretending the learner already started the scored event |
| `EX2-SAME-ROUTE-RECOVER-FIRST` | after protected start, the first recovery move should preserve the same approved route and the same attempt where the official platform explicitly supports it | prefer exit/reopen, restart, approved continue-testing flow, or last-resort same-route device swap before moving to retest / reschedule |
| `EX3-POSTSTART-OWNER-INCIDENT` | once protected start or protected content/question exposure has occurred and recovery fails, the case moves into owner interruption / irregularity / retest handling rather than ordinary local reset | publish that started-session failure now belongs to the live owner/security path |
| `EX4-DEFENSE-SEAL` | once oral-defense questions are exposed, pause / substitute / restart handling must preserve the no-preview boundary | publish that substitute help may not be pre-briefed with defense questions as ordinary setup |

## `SR-READ-FOUND-01A2A` / `SR-READ-FOUND-01A2B` — the archive can now publish the start boundary, not the rescue script

For the hot reading families, the archive still cannot publish one shared same-day rescue timetable. That remains too owner-, state-, and construct-specific.

But the archive can now publish one smaller truth.

`EX1-PRESTART-OWNER-RESET` means that if the route problem is discovered **before** the protected event has actually started — before protected content or the authority's equivalent live start point — the issue can still be handled as correction, setup repair, or later sitting without pretending the learner is already inside a started scored event.

`EX3-POSTSTART-OWNER-INCIDENT` means that once the protected start point is crossed, unresolved route failure belongs to the live assessment owner's interruption / irregularity path. That is where `FM1-NO-SILENT-SWAP` becomes even sharper: the institution still does not get to improvise a cross-mode substitute merely because the ordinary route failed after the start boundary.

For content-reading construct and ELP / ACCESS-family validity alike, that is the honest portable layer: **publish when the case stops being ordinary setup and becomes started-session owner handling**. NCEO and WIDA still do not justify more than that. See `B205`.

## `SR-WRITE-RHET-01B1A` — digital voice-recognition now gets the archive's only same-route-recover-first band

This is the archive's strongest same-day claim in this revision.

Bluebook Help is now explicit:

- **before timed testing**, a student whose device fails before entering the start code can use a backup device;
- **during timed testing**, staff should try exit/reopen and device restart first, with device swap only as a last resort;
- the timer pauses for a limited time while recovery is attempted; and
- the proctor must explicitly let the student continue testing in Test Day Toolkit.

Bluebook Alerts and current AP operational materials then add the next distinction: if the problem cannot be resolved, later retest / reschedule routing depends on whether the student had already crossed the start-code boundary. See `B205`.

That is enough for a three-step same-day band:

1. `EX1-PRESTART-OWNER-RESET` — before start code / timed testing, unresolved route failure can still be handled with setup correction or backup-device use.
2. `EX2-SAME-ROUTE-RECOVER-FIRST` — after start, preserve the same approved route and same attempt first through exit/reopen, restart, and only then last-resort device swap while time remains.
3. `EX3-POSTSTART-OWNER-INCIDENT` — if recovery fails, the case moves into the live owner's interruption / irregularity / retest handling rather than ordinary local reset.

The archive is **not** publishing one universal minute count for this band. The truthful inherited layer is the order and the phase boundary, not the exact timer.

## `SR-WRITE-RHET-01B1B` — approved writer/scribe still gets the start boundary, but not a portable replacement window

The human recording route now inherits `HM1-NAMED-HUMAN-ROUTE`, `FM1-NO-SILENT-SWAP`, `PS2-FAILURE-SHELL`, and now also the protected-exposure boundary.

That means:

- if the approved writer/scribe is unavailable **before** the started-event boundary, the case may still live in prestart correction / reset space rather than being disguised as a started attempt;
- once the started-event boundary has been crossed, unresolved human-route failure belongs to the live owner's interruption / irregularity handling, not to a casual room-level substitute or silent move into speech-to-text.

The archive is still refusing a stronger claim here. Current official materials do **not** yet justify one shared rule about how long a school should wait for a replacement writer/scribe, whether any other approved adult can step in, or which substitute-owner pattern travels across authorities. See `B205`.

## `SR-WRITE-RHET-01B2` — defense-question exposure is now a sharper boundary than assistant arrival time

For checkpointed paper-plus-defense authorship, the most important portable same-day truth is **not** a shared minute-band. It is the defense-question seal.

The current AP accommodations guide keeps three things public at once:

- assistants may deliver performance work as dictated and may assist in the Q&A/panel within the published role;
- approved speaking-time extensions are published by task; and
- interpreters or scribes may not reveal defense questions before the presentation. See `B205`.

That yields a narrow but real same-day boundary:

- before the presentation / defense has crossed its protected exposure point, assistant absence or setup failure can still remain a prestart owner-reset problem;
- once defense questions are exposed, `EX4-DEFENSE-SEAL` applies, so any pause, substitution, or restart must preserve the no-preview boundary rather than treating the exposed questions as ordinary setup knowledge;
- if that seal cannot be preserved, the case belongs to `EX3-POSTSTART-OWNER-INCIDENT`, not to informal room-level rescue.

The archive is also making one non-claim explicit: published speaking-time extension tables are **support-time publication**, not a portable interruption-minute rule. The existence of 8/10/20-minute task maxima and approved extension tables shows that timing matters, but it does not justify one shared rescue window for interrupted live defenses.

## What the archive is now making explicit

### The portable same-day layer is phase-based, not minute-based

The archive can now publish a prestart-versus-started boundary, and in one case — student-operated digital voice-recognition — a same-route-recover-first order inside the started phase. It still cannot publish one universal minute-band.

### Start / exposure now matters more than route inconvenience

A failed route before start is still often a setup problem. A failed route after start is an interruption / incident problem. That distinction now travels farther than any specific rescue timer.

### Defense questions create their own security boundary

For checkpointed presentation / oral-defense families, once defense questions are exposed the no-preview rule becomes part of the interruption logic, not merely part of ordinary preparation.

## What the archive is **not** doing yet

The archive is still refusing four wider moves:

- it is **not** publishing one portable minute-band for all started-session recovery;
- it is **not** publishing one portable substitute-owner rule for absent readers, writers/scribes, or interpreters;
- it is **not** claiming that all digital exam families share Bluebook-like same-route recovery affordances;
- it is **not** collapsing presentation speaking-time extensions into a generic interruption window.

## Current archive bet

The archive's current best guess is that hot exam-modality children now deserve **protected-exposure boundary before minute-band standardization**.

That means:

- hot reading now publishes when route failure is still prestart/reset versus when it has become started-session owner handling;
- digital voice-recognition writing now adds the archive's first same-route-recover-first band after protected start;
- writer/scribe writing now inherits the same start boundary without a portable replacement window;
- checkpointed paper-plus-defense authorship now treats exposed defense questions as a security boundary that survives interruption;
- and all of these families still refuse one universal same-day rescue timer.

That claim is now canon. The next narrower question is no longer whether a protected-exposure boundary exists at all; it is whether any of these phase bands now deserve actual family-specific minute ranges, started-session substitute-owner continuity rules, or hybrid digital/paper divergence rules without overclaiming portability. See `OQ-0005`.
