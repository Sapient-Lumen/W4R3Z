# First hardening judgments and protected-access carveouts for child and writing override rows

This document closes the archive's next narrower governance gap about **which of the newly split child override rows now harden cleanly as inherited defaults, where a small protected-access carveout is honest, and where stakes- or course-sensitive branching still remains live**.

The archive's current bet is:

> once the first child rows exist, harden only the ones whose construct truth is already stable; keep direct-production rows hotter; and separate recording access from surrogate authorship in writing-like rows.

The point is to avoid five predictable mistakes at once:

- **premature child hardening** — a newly split row gets treated as stable inherited canon before its stakes or tool ecology are actually settled;
- **anti-access overcorrection** — ordinary protected access disappears from later supported reading or inquiry work just because an earlier hotter sibling row exists;
- **surrogate-authorship laundering** — dictation, speech-to-text, or writer/scribe support gets conflated with rewriting, reorganizing, or composing for the learner;
- **false symmetry** — final writing, final language presentation, and direct first-pass decoding/procedure get treated as if they all deserve the same inheritance posture;
- **stakes drift** — rows that are still classroom-plausible get copied unchanged into timed, gateway, or proctored settings where the proof burden is materially hotter.

Current public signals point in the same direction. College Board's current accommodation guidance distinguishes response-recording help for disabilities that affect written language expression from ordinary weak handwriting or keyboarding, supports dictation / speech-to-text and writer/scribe in approved AP testing contexts, and still expects the student-facing response to be reviewable and revisable. Current AP AI guidance separately keeps exploratory help, coding assistance, and source-finding support distinct from final student-owned analysis, presentation, and explanation. WIDA's current accessibility guidance keeps the same underlying validity line visible: accommodations may increase access, but modifications that change what is measured are not allowed. Together those signals support a tighter archive rule: later supported reading access and language-project inquiry already look stable enough to harden, ordinary writing can harden only with a narrow recording-not-rewriting carveout, and direct-production rows like first-pass decoding and no-executor symbolic procedure still need stakes-sensitive branching before stronger inheritance. See `B196`, `B197`.

## Small protected-access carveout for writing-like rows

The archive now makes one narrow carveout explicit for rows where **learner-owned language production** remains the claim.

| Carveout type | What is still true | Default treatment |
|---|---|---|
| **recording access** | the learner still chooses the wording, syntax, sequence, and substantive claims, while dictation / speech-to-text / writer-scribe support only records those choices | may stay on the protected-access rail |
| **surrogate wording or organization** | the tool or helper proposes, rewrites, paraphrases, reorganizes, or composes the graded language itself | not protected access; stays on the ordinary-course or local-override rail |
| **timed / gateway / proctored production** | independent production tempo, response independence, or controlled conditions are now part of the claim | usually branch further into a hotter local or stakes-sensitive row |

The archive's current rule is therefore **recording is not the same thing as rewriting**. A protected-access carveout may preserve learner authorship; it may not hide surrogate authorship.

## What the archive is now making explicit

### `SR-READ-FOUND-01B` — later supported reading access can harden

The archive now treats later supported reading access as the clearest newly hardened child row. Once direct first-pass decoding is no longer the graded claim, the honest default should return to protected participation rather than keep importing the hotter decoding posture into every comprehension-heavy or discussion-heavy reading situation. See `B196`, `B197`.

### `SR-LANG-PROJ-01A` — inquiry and source-finding can harden sooner than final product rules

This child row now looks stable enough to inherit more strongly because the stage boundary is already public and legible: exploratory target-language source finding and topic inquiry are not the same thing as the final learner-owned performance. The archive therefore now treats this inquiry child as harder than the parent shell and cooler than the final presented-product row. See `B196`, `B197`.

### `SR-WRITE-RHET-01` — ordinary writing can harden only with a recording-not-rewriting carveout

This is the archive's clearest protected-access clarification. Students with disabilities that affect written language expression may honestly need dictation, speech-to-text, or a writer/scribe to **record** their response. But once the helper or tool starts choosing, rewriting, reorganizing, or composing the graded language itself, the support is no longer just access support. The row therefore hardens only with the carveout kept explicit. See `B197`.

### `SR-READ-FOUND-01A` and `SR-MATH-PROC-01A` — direct-production rows still need a hotter branch map

The archive is deliberately not over-learning from the first child split. These hotter child rows now look more honest than their old parents, but they still do not look stable enough to harden broadly. Both direct first-pass decoding and no-executor symbolic procedure still appear too sensitive to timed, gateway, course-family, and proctored-condition variation for stronger central inheritance yet. See `B196`, `B197`.

## What the archive is **not** doing yet

The archive is still holding back from three wider moves:

- it is **not yet** publishing the first timed / gateway child rows for `SR-READ-FOUND-01A`, `SR-MATH-PROC-01A`, or hotter writing contexts;
- it is **not yet** generalising the writing protected-access carveout into every language-production row; modality and sector still matter;
- it is **not yet** hardening `SR-MATH-PROC-01B` across course families where calculator, CAS, graphing, or symbolic-tool expectations diverge materially.

## Current archive bet

The archive's current best guess is that **post-split hardening should remain asymmetric**.

Some child rows — especially later supported reading access and language-project inquiry — already look stable enough to harden. Some rows — especially ordinary writing — can harden only with an explicit protected-access carveout that keeps response recording distinct from surrogate composition. And some rows — especially direct first-pass decoding and no-executor symbolic procedure — still need the first stakes-sensitive child branches before stronger inheritance becomes truthful.

That claim is now canon, but still live. The next narrower problem is no longer whether the still-hot direct-production rows deserve their first stakes-sensitive child branches or whether any of those hot branches can harden at all; those seams are now closed by [`first-stakes-sensitive-child-branches-for-direct-production-override-rows.md`](first-stakes-sensitive-child-branches-for-direct-production-override-rows.md) and [`first-hardening-and-locality-judgments-for-hot-direct-production-child-branches.md`](first-hardening-and-locality-judgments-for-hot-direct-production-child-branches.md). The live issue is where the still-local hot decoding and hot writing branches deserve their first modality-, age-, sector-, or exam-family child splits. See `OQ-0005`.
