# UOCAVA voting surface checklist

- Identify one authoritative public UOCAVA path and one authoritative help path for military and overseas voters.
- Publish who the path covers and where voters should go if a different path applies.
- Publish the official FPCA path and describe request/registration, delivery, and return semantics separately.
- Publish the official FWAB backup-ballot path and say when it is the right fallback.
- Publish the official ballot-receipt tracking path rather than forcing voters to infer it from generic absentee pages.
- Publish where mailing disruptions, date changes, and alternate return guidance will appear.
- Publish which help path is authoritative for installation assistance, embassy/consulate routing, and local election-office support.
- Treat changed request methods, delivery options, deadlines, help routing, and disruption advisories as explicit superseding notices, not silent edits.
- Check parity across website, downloadable instructions, email/help scripts, hotline guidance, and signed notices.
- Publish accessible and translated versions where required, plus an alternate official contact path when the primary page fails.
- Do not publish per-voter military status, ballot-tracking logs, deployment details, or internal exception queues.
- Record `last_verified_at` and the latest correction or disruption notice pointer.
