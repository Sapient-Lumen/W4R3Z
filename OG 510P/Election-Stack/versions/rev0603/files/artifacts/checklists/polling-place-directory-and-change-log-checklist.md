# Polling-place directory and change-log checklist

Purpose: make the public in-person voting directory a **verifiable surface**, not an editable webpage with no audit trail.

## Before publication

- [ ] One authoritative machine-readable directory payload exists for the election scope.
- [ ] Each site has a stable `site_id` and clear `site_kind`.
- [ ] Effective hours/dates are present for every site.
- [ ] Accessibility minimums are stated in bounded public terms (not left implicit).
- [ ] Replacement / alternate path is defined for any site at elevated contingency risk.
- [ ] The directory is linked from declared official channels.

## Change discipline

- [ ] Site closures, moves, consolidations, and hour changes create explicit change-log entries.
- [ ] Action-affecting changes emit a signed `PublicNotice` or digest-first bulletin reference.
- [ ] Silent edits are prohibited for action-affecting changes.
- [ ] Superseded versions remain reconstructible by digest or mirrored copy.
- [ ] Hotline / call-center scripts are updated and versioned when change notices are issued.

## Accessibility / usability minimums

- [ ] Public notices say whether an accessible path or alternate process exists when a site changes.
- [ ] Accessibility claims are based on a recorded assessment, not assumption.
- [ ] Language-support summaries are present where relevant.

## Security / minimization

- [ ] No floor plans, camera placements, alarm details, or staffing rosters are published.
- [ ] Capacity information is expressed as bounded planning language, not a guarantee.
- [ ] Directory copies on mirrors / status pages match the effective official state.
- [ ] A parity snapshot is captured after major site changes.
