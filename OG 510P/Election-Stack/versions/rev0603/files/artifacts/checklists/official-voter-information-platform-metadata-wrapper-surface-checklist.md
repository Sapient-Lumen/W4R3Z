# Official voter-information platform metadata-wrapper surface checklist

Use this checklist when official voter-information media may be framed by mutable platform-native titles, descriptions, thumbnails, posters, playlist-local labels, or similar metadata wrappers.

## Scope

- [ ] Reviewed the exact media object and the wrapper surfaces most likely to matter publicly.
- [ ] Distinguished the media body from the current written/help lane and from the wrapper metadata around the media.
- [ ] Recorded which source pages, playlists, embeds, or partner wrappers were materially relied on.

## Metadata-wrapper review

- [ ] Verified the current title and description were reviewed, not only the recording body.
- [ ] Verified the current thumbnail or poster image was reviewed, including autogenerated or frame-selected thumbnails where relevant.
- [ ] Verified any playlist-local, collection-local, or container-local display labels were reviewed where materially relevant.

## Currentness and scope

- [ ] Checked whether the title, description, or thumbnail could overstate freshness, geography, eligibility, or actionability.
- [ ] Checked whether description text carries action-changing instructions that should instead live in the current written/help lane.
- [ ] Verified metadata wrappers do not quietly become the controlling summary of what voters should do.

## Drift and recovery posture

- [ ] Checked whether source-file metadata and collection/playlist display metadata can drift and, if so, whether the drift was reviewed.
- [ ] Checked whether corrected or superseded media was relabeled consistently across relevant wrappers.
- [ ] Verified the canonical office page or named office contact remains recoverable when wrapper metadata is incomplete, stale, or misleading.

## Public proof posture

- [ ] Logged which wrapper states were reviewed and when.
- [ ] Avoided publishing individualized watch analytics, recommendation traces, or internal marketing/admin histories.
