# Official voter-information platform restriction surface checklist

Use this checklist when official voter-information media may resolve to a platform-native unavailable, private, age-gated, region-blocked, org-only, or playback-restricted shell.

## Scope

- [ ] Reviewed the actual restriction states in scope (private, unlisted/link-limited, org-only/invite-only, age-restricted, region-blocked, embed/domain denied).
- [ ] Distinguished restriction shells from the underlying current written/help lane.
- [ ] Recorded which platforms, embeds, or destinations were materially relied on.

## Currentness and recovery

- [ ] Verified restricted or unavailable media shells stay subordinate to the current written/help lane for action-changing questions.
- [ ] Verified the public can still recover the canonical office page or named office contact when playback is denied.
- [ ] Verified restriction messages do not overclaim final absence of official guidance.
- [ ] Verified private or organization-only media is not being treated as the ordinary public instruction lane.

## Restriction-state review

- [ ] Checked whether signed-out or age-gated playback silently turns a public route into a platform-account detour.
- [ ] Checked whether embed/domain limits materially change what the public sees compared with the source media page.
- [ ] Checked whether region or permission variance creates materially different availability stories for different viewers.

## Public proof posture

- [ ] Logged which restriction states were reviewed and when.
- [ ] Avoided publishing individualized access logs, account rosters, or viewer-location telemetry.
