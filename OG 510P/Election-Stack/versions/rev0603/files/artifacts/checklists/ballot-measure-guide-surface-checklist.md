# Ballot-measure guide surface checklist

- Identify one authoritative public guide / pamphlet path and one authoritative help path.
- State whether the guide is draft-for-public-display, final, or superseded.
- State the guide’s scope clearly: statewide, regional, countywide, precinct-sensitive, or voter-customized.
- For each measure, publish bounded pointers to the official title, summary, explanatory statement, fiscal impact text, full text, and arguments where those components exist.
- Publish a clear warning when the guide may include measures or races that do not appear on a given voter’s ballot, and point to the authoritative voter-specific ballot lookup.
- Keep online, printable, mailed, translated, audio, and video versions aligned; publish a parity snapshot or correction notice when they diverge.
- Treat changed explanatory statements, changed fiscal-impact links, translation changes, edition-status changes, and silent PDF swaps as explicit superseding events, not quiet edits.
- Distinguish proposed-measure information pages from final certified-on-the-ballot guide pages.
- Publish translated and accessible versions where required, plus a fallback contact path when the primary guide surface fails.
- Do not copy full guide text into general-purpose archive prose when stable pointers and digests suffice.
- Record `last_verified_at` and the latest correction/advisory notice pointer.
