# Source-byte receipt pack

**Track:** Shared

These receipts record one successful byte observation for selected pinned external-source rows. The archive intentionally does **not** bundle the third-party source bytes; operators can place downloaded bytes in an external cache and compare them with the recorded `observed_sha256` and the canonical lockfile pin.

Boundary: source-byte receipts are not current voter instruction, not legal advice, not source-byte cache completeness, not public-release authorization, and not live-pilot approval.
