# Remote proofing checklist (optional subsystem)

**Track:** Shared (cross-cutting)


- [ ] Clearly label remote proofing as optional; provide in-person alternative.
- [ ] Define target IAL/AAL and publish rationale.
- [ ] Ban SMS-only verification; require phishing-resistant authentication.
- [ ] Document fraud controls: liveness, document validation, anomaly detection.
- [ ] Provide human review + appeal path.
- [ ] Privacy: minimize retention; separate proofing store from voting systems.
- [ ] Publish a kill-switch condition (fraud surge, vendor incident).
- [ ] Independent audit of vendor components.
