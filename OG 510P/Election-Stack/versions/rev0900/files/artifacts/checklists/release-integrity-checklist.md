# Release integrity checklist (election-grade)

**Track:** Shared (cross-cutting)


- [ ] Reproducible build verified by >= 2 independent parties
- [ ] SBOM generated and signed
- [ ] Provenance attestation generated and signed
- [ ] Dependencies pinned; diff reviewed
- [ ] Update repository protected with threshold roles
- [ ] Canary rollout plan + rollback plan tested
- [ ] Public hashes and verifier binaries published
