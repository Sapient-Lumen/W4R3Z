# Accessibility/language publication checklist

**Synthetic support checklist only. This is not legal advice, not a formal accessibility certification, not a Section 203 coverage determination, and not current voter instruction.**

Use this before any local evidence-derived public artifact is published. Record reviewer names, dates, exception reasons, and the official channel where the approved text will appear.

## Minimum release checks

1. Plain-language public answer exists and avoids unexplained acronyms, legal conclusions, and speculation.
2. The public answer has an accessible text version; it is not image-only, screenshot-only, map-only, video-only, or PDF-only.
3. Keyboard, focus, headings, labels, contrast, zoom/reflow, and status-update behavior have been checked for the target public surface.
4. Required or locally supported language versions carry equivalent deadlines, correction status, official-channel links, and safety boundaries.
5. Alternate-format and human-help routes are visible where voters may need assistance.
6. Emergency, correction, and safety notices propagate across the same accessibility and language surfaces as ordinary notices.
7. AI-assisted translation, simplification, or summary has named human approval and does not make eligibility, legal, or rights-affecting determinations.
8. Privacy/redaction review has already separated public and private fields.
9. Source freshness has been checked for any current voter instruction.
10. Any exception is documented with an owner, reason, expiration, and safer fallback sentence.

## Stop conditions

Stop publication if a voter-facing artifact lacks a text equivalent, human help route, local language/accessibility review, correction propagation, or source freshness for current instructions. Stop also if reviewers cannot determine whether a translated/simplified version matches the approved source text.
