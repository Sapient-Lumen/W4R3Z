# Polling-place intimidation public-answer checklist

Use for voter-facing answers about intimidation, aggressive observers, unsafe conditions, or challenge pressure.

- [ ] Start with safety and the right to seek help from poll workers or election officials.
- [ ] Do not identify the voter publicly or request unnecessary personal details.
- [ ] Distinguish electioneering boundary issues, observer/challenger conduct, law-enforcement presence, and ordinary line management.
- [ ] Route emergencies to local emergency services and non-emergency election issues to the official election office.
- [ ] Provide the jurisdiction-specific official contact path when available.
- [ ] Preserve evidence safely: time, location, description, witness names if voluntarily provided, and any official incident number.
- [ ] Do not make a legal conclusion; state what the official escalation path is.
