# Provisional-ballot status surface checklist

- Name one authoritative free-access status path and one authoritative help/complaint path.
- Publish the exact voter-facing status labels and not-counted reason labels with plain-language explanations.
- Preserve the privacy rule: do not broaden access beyond the individual provisional voter.
- Publish effective dates/times and a freshness note for the current public answer surface.
- Publish accessible and translated versions where required, plus the fallback path when the primary portal or toll-free system fails.
- Treat reason-language changes, deadline/help-path changes, and outages as explicit superseding notices, not silent edits.
- Check parity across website, toll-free instructions, voter handouts, hotline/help scripts, and signed notices.
- Do not publish searchable voter lists, affidavits, IDs, signatures, challenge statements, or investigative notes.
- Record `last_verified_at` and the latest correction notice pointer.
- Keep a bounded capture note for each major correction or outage so third parties can reconstruct what voters were told at time `T`.
