# Voting-accessibility accommodations surface checklist

- Name one authoritative public path for accessibility/accommodation information and one authoritative help path.
- Publish site-specific accessibility facts, not one generic “accessible voting available” sentence for every location.
- Publish whether an accessible voting device or equivalent accessible voting method is available and how a voter asks for it.
- Publish whether curbside or another alternate access path is available, plus exactly how a voter alerts election workers or requests assistance.
- Publish the bounded vocabulary used for site accessibility features, curbside status, and alternate-path notices.
- Treat blocked entrances, equipment outages, curbside changes, and alternate-path changes as explicit superseding notices, not silent edits.
- Check parity across website, downloadable handout/PDF, hotline/help script packet, site signage, poll-worker quick-reference material, and signed notices.
- Publish accessible and translated versions where required, plus a fallback path when the primary accessibility-information page fails.
- Do not publish disability disclosures, individualized accommodation requests, medical information, or staff-only incident narratives.
- Record `last_verified_at` and the latest correction notice pointer.
