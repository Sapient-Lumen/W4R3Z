# Runoff and special-election participation surface checklist

- Identify one authoritative public path for runoff/special-election participation rules and one authoritative help path.
- State what kind of election this is (`special_election`, `special_runoff`, `primary_runoff`, or other local term) using the jurisdiction's own terminology plus a bounded plain-language explanation.
- State the covered district, counties, precincts, or partial-county territory clearly enough to avoid a false countywide answer.
- State whether ordinary registration in scope is enough, whether party carry-forward matters, whether prior-round participation is required, or whether another clearly described rule controls participation.
- State any registration deadline, affiliation timing, or “if needed” runoff timing that materially changes voter actionability.
- Distinguish calendar facts from scope/participation facts; do not force voters to infer “am I in this election?” from a date page alone.
- Treat changed district scope, changed runoff dates, changed registration timing, and changed party-carry-forward semantics as explicit superseding notices, not silent edits.
- Check parity across current-election pages, proclamations/call notices, FAQs, downloadable guides, hotline/help scripts, and signed notices.
- Publish accessible and translated versions where required, plus a fallback contact path when the scope page fails.
- Do not publish individualized district traces, prior-round party rosters, or copied legal text when a bounded summary plus pointer will do.
- Record `last_verified_at` and the latest correction/advisory notice pointer.
