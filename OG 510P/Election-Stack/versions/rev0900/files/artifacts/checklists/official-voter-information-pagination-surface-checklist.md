# Official voter-information pagination surface checklist

Use this checklist for official voter-information routes that split answer-bearing directories, search results, office lists, or article collections across numbered pages.

## Scope and route inventory

- [ ] Identify the official routes where answer-bearing result sets are split across pages.
- [ ] Record what the public is paging through: locations, offices, articles, FAQs, or another continuous official set.
- [ ] Record whether pagination is being used for amount-based splitting rather than hiding a meaningful topic boundary.
- [ ] Record whether compact/mobile variants, page-size controls, or filter/sort controls materially change page boundaries.

## Page-to-page meaning

- [ ] The current page is indicated both visibly and programmatically rather than by color or styling alone.
- [ ] Numbered links and previous/next/first/last controls make clear that they continue the same result set and where they will go.
- [ ] The route makes the existence of more pages or the end of the set legible enough that page 1 does not masquerade as the whole official answer set.
- [ ] The route distinguishes no-results, end-of-set, and more-pages-exist states instead of leaving the public to guess.

## Placement and continuity

- [ ] Pagination was checked to confirm it remains in a predictable relative location across the set when present.
- [ ] Compact/mobile pagination was reviewed so condensed numbering or ellipsis states do not erase continuation meaning.
- [ ] If page-size, sort, or filter controls exist, the review records whether they materially change which page contains the controlling answer.
- [ ] If the route uses cards or tables inside each page, the review records any dependency on `446` or `447` rather than assuming page-to-page continuity alone is sufficient.

## Evidence discipline

- [ ] The review records which routes were checked, how the current page is indicated, and how continuation/end-of-set cues are exposed.
- [ ] The review records when the check occurred and which route/version or layout variant was observed.
- [ ] The archive does not retain named-user clickstreams, raw query logs, or individualized assistive-technology traces for this bounded surface.
