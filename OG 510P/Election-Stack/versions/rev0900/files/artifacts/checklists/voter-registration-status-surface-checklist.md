# Voter registration status surface checklist

- Identify one authoritative public status-check path and publish it consistently across official channels.
- Publish the exact public status labels voters may see, with plain-language explanations.
- Publish the official next step for unresolved / not-found / update-needed cases.
- Publish accessibility-format indicators and minority-language availability for the lookup/help path.
- Record the effective time window for the current public answer surface.
- Treat outages, degraded service, and materially changed status guidance as explicit superseding events.
- Preserve a signed/publicly referenceable correction trail; do not silently replace help-path text.
- Do not publish voter records, matching logic, sensitive identifiers, or tiny-cell analytics.
- Verify parity between portal, state information page, hotline/help script, and signed notices.
- Keep a bounded capture note for each major correction or outage so third parties can reconstruct what voters were told at time `T`.
