# Official voter-information bypass-blocks surface checklist

Use this checklist for official voter-information routes where repeated banner/header/navigation chrome sits before the answer-bearing main content.

## Scope and repeated-block inventory

- [ ] Identify the official routes where repeated government/site chrome materially sits before the current answer/help lane.
- [ ] Record which repeated blocks are in scope: government banner, site header, utility navigation, megamenu, search box, breadcrumb rail, alert bar, or route-local navigation.
- [ ] Record whether the repeated-block burden changes materially on mobile, zoomed, or menu-expanded views.

## Bypass mechanism and landing target

- [ ] The route was checked to confirm there is a practical mechanism for bypassing repeated blocks before the main answer lane.
- [ ] The primary bypass mechanism lands at the beginning of the main answer/help content rather than at an empty wrapper, decorative hero, hidden heading, or another repeated control cluster.
- [ ] If the route has multiple significant repeated blocks, the review records whether one bounded bypass is sufficient or whether another bypass mechanism is needed.
- [ ] The route does not rely on a nominal skip link that appears only on some templates or breaks on the pages voters actually use.

## Mobile/header/banner variants

- [ ] Mobile header, menu-button, and government-banner variants were checked because they can materially increase repeated traversal burden.
- [ ] The bypass path remains usable when the page uses an extended header, megamenu, stacked utility links, or other heavier repeated chrome.
- [ ] Route-local repeated navigation appearing before the answer lane was reviewed rather than assumed harmless.

## Evidence discipline

- [ ] The review records which routes and repeated blocks were checked and where the primary bypass path lands.
- [ ] The review records when the check occurred and which route/version was observed.
- [ ] The archive does not retain named-user keystroke logs, raw session replay, or individualized assistive-technology traces for this bounded surface.
