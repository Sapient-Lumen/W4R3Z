# Same-day registration surface checklist

- Identify one authoritative public same-day-registration path and one authoritative help path.
- Publish the exact public terminology in use and explain it in plain language.
- Publish where the path is available, including vote-center-only / office-only / assigned-site constraints and the applicable hours.
- Publish the bounded documentary classes required for each relevant case; do not rely on generic “bring ID” language.
- Publish whether each case leads to a regular ballot, provisional ballot, or another official resolution path.
- Publish accessibility-format indicators and minority-language availability for the same-day-registration/help path.
- Treat changed locations, hours, proof requirements, and ballot-path guidance as explicit superseding events.
- Preserve a signed/publicly referenceable correction trail; do not silently replace site or proof guidance.
- Do not publish voter files, proof-document scans, challenge notes, or internal adjudication logic.
- Verify parity between website, location finder, hotline/help script, downloadable handout, site signage, and signed notices.
