# Official voter-information empty-state surface checklist

Use this checklist for official voter-information routes that can produce a **zero-results state**, **empty state**, **no-match screen**, or **empty answer-bearing collection** after search, scoping, filtering, or similar public retrieval steps.

## Query/scope clarity

- [ ] Record which official routes can show a zero-results or empty-state outcome.
- [ ] Record what query text, collection, jurisdiction scope, date window, or active subset remains visible when the route is empty.
- [ ] Review whether the empty state clearly says what was searched or narrowed instead of looking like a generic official “no” page.
- [ ] Review whether the route distinguishes a query/subset miss from a real official negative answer that should instead live on a current page or notice.

## Recovery posture

- [ ] Review whether the empty state offers a truthful clear/reset path when the current narrowing condition can be removed.
- [ ] Review whether the route offers a broader-scope or “all official results” option when narrower collections or subsets may be hiding relevant items.
- [ ] Review whether common high-impact empty states can expose a current recommended destination instead of only a generic retry prompt.
- [ ] Review whether the authoritative office/help route remains reachable when the surface cannot safely resolve the case.
- [ ] Review whether recovery links clearly describe what they do and where they lead.

## Accessibility and dynamic updates

- [ ] Review whether query terms persist into the empty state so users can verify what they asked.
- [ ] Review whether zero-result and recovery updates are exposed as status changes without unnecessary focus movement.
- [ ] Review headings, labels, and link purpose so the empty-state region remains navigable and understandable to screen-reader, keyboard, and magnifier users.
- [ ] Review the implemented route, not only isolated component previews, for compact/mobile layouts where active scope or recovery controls may disappear.

## Evidence discipline

- [ ] Preserve a small public digest of empty-state classes, visible query/scope context, recovery routes, and verification time.
- [ ] Preserve bounded review evidence for recurring no-result or low-click dead ends when the office monitors them.
- [ ] Do not retain person-level raw query logs, click trails, session replay, or other analytics exhaust merely to prove an empty state existed.
