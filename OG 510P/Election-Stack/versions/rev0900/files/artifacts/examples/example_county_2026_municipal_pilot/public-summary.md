# Example County 2026 Municipal public summary

**Synthetic example only. This is not live election evidence.**

## What this exercise shows

The scenario shows how official election-information artifacts can be published as digest-bound packets. A verifier can check that each listed packet is internally consistent, that the payload bytes match the declared digests, and that the verifier output names any failures with stable problem codes.

## What this exercise does not show

This exercise does not prove that an election outcome is correct. It does not replace canvass, audit, certification, recount, or court procedure. It does not turn missing evidence into proof of intent or fraud.

## Public explanation phrases

- Digest: this file is the same file witnesses saw.
- Missingness: the expected notice was not found by the stated deadline.
- Parity divergence: different audiences saw different official information.
- Witness set: these independent parties checked the same artifact.
- Key rotation: the signing key changed; here is the signed explanation.
- Verifier report: this packet passed or failed these checks.

## Minimum public release packet

A live pilot should publish the official-channel directory, notice feed, election-parameter bundle, witness set, results or closeout packet, verifier report, public-language summary, and a drill-run ledger row. Synthetic placeholders must be replaced before making live claims.
