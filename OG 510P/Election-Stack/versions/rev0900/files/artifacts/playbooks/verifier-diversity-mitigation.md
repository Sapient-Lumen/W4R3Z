# Verifier diversity mitigation playbook (anti-monoculture)

**Track:** Shared (cross-cutting)


Use this playbook when the verifier ecosystem becomes a monoculture (single implementation or single org).

## Actions
- Publish current ecosystem diversity metrics and gaps.
- Activate:
  - `CHECK:artifacts/checklists/multi-perspective-validation-checklist.md`
  - `CHECK:artifacts/checklists/monitor-accountability-checklist.md`

## Engineering mitigations
- Multiple independent verifier implementations with cross-checks.
- Reproducible builds and supply-chain attestations for verifier binaries.

## Governance mitigations
- Independent funding and conflict-of-interest disclosures.
