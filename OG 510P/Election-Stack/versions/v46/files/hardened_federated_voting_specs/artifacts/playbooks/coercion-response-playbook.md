# Coercion / vote-buying response playbook (Track B)

This playbook is for coercion / vote-buying signals in remote or high-risk contexts.

## Actions
- Activate `CHECK:artifacts/checklists/registration-coercion-checklist.md`
- Publish an incident comms package:
  - `TEMPLATE:artifacts/templates/incident-communications.md`

## Evidence posture
- Avoid collecting evidence that deanonymizes voters.
- Prefer aggregate indicators and third-party reports.

## Policy options
- Revoting windows, credential reissuance, and escalation paths should be pre-committed where possible.
