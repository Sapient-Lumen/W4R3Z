# Public inspection challenge checklist

- [ ] Challenge defines clear window (start/end)
- [ ] Targets include at least one canary (known-good inclusion)
- [ ] Challenge is signed and anchored (PBB/ATL)
- [ ] Same challenge is issued to >=2 independent monitors
- [ ] Responses are signed and include evidence references
- [ ] Inconsistencies are published as `MonitorInconsistencyReport`
- [ ] Rate limiting prevents challenge spam / DoS
