# Measurement ethics checklist

- [ ] Menlo-style stakeholder analysis performed
- [ ] Targets restricted to owned endpoints or documented public controls
- [ ] No scan-like behavior (no port sweeps, no brute-force, no large payloads)
- [ ] Purpose + contact statement published
- [ ] OONI usage avoids re-identification and respects API rate guidance
- [ ] Emergency override process documented with two-person approval
