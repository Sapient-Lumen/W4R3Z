# Witness Memorandum of Understanding (template)

**Track:** Shared (cross-cutting)


Non-legal outline to clarify expectations for independent witnesses.

## Purpose
Witness operates an independent monitor for the election PBB transparency log, verifying consistency and publishing evidence of misbehavior.

## Commitments
- run monitor software and publish signed status
- gossip checkpoints to peer witnesses
- publish fork proofs if equivocation is observed
- disclose incidents affecting witness integrity

## Independence
Witness affirms operational independence from the log operator.

## Key management
Hardware-backed signing keys, dual control, documented rotation.

## Transparency
Publish software versions/hashes, monitoring policy, contact channels.
