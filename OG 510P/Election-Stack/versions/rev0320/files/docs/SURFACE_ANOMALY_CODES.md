# Surface anomaly codes

**Track:** Shared

This file is generated by `scripts/gen_surface_anomaly_codes.py`.

Codes are intended to be **publishable** (small, stable) and comparable across implementations.
They are designed for *notes fields* in monitoring payloads (e.g., `PublicSurfaceParitySnapshot` and `LivenessBeacon`).
Context MAY follow after `:` for local debugging, but public artifacts SHOULD be able to publish only codes.

| code | severity | meaning |
|---|---:|---|
| `surface_age_divergence` | `WARN` | Age header differs materially across watchers/channels for the same surface |
| `surface_body_hash_changed` | `WARN` | Observed body digest differs from a previous/pinned digest for the same surface |
| `surface_cache_control_divergence` | `WARN` | Cache-Control differs across watchers/channels for the same surface |
| `surface_content_type_unexpected` | `WARN` | Content-Type differs from the expected media type for this surface |
| `surface_effective_state_divergence` | `FAIL` | Computed effective current state (docs/220) diverged across official channels outside holdback window |
| `surface_envelope_kind_unexpected` | `WARN` | Parsed EvidenceEnvelope.kind differs from expected kind for this surface |
| `surface_envelope_parse_failed` | `WARN` | Surface body could not be parsed as an EvidenceEnvelope JSON object |
| `surface_envelope_payload_digest_missing` | `WARN` | Parsed EvidenceEnvelope is missing a valid payload_digest |
| `surface_envelope_tbs_digest_missing` | `WARN` | Parsed EvidenceEnvelope is missing a valid tbs_digest |
| `surface_etag_divergence` | `WARN` | ETag differs across watchers/channels for the same surface |
| `surface_fetch_failed` | `FAIL` | Surface fetch failed (no usable HTTP response captured) |
| `surface_freshness_headers_missing` | `WARN` | Expected freshness headers were missing (etag/last-modified/cache-control) |
| `surface_http_status_unexpected` | `WARN` | HTTP status did not match the expectation for this surface |
| `surface_last_modified_divergence` | `WARN` | Last-Modified differs across watchers/channels for the same surface |
| `surface_pointer_digest_mismatch` | `FAIL` | Pointer digest disagrees with the fetched envelope/payload digest |
| `surface_pointer_digest_missing` | `WARN` | Pointer field missing an expected digest needed for comparability |
| `surface_stale_pointer_suspected` | `WARN` | Freshness headers suggest a stale cached response (review Age/ETag/CC) |
| `unknown_surface_anomaly_code` | `FAIL` | Unknown surface anomaly code (update the registry) |
