# Election-office contact directory surface checklist

- Identify one authoritative public office-contact path and, if needed, one authoritative office-directory path.
- Publish the office name, scope, and public issue classes it handles.
- Publish each official contact method separately rather than burying phone, email, and address details in prose.
- Publish office hours with timezone semantics and any known closure exceptions.
- Publish the alternate official path when the main hotline, webform, or building is unavailable.
- Distinguish main office, satellite office, and special-purpose help paths when routing changes voter actionability.
- Treat changed phone numbers, addresses, office hours, closures, and reroutes as explicit superseding notices, not silent edits.
- Check parity across website, PDFs, hotline scripts, social posts, and signed notices.
- Publish accessible and translated contact/help paths where required, plus relay or alternate communication methods when available.
- Do not publish personal staff contact information, internal escalation trees, or per-voter case records.
- Record `last_verified_at` and the latest correction or closure notice pointer.

- Record at least one direct jurisdiction discovery anchor for the named office/path (current office page, signed reroute notice, or official state/local directory entry).
- If a state directory, EAC, NASS, or Vote.gov router was used to find the office, record that bounded corroborator rather than treating the final office page as if it appeared from nowhere.
- If discovery paths disagree on the responsible office, current phone/address/webform, or live reroute state, mark the routing status explicitly and publish a superseding note instead of silently choosing one path.
- Record when the responsible office/path was last directly confirmed, separate from ordinary office-hours verification.
