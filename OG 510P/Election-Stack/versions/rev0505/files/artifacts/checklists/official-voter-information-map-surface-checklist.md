# Official voter-information map surface checklist

- Inventory each official public map, pin layer, nearest-site view, “use my location” helper, and directions-link surface the public is expected to rely on.
- Make the delivery role explicit: the map helps the voter reach the current controlling official destination; it does not become the rule source by itself.
- Keep the current official site page, reroute notice, office directory entry, or help lane recoverable from the map result.
- Distinguish official place state from external directions-service state so routing estimates do not masquerade as election rules.
- Keep precise geolocation optional when manual address, ZIP, or browsable list paths can safely do the job.
- Preserve a visible manual no-geolocation fallback.
- Do not retain raw coordinates, address-search trails, or route histories longer than the published policy requires.
- Do not turn a public map into a shadow case-management or protected-voter-triage surface.
- Keep moved sites, changed entrances, temporary closures, and reroutes reflected through explicit pin updates, removals, or superseding notices rather than silent stale markers.
- Do not let pop-up snippets present old hours, past-election scope, or stale entrance instructions as if still current.
- Use a small result-state taxonomy so the surface can distinguish current exact site, current scoped site, reroute/conflict result, and unsupported map path.
- Preserve a bounded map trace for action-changing outputs, including map version, layer policy version, result anchors, result-state class, mode of lookup, and timestamp.
- Keep the office/help fallback visible, including the current official contact path and phone number when one exists.
- Keep rights/safety escalation visible when the issue has moved beyond ordinary site-finding or public-help routing.
- If directions links open an external or non-federal service, mark that handoff clearly and keep the official site page as the controlling election-information destination.
- Re-check the map surface after site moves, entrance changes, hours changes, reroute notices, early-voting schedule changes, drop-box changes, office-routing changes, or superseding notices.
- When material pin, layer, entrance, or directions-target behavior changes, publish an explicit update/superseding note instead of relying only on silent map edits.
