# Primary-election participation surface checklist

- Identify one authoritative public path for primary-participation rules and one authoritative help path.
- State which primary model applies, using the jurisdiction's own public terminology plus a bounded plain-language explanation.
- State whether ballot eligibility depends on party affiliation on record, party choice at voting time, no party linkage, or another clearly described rule.
- State whether a deadline to change affiliation or update registration materially affects participation.
- State whether same-day affiliation change or declaration is allowed, if applicable.
- Explain whether nonpartisan contests, ballot questions, or presidential-primary variants alter the simplified answer.
- Treat changed participation semantics, changed deadlines, and changed declaration rules as explicit superseding notices, not silent edits.
- Check parity across website, FAQs, downloadable guides, hotline/help scripts, and signed notices.
- Publish accessible and translated versions where required, plus a fallback contact path when the primary-rules page fails.
- Do not publish voter party-registration rolls, individualized participation histories, or copied legal text when a bounded summary plus pointer will do.
- Record `last_verified_at` and the latest correction/advisory notice pointer.
