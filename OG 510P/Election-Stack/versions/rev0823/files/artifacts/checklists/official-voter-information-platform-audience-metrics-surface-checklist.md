# Official voter-information platform audience-metrics surface checklist

Use this checklist when official voter-information media exposes public view counts, concurrent-viewer labels, like/reaction totals, registration or attendance totals, or similar platform-native audience metrics.

## Scope

- [ ] Reviewed the exact public media or event route whose counts mattered, not just a private analytics console.
- [ ] Distinguished visible on-screen metrics from office-facing analytics or exported reports.
- [ ] Recorded which platform, route, and device contexts were materially relied on.

## Metric-definition review

- [ ] Verified which metric names actually appeared or were quoted (for example: concurrent viewers, peak concurrent, live views, replay views, likes, registrations, or attendance).
- [ ] Verified whether platform documentation described the metric as filtered, delayed, hidden, or otherwise incomplete.
- [ ] Verified whether live, replay, registration, and attendance counts could diverge in ways the public might mistake for the same number.

## Authority-boundary review

- [ ] Verified the office did not let popularity or audience size stand in for currentness, legal effect, or officiality.
- [ ] Verified the current written/help lane remained recoverable even if metrics were absent, lagged, hidden, or disputed.
- [ ] Verified quoted numbers were identified as platform metrics rather than formal election-admin proof objects.

## Cross-route and reporting review

- [ ] Checked whether counts differed across native, embedded, mirrored, replay, or attendee-only routes.
- [ ] Checked whether any later office statement quoted a public on-screen number or a private/exported analytics number.
- [ ] Logged any exclusions or counting caveats that materially changed interpretation.

## Public proof posture

- [ ] Logged the metric-bearing route, the metric names reviewed, and when the review occurred.
- [ ] Avoided publishing individualized audience logs, private analytics dashboards, or unnecessary viewer-identifying traces.
