# Early-voting site-hours surface checklist

- Name one authoritative public path for early-voting sites and hours and one authoritative help path.
- Publish site hours as explicit date/time windows, not only as prose or image text.
- Publish the exact status labels used for `scheduled`, `open`, `delayed_open`, `moved`, `closed`, and `superseded` states where applicable.
- Publish effective dates/times and a freshness note for the current public answer surface.
- Treat closures, relocations, delayed openings, and hour changes as explicit superseding notices, not silent edits.
- Check parity across website, downloadable PDF/handout, hotline/help script packet, map/listing surface, and signed notices.
- Publish accessible and translated versions where required, plus the fallback path when the primary directory or map fails.
- Name the replacement site, replacement hours, or official alternate path whenever a change affects voter actionability.
- Do not publish staffing rosters, floor plans, camera placement, or minute-by-minute turnout for tiny sites.
- Record `last_verified_at` and the latest correction notice pointer.
