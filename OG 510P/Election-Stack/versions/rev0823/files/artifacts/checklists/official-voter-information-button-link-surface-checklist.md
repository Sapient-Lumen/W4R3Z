# Official voter-information button/link surface checklist

Use this checklist for official voter-information routes where **buttons, links, CTA bars, or link-styled buttons carry the voter toward a controlling destination or next step**.

## Control truth review

- [ ] Record which controls on the route are ordinary navigation destinations versus in-page actions, submit actions, downloads, or communication-channel launches.
- [ ] Review whether visually emphasized controls still make clear when they navigate to another official page.
- [ ] Review whether button labels describe an action and link labels describe a destination or next route clearly enough that the next step is not surprising.
- [ ] Review whether nearby controls with similar wording do materially different things without adequate distinction.
- [ ] Review whether the route distinguishes reversible exploration controls from committing submit or confirm actions.

## Grouping, semantics, and continuity

- [ ] Review whether grouped controls preserve which action is primary and which controls are optional secondary help or utility actions.
- [ ] Review whether navigation destinations use truthful link semantics and in-page actions use truthful button semantics unless a more specific native control fits better.
- [ ] Review whether compact/mobile layouts preserve the same meaning and ordering of prominent controls.
- [ ] Review whether destination-link text remains close enough to the landing page title or official route name that the page transition is understandable.
- [ ] Review whether controls that open overlays, downloads, calls, or email routes make that different next-step posture visible.

## Accessibility and evidence review

- [ ] Review whether keyboard and assistive-technology expectations remain aligned with what each prominent control actually does.
- [ ] Review whether links styled as buttons still preserve truthful destination posture instead of looking like harmless current-page actions.
- [ ] Preserve a small public digest of which prominent controls were reviewed and how navigation-versus-action meaning was classified.
- [ ] Do not retain individualized click trails, session replay, or similar interaction exhaust merely to prove that a control label once existed.
