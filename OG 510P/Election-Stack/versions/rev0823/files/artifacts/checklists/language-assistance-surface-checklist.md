# Language assistance surface checklist

- Identify one authoritative public path for language-assistance information and one authoritative help path.
- Publish the exact supported languages and the material classes available in each language.
- Publish the official oral-assistance path when a written translation is unavailable or insufficient.
- Publish accessibility-format indicators and minority-language availability for the help path.
- Record the effective time window for the current public answer surface.
- Treat changed supported-language coverage, translated materials, and help routing as explicit superseding events.
- Preserve a signed/publicly referenceable correction trail; do not silently replace translated links or hotline guidance.
- Do not publish per-voter language preferences, interpreter rosters, or internal translation drafts.
- Verify parity between website, translated handouts, hotline/help script, site signage, and signed notices.
- Keep a bounded capture note for each major change so third parties can reconstruct what voters were told at time `T`.
