# Official voter-information scan-order surface checklist

Use this checklist for official voter-information routes whose layout or promotion choices can change the apparent order of answer-bearing content.

## Scope and sequence inventory

- [ ] Identify the official routes where cards, panels, promoted blocks, sidebars, or grouped controls create a meaningful answer sequence.
- [ ] Record whether the route uses flex/grid reversal, explicit order utilities, featured-slot promotion, or breakpoint-specific block movement.
- [ ] Record which answer-bearing blocks become misleading if visual order, source order, and focus order diverge.

## Source order, visual order, and focus travel

- [ ] The route was checked to confirm that source order still reflects the meaningful answer sequence presented visually.
- [ ] Keyboard focus moves through interactive elements in an order that follows the route’s visible relationships and priorities.
- [ ] Featured or recommended answer blocks do not rely on CSS placement alone to appear first or most important.
- [ ] Reversal or explicit order utilities are not being used as a substitute for correct logical source ordering on answer-bearing content.

## Responsive layout and promoted content

- [ ] Desktop and narrow layouts were checked for sequence drift when columns wrap, sidebars restack, or promoted blocks move.
- [ ] A visually first or highlighted card remains explicit enough that users who encounter it later in source order are not misled.
- [ ] Grouped answer lanes preserve a meaningful top-to-bottom sequence when the layout collapses to one column.
- [ ] If sequence meaning changes across breakpoints, the route makes that change explicit rather than implying the same priority in different orders.

## Evidence discipline

- [ ] The review records which routes/layout variants were checked and whether any order utilities or promoted slots were in play.
- [ ] The review records when the check occurred and which route/version was observed.
- [ ] The archive does not retain named-user keyboard traces, raw session replay, or individualized assistive-technology exhaust for this bounded surface.
