# Official voter-information card/collection surface checklist

Use this checklist for official voter-information routes that present answer-bearing choices as cards, tiles, panels, or collection items.

## Scope and group inventory

- [ ] Identify the official routes where cards/tiles/collection items carry current answer paths, office routing, deadlines, status, or next-step instructions.
- [ ] Record which card groups are decisive enough that a voter must choose the right item to learn what controls.
- [ ] Record whether the route uses a one-column list, multi-column card grid, featured card, collection list, or mixed heading/button treatment.

## Grouping, headings, and meaning

- [ ] Card groups are represented with clear structure so repeated items are programmatically and visually distinguishable.
- [ ] Card headings are specific enough to distinguish the controlling path from adjacent lookalike cards.
- [ ] Badges, dates, tags, icons, or “current/important” labels do not carry essential meaning without nearby explanatory text.
- [ ] The route does not depend on visual style alone to tell informational cards from action-bearing cards.

## Links, actions, and destination clarity

- [ ] Links/buttons on each card clearly communicate where they go or what action they trigger.
- [ ] The route does not repeat vague CTA text across several cards unless surrounding context makes each destination unmistakable.
- [ ] If the whole card is clickable, the visible heading, summary, and actual destination remain aligned.
- [ ] Multiple interactive elements inside the same card do not create ambiguity about which destination is the authoritative next step.

## Responsive layout and scan order

- [ ] Narrow-screen and zoomed views were checked so wrapping/reordering does not bury the controlling card or change the apparent priority silently.
- [ ] Reading order stays meaningful when cards stack vertically or media moves relative to headings/text.
- [ ] Featured or priority cards remain explicitly identified rather than depending only on desktop placement.
- [ ] There is a visible help or overview escape path when no card clearly resolves the voter’s case.

## Evidence discipline

- [ ] The review records which card groups were checked, which layout variants were observed, and whether heading/destination clarity was part of the answer lane.
- [ ] The review records when the check occurred and which route/version was observed.
- [ ] The archive does not retain named-user click paths, individualized hover traces, or unnecessary replay exhaust for this bounded surface.
