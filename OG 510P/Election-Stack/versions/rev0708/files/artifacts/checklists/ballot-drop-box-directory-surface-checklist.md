# Ballot drop-box directory surface checklist

- Name one authoritative public path for official ballot drop boxes and one authoritative help path.
- Publish drop-box availability as explicit date/time windows, not only as prose or image text.
- Publish the exact status labels used for `available`, `temporarily_unavailable`, `moved`, `closed`, and `superseded` states where applicable.
- Publish the operative deposit-deadline semantics for each box or class of boxes, especially when indoor building hours differ from election-law deadlines.
- Treat closures, relocations, temporary disablements, and deadline clarifications as explicit superseding notices, not silent edits.
- Check parity across website, downloadable instructions/PDF, mailed instruction sheet, hotline/help script packet, map/listing surface, and signed notices.
- Publish accessible and translated versions where required, plus the fallback path when a box is unavailable or inaccessible.
- Name the replacement drop box, local office return option, mail path, or other official alternate path whenever a change affects voter actionability.
- Do not publish collection routes, chain-of-custody logs, camera placement, or other sensitive operational-security detail.
- Record `last_verified_at` and the latest correction notice pointer.
