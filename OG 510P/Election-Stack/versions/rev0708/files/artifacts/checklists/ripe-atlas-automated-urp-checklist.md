# RIPE Atlas automated URP checklist

**Track:** Shared (cross-cutting)


- [ ] Measurement ethics policy approved (`EthicsGuardrailsPolicy`)
- [ ] Targets allow-listed + stakeholder analysis recorded
- [ ] Rate caps configured + enforced in tooling
- [ ] Control targets selected and documented
- [ ] Probe cohort selection rules reviewed (avoid bias; ensure minimum probes)
- [ ] API key stored in vault/HSM; access logged; break-glass documented
- [ ] Measurement plan committed in EPB / evidence bundle before use
- [ ] Runbook: what to do if RIPE Atlas is unavailable or suspends activity
- [ ] Raw results stored content-addressed; hashes recorded in URP
- [ ] URP signed and anchored to ATL within MAAD deadline
