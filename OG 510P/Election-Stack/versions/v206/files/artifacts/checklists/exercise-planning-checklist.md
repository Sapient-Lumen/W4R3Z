# Exercise Planning Checklist

## Scope & objectives
- [ ] Define objectives (detect, respond, recover, communicate)
- [ ] Define success/failure criteria
- [ ] Decide tabletop vs gameday vs red team

## Participants
- [ ] Incident commander (IC)
- [ ] Comms lead
- [ ] Legal liaison
- [ ] Ops leads (federation, witnesses, trustees, VRDB)
- [ ] Independent observer/verifier representatives

## Scenario prep
- [ ] Choose scenario card from `../../docs/90-exercise-scenario-library.md`
- [ ] Prepare inject timeline (what participants learn when)
- [ ] Prepare “facts”: checkpoint IDs, hashes, expected alerts

## Evidence
- [ ] Define evidence bundle contents and chain-of-custody
- [ ] Ensure logging is enabled (without collecting unnecessary PII)

## Communications
- [ ] Draft initial public statement + update cadence
- [ ] Confirm status page signing keys and publication path

## After action
- [ ] Assign owners for remediation items
- [ ] Schedule follow-up validation exercise
