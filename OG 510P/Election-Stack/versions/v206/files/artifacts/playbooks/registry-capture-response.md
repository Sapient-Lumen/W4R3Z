# Registry capture response (endorsement/reference-value split-view)

Use this playbook when endorsement or reference-value registries show split views or suspicious updates.

## Actions
- Trigger CT-style audits:
  - consistency proofs, gossip, and public dispute artifacts
- Activate:
  - `CHECK:artifacts/checklists/mirror-consistency-audit-checklist.md`
  - `CHECK:artifacts/checklists/monitor-accountability-checklist.md`

## Evidence obligations
- Publish competing registry views and the proofs that demonstrate inconsistency (if any).
- Publish the exact reference values/endorsements relied on for the election period.
