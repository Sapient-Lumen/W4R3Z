# Verifier problem codes
This file is generated by `scripts/gen_verifier_problem_codes.py`.
Codes are intended to be **publishable** (small, stable) and comparable across implementations.
Context MAY follow after `:` for local debugging, but public reports SHOULD be able to publish only codes.

| code | severity | meaning |
|---|---:|---|
| `attachment_hash_mismatch` | `FAIL` | Attachment digest does not match object bytes. |
| `attachment_media_type_mismatch` | `FAIL` | Attachment media_type does not match requirement. |
| `attachment_missing_digest` | `FAIL` | Attachment digest missing/invalid. |
| `attachment_missing_object` | `FAIL` | Attachment refers to missing object. |
| `attachment_missing_uri` | `FAIL` | Attachment uri missing/empty. |
| `attachment_not_object` | `FAIL` | Attachment entry is not an object. |
| `attachment_size_mismatch` | `FAIL` | Attachment size_bytes does not match object size. |
| `attachment_unsafe_uri` | `FAIL` | Attachment uri is unsafe (path traversal). |
| `attachments_not_array` | `FAIL` | Envelope attachments field is not an array. |
| `canonicalization_unsupported` | `FAIL` | Envelope requests unsupported canonicalization. |
| `envelope_version_unparseable` | `FAIL` | Envelope envelope_version is not semver. |
| `envelope_version_unsupported_major` | `FAIL` | Envelope envelope_version major not supported by this verifier. |
| `envelopes_dir_missing` | `FAIL` | Packet missing envelopes/ directory. |
| `manifest_missing` | `FAIL` | Packet missing manifest.json. |
| `manifest_url_hash_mismatch` | `FAIL` | Manifest artifact hash does not match file bytes. |
| `manifest_url_missing` | `FAIL` | Manifest artifact url points to missing file. |
| `manifest_url_size_mismatch` | `FAIL` | Manifest artifact size_bytes does not match file size. |
| `manifest_url_unsafe` | `FAIL` | Manifest artifact url is unsafe (path traversal). |
| `missing_artifact_object` | `FAIL` | Manifest references a digest that cannot be located in the packet. |
| `missing_required_attachment` | `FAIL` | Missing a required attachment rel for this kind. |
| `object_hash_mismatch` | `FAIL` | Object bytes do not match sha256-<hex> filename. |
| `objects_dir_missing` | `FAIL` | Packet missing objects/ directory. |
| `payload_digest_mismatch` | `FAIL` | Recomputed payload_digest does not match envelope. |
| `payload_inline_unserializable` | `FAIL` | payload_inline cannot be canonicalized as JSON. |
| `payload_pointer_hash_mismatch` | `FAIL` | payload_pointer.digest does not match object bytes. |
| `payload_pointer_json_parse_failed` | `FAIL` | payload bytes failed JSON parse under JCS canonicalization. |
| `payload_pointer_media_type_not_json` | `FAIL` | payload media_type is explicitly non-JSON under JCS canonicalization. |
| `payload_pointer_missing` | `FAIL` | Envelope missing payload_pointer (and has no payload_inline). |
| `payload_pointer_missing_uri` | `FAIL` | payload_pointer.uri missing/empty. |
| `payload_pointer_object_missing` | `FAIL` | payload_pointer refers to missing object. |
| `payload_pointer_size_mismatch` | `FAIL` | payload_pointer.size_bytes does not match object size. |
| `payload_pointer_unsafe_uri` | `FAIL` | payload_pointer.uri is unsafe (path traversal). |
| `payload_schema_mismatch` | `FAIL` | Envelope payload_schema differs from kind registry. |
| `payload_schema_missing` | `FAIL` | Envelope payload_schema path points to a missing file. |
| `public_artifact_lint_failed` | `FAIL` | Publishable artifact lint failed (run tools/public_artifact_lint.py for details). |
| `public_artifact_lint_warn` | `WARN` | Publishable artifact lint produced warnings (run tools/public_artifact_lint.py for details). |
| `public_fingerprint_file_invalid` | `FAIL` | Public fingerprint report file is invalid or missing public_fingerprint_sha256. |
| `public_fingerprint_file_missing` | `WARN` | Public fingerprint report file is missing (expected for mirror equality checks). |
| `public_fingerprint_input_truncated` | `WARN` | Public fingerprint inputs exceeded max-bytes bound; fingerprint may cover only a prefix of one or more publishable surfaces. |
