# Public audit report (template)

## Executive summary
- election scope, dates, jurisdiction
- verification outcomes (log consistency, tally proofs, paper audits)

## Cryptographic verification
- checkpoint policy (witness quorum)
- number of ballots recorded/final
- anomalies (fork proofs / missing checkpoints)
- tally proof verification results

## Paper audit (if applicable)
- audit type (RLA / compliance / recount)
- sample sizes and outcomes
- discrepancies and resolution

## Incidents
- outages, DDoS, partitions
- client malware/coercion reports (aggregate)
- mitigations and impact

## Recommendations
- operational improvements
- protocol/UX improvements
