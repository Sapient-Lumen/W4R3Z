# Coercion / vote-buying response playbook (Track B)

This playbook is for coercion / vote-buying signals in remote or high-risk contexts.

## Actions
- Activate `CHECK:artifacts/checklists/registration-coercion-checklist.md`
- Publish a **verifiable PublicNotice** (avoid hand-wavy screenshots):
  - See: `DOC:docs/186-incident-communications-as-evidence.md`
  - Draft from the worksheet: `TEMPLATE:artifacts/templates/incident-communications.md`
  - Use canonical comms channels: `REG:artifacts/registries/official-channels.csv`

## Evidence posture
- Avoid collecting evidence that deanonymizes voters.
- Prefer aggregate indicators, third-party reports, and pre-committed policy triggers.

## Policy options
- Revoting windows, credential reissuance, and escalation paths should be pre-committed where possible.
