# Verifier diversity checklist

- [ ] At least 2 verifiers from independent orgs
- [ ] Different implementation languages (recommended)
- [ ] Reproducible builds enabled
- [ ] Offline audit-bundle verification supported
- [ ] Conformance harness passes on all verifiers
- [ ] ForkProof + censorship evidence tests included
- [ ] Publish `VerifierReport` for each verifier (tool identity + conformance)
- [ ] Publish `PacketVerificationReport` for each shipped evidence packet (one per verifier)
