# Results disclosure policy checklist

## Before polls open
- [ ] Publish a signed DisclosurePolicy and commit it into the EPB.
- [ ] Define minimum cell sizes for any breakdown publication.
- [ ] Decide whether you will use tally hiding, coarsening/suppression, or both.
- [ ] Define rules for partial/unofficial updates vs certified results.

## During election night reporting
- [ ] Ensure partial updates do not reveal small-cell or unique-pattern signals.
- [ ] Avoid releasing granular breakdowns until after certification (if at all).

## After certification
- [ ] If publishing research datasets, define whether DP is used and how it is evaluated.
- [ ] Publish clear documentation of any noise/suppression; never “quietly change numbers”.
