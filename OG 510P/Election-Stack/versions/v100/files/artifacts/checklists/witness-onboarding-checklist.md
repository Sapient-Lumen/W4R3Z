# Witness onboarding checklist

- [ ] Verify legal entity and jurisdiction
- [ ] Collect and publish Witness Charter (signed)
- [ ] Collect and publish COI disclosure (signed)
- [ ] Validate signing keys (test signatures)
- [ ] Verify hosting diversity constraints (cloud/MSP/region)
- [ ] Run equivocation / fork-proof drill
- [ ] Add to Witness Rotation Schedule
