# Mass credential compromise response checklist

## Detect & confirm
- [ ] Correlate minting anomalies with CSP logs.
- [ ] Confirm whether authenticators / sync ecosystem is implicated.
- [ ] Activate incident command; define comms lead.

## Contain
- [ ] Freeze token minting (affected cohorts).
- [ ] Freeze administrative eligibility actions where possible.
- [ ] Increase monitoring and witness quorum requirements.

## Communicate (fail loud)
- [ ] Publish signed public statement (anchored to PBB).
- [ ] Provide clear fallback instructions (in-person, paper-of-record).

## Recover
- [ ] Rotate affected keys and re-issue credentials.
- [ ] Expand recovery sites/hours.
- [ ] Reconcile eligibility epochs and publish checkpoints.

## After action
- [ ] Publish an evidence bundle (redacted).
- [ ] Update threat model and controls.
