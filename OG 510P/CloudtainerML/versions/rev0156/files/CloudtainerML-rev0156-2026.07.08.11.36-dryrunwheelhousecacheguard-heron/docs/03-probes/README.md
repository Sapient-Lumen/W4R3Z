# Probe notes

This directory describes runnable probe scaffolds added to CloudtainerML.

A probe is not a benchmark. A probe is a cheap falsification instrument:

- it should run quickly;
- it should have simple baselines;
- it should emit JSON/CSV;
- it should make a failure mode more concrete;
- it should be disposable if it fails to separate hypotheses.
