# Rev0036 scout notes

## Routing/gain decoupling

RCA-style signal gain and importance-aware attention sharpen a useful distinction: selecting the right source token is not the same as giving that source enough value magnitude to overcome downstream/internal noise.

## Sparse program page cost

Vortex reinforces that sparse attention needs programmable page-centric execution semantics. CloudtainerML's schema now needs selector overhead, page alignment, fusion and exactness fields before sparse wins are taken seriously.

## Depth routing interpretability

Explicit routing weights can be content-independent schedules. Causal/content tests are required before depth routes are treated as mechanism evidence.

## Boundary depth

Boundary reachability is now trained and multi-hop: depth is useful only if the graph supplies a relay path.
