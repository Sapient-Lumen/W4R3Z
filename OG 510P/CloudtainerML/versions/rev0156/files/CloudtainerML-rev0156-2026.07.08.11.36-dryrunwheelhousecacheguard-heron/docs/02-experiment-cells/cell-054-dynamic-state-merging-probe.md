# CELL-054 — Dynamic State Merging Probe

Question: can content-aware bounded memory preserve transitions better than fixed block summaries?

Cheap first run: synthetic non-stationary sequences with equal state budgets.

Baselines: fixed uniform blocks, recency-highres blocks, random adjacent merge.

Metrics: overall MSE, transition MSE, boundary F1, state count.

Status: candidate-with-runnable-probe.
