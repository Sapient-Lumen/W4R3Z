# Frozen rev0072 public-trace claim contract

This retained historical probe established that a schema-valid external NPZ and an operator flag were not enough to claim public/pretrained evidence. The runner is pinned to `rev0072` so it cannot silently mint a current-revision result.

Its provenance contract is superseded by rev0076, which additionally requires verified post-transform score inputs, exact score semantics, recomputed dense-reference parity, immutable model/tokenizer/trusted-code revisions, and actual-dimensional cost accounting.

Historical reruns belong in a scratch copy and must not overwrite retained rev0072 artifacts.
