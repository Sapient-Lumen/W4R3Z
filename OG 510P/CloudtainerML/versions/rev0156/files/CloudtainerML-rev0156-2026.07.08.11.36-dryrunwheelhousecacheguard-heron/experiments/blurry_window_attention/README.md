# Blurry Window Attention toy probe

Bounded-memory reconstruction experiment inspired by Blurry Window Attention. It compares exact full attention, sliding windows, low-frequency FFT reconstructions, and temporal landmarks on smooth, periodic, recent, needle, and mixed histories.

Run:

```bash
python experiments/blurry_window_attention/blurry_window_probe.py --out artifacts/probe-results/REV0006_BLURRY_WINDOW_SMOKE
```
