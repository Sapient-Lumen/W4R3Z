Run very small modular addition/subtraction tasks and record order parameters every N steps.

## Baselines

## Metrics

- accuracy/exact match
- loss/error
- memory bytes
- runtime
- failure mode count
- seed variance

## Stop condition

If diagnostics cannot distinguish memorize/generalize/collapse regimes in small runs, postpone.
