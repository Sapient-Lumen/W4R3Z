# rev0015 scout notes

## New source clusters

- DocTrace / hypergraph working memory: query-triggered structure and reusable reasoning traces, now a P0 runnable native probe.
- DF-SSM: 1-bit scaffold plus low-rank correction for SSM-like transitions, now a P0 runnable native probe.
- Recalling Too Well: persistent memory can make correctness worse by storing beliefs without correction/provenance, now a P0 runnable red-team probe.
- LongFlow and PTQ scale work: cache importance and quantization scale should be treated as phase-boundary variables, not constants.
- KATE / experiential tool use: concrete instance memory may beat abstract intent memory for tool agents.

## Working interpretation

The project is drifting from “KV cache compression” toward “which memory object should be stored, searched, rewritten, or trusted?” Native C++ is now the default for phase diagrams and high-volume symbolic/tensor probes. Python remains for ledgers, dashboards, and eventual tiny training.
