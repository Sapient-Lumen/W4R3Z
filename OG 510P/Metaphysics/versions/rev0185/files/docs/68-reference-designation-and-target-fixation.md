# Reference, Designation, and Target-Fixation

## Why this file exists

The archive now has explicit files on **representation**, **indexicality**, **truth**, **ontological commitment**, **nonexistents**, **directness**, and **access architecture**. But it still lacked one compact file saying how the archive moves from:

- a name, term, marker, model-label, measurement variable, or first-personal claim,
- to a way of fixing a target,
- to a way of keeping that target stable across reuse,
- to a way of handling drift, proxy-capture, or nonreference,
- to a way of deciding what, if anything, has really been picked out.

Without a dedicated file here, the archive risks seven recurrent mistakes:

- treating **successful use** as if it automatically meant **secure reference**,
- treating **reference** as if it were the same thing as **representation**, **truth**, or **ontology**,
- treating one fixed label as if it automatically preserved the **same target** across theory change, measurement change, or context shift,
- treating **indexical** or **centered** reference as if it were merely subjective,
- treating **misreference**, **partial reference**, or **target drift** as if they automatically showed that no target was ever there,
- treating all reference-fixing as if it had to be either **pure description** or **pure causal dubbing**,
- or treating stable reference as if it automatically settled what kind of thing the target is.

This file gives the archive a compact **reference profile** so future revisions can say what kind of target is at issue, how it is fixed, what keeps reuse anchored, how failure enters, and what ontological pressure—if any—follows.

## Working default

The archive should now say explicitly:

> **Reference is worldly but typed: names, indexicals, model terms, measurement labels, records, and first-personal claims do not all latch onto their targets in the same way.**

And more specifically:

> **Target-fixation should be treated as route-sensitive, history-sensitive, practice-sensitive, and category-sensitive rather than as one flat semantic miracle.**

This fits the archive's wider commitments:

- **representation** matters because a vehicle can be about a target without yet fixing it well,
- **indexicality** matters because some targets are fixed through centered position rather than detached description,
- **truth** matters because successful predication presupposes enough target-fixation for reality-answerability,
- **measurement** matters because variables, indicators, and readouts can drift from target to proxy,
- **directness** matters because some forms of perceptual or practical uptake help fix targets without eliminating mediation,
- **nonexistent-object discipline** matters because meaningful discourse can fail to refer, refer only derivatively, or target fictionally structured contents,
- and **access architecture** matters because reference-fixing is one stage inside a larger route from disclosure to ontological promotion.

## Core distinctions

### 1. Reference is not the same as representation, truth, or ontology

The archive should distinguish:

- **reference** — what a term, token, marker, or use picks out,
- **representation** — how a vehicle is about, of, or for a target,
- **truth or accuracy** — whether what is said, claimed, or displayed fits reality,
- and **ontology** — what sort of thing the target is, and what status it has.

Otherwise the archive will keep sliding from “this term works” to “this representation is accurate” to “this ontology is settled”.

### 2. Target-fixation is route-sensitive

The archive should distinguish at least these target-fixing routes:

- **ostensive or perceptual fixing** — this object, this sample, this event, this person,
- **descriptive fixing** — whatever fits a given role or identifying description,
- **causal-historical borrowing** — later uses inherit a target from earlier anchored uses,
- **operational or measurement fixing** — a variable or readout is tied to a target by setup, calibration, and intervention profile,
- **institutional designation** — office, title, identifier, or status is fixed by rule-governed uptake,
- **indexical or self-locating fixing** — I, here, now, this interface position, this current user,
- and **mixed fixing** — where several routes cooperate.

Otherwise the archive will keep imagining that every case of referring works like one paradigmatic proper name.

### 3. Reuse of a label is not yet sameness of target

The archive should distinguish:

- **stable reference**,
- **reference borrowing with partial drift**,
- **role-preserving target change**,
- **proxy capture**,
- **family resemblance across theory change**,
- and **mere lexical continuity with no stable target**.

Otherwise the archive will keep treating one continued word or variable as if it guaranteed one unchanged ontology.

### 4. Failure can enter in different ways

The archive should distinguish:

- **nonreference** — nothing is picked out,
- **misreference** — the use picks out the wrong target,
- **partial or approximate reference** — the use latches imperfectly onto a target,
- **proxy-bound reference** — the use tracks an indicator rather than the intended target,
- **institutional retargeting** — a designation shifts because the rules or office change,
- and **fictional or merely intentional targeting** — structured discourse without ordinary concrete reference.

Otherwise the archive will keep reading every reference problem as either total success or total collapse.

### 5. Indexical and centered reference can still be objective

The archive should distinguish:

- **private seeming**,
- **centered but objective reality**,
- **role-relative institutional designation**,
- **embodied or interface position**, 
- and **mere context-sensitive convenience**.

Otherwise it will keep sliding from first-personal or situated reference either to subjectivism or to flat semantic deflation.

### 6. Scientific and model terms may fix different kinds of target

The archive should distinguish whether a term, model component, or variable fixes:

- a compact **entity**,
- a **process**,
- a **mechanism**,
- a **structure**,
- a **field-profile**,
- a **response-dependent property**,
- an **institutional status**,
- an **idealized surrogate**,
- or only a **useful parameter**.

Otherwise the archive will keep assuming that once reference is stable, heavyweight object ontology has been earned.

### 7. Reference-fixing does not by itself settle modal or status questions

The archive should distinguish:

- whether the target exists,
- whether it is fundamental,
- whether the designation is rigid or role-bound,
- whether the term survives theory change,
- and whether the best verdict is object realism, structure/process realism, derivative status realism, proxy-only caution, fictional targeting, or still unsettled.

Otherwise it will keep using reference as a shortcut around ontology.

## Four live options

### 1. Description-first fixing

**Picture:** what a term refers to is fixed mainly by descriptive fit or role specification.

**What it gets right:**
- role, concept, and identifying profile matter,
- and many institutional or scientific terms are not fixed by bare encounter alone.

**What it gets wrong for this archive if left alone:**
- it underdescribes historical continuity, borrowing, ostension, and causal/environmental anchoring.

### 2. Causal-chain-only fixing

**Picture:** reference is fixed by an initial anchoring and then transmitted by a causal-historical chain.

**What it gets right:**
- some targets are fixed by worldly encounter and borrowed across uses,
- and lexical continuity can outrun shifting descriptions.

**What it gets wrong for this archive if left alone:**
- it underdescribes role-sensitive, institutional, model-based, measurement-based, and centered cases.

### 3. Practice or inferential-role fixing

**Picture:** what a term refers to is fixed by its place in use, inference, intervention, and coordinated practice.

**What it gets right:**
- reference is often socially, institutionally, and experimentally sustained,
- and target-fixation is rarely a one-shot miracle.

**What it gets wrong for this archive if left alone:**
- it can lose grip on worldly resistance and drift toward scheme-first anti-realism.

### 4. Typed hybrid realism about reference

**Picture:** different domains use different mixtures of ostension, causal history, description, institutional designation, operational role, and centered anchoring. What matters is whether a use remains stably world-answerable under correction and reuse.

**What it gets right:**
- it preserves worldly anchoring without forcing one fixation story on every domain,
- it fits names, models, measurements, indexicals, and institutions better than one flat theory,
- and it lets reference stay serious without turning it into a one-step ontology machine.

**What it risks if left alone:**
- it can become hand-wavy unless each case states what fixes the target, how continuity is sustained, and what failure mode is live.

## Archive commitments

### 1. Always ask what fixes the target

Do not let words like **refers to**, **denotes**, **is about**, **tracks**, **names**, **picks out**, **measures**, **registers**, **this**, **that**, **I**, or **here** settle target-fixation by themselves.

### 2. Distinguish lexical continuity from target continuity

The same label can be reused while the target drifts, splits, or disappears.

### 3. Keep proxy capture live

A variable, score, image, or readout may latch onto an indicator, surrogate, or role-occupant rather than the intended target itself.

### 4. Allow centered and institutional anchoring

Not every genuine target is fixed by detached description; some are fixed by embodied position, role occupancy, registry state, or rule-governed designation.

### 5. Let failure verdicts stay typed

Nonreference, misreference, approximate reference, proxy-bound reference, and fictional targeting are not one flat negative result.

### 6. Do not infer ontology from stable reference alone

Reference can remain stable while the ontological lesson changes: the right verdict may concern an entity, a process, a structure, a mechanism, a response-dependent property, a derivative status, or only a useful representational role.

## Reference profile rule for future revisions

Before inferring a metaphysical verdict from language like **refers to**, **denotes**, **names**, **picks out**, **is about**, **tracks**, **this**, **that**, **I**, **here**, **now**, **actual**, **the same target**, **the variable stands for**, **the detector detects**, **the model is about**, **the label still applies**, **the office-holder**, or **the term has drifted**, future revisions should answer at least these questions:

1. **target candidate** — entity, process, mechanism, structure, field-profile, property, role, office, centered position, fictional target, abstractum, or mixed case;
2. **vehicle type** — proper name, common noun, indexical, demonstrative, measurement variable, model term, registry identifier, map marker, record token, interface label, or mixed vehicle;
3. **fixing route** — ostension, description, causal-historical chain, operational role, institutional designation, centered anchoring, or mixed route;
4. **continuity basis** — repeated encounter, borrowing chain, descriptive stability, registry persistence, calibrated intervention profile, role continuity, or mixed basis;
5. **context profile** — rigid across contexts, context-sensitive, role-sensitive, theory-sensitive, center-sensitive, or mixed profile;
6. **failure mode** — nonreference, misreference, drift, splitting target, proxy capture, fictional targeting, or still unsettled;
7. **world relation** — direct target-fixing, indirect but stable target-tracking, proxy-only latching, institutionally constitutive designation, representational use without ordinary reference, or mixed relation;
8. **ontological pressure** — entity pressure, process/mechanism pressure, structure pressure, status-only pressure, no direct pressure, or still unsettled;
9. **final verdict** — secure typed reference, partial or approximate reference, proxy-bound reference, institutionally fixed designation, fictional/intentional targeting, nonreference, or still unsettled.

If those questions cannot be answered, the archive should usually refuse to let reference-language do heavy ontological work by itself.

## Bottom line

The archive should now prefer a **typed realism about reference and target-fixation**:

- targets can be fixed through different worldly routes,
- lexical stability is not enough,
- drift and proxy capture are real risks,
- centered and institutional designation can still be objective,
- and stable reference does not by itself settle ontology.

That is the compact target-fixation rule the archive was missing.
