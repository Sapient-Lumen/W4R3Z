# Sequestration, Binding, Trapping, and Selective Retention

## Why this file exists

The archive now has explicit files on **porous boundaries / selective exchange**, **gating / coupling / tuning**, **masking / inhibition / suppression**, **history-sensitivity / traces / sedimented constraint**, **delay / temporal decoupling**, **slack / deadband**, **interference / noise**, and **attenuation / filtering / shielding**, but it still lacks one direct file saying what to do when a case is described as **sequestered**, **bound up**, **captured**, **adsorbed onto a surface**, **held in reserve**, **quarantined**, **parked in escrow**, **trapped in a compartment**, or **stored in a sink** rather than straightforwardly absent, merged, or destroyed.

That omission matters because the archive still risks ten opposite mistakes:

- treating every **sequestered** case as if it were already **gone or annihilated**,
- treating every **binding** case as if it implied **identity, merger, or constitutive inclusion**,
- treating every **trap** as if it were already **damage, death, or terminal ending**,
- treating every **sink** as if it implied **permanent elimination**,
- treating every **held-back reserve** as if it were just **delay in transit**,
- treating every **quarantine or escrow** case as if it were only **ordinary boundary closure**,
- treating every **surface capture** as if it were simply **filtering**,
- treating every **inactive complex** as if it meant the captured thing had **ceased to exist or ceased to matter**,
- collapsing **adsorption**, **chelation / complexing**, **protein sequestration**, **sink storage**, **quarantine retention**, **escrow holding**, and **release-ready capture** into one flat story,
- or smuggling the difference between **selective retention**, **protective holding**, **captured but releasable availability**, **compartmental trapping**, and **long-term storage** into neighboring files on gating, dormancy, attenuation, and history.

This file gives the archive a compact **sequestration / selective-retention profile** so future revisions can say whether a case is chiefly about adsorption or surface capture, binding or complexing sequestration, inactive-complex holding, sink or reservoir storage, quarantine or escrow retention, release-ready trapping, or some mixed selective-retention architecture.

## Working default

The archive should now say explicitly:

> **Some real things are neither absent nor freely available, but present under selective retention, binding, capture, or holding.**

In compressed form:

> **Not everything withheld is gone, and not everything bound is one.**

And more carefully:

> **Sequestration, binding, trapping, and selective retention are best understood as typed ways in which one real signal, molecule, field, pathway, resource, organism, person, role, document, or institution can be held, localized, bound, parked, or stored so that it remains real while its circulation, availability, manifestation, or downstream effect is constrained: they often matter for what is present where, what can act now, what can be released later, and which apparent absences are really cases of capture or withholding rather than annihilation.**

This fits the archive's wider commitments:

- **porous boundaries / selective exchange** still matters because retention at or within a boundary differs from full exclusion,
- **gating / coupling / tuning** still matters because selective retention differs from binary admission or closure,
- **masking / inhibition / suppression** still matters because an inactive complex differs from simple blocked manifestation,
- **delay / temporal decoupling** still matters because being held is not the same as merely being en route or waiting in queue,
- **history-sensitivity / traces** still matters because some retained stores are path-dependent or archive-backed,
- **compartmentalization / firebreaks** still matters because trapping within a compartment differs from modular separation across a whole architecture,
- **attenuation / filtering / shielding** still matters because selective passage differs from selective capture,
- **dormancy / latency** still matters because a dormant bearer is not always a captured bearer,
- **malfunction / pathology** still matters because sequestration can protect, regulate, or store rather than merely disable,
- and **social ontology / institutions** still matters because escrow, quarantine, document hold, impoundment, and reserve status are not merely metaphors but organized retention relations.

## Core distinctions

### 1. Sequestration is not the same as absence

A target can remain real while being held in a bounded region, inactive complex, sink, or reserve rather than circulating freely.

So the archive should distinguish:

- **same target selectively retained**,
- **same target presently inactive because captured**,
- **same target removed from one corridor but still extant elsewhere**,
- **genuine target absence**,
- and **mere readout failure only in weaker cases**.

Otherwise it will keep inferring disappearance from withholding.

### 2. Binding is not the same as merger, constitution, or identity

When one thing binds, chelates, complexes with, or adsorbs another, the result may be a real relation of capture without numerical oneness.

So the archive should distinguish:

- **reversible binding or complexing**,
- **stronger constitutive incorporation only in harder cases**,
- **organized partnership without identity**,
- **surface retention without deep absorption**,
- and **mere co-location only in weaker cases**.

Otherwise it will keep letting “bound to” do silent work from contact all the way to fusion.

### 3. Trapping is not the same as destruction or terminal loss

A trapped thing may be immobilized, buffered, delayed in release, or confined to one compartment while still persisting as that very thing.

So the archive should distinguish:

- **same target immobilized or localized**,
- **same target parked pending release**,
- **same target quarantined from one domain**,
- **terminal destruction or dissolution**,
- and **mere transit or passing delay only in weaker cases**.

Otherwise it will keep reading capture as death.

### 4. Sink storage is not the same as permanent elimination

A sink can hold, absorb, or store something for long periods without making it metaphysically unreal or unreleasable in principle.

So the archive should distinguish:

- **long-term storage in a sink or reservoir**,
- **temporary holding pool or reserve**,
- **irreversible elimination only in stronger cases**,
- **ordinary background distribution**,
- and **mere accounting convention only in weaker cases**.

Otherwise it will keep confusing storage with annihilation.

### 5. Sequestration is not the same as filtering, shielding, or boundary closure

Selective retention differs from selective passage or exposure reduction. A filter lets some things through; a sequestration relation holds some things back or localizes them.

So the archive should distinguish:

- **selective retention / capture**,
- **selective passage / attenuation**,
- **binary exclusion or gating**,
- **protective shielding of an interior**,
- and **ordinary compartmental boundary maintenance**.

Otherwise it will keep flattening passage-control and capture into one vocabulary.

### 6. Sequestration is not the same as mere delay or queueing

Something can be held because it is bound, trapped, quarantined, or parked rather than because it is simply waiting its turn in a pipeline.

So the archive should distinguish:

- **bound or trapped retention**,
- **queueing / throughput wait**,
- **transport delay in transit**,
- **reserve held for later controlled release**,
- and **simple reporting lag only in weaker cases**.

Otherwise it will keep using one temporal vocabulary for several different organization profiles.

### 7. Inactive complexing is not the same as unreality

A protein, ion, document, person, or role can be rendered presently unavailable or inactive by sequestration while still remaining real and often releasable.

So the archive should distinguish:

- **same target present but functionally unavailable**,
- **same target under regulatory capture or reserve hold**,
- **same target under local confinement with later release possible**,
- **genuine functional loss only in harder cases**,
- and **mere observer ignorance only in weaker cases**.

Otherwise it will keep confusing nonavailability with nonexistence.

## Typology of selective-retention cases

### A. Surface capture or adsorption

The key feature is that a target is retained at an interface or surface rather than absorbed into the whole bulk.

**Examples:** gases or solutes adsorbed on activated surfaces; contaminants sticking to membranes; particles held on filters or substrates.

### B. Binding, chelation, or inactive-complex sequestration

The key feature is that a target is held through specific binding relations that alter present availability, mobility, or activity.

**Examples:** chelation of metal ions; regulatory protein sequestration in inactive complexes; receptor or ligand capture that withholds downstream action.

### C. Sink or reservoir storage

The key feature is that something is taken up and stored in a reservoir, pool, or sink that reduces immediate free availability while preserving the target.

**Examples:** carbon sequestration in forests, soils, oceans, or geologic formations; stored water in reservoirs; fiscal reserves; held inventory.

### D. Quarantine, escrow, impoundment, or hold status

The key feature is that a target remains real and trackable while organized rules constrain circulation, access, or release.

**Examples:** quarantine of exposed persons; legal escrow; document hold; impounded assets; archived but still operative records under access control.

### E. Compartmental trapping or local retention

The key feature is that a target is localized to one compartment, vesicle, chamber, niche, or bounded region rather than flowing freely across the architecture.

**Examples:** intracellular sequestration; trapped gas pockets; contaminants confined to one sediment layer; hazardous material kept in containment.

### F. Release-ready selective retention

The key feature is that capture is coupled to later release, mobilization, or controlled availability rather than terminal locking.

**Examples:** buffered mediator release; stored charge or resource mobilization; reserve troops; just-in-case stockpiles; dormantly held but activatable factors.

## Cross-domain pressure

### Chemistry, surfaces, and molecular complexes

Chemistry cases pressure the archive because adsorption, chelation, and complex formation all show that something can remain present while being selectively held, localized, or rendered less freely available.

### Cell biology and regulation

Biological regulation pressures the archive because sequestration often explains why an active factor is real yet presently inactive, unavailable, or prevented from acting downstream without having been destroyed.

### Ecology, climate, and geochemical storage

Ecological and climate cases pressure the archive because sinks and sequestration show long-term storage and delayed release rather than magical disappearance of matter or influence.

### Institutions, public health, and legal organization

Institutional cases pressure the archive because quarantine, escrow, archive hold, and impoundment are organized retention relations in which a thing remains real while movement, access, or use is constrained.

### Logistics, reserves, and controlled release

Operational cases pressure the archive because inventory, reserves, parking, and staged release show how something can be present under hold status rather than absent, blocked, or already flowing.

## False moves to avoid

- Do **not** infer absence from every sequestration case.
- Do **not** infer merger or identity from every binding case.
- Do **not** infer destruction from every trapping case.
- Do **not** infer permanent elimination from every sink.
- Do **not** infer mere delay from every held reserve.
- Do **not** infer simple filtering from every capture-at-interface case.
- Do **not** infer dormancy from every presently inactive complex.
- Do **not** infer pathology from every quarantine or hold relation.
- Do **not** infer one flat relation from **sequestered**, **bound**, **captured**, **held**, **adsorbed**, **chelated**, **stored in a sink**, **quarantined**, **in escrow**, **impounded**, or **trapped**.

## Default test for future revisions

When a future revision says that something is **sequestered**, **bound up**, **captured**, **adsorbed**, **chelated**, **stored in a sink**, **quarantined**, **held in escrow**, **impounded**, **parked**, or **trapped**, it should ask:

1. What is the **target** — one molecule, one ion, one protein, one signal, one resource, one document, one person, one role, one institution, one region, or one mixed organization?
2. What kind or stage-kind is at issue?
3. What the relevant **selective-retention relation** is — surface capture / adsorption, binding / complexing sequestration, inactive-complex holding, sink / reservoir storage, quarantine / escrow retention, compartmental trapping, release-ready retention, or mixed?
4. What is actually **doing the retaining work** — surface forces, ligand binding, inhibitory complexing, vesicle or chamber confinement, legal hold rules, quarantine protocol, reservoir structure, sink uptake, archive lock, or mixed?
5. What the relevant **timescale / grain profile** is — transient binding, episodic hold, chronic storage, developmentally stabilized sequestration, seasonally reversible sink storage, or mixed?
6. What remains **real underneath the retention** — same target presently unavailable, same target localized to one region, same target under hold pending release, same target stored in reserve, stronger loss only in harder cases, or mixed?
7. What the relevant **continuity consequence** is — same bearer still there but bound, same organization retaining capacity in held form, same role or document operative under access control, same material or signal stored for later release, stronger elimination only in harder cases, or mixed?
8. What the relevant **comparison class** is — delay, dormancy, filtering, shielding, masking, inhibition, compartmentalization, destruction, or artifact?
9. What the relevant **artifact-risk profile** is — apparent sequestration produced by poor sampling, detection bias, coarse accounting, mislocalized proxy, or mixed?
10. And whether the best verdict is **surface capture / adsorption**, **binding / chelation / inactive-complex sequestration**, **sink or reservoir storage**, **quarantine / escrow / hold retention**, **compartmental trapping**, **release-ready selective retention**, **apparent sequestration / proxy artifact**, or **still unsettled**.
