# Category Discipline: Objects, Events, Facts, Relations, and Kinds

## Why this file exists

By `rev0008`, the archive had become much better at handling **grounding**, **emergence**, **persistence**, **truthmaking**, **properties**, and **modality**. But it was still relying on an often unstated answer to a prior question:

> **What ontological category is at issue here?**

Without that question, the archive risks several recurrent confusions:

- treating **objects** and **processes** as if they had the same unity and persistence conditions,
- treating **facts** and **events** as if they were interchangeable,
- treating **relations** as if they were always reducible to monadic features,
- treating **kinds** as if they were automatically the same thing as universals,
- and treating every truth as if it demanded a heavyweight ontological correlate of the same type.

This file therefore adds a compact **category discipline**. Its job is not to settle the one true final table of categories. Its job is to stop the archive from speaking as if all ontological items belonged to one flat kind.

## Archive default

The archive now favors **disciplined category pluralism**:

- there is no good reason to force all reality into one ontological category,
- but there is equally no reason to proliferate categories without work for them to do,
- so the archive should use the **smallest category scheme that preserves real differences in unity, dependence, modality, and truthmaking**.

The current working family of categories is:

1. **objects / individuals**
2. **events / processes**
3. **properties / powers**
4. **relations / structures**
5. **facts / states of affairs**
6. **kinds / forms / roles**

This is a **working discipline**, not a closed dogma. Future revisions may compress or refine it, but they should not ignore it.

## Core distinction map

### 1. Objects / individuals

These are relatively unified bearers: organisms, artifacts, persons, institutions, cells, planets, and similar candidates.

The archive default is **not** that every object is a metaphysically primitive lump. Many objects are better understood as **stabilized processual organizations**.

Questions that fit this category:

- What makes it one thing?
- What kind of thing is it?
- What changes can it survive?
- What powers does it have in virtue of its organization?

Questions that do **not** fit it cleanly:

- whether every truth needs an object as its truthmaker,
- whether every dependence claim is object-to-object,
- whether all causation should be modeled as interaction between persisting substances.

### 2. Events / processes

These are happenings, occurrences, unfoldings, or temporally extended doings.

The archive should distinguish:

- **events** — more bounded occurrences,
- **processes** — extended, often ongoing organized unfoldings.

Births, storms, court rulings, cell division, combustion, erosion, bargaining, digestion, and learning are more naturally placed here than under object alone.

Questions that fit this category:

- What begins, unfolds, is sustained, or terminates?
- What temporal articulation matters?
- What counts as interruption, continuation, acceleration, or completion?

The archive default is that many enduring entities are partly intelligible through the processes that sustain them, but **a process is not merely an object moving**, and **an object is not merely a frozen event-description**.

### 3. Properties / powers

These are ways things are, can act, can be acted upon, or tend to behave.

The archive already treats powers as especially important because modality is not exhausted by what is occurrent. This file adds only a category warning:

- do not talk as if a property, a power, a trope, and a kind were automatically the same sort of thing,
- do not infer from predication alone that the relevant ontological category has been settled.

### 4. Relations / structures

Relations connect, order, compare, constitute, or organize. Structures are stabilized patterns of relational articulation.

This matters because some metaphysical frameworks treat relations as derivative, while others treat some relations or structures as ontologically constitutive.

The archive default is modest but real:

- **not every relation is reducible to monadic profiles plus bookkeeping**,
- and **some structures are constitutive of what their relata are in the relevant domain**.

This is especially important for:

- social and institutional reality,
- biological organization,
- part-whole articulation,
- network-dependent roles,
- and structural constraints in lawfulness and modality.

### 5. Facts / states of affairs

The archive should remain careful here.

Facts or obtaining states of affairs can do work in:

- truthmaking,
- metaphysical explanation,
- inclusion or necessitation relations,
- and the articulation of what obtains.

But the archive should stay **sparse**:

- do **not** posit a bespoke fact for every true sentence by default,
- do **not** assume that every obtaining state of affairs is an event,
- do **not** use facts as a universal solvent for every ontological problem.

The current stance is:

- use facts or states of affairs when they clarify truthmaking or constitutive explanation,
- prefer leaner grounds when an object, process, structure, power-profile, or bounded totality already does the work,
- and keep negative-fact inflation under strict suspicion.

The fuller typed treatment now lives in `56-facts-states-of-affairs-and-obtaining.md`.

### 6. Kinds / forms / roles

These are not all the same thing, but the archive groups them here because they play **individuating, organizing, and normative-structuring** roles.

- **Kinds** help answer what sort of thing something is.
- **Forms** help answer what organization makes it the thing it is.
- **Roles** help answer what place something occupies in a structured practice, system, or institution.

The archive should not simply identify these with universals, predicates, or abstract classes. They earn their place when they do explanatory work in:

- unity,
- persistence,
- modal expectation,
- realization,
- social ontology,
- and normative status.

## Non-collapse rules

### Rule 1: Do not collapse objects into processes or processes into objects

Many objects are processually sustained, but not every object-question is an event-question. Conversely, not every process is best redescribed as a moving object.

### Rule 2: Do not collapse facts into events

An explosion is an event. The fact that the bomb exploded is not obviously just the explosion itself under another name. The archive should keep these categories distinct unless a case gives a good reason to identify them.

### Rule 3: Do not collapse relations into intrinsic profiles by default

Some relations may supervene on intrinsic features of relata plus arrangement; others may be constitutive of the relata's standing, role, or identity in a domain. The archive should not prejudge all cases in favor of monadic reduction.

### Rule 4: Do not collapse kinds into properties or predicates

To say that something falls under a kind is not yet to say what ontological category that kind occupies, nor whether the kind is essence-like, cluster-like, genealogical, structural, or role-governed.

### Rule 5: Do not collapse truthmaking into fact-posits

Some truths are best handled by objects, some by processes, some by structures, some by absences or privations under discipline, and only some by explicit fact ontology.

## Category profile template for future revisions

Any new substantial claim in the archive should, where relevant, answer these six questions:

1. **Category** — Is the target chiefly an object, event/process, property/power, relation/structure, fact/state of affairs, or kind/form/role?
2. **Unity** — What makes it one?
3. **Persistence / obtaining** — How does it continue, recur, obtain, or end?
4. **Dependence** — What sort of dependence relation is central here?
5. **Modal profile** — What powers, necessities, permissions, or constraints belong to it?
6. **Truthmaking / explanation** — What sort of ontological item best answers to the truths or explanations at issue?

This template is not busywork. It is meant to stop silent category shifts. For cases where the target is a whole with parts, it should now be paired with the boundary-and-composition profile in `17-mereology-composition-and-boundaries.md`.

## Default archive applications

### Ordinary objects

Treat as **individuals** whose identity and persistence are often governed by kind, form, and organized continuity.

### Organisms and minds

Treat as **individuals sustained by processes**, with powers and structures doing major explanatory work.

### Institutions

Treat as **structured roles and statuses** grounded in practices, recognition, and enforcement, not as mere object lumps.

### Laws

Treat lawfulness primarily through **powers and structures**, not as a separate category of ontological policeman unless later revisions force that move.

### Truths about absences

Ask first whether the case is better handled by **privation**, **bounded totality**, **blocked process**, or **structured absence**, rather than immediately positing negative facts.

## What this file changes in the archive's style

From this revision onward, the archive should avoid sentences of the form:

- “X exists, therefore it is an object.”
- “Y is real, therefore it is fundamental.”
- “Z is true, therefore there is a corresponding fact of the same type.”
- “A is processual, therefore objects are unreal.”
- “B is a relation, therefore it is merely conceptual.”

These are exactly the shortcuts category discipline is meant to block.

## Current archive posture in one line

> **Reality is category-plural but not category-chaotic: objects, processes, powers, structures, facts, and kinds are not interchangeable, and metaphysical clarity often begins by asking which of them is doing the work.**
