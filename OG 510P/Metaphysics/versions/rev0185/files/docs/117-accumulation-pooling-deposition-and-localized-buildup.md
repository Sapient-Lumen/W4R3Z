# Accumulation, Pooling, Deposition, and Localized Buildup

## Why this file exists

The archive now has explicit files on **history-sensitivity / traces / sedimented constraint**, **saturation / capacity limits**, **sequestration / selective retention**, **release / mobilization**, **leakage / uncontrolled escape**, **fusion / coalescence**, and **attrition / reserve erosion**, but it still lacks one direct file saying what to do when a case is described as **accumulating**, **building up**, **pooling**, **settling out**, **depositing**, **thickening**, **encrusting**, **backing up**, or **leaving a growing residue** rather than being merely stored, merely delayed, or simply fused into one new thing.

That omission matters because the archive still risks ten opposite mistakes:

- treating every **buildup** case as if it were already **selective sequestration**,
- treating every **pooling** case as if it were already **one fused bearer**,
- treating every **deposit** case as if it were just a **historical trace**,
- treating every **residue** case as if it were mere **evidence** rather than a still-present burden,
- treating every **backlog** case as if it were only **delay**,
- treating every **local concentration** case as if it were already **saturation**,
- treating every **reservoir accumulation** case as if it implied **stable storage by design**,
- treating every **sedimented load** case as if it were already **permanent elimination** from the wider system,
- collapsing **sedimentation**, **pooling in traps or basins**, **bioaccumulation**, **backlog buildup**, **encrustation**, and **residual thickening** into one flat story,
- or smuggling the difference between **holding**, **settling**, **crowding**, **depositing**, and **capacity pressure** into neighboring files on history, sequestration, saturation, and fusion.

This file gives the archive a compact **accumulation / pooling / deposition / localized-buildup profile** so future revisions can say whether a case is chiefly about net inflow outrunning clearance, trap- or basin-shaped pooling, settling deposition from a moving medium, persistent tissue or substrate burden, backlog accumulation in a corridor, residual buildup on surfaces, or some mixed architecture of localized retained increase.

## Working default

The archive should now say explicitly:

> **Some real things are neither merely held nor merely leaking away, but building up, pooling, depositing, or thickening somewhere because arrival, retention, or settling outruns clearance.**

In compressed form:

> **Not every staying is a hold, and not every increase is a new bearer. Some are buildups.**

And more carefully:

> **Accumulation, pooling, deposition, and localized buildup are best understood as typed ways in which one real material, contaminant, signal, burden, workload, population, document stream, charge, or residue can become more concentrated, thicker, denser, or more localized in one site, medium, tissue, surface, queue, basin, or trap without thereby becoming a new fused entity, a merely historical trace, or a case of deliberate sequestration by design.**

This fits the archive's wider commitments:

- **history-sensitivity** still matters because deposits and residues can carry the past forward, but a trace is not the same as an ongoing buildup,
- **sequestration / retention** still matters because deliberate holding differs from net accumulation,
- **release / leakage** still matter because what leaves one site can accumulate in another,
- **fusion / coalescence** still matters because many arrivals in one place are not automatically one new bearer,
- **saturation / overload** still matter because buildup can remain sub-saturating for long stretches,
- **attrition / erosion** still matter because systems can accumulate burden even while losing margin elsewhere,
- and **institutions / infrastructures** still matter because logs, cases, inventories, and obligations can pile up without becoming mere metaphors.

## Core distinctions

### 1. Accumulation is not the same as sequestration

Something can build up in a place because inflow, persistence, or repeated arrival outruns clearance, not because a selective capture system intentionally holds it there.

So the archive should distinguish:

- **net buildup in one site**,
- **deliberate capture or holding only in stronger sequestration cases**,
- **same target more concentrated or burdening one region**,
- **same corridor with poor clearance**,
- and **mere storage-by-design only in different cases**.

Otherwise it will keep mistaking accumulation dynamics for organized retention.

### 2. Pooling is not the same as fusion

Many units or increments can gather in one basin, trap, chamber, tissue, or queue without ceasing to be numerically many or without yielding one new higher-order bearer.

So the archive should distinguish:

- **localized many-in-one-place**,
- **same medium with increased local load**,
- **same stock more concentrated in one region**,
- **fusion only in stronger integrative cases**,
- and **mere co-location only in weaker cases**.

Otherwise it will keep turning gathering-together into bearer-formation by default.

### 3. Deposition is not the same as mere passage

Material can settle out of suspension or transport and become laid down in one place rather than merely moving through the corridor.

So the archive should distinguish:

- **transport still underway**,
- **settling or laying down**,
- **temporary lodging only in weaker cases**,
- **same material now deposited at a site**,
- and **trace-only significance only in thinner evidential cases**.

Otherwise it will keep hiding site-making buildup inside flow vocabulary.

### 4. Buildup is not the same as saturation

A system can undergo real accumulation long before it hits a hard capacity limit, overload threshold, or refractory ceiling.

So the archive should distinguish:

- **sub-saturating burden increase**,
- **approach toward capacity**,
- **local thickening without immediate failure**,
- **saturation only in stronger limit cases**,
- and **ordinary fluctuation only in weaker cases**.

Otherwise it will keep treating every accumulation as if the decisive metaphysical fact were already maximum occupancy.

### 5. Residual buildup is not the same as mere history-trace

A residue can be presently operative as mass, burden, coating, blockage, contamination, or liability, not merely as evidence that something happened before.

So the archive should distinguish:

- **operative residue still doing work now**,
- **mere record or trace of the past**,
- **same surface or tissue under accumulating layer**,
- **same organization under growing backlog or debt**,
- and **artifact-only appearances only in weaker cases**.

Otherwise it will keep turning present burden into passive historical evidence.

### 6. Accumulation is not the same as simple presence

More of the same target in one place can matter because quantity, density, or concentration changes what that region is like and what it can do.

So the archive should distinguish:

- **ordinary presence**,
- **localized increase in burden or density**,
- **same target now concentrated enough to matter differently**,
- **threshold-triggered regime change only in stronger cases**,
- and **mere detection improvement only in weaker cases**.

Otherwise it will keep missing what buildup changes before any dramatic transition occurs.

### 7. Source loss and sink buildup are not the same operator

What leaks, erodes, or is mobilized away from one place may accumulate elsewhere, but source-side outflow and destination-side buildup are different metaphysical operators.

So the archive should distinguish:

- **loss from the source**,
- **arrival and buildup at the destination**,
- **same wider process linking both**,
- **mixed source-sink architectures where both operators are needed**,
- and **mere bookkeeping transfer only in thinner cases**.

Otherwise it will keep letting one side of the movement hide the other.

## Typology of accumulation cases

### A. Net buildup from inflow outrunning clearance

The key feature is that arrivals or additions continue faster than removal, decay, drainage, or processing.

**Examples:** queue backlog; debt accumulation; charge buildup; pollutant load increasing in one basin.

### B. Pooling in traps, basins, or low-clearance sites

The key feature is that a geometry, gradient, permeability difference, or trapping arrangement localizes what would otherwise disperse.

**Examples:** petroleum accumulation in a reservoir trap; water pooling in a depression; traffic or inventory piling up at a chokepoint.

### C. Deposition and settling out of transport

The key feature is that what had been suspended, carried, or flowing becomes laid down, layered, or lodged in one site.

**Examples:** sediment deposition in reservoirs or floodplains; particulate settling; mineral scale laid down on surfaces.

### D. Bioaccumulation or tissue burden

The key feature is that uptake or exposure outruns excretion, metabolism, or clearance, so the target becomes increasingly concentrated in tissues.

**Examples:** persistent contaminants accumulating in organisms; toxins concentrating in food webs; chronic tissue burden from repeated exposure.

### E. Residual coating, encrustation, or fouling buildup

The key feature is that repeated small additions leave an operative layer, burden, or obstruction on a surface or in a corridor.

**Examples:** plaque-like buildup; scaling in pipes; grime accumulation on sensors; bureaucratic residue thickening one workflow.

### F. Documentary, logistical, or institutional stock buildup

The key feature is that cases, obligations, requests, or inventories pile up in one governed corridor because intake outruns adjudication, release, or consumption.

**Examples:** permit backlogs; warehouse stockpiles; archived requests awaiting review; pending liabilities concentrated on one ledger.

## Cross-domain pressure

### Geology and sediment transport

Geology pressures the archive because sedimentation and deposition show how transport can become laying-down, layering, and basin-filling rather than mere movement.

### Environmental toxicology and ecology

Toxicology pressures the archive because bioaccumulation shows that repeated small exposures can produce real growing burden in tissues before any overt phase change or collapse.

### Reservoirs, traps, and low-permeability structures

Reservoir cases pressure the archive because pooling depends on the shape and permeability of the containing site, not only on the substance being pooled.

### Engineering and infrastructure

Engineering pressures the archive because lines, surfaces, filters, and pipes often fail or change function through gradual buildup long before rupture or total blockage.

### Institutions and logistics

Institutional cases pressure the archive because backlogs, stockpiles, and concentrated obligations are real organizational states rather than merely delayed future actions.

## False moves to avoid

- Do **not** infer deliberate holding from every accumulation.
- Do **not** infer new bearerhood from every pool.
- Do **not** infer saturation from every buildup.
- Do **not** infer trace-only status from every residue.
- Do **not** infer absence at the source from every local increase at the sink.
- Do **not** infer fusion from every gathering-together.
- Do **not** infer permanence from every deposit.
- Do **not** infer one flat relation from **accumulating**, **building up**, **pooling**, **depositing**, **settling out**, **thickening**, **backing up**, **fouling**, or **leaving residue**.

## Default diagnostic questions

When a case is described as **accumulating**, **building up**, **pooling**, **settling out**, **depositing**, **thickening**, **fouling**, or **leaving residue**, ask:

1. What exactly is the **target** — sediment, fluid, gas, contaminant, charge, queue, document stream, inventory, obligation, residue layer, or mixed organization?
2. Is the case chiefly about **net buildup**, **pooling in a trap or basin**, **deposition / settling**, **bioaccumulation / tissue burden**, **residual surface buildup**, **institutional backlog**, or a mixed accumulation architecture?
3. What is actually **doing the buildup work** — repeated inflow, weak clearance, settling, low permeability, trapping geometry, persistent exposure, poor drainage, slow processing, adhesive retention, or mixed?
4. What remains **real underneath the increase** — same target more concentrated, same site under growing burden, same corridor with mounting backlog, same surface under a thickening layer, stronger saturation or blockage only in harder cases, or mixed?
5. What is the nearest **comparison class** — sequestration, fusion, saturation, delay, history-trace, leakage, reserve storage, ordinary transport, or artifact?
6. Is the right verdict **typed net accumulation**, **typed pooling**, **typed deposition**, **typed tissue burden**, **typed residual buildup**, **typed backlog / stockpile accumulation**, **mixed localized buildup architecture**, **apparent accumulation / proxy artifact**, or **still unsettled**?

## Compression rule

Future revisions should normally treat **accumulation / pooling / deposition / localized buildup** as one operator-family whenever the explanatory burden is: **real target, repeated or persistent arrival plus incomplete clearance, growing local burden or concentration, present operative consequence, and increase not yet best typed as deliberate sequestration, fusion, or saturation.**
