# Start here

## Current answer

Humans remain the default direct tax persons; current LLMs are taxed through controllers, beneficiaries, bottlenecks, rents, and harms rather than as direct civic subjects; mere prompting, delegated operation, outside oversight, risk finance, channel intermediation, third-party tool provision, ordinary training-input supply, or white-label branding does not relocate controller status, collective governance without a single dominant owner still routes through the real controller group, version resets or affiliate transfers do not by themselves erase controller continuity, but durable downstream customization, mission-specific commissioning, inside-the-loop tool governance, training / release gate control, real public-body deployment, or temporary step-in command can create co-controller duties; future artificial persons would enter ordinary person-tax logic only after a real rights / standing / non-ownership regime switch.
