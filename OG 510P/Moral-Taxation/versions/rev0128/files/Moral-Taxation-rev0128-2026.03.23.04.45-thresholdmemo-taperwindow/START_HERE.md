# Start here

This archive should reopen quickly. Treat this file as a route card, not a duplicate mini-manual.

## Current answer in one sentence

Humans remain the default direct tax persons; current LLMs are taxed through controllers, beneficiaries, bottlenecks, rents, and harms rather than as direct civic subjects; future artificial persons would enter ordinary person-tax logic only after a real rights / standing / non-ownership regime switch.

Then branch only if the dispute turns on a specific routing question:

- **who is taxed directly:** subjecthood and regime-switch routing
- **who really bears the burden:** incidence and regressivity routing
- **where proceeds should go:** proceeds and net-fiscal-stack routing
- **when payment should land:** timing, measurement, and real-value routing
- **which level of government has the first claim:** jurisdiction and international co-ordination routing
- **how administration stays just:** collection, administration, enforcement, and standing routing
