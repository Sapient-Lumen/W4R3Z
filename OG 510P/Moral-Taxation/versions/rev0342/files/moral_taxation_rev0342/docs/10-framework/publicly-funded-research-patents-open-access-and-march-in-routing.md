# Publicly funded research, patents, open access, and march-in routing

## Question in one sentence

When public grants produce publications, data, patents, or commercial products, how do we distinguish innovation incentives from taxpayer-funded paywalls, exclusive-license rents, and access failures?[S607][S608][S609]

## Core rule

Public funding creates a public claim. Patent exclusivity and publication charges can still be justified to commercialize or disseminate results, but the archive requires open-access, licensing, price/access, data, and unused-invention review before taxpayers fund both discovery and exclusion.[S607][S608][S609]

## Routing table

| Signal | Start here | Default output |
|---|---|---|
| publication from public grant | open-access gate | require timely public availability and reasonable publication-cost treatment. |
| patent from public funding | Bayh-Dole gate | track funding, disclosure, licensing, utilization, and public access. |
| exclusive license proposed | competition gate | use field, term, territory, performance, and access limits. |
| product price blocks access | access gate | test reasonable availability, government-use rights, march-in posture, or procurement leverage. |
| public data or infrastructure used | commons gate | require metadata, repository, privacy, and reuse conditions where feasible. |

## Anti-patterns

- **taxpayer-funded paywall** — public pays for knowledge and then must buy access again.
- **exclusive-license rent** — public invention becomes private exclusion beyond commercialization need.
- **publication-fee rent** — open access shifts excessive costs into grants.
- **unused-patent blockade** — publicly funded patent blocks follow-on use without deployment.
