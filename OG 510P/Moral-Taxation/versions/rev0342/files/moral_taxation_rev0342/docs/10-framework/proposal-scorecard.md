# Proposal scorecard

This table is generated from `scorecard-template.json`; edit the JSON, then render this markdown. The checker treats JSON as canonical.

## One-line thesis

A morally serious tax proposal should pass recurring tests for floor protection, subject/base clarity, incidence, timing, measurement, standing, review, channel access, current-law integrity, and classification seams before prose expansion.

## Score scale

- **+2** — strongly satisfies the criterion
- **+1** — mostly satisfies it
- **0** — mixed or unclear
- **-1** — significant defect
- **-2** — strong failure
- **Maximum score:** +196; **minimum score:** -196.

Protected-floor vetoes, non-compensable harm gates, standing/remedy failures, and source-currentness failures can block approval even when the arithmetic score is positive.
