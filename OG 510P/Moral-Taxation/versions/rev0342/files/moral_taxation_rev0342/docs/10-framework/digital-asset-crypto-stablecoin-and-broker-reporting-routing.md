# Digital-asset, crypto, stablecoin, and broker-reporting routing

## Question in one sentence

When cryptoassets, stablecoins, wallets, exchanges, DeFi interfaces, token rewards, basis records, broker reports, and cross-border crypto information flows are at issue, how should tax follow real gain, custody, control, and reporting capacity without gross-proceeds traps?[S487][S488][S489][S490]

Route: tax real income, gain, rent, payment intermediation, and systemic-risk value; require reporting where a party has custody, records, or regular facilitation capacity; protect users from gross-proceeds/basis mismatch and custody-blind penalties.[S487][S489]

## Core rule

The token is not the taxpayer. Liability follows the person or entity with income, gain, custody, broker capacity, issuer rent, validator/miner reward, or payment-system benefit. Reporting duties follow record power; penalties require correction paths when basis, wallet transfers, forks, or custodian data create mismatch.

## Routing table

| Signal | Start here | Default output |
|---|---|---|
| custodial exchange sale | broker-reporting gate | 1099-DA/gross proceeds/basis with correction and transfer basis. |
| self-custody transfer | realization gate | no taxable event merely from self-transfer; preserve basis trail. |
| stablecoin issuer earns reserve spread | issuer-rent gate | ordinary tax, reserve transparency, systemic-risk route if run risk. |
| DeFi interface without custody | control/capacity gate | do not assign broker duty without record/control capacity. |
| gross proceeds reported but basis absent | mismatch gate | bounded shelter, correction, and no penalty by default. |
| cross-border crypto reporting | coordination gate | CARF/CRS-style data use with due process and data minimization. |

## Anti-patterns

- **gross-proceeds trap** — proceeds are treated as gain when basis is missing.
- **custody-blind duty** — reporting obligation falls on actors without custody, records, or control.
- **chain analytics as guilt** — probabilistic traces substitute for notice and proof.
- **stablecoin shadow bank** — redemption promises avoid bank-like risk pricing.
