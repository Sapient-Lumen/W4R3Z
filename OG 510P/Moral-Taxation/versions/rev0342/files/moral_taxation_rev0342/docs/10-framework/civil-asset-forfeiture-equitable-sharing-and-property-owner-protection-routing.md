# Civil asset forfeiture, equitable sharing, and property-owner protection routing

## Question in one sentence

When the state seizes cash, vehicles, homes, accounts, or other property through civil forfeiture or equitable sharing, when is the instrument a legitimate crime-proceeds remedy and when is it self-funding policing or property-owner hostage taking?[S519][S520][S521][S522]

Route: forfeit crime proceeds and instrumentalities only with strong proof, prompt hearing, proportionality, innocent-owner protection, counsel/access, and proceeds routing that removes agency self-interest.[S520][S521]

## Core rule

Forfeiture is tax-like when it funds the seizing apparatus. The archive permits recovery of criminal proceeds and victim/public restoration, but rejects suspicion-based property loss, owner-burden traps, equitable-sharing end runs around state limits, and official-use incentives.

## Routing table

| Signal | Start here | Default output |
|---|---|---|
| no criminal charge or conviction | proof gate | heightened proof, prompt hearing, and proportionality review. |
| owner is not alleged wrongdoer | innocent-owner gate | shelter, notice, counsel access, and return path. |
| seizing agency keeps proceeds or property | proceeds-conflict gate | route to neutral fund, victims, or public repair. |
| state reform avoided through federal adoption | federalism gate | anti-end-run rule and local-law respect. |
| seizure value is small relative to contest cost | access gate | fee waiver, simple claim form, and cost shifting. |

## Anti-patterns

- **self-funding policing** — the agency that seizes receives the fiscal upside.
- **property-owner hostage trap** — the cost of contesting exceeds the property value.
- **suspicion tax** — property loss occurs without adequate proof of culpable connection.
- **equitable-sharing end run** — federal adoption bypasses state-law protections.
