## Core rule

A living archive needs release controls as much as doctrine. Each revision should prove that sources are bijective, machine surfaces agree, golden cases still route, stale revision openings are caught, and new files add a genuine axis, not another version of the same no-rent sentence.[S594][S645][S646]

## Routing table

| Signal | Start here | Default output |
|---|---|---|
| source appears in markdown but not JSON or vice versa | source-bijection gate | regenerate SOURCES.md and fail the release until both surfaces match. |
| README or index names an older revision as current | stale-surface gate | make the checker treat stale public openings as release blockers. |
| new route duplicates an existing axis family | sprawl gate | merge into existing ladder or golden case rather than adding a file. |
| official source has changed since a route was written | freshness gate | refresh primary source status and record proposal/final/effective-date state. |
| golden case cannot be routed without inventing doctrine | regression gate | add a narrow axis or ladder before expanding prose. |
