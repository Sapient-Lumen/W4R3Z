# Occupational licensing, professional entry, and reciprocity routing

## Question in one sentence

When licensing, fees, exams, continuing education, or reciprocity rules are used to protect consumers or public safety, how should the archive prevent entry rents and mobility traps?[S619][S620]

## Core rule

Licensing is legitimate when the state can show a concrete risk, least-restrictive design, cost-based fees, fair exams, provisional entry, and reciprocity where competence is portable. It fails when incumbents use the state to sell work permission.[S619][S620]

## Routing table

| Signal | Start here | Default output |
|---|---|---|
| public safety risk is concrete | necessity gate | license only to the minimum scope needed. |
| fees exceed administrative cost | fee gate | treat excess as hidden tax or incumbent rent. |
| worker moves across state or country | reciprocity gate | recognize comparable competence with bounded local supplements. |
| low-income entrant faces schooling/exam burden | entry gate | use provisional practice, waivers, or title protection. |
| criminal record or debt blocks license | relevance gate | require individualized relation to practice risk. |

## Anti-patterns

- **entry rent** — fees, hours, or exams protect incumbents rather than consumers.
- **mobility trap** — valid skills must be repurchased jurisdiction by jurisdiction.
- **debt gate** — unrelated fines or fees become work-permission ransom.
- **scope creep** — low-risk tasks are pulled into protected monopoly.
