# Cumulative-burden, environmental-justice, and siting-tax routing

## Question in one sentence

When a tax, credit, permit fee, abatement, or mitigation payment affects an already burdened place, how should fiscal design account for cumulative impacts rather than treating each burden as isolated and priceable?[S638][S639][S640]

## Core rule

Cumulative burden is not an optional equity appendix. Where multiple chemical, physical, fiscal, policing, utility, climate, and social stressors stack in one community, average statewide incidence is morally insufficient; siting, abatements, credits, fees, and offsets need place-based veto, repair, monitoring, and non-compensation limits.[S638][S639][S640]

## Routing table

| Signal | Start here | Default output |
|---|---|---|
| new facility or data center enters overburdened community | cumulative-impact gate | map existing pollution, health, infrastructure, and fiscal burdens before approving mitigation or abatement. |
| project offers tax revenue or community benefits | sacrifice-zone gate | do not sell permission for non-compensable health burden. |
| screening tool is missing or politically removed | data-continuity gate | use state, tribal, community, and archived data with uncertainty labels. |
| mitigation money is offered instead of exposure reduction | offset-limit gate | require direct burden reduction before community-benefit payments. |
| statewide average burden looks modest | place-based gate | disaggregate by neighborhood, race/proxy, income, tribal status, and health vulnerability. |
