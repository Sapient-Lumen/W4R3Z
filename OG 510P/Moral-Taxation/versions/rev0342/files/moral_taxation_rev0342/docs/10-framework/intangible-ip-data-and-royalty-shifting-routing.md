# Intangible, IP, data, and royalty-shifting routing

## Question in one sentence

When income is routed through patents, software, brands, algorithms, user data, cost-sharing, intra-group licenses, royalty conduits, or hard-to-value intangibles, how should the archive distinguish real value creation from paper ownership, source-state erasure, and royalty-stripping rents?[S456][S457][S458]

Route: legal ownership is evidence, not a moral endpoint. Allocate intangible income by real development, enhancement, maintenance, protection, exploitation, funding control, risk control, market/user contribution, and administrability; then protect low-capacity jurisdictions from proof burdens that erase their claim.[S456][S458]

## Core rule

Intangibles are tax-relevant because they can hold real rents and because they are easy to move on paper. The archive should neither pretend that legal IP boxes create value by themselves nor ignore genuine development, risk-taking, and public-input contribution.

## Routing table

| Signal | Start here | Default output |
|---|---|---|
| legal owner lacks people, risk control, or exploitation role | DEMPE/substance gate | reallocate, deny royalty strip, or require stronger proof. |
| hard-to-value intangible | valuation gate | ex ante documentation plus ex post reasonableness review. |
| routine distributor in low-capacity setting | simplification gate | use bounded simplified returns where eligible, not full bespoke litigation. |
| market/user data materially contributes | market/user contribution gate | consider source/market share, data-extraction route, or digital-service proxy. |
| developing-country administration lacks comparables | capacity gate | use safe harbor, Amount B-like simplification, formulary proxy, or UN-inclusive coordination. |
| intra-group royalty strips local base | conduit gate | beneficial-owner and substance-over-form review before deduction/credit. |

## Anti-patterns

- **paper ownership as value creation** — tax follows shell title rather than control, people, risk, exploitation, or market contribution.
- **royalty drain** — deductible payments erase source-state base without commensurate value.
- **comparables veto** — lack of perfect data defeats a weaker state's claim while sophisticated groups control the records.
- **simplification capture** — streamlined rules for routine distribution become a shelter for unique intangibles or economically significant risks.[S457]
