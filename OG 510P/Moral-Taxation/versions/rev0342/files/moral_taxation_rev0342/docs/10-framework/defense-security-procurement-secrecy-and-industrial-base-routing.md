# Defense, security procurement, secrecy, and industrial-base routing

## Question in one sentence

When national security procurement uses secrecy, urgency, sole-source awards, contract financing, or industrial-base subsidies, how do we prevent cost-overrun backstops, incumbent lock-in, and security theater?[S610][S611][S612][S613]

## Core rule

Security need can justify secrecy, speed, capacity finance, and domestic or allied industrial investment. It does not justify unlimited opacity: moral procurement requires mission fit, cost discipline, test evidence, supply-chain visibility, public-upside conditions, and protected whistleblower/audit lanes.[S610][S611][S612][S613]

## Routing table

| Signal | Start here | Default output |
|---|---|---|
| classified or urgent award proposed | secrecy gate | minimize opacity and create cleared audit, cost, and performance review. |
| sole-source continuation appears | competition gate | require documented necessity, exit plan, and modular/open architecture. |
| contract financing requested | financing gate | tie advances to recoverable milestones and public price benefit. |
| industrial-base subsidy claimed | resilience gate | test supplier diversity, workforce, allied capacity, and public upside. |
| cost growth or schedule slip appears | backstop gate | trigger redesign, clawback, or scope reset before taxpayers absorb all downside. |

## Anti-patterns

- **secrecy rent** — classified status shields weak cost or performance.
- **cost-overrun backstop** — public absorbs downside while contractors retain upside.
- **incumbent lock-in** — urgency and interoperability become permanent monopoly.
- **security theater** — mission language hides ordinary subsidy or procurement failure.
