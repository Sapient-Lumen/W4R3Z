# Measurement cadence and proxy graduation ladder

## Question in one sentence

Given the archive's closed rule that tax bases must be measured honestly and proxied only as far as necessary, **what is the smallest workable ladder for valuation cadence, proxy choice, and graduation so land, small-firm, and AI-related taxes stay measurable without fake precision, stale privilege, or threshold camping?**[S5][S10][S15][S16][S23][S25][S26][S27][S44]

The constitutional question is already settled: **the state should use the most observable, least gameable base that still tracks the moral target, publish the proxy ladder it is using, revalue or recalibrate before the proxy becomes privilege, and force graduation once a simplified regime is no longer the honest approximation.**[S15][S16][S23][S25][S26][S27][S44]

## Why calibration is still needed

The archive already says what measurement regimes may **not** become, but it still needs the narrowest workable operating ladder for live tax design. A usable ladder has to avoid two opposite failures at once:

1. **precision theater**, where the system pretends to know values, harms, or capacities that it can only guess at, and  
2. **proxy rot**, where old valuations, crude safe harbors, or simplified regimes persist long after they have become shelters, stale privilege, or distributionally arbitrary burdens.[S15][S16][S23][S25][S26][S27]

## Small option set

### Option A — static simplification and ad hoc discretion

Keep cadastral values, small-firm presumptions, or AI-use proxies in place for long periods with occasional discretionary overrides but no binding revaluation cadence, no published proxy hierarchy, and no forced graduation rule.[S23][S25][S26]

This is too weak for the archive. It invites stale privilege, cliff gaming, and opaque bargaining.

### Option B — bespoke accuracy everywhere

Push every domain toward case-by-case valuation or bespoke fact finding: individualized property review, full-book accounting for all firms, or bespoke impact estimation for AI deployments before any liability can attach.[S15][S16][S25][S26]

This is stronger than the archive needs as a general operating standard. It collapses compliance simplicity and makes low-capacity administration impossible.

### Option C — cadence-and-graduation ladder

Use a public ladder with four parts:

1. **direct-observation default** where a hard-to-fake base is available (metered draw, realized transactions, receipts, situs, payroll, or similarly observable facts),  
2. **published proxy hierarchy** where direct observation is impossible or too costly, naming the allowed proxy families in order of preference,  
3. **scheduled recalibration / revaluation cadence** before valuations or thresholds go stale, and  
4. **graduation and anti-bunching rules** that move taxpayers or regulated entities out of simplified regimes once size, margin, repeated threshold behavior, or operational complexity makes the proxy dishonest.[S15][S16][S23][S25][S26][S27][S44]

This option accepts approximation, but only on terms that remain visible, reviewable, and temporary.

### Option D — proxy-plus-watchlist ladder

Use Option C, but add a **watchlist trigger** whenever one of the following appears repeatedly:

- valuations miss market reality by a visible band,  
- entities bunch near simplified-regime thresholds,  
- a proxy is being treated as if it were the moral target rather than an approximation, or  
- machine-assisted estimates begin driving adverse actions without a visible correction packet.[S16][S23][S25][S26][S27][S44]

That trigger does not automatically tighten liability. It forces proxy review, parameter reset, or migration to a more observable base.

## Provisional recommendation

Adopt **Option D — the cadence-and-graduation ladder with watchlist triggers** as the archive's default calibration setting.[S15][S16][S23][S25][S26][S27][S44]

Use the following default operating standard:

- **Land and property** should sit on a named revaluation schedule with an appeal path and no indefinite freeze.[S23][S25]
- **Small-firm simplifications** should be framed as on-ramps, with graduation tests keyed to repeated threshold bunching, durable scale, margin patterns, or bookkeeping capacity rather than a single forever-threshold.[S26][S27]
- **AI-related levies or obligations** should prefer controller-side physical aggregates or deployment categories that can actually be measured, but those proxies should never be treated as value, consciousness, or total social harm; once the proxy stops tracking the moral target well enough, the regime should tighten governance, reset the proxy, or move outward to a more honest base.[S10][S15][S16][S44]

That is the narrowest workable setting because it preserves administrative tractability without letting convenience proxies harden into privilege or metaphysics.

## Default cadence-and-graduation table

| Domain | Default base choice | Reset / review cadence | Graduation trigger | Archive stance |
|---|---|---|---|---|
| land / property | market-linked appraisal or transparent mass-appraisal proxy | scheduled revaluation, not open-ended freeze | repeated gap between assessed and observable value bands | allow proxy use, but force cadence and appeals[S23][S25] |
| small firms | simplified turnover / presumptive regime only as on-ramp | threshold and error review on a fixed schedule | repeated bunching, durable scale, margin depth, or bookkeeping maturity | simplify early, graduate visibly[S26][S27] |
| AI scarce-capacity or burden proxies | controller-side observable aggregates first | reset when hardware / deployment conditions materially shift | proxy drift, gaming, or mismatch between proxy and burden | use measurable proxies, but do not confuse them with total harm or value[S10][S15][S16] |
| model-assisted estimates in administration | replayable proxy ladder plus review packet | rule-version review and rollback checks | adverse action without usable reconstruction / challenge path | no black-box coercive dependence[S16][S27][S44] |
