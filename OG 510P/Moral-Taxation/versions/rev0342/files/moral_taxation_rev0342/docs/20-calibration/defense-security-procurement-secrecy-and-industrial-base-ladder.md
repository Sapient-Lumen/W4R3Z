# Defense, security procurement, secrecy, and industrial-base ladder

## Question in one sentence

How should defense procurement preserve mission urgency without turning secrecy, lifecycle cost, or industrial-base fragility into fiscal rent?[S610][S611][S612][S613][S673]

## Priority gates

1. **mission/maturity gate** — state threat, capability, user, time horizon, technology maturity, and requirement stability.
2. **competition gate** — test alternatives, modularity, open architecture, data rights, second sources, and exit from incumbent lock-in.
3. **secrecy gate** — limit classified withholding; preserve cleared oversight, protest substitutes, and whistleblower channels.
4. **financing gate** — tie advances and performance-based payments to objective, recoverable milestones.[S612]
5. **supply-chain gate** — require critical-origin and foreign-dependency visibility where supplier opacity creates security risk.[S611]
6. **test/lifecycle gate** — do not treat deployment pressure as evidence of capability; include operating and support cost growth in review.[S610][S673]
7. **public-upside gate** — use pricing, data rights, clawbacks, royalties, or equity-like returns when public capacity finance builds private value.
8. **review gate** — reopen on cost growth, schedule slip, test failure, audit weakness, sole-source drift, sustainment growth, or unverified supply-chain dependency.
