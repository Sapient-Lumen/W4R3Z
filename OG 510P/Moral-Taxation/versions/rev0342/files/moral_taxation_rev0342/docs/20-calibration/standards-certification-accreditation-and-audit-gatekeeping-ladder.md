## Option scan

| Option | Shape | Archive verdict |
|---|---|---|
| A — single private certification gate | one paid badge decides market or public eligibility. | Weak unless justified, price-capped, and appealable. |
| B — recognized-equivalent standards | accept equivalent evidence and multiple assessors. | Strong default for avoiding certification monopoly. |
| C — public-interest conformity assessment | test specified requirements with transparent scope. | Strong when the requirement is clear and risk-based. |
| D — audit rotation / conflict firewall | separate paid assessor incentives from pass/fail control. | Use when certification markets become captured. |
| E — public schema / open standard | publish the compliance target and evidence format. | Strong for rights-bearing and small-entity access. |

## Default settings

| Posture | Instrument | Guardrail |
|---|---|---|
| public procurement standard | public schema plus equivalent evidence | multiple qualified assessors. |
| high-risk product | conformity assessment | appealable and conflict-screened. |
| small entity | fee cap or public testing support | no certified-access rent. |
