## Option scan

| Option | Shape | Archive verdict |
|---|---|---|
| A — add route | new framework file plus ladder. | Use only for distinct recurring routing problem. |
| B — add ladder only | settings remain open under existing rule. | Preferred for calibration. |
| C — add golden case | tests existing routes without new doctrine. | Preferred for examples and edge cases. |
| D — merge/retire | compress duplicate routes or stale files. | Required when axes overlap. |
| E — refresh evidence | update sources and review triggers. | Required for unstable external facts. |

## Ten-gate ladder

1. **distinctness gate** — name the axis combination not covered elsewhere.
2. **recurrence gate** — show at least two realistic cases or one high-stakes recurring case.
3. **compression gate** — prove the new file shortens rather than lengthens future routing.
4. **golden-case gate** — add or update a case card.
5. **source gate** — mark evidence state and source freshness.
6. **axis gate** — reuse existing axis values unless a real new value is necessary.
7. **family gate** — check whether an archive note or table suffices.
8. **retirement gate** — identify any file, phrase, route, or axis value made redundant.
9. **checker gate** — encode a new invariant if the revision fixed a drift class.
10. **review gate** — set a trigger for evidence refresh, source drift, or route merger.

## Default settings

| Posture | Instrument | Guardrail |
|---|---|---|
| repeated case, missing axis | new route | add cube record and case. |
| same rule, new parameters | ladder | no new framework note. |
| example-only pressure | golden case | keep waist closed. |
| stale source | refresh | cite current authority and mark uncertainty. |
| duplicated no-rent note | merge/retire | protect archive usability. |
