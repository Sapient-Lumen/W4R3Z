# Changelog

## rev0300 — cross-border-reporting-accountability-refactor

Rev0300 is a substantive accountability and cube-axis revision. It rewrites all 6 `cross_border_reporting` actor-accountability profiles so international coordination, customs/CBAM border charges, remittance corridors, immigration/asylum/status fees, withholding/treaty/MAP relief, and GIR/claim-split routes no longer rely on generic beneficiary/rent-recipient placeholders or generic benefit-trace evidence. It also refactors cross-border cube records that had inherited generic templates, with the deepest corrections to `international_coordination_claim_split` and `un_inclusive_international_tax`.
