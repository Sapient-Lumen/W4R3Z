# Procurement, subsidy, clawback, and public-upside ladder

## Question in one sentence

What ladder should decide when procurement, tax credits, grants, guarantees, or industrial-policy support buy public capability and when they create private rents?[S512][S513][S514]

## Option scan

| Option | Shape | Archive verdict |
|---|---|---|
| A — competitive procurement | buy goods/services at public value. | Default where market exists and switching is possible. |
| B — tax credit | reward qualifying private investment. | Use only with net-stack disclosure and incidence review. |
| C — grant or guarantee | public shares cost/risk. | Require conditions, clawback, and upside if private value rises. |
| D — public equity/royalty | public gets return if project succeeds. | Strong where public risk and private upside are large. |
| E — local abatement | reduce taxes to attract investment. | Suspect unless net local burden and equalization are solved. |

## Ten-gate ladder

1. **purpose gate** — name the public purpose: capacity, resilience, security, affordability, decarbonization, access, jobs, or local repair.
2. **instrument gate** — compare procurement, direct public provision, grant, loan, guarantee, tax credit, abatement, price preference, public equity, or regulation.
3. **net-stack gate** — count grants, credits, abatements, accelerated depreciation, cheap land, utility discounts, infrastructure, procurement, and guarantees together.
4. **competition gate** — test bidder count, lock-in, interoperability, switching cost, local small-business access, and market concentration.[S512]
5. **performance gate** — define milestones, job quality, access, price, domestic or local capability, emissions, resilience, or service obligations.[S513]
6. **clawback gate** — set automatic recovery if promised performance fails, assets move, jobs vanish, or public use is denied.
7. **upside gate** — use warrants, royalties, profit share, price caps, open licenses, or public equity where public risk creates private asset value.
8. **incidence gate** — check whether support enriches shareholders, executives, landlords, input suppliers, or contractors instead of the public purpose.
9. **equalization gate** — repair host burdens first, then prevent rich jurisdictions from hoarding location windfalls.
10. **review gate** — revisit after single-bid awards, cost overruns, missed milestones, lobbying capture, market-share shifts, or subsidy races.[S514]

## Default settings

| Posture | Instrument | Guardrail |
|---|---|---|
| ordinary purchase | competitive procurement | open standards and audit. |
| strategic capacity | grant/credit/loan | performance and sunset. |
| public risk/private upside | equity/royalty/clawback | public return. |
| local burden | host repair | net-stack disclosure. |
| concentrated winner | antitrust/procurement review | no captive standard. |
