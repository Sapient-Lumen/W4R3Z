# Distributional equality-impact and fiscal-incidence ladder

## Question in one sentence

How should the archive scale fiscal-incidence and equality-impact analysis when data are incomplete or protected-class measurement is constrained?[S569][S571][S564]

## Option scan

| Option | Shape | Archive verdict |
|---|---|---|
| A — no distribution table | aggregate revenue only. | Reject for material proposals. |
| B — income-only table | quintiles or deciles. | Minimum but incomplete. |
| C — net fiscal incidence | taxes, transfers, and service changes. | Default where data allow. |
| D — equality and place slices | lawful proxies and local effects. | Required for plausible concentrated burden. |
| E — conservative proxy/sunset | acknowledge data gaps and remeasure. | Use when direct measurement is impossible. |

## Ten-gate ladder

1. **unit gate** — define household, filing unit, firm, region, or beneficiary group consistently.
2. **income gate** — show decile/quintile effects and protected floor impacts.
3. **wealth/liquidity gate** — test asset-rich/income-poor, cash-flow, debt, and realization effects.
4. **household gate** — test care, disability, age, second earners, dependents, and joint liability.
5. **place gate** — test local ratepayer, infrastructure, climate, housing, and service burdens.
6. **protected-proxy gate** — use lawful proxy, qualitative, or community evidence where direct data are unavailable.
7. **net-fiscal gate** — include transfers, tax credits, user charges, and public-service changes when feasible.
8. **tail gate** — examine cliffs, outliers, and transition losers, not just averages.
9. **uncertainty gate** — state data limits and use conservative defaults for floor risks.
10. **review gate** — schedule remeasurement after implementation and fix concentrated surprises.

## Default settings

| Posture | Instrument | Guardrail |
|---|---|---|
| small technical correction | income table if material | avoid false precision. |
| major tax package | net fiscal incidence | include transfers. |
| local infrastructure charge | place analysis | show local burdens and repair. |
| protected proxy plausible | lawful proxy/qualitative review | do not claim blindness. |
| missing data | sunset and remeasure | use conservative floor default. |
