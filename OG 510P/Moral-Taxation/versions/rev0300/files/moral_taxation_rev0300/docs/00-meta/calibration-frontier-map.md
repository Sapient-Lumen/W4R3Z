## Default rule

When a live issue fits calibration, prefer one of these over a new `docs/10-framework/` note:

1. an archive note,
2. a calibration memo that narrows one range,
3. a scorecard or decision-procedure refinement,
4. or a dedupe patch to a re-entry surface.

Reopen the waist only for a missing routing rule, reversal, or compression win.

## Triage order

Prefer this order for the next addition:

1. questions that block multiple downstream calibrations,
2. questions that change real burden-bearing or standing,
3. questions that affect machine-assisted administration before deployment,
4. only then narrower rate or threshold tuning.

## Compression

If a proposed addition does not narrow a cluster, compress an existing note, or clarify a re-entry surface, it probably does not belong in the archive yet.
