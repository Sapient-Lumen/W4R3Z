# AI regulatory-role crosswalk and controller-evidence routing

## Question in one sentence

How should the archive use AI regulatory roles — provider, deployer, importer, distributor, GPAI provider, systemic-risk GPAI provider, open-source provider, product manufacturer, public-sector deployer, significant modifier, or critical-infrastructure operator — without mistaking them for tax subjecthood or controller status?[S17][S44][S446][S447][S448]

## Core rule

Regulatory role is evidence, not identity. It can show knowledge, documentation access, release control, deployment control, risk management capacity, or public-law duty. It does not by itself make the actor the tax subject, the taxable base, the primary controller, or the beneficiary of the rent.[S446][S447]

## Crosswalk

| Regulatory role | Tax relevance | Non-dispositive point |
|---|---|---|
| model/provider or GPAI provider | release governance, documentation, systemic-risk duties, copyright/transparency duties | provider status does not automatically make the provider liable for every downstream use.[S447] |
| deployer | local purpose, tool permissioning, user interface, human review, procurement, affected users | deployment role can be strong controller evidence when it controls live action. |
| importer/distributor | market access, chain-of-supply records, conformity duties | distribution alone may be remittance or record capacity, not primary control. |
| significant modifier | changes model behavior, safety, or intended purpose | modification can create co-controller status for the modified layer. |
| open-source provider | public release, maintenance, update channels, governance | static release differs from maintained hub or gated distribution. |
| critical-infrastructure operator | safety, resilience, continuity, public dependency | criticality strengthens precaution and review, not a token tax.[S448] |
| tax authority as AI deployer | model score, audit selection, notice generation, service automation | enforcement AI requires taxpayer explanation and appeal parity.[S44][S449] |

## Tax administration symmetry

If a tax authority uses AI to detect, prioritize, adjust, score, or communicate, it must also maintain taxpayer-side explanation, correction, and appeal capacity. A model-assisted notice should disclose the issue, data category, action requested, correction route, deadline, human review path, and limits of the model's role where feasible without defeating legitimate enforcement.[S44][S449]
