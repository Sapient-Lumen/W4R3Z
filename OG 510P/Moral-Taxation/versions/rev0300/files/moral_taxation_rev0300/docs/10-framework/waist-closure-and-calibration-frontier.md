# Waist closure and calibration frontier

The archive is now large enough that the next discipline is not only **what** it says, but **where future growth is allowed to happen**. This note draws the line.

## What is now treated as closed at the narrow waist

The archive now has compact routing rules for the questions that should not have to be re-argued every time a new tax proposal appears:

- what the moral target is,
- which base should usually be preferred before ordinary labor,
- who is the direct subject, remitter, controller, and likely burden-bearer,
- how rates, threshold shape, timing, losses, inflation, and measurement should be handled,
- how assessment units, anti-fragmentation, classification integrity, and standing work,
- how collection, administration, channel pluralism / access independence, burden salience / disclosure, model-assisted review, verification intensity, appeals, third-party reporting correction, household-status allocation, official-error reliance, bounded recipient shelter, contest windows, issue-scoped correction, period-bounded finality, interim liability, stays, escrow, hardship relief, overcollection return, narrow setoff, same-facts reuse, portability, delta updates, enforcement, floor protection, proceeds routing, and superior-access proof burdens work,
- how scale, jurisdiction, coordination, and AI-specific exceptions should be handled,
- and when present tool-regime logic would have to switch to person-regime logic for a future artificial subject.

These are now the archive's **constitutional waist**. New work should presume them unless it is actually revising them.

## What belongs in the calibration frontier instead

Most remaining open questions are no longer about whether a routing rule exists. They are about **calibration after the rule exists**:

- threshold interaction and exact taper speeds,
- disclosure cadence and visibility depth,
- index sets,
- proxy hierarchies,
- apportionment weights,
- bonding levels,
- review cadence,
- trigger evidence,
- and delivery / appeal usability.

That work still matters, but it usually belongs in focused archive notes, empirical memos, or updates to `open-questions.md`, not in an ever-growing list of new narrow-waist files. When possible, those memos should use [`../00-meta/calibration-memo-format.md`](../00-meta/calibration-memo-format.md).

## Admission rule for future framework additions

Add a new file to `docs/10-framework/` only if at least one of these is true:

1. a genuinely missing routing rule is preventing consistent evaluation,
2. several existing notes can be collapsed by introducing one cleaner shared rule,
3. a current waist rule is being materially revised rather than merely tuned,
4. or a repeated open question has become stable enough to graduate from calibration into constitutional guidance.

If none of those is true, prefer a smaller move:

- tighten an existing routing note,
- update `open-questions.md`,
- add or refine a single archive note,
- or improve the scorecard / runbook / context pack.

## Compression rule

When space pressure appears, protect this order:

1. constitutional principles,
2. default tax stack by scale,
3. routing notes that answer subject, burden, timing, measurement, scale, proceeds, and rights questions,
4. the class/context/species matrix and ideal schedule,
5. then archive notes that supply depth, examples, and empirical support.

The narrow waist should therefore grow **more slowly** than the archive around it.

## Editorial consequence

Future revisions should increasingly look like one of two things:

- a **calibration refinement** that narrows an open question without pretending to change the constitutional waist, or
- a **compression / dedupe revision** that makes reopening easier.

That is now the default. The archive has enough first-order routing notes to stop treating every unresolved parameter as a missing constitutional principle.
