## Core rule

A route earns its place only if it adds a distinct axis combination, resolves recurring cases better than existing files, or compresses several live disputes. Otherwise the correct action is merge, retire, refresh evidence, or add a golden case without widening the waist.[S59][S594]

## Routing table

| Signal | Start here | Default output |
|---|---|---|
| new memo repeats no-rent pattern | duplication gate | merge into family route or archive note. |
| source basis is stale or disputed | evidence gate | refresh source IDs, mark uncertainty, or downgrade rule. |
| many cases route to same output | compression gate | build a ladder or table instead of more prose. |
| route has no golden case | usability gate | add a case card before expanding. |
| axis values are proliferating | axis gate | dedupe synonyms and keep route records canonical. |

## Anti-patterns

- **prose sprawl** — more memos substitute for sharper routing.
- **stale doctrine** — old external facts silently govern new cases.
- **axis bloat** — synonyms create fake distinctions.
- **permanent frontier** — unresolved calibration becomes unreviewed doctrine.
