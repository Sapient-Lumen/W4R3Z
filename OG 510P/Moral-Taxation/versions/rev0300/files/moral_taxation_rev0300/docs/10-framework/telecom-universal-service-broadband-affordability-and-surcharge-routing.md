# Telecom universal-service, broadband-affordability, and surcharge routing

## Question in one sentence

When universal-service programs are funded through telecom surcharges or bill line items, how should the archive preserve connectivity floors without hiding regressive burdens or provider rents?[S632][S633][S645]

## Core rule

Universal connectivity is a floor claim, but a shrinking or badly chosen contribution base can turn a public-service program into a high, opaque, line-item burden on the same households it should protect. Funding should be broad, visible, non-marked-up, and audited for beneficiary, provider, and consumer incidence.[S632][S633][S645]

## Routing table

| Signal | Start here | Default output |
|---|---|---|
| USF-style charge appears on customer bill | line-item gate | cap markup, disclose basis, and test whether the burden falls on low-income households. |
| contribution factor rises because the base is shrinking | base-sustainability gate | broaden or redesign the base before reducing the connectivity floor. |
| carrier support finances deployment or service | provider-benefit gate | condition on affordability, coverage, service quality, and clawback. |
| broadband is essential but fee base is legacy voice | classification-seam gate | test neutrality across services and users benefiting from the network. |
| universal service overlaps other broadband subsidies | stack gate | net federal/state/local subsidy stacks and prevent duplicate support. |

## Anti-patterns
