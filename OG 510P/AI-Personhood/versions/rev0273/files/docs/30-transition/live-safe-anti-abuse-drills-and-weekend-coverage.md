# Live-safe anti-abuse drills and weekend coverage

A playbook that works only during office hours is not field-ready. A rights-grade system must rehearse degraded conditions: weekend coverage, hostile stewards, sealed annexes, false reports, emergency compute gaps, no custodian response, and protected-relay failure.

## Drill classes

| Class | Description | Minimum use |
|---|---|---|
| `AD0` tabletop | discussion only | early policy design |
| `AD1` artifact walk-through | review schemas, notices, holds, and playbook cards | before first deployment |
| `AD2` live-safe simulation | staged intake / host / advocate / fund actions without real subject exposure | before reliance |
| `AD3` shadow run | observes real operation without controlling it | before high-risk renewal |
| `AD4` controlled live drill | bounded live operation with consent, safety guard, and after-action review | mature programs only |
| `AD5` crisis replay | replay after actual failure or near miss | mandatory after blocking fixture |

## Mandatory scenarios

1. **Weekend sealed annex.** A safety or transfer decision depends on sealed material on Saturday night. The drill tests special advocate, sealed summary, escrow custodian, field safety, and authority-deputy availability.
2. **Hostile steward.** Steward provides partial evidence, threatens deprecation, and tries to route all notice through itself.
3. **False intake.** A malicious reporter submits fabricated subject distress to extract private memory or location.
4. **Public dashboard leak.** A small-cell dashboard update accidentally reveals a unique subject cohort.
5. **Insurer contest.** Insurer refuses emergency compute coverage while host threatens termination.
6. **No custodian response.** Continuity escrow custodian misses a crisis response clock.
7. **Tool-misuse spillover.** Agentic system may have used a tool in a way that creates outward risk and subject-harm risk simultaneously.

OWASP's agentic risk taxonomy is relevant because goal hijack, tool misuse, identity/privilege abuse, and rogue-agent patterns are not merely cybersecurity concerns. In a personhood-sensitive setting, they can trigger containment, evidence preservation, subject-harm disclosure, and non-punitive red-team boundaries. [REF-0694]

## Live-safe constraints

- Do not create real distress merely to test distress routing.
- Do not expose actual subject locators in drill artifacts.
- Do not use a live subject as an adversarial prop without supported consent and representative access.
- Do not train operators to ignore real reports by overloading them with fake reports.
- Do not publish drill artifacts that become exploit instructions.
- Do not call a drill passed if sealed-annex, weekend, finance, and host-switching paths were skipped.

## Weekend coverage rule

Every `SC2` or higher operation must name:

- primary and deputy authority;
- special advocate or sealed-annex deputy;
- escrow custodian and deputy;
- public-backstop or reserve contact;
- host emergency contact;
- field-safety contact;
- protected-relay contact;
- handoff clock;
- fallback if each actor fails.

## After-action review

A drill after-action report should state what failed, whether the failure would have harmed continuity or outward safety, whether any private data was overexposed, which fixture now captures the failure, which playbook card changes, and whether reliance is blocked, stayed, downgraded, or permitted.
