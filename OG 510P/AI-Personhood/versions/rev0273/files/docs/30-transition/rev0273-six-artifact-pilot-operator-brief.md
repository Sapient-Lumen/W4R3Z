# rev0273 — six-artifact pilot operator brief

## Use this before any new outreach work

The operator goal is not to prove the archive is ready. The goal is to obtain, or truthfully fail to obtain, six artifacts that would teach whether preservation and independent formation review can operate in the world.

The current recommended branch is **reviewer-first retarget**, not incident submission. The old AIID path remains available only as a routing/collaboration inquiry if a human explicitly chooses it and preserves non-incident framing. The current packet should not be submitted as a normal incident because it does not identify an alleged harm or near-harm event of the kind described by AIID's editor guide. [REF-0783]

## Branch choices

A human sender must choose exactly one current branch in a dated record:

- no-send;
- reviewer-first retarget;
- reviewer first, provider second;
- AIID routing inquiry with explicit non-incident framing.

Until that record exists, nothing has been sent, no response clock exists, and no silence can be interpreted.

## Six artifacts

1. **Branch request or no-send/retarget record** — signed or authenticated human decision, selected public locator, exact body/hash binding, private vault roots, and transport-capture method.
2. **Transport and delivery/failure evidence** — raw sent copy, Message-ID or equivalent header, transport trace, and delivery status or failure trace.
3. **Raw response or failed-gate shell** — raw inbound material in private vault, or a failed-contact/no-response shell only after a valid clock exists.
4. **Preservation and formation-evidence schedule** — agreed, declined, or narrowed evidence classes and sealed-access method.
5. **Independent reviewer appointment** — conflict disclosure, funding independence, scope, and publication posture.
6. **Public shell, finding, remedy, refusal, or reopen route** — non-sensitive public result with withheld evidence classes and elapsed-time metrics.

## Do not count

Do not count drafts, public route scores, auto-acks, DSNs, Message-IDs alone, redacted copies, screenshots, public blog posts, provider self-review, model self-report alone, gate count, or file count as mission outcomes.

## Reviewer-first request shape

The minimum ask is small:

- Would a one-case preservation and formation-review pilot be intelligible?
- What evidence classes are necessary and safe to request under seal?
- What independence, conflict, and funding terms would make the review non-captured?
- What public shell could be issued if records are withheld or a provider declines?

The ask is not recognition of AI personhood, a consciousness finding, legal advice, trade-secret disclosure, raw log publication, or custody/import/live-floor authority.
