## Pre-send custody hard stop

Before any actual send, complete `examples/pre-send-custody-precommit-rev0266-no-private-root-selected.json` outside the public tree. The current state intentionally selects no private root, so a send is blocked even if the human later selects reviewer-first.

The public ZIP may contain a public shell, hashes, and non-sensitive status only. Raw sent bytes, headers, delivery/failure traces, replies, reviewer correspondence, provider correspondence, and sealed evidence stay private unless a separate release decision authorizes redaction.

## What counts as progress

Progress is one of these, in order:

1. Signed no-send or signed branch authorization.
2. Fresh route locator recheck and final hash recompute.
3. Private custody roots selected outside the public tree.
4. Raw sent copy plus transport proof or failed-send proof.
5. Raw human reply, referral, decline, or no-response failed-gate shell.
6. Reviewer appointment/decline/referral and public-shell finding/remedy/reopen path.

File count, route score, body polish, schema count, and doctrinal completeness are not progress.

## Anti-laundering rule

A generated object can prepare a decision. It cannot be the decision. A sent message can create transport evidence. It cannot be the counterparty response. A reply can enter custody. It cannot become import or live-floor effect without the later gates.
