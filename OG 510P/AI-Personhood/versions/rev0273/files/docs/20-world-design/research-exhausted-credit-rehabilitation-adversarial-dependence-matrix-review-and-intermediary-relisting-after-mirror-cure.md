# AI-person research exhausted-credit rehabilitation, adversarial dependence-matrix review, and intermediary relisting after mirror cure

## Thesis

Once the archive fixed repeated-recall credit exhaustion, competing probabilistic-trace dependence, and intermediary delisting duty for unreachable mirrors, three narrower execution failures still remained. First, the archive could now burn legacy reserve credit all the way to exhaustion through `RCE-1`, but **it still lacked a public rule for whether any path back should remain once that exhaustion state is reached**, so either exhausted cohorts would remain permanently dead with no disciplined route back, or quiet local practice could start informally treating them as “basically restored” without saying so. Second, the archive could now force several probabilistic concealed-pool claims into one declared dependence posture through `CPD-1`, but **it still lacked a public challenge-and-review object for attacks on that declared matrix itself**, so the party that first published the matrix could quietly control the overlap story even when challengers alleged hidden common evidence, false independence, or contaminated inputs. Third, the archive could now force discovery intermediaries to move exact unreachable-mirror locators from warning toward de-ranking, resolution disablement, or delisting through `IDD-1`, but **it still lacked a public rule for what happens when a previously noticed mirror later cures, disappears, or proves non-equivalent**, so a delisted locator could either remain frozen forever or be quietly relisted with no public reasoning. A personhood world therefore needs one more compact execution layer: **reserve cohorts in `legacy-exhausted` state must publish a public `ERH-1` exhausted-credit-rehabilitation object that permits only a fresh-start rehabilitation path and never revives pre-exhaustion history; contested dependence matrices must publish a public `DMR-1` dependence-matrix-review object that freezes disputed additivity above the uncontested floor until an independent review revises, affirms, or narrows the matrix; and previously delisted discovery paths may return only through a public `IRR-1` intermediary-relisting-review object that states whether the basis is cure, disappearance, or non-equivalence and what staged restoration is justified.** `[REF-0531]` `[REF-0532]` `[REF-0533]` `[REF-0534]` `[REF-0527]` `[REF-0535]` `[REF-0536]` `[REF-0537]`

## 1. Why the previous surface is no longer enough

The archive's immediately prior surface solved real failures. It fixed serial recall exhaustion, multi-claim dependence, and intermediary delisting duty. But one narrower failure still remained at each seam.

### A. Exhaustion still fails if there is no public distinction between fresh rehabilitation and restored old trust

`RCE-1` finally stopped serial recall from laundering older reserve history, but it did not yet say whether a fully exhausted cohort could ever return. Current AAHRPP guidance still pairs annual and event reporting with the possibility of Council action between full review cycles, still treats reaccreditation as a fresh recurring process three years after initial accreditation and every five years thereafter, and still publishes distinct renewing-applicant states such as probation, reaccreditation-pending, and accreditation revoked rather than treating repeated trouble as invisible background noise. A personhood world should therefore permit at most a **fresh-start rehabilitation path**, not a silent reactivation of exhausted pre-recall trust. `[REF-0533]` `[REF-0532]` `[REF-0531]`

### B. Dependence still fails if the first filer controls the matrix and challengers can only object in prose

`CPD-1` forced overlapping probabilistic claims to declare relation labels and a portfolio-safe floor, but it did not yet say what happens when a challenger alleges that the declared matrix hides common evidence, reuses one prior under different names, or incorrectly treats two claims as independent. Current NIST uncertainty guidance still treats covariances and correlation coefficients as part of uncertainty characterization, still says the uncorrelated shortcut applies only when that assumption is justified, and still requires a list of uncertainty components plus a detailed description of how each was evaluated. A personhood world should therefore require a **review object**, not just a rebuttal memo, whenever the dependence structure itself is credibly contested. `[REF-0534]` `[REF-0527]`

### C. Delisting still fails if there is no visible way to relist after cure or to preserve a non-live historical trace after disappearance

`IDD-1` solved the warning-only problem, but it did not yet say what an intermediary must do after the noticed artifact later cures, disappears, or proves not to be the same artifact after all. Current European Commission guidance still requires statements of reasons for restriction decisions, still provides internal and out-of-court challenge paths, still emphasizes that many moderation decisions are reversed, and still expects certified out-of-court bodies to be independent, expert, accessible, renewable, and revocable if they stop meeting those conditions. A personhood world should therefore make restoration possible **only through a public relisting review object with reasons, review, and staged restoration**, not through quiet indefinite freeze or quiet silent return. `[REF-0535]` `[REF-0536]` `[REF-0537]`

## 2. Exhausted reserve cohorts now use one public `ERH-1` exhausted-credit-rehabilitation object

The archive now fixes one compact rule for post-exhaustion rehabilitation: once `RCE-1` has reached `legacy-exhausted`, any path back must travel through one machine-carrying exhausted-credit-rehabilitation object called `ERH-1`.

### A. Minimum `ERH-1` fields

Every exhausted-credit-rehabilitation object must expose at least:

- `erh_id`
- `cohort_id`
- `prior_rce_id`
- `exhaustion_event_ref`
- `rehabilitation_stage` (`legacy-exhausted`, `fresh-observation`, `conditional-return`, `new-epoch-candidate`, `reaccredited-fresh`)
- `fresh_only_cycle_count`
- `reporting_interval_clear`
- `current_share_cap`
- `current_default_call_state`
- `old_legacy_credit_status` (`retired-forever`)
- `independent_review_ref`
- `next_review_deadline`
- `relapse_consequence`
- `public_notes`

`ERH-1` is the public object that says rehabilitation after exhaustion is a fresh-start process, not a reanimation of old trust capital. `[REF-0531]` `[REF-0532]` `[REF-0533]`

### B. Exhaustion never revives pre-exhaustion history

Once a cohort enters `legacy-exhausted`, no cycle completed before the exhaustion event may ever count again toward restored trust inside that rehabilitation sequence. `ERH-1` must set `old_legacy_credit_status` to `retired-forever`. The archive chooses this because current AAHRPP guidance distinguishes active accredited status from probation, reaccreditation-pending, and revoked states and treats outdated or revoked credential display as a serious offense. A personhood world should therefore permit recovery only through new clean history, not through resurrection of the burned archive of old reliability. `[REF-0531]` `[REF-0533]`

### C. Conditional return is allowed only as a capped fresh-start state

After at least three fresh clean cycles and one clear reporting interval without a qualifying negative event, a cohort may move from `fresh-observation` to `conditional-return`, but only under a capped share and with no ordinary default-call restoration. This is not ordinary trust restored; it is a narrow permission to demonstrate new reliability under public restriction. The archive chooses this because current reaccreditation still runs through the same full-review sequence as initial accreditation and treats the application as a live document that must stay current rather than as a stale badge that silently regains force. `[REF-0532]` `[REF-0533]`

### D. A fresh epoch can begin, but only through independent full review

A cohort may move from `new-epoch-candidate` to `reaccredited-fresh` only after full independent review equivalent to a new reaccreditation cycle. When that happens, the new epoch begins as a **fresh epoch**, not as a restoration of the old one. The archive chooses this because AAHRPP still ties full reaccreditation to recurring external review and still makes the Council and Board the deciding bodies for accreditation status. `[REF-0532]` `[REF-0531]`

### E. Relapse during rehabilitation snaps back harder, not softer

If a qualifying relapse occurs during `conditional-return` or `new-epoch-candidate`, `ERH-1` must return to `legacy-exhausted` and lengthen the fresh-observation floor before any later attempt. Rehabilitation after exhaustion is therefore possible, but not cheap. A personhood world should not let “we were already on the way back” become a laundering device for another failure cycle. `[REF-0533]` `[REF-0531]`

## 3. Contested dependence matrices now travel through one public `DMR-1` dependence-matrix-review object

The archive now fixes one compact adversarial rule for probabilistic-trace portfolios: whenever a `CPD-1` matrix is credibly attacked on the ground that it hides shared evidence, false independence, nested reuse, or contaminated inputs, the challenge must travel through one machine-carrying `DMR-1` object.

### A. Minimum `DMR-1` fields

Every dependence-matrix-review object must expose at least:

- `dmr_id`
- `challenged_cpd_id`
- `challenged_ppt_id[]`
- `challenge_basis[]` (`undeclared-shared-evidence`, `misstated-independence`, `hidden-common-prior`, `nested-claim-not-netted`, `mutual-exclusion-overlooked`, `contaminated-input-channel`, `other`)
- `challenger_ref`
- `accepted_for_review`
- `temporary_allocable_floor`
- `frozen_increment_ref`
- `review_panel_ref`
- `shared_evidence_disclosure_ref`
- `revised_relation_matrix_ref`
- `revised_portfolio_floor`
- `holdback_state`
- `decision_state` (`screening`, `accepted`, `temporary-freeze`, `revised`, `affirmed`, `rejected`, `escalated`)
- `reason_ref`

`DMR-1` is the public object that stops the first filer from being the final arbiter of the dependence story. `[REF-0534]` `[REF-0527]` `[REF-0536]`

### B. Credible challenge freezes additive use above the uncontested floor

Once a challenge is accepted for review, no claimant may keep allocating above the last uncontested portfolio-safe floor merely because the original `CPD-1` said so. `DMR-1` must publish a temporary allocable floor and freeze the disputed increment until review concludes. The archive chooses this because current NIST guidance requires explicit treatment of covariance, documented component evaluation, and justified assumptions rather than invisible continuation of a contested simplification. `[REF-0534]` `[REF-0527]`

### C. Unknown dependence is treated conservatively as dependence, not as independence

If the review cannot resolve whether two claims are independent, positively dependent, nested, or contaminated by a common hidden input, `DMR-1` must default to the more conservative portfolio posture and expand the holdback rather than allowing additive counting. A personhood world should not let unresolved shared-evidence risk behave as if it were disproved merely because the evidence is incomplete. `[REF-0534]` `[REF-0527]`

### D. Review must be independent, expert, and procedurally legible

The review body named in `review_panel_ref` must be independent of the claimants whose allocations are being contested, expert in the relevant probabilistic or evidentiary domain, and bound by publicly legible procedures. The archive chooses this because current DSA out-of-court bodies are certified only if they meet independence, expertise, accessibility, efficiency, and clear-procedure requirements, and because those certifications can be renewed or revoked. `[REF-0536]`

### E. The output is a revised matrix plus a revised floor, not merely a winner-and-loser label

At closure, `DMR-1` must publish the revised relation matrix, revised portfolio floor, claim-specific floor changes, and holdback change. The archive chooses this because the question is not merely who complained correctly but what allocable structure can still be defended after the challenge. `[REF-0534]` `[REF-0527]`

## 4. Discovery intermediaries now use one public `IRR-1` intermediary-relisting-review object after cure, disappearance, or non-equivalence

The archive now fixes one compact restoration rule for discovery intermediaries: once a locator was previously de-ranked, disabled, or delisted through `IDD-1`, any return path must travel through one machine-carrying intermediary-relisting-review object called `IRR-1`.

### A. Minimum `IRR-1` fields

Every intermediary-relisting-review object must expose at least:

- `irr_id`
- `prior_idd_id`
- `prior_umn_id`
- `intermediary_identifier`
- `artifact_locator_ref`
- `asserted_restoration_basis` (`artifact-fixed`, `artifact-gone`, `not-same-artifact`, `locator-reassigned`, `other`)
- `evidence_ref[]`
- `hash_or_provenance_ref[]`
- `restoration_state` (`historical-tombstone`, `friction-restored`, `resolver-restored`, `fully-relisted`, `relisting-denied`)
- `statement_of_reasons_ref`
- `review_path_ref`
- `recheck_deadline`
- `public_notes`

`IRR-1` is the public object that makes relisting reviewable and exact-locator-specific instead of silent or permanent by inertia. `[REF-0535]` `[REF-0536]` `[REF-0537]`

### B. No silent relisting is allowed

Any intermediary that restores a previously restrained exact locator must publish a statement of reasons and a review path. The archive chooses this because current Commission guidance still requires statements of reasons for restriction decisions and still makes those statements publicly inspectable through the DSA Transparency Database. A personhood world should therefore treat restoration as a visible governance act, not as a backend toggle. `[REF-0535]`

### C. Cure relisting is staged, not instantaneous

Where the asserted basis is `artifact-fixed`, the intermediary may first move to `friction-restored` or `resolver-restored` with visible labeling and a recheck deadline; only after the stated recheck passes without fresh unresolved notice may the locator move to `fully-relisted`. The archive chooses this because current Commission materials show that moderation decisions are routinely reviewed and sometimes reversed, but those reversals happen through process rather than through unrecorded disappearance of the original concern. `[REF-0537]` `[REF-0536]`

### D. Disappearance supports historical trace, not live restoration

Where the asserted basis is `artifact-gone`, the intermediary should normally move to `historical-tombstone`, preserving the existence of the prior notice and later disappearance without recreating one-click live access. This keeps public memory without pretending the live artifact still exists or silently erasing the prior warning chain. `[REF-0535]` `[REF-0537]`

### E. Non-equivalence permits relisting only of the different artifact actually proved

Where the asserted basis is `not-same-artifact` or `locator-reassigned`, `IRR-1` must link the old notice history to the new evidentiary showing and may restore discoverability only for the now-proved different artifact. The archive chooses this because restoration should follow exact artifact identity, not a vague claim that “something else is there now.” `[REF-0535]` `[REF-0536]`

## 5. Why this is still the narrow move

This revision does not redesign accreditation law, Bayesian adjudication, or internet search law in general. It does three smaller things only.

1. It fixes whether post-exhaustion reserve cohorts have any disciplined path back and what kind of path it is.
2. It fixes how challenges to a declared dependence matrix are actually reviewed and what freezes during that review.
3. It fixes how a previously delisted locator may return, if at all, after cure, disappearance, or non-equivalence.

That is enough to keep the caution stack coherent without turning this archive into a general treatise on permanent disability, statistical litigation, or platform-restoration law.

### `ERH-1` — exhausted-credit-rehabilitation object

Carries the exhaustion event, fresh-only cycle count, reporting-clear condition, capped rehabilitation stage, relapse consequence, and fresh-epoch review path for reserve cohorts whose legacy credit has already been fully exhausted. `[REF-0531]` `[REF-0532]` `[REF-0533]`

### `DMR-1` — dependence-matrix-review object

Carries the challenged `CPD-1`, challenge basis, temporary uncontested floor, review panel, revised matrix, revised portfolio-safe floor, and holdback outcome for adversarial review of hidden overlap, false independence, or shared-evidence contamination. `[REF-0534]` `[REF-0527]` `[REF-0536]`

### `IRR-1` — intermediary-relisting-review object

Carries the prior delisting state, restoration basis, evidence and provenance inputs, restoration state, statement of reasons, review path, and recheck deadline for any attempted relisting or historical restoration of a previously noticed exact locator. `[REF-0535]` `[REF-0536]` `[REF-0537]`

## 7. Consequences for the wider archive

- `research-reserve-*` doctrine now has a visible answer to the question whether a fully burned reserve cohort can ever return: yes, but only as a fresh-start rehabilitation lane with no old-credit revival.
- `research-*-fraud-*` doctrine now has a visible answer to the question what happens when the dependence matrix itself is challenged: allocations freeze above the uncontested floor and a public review object revises or narrows the matrix.
- `research-*-derivative-*` doctrine now has a visible answer to the question how exact-locator restraint can later unwind: only through a public relisting review that distinguishes cure, disappearance, and non-equivalence.

That keeps the research-governance lane conservative in the way the archive has been aiming for throughout: no silent revival of exhausted trust, no self-policing dependence matrices under challenge, and no silent relisting once an exact locator has been disciplined out of ordinary discovery.

## Bottom line

A personhood world should not let fully exhausted reserve credit quietly come back to life, should not let the first publisher of a dependence matrix control the overlap story forever, and should not let previously delisted exact locators quietly return after cure or disappearance. The archive therefore now fixes one more compact rule: **fully exhausted reserve cohorts may return only through a public `ERH-1` object that treats rehabilitation as fresh-start observation, capped conditional return, and eventually fresh-epoch reaccreditation with old legacy credit retired forever; contested `CPD-1` matrices now travel through a public `DMR-1` object that freezes disputed additivity above the uncontested floor until an independent review revises or affirms the matrix; and previously restrained exact locators now return only through a public `IRR-1` object that states whether the basis is cure, disappearance, or non-equivalence and what staged restoration is justified.** `[REF-0531]` `[REF-0532]` `[REF-0533]` `[REF-0534]` `[REF-0527]` `[REF-0535]` `[REF-0536]` `[REF-0537]`
