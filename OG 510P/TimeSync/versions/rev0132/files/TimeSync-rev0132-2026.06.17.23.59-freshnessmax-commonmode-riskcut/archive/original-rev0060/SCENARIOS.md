# SCENARIOS

This is the current shared scenario set.

## S1 — General-purpose networked computing
Ordinary system functions such as auth windows, certificate checks, logs, and routine coordination.

## S2 — Datacenter / distributed-system coordination
Event ordering, transaction handling, and stronger temporal trust in distributed systems.

## S3 — Financial timestamping and traceability
Accurate shared time for transaction timestamps, records, and audit/traceability.

## S4 — Telecommunications / network synchronization
Precision, continuity, holdover, and operational resilience at network scale.

## S5 — Electric power / critical infrastructure timing
Consequence-sensitive timing dependence where failure is a systems issue rather than a mere IT inconvenience.

## S6 — Degraded / disconnected local operation
Loss of trusted external inputs; continued operation under holdover, fallback, or partition-local conditions.
