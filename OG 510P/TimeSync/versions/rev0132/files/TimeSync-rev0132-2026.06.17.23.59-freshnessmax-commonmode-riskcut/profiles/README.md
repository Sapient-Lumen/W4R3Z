# TimeSync rev0132 profiles

The normative catalog remains six profiles, P1 through P6. rev0130 changes no profile rule or digest.

Profiles are consumer-use policies, not claims that a source or clock is globally “good.” A single TimeState may satisfy one profile and fail another. FT-0121 now exercises P1 against chrony and ntpq replay surfaces; future real-host capture must not change profile rules merely to make an example pass.
