## What to do on future revisions

1. Reopen the current constitutional core before adding novelty.
2. Add citations, not bulk artifacts.
3. Prefer `research-cite`, `refine-compress`, and `bridge-build` moves.
4. Update one canonical surface rather than proliferating overlapping docs.
5. Keep speculative material in quarantine unless promotion is earned.
6. Rebuild the archive index and run lint before packaging.
7. Prefer one new admission gate or audit over another survey.
8. When a gate is installed, apply it to one bounded worked example before widening the family prose.
9. If a non-equilibrium extension is proposed, ask which coarse-grained trace and witness channel would actually carry it.
10. If a bridge claim says it reduces witness borrowing, ask which ladder level it actually climbs and what native record structure was newly earned.
11. Emit a revision receipt and package with a predictable bundle name.
12. If a claim seems to explain too much at once, ask whether it earned local-law credit, cosmological-boundary credit, or both.
