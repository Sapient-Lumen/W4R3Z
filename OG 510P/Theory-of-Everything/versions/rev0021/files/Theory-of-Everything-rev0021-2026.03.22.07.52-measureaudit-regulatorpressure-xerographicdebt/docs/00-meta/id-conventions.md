# ID conventions

Use stable ids so future sessions can point instead of paraphrase.

## Families

- `REF-####` — bibliography entry
- `CL-####` — claim
- `OQ-####` — open question
- `INV-####` — invariant / recovery target
- `MV-####` — certified move class
- `WS-####` — workstream
- `BR-####` — bridge experiment
- `AS-####` — assumption
- `FQ-####` — followthrough queue item

## Naming rules

- Prefer short ids plus descriptive titles.
- Do not recycle ids.
- If a concept changes status, update its registry entry rather than creating a duplicate with new prose.
- If a concept is replaced, leave a pointer from the old id to the new canonical home.
