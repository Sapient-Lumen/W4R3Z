# Family-B beyond-equilibrium gain gate

This document is a **third compact application of `W-0001`**.
It asks what the smallest additional package is before a thermodynamic-gravity claim can say more than:

> under a local-equilibrium horizon setup, Einstein-like dynamics can be reconstructed.

Read this together with:

## Compression verdict

Family B should now carry a compact **minimum-gain gate**.
A beyond-equilibrium thermodynamic-gravity claim earns explanatory credit only if it names all five of the following:
- an extra state or constitutive structure not already hidden inside the equilibrium Einstein reconstruction,
- a local-law role for that structure rather than a merely special horizon/ensemble/global setup,
- a bounded observable difference relative to the equilibrium or EFT-baseline reading,
- a witness route through which the difference becomes a persistent coarse-grained trace,
- and a portability statement saying how far the gain survives beyond the setup that made it visible.

The current strongest family-B lane does **not** yet satisfy that full package.
It earns better trace discipline, but not a clean beyond-equilibrium explanatory surplus.

## Why this gate is needed

The archive already has three bounded results:
- `docs/40-model/thermodynamic-gravity-assumption-audit.md` says the Jacobson-style lane is a real clue but not a promoted replacement for the EFT gravity baseline,
- `docs/40-model/non-equilibrium-observable-record-map.md` says non-equilibrium widening only counts when it cashes out as coarse-grained traces with real witness channels,
- `docs/40-model/family-b-witness-climb-audit.md` says the current strongest family-B extension still does not climb beyond `WB-1`.

What was still missing was a smaller question than full promotion:

> what extra burden must family B meet before it can honestly claim any explanatory gain beyond the equilibrium reconstruction clue itself?

Without that gate, a widened thermodynamic derivation can look like progress merely by adding constitutive vocabulary.

## Minimum-gain package

| Requirement | Why it is needed | Failure mode if missing |
|---|---|---|
| **G1. Extra state / constitutive content** | shows that the widening adds more than a relabeled equilibrium derivation | the "new" result is only Einstein reconstruction plus extra prose |
| **G2. Local-law assignment** | separates genuine local dynamical gain from special horizon, asymptotic, ensemble, or boundary setup | a global package gets laundered into local explanation |
| **G3. Observable discriminator** | forces the added structure to change some bounded coarse-grained response, lag, transport relation, or recovery claim | no empirical difference from the EFT/equilibrium baseline is ever stated |
| **G4. Witness route** | ties the claimed gain to persistent records rather than to formal repair notation | the extra term exists only on paper and never becomes re-readable evidence |
| **G5. Portability statement** | prevents a narrow setup win from being retold as generic gravitational explanation | a special derivation is inflated into regime-free success |

## What should count as real beyond-equilibrium gain

A family-B proposal may claim **bounded explanatory surplus** only when all of the following are explicit.

### 1. The extra variables are not already borrowed from the matter-side EFT baseline

If the widening just points to dissipation, constitutive lag, or entropy production while all real content still lives in ordinary matter-side coarse-graining, then the gain is mainly diagnostic.
To count as more than diagnosis, the proposal must say what new thermodynamic-gravity-side structure is doing explanatory work.

### 2. The extra structure is assigned to local dynamics rather than to a favorable global package

A claim does not earn local-law credit simply because it works in a horizon ensemble, special asymptotic setting, or carefully chosen boundary state.
Use `docs/40-model/local-law-vs-cosmological-boundary-split.md` here: the burden is to say what the local law gained, what the global package fixed, and what would survive if the package changed.

### 3. There is a bounded discriminator against the equilibrium clue reading

The archive should ask: what could be different, even in principle, if the beyond-equilibrium structure is real?
Good answers name a response asymmetry, constitutive lag, dissipative trace family, or constrained transport behavior that the equilibrium reading alone does not already organize.

### 4. The discriminator has a witness channel

A response difference that never reaches matter, detector, environment, or memory chains does not yet buy explanatory contact.
This is weaker than a witness-ladder climb, but still stronger than pure formal repair.

### 5. The proposal says how narrow its regime is

A setup-specific success is still worth keeping if it is presented honestly.
It becomes misleading only when a local, horizon-based, or coarse-grained derivation is narrated as if it had already explained gravity generically.

## Current archive verdict on family B

The current strongest family-B lane passes this new gate only **partially**.

- `G1` — **partial at best**: extra constitutive / entropy-production vocabulary is present, but much of the concrete content still looks borrowed from ordinary coarse-grained matter-side bookkeeping.
- `G2` — **not yet cleanly passed**: the archive does not yet have a compact case where the beyond-equilibrium addition is clearly local-law gain rather than setup-dependent repair.
- `G3` — **partially passed**: the non-equilibrium map now demands observable-bearing traces, which is real progress in discipline.
- `G4` — **partially passed**: witness routes must be named, but the carriers remain borrowed and the family stays at `WB-1`.
- `G5` — **not yet cleanly passed**: the current widening is still best read as bounded regime discipline, not portable explanatory closure.

So the present result is:

> family B has earned a better gate and a stricter admissibility standard, but not yet a beyond-equilibrium explanatory win.
