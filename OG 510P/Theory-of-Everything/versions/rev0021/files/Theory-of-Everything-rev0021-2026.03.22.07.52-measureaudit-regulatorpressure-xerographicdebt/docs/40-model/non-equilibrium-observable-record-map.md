# Non-equilibrium terms: observable / record map

This document is a **compact second application of `W-0001`**.
It asks when the non-equilibrium widening of thermodynamic-gravity arguments should count as real empirical content rather than as formal repair vocabulary.

Read this together with:
- `docs/40-model/thermodynamic-gravity-assumption-audit.md`
- `docs/40-model/discriminator-wedges.md`
- `docs/40-model/observer-record-minimum.md`

## Compression verdict

The archive should now hold a bounded but useful result:
- non-equilibrium entropy-production terms do **not** automatically add new witness structure,
- they count as observable-bearing only when tied to named coarse-grained fluxes, relaxation lags, constitutive responses, or hysteresis-like traces,
- and the durable records of those terms still live in ordinary matter, apparatus, environments, and memory chains rather than in the entropy-production term by itself.

So family B gains a cleaner empirical discipline without winning promotion.
The new rule is: **no record carrier, no explanatory credit beyond formal repair.**

## Why this document is needed

`REF-0018` matters because it blocks a cheap move.
Once the simple local-equilibrium package is widened, explicit entropy-production structure appears.
That is already enough to show that the equilibrium derivation is not universally free.
But the archive still needed a second question:

> which parts of that extra structure are empirically meaningful, and which parts are merely bookkeeping inserted to keep the generalized derivation alive?

Without that question, family B can grow by formal vocabulary alone.

## Minimal admissibility test

A non-equilibrium term should count as **observable-bearing** only if all of the following are named.

1. **Carrier quantity**
   - Which coarse-grained variable is changing?
   - Examples: stress/energy flux imbalance, shear-like distortion, relaxation time, constitutive coefficient, or repeatable lag between driving and response.

2. **Operational trace**
   - What downstream difference could persist in a record?
   - Examples: repeated response asymmetry, dissipative heating signature, area-growth mismatch, or protocol-dependent hysteresis in a controlled coarse-grained description.

3. **Witness channel**
   - Through which physical degrees of freedom is the trace re-readable?
   - The answer has to point to matter, detector, environment, memory, or boundary channels already allowed by `docs/40-model/observer-record-minimum.md`.

4. **Domain statement**
   - In what regime is the non-equilibrium term supposed to matter?
   - If the term only rescues a formal derivation outside equilibrium but has no bounded observational domain, it does not yet earn explanatory promotion.

## What the archive should count as real gain

The non-equilibrium widening earns something real only in the following limited sense.

### 1. It can expose which equilibrium assumptions were doing hidden work

A named entropy-production or constitutive term can show exactly where the clean Jacobson-style package breaks.
That is scientifically useful because it reveals the extra dynamical burden rather than hiding it.

### 2. It can point to coarse-grained irreversible traces

If the widened story predicts a persistent mismatch between reversible bookkeeping and actual coarse-grained response, then the extra term is more than syntax.
It becomes a candidate trace-bearing quantity.

### 3. It can discipline thermodynamic language by forcing constitutive honesty

A family-B claim is better if it says which relaxation variables or response functions are required, rather than retelling every deviation from equilibrium as “more entropy.”
That is not a full microphysical explanation, but it is a real compression improvement.

## What it does **not** buy

The archive should block four overclaims.

1. **No new primitive record carriers**
   - An entropy-production term is not itself a stable record.
   - The durable record still lives in ordinary physical substrates that can store, preserve, and re-present the coarse-grained fact.

2. **No automatic microstructure win**
   - Non-equilibrium correction terms do not, by themselves, reveal the microscopic ontology of gravity.

3. **No promotion by widened vocabulary**
   - Adding constitutive coefficients or internal-production symbols does not count as explanatory gain unless a witness channel is stated.

4. **No bypass around `CL-0014`**
   - Observable-bearing content and record carriers remain mandatory even when the derivation becomes more sophisticated.

## Compact map

| Non-equilibrium ingredient | What it can honestly mean | Where the record still lives | When to demote it |
|---|---|---|---|
| Entropy-production term | coarse-grained irreversible correction to the equilibrium package | matter/environment/apparatus channels that preserve a downstream trace | if it appears only as a symbol that closes the derivation |
| Relaxation or constitutive coefficient | response timescale or transport-like parameter in an effective description | repeated measurements, protocol comparisons, detector histories, boundary readout chains | if no operational route for inferring the coefficient is named |
| Shear/expansion-style correction | deformation or flux mismatch relative to reversible idealization | coarse-grained geometric/matter records, not the formal term itself | if it is presented as direct evidence of microstructure without a witness chain |
| Hysteresis / path dependence | history-sensitive response that leaves a re-readable difference | multi-step experimental or simulated record sequence | if the path dependence is only asserted verbally |

## Archive-state consequence

`W-0001` now has a tighter second-pass answer.
The archive should hold:
- family B keeps its status as a live bridge family,
- the equilibrium derivation remains the cleanest result,
- non-equilibrium widening counts as progress only when it names trace-bearing coarse-grained consequences,
- and family B still borrows its durable record/objectivity story from ordinary witness substrates rather than deriving new candidate-native record carriers.

This means `FQ-0004` can now close in bounded form.
The archive no longer needs to ask whether non-equilibrium terms have *any* observable content.
It now needs to ask whether any such term can do more than parameterize borrowed matter-side traces.

## Net result

The thermodynamic lane is now better disciplined.
Non-equilibrium structure is allowed, but only under a **trace-and-witness rule**:
if the extra term cannot be tied to a coarse-grained persistent trace with a real re-reading channel, it stays formal and does not count as added explanatory contact.
