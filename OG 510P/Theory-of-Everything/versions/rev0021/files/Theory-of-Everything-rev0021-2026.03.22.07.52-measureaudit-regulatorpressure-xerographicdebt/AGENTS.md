# AGENTS

This archive is written for future human–LLM continuation.

## Operating posture

- Be compact.
- Be explicit about epistemic status.
- Prefer invariants and bridge claims over encyclopedic narration.
- Cite external work; do not retain bulky source artifacts in release bundles.
- Do not quietly widen scope from “salient ToE program” into “all of physics.”

## Preferred move classes

1. `read-reopen`
2. `research-cite`
3. `refine-compress`
4. `bridge-build`
5. `quarantine`
6. `promote`
7. `package-handoff`

## Anti-patterns

- literature accumulation without changed structure,
- speculative elegance without recovery of known limits,
- multiple near-duplicate docs for one concept,
- quoting where a one-line citation would do,
- treating framework names as explanations,
- confusing metaphors with invariants.
