# Local-to-global gluing and obstruction control

## Local records are not global records

A local theorem, reconstruction, likelihood, simulator success, laboratory discriminator, survey update, or RG match can remain correct while failing to assemble into a global candidate. The failure may occur at an interface, overlap, gauge quotient, boundary condition, scale match, semantic binding, or public-record carrier.

## Required checks

A global claim must name:

```text
source local rows
composition law
interface / overlap object
preserved invariants
obstruction or cocycle test
global integrability target
unmatched residual
rollback rule
maximum authority effect
```

## Archive posture

The default is local credit. Global credit is allowed only when the declared gluing data survive the obstruction and interface tests. A route that fails these tests does not necessarily become false; it becomes local again.
