# Perturbative-completion stop rule

`OQ-0105` blocks a common support-laundering move: treating a useful series, finite loop result, counterterm calculation, RG-improved expression, Padé/Borel result, or transseries-like reconstruction as if it were UV completion or candidate-native identity.

A route may use perturbative language only after it declares the expansion denominator. It may use loop-order language only after it declares the order, counterterm/subtraction object, and omitted terms. It may use resummation or convergence language only after it declares large-order behavior, ambiguity cancellation, nonperturbative sectors, and residual failure modes.
