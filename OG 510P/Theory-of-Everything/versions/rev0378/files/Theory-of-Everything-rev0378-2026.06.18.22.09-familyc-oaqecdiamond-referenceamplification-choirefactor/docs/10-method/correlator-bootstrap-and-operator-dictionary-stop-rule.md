# Correlator/bootstrap and operator-dictionary stop rule

`OQ-0094` blocks correlator, n-point, generating-functional, operator-dictionary, OPE, conformal-block, crossing, bootstrap-island, CFT-data, and bulk-boundary-correlator wording unless all three executable ledgers are current.

A public or formal correlator must still pass through measurement, gauge/observable quotient, state-preparation, asymptotic/IR, discretization/continuum, public-record, and observed-sector controls before it can transmit more than bounded route-local support.
