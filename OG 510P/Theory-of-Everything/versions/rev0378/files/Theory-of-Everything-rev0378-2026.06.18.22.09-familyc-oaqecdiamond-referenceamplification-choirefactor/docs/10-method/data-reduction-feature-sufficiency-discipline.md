# Data reduction, feature extraction, and summary-statistic sufficiency discipline

Data reduction is a route denominator, not an authority multiplier. A compressed record, feature vector, embedding, score summary, MOPED statistic, information-bottleneck code, or likelihood-free summary can make inference tractable, but it must declare what information it preserves and what it is allowed to lose.

The active rule is noncompensatory: data reduction can preserve a target statistic without proving feature sufficiency; a feature can be stable without preserving candidate-distinguishing residuals; and a summary statistic can be sufficient for one local parameterization while failing for model comparison, multimodal likelihoods, tails, nuisance structure, or candidate identity.
