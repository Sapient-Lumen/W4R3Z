# Circuit, holographic complexity, and computational-hardness discipline

Complexity language is route-local. A route that invokes circuit complexity must declare the target state or unitary, the reference state, allowed gate set, cost metric, tolerance, representation, and public replay object.

Holographic complexity language is also route-local. Complexity=volume, complexity=action, WDW-patch, bridge-growth, black-hole-interior, or cosmological-complexity claims must name the boundary state, bulk region, regulator, counterterm prescription, normalization, and comparison class.

Computational-hardness language requires a stated problem, input encoding, verifier, asymptotic regime, average/worst-case convention, and public benchmark. Hardness can explain limits on reconstruction or observer access; it cannot promote a route to candidate identity.
