# Correlation-function / operator-insertion / bootstrap-data discipline

rev0296 adds a route-local correlator/operator/bootstrap stop rule. A route may use correlation functions, operator insertions, OPE coefficients, conformal blocks, crossing equations, numerical-bootstrap regions, or bulk-boundary correlator dictionaries only after it declares the row-local denominator that carries the claim.

The noncompensation rule is strict: a matched correlator does not define an operator dictionary, an operator dictionary does not provide complete CFT/bootstrap data, and bootstrap/CFT data does not identify a candidate ontology or public record. Each row can cap, freeze, demote, or roll back wording; none can promote a route beyond its state-machine ceiling.
