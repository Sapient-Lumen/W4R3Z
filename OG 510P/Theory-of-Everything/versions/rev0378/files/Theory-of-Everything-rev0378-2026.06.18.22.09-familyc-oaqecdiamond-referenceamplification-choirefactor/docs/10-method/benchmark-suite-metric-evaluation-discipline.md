# Benchmark suite / metric / evaluation discipline

Benchmark evidence is route-local. A benchmark suite names the task and record boundary; a metric names the proxy being optimized; an evaluation protocol names the submission, holdout, blinding, refresh, and adjudication rules.

A benchmark pass can constrain a route only after the archive declares contamination checks, leakage controls, public/private split, adaptive-query budget, metric uncertainty, noise floor, and transfer target. Benchmark success does not compensate for public-record custody, measurement, selection, simulator, compression, observed-sector, or residual debts.
