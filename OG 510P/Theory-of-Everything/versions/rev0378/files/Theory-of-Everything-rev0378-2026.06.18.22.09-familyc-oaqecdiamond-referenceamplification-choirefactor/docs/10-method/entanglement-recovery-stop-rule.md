# Entanglement / modular / recovery stop rule

Introduced in `rev0303` and governed by `OQ-0101`.

No route may use the following language unless entanglement-structure, modular-flow, and relative-entropy/recovery rows are declared and current:

```text
entanglement wedge
RT / HRT / QES
geometry from entanglement
modular Hamiltonian
modular flow
JLMS
relative entropy equality
Petz / recovery map
bulk reconstruction by entanglement
holographic completeness
```

A route must identify what is being entangled, which algebra or subsystem is used, which modular flow is claimed, which recovery map or equality is being invoked, which approximation or code-subspace restriction applies, and which public-record carrier can replay the claim.
