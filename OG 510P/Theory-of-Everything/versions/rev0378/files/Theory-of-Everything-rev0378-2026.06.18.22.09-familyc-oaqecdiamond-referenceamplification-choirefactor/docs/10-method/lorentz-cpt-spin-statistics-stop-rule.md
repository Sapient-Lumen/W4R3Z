# Lorentz / CPT / spin-statistics stop rule

`OQ-0099` blocks a route from treating Lorentz covariance, a Lorentz/CPT test corridor, spin-statistics consistency, or CPT/discrete-symmetry compatibility as candidate identity.

Required before stronger wording:

1. a declared Lorentz or local-frame covariance object;
2. a declared spin/statistics object and theorem-assumption scope;
3. a declared CPT/discrete-symmetry object and sector/domain;
4. public-record carrier and route-state ceiling;
5. rollback rule if the covariance, statistics, or CPT row fails.

Satisfying one of these rows does not compensate for missing matter-sector, Hilbert-space, detector, public-record, classical-GR, cosmology, or observed-sector recovery.
