# Candidate-native docket common block

## Purpose

This is the shared front-matter owner for the candidate-native identifiability docket family under `OQ-0057`.
It exists to reduce repeated boilerplate without weakening any docket's state machine, mandatory row, rollback rule, or non-promotion boundary.

The common rule is: **a docket may route, freeze, narrow, audit, or repair candidate-native identifiability claims, but it cannot by itself promote a route, certify closure, upgrade evidence credit, or turn release packaging into scientific support.**

## Shared release / reimport warning

If a candidate-native docket returns through an older release, fork, cherry-picked document, generated index, user-facing answer, abstract, handoff note, or external paraphrase, do not merge its route state directly.
First check release identity, owner-chain replay, residual caps, export wording, reimport firewall state, lineage merge state, release seal, seal verification, and current-authority transition / rollback rows.

A release package can carry a bounded posture. It does not own the scientific authority of that posture after the owner rows have moved.

## Shared compression rule

Future docket compression should remove repeated read-together and warning blocks before touching state tables.
A safe compression is one where:

1. the docket still names this common block;
2. the docket keeps its unique state codes and mandatory row;
3. generated restart/index surfaces still expose the docket as discoverable;
4. lint or a generated audit can prove no required owner disappeared.

## Non-promotion boundary

This common block is an archive-ergonomics refactor only.
It does not change `OQ-0057`, route scores, field cells, evidence units, public-record credit, forecast realization, decision outcomes, or current-head scientific authority.
