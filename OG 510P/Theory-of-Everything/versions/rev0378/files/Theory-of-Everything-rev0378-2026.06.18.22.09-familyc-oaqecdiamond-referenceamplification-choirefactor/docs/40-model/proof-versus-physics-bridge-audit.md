# Proof versus physics bridge audit

Formal mathematics can strengthen internal consistency, derive consequences, expose hidden assumptions, and make route statements less ambiguous. It does not by itself supply measurement, public-record custody, observed-sector recovery, semantic identity, or candidate-native closure.

## Audit questions

- What is proved?
- In which formal system or notation?
- Under which assumptions?
- Which assumptions are discharged?
- What physical bridge remains outside the theorem?
- What public record, if any, can challenge it?
- What route state can the proof actually support?
