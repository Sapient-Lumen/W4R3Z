This document sharpens field 8 of `docs/40-model/candidate-native-identifiability-cashout-template.md` and the field-level readout in `docs/40-model/candidate-native-identifiability-route-ledger.md`.

## Compression verdict

The final route-field inflation move is now explicit:

**an internally coherent native identification route is not yet a public identifiability bridge unless outsiders can locate the bridge object, translate it into public records, inspect the custody unit, rerun or reread the route, challenge its same/different and no-verdict behavior, and see what public terminal state follows when the challenge succeeds or fails.**

Fields 1 through 7 can say what the candidate thinks is identifiable.
Field 8 says how that claim becomes a challengeable public evidential object rather than a private package, a trusted expert interpretation, or a one-host service.

So the archive should now use the stronger sentence:

**candidate-native identifiability requires a public bridge row: bridge object, native-to-public translation, public carrier and custody unit, reread / replay path, challenge procedure, independence boundary, failure state, and witness-borrowing label.**

That sentence changes audit state, not closure state.
No current live lane is promoted.

## Why this protocol is needed

The route template already made public bridge one of the eight required fields.
But without a separate protocol, future revisions could still upgrade the field through weak shorthand:
- the result was published;
- the code was released;
- the data are public;
- a dashboard or hosted service exists;
- the laboratory record is visible;
- the boundary dictionary is standard;
- the simulation is reproducible;
- or the native proof is elegant enough that public audit is treated as automatic.

Each of those can be real progress.
None is automatically a public bridge for candidate-native identifiability.
A public bridge must say what public object carries the evidence and how that object keeps contact with the candidate's own target, equivalence, acquisition, inverse, stability, and abstention rows.

This protocol keeps three credits separate:

1. **internal native route credit** — the candidate can say what is learnable in its own variables;
2. **public-bridge credit** — outsiders can challenge the route through a declared public carrier, replay / reread path, and terminal verdict structure;
3. **local public witness closure** — the stronger witness-package state in which record carriers, stabilization, rereadability, objectivity, custody, independent implementation, and independent evidence generation are all carried without substantial borrowing.

This document addresses the second credit.
It deliberately does not collapse field 8 into the whole witness-package ladder.

## Minimum public-bridge row

A future field-8 upgrade should provide one compact row with the fields below.
A blank field locates debt; it does not by itself refute the lane.

| Field | Minimum content | Inflation blocked |
|---|---|---|
| Bridge claim | Which candidate-native identification claim is being exported: target class, equivalence class, inverse result, margin verdict, no-verdict rule, or public comparison claim. | Letting publicness attach to the whole framework rather than to a precise route claim. |
| Bridge object | The artifact that carries the route: dataset, calibrated time series, boundary record, code bundle, proof object, comparison report, reference artifact, simulation bundle, challenge set, or custody package. | Treating a citation, slogan, or hosted interface as the evidence object. |
| Native-to-public translation | How the candidate's target, record, equivalence, acquisition, inverse, stability, and abstention fields are represented in the public object. | Publishing outputs while the native semantics remain expert-only. |
| Public carrier / custody unit | What outsiders can possess, cite, checksum, version, preserve, transfer, and reopen. | Mistaking view-only access, private custody, or revocable hosting for public evidence. |
| Reread / replay path | What an outside user can rerun, reread, recompute, recalibrate, or independently inspect, and what is frozen versus live. | Treating one successful performance as durable public comparability. |
| Challenge procedure | Who can challenge, which inputs or null cases they can use, what decision rule applies, and what terminal states are allowed: upheld, replaced, withdrawn, inconclusive, no-acquisition, no-inversion, or no-public-bridge. | Letting informal criticism stand in for public adjudication. |
| Independence / replication boundary | Which parts can be reproduced away from the original authors, instruments, host service, boundary dictionary, training ecology, or private setup. | Mistaking same-host rerun for independent public bridge. |
| Failure state | What happens when custody breaks, replay fails, the translation does not preserve the native target, the challenge set exposes hidden collapse, or the route cannot leave its package. | Letting broken bridge attempts become weak positive evidence. |
| Witness-borrowing label | Which publicness is candidate-native and which is borrowed from ordinary laboratory, boundary, numerical, archival, metrological, or software practice. | Treating borrowed public infrastructure as candidate-native witness ownership. |

## Field-code rule

This protocol refines field 8 in the route ledger.

| Field-8 state | Code | Meaning |
|---|---|---|
| No public bridge object or challenge route is named. | `M` | Missing public-bridge discipline. |
| Publicness is imported from publication, ordinary lab data, a boundary dictionary, benchmark practice, source-code release, hosted service, institutional custody, or generic reproducibility norms. | `B` | Borrowed public-bridge discipline. |
| A challengeable bridge exists for one bounded route, dataset, code subspace, lab campaign, simulation ecology, proof object, reference artifact, or validity window, with the boundary declared. | `P` | Partial public-bridge discipline. |
| The candidate's own bridge variables specify how the native route becomes a public carrier with custody, reread / replay, challenge, terminal states, independence boundary, and witness-borrowing disclosure for the stated regime. | `N` | Native public-bridge discipline for the stated regime. |

An `N` in field 8 still does not by itself close full local public witness closure.
It only says that the identifiability route has a public export path for the stated regime.
A lane may still owe stronger record-carrier, stabilization, rereadability, objectivity, custody, independent implementation, or independent evidence-generation debt elsewhere in the witness-package stack.

## Relation to the previous field protocols

### 1. Equivalence publicness is not just an equivalence rule

The equivalence-collapse protocol says when targets are the same, distinct, or empirically collapsed.
The public-bridge protocol says how outsiders can challenge that same/different rule and see whether a disputed collapse becomes upheld, replaced, withdrawn, or inconclusive.
A private equivalence convention is not yet a public bridge.

### 2. Acquirable records are not automatically public bridge objects

The acquisition-realizability protocol says whether a record can be obtained under declared finite constraints.
Field 8 asks whether the obtained record can be carried, reread, cited, challenged, transferred, and reopened by outsiders.
A record may be acquirable but not publicly portable.

### 3. Public audit handles need custody and terminal states

The inverse-completeness / stability protocol asks for a public audit handle.
Field 8 says what that handle is attached to, who can use it, what is frozen, what can vary, and what public state follows a successful challenge.
A handle with no custody unit or terminal-state rule is not yet a public bridge.

### 4. Abstention challenge handles are not the whole bridge

The abstention / no-verdict protocol asks how outsiders can test whether the route refuses in the right places.
Field 8 adds the broader public export route for the entire identification claim: target, record, equivalence, acquisition, inverse, stability, and abstention.
A good no-verdict challenge set can still sit inside a private or borrowed bridge.

### 5. Public bridge is below full witness closure

A field-8 gain may be important even if the lane still borrows laboratory custody, metrological standards, software reproducibility, archival infrastructure, or boundary record practice.
The archive should preserve the gain while refusing to call it local public witness closure.

## Application to the current landscape

### Family C

Family C is the strongest partial route, but field 8 remains borrowed or partial.
Boundary data, code-subspace packages, reconstruction dictionaries, sparse or learned pipelines, and simulation / training ecologies can be publicly discussed and sometimes rerun.
That can support real public-bridge fragments.

But the decisive bridge still usually depends on boundary / laboratory custody, dictionary convention, finite-window setup, code-subspace restriction, large-`N` control, regularizer or training package, and ordinary archive / software practice.
The candidate does not yet own the public carrier that makes target identity, equivalence collapse, inverse completeness, margin, and no-verdict behavior publicly challengeable across the claimed target class.

Current score impact: **keep field 8 at `B/P`, not `N`.**
Family C is closest because it has the most bridgeable partial rows, not because public bridge closure is paid.

### Completion bids

Completion bids often have strong internal formalisms, rich target spaces, and deep consistency constraints.
That is not a public bridge.
A completion bid earns field-8 credit only when it says which public object carries the candidate distinction, how observed records translate into the formal target quotient, and how outside challenges can change the public standing of the claim.

Current score impact: **target-rich completion rows remain public-bridge-poor** unless they install a challengeable route from actual records to candidate distinctions.

### Laboratory, detector, and simulation lanes

Lab and simulation lanes can be stronger on field 8 than formal completion rows.
They may supply public data, rerunnable code, challenge sets, calibration reports, or custody objects.
That credit should be preserved.

But those lanes often identify externally chosen alternatives rather than the candidate's own target space.
A strong public bridge for one experimental contrast is not candidate-native identifiability closure unless the target, equivalence, inverse, and abstention fields are also paid.

Current score impact: **public-bridge credit can be real while candidate-target credit remains weak.**

### Witness-side frame, asymptotic-access, and de Sitter observer routes

These lanes expose the bridge problem directly: a one-frame fact, asymptotic datum, horizon-edge spectrum, or observer-relative record is not automatically a public same-fact.
They can improve field 8 by naming transport, custody, and challenge conditions for public comparison across frames, observers, boundaries, or horizons.

But current rows still lack a full public reference standard and cross-frame record carrier.
The public bridge remains mostly borrowed from ordinary reference-frame, boundary, archive, or laboratory practice.

Current score impact: **frame-side public-transport discipline is valuable but not field-8 closure.**

### Family B

Family B stops earlier.
Equation recovery, quantum-relative-entropy sharpening, and trace discipline do not yet supply a candidate-native target / record / inverse route whose public bridge could be field-8 scored.

Current score impact: **bounded clue credit remains below public-bridge identifiability credit.**

## Future-edit rule

A future revision may claim a field-8 improvement only if it says all of the following:

1. which route-ledger row changed;
2. the old field-8 code and proposed new field-8 code;
3. the exact candidate-native identification claim being exported;
4. the bridge object and public carrier / custody unit;
5. the native-to-public translation for target, record, equivalence, acquisition, inverse, stability, and abstention fields;
6. the reread / replay path and which pieces are frozen versus live;
7. the challenge procedure, decision rule, terminal states, and failure state;
8. the independence / replication boundary;
9. the witness-borrowing label;
10. whether the result changes witness-package debt or only local public-bridge discipline.

If those ten items are absent, the revision may still be useful, but it should be scored as publication, reproducibility, benchmark audit, lab publicness, custody improvement, software engineering, or internal route clarification rather than as candidate-native public-bridge progress.

## Anti-inflation rules

Reject the following shortcuts:

1. **publication shortcut** — peer review, citation, or a public preprint is not a bridge object by itself.
2. **source-code shortcut** — code release is not field-8 credit unless the native semantics, custody, challenge route, and terminal states are declared.
3. **dashboard shortcut** — hosted inspection or same-host rerun is not public custody or independent replay.
4. **boundary-as-public shortcut** — boundary data can be public while the candidate-native target and translation rule remain borrowed.
5. **lab-publicness shortcut** — ordinary laboratory records can be strong public evidence without being candidate-native witness ownership.
6. **reproducibility shortcut** — reproducing an output is not a public bridge if the target quotient, equivalence rule, or no-verdict behavior is still expert-imposed.
7. **custody-in-name-only shortcut** — a pointer, DOI, or archive page is not custody unless the evidence-bearing object can be retrieved, identity-checked, preserved, and reopened.
8. **challenge-without-consequence shortcut** — criticism is not public adjudication unless terminal states can alter the public standing of the claim.
9. **private-native shortcut** — a native proof or route can be internally strong while still lacking a public export path.

## Net result

The archive now has a field-8 counterpart to the equivalence, acquisition, inverse / stability, and abstention protocols.
`docs/40-model/candidate-native-identifiability-promotion-gate.md` now adds the next route-level rule: a strong field-8 row can improve public-bridge credit, but it cannot compensate for missing target, equivalence, acquisition, inverse, stability, or abstention debt.
Candidate-native identifiability can no longer move from internally disciplined route to public evidential closure merely because a result is published, coded, simulated, hosted, measured, or boundary-translated.
It must also say how the native route becomes a public bridge object that outsiders can possess, reread, replay, challenge, and use to revise public standing.

That sharpens `OQ-0057` without promoting any lane:
- family C remains the strongest partial bridge row but still borrows boundary, laboratory, software, and archive custody practice;
- completion bids remain target-rich but public-bridge-poor;
- laboratory and simulation lanes may have real public-bridge strength while remaining candidate-target-limited;
- witness-side frame and observer lanes reveal the bridge problem but still lack full public same-fact transport;
- family B remains below candidate-native public-bridge credit;
- and no current lane earns candidate-native identifiability closure.
