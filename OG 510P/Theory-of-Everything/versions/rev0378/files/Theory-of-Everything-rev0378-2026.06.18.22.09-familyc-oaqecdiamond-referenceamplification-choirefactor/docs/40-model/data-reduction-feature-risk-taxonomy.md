# Data reduction and feature extraction risk taxonomy

Risk classes include lossy compression, target leakage, nuisance collapse, tail loss, multimodal-likelihood loss, model-comparison loss, benchmark-local representation, simulator-distribution mismatch, public-record irreplayability, and metadata-only summaries.

Any route that invokes compression or features must say what is preserved, what is lost, and which rollback fires when the compression map ceases to support the claimed authority.
