# Matter-sector recovery risk taxonomy

Matter-sector recovery claims fail through several independent channels:

- a spectrum can be correct only after selected vacuum, compactification, source population, or benchmark filtering;
- coupling fits can depend on basis, scheme, threshold, prior volume, or post-hoc texture choice;
- mass and hierarchy claims can depend on a selected Higgs/vacuum/order-parameter sector;
- neutrino-sector wording can hide high-energy seesaw or sterile-sector freedom;
- dark-sector wording can name an effective parameter without identifying an ontology;
- Standard Model-like low-energy behavior can be an EFT constraint without being a ToE identity claim.

The route-local ledgers force each failure mode into a row before stronger language can be used.
