## Shared rule

Earlier comparison-stage payment is real progress, not later-stage credit.
Benchmark success is not portable fixation.
Prediction is not rival discrimination.
Allocation is not retirement.
Exclusion is not salvage.
Import is not assimilation.
Convergence is not closure.

## Routing

Use `docs/40-model/completion-bid-credit-stack.md` when a stable or program surface only needs the broad completion-bid control route.
Use `docs/40-model/completion-bid-cashout-sieve.md` for the five-axis payment check that decides whether a lane is even ready for the ladder.
Use `docs/40-model/completion-bid-comparison-stack.md` for ordered stage routing.
Use the directly touched gate for the pair-specific inflation move, test, and current readout.
Stable, restart, and program surfaces should name those routers instead of replaying gate-family boilerplate or relisting broad stage order.

## Authoring

If shared completion-gate scaffolding changes, edit this file, `docs/40-model/completion-bid-credit-stack.md`, the cash-out sieve, or the stack router rather than cloning new preambles across the whole gate family.
