Purpose: canonical broad router for cross-family bridge pressure and comparison. Use this when stable, restart, or program surfaces need the archive's bridge-family snapshot, cross-family pressure map, and archive-state-changing wedge surface without separately naming `candidate-bridges.md`, `invariant-matrix.md`, and `discriminator-wedges.md`.

## Shared rule

Cross-family pressure should be scored in order:
- first by reopening the compact bridge-family snapshot rather than narrating one favored lane in isolation,
- then by checking the archive's cross-family invariant matrix rather than one family's self-description,
- and only then by asking which wedges could actually change archive state through promotion, demotion, merge, or sharpened burden.

A family snapshot is not yet a cross-family pressure verdict.
A matrix cell is not yet a state-changing wedge.
A live wedge is not yet a promoted bridge winner.

Stable, restart, and program surfaces should therefore name this router when they only need the archive's broad cross-family bridge-comparison architecture.
Do not replay `candidate-bridges.md`, `invariant-matrix.md`, and `discriminator-wedges.md` as separate broad-surface obligations unless the revision is actually changing one of those subordinate surfaces.
If the issue is default archive-head routing rather than cross-family pressure specifically, route through `docs/40-model/current-head-control-router.md` instead.
