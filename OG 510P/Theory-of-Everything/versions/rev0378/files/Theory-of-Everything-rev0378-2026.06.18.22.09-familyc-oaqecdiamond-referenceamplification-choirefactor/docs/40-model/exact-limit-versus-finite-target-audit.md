# Exact limit versus finite target audit

This audit surface keeps the physics spine honest about a recurring failure mode: a result becomes cleaner as a limit is taken, while the public record remains finite, noisy, discretized, calibrated, and convention-bound.

Route rows should therefore report:

```text
source ideal model → approximation error → limit sequence → finite recovery → allowed authority language
```

If the finite-recovery step is missing, the route remains at its declared ideal-model ceiling even if the limiting result is exact.
