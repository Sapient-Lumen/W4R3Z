# Observed-sector recovery crosswalk

## Purpose

This surface connects candidate route rows to the observed-sector obligations in `OBSERVED-SECTOR-RECOVERY-LEDGER.json`.

## Crosswalk principle

A route can be strong in one observed sector and weak elsewhere. The archive should preserve that asymmetry instead of converting it into a scalar rank.

| Obligation | Typical strong route | Typical unresolved debt |
|---|---|---|
| `OSR-CLASSICAL-GR` | strong-field GW and classical-limit corridors | quantum/candidate attribution |
| `OSR-QM-QFT` | EFT, amplitudes, lab quantum records | native record and gauge-local publicness |
| `OSR-STANDARD-MODEL-MATTER` | string/M atlas and matter-coupling programs | observed-sector inverse / parameter fixation |
| `OSR-COSMOLOGY-VACUUM` | vacuum-energy and cosmology proposals | measure / boundary / selection dependence |
| `OSR-BLACK-HOLE-THERMO` | Family C and holographic reconstruction | public bridge / cross-package quotient |
| `OSR-LOW-ENERGY-QG-DISCRIMINATORS` | GIE/BMV and graviton-counting routes | candidate target quotient |
| `OSR-PUBLIC-RECORD-CUSTODY` | public lab/catalog/code artifacts | candidate-native same-record and replay standard |

## Consequence

Observed-sector success is necessary for high-state ToE claims but insufficient for candidate identity. The ledger prevents both failure modes: ignoring recovery debt and over-crediting recovery as uniqueness.
