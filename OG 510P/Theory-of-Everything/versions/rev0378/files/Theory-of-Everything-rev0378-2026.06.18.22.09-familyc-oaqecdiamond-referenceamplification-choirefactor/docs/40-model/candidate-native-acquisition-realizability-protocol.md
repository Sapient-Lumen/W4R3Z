## Compression verdict

The next inflation move to block is now explicit:

**a candidate-native forward map is not an acquisition route unless the lane also names the record object, preparation or access channel, public acquisition path, finite-resource budget, nuisance and drift controls, and the no-acquisition outcome.**

Equivalence discipline prevents one target from being double-counted as many.
Acquisition discipline prevents one formal record from being counted as public evidence before there is a credible path by which that record could actually exist, be obtained, and be compared.

So the archive should now use the stronger sentence:

**candidate-native identifiability requires not only a native same/different rule, but a realizable native-to-public record route that survives finite access, finite exposure, finite precision, setup dependence, nuisance shadowing, and no-record outcomes.**

That sentence changes audit state, not closure state.
No current live lane is promoted.

## Why this protocol is needed

The route ledger already showed that field 4 is a common source of over-credit.
A lane may have:
- a formal observable or boundary quantity;
- a native equation-to-record map in an idealized regime;
- a simulation that generates candidate-labeled outputs;
- a detector concept that would separate two alternatives if built;
- or a cosmological / astrophysical trace that could in principle carry information.

Each of those can be real progress.
None of them is yet enough for candidate-native identifiability.
The archive must still ask whether the record can be acquired under declared regimes and whether the acquisition path belongs to the candidate, to an external laboratory / boundary ecology, or only to a modeler's benchmark.

This protocol keeps three credits separate:

1. **formal forward credit** — the candidate can say what record-like object would vary with the target;
2. **acquisition-realizability credit** — the lane can say how an actual public record could be prepared, accessed, measured, simulated, extracted, or compared under finite constraints;
3. **attribution-grade credit** — the acquired record can be stably routed back to the lane rather than to nuisance packages, nearby forward models, or analysis-pipeline choices.

This document addresses the second credit.
Attribution-grade theory support remains controlled by `docs/40-model/acquisition-vs-attribution-gate.md`.

## Minimum acquisition-realizability row

A future field-4 upgrade should provide one compact row with the fields below.
A blank field locates debt; it does not by itself refute the lane.

| Field | Minimum content | Inflation blocked |
|---|---|---|
| Candidate target | Which native target, equivalence class, parameter, geometry, history, sector, or state is supposed to affect the record. | Letting a generic observable float free of a target. |
| Record object | The record-bearing object in candidate language: boundary data, detector click, correlator, edge mode, simulation output, state structure, trace, spectrum, count, map, or public archive item. | Treating a formal symbol as a stabilized record. |
| Access channel | How the record is reached: boundary reconstruction, laboratory preparation, cosmological observation, scattering, simulation, archival comparison, or controlled proxy. | Treating formal observability as practical access. |
| Regime and preparation assumptions | Background, code subspace, finite-`N`, EFT window, source state, detector state, environment, exposure, calibration, or simulation setup needed before the record exists. | Hiding the setup inside the success story. |
| Public acquisition path | What a competent outside community could actually obtain, store, reread, or compare, and which parts remain borrowed from ordinary laboratory, boundary, numerical, or archival practice. | Counting private, package-bound, or benchmark-only access as public evidence. |
| Finite-resource budget | Resolution, noise, exposure, counts, dynamic range, computational cost, cutoff, sample complexity, or precision needed to separate the claimed record class. | Treating infinite idealization as acquired evidence. |
| Nuisance and drift controls | Backgrounds, systematics, emulator error, theory discrepancy, calibration drift, training ecology, instrument drift, cosmic variance, or selection effects that can mimic or erase the record. | Treating one clean forward model as a robust acquisition route. |
| No-acquisition outcome | What the route returns if the record cannot be prepared, is below threshold, is unstable, is nuisance-dominated, or is only available through an external proxy. | Forcing acquisition credit where the honest state is no-record or proxy-only. |

## Acquisition field code rule

This protocol refines field 4 in the route ledger.

| Acquisition field state | Code | Meaning |
|---|---|---|
| No record route is named. | `M` | Missing acquisition discipline. |
| A record route exists only through ordinary lab practice, a boundary dictionary, simulation labels, benchmark data, modeler's truth, or generic phenomenological extraction. | `B` | Borrowed acquisition discipline. |
| A route is stated for a bounded regime, proxy, dataset, code subspace, detector concept, special background, or finite campaign, and its boundary is named. | `P` | Partial acquisition discipline. |
| The candidate's own bridge variables specify the record object, access channel, public acquisition path, finite-resource budget, nuisance controls, and no-acquisition outcome for the claimed target class. | `N` | Native acquisition discipline for the stated regime. |

An `N` in field 4 does not close candidate-native identifiability.
The route still owes target, record, equivalence, inverse-completeness, stability / margin, abstention, and public-bridge fields.
The inverse-completeness / stability protocol handles the next inflation move: an acquired record is not yet an identified target unless the route says what is recoverable, what is rank-deficient or collapsed, and what margins separate nearby targets. The abstention / no-verdict protocol then handles what the route must return when the record is unavailable, proxy-only, nuisance-dominated, rank-deficient, low-margin, or out of regime.
It also does not erase attribution debt.
An acquirable record may still be weak evidence for a lane if nearby forward models or nuisance packages can absorb it.
It also does not erase public-bridge debt. An acquired record may still lack custody, replay, challenge, terminal states, independence boundary, or native-to-public translation under `docs/40-model/candidate-native-public-bridge-challenge-protocol.md`.

## Distinctions the archive should preserve

### 1. Formal record versus acquired record

A formal record is a quantity that the candidate can define.
An acquired record is a quantity that can be stabilized, obtained, and compared under finite constraints.
The archive should preserve formal progress but refuse to call it acquisition until the route names the setup and finite-resource budget.

### 2. Simulated truth versus public acquisition

A simulation can be a strong acquisition tool when it closes a real loop, exposes finite-resource limits, or generates a publicly rerunnable record route.
But synthetic labels, modeler's truth, or benchmark classes are not candidate-native acquisition by default.
They are proxies unless the lane says how the proxy is tied to public records and where it fails.

### 3. Boundary access versus candidate-owned records

Boundary data, entanglement inputs, asymptotic data, or holographic dictionaries may be meaningful record routes.
They are not automatically candidate-owned public records.
A lane that borrows boundary stabilization and lab custody should say so and keep the acquisition field at `B/P` rather than `N`.

### 4. Detector concept versus acquisition campaign

A proposed detector, resonator, interferometer, simulation platform, or cosmological statistic can earn acquisition-realizability credit when it states channel, exposure, backgrounds, thresholds, and finite-resource requirements.
It does not earn acquisition closure merely because the signal is in principle measurable.

### 5. Acquisition versus attribution

This protocol says when a record can plausibly be acquired.
It does not say whether the record uniquely supports one lane.
That stronger question needs forward-model, inversion, nuisance, discrepancy, and pipeline-stability disclosure under `docs/40-model/acquisition-vs-attribution-gate.md`.

## Application to the current landscape

### Family C

Family C already has the strongest partial acquisition profile among the current identifiability rows.
Boundary subregions, entanglement data, correlators, reconstruction inputs, sparse data, learned routes, and controlled holographic packages give it real record-like structure.
The family-C screen chain also already names thin-data, inverse-stability, recoverand, calibration, abstention, policy, and margin pressures.

But field 4 still should not be upgraded to native closure.
The record route remains dependent on boundary packaging, code-subspace restriction, finite-window control, dictionary choice, large-`N` assumptions, simulation / training ecology, and ordinary public data custody.
The candidate does not yet own the full path from native target to public record.

Current score impact: **keep `P` or `B/P`, not `N`.**
The route is strongest because it can name many acquisition burdens, not because it has paid them natively.

### Completion bids

Completion bids often have powerful formal observables and internal consistency structures.
Those are not enough for acquisition-realizability credit.
A string vacuum, asymptotic-safety fixed point, spin-foam continuum corridor, causal-set growth law, or bootstrap island must still say what record can be acquired and what finite public path turns the record into evidence-bearing material.

Current score impact: **target-rich rows stay acquisition-borrowed** unless they give a finite route from candidate target to public record.

### Low-energy laboratory, detector, and simulation lanes

These lanes can be stronger on field 4 than on target or equivalence fields.
They often name actual detector outcomes, simulations, counts, coherence sectors, local operators, or acquisition campaigns.
That is real acquisition credit.

But their target class is often externally chosen, their same/different rule is often experimenter-supplied, and attribution may remain weak.
A record-rich row should therefore not be promoted to candidate-native identifiability merely because it has a credible acquisition path.

Current score impact: **acquisition credit can be real while candidate-native identification remains unpaid.**

### Witness-side frame and observer routes

Frame-conditioned or observer-relative routes may define sharp internal records, edge structures, clocks, local operators, or perspective-indexed quantities.
Their acquisition debt is usually public transport: who can obtain the same fact, under which reference standard, and how does the record survive frame or observer changes?

Current score impact: **special access and observer records remain bounded until the public acquisition path is transportable.**

### Family B

Family B still stops earlier.
Equation recovery, entropy balance, and trace discipline do not yet supply a native target-to-record acquisition row.

Current score impact: **bounded trace discipline remains below field-4 acquisition-realizability credit.**

## Future-edit rule

A future revision may claim an acquisition-field improvement only if it says all of the following:

1. which ledger row changed;
2. which candidate target and record object are linked;
3. the old field-4 code and proposed new field-4 code;
4. the access channel and regime / preparation assumptions;
5. the public acquisition path and which parts remain borrowed;
6. the finite-resource budget;
7. the nuisance, drift, or discrepancy controls;
8. the no-acquisition outcome;
9. whether attribution-grade credit changed or stayed unpaid.

If those nine items are absent, the revision may still be useful, but it should be scored as formal-forward-map, reconstruction, simulation, detector-concept, discriminator, or proxy progress rather than as candidate-native acquisition progress.

## Anti-inflation rules

Reject the following shortcuts:

1. **observable-as-record shortcut** — a defined quantity is not yet an acquired record.
2. **dictionary-as-acquisition shortcut** — a boundary or dual dictionary is not by itself a public acquisition path.
3. **simulation-label shortcut** — synthetic truth is not candidate-native acquisition unless tied to public record semantics.
4. **detector-concept shortcut** — an in-principle measurable signal is not acquisition-grade without exposure, background, and threshold budgets.
5. **proxy-portability shortcut** — a useful surrogate is not the target unless the surrogate-to-target route and failure modes are declared.
6. **acquisition-as-attribution shortcut** — a record that can be obtained is not yet stable support for one theory lane.
7. **publicness shortcut** — public laboratory or archive custody can be strong while the candidate-native acquisition field remains borrowed.

## Net result

The archive now has a field-4 counterpart to the equivalence-collapse protocol.
Candidate-native identifiability no longer allows a formal observable, reconstruction dictionary, simulation output, detector proposal, or cosmological trace to stand in for acquired evidence unless the acquisition route itself is written down.

That sharpens `OQ-0057` without promoting any lane:
- family C remains the strongest partial acquisition row but still borrows decisive boundary and public-record machinery;
- completion bids remain formal-target-rich but acquisition-route- and inverse-route-poor;
- lab and simulation lanes may be acquisition- and margin-richer while still candidate-target-limited;
- witness-side frame routes may be special-access-rich while public acquisition transport remains unpaid;
- and no current lane earns candidate-native identifiability closure.
