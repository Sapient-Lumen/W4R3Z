# Typicality, naturalness, and anthropic audit

Naturalness, typicality, and anthropic language must name the reference class, conditionalization rule, weighting function, and rare-event failure mode. The archive treats these as route-local denominators, not as evidence substitutes. A typicality row can cap support; it cannot promote a route beyond public-record, observed-sector, viability, and candidate-native ceilings.
