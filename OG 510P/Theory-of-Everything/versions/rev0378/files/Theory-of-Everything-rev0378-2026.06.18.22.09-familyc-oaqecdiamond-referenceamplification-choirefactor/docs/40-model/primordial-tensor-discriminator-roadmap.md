# Primordial tensor discriminator roadmap

## Purpose

This surface gives the new `R-OQ0057-PRIMORDIAL-TENSOR-BMODES` row a model home. Primordial tensor and CMB B-mode records can strongly constrain early-universe packages, inflationary mechanisms, and high-energy bridge stories. They remain many-to-one records unless additional structure shrinks the quotient.

## What counts

A primordial-tensor decision needs:

- a declared public artifact: map, likelihood, forecast tool, delensing product, or released data product;
- foreground, lensing, sky-mask, calibration, and null-channel controls;
- a candidate-native derivation of the tensor spectrum, not merely a fitted `r` value;
- an equivalence rule for packages with the same tensor likelihood;
- additional records if a route wants to move beyond class constraint.

## Current cap

This is an `S2` early-universe constraint corridor. A clean tensor detection could become an extremely important public record and might create a route-local `S3` class pocket if a candidate had predeclared spectrum / tilt / ancillary predictions. It still would not be candidate-native ToE identification by itself.

## Failure modes

The two explicit negative controls are:

- `NC-PRIMORDIAL-FOREGROUND-LENSING-DECOY` — contamination or delensing/foreground dependence is treated as primordial evidence;
- `NC-PRIMORDIAL-MANY-MODEL-DECOY` — one tensor likelihood is treated as unique support for one early-universe ontology.

## Bridge to decision experiments

The relevant decision row is `DX-0005-CMB-PRIMORDIAL-TENSOR-BMODE`. Forecasts become useful only when they define later outcome classes and non-promotion caps.
