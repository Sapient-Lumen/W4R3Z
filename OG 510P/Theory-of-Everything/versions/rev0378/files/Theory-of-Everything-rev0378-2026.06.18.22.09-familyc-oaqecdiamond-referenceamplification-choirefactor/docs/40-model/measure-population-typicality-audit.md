# Measure / population / typicality audit

This audit scores explicit measure, population, and typicality proposals inside the shared vacuum-energy proposal-class frame.
Broad routing now lives in `docs/40-model/vacuum-energy-burden-router.md`; this audit keeps only its proposal-class-specific burden move, residual debt, wedge, and current readout.
Read this together with:
- `docs/40-model/vacuum-energy-burden-router.md`
- `docs/40-model/vacuum-energy-proposal-class-family-frame.md`
- `docs/40-model/vacuum-energy-proposal-class-stack.md`

## Compression verdict

The current archive should treat **explicit measure / population / typicality proposal classes as real cosmological-package refinements that can sometimes create bounded cross-parameter or temporal pressure, but not as generic closure of the selection problem and not as local threshold relief**.

Bounded result:

1. **What they genuinely change:** they replace vague “some observers somewhere” rhetoric with an explicit rule for what is counted, how vacua or histories are populated, and how first-person observational location is weighted.
2. **What the strongest versions can buy:** local or causal measures can reduce some slicing ambiguities and sometimes yield nontrivial pressure on which vacua, histories, or observer proxies dominate.
3. **What they still owe:** robustness across nearby regulators, explicit population dynamics, a justified observer or entropy proxy, and an honest xerographic or typicality rule rather than an invisible self-location prior.
4. **What they therefore currently earn:** bounded **cosmological-package credit**, sometimes stronger than vague landscape prose, but still not generic **local-law credit** and still not a thick empirical wedge by default.

That is already a sharper archive state.
It means the archive can now separate three non-identical package moves:
- **scan plus selection without an explicit counting rule**,
- **explicit measure or population rule with bounded regulator discipline**,
- and **explicit self-location / xerographic weighting** that turns third-person ensemble statements into first-person claims while introducing a new package burden of its own.

## Why this document exists

The previous audit closed the anthropic / landscape-selection pass by saying that scanning plus selection can earn real cosmological-package credit while still leaving measure, population, typicality, and empirical-thickness debt unresolved.
That leaves the archive with the next necessary question:

**Does any explicit measure / population / typicality proposal class do more than tidy the bookkeeping of selection, and actually produce robust explanatory pressure?**

This is the right place to block four laundering moves:
- “we chose a measure” being retold as if local vacuum-energy sensitivity had shrunk,
- “we can count observers in one regulator” being retold as if the package were now unique,
- “typicality” being smuggled in as if theory alone had fixed our observational location,
- and a successful fit in one observer proxy being retold as if the empirical wedge were thick and regulator-independent.

## What an explicit measure / typicality move actually buys

In the archive's current bounded reading, explicit measure, population, and xerographic proposals can genuinely buy four things.

### 1. They force the package to say what is being counted

This is the first honest gain over loose landscape language.
A proposal now has to say whether it counts:
- physical volume,
- bubble entries along worldlines,
- events in a causal patch or causal diamond,
- entropy production,
- observer proxies,
- or some other class of occurrences.

That matters because different choices are not cosmetic.
They change what the proposal predicts.
The archive should count that explicitness as real package progress.

### 2. Local or causal measures can reduce some global-slicing ambiguity

Causal-diamond or causal-patch style proposals are stronger than generic “count all observers in the multiverse” language because they try to regulate infinities by restricting attention to a bounded causal region or worldline-based history rather than an arbitrary global slicing.
That is a real formal gain.

The archive should therefore stop treating all measure proposals as equally vague.
Some are sharper because they make the regulator and counted region explicit.

### 3. Explicit first-person prediction requires more than ensemble frequencies

Srednicki–Hartle style xerographic frameworks are load-bearing here because they state the part many multiverse discussions hide:
third-person probabilities for what exists are not yet first-person probabilities for what *we* should expect to observe.
A self-location rule is needed once our data may be replicated.

That is not a vice by itself.
It is an honesty gain.
It tells the archive where another real package burden lives.

### 4. Some bounded cross-parameter or temporal pressure can appear

Once a proposal gives:
- a concrete population rule,
- a regulator,
- an observer or entropy proxy,
- and a xerographic choice,

it can sometimes do more than say “small `Lambda` is selection-allowed.”
It may also prefer certain vacua, histories, or time windows over others.
That counts as bounded extra pressure.
The archive should allow that credit when it is explicit.

## What these proposal classes still do **not** buy automatically

### 1. Generic local radiative burden reduction

This remains the decisive discipline point.
An explicit measure, population rule, or xerographic distribution can change how observations are weighted across vacua or histories.
It does **not** thereby show that local EFT threshold sensitivity has been reduced inside each vacuum.

So the archive should now say this plainly:

**better counting of realizations is not the same as shrinking local vacuum-energy sensitivity.**

### 2. Unique package closure

A concrete measure can be better than vague rhetoric without being unique.
Nearby regulators, nearby observer proxies, or different xerographic choices can still move the result.
So the class does not automatically close the package debt merely by being explicit.

### 3. Observer-proxy closure

Entropy production, galaxy formation, habitable volume, observer number, or other proxies are not interchangeable for free.
Each changes what is favored.
If the proposal does not justify why one proxy is privileged, the archive should keep that debt visible.

### 4. Thick empirical closure by default

Even when a measure proposal is explicit, it can remain empirically thin if the main output is still only a better-conditioned small-`Lambda` story or a regulator-sensitive preference ordering.
The archive should score that honestly as **bounded pressure**, not generic predictive victory.

## Three concrete proposal classes the archive should now distinguish

### 1. Global-counting or cutoff packages

These classes attempt to regulate infinities by imposing a global cutoff or counting rule across the whole eternally inflating spacetime.
Their main gain is explicitness.
Their main weakness is regulator sensitivity and slicing dependence.

Current archive score: **explicit package structure, but often fragile under regulator choice**.

### 2. Local or causal measures

These classes count only what occurs in a bounded causal region, causal patch, or causal diamond, often using worldline entry probabilities and a local weighting prescription.
They are stronger because they try to reduce global-slicing arbitrariness and sometimes generate sharper cross-parameter pressure.

Current archive score: **the strongest currently audited measure family, but still package-level and still dependent on counted proxy and weighting rule**.

### 3. Xerographic / typicality frameworks

These classes make self-location assumptions explicit.
Their gain is conceptual honesty: first-person predictions require more than theory-only ensemble counts when our data may be replicated.
Their weakness is equally clear: self-location weightings are another assumption family that can materially alter predictions.

Current archive score: **honest package completion, not free closure**.

## Scoring measure / population / typicality proposals under the debt split

### Local radiative burden

**Current archive score:** not reduced.

No current measure, population, or typicality proposal class audited here generically shrinks local EFT threshold sensitivity.
These are package-side refinements, not local radiative repairs.

### Cosmological-package burden

**Current archive score:** partially reduced when the proposal makes counting, population, and self-location rules explicit.

This is the real gain.
The archive should now count explicit measure proposals as better than vague anthropic language when they say:
- what is counted,
- how vacua or histories are populated,
- what observer proxy is used,
- and how first-person probabilities are extracted.

But the archive should still withhold closure when nearby regulators, proxies, or xerographic rules materially shift the conclusion.

### Mixed debt-shift burden

**Current archive score:** still active, but now more diagnosable.

The debt here is not mostly a local-to-global relabeling.
It is a shift from vague global-package rhetoric to explicit regulator, proxy, and self-location choices.
That is progress.
But it is still a package burden unless robustness is shown.

## Five checks the archive should now apply

### 1. What exactly is counted?

Name the counted object explicitly:
- volume,
- vacua entered by a worldline,
- events in a causal patch,
- entropy production,
- observer proxies,
- or histories.

If this is vague, the proposal has not yet become a real measure surface.

### 2. What populates the support space?

State the population dynamics explicitly:
- tunneling network,
- eternal inflation branching,
- initial-state prior,
- no-boundary or other quantum-state weighting,
- or another mechanism.

Without a population rule, a measure is only half a package.

### 3. What observer or complexity proxy is being used?

If the weighting depends on entropy production, structure formation, habitable regions, or observers, say so plainly.
If nearby proxy choices would materially change the result, the empirical wedge is thin.

### 4. What xerographic or typicality rule is assumed?

If the proposal uses typicality, atypicality, mediocrity, or another self-location rule, name it explicitly.
If this assumption is left invisible, the archive should treat the claimed prediction as underdescribed.

### 5. What survives nearby rule changes?

This is the decisive new test.
A proposal earns stronger archive credit only if its qualitative pressure survives nearby changes in:
- regulator,
- observer proxy,
- xerographic rule,
- or mild population variation.

If not, the archive should score the result as **regulator- or self-location-sensitive package pressure**, not closure.

## Family-by-family relevance

### Family A — EFT-first baseline

Family A is decisive here because it keeps the local burden explicit.
No counting rule earns local-law credit unless threshold sensitivity actually shrinks.

### Family B — Thermodynamic / entropy gravity

Family B matters only indirectly here.
Entropy production may be used as a weighting proxy, but that does not by itself turn thermodynamic language into a vacuum-energy solution.

### Family C — Holography / entanglement geometry

Family C matters only if a concrete causal or holographic measure actually yields a more robust counting rule than ordinary global packages.
That possibility is still open, not earned.

### Family D — Measurement / nonlocality pressure

Family D matters directly because typicality and self-location assumptions implicitly lean on what counts as an observer, record, or observational situation.
This is another reason the archive should not treat “observer weighting” as a free primitive.


## Concrete worked example — causal-diamond / entropic-weighting package

This section forces the archive's generic measure audit through one explicit package rather than another broad survey.

### Minimal package components

1. **Support space:** a landscape or eternal-inflation style population of vacua / histories supplies the ensemble side of the problem (`REF-0028`, `REF-0029`).
2. **Counted region:** the regulator is one causal patch or causal diamond rather than an arbitrary global slice (`REF-0029`, `REF-0031`).
3. **Weighting proxy:** the worked package weights by total entropy production inside that causal diamond; in the original concrete treatment, dust heated by stars dominates the counted entropy budget (`REF-0031`).
4. **First-person extraction:** unless a xerographic rule is named explicitly, the move from third-person ensemble weighting to “what we should expect to observe” still hides a self-location assumption (`REF-0030`).

### What this concrete package genuinely earns

- It is stronger than vague anthropic prose because the counted region and weighting rule are explicit.
- It is stronger than generic global cutoff talk because the causal-diamond restriction removes part of the slicing arbitrariness that plagues global counting (`REF-0029`).
- It can create bounded extra pressure rather than only a bare small-`Lambda` selection story, because once the proxy and region are fixed the package can also prefer some environmental ranges or histories over others (`REF-0031`).

### What remains unpaid

- **Local radiative burden:** unchanged. Better weighting across vacua is not a repair of local EFT threshold sensitivity.
- **Proxy burden:** entropy production is still a surrogate for observers or evidence, not observer closure.
- **Xerographic burden:** first-person expectations remain underdescribed unless typicality or another xerographic rule is made explicit (`REF-0030`).
- **Robustness burden:** later analysis shows that inhomogeneity, late-time entropy sources, support-formation or regulator-entry weighting, and related measure-handling choices can materially alter the prediction, so the archive should not call this package unique closure (`REF-0029`, `REF-0032`).

### Archive score for this worked example

- **Local-law credit:** none.
- **Cosmological-package credit:** real, and stronger than vague landscape-selection rhetoric.
- **Empirical wedge:** bounded.
- **Robustness:** partial; still sensitive to proxy, late-time entropy treatment, support-formation / regulator-entry weighting, and self-location specification.
- **Net verdict:** this is the strongest concrete local-measure package currently worked in the archive, but it remains a proxy-sensitive and xerographic-sensitive package refinement rather than closure.

## Compact robustness pass — nearby perturbations of the worked package

This section asks what survives small rule changes **without** silently changing the support space.
The point is not to rescue a unique prediction; it is to separate the package core from the package shell.

| Perturbation | Keep fixed | What moves | What survives |
| --- | --- | --- | --- |
| **Proxy swap**: entropy production -> a nearby observer-adjacent or habitable-structure proxy | same causal-diamond regulator, same support space, same broad population story | which histories dominate and how sharp the preferred `Lambda` / time-window pressure looks | explicit counted-region discipline still beats vague selection prose, but any sharper environmental preference is proxy-sensitive rather than canonically fixed |
| **Late-time / inhomogeneous entropy treatment** | same causal-diamond packaging and same broad weighting idea | the causal-entropic preference can weaken or drift once inhomogeneity and later entropy sources are treated more explicitly (`REF-0032`) | the package remains a real local-measure proposal, but not a unique closure of the cosmological package |
| **Explicit xerographic rule**: typicality vs nearby self-location choices | same third-person ensemble weighting | first-person expectation and empirical sharpness can move even when the ensemble side does not (`REF-0030`) | the archive can now say cleanly that explicit self-location is required; it cannot pretend the theory fixed that step for free |
| **Mild population-prior variation** | same support space and counted region | strength and ordering of some package preferences can move if tunneling or initial-state weights change | only conclusions that survive support-fixed prior variation deserve robustness credit; everything else stays package-sensitive |

### Robust core versus non-robust shell

**Robust core:**
- explicit local / causal counting is stronger than vague anthropic rhetoric,
- explicit weighting and explicit xerographic statement are honesty gains,
- and none of that buys local EFT threshold relief.

**Non-robust shell:**
- any claim that one entropy proxy, one late-time treatment, or one xerographic rule yields a uniquely preferred observed `Lambda`,
- any claim that the package has become a thick empirical discriminator,
- and any claim that local-law credit has been earned by better ensemble bookkeeping.

## Fixed-support proxy comparison — entropy weighting versus a nearby record-adjacent proxy

This section changes **only** the weighting proxy while holding support space, causal-diamond regulator, and the broad population story fixed.

**Comparison proxy:** instead of weighting by total entropy production, weight by **record-bearing free-energy sites** — sites inside the same causal diamond that plausibly sustain stable gradients, complex structure, and rereadable records for long enough to count as evidence-bearing situations.
This is still not observer closure.
It is only a closer surrogate for the archive's record discipline than raw entropy throughput (`REF-0015`, `REF-0016`, `REF-0030`).

| Fixed element | Entropy-weighted package | Record-adjacent proxy package | What the comparison says |
| --- | --- | --- | --- |
| Support space | same landscape / eternal-inflation ensemble | same | no gain comes from silently changing the ensemble |
| Counted region | same causal diamond | same | local / causal regulation remains part of the stable package core |
| What gets rewarded most | total entropy production, including high-throughput dusty or diffuse processes (`REF-0031`) | long-lived free-energy sites that can plausibly host persistent, rereadable records (`REF-0015`, `REF-0016`) | entropy and record-adjacent weighting overlap only partially; throughput is not yet the same thing as evidence-bearing structure |
| Late-time tail | can stay sensitive to late or inhomogeneous entropy sources (`REF-0032`) | tends to downweight entropy-rich eras that no longer improve durable record support | any sharper temporal preference is shell-level unless it survives both proxies |
| `Lambda` / environmental pressure | may look sharper when total entropy production peaks in a narrower window | shifts toward whichever vacua keep habitable, record-bearing structure available for longer | bounded package pressure can persist, but the sharp location and thickness of the preference move with proxy choice |
| First-person extraction | still needs explicit xerographic rule (`REF-0030`) | still needs explicit xerographic rule (`REF-0030`) | proxy refinement does not remove self-location debt |

### Verdict from the fixed-support proxy swap

- **What survives:** explicit local counting, explicit weighting, and explicit xerographic burden.
- **What weakens:** any claim that entropy weighting is already a near-canonical observer rule.
- **What does not change:** local EFT threshold sensitivity remains untouched.
- **Net result:** under fixed support space, the entropy-weighted and record-adjacent packages agree only on a bounded broad window, not on a uniquely preferred cosmological prediction. The archive should therefore treat entropy weighting as one useful package proxy, not as canonical observer accounting.

## Explicit xerographic split — instance typicality versus record-equivalence restraint

This section holds the support space, causal-diamond regulator, and the fixed entropy / record-adjacent proxy pair constant while changing **only** the self-location rule.

Two explicit archive-side xerographic options are enough to expose the remaining burden:

1. **Instance typicality:** conditional on our present data, assign equal first-person weight to each matching proxy-counted realization. Numerical multiplicity counts linearly (`REF-0030`).
2. **Record-equivalence restraint:** conditional on our present data, assign equal first-person weight only across distinct rereadable-record classes; extra near-duplicate instances inside one coarse-grained record class do not automatically amplify first-person credit unless they add record-distinguishable content (`REF-0015`, `REF-0016`, `REF-0030`).

The second rule is not claimed here as a unique truth.
It is only a nearby, archive-native alternative that respects the archive's existing record / objectivity discipline better than silent multiplicity weighting.

| Proxy / xerographic cell | What gets amplified | What contracts | Archive reading |
| --- | --- | --- | --- |
| **Entropy proxy + instance typicality** | high-throughput eras or vacua where many proxy-counted instances appear (`REF-0031`) | little; multiplicity and throughput reinforce each other | this is the sharpest-looking cell, but also the one most exposed to hidden self-location credit |
| **Entropy proxy + record-equivalence restraint** | only broad support for record-capable windows that still score well on entropy | sharp temporal or `Lambda` peaks driven mostly by many similar instances | the entropy lane keeps bounded package credit, but its first-person sharpness softens once duplicate-like record classes stop counting linearly |
| **Record-adjacent proxy + instance typicality** | vacua with many durable record-bearing sites | part of the pure-throughput advantage of raw entropy weighting | this cell remains more evidence-facing than raw entropy, but still carries multiplicity-sensitive self-location debt |
| **Record-adjacent proxy + record-equivalence restraint** | existence of durable rereadable-record classes across a broad habitable window (`REF-0015`, `REF-0016`) | most abundance-driven sharpness | this is the most conservative first-person cell; it preserves the archive's record discipline while refusing to turn duplicate support into free predictive sharpness |

### Verdict from the xerographic split

- **What survives across all four cells:** explicit local counting is still better than vague selection prose, and explicit proxy plus explicit xerographic rule are both honesty gains.
- **What narrows:** once record-equivalence restraint is allowed, the apparent first-person advantage of entropy weighting contracts; some broad window pressure can remain, but the sharpness of the preference is no longer theory-fixed.
- **What can still move:** even with the proxy pair fixed, xerographic choice can change not just first-person sharpness but which proxy lane looks more trustworthy as an evidence-facing package.
- **What still does not move:** no cell reduces local EFT threshold sensitivity.

## Support-fixed population-prior split — support-neutral versus abundance-tilted priors

This section holds the support space, causal-diamond regulator, fixed proxy pair, and fixed xerographic pair constant while changing **only** the prior weight assigned to already-admitted support classes.

Two nearby prior choices are enough for the archive's current purpose:

1. **Support-neutral prior:** treat each viable support class in the already-fixed ensemble as equally admitted before proxy and xerographic weighting. This is the archive's cleanest way to ask what the package says without silently rewarding branch proliferation first.
2. **Abundance-tilted prior:** before proxy and xerographic weighting, weight each viable support class by how much population supply, branch abundance, or occupancy it contributes inside that same fixed support space. This is a nearby package move because many measure stories implicitly lean this way once prolific vacua or histories are admitted.

The point is not to declare either prior uniquely right.
It is to test whether the same proxy / xerographic cell still deserves the archive's bounded package credit once support space is held fixed but prior mass is redistributed.

| Proxy / xerographic cell | Under support-neutral prior | Under abundance-tilted prior | What survives |
| --- | --- | --- | --- |
| **Entropy proxy + instance typicality** | still gives a sharp-looking lane, but some of that sharpness now has to come from the entropy proxy plus explicit instance weighting rather than from prior-loaded abundance | becomes the most amplified cell because prolific support classes, entropy throughput, and multiplicity all reinforce one another | this cell remains a usable package lane, but its apparent dominance is now visibly triply conditional rather than theory-canonical |
| **Entropy proxy + record-equivalence restraint** | keeps broad entropic support while suppressing duplicate-driven peaks | can recover some sharpness if prolific support classes also sustain large entropy budgets, but less dramatically than with instance typicality | the entropy lane keeps bounded package credit, yet its shape still depends on how prior abundance is allowed to matter |
| **Record-adjacent proxy + instance typicality** | remains evidence-facing while still granting linearly more weight to vacua with many durable record-bearing sites | grows stronger when prolific support classes also host many record-bearing sites, though less by raw diffuse throughput than the entropy lane | this cell stays a serious nearby alternative, but its advantage is still multiplicity-sensitive |
| **Record-adjacent proxy + record-equivalence restraint** | becomes the most stable conservative cell because it asks only for durable rereadable-record support across the fixed ensemble (`REF-0015`, `REF-0016`) | loses relative rank whenever prolific support classes are given extra prior weight, because it refuses to turn sheer abundance into automatic first-person sharpness | this cell best preserves the archive's record discipline, but it cannot claim unique package status under abundance-tilted priors |

### Verdict from the support-fixed prior split

- **What survives:** the broad package window and the archive's real gains remain explicit counted-region, proxy, xerographic, and support bookkeeping.
- **What reorders:** once prior weight is allowed to shift across the same support space, the ranking of the four proxy / xerographic cells can change even though the support set itself does not.
- **What now looks overclaimed:** no cell can yet present itself as the canonical cosmological-package winner across both nearby priors.
- **What still does not move:** no prior choice here reduces local EFT threshold sensitivity.


## Support-fixed late-time split — full-throughput carry versus record-window restraint

This section holds the support space, causal-diamond regulator, fixed proxy pair, fixed xerographic pair, and support-fixed prior pair constant while changing **only** how late-time or strongly inhomogeneous entropy is allowed to contribute.

Two nearby treatments are enough for the archive's current purpose:

1. **Full-throughput carry:** once a process lies inside the admitted causal diamond and contributes to the chosen proxy, count it even when the contribution arrives in late, diffuse, or strongly inhomogeneous tails. This is the most generous continuation of the original entropic package (`REF-0031`, `REF-0032`).
2. **Record-window restraint:** count late or strongly inhomogeneous contributions only insofar as they materially extend durable rereadable-record support, rather than merely adding raw throughput after the archive's evidence-bearing window has effectively saturated. This is not claimed as unique truth; it is only the nearest archive-side restraint consistent with the existing record discipline (`REF-0015`, `REF-0016`, `REF-0032`).

| Proxy / xerographic cell | Under full-throughput carry | Under record-window restraint | What the split shows |
| --- | --- | --- | --- |
| **Entropy proxy + instance typicality** | remains the sharpest-looking cell, especially once abundance-tilted priors are allowed to reinforce late throughput and linear multiplicity | loses the largest share of its advantage because late diffuse entropy no longer converts automatically into first-person credit | this cell is usable, but its apparent dominance now depends jointly on late-time credit, prior abundance, and self-location |
| **Entropy proxy + record-equivalence restraint** | keeps a broad entropic window while suppressing some duplicate-driven sharpness | contracts to a milder broad-window lane once late tails that do not improve rereadable-record support stop counting for much | entropy weighting keeps bounded package credit, but no longer anchors a late-time-neutral winner |
| **Record-adjacent proxy + instance typicality** | gains only when later eras actually host more durable record-bearing sites, not merely more diffuse entropy | stays relatively stable because its proxy was already closer to evidence-bearing structure than raw throughput | once late diffuse entropy is discounted, this cell can match or overtake the entropy-instance lane under abundance-tilted priors |
| **Record-adjacent proxy + record-equivalence restraint** | remains the most conservative broad-window cell | moves the least, because both the proxy and xerographic rule already refuse to turn sheer late abundance into free sharpness | this is the archive's stability anchor, but not a unique package winner across both prior choices |

### Verdict from the late-time treatment split

- **What survives:** the archive's real gains remain explicit counted-region, proxy, xerographic, prior, and now late-time bookkeeping.
- **What reorders:** under generous late-throughput credit, entropy-plus-instance typicality can still look strongest; once record-window restraint is imposed, record-adjacent cells gain relative standing and no single cell remains on top across both late-time treatments.
- **What now looks overclaimed:** late diffuse entropy should not be treated as free first-person or evidence credit merely because it falls inside the counted causal diamond.
- **What still does not move:** no treatment here reduces local EFT threshold sensitivity.


## Support-fixed entry-weighting split — formation-neutral admission versus regulator-entry supply

This section holds the support space, fixed proxy pair, fixed xerographic pair, nearby prior pair, and late-time treatment pair constant while changing **only** how admitted support classes are weighted at formation or regulator entry.

Two nearby treatments are enough for the archive's current purpose:

1. **Formation-neutral admission:** once a support class is already inside the fixed support space, treat each admitted class as equally available to the local measure before downstream proxy, xerographic, prior, and late-time bookkeeping. This isolates the package from silently rewarding prolific branch formation merely because it exists (`REF-0028`, `REF-0029`).
2. **Regulator-entry weighting:** before downstream proxy, xerographic, prior, and late-time bookkeeping, weight support classes by regulator-level entry frequency or worldline encounter supply into the counted causal diamond. This is the nearest archive-side way to let causal-diamond style population mechanics do real work rather than remain implicit (`REF-0029`, `REF-0031`).

| Proxy / xerographic cell | Under formation-neutral admission | Under regulator-entry weighting | What the split shows |
| --- | --- | --- | --- |
| **Entropy proxy + instance typicality** | keeps only the sharpness that downstream abundance-tilted priors and generous late-throughput carry can already amplify; it no longer gets extra credit merely from how often support classes form | can recover the strongest-looking status whenever prolific regulator entry lines up with high entropy throughput and linear multiplicity | this cell remains usable, but its apparent dominance now depends on entry supply as well as proxy, self-location, prior, and tail credit |
| **Entropy proxy + record-equivalence restraint** | keeps a broad entropic window without duplicate-driven amplification | strengthens when frequently entered classes also sustain large entropy budgets, but less sharply than under instance typicality | entropy weighting keeps bounded package credit, yet still cannot claim an entry-neutral winner |
| **Record-adjacent proxy + instance typicality** | stays a serious evidence-facing alternative whenever late-time restraint and neutral admission already weaken diffuse-entropy cells | rises when the regulator preferentially enters support classes rich in durable record-bearing sites, and can then match or overtake entropy lanes once generous tail credit is removed | this cell shows that record-facing pressure can also be entry-sensitive rather than merely proxy-sensitive |
| **Record-adjacent proxy + record-equivalence restraint** | remains the most conservative stability anchor because it demands durable rereadable-record support without abundance or duplicate bonuses (`REF-0015`, `REF-0016`) | is amplified the least unless entry supply itself tracks durable record support closely | this cell best preserves archive-side restraint, but still does not become a unique package winner across both entry treatments |

### Verdict from the support-formation / regulator-entry split

- **What survives:** the archive's real gain is now explicit counted-region, proxy, xerographic, support, prior, late-time, and entry bookkeeping.
- **What reorders:** once regulator-entry supply is allowed to matter, cells that looked conservative under formation-neutral admission can regain or lose rank depending on whether prolific entries align with entropy throughput or durable record support. No current cell stays on top across both entry treatments plus the already-explicit prior and late-time pair.
- **What now looks overclaimed:** any local-measure story that treats support formation or regulator-entry supply as a harmless implementation detail rather than a material cosmological-package burden.
- **What still does not move:** no entry weighting here reduces local EFT threshold sensitivity.


## Evidence-floor split — permissive proxy support versus witness-thick record support

This section holds the support space, fixed proxy pair, fixed xerographic pair, nearby prior pair, late-time treatment pair, and entry-weighting pair constant while changing **only** what is allowed to count as evidence-bearing support.

The archive-side split is intentionally minimal and is borrowed from the existing record discipline in `docs/40-model/observer-record-minimum.md`, not from a new external literature branch.

1. **Permissive proxy floor:** once a site is counted by the chosen proxy inside the admitted causal diamond, let it contribute package weight even if the counted support is only loosely connected to durable, rereadable evidence. This preserves the broadest reading of entropy-heavy or multiplicity-heavy package pressure.
2. **Witness-thick floor:** only let counted support contribute strongly when it plausibly carries a causally generated, persistent, rereadable record trace in the archive's current minimal sense; diffuse throughput that does not thicken into evidence-bearing support is demoted to background package credit (`REF-0015`, `REF-0016`).

| Proxy / xerographic cell | Under permissive proxy floor | Under witness-thick floor | What the split shows |
|---|---|---|---|
| **Entropy proxy + instance typicality** | can still look strongest whenever abundant late throughput, prolific entry, and linear multiplicity all point the same way | contracts the most, because much of its advantage came from counting many high-throughput situations whose link to durable rereadable records was only indirect | this cell keeps package relevance, but not an evidence-thick unique wedge |
| **Entropy proxy + record-equivalence restraint** | keeps a broad entropic window while muting duplicate-driven sharpness | survives only where entropy-rich histories also sustain stable rereadable record support for long enough to matter | entropy weighting remains usable as a package proxy, but only after its evidence-bearing subset is made explicit |
| **Record-adjacent proxy + instance typicality** | remains a serious nearby alternative whenever durable record-bearing sites are already favored | loses some multiplicity-driven sharpness, but less than the raw entropy lane because its proxy was already closer to evidence-bearing support | this cell can still carry bounded pressure, though it remains self-location-sensitive rather than uniquely privileged |
| **Record-adjacent proxy + record-equivalence restraint** | already behaved like the archive's conservative stability anchor | moves the least, because it was already asking for durable rereadable support rather than sheer throughput or duplicate abundance (`REF-0015`, `REF-0016`) | this is the surviving witness-thick anchor, but it yields only a broad record-support window rather than a sharp package winner |

### Verdict from the evidence-floor / witness-thickness split

- **What survives:** the archive's robust gain is now explicit counted-region, proxy, xerographic, support, prior, late-time, entry, and evidence-floor bookkeeping.
- **What compresses:** once counted support must actually thicken into durable rereadable evidence traces, the apparent advantage of entropy-heavy and multiplicity-heavy cells softens sharply.
- **What now looks overclaimed:** any local-measure story that treats proxy-counted abundance as if it were already an evidence-bearing wedge without saying where the durable rereadable records physically live.
