## Compression verdict

The archive should now classify family-C multiplicity in three steps:
- **reference-frame / gauge redescription** — if the difference is only a change of relational reference frame or gauge presentation, it is not a new target to be identified; it is a sameness-rule debt. `REF-0120`
- **dictionary / observer-map drift** — if the difference appears only after changing which observer is included, where the effective boundary sits, or which holographic map/post-selection rule is used, the ambiguity is not yet candidate-native bulk non-uniqueness; it is map-side drift. `REF-0135`, `REF-0136`
- **residual empirical collapse / underdetermination** — only after the first two are fixed should the archive treat remaining multiplicity as live identifiability debt, and current family-C work still leaves such debt because one boundary state may admit multiple semiclassical bulk readings while partial observability can stabilize predictions without uniquely fixing the microscopic story. `REF-0061`, `REF-0129`

So the correct archive move is:
**score family-C non-uniqueness by triage, not by rhetoric: clear reference-frame redescription first, then map-side drift, and only then count what remains as empirical-collapse pressure.**

## Why this document exists

The archive already says that family C has real restricted inverse progress without identifiability closure.
What remained underspecified was a practical classification rule:

> when a boundary package seems to support more than one bulk story, what kind of ambiguity is that actually?

Without a triage rule, future revisions can overreact in opposite directions:
- treat every multiplicity as deep ontological underdetermination,
- or dismiss every multiplicity as mere gauge without saying why.

Both are too cheap.
This document installs the missing middle classifier.

## The three classes

### 1. Reference-frame / gauge redescription

Some family-C multiplicity is not evidence that the candidate has multiple physically distinct bulk targets.
It may instead reflect the fact that gravitational variables are interpreted through relational observables and reference-frame choices.
Thiemann's 2026 analysis makes this burden explicit: physical interpretation requires an operational translation of reference frames into mathematics, and different quantum reference frames can be related by a relational reference frame transformation rather than by a change in empirical content. `REF-0120`

Archive consequence:
if a purported ambiguity disappears once the relevant relational frame-change or gauge-honest sameness rule is declared, then family C has not discovered a second target.
It has only exposed an undeclared equivalence rule.
That is a same/different-discipline issue, not a fresh ontological win or failure.

### 2. Dictionary / observer-map drift

Some multiplicity survives gauge cleanup but still should not yet be scored as bulk underdetermination.
Recent holographic work shows that the map itself can change when the observer is treated differently.
Akers et al. construct a non-isometric code by effectively removing the part of the holographic map that acts on the observer, thereby creating an effective boundary at the observer-environment interface. `REF-0135`
Higginbotham then shows that, with a different holographic map consistent with post-selection on closed universes, a swap test need not distinguish the Antonini-Rath candidate bulk duals. `REF-0136`

Archive consequence:
if the multiplicity arises because the observer-coding rule, effective boundary location, or post-selection/dictionary package changed, then the ambiguity is still partly map-side.
Family C does not yet get to retell that as candidate-native bulk non-uniqueness.
The archive should first ask whether the alleged alternatives live in the same fixed dictionary at all.

### 3. Residual empirical collapse / underdetermination

Only after gauge/frame redescription and map drift are held fixed should the archive score what remains as live identifiability debt.
At that point, the question becomes whether the surviving bulk alternatives are genuinely distinct yet not separable by the available witness route.
Antonini and Rath provide the sharpest current family-C warning shot: one holographic CFT state may admit multiple simple semiclassical bulk descriptions. `REF-0129`
Nomura and Ugajin sharpen the broader lesson from a different angle: partial observability can recover statistically stable semiclassical predictions even when the underlying microscopic structure is not uniquely fixed by what observers can access. `REF-0061`

Archive consequence:
this is the only class that should count as genuine residual identifiability pressure.
It is not solved by saying “the dictionary is strong,” and it is not dissolved by saying “everything is gauge.”
It marks the point where family C still lacks a native empirical-collapse rule.

## Decision rule the archive should apply

When a future family-C result advertises bulk non-uniqueness, apply this sequence before scoring it:

1. **frame/gauge check** — is the difference removed by a declared relational reference-frame or gauge-equivalence rule? If yes, score as redescription, not residual multiplicity.
2. **map-fix check** — is the difference produced only by changing observer inclusion, effective boundary placement, post-selection, code-subspace choice, or dictionary package? If yes, score as dictionary / observer-map drift.
3. **fixed-package distinguishability check** — with the same witness route and map fixed, do the surviving alternatives remain observationally inseparable? If yes, score as residual empirical collapse / underdetermination.

This sequence is intentionally conservative.
It blocks the archive from inflating family-C ambiguity into a deep win or deep failure before the ambiguity type is known.

## False promotions the archive should reject

1. **every multiplicity is not underdetermination**
   - Some multiplicity is only undeclared frame or gauge redescription.

2. **every new map is not gauge**
   - A changed observer-coding or post-selection rule is not automatically a harmless symmetry; it may be dictionary drift.

3. **coarse-grained agreement is not unique ontology**
   - Stable predictions or one nondistinguishing test do not yet settle which bulk story is uniquely learnable.

4. **non-uniqueness talk is not yet identifiability closure**
   - Merely naming ambiguity classes is weaker than giving a candidate-native collapse rule for them.

## What would change archive state

A future family-C lane should earn stronger identifiability credit only if it adds, in one compact route:
1. one declared native equivalence rule for reference-frame / gauge redescription,
2. one declared fixed-dictionary rule saying when observer inclusion or boundary placement counts as the same map,
3. one fixed-package distinguishability statement for surviving bulk alternatives,
4. one native abstention rule for when the correct verdict is empirical collapse rather than uniqueness,
5. and one bridge back to public records showing which of those classifications is actually witness-supported.

Without that five-part route, family C still lacks candidate-native identifiability closure.

The archive should now say something more disciplined than either “family C has multiple bulk duals” or “family C ambiguity is just gauge.”

**family-C non-uniqueness must first be triaged into reference-frame redescription, dictionary / observer-map drift, and residual empirical collapse; current literature sharpens all three classes but still does not supply the candidate-native rule that would close identifiability.** `REF-0061`, `REF-0129`, `REF-0120`, `REF-0135`, `REF-0136`
