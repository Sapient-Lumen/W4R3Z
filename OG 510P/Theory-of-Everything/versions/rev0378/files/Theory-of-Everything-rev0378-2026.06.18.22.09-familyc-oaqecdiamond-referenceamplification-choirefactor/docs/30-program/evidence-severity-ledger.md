# Evidence severity ledger

Executable source: `EVIDENCE-SEVERITY-LEDGER.json`.

Severity rows are route-local tests. They say what positive evidence must rule out, which public artifact carries the test, which negative controls are relevant, which maximum route credit is possible, and which rollback applies if the test fails.

This surface should be read before turning a future experiment, benchmark, catalog, proof, likelihood, or mission result into an empirical delta.
