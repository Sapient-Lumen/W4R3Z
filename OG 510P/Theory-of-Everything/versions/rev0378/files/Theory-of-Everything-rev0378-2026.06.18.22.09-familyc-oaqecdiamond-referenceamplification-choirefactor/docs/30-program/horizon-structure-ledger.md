# Horizon-structure ledger

Program mirror for `HORIZON-STRUCTURE-LEDGER.json`.

This ledger asks what horizon-like object is actually being invoked: event horizon, apparent/trapping horizon, Killing horizon, isolated/dynamical horizon, QES/island surface, asymptotic boundary, causal-order cut, detector/catalog proxy, cosmological horizon, or metadata-only convention.

The row is a denominator for black-hole-sector wording, not a promotion source.
