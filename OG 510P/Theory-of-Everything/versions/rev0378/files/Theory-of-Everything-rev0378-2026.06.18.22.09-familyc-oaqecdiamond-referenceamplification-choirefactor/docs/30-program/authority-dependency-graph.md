# Authority dependency graph

Executable source: `AUTHORITY-DEPENDENCY-GRAPH.json`.

This graph is generated by `make index` from the route, carrier, protocol, negative-control, promotion-gate, observed-sector, defeater, rollback, severity, and claim-binding ledgers. It records which objects support or attack which route/claim/open-question nodes.

The graph is a dependency map, not a new evidence source. Its job is to make rollback possible: when a carrier, protocol, control, quotient, or severity row fails, downstream authority can be found without rereading every markdown surface.
