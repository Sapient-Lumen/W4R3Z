# Credit-allocation ledger

Executable source: `CREDIT-ALLOCATION-LEDGER.json`.

Credit-allocation rows say how each route may spend its evidence units. They name the units, independence assumptions, shared-support clusters, current basis, maximum authority effect, no-double-counting rule, non-compensation debts, claim/open-question targets, and rollback rules.

This ledger is an anti-overcounting layer. It does not create new evidence, promote routes, or relax the candidate-identifiability state machine.
