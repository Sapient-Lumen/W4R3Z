# Calibration-traceability ledger

Executable ledger: `CALIBRATION-TRACEABILITY-LEDGER.json`
Schema: `schemas/calibration-traceability-ledger.schema.json`

This ledger records the traceability chain behind a route-local record: instrument calibration, catalog release lineage, benchmark harness, proof artifact, covariance product, frozen environment, public data release, or metadata/provenance wrapper. Traceability closure is not physical closure. It is a custody and uncertainty-propagation prerequisite for support language.
