# Source admission and eviction sieve

Use this surface when a revision is tempted to add literature.
The archive does not reward source accumulation by itself; a source earns entry only by changing continuation state.

## Admission rule

A new external source is admissible only if it does at least one of the following:
- sharpens a live claim, open question, wedge, or gate already carried in canon,
- replaces a weaker or more diffuse source with a tighter one,
- anchors a new discriminator that would actually change archive scoring,
- or compresses several citations into one cleaner canonical anchor.

If none of those happen, do not add the source.
Keep the idea in working memory for the session, not in the durable archive.

## Per-source burden of proof

Before adding a new `REF-####`, state all four items explicitly:
1. **Target surface:** which canonical document, claim, open question, or wedge will use it.
2. **Load-bearing delta:** the smallest distinction the source sharpens that the archive could not already carry honestly.
3. **Why current sources are insufficient:** what gap, ambiguity, or stale anchor remains without it.
4. **Compression payoff:** what older source, repeated explanation, or background temptation this addition lets the archive avoid.

If one of these fields is weak, the source probably has not earned entry.

## Preferred source shape

When several sources could do the same job, prefer the one that minimizes archive burden while preserving the needed claim:
- one decisive primary source beats several retellings,
- one compact review beats a scatter of background summaries when the archive only needs a map,
- one recent technical anchor beats an older diffuse overview when current posture depends on the newer distinction,
- and one archive citation with a one-line load-bearing use beats copied notes, screenshots, or retained PDFs.

The archive keeps URLs and compact reasons, not local literature hoards.

## Quotation rule

Do not quote by default.
Quote only when the exact wording itself is the object of comparison, ambiguity removal, or claim adjudication.
Otherwise keep one compact paraphrase plus the citation.

## Artifact rule

Do not retain downloaded papers, PDFs, slide decks, or other bulky source artifacts in release bundles.
Temporary scratch is allowed during a working session, but durable release state should keep only the bibliography entry and the smallest canon-facing consequence.

## Duplication rule

If two bibliography entries now carry the same archive job, keep the sharper one and evict or stop citing the redundant one.
If the exact same source is about to re-enter under a second `REF-####`, do not mint a parallel id; widen the surviving entry's load-bearing use or its live citation homes instead.
The bibliography is not a prestige ledger; it is a load-bearing support surface.

## Eviction rule

A source should be removed, demoted in use, or left uncited in future revisions when:
- its archive job is fully covered by a tighter source,
- the claim it supported has been demoted, merged, or closed in a way that no longer needs that support,
- it survives only as general background,
- it no longer has any live canonical citation home after the current revision pass,
- or it requires too much surrounding explanation relative to the actual distinction it contributes.

Eviction is a compression win, not a loss of seriousness.

## Minimal intake pattern

When adding a source, do the smallest complete thing:
1. add the bibliography entry with one load-bearing-use line,
2. wire the source into the exact canonical home that needs it,
3. update the relevant registry or workstream only if archive state changes,
4. and remove any now-redundant neighboring citation or prose.

## Refusal cases

Do not add sources just because they are famous, recent, adjacent, review-like, mathematically elegant, or politically central inside a field.
A salient archive keeps only the references that move its own discriminators.
