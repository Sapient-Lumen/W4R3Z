# Parameter-fixation gate

Purpose: split the **observed-sector recovery** credit inside `docs/40-model/matter-sector-recovery-gate.md` one step further.
A completion bid should not earn the same matter-side credit merely because it can recover the right **kind** of low-energy sector and because it can explain why the **observed parameter pattern** looks the way it does.
Shared family scaffolding and ordered routing live in `docs/40-model/completion-bid-comparison-gate-family-frame.md` and `docs/40-model/completion-bid-comparison-stack.md`; this file keeps only the pair-specific split between observed-sector recovery and parameter fixation.

## Compression verdict

The archive should now score observed-sector cash-out in **three distinct layers**:

1. **architecture recovery** — the lane recovers or sharply constrains the right gauge / chiral / generation architecture;
2. **pattern restriction** — the lane imposes real structure on hierarchies, textures, mixings, or coupling relations, so the allowed low-energy space is not arbitrarily broad;
3. **parameter fixation or explicit selection disclosure** — the lane either sharply fixes the observed values / ratios / orderings with limited extra freedom, or explicitly states which package, environmental, or dynamical selection story is still carrying the remaining burden.

A lane may earn real credit on layer 2 while still being weak on layer 3.
That is still progress.
It is just not full observed-parameter closure.

## Why this gate exists

`docs/40-model/matter-sector-recovery-gate.md` already blocked one inflation move:
**generic regime recovery pretending to be observed-sector recovery.**

A new inflation move remained too easy:
**architecture recovery or texture language pretending to be actual observed-parameter closure.**

That confusion appears whenever a completion bid is praised because it:
- realizes a Standard-Model-like sector,
- produces selection rules, texture zeros, or modular structures,
- narrows a fixed-point critical surface,
- or can fit masses and mixings after a broad package choice,

and those real gains are then narrated as if the observed couplings, hierarchies, and mixings had already been explained.

This gate keeps those credits separate.

## The three-step parameter cash-out test

### 1. Restriction

A lane earns **pattern-restriction** credit when it genuinely reduces freedom in the observed low-energy parameter sector.
Examples include:
- symmetry or geometry forcing certain couplings to vanish,
- texture relations,
- fixed-point restrictions,
- selection rules,
- or a sharply reduced family of allowed patterns.

This is stronger than mere architecture recovery.
But it is not yet observed-parameter closure.

### 2. Fixation

A lane earns **parameter-fixation** credit only when it can say something comparably sharp about the actual observed values or ordered relations.
At minimum, the archive should ask whether it can nontrivially constrain or predict some combination of:
- Yukawa hierarchies,
- mixing angles or ordered mixing structure,
- CP phases if claimed,
- gauge-coupling relations,
- neutrino-sector pattern if that sector is part of the claim,
- or other low-energy ratios / orderings with fewer effective knobs than the data being matched.

A successful fit with many package choices is not the same as fixation.
A lane should get more credit for portable relations than for one tuned successful point. Route that extra distinction through `docs/40-model/benchmark-portability-gate.md` rather than silently scoring a benchmark as lane-level closure. Then use `docs/40-model/fit-vs-prediction-gate.md` to separate accommodated fits from genuinely exposed risky surplus.

### 3. Selection disclosure

If the lane does **not** fix the observed parameter pattern, it should say what is still carrying the burden.
Typical carriers include:
- compactification or vacuum choice,
- moduli stabilization,
- landscape or environmental selection,
- dynamical attractor or relaxation stories,
- truncation or regulator dependence,
- or phenomenological input imported by hand.

The archive should not punish honest disclosure.
It should punish silent borrowing.
An explicit selection story may still earn bounded credit, but it is different from derivation.

## Common failure modes

1. **Texture inflation** — a nontrivial texture, modular form, or symmetry rule is narrated as if the observed values were already fixed.
2. **Fit inflation** — one successful benchmark point is narrated as if the parameter pattern were generically explained.
3. **Restriction inflation** — eliminating some parameter space is narrated as if the observed point had been selected.
4. **Selection smuggling** — vacuum choice, stabilization, environmental weighting, or phenomenological priors carry the result but remain implicit.

## Immediate archive rules

1. **Do not let architecture recovery count as observed-parameter closure.**
2. **Do not let texture or symmetry language count as fixation unless the observed pattern is actually constrained with low fit freedom.**
3. **Do not let one successful benchmark point count as portable explanation.**
4. **Require explicit selection disclosure whenever the observed point still depends on package, vacuum, stabilization, or environmental choice.**
5. **Keep this gate subordinate to the matter-sector gate and the main completion-bid sieve.**
   This surface sharpens observed-sector cash-out; it does not replace the separate debts on package disclosure, observables, witness closure, or cosmological burden.

## Net result

The archive now has a smaller and more honest sentence available:

> a completion bid may recover the observed matter architecture and still be weak on fixing the observed parameter pattern.

That sentence blocks another large amount of framework inflation without widening the archive.
