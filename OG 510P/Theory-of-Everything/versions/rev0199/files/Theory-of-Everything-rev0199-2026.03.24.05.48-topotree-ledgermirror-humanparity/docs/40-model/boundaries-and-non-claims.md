# Boundaries and non-claims

This archive is **not** currently claiming:

1. that one candidate formalism has already won,
2. that entanglement by itself explains geometry,
3. that gravity is proven emergent,
4. that a single equation is already visible behind current theories,
5. that cosmological boundary problems are solved by local EFT success,
6. that observer / measurement structure can be ignored until the end,
7. that decoherence by itself has already solved definite outcomes,
8. or that naming a framework counts as explanatory progress.

The archive currently treats these as live and important, but not settled.

Use `docs/40-model/local-law-vs-cosmological-boundary-split.md` when a claim starts blending special global packages into generic local-law explanation or treating local recovery as if it had already solved cosmological boundary questions.
