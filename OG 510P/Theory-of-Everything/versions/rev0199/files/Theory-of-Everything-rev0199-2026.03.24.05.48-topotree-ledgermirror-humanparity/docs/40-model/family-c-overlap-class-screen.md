## Compression verdict

The archive should now require **four declared alignments** before family-C routes are scored as convergent evidence about one bulk target:
- **frame / gauge alignment** — the routes must either use the same gauge / relational-frame convention or provide an explicit translation rule, because some reconstruction interfaces are gauge-indexed already at the point where boundary data are mapped to radial position or bulk geometry. `REF-0120`, `REF-0137`
- **observer / dictionary-map alignment** — the routes must hold fixed how the observer is encoded and where the effective boundary sits, because changing the holographic map can change what a boundary-side operator or SWAP-style test actually settles. `REF-0135`, `REF-0139`
- **recoverand-class alignment** — the routes must declare whether they are recovering metric perturbations near a fixed background, scattering-visible bulk-point structure, correlator-defined effective geometry, finite-window learned metrics, operator support, or something else; neighboring geometric readouts are not yet one target class merely because each is called “bulk reconstruction.” `REF-0128`, `REF-0130`, `REF-0131`, `REF-0138`
- **regime / cutoff alignment** — the routes must share one regime statement about asymptotics, background neighborhood, large-`N` control, frequency window, radial cutoff, and finite-`N` vulnerability before any agreement is promoted beyond route-local credit. `REF-0128`, `REF-0130`, `REF-0131`, `REF-0132`

So the correct archive move is now:
**preserve family C as a widened restricted inverse portfolio, preserve the non-uniqueness triage, and add one overlap-class screen saying that multi-route breadth is still weaker than declared convergence on one candidate-native target.**

## Why this document exists

The archive already has two sharper family-C claims than it had before:
- a widened but still restricted inverse portfolio, and
- a triage rule for family-C multiplicity.

What it still lacked was one compact discipline for a different inflation move:

> several reconstruction routes touch geometry, therefore they are converging on the same bulk target.

That step is still too fast.
Different routes may all be informative while still differing in frame choice, observer-map choice, recoverand class, or regime package.
This document prevents the archive from mistaking **portfolio breadth** for **common-target convergence**.

## The four required alignments

### 1. Frame / gauge alignment

Recent family-C work makes the gauge debt visible rather than removable.
Ji et al. show that their CMI reconstruction route requires the function `z_*(l)` to be specified as a gauge criterion before boundary real-space entanglement is mapped to bulk geometry. `REF-0137`
Thiemann's relational-reference-frame analysis sharpens the same moral at the conceptual level: apparent differences cannot yet be scored as different targets until the operational reference-frame translation into mathematical variables is declared. `REF-0120`

So one family-C route should not be said to agree with another merely because both output “a geometry.”
The archive should ask first whether they even mean the same target under the same frame rule.

### 2. Observer / dictionary-map alignment

Akers et al. already showed that changing how the observer is included can move the effective holographic boundary to the observer-environment interface. `REF-0135`
Higginbotham's 2026 observer follow-up sharpens the operational consequence: using holographic maps to define different operators can change what the same SWAP-style task lets the AdS or closed-universe observer conclude. `REF-0139`

So some apparent agreement or disagreement between family-C routes is not yet about the bulk target at all.
It may still be about which observer-map package is being held fixed.

### 3. Recoverand-class alignment

Family C now has several real inverse-style interfaces, but they do not automatically recover the same thing.
Jokela et al. recover metric deviations near a fixed AdS background from entanglement-area variations. `REF-0128`
Fan and Yang recover geometry through inverse-scattering structure from boundary correlators. `REF-0130`
Ran, Wu, and Xian learn effective geometries from finite-window Green-function data with a finite radial cutoff. `REF-0131`
Caron-Huot, Chakravarty, and Namjou show that suitably organized wavepacket correlators can reveal bulk-point structure and geometry through sharp boundary features along hyperboloids. `REF-0138`

These are neighboring interfaces.
But “metric deformation near background,” “bulk-point/scattering feature,” “finite-window learned geometry,” and “operator/map-sensitive effective description” should not yet be collapsed into one recoverand class without an explicit archive declaration.

### 4. Regime / cutoff alignment

Even after the first three alignments, family-C comparisons still remain regime-indexed.
Current routes depend on fixed asymptotics, perturbative control, selected probes, finite windows, radial cutoffs, or large-`N` structure. `REF-0128`, `REF-0130`, `REF-0131`
Terashima adds the portability brake: some subregion reconstruction stories can fail already at a logarithmic cutoff in finite `N`, so idealized route agreement is weaker than robust common-target identification. `REF-0132`

So the archive should not promote route agreement that lives only inside mismatched or idealized regimes.

## False promotions the archive should reject

1. **several geometric readouts are not yet one recoverand**
   - Similar language across papers does not yet establish one shared target class.

2. **same observable family is not yet same map**
   - Boundary-side agreement can still depend on which observer or holographic map is being used.

3. **same map is not yet same gauge-fixed target**
   - Agreement before frame / gauge alignment can still be redescription rather than convergence.

4. **portfolio breadth is not route convergence**
   - Family C can widen its inverse portfolio while still lacking any one overlap class across methods.

5. **route convergence is not identifiability closure**
   - Even a declared overlap class would still be weaker than a candidate-native sameness / empirical-collapse rule.

## What would change archive state

A future family-C lane should earn stronger convergence or identifiability credit only if it adds, in one compact route:
1. one declared overlap class spanning at least two current inverse interfaces,
2. one explicit frame/gauge translation rule inside that overlap class,
3. one fixed observer/dictionary-map convention or a declared map-translation rule,
4. one statement of what the shared recoverand is and is not,
5. one regime / cutoff / finite-`N` validity statement for the overlap class,
6. and one native sameness / empirical-collapse rule for the distinctions recovered there.

Without that six-part upgrade, family C should be scored as method-diverse but not yet convergent on one candidate-native target.

## Net result

The archive should now stop moving directly from “several family-C inverse routes exist” to “family C is converging on one identified bulk target.”
That is too fast.
The stronger and still disciplined statement is:

**family C now has a small method-diverse restricted inverse portfolio, plus a new overlap-class screen that blocks route agreement from counting as convergence until frame/gauge, observer-map, recoverand class, and regime package are explicitly aligned.** `REF-0128`, `REF-0130`, `REF-0131`, `REF-0132`, `REF-0120`, `REF-0135`, `REF-0137`, `REF-0138`, `REF-0139`
