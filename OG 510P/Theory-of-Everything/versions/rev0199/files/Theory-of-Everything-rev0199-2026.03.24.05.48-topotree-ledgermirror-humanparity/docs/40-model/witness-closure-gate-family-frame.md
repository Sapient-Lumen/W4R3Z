## Shared rule

Earlier-stage payment is real progress, not later-stage closure.
Later-stage closure does not erase remaining borrowed witness debt.
Full local public witness closure still requires candidate-native record carrier, stabilization, rereadability, publicity, challengeability, and objectivity.

## Routing

Use `docs/40-model/empirical-contact-burden-router.md` for the broad record-minimum plus witness-borrowing prerequisites, `docs/40-model/witness-package-burden-router.md` for witness-package control, `docs/40-model/witness-package-subgate-stack.md` for stage order, and the directly touched gate for the pair-specific test.
Stable, restart, and pairwise gate surfaces should name that route instead of replaying either the record-minimum / borrowing prerequisites, the stage list, or generic gate-family boilerplate.

## Authoring

If shared witness-gate scaffolding changes, edit this file, `docs/40-model/empirical-contact-burden-router.md`, the subgate-stack router, or the borrowing ladder rather than cloning new gate-family prose across many gate docs.
