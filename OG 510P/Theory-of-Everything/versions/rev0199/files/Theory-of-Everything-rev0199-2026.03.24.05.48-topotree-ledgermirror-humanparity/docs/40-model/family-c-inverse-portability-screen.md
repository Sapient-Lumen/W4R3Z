## Compression verdict

The archive should now preserve four compact points at once:
- family C no longer relies on one isolated inverse result, because recent work now gives restricted bulk recovery routes from entanglement data, from boundary two-point correlators, and from finite-window learning procedures that can extend beyond asymptotically AdS packages; `REF-0128`, `REF-0130`, `REF-0131`
- that diversification is real progress, because it shows the inverse lane is not only RT-style slogan or one privileged entanglement formula; `REF-0128`, `REF-0130`, `REF-0131`
- but every current route still depends on heavy package choices such as probe selection, fixed asymptotic or cutoff structure, finite frequency windows, training / ansatz assumptions, or near-background control rather than on a regime-free candidate-native inverse map; `REF-0128`, `REF-0130`, `REF-0131`
- and finite-`N` / localized-observer results still block any portability promotion, because subregion reconstruction can fail already at a logarithmic cutoff in `N`, while nonlocal detectability itself can be suppressed in perturbatively localized regimes. `REF-0132`, `REF-0133`

So the right archive state is now:
**method-diverse restricted inverse credit for family C, no inverse portability closure, no candidate-native identifiability closure.**

## Why this document exists

The previous family-C audit already said that restricted inverse progress is real but bounded.
What it still left open was whether that progress should be read as:
- one narrow entanglement-specific exception, or
- a wider but still bounded family-C inverse portfolio.

That distinction matters.
If the gain is only one narrow exception, it should stay almost entirely local to one paper.
If the gain is now method-diverse, the archive should preserve that broader credit honestly.
But it should do so without mistaking method diversity for closure.

## What family C has now genuinely gained

### 1. There is now more than one restricted inverse route

The archive can now point to several concrete inverse-interface routes rather than only to operator-reconstruction rhetoric.
Jokela et al. derive an explicit inversion formula from entanglement-entropy variations for ball-shaped regions to bulk metric deviations near a fixed AdS background. `REF-0128`

Fan and Yang push the inverse lane along a different observable class: boundary two-point correlators and inverse-scattering methods, including anisotropic and gauge-field cases plus a stability discussion under measurement noise. `REF-0130`

Ran, Wu, and Xian push the lane in a different direction again: finite-window Green-function data with a finite radial cutoff can be used in a data-driven learning procedure that recovers bulk metrics even beyond asymptotically AdS settings. `REF-0131`

That is enough to say the archive is no longer dealing with one lone inverse anecdote.
Family C now has a **small but real inverse portfolio**.

### 2. The gain is still portfolio-level, not portable closure

The new inverse routes do not converge on one regime-free identification rule.
Instead, each route is packaged by a different observational interface and a different control structure:
- entanglement-area variations near a fixed background, `REF-0128`
- correlator/inverse-scattering packages for selected probes and symmetry classes, `REF-0130`
- finite-window Green-function learning with finite radial cutoffs and ansatz-dependent training structure. `REF-0131`

So the archive should award broader credit than before, but only as **method-diverse restricted inverse credit**.
The gain still does not tell us that family C has one portable native inverse map across its own full target class.

### 3. Broader inverse access is not yet finite-`N` stable

Terashima provides a strong portability brake for the subregion side of the story.
In the AdS-Rindler setting, reconstructed bulk operators can cease to be well-defined in the finite-`N` theory once the UV scale crosses a critical scale proportional to `ln N`, so a bulk operator that exists in the perturbative large-`N` story need not survive as a genuine operator in the full finite-`N` quantum-gravity description. `REF-0132`

This matters because it blocks a common overpromotion:
"we have a restricted inverse route in the idealized package, therefore the inverse route is generically portable once quantum gravity is treated seriously."
The archive should now reject that jump explicitly.

### 4. Nonlocal detectability is not generic evidence of closure

Geng, Jafferis, Shrivastava, and Tata add a second brake.
They show that there are semiclassical situations where nonlocal boundary detection of a bulk excitation is efficient, but also cases where that protocol fails and nonlocality is suppressed, which they interpret as explicit examples of the emergence of a perturbatively localized observer. `REF-0133`

That means even the dramatic nonlocality often used to motivate holographic witness rhetoric is not automatically regime-portable.
The archive should therefore treat present inverse diversity as restricted interface progress, not as a generic guarantee that family C has already solved localization or witness transport.

## Why this still does not close candidate-native identifiability

### 1. The inverse routes do not yet share one native target grammar

Current routes reconstruct different kinds of bulk structure through different observational packages.
The archive still lacks one native statement of which bulk distinctions across those routes are supposed to count as the same target class.
Without that, a diversified inverse portfolio is still weaker than candidate-native identifiability closure.

### 2. Failure sets are still package-indexed

Current limitations are still described by route-specific language: background neighborhoods, frequency windows, radial cutoffs, symmetry restrictions, large-`N` assumptions, and finite-`N` breakdown thresholds. `REF-0128`, `REF-0130`, `REF-0131`, `REF-0132`
The candidate still does not provide one native rule saying which distinctions disappear because they are gauge, which disappear because the observable package is incomplete, and which disappear because the theory itself collapses them empirically.

### 3. Method diversity is not yet convergence

Several restricted inverse routes would support stronger identifiability credit only if they converged on one declared overlap class and one explicit sameness / difference rule for the recovered bulk structure.
Right now they show breadth of access, not yet closure of the inverse map.

### 4. Witness debt remains borrowed

Nothing in the new inverse portfolio removes the earlier witness-closure debt.
The decisive record carriers, rereadability, objectivity conditions, and public comparison structures still ride on the boundary/laboratory side.
So even a widened inverse lane still does not climb beyond the current family-C witness posture.

## False promotions the archive should reject

1. **three restricted inverse methods are not yet one portable inverse map**
   - Method diversity is real progress, but it is not yet regime-free inverse closure.

2. **finite-window learning is not yet generic geometry identification**
   - A trained finite-window reconstruction route still depends on cutoff, observable, and ansatz choices.

3. **large-`N` subregion reconstruction is not yet finite-`N` security**
   - A perturbative reconstruction story can fail well before generic quantum-gravity portability is earned.

4. **nonlocal detectability is not yet witness transport or localization closure**
   - A dramatic nonlocal access effect in one regime does not settle what localized observers can actually identify across regimes.

5. **portfolio breadth is not identifiability closure**
   - Family C can widen its restricted inverse portfolio while still lacking a native learnability / empirical-collapse account.

## What would change archive state

A future family-C lane should earn stronger portability or identifiability credit only if it adds, in one compact route:
1. one declared overlap class across current inverse methods,
2. one native sameness / equivalence / empirical-collapse rule for the recovered bulk distinctions,
3. an explicit statement of which route limitations are merely package-contingent and which are theory-intrinsic,
4. a finite-`N` robustness or principled finite-`N` cutoff account rather than idealized large-`N` inheritance alone,
5. and a witness story that does not simply borrow public record structure from the boundary side.

Without that five-part upgrade, family C remains a widened restricted inverse lane rather than a closed identification lane.

## Net result

The archive should now stop saying only that family C has one bounded partial-identification result.
That is too weak.
The stronger and still disciplined statement is:

**family C now has a small method-diverse inverse portfolio, but it remains packaged by route-specific observables, windows, cutoffs, and large-`N` control; finite-`N` and localized-observer brakes still block portability and candidate-native identifiability closure.** `REF-0128`, `REF-0130`, `REF-0131`, `REF-0132`, `REF-0133`
