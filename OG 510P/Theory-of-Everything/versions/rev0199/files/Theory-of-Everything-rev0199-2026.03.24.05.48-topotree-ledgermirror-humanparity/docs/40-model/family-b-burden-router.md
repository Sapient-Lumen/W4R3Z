## Shared rule

Family B should be scored in order:
- first by preserving the narrow but real equilibrium derivation clue rather than inflating it into a promoted replacement theory,
- then by forcing any beyond-equilibrium widening to cash out as named coarse-grained traces with real witness channels,
- then by keeping the witness-borrowing ceiling explicit rather than counting better bookkeeping as a ladder climb,
- and only then by asking whether any widened thermodynamic package earns bounded local-law explanatory gain rather than setup-dependent repair.

A serious equilibrium clue is not yet a promoted bridge winner.
A non-equilibrium repair term is not yet an observable-bearing gain.
A better tagged trace is not yet a reduced witness-borrowing score.
A bounded trace discipline plus a no-climb verdict is not yet a beyond-equilibrium explanatory win.

Stable, restart, and program surfaces should therefore name this router when they only need the established family-B control route.
Do not replay the thermodynamic audit, observable / record map, witness-climb audit, and beyond-equilibrium gain gate separately unless the revision is actually changing one of those subordinate surfaces.
If the issue is witness-side empirical contact across families rather than family-B pressure specifically, route through `docs/40-model/empirical-contact-burden-router.md` instead.
