## Shared rule

A later comparison-stage verdict does not erase or absorb earlier stages.
Recovery is not observed-sector fixation.
Fixation is not portable explanation.
Prediction is not rival discrimination.
Ranking is not allocation.
Convergence is not closure.

Stable, restart, and program surfaces should therefore name this stack rather than relisting each gate whenever the touched revision is only using the established order.
