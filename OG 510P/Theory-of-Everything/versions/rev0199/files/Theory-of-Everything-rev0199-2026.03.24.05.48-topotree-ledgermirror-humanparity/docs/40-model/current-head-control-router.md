# Current head control router

Purpose: canonical broad router for the archive's current theory head and default continuation control. Use this when stable, restart, or program surfaces need the archive's present model posture without separately naming the smallest current spine, the cross-family pressure router, the empirical-contact burden router, and the broad ToE credit router.

## Shared rule

Default current-head re-entry should be scored in order:
- first by reopening the smallest current problem/model spine,
- then by reopening the archive's cross-family pressure route rather than narrating one favored family or matrix cell in isolation,
- then by reopening the archive's empirical-contact burden route rather than narrating witness borrowing in isolation,
- and only then by asking how the archive's integrated broad-credit route scores any lane across local-law, cosmological-package, and witness-package books.

A compact spine is not yet a cross-family pressure verdict.
A stronger cross-family pressure route is not yet a fixed empirical-contact burden route.
A stronger empirical-contact route is not yet integrated broad ToE credit.

Stable, restart, and program surfaces should therefore name this router when they only need the archive's current head architecture.
Do not replay `spine.md`, `cross-family-pressure-router.md`, `empirical-contact-burden-router.md`, and `broad-toe-credit-router.md` as separate broad-surface obligations unless the revision is actually changing one of those subordinate surfaces.
