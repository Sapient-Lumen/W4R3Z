# Contrast-class ledger

Executable source: `CONTRAST-CLASS-LEDGER.json`.

This ledger says which rival, null, decoy, quotient, or model-class set an evidence unit is being read against. A record may be public, replayable, severe, and independently acquired while still supporting only a narrow contrast class.

Read this ledger before using words such as favors, rules out, selects, identifies, confirms, or converges.
