# Domain-of-validity ledger

`DOMAIN-OF-VALIDITY-LEDGER.json` is the executable source-domain ledger for route evidence.

Use it when a result is tempting to export beyond the regime in which it was produced. Each row declares source and target domains, preserved invariants, boundary conditions, known exclusions, domain-shift watchlists, maximum authority effect, and rollback handles.

Generated counts and cross-ledger coverage live in `docs/30-program/validity-transport-summary.generated.md`.
