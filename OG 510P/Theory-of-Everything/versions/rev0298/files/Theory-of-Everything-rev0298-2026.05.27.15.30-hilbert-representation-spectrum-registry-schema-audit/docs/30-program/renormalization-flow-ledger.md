# Renormalization-flow ledger

Machine source: `RENORMALIZATION-FLOW-LEDGER.json`.

The ledger records RG trajectories, scale parameters, running objects, coarse-graining maps, fixed-point claims, universal-quantity claims, and truncation/scheme residuals. It separates physical scale, cutoff scale, renormalization scale, radial scale, detector window, survey scale, simulator resolution, and package version.
