# Transportability ledger

`TRANSPORTABILITY-LEDGER.json` is the executable source-to-target permission ledger.

The default state is source-domain-only support. A transport row must declare source context, target context, shift variables, invariance claim, map/formula or explicit absence of one, stress test, failure effect, maximum authority effect, defeaters, and rollback rules.

A transport row can license bounded wording; it cannot promote a route.
