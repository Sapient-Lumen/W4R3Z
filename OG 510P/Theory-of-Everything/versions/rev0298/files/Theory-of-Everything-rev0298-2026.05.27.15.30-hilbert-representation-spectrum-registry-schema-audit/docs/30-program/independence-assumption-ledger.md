# Independence-assumption ledger

Executable source: `INDEPENDENCE-ASSUMPTION-LEDGER.json`.

Independence rows declare what must be true before two evidence units can be combined as independent support. They cover shared carriers, shared models, shared theory assumptions, shared nuisance stacks, shared benchmarks, shared quotients, and genuine independent challenges.

These rows are conservative by design: the default is dependence when the same target quotient, simulator, detector chain, benchmark, likelihood package, gauge/frame rule, regulator, or provenance wrapper is doing the evidential work.
