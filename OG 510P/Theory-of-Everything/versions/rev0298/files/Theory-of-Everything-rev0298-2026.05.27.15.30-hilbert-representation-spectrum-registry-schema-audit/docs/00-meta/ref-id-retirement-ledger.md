# REF id retirement ledger

## Purpose

Bibliography gaps are allowed only when they are explicit. Missing `REF-####` ids may represent retired drafts, merged duplicates, rejected low-load sources, or reserved ids that should not be recycled.

## Policy

- Never recycle a `REF-####` id.
- If a source is merged into a stronger entry, keep the missing id in this ledger.
- If a source was rejected before durable admission, keep the missing id in this ledger only if the gap already exists in a released bundle.
- New gaps should be rare and should explain why contiguous numbering was not possible.
