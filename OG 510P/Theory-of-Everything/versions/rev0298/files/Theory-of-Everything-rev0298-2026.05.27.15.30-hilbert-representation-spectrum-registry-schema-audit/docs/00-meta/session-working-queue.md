# Session working queue

## Purpose

This is a scratch routing surface for an active editing session. It is not the durable followthrough queue and should not be cited as an archive-level obligation.

## Current session notes

- Durable active tasks remain in `FOLLOWTHROUGH-QUEUE.json`; it is still empty unless a future revision deliberately adds an active item.
- Temporary ideas may be written here during a session, then either promoted into a canonical surface, merged into a receipt, or deleted before a release.
- A note here has no posture force until it is wired into a registry, claim, route row, or release receipt.

## Cleanup rule

Before packaging, leave only general scratch-policy text here. Do not ship unresolved tactical todo lists as if they were archive commitments.
