# Independence and double-counting control

Purpose: force every convergence, robustness, replication, cross-check, or variety-of-evidence claim to say what is actually independent.

`INDEPENDENCE-ASSUMPTION-LEDGER.json` records assumptions under which multiple evidence units may be combined. The archive distinguishes several cases that are often collapsed in prose:

- independent acquisition of a public artifact;
- independent analysis of a shared artifact;
- independent implementation of a shared benchmark;
- independent theory derivation using shared target assumptions;
- independent nuisance/control handling inside a shared likelihood pipeline;
- independent presentation of the same quotient or duality class;
- independent challenge by a genuine negative control.

Only the last few cases can sometimes raise the strength of a route-local test. Most of the others improve custody, replay, or robustness without adding a new line of candidate-native evidence.

## Aggregation rule

A route may aggregate evidence only after its credit row names:

```text
evidence units + independence assumptions + shared clusters + non-compensation limits
```

If two records share a carrier, protocol, nuisance model, target quotient, benchmark scorer, simulator, gauge convention, compactification choice, regulator, or metrology chain, the default posture is dependence until a declared stress test says otherwise.

## Failure mode

The blocked failure mode is:

```text
same support cluster
+ multiple papers or artifacts
+ public metadata
+ friendly benchmark agreement
= rhetorically independent convergence
```

The archive instead requires:

```text
shared-support cluster disclosed
+ independence stress test declared
+ credit-allocation row caps the route effect
```

## Relation to severity

A severe test must be more than a positive result. It must also avoid hidden dependence on the same assumptions that generated the target. Evidence-unit and independence rows therefore condition `EVIDENCE-SEVERITY-LEDGER.json`; they do not replace it.
