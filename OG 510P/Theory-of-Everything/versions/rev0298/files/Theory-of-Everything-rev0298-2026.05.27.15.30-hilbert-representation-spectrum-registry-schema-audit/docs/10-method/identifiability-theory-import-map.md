# Identifiability theory import map

## Purpose

The archive already has a candidate-native identifiability vocabulary. This surface prevents that vocabulary from becoming idiosyncratic by mapping it onto established identification, experiment-comparison, and causal-identification ideas.

## Imports

| External idea | Archive use | Supported by |
|---|---|---|
| Structural / parametric identifiability | Do not confuse a fitted surface with learnability of the target structure. Local identifiability is about the map from structure to observable law, not about a good-looking estimate. | `REF-0193` |
| Reduced-form versus structural target | Treat surrogate variables, benchmark scores, boundary encodings, and reconstruction coordinates as reduced forms unless the target quotient is declared. | `REF-0193` |
| Statistical experiment comparison | Treat a route as an experiment with information content; compare route strength by information loss, not prose force. | `REF-0194` |
| Deficiency / simulation loss | Express inverse deficiency as the loss incurred when one public or candidate-native experiment is used in place of another. | `REF-0194` |
| Causal identification | Separate observational fit from intervention-bearing target identification; do not treat a passive public record as a native experiment menu. | `REF-0195` |
| Transportability / metasynthesis | When a route imports laboratory, boundary, simulation, or frame publicness, state the transport assumptions explicitly. | `REF-0195` |
| Operational-probabilistic record language | Define states, transformations, tests, processes, and public records before choosing ontology. | `REF-0196` |

## Archive translation table

| Archive term | Formal analogue | Warning |
|---|---|---|
| `record denominator` | experiment specification / sample space / operational test family | no denominator, no cross-route comparison |
| `target quotient` | identifiable parameter modulo equivalence | no quotient, no same/different claim |
| `public bridge` | Markov kernel / transport map / operational equivalence relation | borrowed publicness must be named |
| `inverse deficiency` | information loss under attempted inversion or experiment simulation | small fit error is not the same as small deficiency |
| `residual cap` | partial-identification region / confidence set / remaining equivalence class | caps must survive summaries and releases |
| `abstention` | decision rule with no-decision region | forced best answer is not identification |
| `negative control` | adversarial model with matching positive surface pattern | no hostile decoys, no `S4` spending |

## Candidate route as an experiment

A route row should be read as:

```text
Theta_candidate / ~target  -->  X_native  -->  X_public  -->  decision or abstention
```

where:

- `Theta_candidate / ~target` is the target quotient;
- `X_native` is the candidate-native record experiment;
- `X_public` is the public record experiment or public replay object;
- the final arrow is a decision rule with declared errors, no-verdict region, and residual cap.

A strong theorem about the first arrow does not close the route if the public bridge is missing. A strong public record does not close the route if it is not native to the candidate. A good decision rule does not close the route if adversarial models collapse into the same public record distribution.

## Promotion consequences

- `S1` evidence may suggest relevance but lacks a full experiment diagram.
- `S2` evidence names the diagram but has unresolved deficiency, transport, or quotient gaps.
- `S3` evidence identifies a bounded target class under declared conditions.
- `S4` would require a native public experiment with low unresolved deficiency and survived negative controls.
- `S5` would require the same across the claimed ToE target, not merely a favored sector.

## Speculative pressure

The archive can probably replace much of its prose scoring with two quantities: a partial-identification region for the target quotient and a deficiency-like loss between the candidate-native experiment and the public record experiment. This is speculative because gravitational public records, frame-dependent observables, and code-subspace reconstruction may not satisfy classical regularity assumptions; nonetheless the import supplies a useful anti-overclaiming grammar.
