# Phase structure, order parameter, and universality discipline

`OQ-0095` makes phase, criticality, and universality language executable. A route may name a phase diagram, order parameter, critical exponent, scaling collapse, fixed point, or universality class only through the three executable ledgers:

- `PHASE-STRUCTURE-LEDGER.json`
- `ORDER-PARAMETER-LEDGER.json`
- `UNIVERSALITY-CLASS-LEDGER.json`

The rows are noncompensatory. A phase chart does not identify the order parameter; an order parameter does not establish universality; universality does not identify the candidate ontology.

## Required distinction

A route must separate the control parameters, phase boundary, diagnostic variable, finite-size/scaling behavior, universality quotient, and public-record carrier. The result remains local until the route also survives discretization, continuum, gauge, topology/signature, measure/ensemble, observed-sector, and promotion-gate controls.
