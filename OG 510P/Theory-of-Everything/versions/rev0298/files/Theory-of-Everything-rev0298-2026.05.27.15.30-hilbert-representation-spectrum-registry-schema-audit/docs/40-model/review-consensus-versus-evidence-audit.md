# Review / consensus versus evidence audit

Revision: `rev0273`

## Audit rule

Review status asks whether a community process inspected a claim. Evidence status asks whether a public record, acquisition protocol, measurement model, contrast class, validity domain, causal mechanism, selection function, capacity penalty, semantic binding, and rollback handle support the route-local claim.

Those are different questions.

## Non-identities

- publication is not replication;
- peer review is not severe testing;
- registered protocol review is not a positive result;
- collaboration release is not candidate-native ontology;
- expert consensus is not independent evidence;
- citation prestige is not no-double-counting;
- institutional custody is not route promotion.

## Practical test

Remove all author names, journals, institutions, citation counts, awards, collaborations, and consensus labels. If the route claim no longer has enough public-record and denominator support, the prior statement was social-authority laundering.
