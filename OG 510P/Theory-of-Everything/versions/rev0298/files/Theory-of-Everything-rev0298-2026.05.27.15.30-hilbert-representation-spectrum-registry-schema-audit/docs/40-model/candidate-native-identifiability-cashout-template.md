## Compression verdict

The current archive can now say the identifiability debt in one smaller, harder-to-inflate sentence:

**candidate-native identifiability is not earned by native thresholds, sharper reconstruction, policy-stable ranking, or public experimental access unless the same lane also declares a native target class, native record class, native empirical-equivalence rule, native forward/acquisition map, native inverse-completeness claim, native stability and margin budget, native abstention rule, and public bridge from those native structures to actual records.**

That sentence changes continuation state without changing closure state.
It supplies a concrete audit template for future claims while preserving the existing verdict: no current live lane clears candidate-native identifiability closure.

## Why this template is needed

The archive already had a final gate separating candidate-native threshold closure from candidate-native identifiability closure.
The remaining risk was practical rather than conceptual: future revisions could keep passing through the gate in prose, saying that a lane has better thresholds, more reconstruction, stronger decision policy, or better data access, while never writing the route that says what is actually learnable in the candidate's own variables.

This template blocks that failure mode.
It asks for one compact ledger row before promotion language is allowed.
The row may be incomplete.
Incomplete rows are useful: they say exactly where the debt remains.

## The eight-field route sheet

A candidate-native identifiability claim must be scored through all eight fields below.
A blank field is not a stylistic problem; it is the location of the debt.

| Field | Minimum content | Inflation blocked |
|---|---|---|
| 1. Native target class | The candidate-level states, couplings, geometries, frame choices, histories, sectors, or effective variables the lane claims can be identified. Mark which are exact, effective, approximate, or regime-limited. | Treating any successful output as recovery of the real target. |
| 2. Native record class | The evidence-bearing record classes in the candidate's own bridge language, plus the imported laboratory, boundary, detector, or archive-side carrier if one is still doing the stabilizing work. | Treating external record ecology as if it were candidate-native witness structure. |
| 3. Empirical-equivalence rule | The gauge, frame, counterpart, branch, coarse-graining, or empirical-collapse rule that says when two apparent targets count as the same for this route; use the equivalence-collapse protocol when this field is claimed to improve. | Counting gauge or map redescription as physical distinction. |
| 4. Forward / acquisition map | The native-to-record map plus the actual path by which public records could be obtained, prepared, or compared. Include regime, exposure, systematic, setup assumptions, finite-resource budget, nuisance controls, and no-acquisition outcome; use the acquisition-realizability protocol when this field is claimed to improve. | Treating formal observability as acquired evidence. |
| 5. Inverse-completeness claim | Whether the record route is complete, partially identifying, rank-deficient, nonunique, or only discriminating for a named subset of targets; use the inverse-completeness / stability protocol when this field is claimed to improve. | Treating separability of some alternatives as identification of the target space. |
| 6. Stability / margin budget | Finite-resolution, noise, cutoff, finite-`N`, regularization, training-ecology, no-inversion-zone, tie, and separation-margin discipline; use the inverse-completeness / stability protocol when this field is claimed to improve. | Treating a formal inverse or one stable policy as portable identification. |
| 7. Abstention / collapse rule | The native rule for returning equivalence-class, calibrated-bundle, proxy-only, underdetermined, non-identifiable, out-of-regime, no-acquisition, no-inversion, or no-verdict outcomes; use the abstention / no-verdict protocol when this field is claimed to improve. | Forcing one answer where the candidate itself should say "not identified." |
| 8. Public bridge | How the native route is connected to public rereadability, custody, challenge, replication, or at least explicitly borrowed laboratory / boundary practice; use the public-bridge challenge protocol when this field is claimed to improve. | Letting a private or package-bound route masquerade as public evidential closure. |

A lane may fill some fields well and still stop below closure.
The route sheet is not a pass/fail checklist by itself; it is a debt locator.

## Scoring rule

Use the following compact scoring rule when future revisions invoke this template.

### A. Threshold-only credit

Award only candidate-native threshold credit when a lane supplies native resolution, tolerance, or coarse-graining budgets but leaves the target class, equivalence rule, inverse completeness, or abstention boundary external or vague.

Typical sign:
- the lane says when two records count as different evidence;
- it does not yet say which candidate-level distinctions those records can actually identify.

### B. Partial-identification credit

Award partial-identification credit when a lane names a target class, a record map, and a restricted inverse claim, but only for one regime, dictionary, code subspace, frame convention, observable family, dataset ecology, or ansatz class.

Typical sign:
- the lane can identify some targets or some equivalence classes;
- it also names where the map is incomplete, unstable, or borrowed;
- if the claimed change is in inverse completeness or margin discipline, the lane fills the inverse-completeness / stability protocol rather than relying on reconstruction, fit, regularization, or benchmark success.

### C. Candidate-native identifiability credit

Award candidate-native identifiability credit only when all eight fields are declared in the lane's own bridge language and the unresolved zones are native rather than imported from generic tomography, benchmark fitting, external model selection, or ordinary lab prose.

Typical sign:
- the lane can say what is learnable, what is collapsed, what is underdetermined, when it should abstain, and how actual public records connect to that native account.

### D. Local public witness closure remains higher

Even a good identifiability route is still not full local public witness closure unless record carriers, stabilization, rereadability, objectivity, public challenge, custody, and independent evidence generation are also paid at the witness-package level.

This prevents a second inflation move: candidate-native identifiability does not erase remaining public-witness debt.

## Current-family application

### Family C

Family C is the strongest current partial case under this template.
It has real entries in several fields:
- candidate targets can be named inside bounded holographic or reconstruction packages;
- record classes can be named through boundary subregions, entanglement data, correlators, sparse data, or learned geometry routes;
- restricted inverse claims exist;
- some stability, overlap-class, surrogate, calibration, abstention, policy, and margin screens are now explicit.

But the decisive fields still remain partly borrowed or incomplete:
- target identity still depends on boundary packaging, dictionary choice, code-subspace restriction, frame/gauge convention, large-`N` control, or finite-window assumptions;
- record stabilization and public rereadability still ride mostly on boundary / laboratory infrastructure;
- empirical-equivalence and same/different rules are not yet candidate-native across the whole target class;
- inverse completeness and stability / margin remain route-limited, sometimes surrogate-bound, sometimes regularization- or training-ecology-dependent, and not yet paid through the paired inverse-completeness / stability protocol;
- abstention and no-identification verdicts now have a field-7 protocol, but Family C still borrows deferral semantics from boundary, policy, regularization, simulation, and public-record practice rather than owning candidate-native refusal closure;
- public bridge debt is inherited rather than carried by the candidate itself, and any claimed improvement now owes the public-bridge challenge protocol rather than publication, code, dashboard, boundary, or ordinary lab-publicness shorthand.

Current score: **partial-identification credit, not candidate-native identifiability closure.**

### Family B

Family B scores much earlier.
It can sharpen equation recovery, trace discipline, and semiclassical thermodynamic clues.
It does not yet supply the native record class, native inverse-completeness claim, or public bridge that this template would require.

Current score: **bounded clue / trace discipline, not identifiability-route credit.**

### Completion-bid and atlas lanes

Completion bids may have deep formal target spaces, consistency constraints, and controlled examples.
That is not enough for this template.
They must still say which observed or record-bearing distinctions identify which candidate targets, which distinctions are gauge/counterpart-equivalent or empirically collapsed, and how public records carry the comparison without hiding decisive work inside compactification choice, truncation choice, prior-volume convention, benchmark selection, or special corridor assumptions.

Current score: **cash-out debt remains upstream of candidate-native identifiability closure.**

## Failure modes this template should catch

1. **target drift** — the route starts by identifying one object and ends by scoring a different object.
2. **record import silence** — public evidence is stabilized by ordinary lab, boundary, or archive infrastructure while the candidate is credited as if it supplied the record ecology.
3. **gauge-or-frame double counting** — redescription freedom is retold as physical distinguishability.
4. **formal inverse theater** — an inverse exists in notation but collapses under finite resolution, cutoff, noise, finite-`N`, regularization, or setup variation.
5. **surrogate substitution** — the route accurately recovers a filtered, ansatz-bound, or prior-loaded surrogate and then advertises target recovery.
6. **selective safety hiding** — abstention improves retained-case cleanliness by dropping the discriminator-bearing hard cases.
7. **policy-dependent sameness** — the same/different verdict changes with loss convention, calibration policy, mixture weighting, or rival-set definition.
8. **formal-acquisition laundering** — a formal observable, dictionary output, simulation label, detector concept, or trace is counted as acquired evidence without a declared access channel, finite-resource budget, nuisance controls, and no-acquisition outcome.
9. **marginless ranking** — one candidate is ranked above another without a declared separation margin, no-inversion zone, tie policy, or pairwise diagnostic.
10. **private-bridge overclaim** — the lane identifies something inside one package but does not provide a public reread or challenge path.
11. **compensatory aggregation** — several strong fields are averaged into closure while one decisive field still remains missing, borrowed, or incompatible.
12. **unanswered-challenge durability** — replayed credit keeps supporting posture after a route-bearing challenge because the archive never classified whether the challenge was duplicate, mis-scoped, answered, damaging, or posture-freezing.

- family C is the strongest partial route and should be preserved as such;
