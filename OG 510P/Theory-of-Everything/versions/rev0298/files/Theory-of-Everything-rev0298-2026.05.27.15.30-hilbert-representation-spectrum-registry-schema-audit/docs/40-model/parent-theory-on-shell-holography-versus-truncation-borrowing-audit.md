# Parent-theory on-shell holography versus truncation-borrowing audit

This document keeps one real string-theory gain from inflating into broader completion or recovery rhetoric.
It asks what the archive should count when recent Type IIB holography work is praised not only for sharpening direct on-shell comparison, but for supposedly already delivering package independence, observed-sector portability, or witness-package relief.

## Compression verdict

The archive should now hold one tighter sentence:

**inside string / M-theory, recent Type IIB holography work earns one bounded parent-theory on-shell cash-out gain rather than package-independent recovery or closure credit. A refined PST-IIB action with a generalized topological correction extends direct ten-dimensional on-shell comparison beyond `AdS_5\times S^5` to a broader class of AdS backgrounds, including cases with non-vanishing 2-form potentials, and reproduces the expected non-vanishing holographic on-shell values in tested examples without relying exclusively on lower-dimensional gauged-supergravity truncation. That is real reduction of one specific truncation-borrowing debt inside tightly controlled holographic packages, but it is still weaker than package independence, observed-sector portability, or local witness closure.** `REF-0181`

That is not a demotion of the lane.
It is a sharper cash-out rule.
The strongest current completion bid now has one additional parent-theory / on-shell corridor, but stronger explanatory credit still owes broader low-energy transport, wider package robustness, observed-sector portability, and a less borrowed observable / witness story.

## What has genuinely improved

### 1. The archive now has one fresher direct parent-theory holography gain inside the string lane

Earlier archive posture already treated string / M-theory as the strongest current completion bid because of controlled dual examples, the archive's strongest reviewed observed-sector contact among completion bids, and several bounded low-energy gains. `REF-0034`, `REF-0167`, `REF-0168`, `REF-0173`

`REF-0181` adds a different kind of gain: one more explicit route from the ten-dimensional parent action itself to holographic free-energy comparison, rather than only to a lower-dimensional gauged-supergravity truncation. The paper starts from the longstanding fact that the conventional Type IIB pseudo-action vanishes on shell for `AdS_5\times S^5`, then extends a refined PST-style resolution to a broader class of AdS backgrounds and finds the expected non-vanishing on-shell values in tested examples. `REF-0181`

That matters because the archive prefers one concrete reduction of borrowing debt over vague claims that the parent theory “must already contain the right answer somehow.”

### 2. The gain is strongest as truncation-relief in one observable corridor, not as generic recovery

`REF-0181` does not merely restate that lower-dimensional gauged supergravity is useful.
It argues that a direct parent-theory action principle can be refined so that special holographic comparisons no longer have to lean entirely on the lower-dimensional truncation as the action-level comparison vehicle. `REF-0181`

That is useful because it sharpens a real middle layer the archive previously described only loosely:
- **broad UV-completion ambition**,
- **direct parent-theory on-shell holographic cash-out in a controlled package**,
- **generic low-energy or observed-sector recovery**,
- and **portable empirical or witness cash-out**.

The new paper materially strengthens the second layer.
It does not collapse the remaining layers.

### 3. The same gain still carries a visible package boundary

The paper's strongest statements remain tied to AdS holographic backgrounds, to the refined PST-IIB framework, and to tested examples such as the Lunin-Maldacena and `AdS_4` S-fold solutions. It explicitly presents this as a first step and notes that broader classes of Type IIB backgrounds still require further extension. `REF-0181`

So the archive should now distinguish more sharply between:
- **one direct parent-theory on-shell holography corridor**,
- **generic package-independent low-energy closure**,
- and **observed / empirical cash-out that survives broader compactification, cosmology, and witness burdens**.

## What this does **not** buy

### 1. Not observed-sector recovery or fixation by itself

The new result does not derive Standard-Model architecture, flavor data, or observed parameter values.
It sharpens action-level holographic cash-out in special AdS packages, not observed-sector closure. `REF-0181`

### 2. Not package-independent relief

Even if a direct ten-dimensional on-shell comparison is now firmer in the tested corridor, the gain still depends on a specific holographic package, action refinement, and boundary structure.
So the archive should score it as bounded truncation relief, not as generic package-independent recovery. `REF-0181`

### 3. Not witness-package relief

A sharper parent-theory holographic comparison still remains weaker than a candidate-native record-carrier story, local rereadability, or public witness closure.
This revision adds direct on-shell cash-out credit, not local empirical-contact closure. `REF-0181`

## False promotions to reject

1. **"Ten-dimensional Type IIB now directly reproduces the right observables, so string / M-theory is basically closure-complete."**
   - The new gain is a bounded parent-theory on-shell corridor, not archive-closing recovery.

2. **"Because the parent action no longer vanishes in the tested corridor, lower-dimensional truncation debt mostly disappears."**
   - The paper reduces one specific borrowing debt in special AdS packages; it does not erase wider compactification, cosmology, or observed-sector debt.

3. **"Direct parent-theory holographic cash-out already buys witness closure."**
   - Better action-level comparison is still weaker than local record carriers and public evidence transport.

## What would move the archive further

A later revision should score this lane as materially stronger only if one compact package adds most of the following together:
1. broader parent-theory action control across a wider class of holographic Type IIB backgrounds,
2. clearer transport from that direct action-level cash-out into generic low-energy or observed-sector recovery,
3. sharper evidence that the gain survives nearby admissible package choices rather than one specially prepared corridor,
4. a clearer route from those direct holographic observables into rival-discriminating or attribution-stable support,
5. and some route from that improved observable story toward witness-package reduction rather than pure formal comparison.

Without that package, the archive should preserve the gain as a bounded **parent-theory on-shell holography versus truncation-borrowing audit** and stop there.

## Net result

The archive now has a better strongest-lane sentence available:

> string / M-theory now has one additional bounded parent-theory on-shell holography gain, but that gain is still weaker than package independence, observed-sector portability, or local witness closure.

That keeps the lane genuinely strengthened without letting direct-on-shell rhetoric overclose the archive. `REF-0181`
