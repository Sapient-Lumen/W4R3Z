## Shared rule

A vacuum-energy proposal class should be scored by **which burden it actually reduces**:
- local radiative burden,
- cosmological-package / boundary burden,
- mixed debt-shift burden,
- or some bounded combination.

Moved debt is not closed debt.
No proposal class in this lane currently earns generic two-burden closure.
Self-tuning / relaxation routes now also owe an explicit **slow-physics selectivity** account whenever the claimed gain is timescale-based rather than vacuum-specific.
The measure / population / typicality lane remains standby-only residue under `CL-0049` / `AS-0035` unless it is the directly touched lane.

Stable, restart, and program surfaces should therefore name this router when they only need the archive's established cosmological-constant / vacuum-energy control route.
Do not relist the debt split, proposal-class stack, and audit-family frame separately unless the revision is actually changing one of those surfaces.
If the issue is integrated broad ToE credit rather than cosmological pressure specifically, route through `docs/40-model/broad-toe-credit-router.md` instead.
