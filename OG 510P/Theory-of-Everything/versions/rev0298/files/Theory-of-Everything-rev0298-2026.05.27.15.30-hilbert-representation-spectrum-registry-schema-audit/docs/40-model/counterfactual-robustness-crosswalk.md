# Counterfactual robustness crosswalk

Revision: `rev0269`

This surface crosswalks counterfactual robustness against existing executable layers.

A counterfactual result is spendable only when it is also:

- evidence-unit accounted,
- not double-counted,
- contrastive,
- prior/nuisance stressed,
- measured or formally transformed through a declared model,
- systematic/error bounded,
- valid in its source domain,
- transportable to its target domain if used there,
- not violating an extrapolation fence,
- and still below the route's state-machine ceiling.

Counterfactual robustness is therefore a cap/permission layer, not a closure layer.
