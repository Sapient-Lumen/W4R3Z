# Horizon thermodynamics versus information recovery audit

Black-hole thermodynamics, entropy accounting, and information recovery are neighboring but nonidentical support objects.

A route can satisfy a horizon law and still fail microstate accounting. It can match entropy and still fail endpoint control. It can reproduce a Page-like curve and still lack public-record, subsystem, and no-go-theorem closure.

The audit rule is:

```text
horizon mechanics + entropy formula + radiation proxy ≠ information recovery closure
```

The route must state which horizon object, entropy definition, radiation channel, information carrier, subsystem algebra, no-go assumptions, and public records are current.
