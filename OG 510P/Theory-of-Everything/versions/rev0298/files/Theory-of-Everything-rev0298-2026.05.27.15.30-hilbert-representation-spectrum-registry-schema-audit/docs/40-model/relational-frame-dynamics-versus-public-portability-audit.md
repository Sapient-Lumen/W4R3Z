# Relational-frame dynamics versus public portability audit

This document keeps one witness-side frame gain load-bearing without widening the archive.
It asks what the archive should count when reference-frame talk stops being mostly interpretive and instead earns an explicit relational-observable and frame-conditioned-dynamics route.

## Compression verdict

The archive should now hold one tighter sentence:

**reference-frame work has crossed the line from pure perspective rhetoric to a first bounded explicit-dynamics gain, because recent relational-observable analysis makes reference fields and gauge-fixing conditions operationally explicit while newer canonical work derives an exact evolution Hamiltonian for genuine relational observables directly from quantum constraints and frame conditions; but that gain is still weaker than cross-frame witness portability, public reference-standard closure, and local witness closure.** `REF-0120`, `REF-0179`

That means the honest archive move is neither:
- “frame-conditioned dynamics is too gauge-laden to score at all,”
- nor “one explicit relational Hamiltonian already solves public witness transport.”

The right score is in between.

## What has genuinely improved

### 1. Reference-frame choice is now more operationally explicit than a loose interpretive gloss

Thiemann's 2026 analysis sharpens the point that a physical interpretation of generally covariant calculations requires an operational mathematical definition of the reference frame, not merely an after-the-fact verbal story.
Reference fields and gauge-fixing conditions are part of the construction rather than optional commentary. `REF-0120`

That matters because the archive should score explicit frame-conditioned structure above generic “everything is relational” rhetoric.
A lane that names the operational frame package is more disciplined than one that only gestures at observer dependence.

### 2. One-frame relational dynamics can now be generated natively from the constraint package

Lin's 2026 result goes one step further: for a Dirac theory of quantum gravity with a well-defined quantum-constraint set, it gives a universal formula for the exact evolution Hamiltonian operator in a variable quantum reference frame using only the quantum constraints and frame-condition operators.
The resulting Hamiltonian generates Schrödinger evolution for genuine relational observables on the physical Hilbert space. `REF-0179`

This is real progress over a merely kinematical perspective switch.
It means at least one witness-side frame lane can now point to an explicit dynamical object rather than only to a change of descriptive chart.

### 3. Frame changes remain dynamically imprinted rather than free redescription moves

The same 2026 reference-frame analysis also sharpens a brake the archive already needed: changing reference fields or gauge-fixing conditions can change the boundary term and therefore the physical Hamiltonian, so not every frame change is a harmless relabeling inside one frozen descriptive package. `REF-0120`

That matters because the archive should not treat “same physics in another frame” as an empty phrase.
Even when two frame packages are related, the dynamical and boundary bookkeeping still has to be named.

## What this does **not** buy

### 1. Not yet cross-frame witness portability

An explicit relational Hamiltonian in one chosen frame is still weaker than a transported public fact across nearby frame changes.
The archive still needs:
- a declared fact-identity rule across frames,
- an explicit transport or reidentification map,
- and a statement of what remains invariant, what becomes frame-indexed, and where the validity class ends. `REF-0062`, `REF-0063`, `REF-0120`, `REF-0179`

So this gain belongs above loose one-frame rhetoric but below cross-frame public witness portability.

### 2. Not yet public reference-standard closure

Neither an operational frame definition nor a frame-conditioned Hamiltonian tells the archive how the shared comparison standard itself becomes public enough for multi-observer use.
Axes, clocks, adequacy thresholds, fragment standards, and calibration conventions can still be silently borrowed. `REF-0066`, `REF-0120`, `REF-0179`

So this gain is also weaker than public reference-standard closure.

### 3. Not yet local witness closure

Nothing here says where durable records live, what stabilizes them, how they are reread, or why ordinary evidence custody becomes candidate-native.
The gain is about explicit relational dynamics and frame-conditioned observables, not about public record carriers. `REF-0015`, `REF-0016`, `REF-0017`, `REF-0120`, `REF-0179`

## The archive score change

The witness-side frame lane should now remember one smaller internal distinction explicitly:

1. **perspective rhetoric** — observer or frame dependence is asserted in prose;
2. **explicit frame-conditioned relational dynamics** — one chosen frame package supports declared relational observables and a corresponding dynamical rule;
3. **cross-frame witness portability** — multiple physical observers or frame choices can recover and agree on the same coarse-grained fact under a declared transport map;
4. **public reference-standard closure** — the shared comparison standard itself becomes public enough for multi-observer use;
5. **local witness closure** — records, stabilization, rereadability, and publicity are candidate-native.

The archive does **not** need to insert a new formal stage into the global witness ladder for this.
But it should keep this internal distinction live inside `OQ-0040` and `OQ-0041`.

## False promotions to reject

1. **one explicit frame Hamiltonian is not public evidence**
   - Exact relational evolution in one chosen frame is still weaker than a public multi-observer fact.

2. **gauge-fixing discipline is not public comparison-standard closure**
   - A mathematically explicit frame package does not by itself make the standard of comparison public.

3. **relational dynamics is not record closure**
   - Genuine observables and their evolution still do not tell us where durable records live or how they are reread.

4. **same-theory redescription is not always zero-cost**
   - Frame changes can carry real boundary-term and Hamiltonian consequences, so archive scoring should not flatten them into empty rhetoric.

## What would move the archive further

A later revision should score the witness-side frame lane as materially stronger only if one compact route adds most of the following together:
1. an explicit cross-frame fact-identity rule,
2. a transport or reidentification map between frame packages,
3. a declared validity class and boundary-condition budget,
4. a public comparison-standard story rather than a merely chosen frame condition,
5. and a record-carrier / rereadability route that turns relational dynamics into public evidence.

Without that package, the archive should preserve this gain as a bounded relational-dynamics result and stop there.

## Net result

The archive now has a better brake sentence for `OQ-0040` and `OQ-0041`:

> explicit frame-conditioned relational dynamics is real progress, but it still sits below public witness portability and well below public reference-standard or local witness closure.

That keeps the gain load-bearing without letting it inflate. `REF-0120`, `REF-0179`
