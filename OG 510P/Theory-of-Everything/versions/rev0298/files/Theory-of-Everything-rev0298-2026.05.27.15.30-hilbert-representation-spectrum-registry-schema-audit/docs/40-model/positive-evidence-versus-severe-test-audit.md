# Positive evidence versus severe-test audit

Positive evidence can still be weak for identifiability.

The archive should ask:

- Did the positive result make the target more likely only inside one assumed model class?
- Would a known decoy have produced the same public pattern?
- Is the record public but the target quotient still borrowed?
- Is the acquisition replayable or merely citable?
- Did the result test a route field, or only a surrounding plausibility story?
- What would have changed if the target claim were false?

A severe test is not a strong emotion about a result. It is a declared route-local contrast class with a public artifact, negative controls, pass condition, maximum credit, and rollback-if-failed.
