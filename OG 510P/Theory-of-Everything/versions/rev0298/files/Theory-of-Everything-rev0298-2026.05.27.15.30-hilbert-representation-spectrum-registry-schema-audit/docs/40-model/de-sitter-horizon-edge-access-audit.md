# De Sitter horizon-edge access audit

This document keeps one real de Sitter / finite-region gain from inflating into generic observable or witness-closure rhetoric.
It asks what the archive should count when recent `\Lambda>0` quantum-gravity work is praised not only for clarifying one-loop horizon thermodynamics, but for supposedly already supplying a local observable package or a meaningful reduction of witness-package debt.

## Compression verdict

The archive should now hold one tighter sentence:

**inside the asymptotic / special-access lane, recent de Sitter horizon-edge work earns bounded finite-region edge-spectrum credit rather than generic local-observable or witness-closure credit. Codimension-2 horizon edge spectra have now been derived for gravity and higher-spin gauge fields in de Sitter and static Nariai backgrounds, the spectra exhibit universal shift symmetries, and in the graviton case they admit a geometric interpretation as fluctuations of the cosmic horizon. Those are real special-access gains, but they are still weaker than generic local observables, public record carriers, or local witness closure.** `REF-0180`

That is not a demotion of the lane.
It is a sharper rule for what this success actually buys.

## What has genuinely improved

### 1. The archive now has one stronger explicit finite-region / horizon-edge result in `\Lambda>0` gravity

`REF-0180` derives codimension-2 horizon edge spectra for gravity and higher-spin gauge fields in de Sitter space and in the static Nariai spacetime.
In archive terms, that matters because the result is not merely another slogan about de Sitter entropy, edge modes, or Euclidean-versus-Lorentzian mismatch; it gives a concrete spectral package for a special access window that had previously remained easier to gesture at than to compute. `REF-0180`

That is real progress.
The archive should score it above generic horizon-language rhetoric.

### 2. The lane now has one more geometric interpretation rather than only a bookkeeping correction

For the graviton, `REF-0180` interprets the relevant edge modes as fluctuations of the cosmic horizon itself, and says that this interpretation persists in the Nariai case.
That matters because the archive prefers explicit finite-region structure over purely formal partition-function repair language. `REF-0180`

This still remains a bounded gain.
But it is stronger than treating the one-loop discrepancy as a featureless normalization issue.

### 3. The special-window nature of the gain is now easier to name honestly

The same source also makes the archive more honest about what still has not been won.
The construction is tied to de Sitter / Nariai horizon settings, codimension-2 edge sectors, and one-loop thermodynamic structure with positive cosmological constant.
So the archive can now say more sharply that a special finite-region / horizon-edge observable sector is not yet the same thing as generic local observables, still less a public witness package. `REF-0180`

That is useful because witness inflation often hides behind the word “edge” as though the existence of a boundary-adjacent algebra or partition function had already solved empirical contact.

## What this does **not** buy

### 1. Not generic local observables

A horizon-edge spectrum in de Sitter or Nariai is still a special access window.
The archive still needs observable structure that is not confined to a horizon sector, one-loop thermodynamic setup, or specially chosen finite region. `REF-0180`

So this gain sits above featureless horizon thermodynamic rhetoric, but below generic local-observable control.

### 2. Not public witness closure

Nothing here says where durable records live, what stabilizes them, how they are reread, or how multi-observer evidence becomes public in candidate-native language.
A codimension-2 edge spectrum is not yet a record carrier, and a horizon fluctuation mode is not yet an ordinary public evidence token. `REF-0015`, `REF-0016`, `REF-0017`, `REF-0180`

So this result is also weaker than local witness closure.

### 3. Not a de Sitter-completion or microstate-closure promotion by itself

This revision does not turn de Sitter thermodynamic control into a finished microscopic account of de Sitter quantum gravity.
The result clarifies one special observable / partition-function sector; it does not by itself settle bulk completion, local-law transport, or witness-package debt. `REF-0180`

## The archive score change

The archive should now keep one smaller distinction explicit inside the asymptotic / special-access lane:

1. **formal horizon thermodynamic rhetoric** — horizons, entropy, or path-integral phrases are advertised without a concrete observable-sector package;
2. **bounded horizon-edge access** — one special finite-region or codimension-2 sector is computed explicitly enough to support structured edge-spectrum claims;
3. **generic local or observer-portable observables** — the lane can recover a broader observable package not confined to one special horizon setup;
4. **local witness closure** — the lane can explain how persistent public evidence is carried, stabilized, and reread without mainly outsourcing that work.

The archive does **not** need to add a new formal global witness stage for this.
But it should keep this smaller distinction alive inside `OQ-0039`.

## False promotions to reject

1. **"A computed de Sitter edge spectrum means the local observable problem is basically solved."**
   - A special horizon-edge sector is still weaker than generic local observables.

2. **"If the horizon can fluctuate geometrically, the witness package is mostly gone."**
   - Horizon fluctuations are not yet durable public record carriers.

3. **"One-loop de Sitter edge control is already microscopic de Sitter completion."**
   - The gain is a bounded special-access result, not a full completion bid or closure package.

## What would move the archive further

A later revision should score this lane as materially stronger only if one compact package adds most of the following together:
1. a route from special horizon-edge sectors to broader local observable control,
2. a declared validity class beyond one-loop thermodynamic or special finite-region setups,
3. a sharper link between edge-sector structure and bulk explanatory burden reduction,
4. an explicit multi-observer or public-evidence transport story,
5. and some route from special-access success into witness-package reduction rather than elegant bookkeeping alone.

Without that package, the archive should preserve the gain as a bounded **de Sitter horizon-edge access audit** and stop there.

## Net result

The archive now has a better special-access sentence available:

> de Sitter horizon-edge work now has stronger bounded finite-region structure credit, but a computed codimension-2 edge spectrum is still weaker than generic local observables or local witness closure.

That keeps the lane genuinely strengthened without letting special-access elegance overclose the archive. `REF-0180`
