## Compression verdict

The current archive answer is compact and negative:
- no current live bridge family or atlas lane earns **candidate-native identifiability closure**;
- family B stops much earlier, because its present gain is cleaner trace discipline rather than candidate-native record ownership, threshold closure, or inverse-map closure;
- family C is the strongest current partial case, because controlled reconstruction now includes some restricted inverse progress from boundary entanglement data to bulk deformation structure plus a first package-bound entanglement-to-dual-gravity extension, but that still does **not** close the candidate-native inverse map;
- the broader atlas of completion bids and diagnostic / reconstruction tools still lacks any compact target-to-public-record acquisition route, public-record-to-candidate-distinction route, and challengeable public bridge that would justify identifiability credit.

So the correct archive posture is:
**preserve family C as the strongest partial inverse-interface lane, preserve family B and the atlas as earlier-stop lanes, require future claims to fill the candidate-native identifiability cash-out template, and award no candidate-native-identifiability closure yet.**

`docs/40-model/candidate-native-identifiability-promotion-gate.md` now makes that posture route-level rather than merely field-level: family C can remain the strongest row without being promoted by average-strength aggregation, and record-rich or target-rich lanes can keep their local credit without becoming closure candidates.
`docs/40-model/candidate-native-identifiability-promotion-readiness-matrix.md` now makes the same posture lane-specific: family C, completion bids, laboratory / simulation routes, witness-side frame routes, and cosmological proposal classes fail for different first blockers, so their strengths should not be collapsed into one generic nearly-closed bucket.

## Why this document exists

The identifiability gate now blocks one more inflation move in principle.

Without this readout, future revisions could keep retelling stronger reconstruction, better thresholds, or stable predictions as if the new debt were already mostly paid.

## Family readout

### Family B — not yet in the native-identifiability neighborhood

Family B does not yet own native record carriers, native rereadability, or native threshold budgets.
Its present scientific gain is a stricter rule that widened thermodynamic language must cash out as named coarse-grained traces with real witness channels rather than as formal repair vocabulary. `REF-0009`, `REF-0018`
That matters, but it is still far short of candidate-native identifiability closure.
For family B, the decisive current debt is still **candidate-native witness ownership**, not native inverse-map closure.

### Family C — strongest partial case, still borrowed on the decisive inverse map

Family C does something real that no other live bridge family currently matches.
Under a controlled holographic / code-subspace package, a chosen boundary subregion can reconstruct some bulk operator content in the corresponding entanglement wedge, and restricted inverse work now sharpens that story by recovering some bulk metric deformation data from boundary entanglement variations near a fixed AdS background. A newer entanglement-driven reconstruction pass also pushes further toward a bulk scalar-potential / RG-flow package in a tightly controlled holographic setting. `REF-0020`, `REF-0127`, `REF-0128`, `REF-0160`
That is genuine access and inverse-interface structure, not empty metaphor.

But the archive should still block a stronger overclaim.
This reconstruction gain does **not** yet say, in candidate-native terms alone:
- which bulk distinctions remain gauge-equivalent, reference-frame-dependent, or branch-comparison-dependent,
- which apparent bulk differences are only identifiable after a particular boundary packaging or code-subspace restriction is fixed,
- when the right answer is an explicitly collapsed, non-unique, or underdetermined verdict rather than a unique bulk reading,
- or how partial observability, finite-`N`, closed-universe effects, or holographic dictionary ambiguities alter what can actually be learned about underlying structure. `REF-0119`, `REF-0061`, `REF-0127`, `REF-0128`, `REF-0129`

So family C is best read as the archive's strongest current **partial inverse-interface lane**.
It sharpens the boundary-to-bulk map.
It now also has a first internal ambiguity triage separating frame/gauge redescription, map-side drift, and only then residual empirical collapse.
It now also has a first overlap-class screen blocking multi-route breadth from being retold as common-target convergence before frame/gauge, observer-map, recoverand class, and regime package are aligned.
It now also has a thin-data / acquirable-witness screen blocking sparse-data geometry recovery from being retold as candidate-thick identification or already acquirable witness access.
It now also has an inverse-stability / regularization screen blocking filtered or trained route success from being retold as stable candidate-native identification.
It does **not** yet close candidate-native identifiability.

### Atlas completion bids and tools — formal depth is not yet inverse closure

String / M-theory, asymptotic safety, loop / canonical quantum gravity, causal-set programs, and bootstrap / positive-geometry tools each contribute something real: controlled examples, conservative UV ambition, background-independence pressure, discreteness pressure, or sharp consistency constraints.
What the archive still lacks for **all** of them is one compact route from thresholded public records to uniquely learnable candidate-level distinctions expressed in the lane's own bridge variables.

Until that route is explicit, the archive should keep formal richness, UV ambition, or consistency sharpness separate from candidate-native identifiability closure.

## False promotions the archive should reject

1. **reconstructable operator is not identified ontology**
   - A recoverable bulk operator class is not yet a uniquely identified candidate-level state, geometry, or history.

2. **stable prediction is not unique microstructure**
   - A lane may produce robust predictions while leaving substantial underlying structure empirically collapsed.

3. **gauge-aware formalism is not yet a same/different rule for witnessed distinctions**
   - Naming symmetry or relational observables is useful, but identifiability still fails unless the candidate says what counts as the same or different target under the actual witness route.

4. **native thresholds are not yet a native inverse map**
   - Resolution and tolerance budgets are necessary; they do not by themselves say which candidate distinctions those budgets can actually identify.

5. **formal observability is not yet acquisition**
   - A defined observable, boundary dictionary, detector concept, simulation output, or cosmological trace is not yet an acquired evidence route unless the lane names the record object, access channel, finite-resource budget, nuisance controls, and no-acquisition outcome.

6. **reconstruction is not yet stable inverse completeness**
   - An acquired record, reconstruction, fit, or regularized benchmark output is not yet candidate-native identification unless the lane names the target quotient, completeness claim, deficiency map, finite margin, robustness transport, no-inversion zone, and public audit handle.

7. **publication is not yet public bridge**
   - A public paper, code release, dashboard, boundary data set, lab record, or hosted rerun is not yet candidate-native public-bridge credit unless the lane names the bridge object, custody unit, native-to-public translation, replay path, challenge rule, terminal states, and witness-borrowing boundary.

## What would change archive state

A future lane should earn stronger candidate-native-identifiability credit only if it adds all of the following in one compact route:

1. a native target space of states, couplings, geometries, frame-choices, or histories,
2. a native equivalence / empirical-collapse rule for when different targets count as the same,
3. a native acquisition-realizability route from target to public record,
4. a native informational-completeness or partial-identification statement,
5. a native inversion-stability rule under finite resolution and noise,
6. an explicit abstention rule for when the right answer is non-identifiable,
7. an explicit public-bridge row with custody, reread / replay, challenge, terminal states, independence boundary, and witness-borrowing disclosure,
8. and a native bridge from those structures back to actual public records.

Without that eight-part route, the archive should keep identifiability credit unpaid.
