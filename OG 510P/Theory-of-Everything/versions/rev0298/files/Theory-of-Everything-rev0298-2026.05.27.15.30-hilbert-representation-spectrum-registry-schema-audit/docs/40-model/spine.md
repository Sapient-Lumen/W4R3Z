# Current theory spine

This is the archive’s current best compact model of the problem, not a final theory.

## Candidate minimal spine

A future theory of everything likely needs at least these layers:

1. **Fundamental object layer**
   - some dynamical substrate: algebraic, geometric, informational, categorical, or otherwise.

2. **Constraint / symmetry layer**
   - what is physical, what is redundancy, what is conserved.

3. **Scale and coarse-graining layer**
   - how effective descriptions arise and why they remain valid. See `REF-0003`, `REF-0004`, `REF-0005`.

4. **Geometry / gravity layer**
   - how spacetime or gravitational dynamics appear. See `REF-0006`, `REF-0008`, `REF-0009`.

5. **Entropy / information layer**
   - how horizons, entanglement, and information constraints fit into the story. See `REF-0007`, `REF-0012`, `REF-0013`.

6. **Observer / record layer**
   - how stable empirical records emerge inside the theory rather than outside it. See `docs/40-model/observer-record-minimum.md`.

7. **Cosmological boundary layer**
   - what fixes or explains global state, constants, or boundary conditions.

## Working thesis

The current archive posture is that a salient ToE may emerge not from one spectacular replacement of all current theories, but from a compact **bridge atlas** whose overlap structure becomes so constrained that only a small number of deep organizing principles remain viable.
That atlas now carries an explicit sorting rule: completion bids, bridge families, and diagnostic / reconstruction tools should not be scored as though they were the same kind of object.

## Current stop rule

When a future revision is tempted to say that some lane is broadly “closest to a ToE,” stop and ask three questions:
1. what local-law debt was actually reduced,
2. what cosmological-package debt was actually reduced,
3. what witness-package or cosmological-package debt was actually reduced, and where that reduction sits on `docs/40-model/broad-toe-credit-router.md` rather than in a hand-replayed stack of subordinate routers.

If the answer is strong on only one book, the archive should score one book, not broad closure.
Within family C specifically, if a result advertises multiple bulk readings, the archive should first ask whether the difference is a relational-frame/gauge redescription, then whether it appears only after changing the observer/dictionary map, and only then whether a fixed package still leaves empirical collapse. If several family-C methods appear to agree, the archive should then ask one more question before scoring convergence: are frame/gauge choice, observer-map choice, recoverand class, and regime package actually aligned? If a route advertises broad geometry recovery from a thin or selected data class, the archive should ask one more question before scoring witness or identifiability progress: is the relevant data class acquirable at the precision that makes the bulk conclusion meaningful, and does that route identify candidate-level differences rather than only a route-local recoverand? If a route advertises robustness under noisy data, one learned inverse package, or one regularization stack, the archive should ask one more question before scoring stable identification: does the recovered bulk verdict survive nearby filtering, training-prior, ansatz, and validity-window variation, and does the route know when to abstain rather than always output a geometry? If a route outputs a bulk geometry-like object with strong accuracy, the archive should ask one more question before scoring target recovery: is the output the candidate-native bulk target, or one declared surrogate recoverand selected by a phenomenological dictionary, large-`N` package, metric ansatz, hard constraint, or regularization stack? And if the route returns one sharp answer, the archive should ask one more question before scoring calibrated identification: is that answer actually data-forced, or is it one point estimate inside a posterior that should instead be represented as a calibrated solution bundle or an explicit abstention state? And if a route advertises uncertainty-aware behavior, the archive should ask one more question before scoring abstention-ready identification: what are the route's coverage semantics, commitment / deferral profile, and regime-shift triggers, and can it refuse rather than merely emit low-confidence geometry? And if the route now does abstain responsibly, the archive should ask one more question before scoring stronger identification: does the retained answered set still cover the discriminator-bearing hard cases, or has selective safety simply been purchased by dropping them? And if the hard cases do remain covered, the archive should ask one more question before scoring decision-ready candidate ordering: does the resulting same/different verdict survive reasonable action / loss choices and source-ecology variation, or is it still an artifact of one tuned policy package? And if the verdict does survive that policy variation, the archive should ask one more question before scoring discriminator-grade candidate separation: is the winning bulk actually separated from nearby rivals by a declared margin, no-inversion zone, or tie-robust pairwise diagnostic, or is the order still living inside a flat ambiguity band? And if the route is publicly exposed, the archive should ask one final field-8 question before scoring public identifiability: what bridge object, custody unit, replay path, challenge rule, terminal state, independence boundary, and witness-borrowing label make that exposure more than publication, code release, hosted replay, boundary access, or ordinary laboratory publicness?
