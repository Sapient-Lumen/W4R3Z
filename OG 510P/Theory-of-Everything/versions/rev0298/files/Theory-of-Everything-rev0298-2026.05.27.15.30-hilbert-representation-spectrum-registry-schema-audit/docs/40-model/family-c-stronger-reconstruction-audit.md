## Candidate claim under audit

Use the smallest stronger reconstruction claim that genuinely changes family-C posture without widening into a literature sweep:

- boundary subregion `A` is not only linked to an extremal surface,
- but can, in a controlled holographic code-subspace setting, reconstruct certain bulk operators in the corresponding entanglement wedge.

This is stronger than the RT/HRT area rule because it is about **recoverable bulk operator content**, not only area/entropy linkage. `REF-0011`, `REF-0019`, `REF-0020`

## What is genuinely gained

### 1. The interface is sharper than pure area language

The claim is no longer only that a boundary entropy quantity tracks a geometric surface.
It now says that a chosen boundary subregion constrains which bulk operator content is accessible from that subregion.
That is a real strengthening of family C's dictionary. `REF-0011`, `REF-0020`

### 2. Subregion structure remains load-bearing

As in the earlier RT/HRT audits, the split is not decorative.
The claim still depends essentially on which boundary region is chosen.
That preserves the archive's verdict that family C earns a genuine partition-sensitive surplus over generic thermodynamic language. `REF-0013`, `REF-0019`, `REF-0020`

### 3. Family C keeps more than thermodynamic bookkeeping

A thermodynamic family-B story does not by itself provide a comparably sharp rule for which bulk operators are reconstructable from which boundary subregion.
So this stronger reconstruction pass reinforces, rather than weakens, the archive's earlier conclusion that family C has a real bounded surplus. `REF-0009`, `REF-0013`, `REF-0020`

## Why this still does not climb the witness ladder

### 1. Reconstructability is not yet record carriage

Saying that a bulk operator can be represented in a boundary subregion is not the same as saying where a durable record physically lives.
The evidence-bearing record still lives in boundary degrees of freedom, apparatus couplings, environment fragments, memory chains, and other already-familiar witness substrates.
The reconstruction theorem sharpens access; it does not itself supply a candidate-native record carrier. `REF-0015`, `REF-0016`, `REF-0017`, `REF-0020`

### 2. Code-subspace redundancy is not witness redundancy

The language of encoding and reconstruction can sound close to record/objectivity language.
The archive should keep them separate.
Representational redundancy in a code-subspace or dual description is not yet the same thing as a physical account of persistent, re-readable, intersubjectively stable evidence.
So this stronger claim does not earn `WB-3`. `REF-0015`, `REF-0016`, `REF-0020`

### 3. Boundary readability is still doing the empirical work

The claim still cashes out operationally through the boundary theory and its ordinary routes to observables and records.
That means the empirical loop remains structured and useful, but still largely borrowed from the boundary/laboratory side rather than closed inside candidate-native bridge variables. `REF-0011`, `REF-0017`, `REF-0020`

### 4. The regime package remains special

This stronger reconstruction lane still depends on a heavily structured holographic setting and controlled code-subspace logic.
It is therefore a sharper special-case success, not a regime-free account of emergence, measurement, or objectivity. `REF-0011`, `REF-0019`, `REF-0020`

## False promotions to keep blocked

Do not let this audit be used to smuggle in any of the following:

- “entanglement wedge reconstruction solves the record problem,”
- “code redundancy already explains objectivity,”
- “reconstructable bulk operators are the same thing as candidate-native witness carriers,”
- or “a stronger boundary-to-bulk dictionary by itself climbs family C from `WB-2` to `WB-3`.”

## What would count as a real family-C climb

A future family-C claim should count as a real climb only if it adds at least one of the following in its own bridge language:

1. a candidate-native record carrier rather than only a reconstructable operator,
2. a stabilization story for why evidence persists,
3. a reread path that does not immediately collapse into ordinary borrowed boundary/laboratory witness talk,
4. or a genuine objectivity route that is more than code-subspace representability.

Until then, stronger reconstruction remains **interface gain**, not **witness closure**.
