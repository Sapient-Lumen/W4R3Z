# Formal proof risk taxonomy

## Main risks

1. theorem statement stronger than the actual route target;
2. hidden physical idealization inside a mathematical lemma;
3. proof assistant kernel trust mistaken for observed-sector recovery;
4. proof certificate checked for one statement but cited for another;
5. dictionary or duality translation treated as ontology identity;
6. no-go theorem scoped to a toy model retold as global exclusion;
7. metadata/lint/provenance treated as proof.

Each risk routes through `OQ-0072` and the formal-proof ledgers.
