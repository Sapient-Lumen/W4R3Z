## Compression verdict

The next hidden bottleneck after the rev0228 route ledger is **not** more confidence about reconstruction.
It is the same/different rule.

A candidate-native identifiability route cannot close while the route still borrows the rule that says whether two outputs are:
- the same physical target written in two gauges, frames, charts, dual dictionaries, or counterpart conventions;
- different target descriptions that collapse under the record route's thresholds;
- genuinely distinguishable targets with a declared margin;
- or an underdetermined class for which the right answer is no unique verdict.

Without this protocol, the archive can make two symmetric mistakes.
It can over-count formal alternatives by treating redescription freedom as physical plurality.
It can also over-count empirical success by treating one selected output as identified even though the available record route collapses several candidate targets.

## Minimum equivalence-collapse row

Any future claim that the empirical-equivalence field improved should supply one compact row before stronger credit is awarded.

| Slot | Required declaration | Inflation blocked |
|---|---|---|
| Target token | The state, coupling, geometry, operator, history, frame fact, sector, vacuum, recoverand, or candidate-ordering verdict whose identity is under test. | Letting the object under test drift across the argument. |
| Variation axis | The transformation or perturbation being compared: gauge, diffeomorphism, duality, frame change, branch/counterpart shift, code-subspace change, coarse-graining, cutoff, dictionary, ansatz, surrogate, training ecology, model-selection policy, or experimental setup. | Calling two things different without saying along which axis they differ. |
| Collapse status | One of: exact equivalence, regime equivalence, threshold-level empirical equivalence, partial degeneracy, distinguishable-with-margin, undecidable, or out-of-regime. | Treating every non-identical description as either a new physics target or a unique identification. |
| Invariant / carrier | The invariant, record class, public comparison, or preserved relation that survives the variation and carries the sameness claim. | Using equivalence language without saying what is actually invariant. |
| Boundary of rule | The package, regime, finite-resolution budget, validity window, public-record condition, or no-inversion zone under which the collapse status holds. | Exporting a local same/different rule outside its domain. |
| Abstention outcome | What the route returns when the row cannot decide: equivalence class, bounded set, tie, no-verdict, non-identifiable, out-of-regime, or request for extra evidence. | Forcing one answer where the candidate should collapse or abstain. |

The row can be incomplete.
Incomplete rows are useful because they locate the borrowed same/different machinery.
They should not be upgraded to candidate-native identifiability closure.

## Collapse classes

Use these classes before scoring an apparent distinction as physically load-bearing.

### 1. Redescription collapse

Two target descriptions collapse because the candidate itself supplies an equivalence relation: gauge orbit, diffeomorphism orbit, dual map, chart overlap, or exact frame transformation.
This is the cleanest collapse class, but only inside the declared overlap domain.
A duality or gauge rule is not a public-record rule unless the route also says how records travel through it.

### 2. Regime collapse

Two descriptions collapse only in a limit, window, approximation, code subspace, large-`N` regime, semiclassical sector, EFT regime, hydrodynamic limit, or coarse-grained scale.
This can be real progress, but it is not full target identity.
The archive should ask whether the claimed distinction reappears outside the regime and whether the route knows that boundary.

### 3. Record-threshold collapse

Two candidate targets may be different in the candidate's formal space but indistinguishable under the available public or candidate-native record class at the declared resolution.
This is an empirical collapse, not necessarily an ontological equality.
It is still decisive for identifiability credit because a route cannot identify distinctions its own records collapse.

### 4. Partial-degeneracy collapse

The records identify only a quotient, interval, bundle, posterior family, rank-deficient subspace, solution set, or equivalence class.
This is often the honest middle state for family C and for several completion-bid corridors.
The archive should preserve the partial gain while refusing unique-target language.

### 5. Policy / selection collapse

A winner, ranking, or same/different verdict may depend on the loss function, prior-volume rule, benchmark ecology, calibration policy, selective-retention rule, rival set, or tie policy.
When reasonable policy changes alter the verdict, the correct output is not candidate-native identification; it is a policy-conditioned row with a declared no-inversion or tie zone.

### 6. Public-bridge collapse

A route may have an internal same/different rule but no public reread, custody, challenge, or replication path that lets outsiders test whether that rule tracked the intended target.
This does not erase the internal gain.
It only keeps the public-bridge field borrowed.

## Field code upgrade rule

This protocol refines the `N / P / B / M` codes in the route ledger.

| Equivalence field state | Code | Meaning |
|---|---|---|
| No same/different rule is named. | `M` | Missing equivalence discipline. |
| The rule is supplied by ordinary gauge-fixing, lab practice, benchmark labels, model selection, or phenomenological prose outside the candidate's own bridge variables. | `B` | Borrowed equivalence discipline. |
| A local package, route, code subspace, dictionary, or regime supplies the rule and names its boundary. | `P` | Partial equivalence discipline. |
| The candidate's own bridge variables declare the target token, variation axis, collapse status, invariant / carrier, boundary, and abstention outcome for the claimed target class. | `N` | Native equivalence discipline for the stated regime. |

Even an `N` in this field does not by itself close candidate-native identifiability.
The route still owes target, record, acquisition, inverse-completeness, stability / margin, abstention, and public-bridge fields. The acquisition, inverse-completeness / stability, and abstention / no-verdict fields now have their own protocols so that a clean sameness rule cannot be used to smuggle formal observability, reconstruction, regularized success, or forced-answer behavior into acquired evidence or stable identification.

## Application to the current landscape

### Family C

Family C is where this protocol bites hardest.
The route often has meaningful target tokens and meaningful record proxies, but the decisive same/different rule is distributed across boundary dictionary choice, code-subspace restriction, gauge or frame convention, finite-window control, recoverand selection, and route-local policy.

For family C, future upgrades should not say only that two reconstructions agree.
They should declare:
- whether the apparent agreement is a common candidate target, a shared surrogate recoverand, a shared gauge/frame choice, a shared boundary dictionary artifact, or a threshold-level empirical collapse;
- which invariant or carrier survives the change in reconstruction route;
- where finite-`N`, cutoff, training ecology, or code-subspace changes reopen the ambiguity;
- and what no-verdict state the route returns when a bulk target sits inside a flat ambiguity band.

Current score impact: **no code upgrade yet**.
The field remains mostly `B/P` because the archive now names the test but no family-C route has supplied the native equivalence row across the relevant target class.

### Completion bids

Completion bids often have many formal target tokens and rich internal equivalence machinery.
That does not automatically solve empirical collapse.
A string vacuum, asymptotic-safety trajectory, spin-foam continuum corridor, causal-set growth law, or amplitude/positive-geometry selection result still has to say which observed or record-bearing distinctions identify which target rather than merely select, fit, or constrain a formal package.

For completion bids, this protocol asks whether many formal alternatives should be treated as empirically collapsed under present records, not as secretly distinguished by prestige or framework depth.

Current score impact: **target-rich rows remain record-poor and equivalence-borrowed** unless they declare record-bearing collapse classes.

### Low-energy laboratory and simulation lanes

Laboratory and simulation routes often have the opposite strength profile: real records, setup control, and public comparison, but no full candidate-native target space.
Their same/different rules usually compare model alternatives chosen by the experimenter.
That is valuable discriminator credit.
It is not yet native identification of a completion candidate.

For lab rows, the protocol blocks one false promotion: a clean contrast between two external alternatives should not be retold as a native equivalence rule for the underlying theory space.

Current score impact: **record-rich discriminator credit remains distinct from candidate-native identifiability.**

### Witness-side frame and observer routes

Frame and observer lanes are unusually good at exposing why same/different is not automatic.
Their debt is the public same-fact transport rule.
A frame-conditioned entropy, edge spectrum, local operator, or observer-relative record can be meaningful without yet supplying the public equivalence row that says what survives transport across frames, observers, horizons, or reference standards.

Current score impact: **frame discipline improves honesty about equivalence but still does not close public bridge or cross-frame witness portability.**

### Family B

Family B mostly stops before this protocol becomes the central question.
Equation recovery, trace discipline, and semiclassical entropy balance are not yet candidate-target identification rows.
A same/different rule for candidate-level states or histories would be a new contribution, not an implication of the present family-B clue lane.

Current score impact: **bounded clue credit remains below identifiability-route credit.**

## Future-edit rule

A future revision may claim an equivalence-field improvement only if it says all of the following:

1. which ledger row changed;
2. which target token and variation axis were tested;
3. the old field code and proposed new field code;
4. the collapse status and invariant / carrier;
5. the boundary of the rule;
6. the abstention or no-verdict outcome;
7. whether the public-bridge field changed or stayed borrowed.

If those seven items are absent, the revision may still be useful, but it should be scored as reconstruction, selection, threshold, discriminator, or record-acquisition progress rather than as candidate-native equivalence progress.

## Anti-inflation rules

Reject the following shortcuts:

1. **duality-as-identity shortcut** — a dual map inside one overlap domain is not a global same/different rule.
2. **gauge-invariant-output shortcut** — one gauge-invariant quantity is not a full equivalence rule for all target distinctions.
3. **benchmark-label shortcut** — supervised labels, synthetic truth, or benchmark classes are not candidate-native sameness unless the candidate supplies their semantics.
4. **best-fit shortcut** — the best-ranked candidate is not identified without margin, tie, and no-inversion discipline.
5. **abstention-cleanliness shortcut** — a route that abstains on hard cases has not identified the target class unless the retained set still covers the discriminator-bearing distinctions.
6. **public-record shortcut** — public records can be strong while the candidate-native target and equivalence rule remain missing.

## Net result

The archive now has a narrower operational answer to the most underpaid part of `OQ-0057`.
Candidate-native identifiability no longer merely asks for a target, record, and inverse route.
It now also demands a declared collapse row for the same/different relation itself.

That sharpens rev0228 without promoting any lane:
- family C remains the strongest partial row but still borrows decisive equivalence structure;
- completion bids remain target-rich but empirical-collapse-poor;
- laboratory and simulation routes remain record-rich but candidate-target-limited;
- witness-side frame routes remain equivalence-aware but public-bridge-limited;
- and no current lane earns candidate-native identifiability closure.
