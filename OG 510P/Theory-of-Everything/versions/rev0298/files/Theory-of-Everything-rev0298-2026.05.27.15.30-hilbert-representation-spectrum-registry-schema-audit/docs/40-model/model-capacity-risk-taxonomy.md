# Model capacity risk taxonomy

This model surface names candidate-family risks that can turn fit into overclaim: code-subspace capacity, learned inverse overfit, thermodynamic derivation elasticity, compactification/vacuum selection, RG truncation freedom, simulator target leakage, EFT cutoff tuning, apparatus tuning, catalog nuisance capacity, frame/dictionary choice, and cosmological parameterization freedom.

The taxonomy is intentionally adversarial. It asks not only what a candidate fits, but what else it could have fit had the route been tuned differently.
