# Locally covariant public-record bridge

## Purpose

The archive needs a background-sensitive locality language between fixed-background QFT and full candidate-native public records. Locally covariant QFT supplies one disciplined bridge: assign algebras to globally hyperbolic spacetimes functorially and treat fields as natural transformations (`REF-0190`).

## Why this matters

A candidate can fail public-record discipline in several different ways:

- it may define observables only on one fixed background;
- it may move observables across backgrounds without a functorial rule;
- it may have formal covariance but no public record object;
- it may have public records but only through an external laboratory or boundary substrate;
- it may treat two frame descriptions as the same fact without a declared equivalence map.

Locally covariant language helps separate those failures.

## Bridge diagram

```text
Background / spacetime category
        -> algebra or process assignment
        -> field / observable naturality
        -> record-producing operation
        -> public record denominator
```

The first two arrows are locality / covariance discipline. The last two arrows are witness discipline. The archive should not treat the first two as if they automatically closed the last two.

## Route fields

| Field | Required question |
|---|---|
| Background domain | Which spacetime or causal category is covered? |
| Morphisms | What counts as an embedding, frame change, region inclusion, or background perturbation? |
| Assigned object | Algebra, process, state space, event structure, boundary data, or detector history? |
| Naturality / covariance | What is preserved under the morphisms? |
| Relative response | How does the assigned object respond to local metric or causal changes? |
| Record production | Which operation creates a persistent trace? |
| Public equivalence | When do two transported records count as the same fact? |
| Candidate-native gap | Which part of the bridge is borrowed from ordinary QFT, lab practice, or boundary convention? |

## Promotion consequence

A functorial locality bridge can raise route discipline, but it does not by itself identify a ToE candidate. It earns at most structured partial credit until the record denominator, public equivalence rule, and inverse deficiency are declared.
