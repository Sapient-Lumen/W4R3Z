## Shared rule

A vacuum-energy proposal class should be scored by **which burden it actually reduces**:
- local radiative burden,
- cosmological-package / boundary burden,
- mixed debt-shift burden,
- or some bounded combination.

No proposal class in this stack currently earns generic two-burden closure.
Stable, restart, and program surfaces should therefore name `docs/40-model/vacuum-energy-burden-router.md` when they only need the established broad control route, and name this stack only when the proposal-class order itself is the relevant touched surface.
