# Bootstrap selection-corridor versus ontology audit

This document keeps one real bootstrap / reconstruction gain from inflating into a broader ontology or completion claim.
It asks what the archive should count when a recent AdS / CFT bootstrap result is praised not only for constraining one holographic package, but for supposedly already delivering a standalone theory of quantum gravity.

## Compression verdict

The archive should now hold one tighter sentence:

**inside the bootstrap / positive-geometry / amplitude tool lane, recent holographic consistency work earns one bounded corridor-level theory-selection gain rather than ontology or completion credit by default. A one-loop AdS$_3\times$S$^3$ CFT bootstrap result fixes `n=21` for a six-dimensional `(2,0)` supergravity correlator, matching the K3 compactification spectrum of IIB string theory, where the tree-level correlator left `n` unconstrained. That is real selection pressure and dictionary sharpening inside one controlled holographic corridor, but it is still weaker than a standalone dynamical ontology, generic low-energy recovery, or observed-sector closure.** `REF-0174`

That is not a demotion of the tool lane.
It is a sharper cash-out rule.
The archive now has one explicit case where bootstrap consistency does more than merely chart an allowed region; it picks out one discrete theory datum inside a known dual package.
But the gain still lives inside a special holographic corridor and does not yet close the ontology question.

## What has genuinely improved

### 1. The archive now has one sharper bootstrap example than a generic “consistency island” slogan

Earlier archive posture already treated bootstrap / amplitude / positive-geometry work as a high-value diagnostic / reconstruction tool because it can compress observable structure and put sharp pressure on rival formalisms. `docs/40-model/uv-completion-atlas.md`

`REF-0174` strengthens that posture with a more discrete result: strong bootstrap equations for the one-loop correlator constrain `n`, and the solution uniquely selects `n=21`, whereas the tree-level correlator did not fix `n` at all. `REF-0174`

That matters because the archive prefers one explicit corridor where consistency conditions actually choose a theory datum over vague claims that bootstrap “probably knows the right theory somehow.”

### 2. The gain is strongest as corridor-level theory selection, not as ontology

The same paper stays inside a tightly specified AdS$_3\times$S$^3$ / dual-CFT package, for the simplest four-point amplitude of `SO(n)` tensor multiplets in six-dimensional `(2,0)` supergravity, and works at one loop / order `1/c^2`. `REF-0174`

That is exactly the layer the archive needs to preserve:
- **sharp consistency pressure**,
- **corridor-level selection of a discrete datum inside a known dual package**,
- **generic dynamical completion or ontology**,
- **observed-sector or witness-bearing closure**.

`REF-0174` materially strengthens the second layer.
It does not collapse the third or fourth.

### 3. The same result still leans on a pre-existing string / holographic package

The paper's punchline is powerful precisely because the selected value `n=21` corresponds to the spectrum of IIB string theory compactified on K3, and because the flat-space limit agrees with a recently obtained one-loop amplitude. `REF-0174`

So the archive should score this as:
- **a sharper bootstrap discriminator inside one already-legible holographic lane**,
- not **an independent ontology replacing that lane**,
- and not **generic low-energy or observed-sector recovery**.

## What this does **not** buy

### 1. Not standalone completion-bid status

The result does not by itself produce a new microscopic ontology, cosmological package, or witness story.
It sharpens one holographic corridor within a known string / supergravity setting. `REF-0174`

### 2. Not observed-sector closure

Fixing `n=21` in this AdS$_3\times$S$^3$ package is real theory-selection pressure, but it is not a derivation of Standard-Model structure, low-energy couplings, cosmological data, or local witness closure. `REF-0174`

### 3. Not ontology closure from consistency alone

A sharp bootstrap selection result can still function as a reconstruction tool that borrows the meaning of the target package from a pre-existing holographic / string dictionary.
So the archive should still distinguish **corridor-level discrete selection** from **theory-complete ontology**. `REF-0174`

## False promotions to reject

1. **"Bootstrap now uniquely identifies the full theory of quantum gravity."**
   - The new gain is one bounded corridor-level selection of `n=21`, not archive-wide ontology closure.

2. **"If consistency fixes a discrete datum in one holographic package, bootstrap no longer needs the underlying string lane."**
   - The result is strongest precisely inside a pre-existing AdS / string / supergravity corridor whose interpretation remains load-bearing.

3. **"A one-loop dual-CFT selection result already beats generic low-energy recovery or witness closure."**
   - The archive still needs low-energy transport, observed-sector contact, and witness-package relief before scoring anything that highly.

## What would move the archive further

A later revision should score this lane as materially stronger only if one compact package adds most of the following together:
1. more cases where bootstrap consistency selects discrete theory data rather than only constraining a region,
2. less dependence on a pre-given string / holographic interpretation for saying what has been selected,
3. a clearer route from corridor-level selection to broader dynamical reconstruction,
4. transport into low-energy or observed-sector discriminators,
5. and evidence that the gain is not confined to one unusually controlled supersymmetric corridor.

Without that package, the archive should preserve the gain as a bounded **bootstrap selection-corridor audit** and stop there.

## Net result

The archive now has a better tool-lane sentence available:

> bootstrap / positive-geometry / amplitude programs now have one explicit corridor where consistency selects a discrete theory datum, but that remains weaker than standalone ontology, generic completion, observed-sector recovery, or witness closure.

That keeps the tool lane genuinely strengthened without letting one sharp K3-selection corridor overclose the archive. `REF-0174`
