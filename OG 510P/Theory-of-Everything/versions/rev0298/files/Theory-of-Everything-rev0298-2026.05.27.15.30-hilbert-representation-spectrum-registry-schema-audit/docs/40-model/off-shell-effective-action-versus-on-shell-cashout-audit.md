# Off-shell effective-action versus on-shell cash-out audit

This document keeps one fresh low-energy / formal-transport gain load-bearing without letting it inflate into premature observable or attribution closure.
It asks what the archive should count when a gravity lane advertises explicit effective-action control, while the same calculation still depends on background-gauge choices away from the on-shell observable surface.

## Compression verdict

The archive should now hold one tighter sentence:

**inside low-energy quantum-gravity cash-out, explicit off-shell effective-action control is weaker than gauge-honest observable cash-out. Recent gravity-plus-matter work computes the one-loop effective action in a general background gauge, confirms by the DeWitt-Kallosh theorem that the on-shell effective action is gauge-parameter independent, and uses that split to expose non-renormalizability in a gauge-honest way.** `REF-0177`

That is a real gain.
It gives the archive a cleaner way to score what formal transport buys and where it stops.
But it is still not the same thing as a gauge-invariant observable story, portable empirical attribution, or broad ToE credit.

## What has genuinely improved

### 1. The archive now has an explicit off-shell / on-shell split instead of only generic caution

Earlier archive posture already warned that completion bids and bridge lanes should not hide observables behind formal control language.
`REF-0177` sharpens that warning by giving an explicit perturbative-gravity example: the one-loop off-shell effective action depends on the background-gauge parameters, while the on-shell effective action does not. `REF-0177`

That matters because it turns a broad methodological caution into a smaller operational rule: a lane can have a technically serious effective-action calculation and still owe the archive a separate observable / attribution story.

### 2. The archive now has a cleaner non-renormalizability honesty rule

The same source uses the on-shell gauge-independence result to show more cleanly that gravity coupled to a scalar field remains non-renormalizable in a general background gauge.
For the archive, that is valuable because it blocks a quiet inflation move in which one especially convenient gauge package makes a lane look more cash-out-stable than it really is. `REF-0177`

### 3. The archive now has a better distinction between formal extraction and empirical credit

A technically controlled off-shell effective action can still be important.
But once the archive asks for observable leverage, rival separation, or theory attribution, it should care more about on-shell quantities, gauge-honest relational observables, and pipeline stability than about one preferred off-shell package. `REF-0177`

## What this does **not** buy

### 1. Not a general anti-formalism veto

The new source does **not** say that effective-action work is useless.
It says that off-shell control and physical cash-out should be scored separately.
The archive should still credit explicit formal transport work; it should simply stop overpaying it as though it were already observable closure. `REF-0177`

### 2. Not yet observed-sector or witness-package relief

Even an on-shell gauge-honest result still sits well upstream of observed-sector fixation, public record carriers, cross-site reproducibility, or candidate-native witness closure.
This revision therefore sharpens formal-to-observable discipline, not the downstream witness ladder. `REF-0039`, `REF-0058`, `REF-0059`, `REF-0177`

### 3. Not a unique-lane victory

The source is useful precisely because it is a discipline result, not because it crowns one completion bid.
It should tighten how several lanes talk about low-energy extraction and observable support, especially when they rely on effective-action language, truncation packages, or background-field bookkeeping. `REF-0166`, `REF-0177`

## The archive score change

The archive should now keep one smaller distinction explicit whenever a lane advertises low-energy gravity cash-out:

1. **off-shell formal control** — one computes or organizes an effective action in a specified gauge / background package;
2. **on-shell or relational cash-out** — the claim is expressed in a gauge-honest quantity that survives the move to physical observables;
3. **attribution-grade support** — nearby admissible packages, nuisance choices, or extraction pipelines do not erase the lane credit;
4. **witness-package relief** — the resulting quantities can actually ride a durable public evidence stack.

Current archive posture should allow real credit at stage 1 and sometimes stage 2.
It should not let stage 1 silently impersonate stages 2-4.

## False promotions to reject

1. **"An explicit off-shell effective action already gives physical observable closure."**
   - The new result says the off-shell object can remain gauge-dependent even when the on-shell story is cleaner.

2. **"One preferred background gauge is enough for stable theory attribution."**
   - The archive should now demand more explicit on-shell / relational and pipeline-stability discipline.

3. **"General-gauge technical control softens non-renormalizability debt by itself."**
   - The new result is valuable partly because it exposes that debt more cleanly rather than hiding it.

## What would move the archive further

A later revision should score this lane as materially stronger only if one compact package adds most of the following together:
1. explicit gauge-honest on-shell or relational observables rather than mainly off-shell transport,
2. stability across nearby admissible gauge, truncation, or matching packages,
3. a cleaner route from those observables to rival separation rather than one-lane rhetoric,
4. and a route from that separation to public witness-bearing evidence.

Without that package, the archive should preserve the gain as a bounded **off-shell effective-action versus on-shell cash-out audit** and stop there.

## Net result

The archive now has a better sentence available:

> explicit low-energy effective-action control can be real progress, but off-shell gauge-bound bookkeeping is still weaker than on-shell observable cash-out, attribution-grade support, or witness-package relief.

That keeps formal transport load-bearing without letting it overclose the archive. `REF-0177`
