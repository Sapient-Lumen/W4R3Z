  - Meaning: reopen the current archive state before claiming progress.

- `MV-0002` — `research-cite`
  - Meaning: add or use current external sources while preserving only compact, load-bearing trace.

- `MV-0003` — `refine-compress`
  - Meaning: reduce redundancy, sharpen definitions, and improve canonical surfaces.

- `MV-0004` — `bridge-build`
  - Meaning: connect two successful domains with an explicit recovery map or discriminator.

- `MV-0005` — `quarantine`
  - Meaning: keep a bold idea live without granting it canon.

- `MV-0006` — `promote`
  - Meaning: raise a claim or distinction into canon with explicit basis and demotion trigger.

- `MV-0007` — `package-handoff`
  - Meaning: emit a compact release object for later continuation.
