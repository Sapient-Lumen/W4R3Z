# rev0037 U-123 identity-guard limit evidence

The rev0036 identity-guard fix shape is necessary for stale deactivation if duplicate activation is permitted, but rev0037 finds it is not sufficient as the final fix shape. It does not prevent a second same-user/same-token TransferRequest from replacing a different active F-connection owner before any stale timeout fires.
