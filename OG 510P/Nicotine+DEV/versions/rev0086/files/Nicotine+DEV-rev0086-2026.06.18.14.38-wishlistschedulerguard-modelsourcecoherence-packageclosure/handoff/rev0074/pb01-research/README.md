# PB-01 research experiment — rev0074

This directory preserves the narrower origin-aware comparison patch used by the
rev0074 matrix. It is **not selected** and is not upstream contribution material.
Its purpose is to ask whether direct-over-direct replacement can be distinguished
from the legitimate direct/indirect response race.

The experiment still lacks a complete generation, liveness, reconnect, mixed-client,
and peer-identity policy. Read `docs/PB01-CURRENT-DISPOSITION-REV0074.md` before
interpreting it.
