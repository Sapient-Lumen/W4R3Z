# ID conventions

Stable ids are part of the method.

- `CL-####` — claim registry item
- `INV-####` — invariant / discipline item
- `OQ-####` — open question
- `PP-####` — prompt pair
- `REF-####` — bibliography / external reference
- `SEED-####` — session seed item

Rules:
- ids are never reused,
- ids survive renaming,
- registry docs are canonical homes,
- prose may mention ids but should not replace registry entries.

- `LX-####` — core lexicon registry entries

- `MV-####` — move registry entries
