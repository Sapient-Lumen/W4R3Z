# GPU replay reopened-residue post-arbitration-governance-retirement threshold-scope retirement witnesses, settled, window-expired, authority-return, history-freeze, successor-handoff, residue-quarantine, and mixed retirement

This is the compact successor surface for `OQ-0205`.

`rev0311` answers the question: how does threshold-bounded governance retire without becoming permanent scope machinery? The answer is not a standing retirement court. It is a packet-local retirement witness that records why scoped threshold governance is closed, expired, handed off, quarantined, or reduced to nonbinding history.

## Working pressure

`rev0310` admitted a compact threshold-scope family for post-arbitration-governance-retirement governance pressure. That was enough to bind threshold governance to a packet, closeout-history row, authority lane, successor route, retirement window, or mixed bounded scope. It did not say how the scoped threshold surface itself retires after the bounded use has been discharged.

Without a compact retirement witness, two bad moves remain tempting:

- threshold scope persists as permanent authority merely because it once had a bounded use;
- threshold scope vanishes without retaining the history, lane return, successor handoff, or residue quarantine facts needed by later packets.

## Token semantics

### `settled-post-arbitration-governance-retirement-threshold-scope-retirement`

Use when the scoped threshold-governance task has been satisfied inside its named packet, history row, lane, route, or retirement window. The surviving record is a nonbinding closeout fact, not a live authority surface.

### `window-expired-post-arbitration-governance-retirement-threshold-scope-retirement`

Use when the retirement window named by the prior scope witness has elapsed. The witness preserves the expiration fact and prevents silent renewal by inertia.

### `authority-return-post-arbitration-governance-retirement-threshold-scope-retirement`

Use when the authority lane that temporarily carried threshold governance returns to its ordinary owner, baseline receipt, or successor packet. The token must name what authority returned and what did not travel.

### `history-freeze-post-arbitration-governance-retirement-threshold-scope-retirement`

Use when closeout history remains inspectable as nonbinding audit residue but no longer decides future packets by itself. This token is for history preservation without live governance.

### `successor-handoff-post-arbitration-governance-retirement-threshold-scope-retirement`

Use when a named successor surface receives only a narrow unresolved question, warning, or handoff duty. The successor must not inherit the whole retired governance surface.

### `residue-quarantine-post-arbitration-governance-retirement-threshold-scope-retirement`

Use when something remains unresolved after retirement, but the remainder is quarantined as residue rather than preserved as a standing court, vault, or board.

### `mixed-post-arbitration-governance-retirement-threshold-scope-retirement`

Use only when multiple retirement shapes are genuinely present and cannot be collapsed without hiding evidence. The receipt must name each branch and the fail-closed repair.

## Retirement rule

Retirement preserves history, returns authority, names residue, and closes the scope. It must not create a standing body whose job is to decide future scope.

The retirement witness is admissible only after a prior `gpu_replay_cross_observer_custody_exit_appeal_precedent_tiebreak_registry_reopened_residue_post_closeout_portability_drift_conflict_arbitration_retirement_governance_retirement_portability_drift_conflict_arbitration_retirement_governance_retirement_portability_drift_conflict_arbitration_retirement_governance_threshold_governance_scope_state` token has named the scoped threshold-governance surface. It cannot be used to skip threshold, scope, closeout-history, lane, route, or window evidence.

## Currentness and decay guard

This packet is coupled to the `rev0311` currentness repair. A retirement token is not current merely because it appears in a latest receipt. Currentness requires that stale `current_*` fields, overdue decay-watch horizons, postureless open questions, and old queue debt are surfaced rather than silently trusted.

## Self-sufficiency assay hook

A cold re-entry reader should be able to answer five questions from compact surfaces alone: current head, live question, resolved question, forbidden move, and next safe move. The new `SELF-SUFFICIENCY-LEDGER.json` records that assay so retirement machinery is tested for legibility rather than only exact-token presence.

## Fail-closed rule

If threshold-scope retirement is unclear, freeze the old scope as nonbinding history, return ordinary authority, quarantine residue, or open the successor `OQ-0206`. Do not promote a `permanent-threshold-scope-court`, `scope-history-vault-by-retirement`, `authority-lane-board-by-closeout`, `successor-route-senate-by-retirement`, or `retirement-ish-governance` surface by default.
