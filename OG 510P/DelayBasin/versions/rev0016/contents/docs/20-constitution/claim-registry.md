# Claim registry

These are working claims, not eternal truths.

- `CL-0001` — A method archive must keep **practice / observation / mechanism / speculation / disagreement** distinct or it will launder its own uncertainty.
  - Status: accepted working discipline
  - Wired docs: `docs/10-method/practice-observation-mechanism-speculation.md`

- `CL-0002` — Prompt pairs are **state-transition operators** in archive evolution and must be preserved as first-class artifacts.
  - Status: accepted working discipline
  - Wired docs: `docs/50-promptcraft/prompt-pairs.md`, `docs/20-constitution/prompt-pair-registry.md`

- `CL-0003` — Some repository hygiene is causally load-bearing because it changes the recurrence conditions for later turns.

  - Status: speculative but central
  - Wired docs: `docs/30-speculation/exosomatic-delay-embedding.md`
