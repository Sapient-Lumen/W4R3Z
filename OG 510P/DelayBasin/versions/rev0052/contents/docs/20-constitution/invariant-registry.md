# Invariant registry

- `INV-0001` — Every substantial claim must carry a status orientation:
  `observed`, `inferred`, `speculative`, `adversarial-countermodel`, or `quarantined-wild-speculation`.

- `INV-0002` — Every new doc must be linked from `docs/README.md`.

- `INV-0003` — Every new prompt pair must get a stable `PP-####` id and registry entry.

- `INV-0004` — The archive must preserve at least one explicit disagreement surface.

- `INV-0005` — Each revision should add at least one ratchet:
  a guardrail, a clarified distinction, a refined open question, a new prompt pair, or a new canonical surface.

- `INV-0006` — External research may sharpen the archive, but it must not silently replace archive-internal observations.

- `INV-0007` — Release artifacts must remain small enough to hand off and inspect.

- `INV-0008` — The archive must not pretend repo hygiene is causal unless it can point to a plausible mechanism or observed effect.

- `INV-0009` — Risky transformer-facing speculation is allowed and encouraged, but if its status is too weak for canon it must enter quarantine rather than leak upward implicitly.

- `INV-0010` — A bounded constitutional state should preserve the current load-bearing control lexicon needed for faithful re-entry, not just generic summary prose.

- `INV-0011` — Portable state surfaces must preserve structural fidelity: bounded state, stable ids, and generated context-pack entries may not silently degrade through formatting accidents.

- `INV-0012` — If a handoff surface claims to be portable project state, it should preserve typed continuation structure where applicable: workflow request, bounded state/resources, and deterministic checks/tools should not be silently collapsed together.

- `INV-0013` — If the archive relies on local control language, certified core terms and provisional/private handles must remain distinguishable; provisional terms may not silently masquerade as certified canon.
- `INV-0014` — If the archive relies on certified move classes, revisions should be able to name which move classes they instantiated; otherwise procedural admission collapses back into vibe.
- `INV-0015` — If a revision promotes or demotes canon-level trust, the archive should preserve the promotion contract or demotion reason explicitly enough that later sessions can tell why the status changed and what could reverse it.

- `INV-0016` — If a canon-level claim depends materially on fresh external literature or fast-moving ecosystem state, the archive should either preserve a compact temporal-validity / decay-watch posture for it or keep it below canon.


- `INV-0017` — If the archive claims a recovery route back to legitimate continuation, it should preserve a small recovery kernel and an explicit recovery move rather than treating recovery as a vague promise.


- `INV-0018` — If the archive claims a revision counted as legitimate progress, it should preserve a compact revision receipt naming move classes, status changes, refs used, and checks passed rather than leaving admissibility implicit in prose alone.


- `INV-0019` — If a substantial revision had a real nearby rejected alternative, the archive should preserve a compact counterfactual shadow rather than letting the accepted move erase the local decision boundary.


- `INV-0020` — If the archive claims stable continuation-regime re-entry, it should preserve at least one discriminating probe or countermodel rather than treating stylistic continuity as sufficient evidence.


- `INV-0021` — If the archive claims a public hidden state / re-entry ABI, it should keep **state packet**, **evidence packet**, and **check packet** explicitly distinguishable rather than letting “state” absorb arbitrary text.



- `INV-0022` — If the archive claims a public belief state under partial observability, it should preserve uncertainty, rewrite/demotion pressure, and rival explanations explicitly rather than reducing the state packet to retained facts.

- `INV-0023` — If the archive claims innovation-packet / reconciliation discipline, it should name the anchor revision or state surface and the local correction explicitly rather than relabeling recap as novelty.


- `INV-0024` — If the archive claims a compression or innovation win, it should name the relevant **distortion target** and at least one **mismatch / prior-intrusion risk** rather than treating shorter text or cleaner reconstruction as sufficient evidence of fidelity.


- `INV-0025` — If the archive claims a substantial belief update or surprise-driven rewrite, it should preserve the **trigger**, intended **update gain**, and at least one **challenge probe** or rival explanation rather than treating revision force as self-justifying.


- `INV-0026` — If the archive claims witness-set / boundary-panel discipline, it should preserve the **property discriminated** and an expected **drift signature** rather than treating named examples as self-explanatory.


- `INV-0027` — If the archive treats non-movement as meaningful, it should preserve the **anchor held fixed**, the **blocker**, the chosen **brake posture** (`hold`, `abstract`, or `recover-resync`), and the **unlock condition** rather than hiding the decision inside vague caution.



- `INV-0028` — If the archive claims sentinel-panel / reopen-canary discipline, it should preserve the **property monitored**, the **expected deviation signature**, and what continuation action follows if the canary trips rather than treating a named canary as self-justifying.



- `INV-0029` — If the archive claims dual-control revision / identification-packet discipline, it should preserve the **rival hypothesis split**, the **observation sought**, and the **continuation decision gated** rather than treating "more probing" as self-justifying.


- `INV-0030` — If the archive claims timescale stratification / consolidation-lane discipline, it should preserve at least one explicit **lane classification** and **transfer rule** (`refresh`, `consolidate`, `demote`, or `expire`) rather than treating “memory” as undifferentiated persistence.



- `INV-0031` — If the archive claims phase-boundary / rollover-packet discipline, it should preserve what phase just ended, what **persists**, what **resets / cools / retires**, and what new operating question or posture now governs ordinary continuation rather than treating segmentation as a decorative heading.


- `INV-0032` — If the archive invokes coordinate-loaded mechanism language — e.g. vectors, basins, charts, tangents, holonomy, support vectors, or atlases — it should preserve at least one **invariant claim**, observable, or operational contract that should survive a chart switch, plus any chart-specific remainder, rather than letting one coordinate choice masquerade as the phenomenon itself.



- `INV-0033` — If the archive claims that two short revision paths, orderings, or chart switches should preserve the same operative consequence, it should preserve the **shared anchor**, the **compared paths**, the **closure target**, and what mismatch would count as material **closure error** rather than assuming commutation by prose alone.


- `INV-0034` — If the archive claims a continuation margin / guard band for a load-bearing local object, it should preserve the **protected property**, the relevant **perturbation family**, and the first **failure signature** that would justify bounded rollback, a hold packet, or `recover-resync` rather than treating “robustness” as a prestige synonym for confidence.



- `INV-0035` — If the archive claims that some phrase, id, prompt pair, witness panel, canary, or other surface functions as a real steering handle, it should preserve the **actuator surface**, the **target property**, the rough **effort scale**, and the expected **leakage or endogenous-resistance signature** rather than letting control-handle language float as prestige.


- `INV-0036` — If the archive claims balanced archive-reduction / dual-salience discipline, it should preserve the surface's **observation role**, **control role**, and **truncation consequence** rather than treating bounded-state selection as taste, frequency, or elegance.


- `INV-0037` — If the archive invokes "memory" in a load-bearing way, it should preserve whether the surface is functioning as a **memory store**, a **regime-reentry packet**, or a **check/admission object** rather than letting storage, continuation state, and validity checks silently masquerade as one thing.


- `INV-0038` — If the archive claims predictive-state / test-sufficient-packet discipline, it should preserve the relevant **future test or intervention family**, the **continuation decision supported**, and at least one **failure signature** that would show the packet no longer answers that family cheaply enough to justify bounded-state residency.


- `INV-0039` — If the archive claims future-equivalence / causal-partition compression, it should preserve the relevant **future family**, the **continuation decision held invariant**, and the first **lost distinction** that would show the merge or collapse was too aggressive rather than treating compression as self-justifying.

- `INV-0040` — If the archive claims intervention-equivalence / causal-control-packet discipline, it should preserve the relevant **intervention family**, the **target property or continuation decision** meant to stay invariant, and the first **branch divergence / passive-alias risk** that would show two surfaces were only observationally similar rather than safely mergeable.

- `INV-0041` — If the archive claims homing-packet / adaptive-distinguishing-probe discipline, it should preserve the **ambiguity class**, the **probe family or branch rule**, the **orientation/update rule**, and the **stop or escalation condition** rather than treating “ask a few probes” as self-justifying.

- `INV-0042` — If the archive claims probe-economics / value-of-information discipline, it should preserve the **candidate probe family**, the **gated continuation decision**, the rough **cost class**, the expected **split power**, the **nearest deferred alternative**, and the **stop or escalation rule** rather than treating “this seemed like a good probe” as self-justifying.

- `INV-0043` — If the archive claims stopping-packet / sequential-threshold / commit-certificate discipline, it should preserve the **ambiguity class**, the **decision threshold or commit criterion**, the **licensed continuation action**, the **tolerated error / rollback posture**, and the **budget-exhaustion fallback** rather than letting “enough evidence” float as prose confidence.


- `INV-0044` — If the archive claims continuation-monitor / evidence-process discipline, it should preserve the **monitored property or ambiguity split**, the **accumulating evidence state or score**, the **update or shrink rule**, the **reset or stitching rule**, and the **coupling to stop rule / hold posture** rather than letting “growing confidence” float as prose mood.

- `INV-0045` — If the archive claims an observer/actuator split or treats a surface as both steering handle and readout, it should preserve the **observer surface**, the **actuator surface**, the **allowed coupling**, the **independent witness / canary / check**, and the main **self-certification risk** rather than letting a potent local handle become its own judge.

- `INV-0046` — If the archive claims that a handle, witness, or privileged prompt surface is load-bearing beyond generic prompting effects, it should preserve the **active surface**, the **matched sham / negative control**, the **expected differential signature**, the **pass/fail rule**, and the **retire / escalate rule** rather than letting vivid wording, position privilege, or familiarity silently masquerade as real leverage.


- `INV-0047` — If the archive claims blind-packet / label-scrubbed-adjudication discipline, it should preserve the **judged artifact / property**, the **scrubbed or relabeled view**, the **hidden metadata / authorship / handle identity**, the **reveal / unblinding rule**, and the **disagreement / escalation consequence** rather than treating “we reviewed it more objectively” as self-justifying.


- `INV-0048` — If the archive claims execution-witness / substrate-perturbation discipline, it should preserve the **judged effect / continuation property**, the relevant **substrate family**, the **fixed controls / allowed perturbation**, the first **divergence signature**, and the **rerun / escalation consequence** rather than treating one successful run as if visible text alone determined the result.

- `INV-0049` — If the archive claims assistant-echo-filter / self-carry-omission discipline, it should preserve the **judged task / continuation property**, the **kept user-side anchor / retained evidence surface**, the **omitted or thinned assistant-side surface**, the expected **invariance or gain signature**, and the **reinclusion / escalation consequence** rather than treating all prior assistant prose as if it were neutral memory or necessary evidence.


- `INV-0050` — If the archive claims reasoning-firebreak / scratchpad-quarantine discipline, it should preserve the **judged task / decision / continuation property**, the **public extract / compact residue kept in canon**, the **trace or scratchpad surface withheld / thinned / quarantined**, the **allowed role**, and the **exposure / reinclusion / escalation consequence** rather than letting long rationale text silently become explanation, evidence, memory, and control surface at once.


- `INV-0051` — If the archive claims that several witnesses, judges, probes, or challenge passes count as cumulative evidence, it should preserve the **witness family / probe family**, the main **shared-origin coupling / dependence structure**, the rough **effective evidence weight / discount rule**, **what still counts as genuinely new evidence**, and the **stop / escalation consequence** rather than letting raw agreement count silently stand in for independent corroboration.


- `INV-0052` — If the archive claims that a recap, paraphrase, compressed rewrite, or stitched restatement has earned source-of-truth authority, it should preserve the **source packet / authority anchor**, the **rewritten packet / compressed rewrite**, the **round-trip or cross-exam witness**, the expected **divergence signature**, and the **promotion / demotion / rollback consequence** rather than letting a fluent rewrite silently replace the source it was supposed to preserve.


- `INV-0053` — If the archive claims that a packet, prompt pair, or re-entry surface functions as a stable loader for operative state, it should preserve the **interface surface / claimed loader**, the **supported model-wrapper-context family**, the **minimal conformance test or metamorphic check family**, the first **non-conformance / drift signature**, and the **narrowing / demotion / fallback consequence** rather than letting repeated local success silently stand in for interface stability.

- `INV-0054` — If the archive claims that a packet, prompt pair, or evidence bundle is load-bearing as a bounded-state surface, it should preserve the **full candidate surface**, the **proposed support core**, the **smallest ablation / removal family**, the **tolerated degradation / continuation margin**, and the **prune / promote / rollback consequence** rather than letting repeated success silently protect decorative or distractive ballast from being tested.



- `INV-0055` — If the archive claims that a reduced packet, support core, or public extract is enough for re-entry, it should preserve the **candidate reduced packet / replay seed**, the **core-only replay surface**, the **fixed or withheld context family**, the **target continuation property / tolerated degradation**, and the **reinflate / fallback / quarantine consequence** rather than letting one successful larger-context continuation silently certify sufficiency.
