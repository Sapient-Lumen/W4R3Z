# Rev0993 authority incidents

- An initial rev0993 draft retained targeted payload access for the network-session lifetime. The retention audit showed that this capability conservatively rooted every current payload. That draft was removed before the frozen source; no validation result from it is release authority.
- Some foreground CTest pipelines remained open after the tested process had completed because process-test descendants inherited the command output pipe. Tests were re-executed with regular-file logging and hard bounds; only terminal per-test or detached full-lane records are counted. No timeout or interrupted parent command is represented as a test failure or success.
- The sanitizer folder-owner executable continued at high CPU after a tool-channel timeout and completed 536 checks. The authoritative sanitizer product lane was therefore detached to regular-file logging and reached a terminal 43/43 result with the requested ASan/UBSan settings.
