The implementation was reconstructed from the sealed rev0994 package plus independently hashed reviewed patches and a full-source tar.

- A redundant direct sanitizer rerun of the already-passing folder-owner product test was killed by the same external cleanup class and is excluded. The complete neutral sanitizer product lane, including that test, passed 44/44.
- Python bytecode accidentally created while computing a preliminary projection was detected and removed. The discarded 607-file preliminary projection is not authority; the sealed projection is 602 files and contains no Python cache artifacts.
