# Rev1019 authority incidents

Two inherited registry processes were running against binaries behind the reviewed source. They were terminated and their output is excluded. The exact final source was rebuilt and replayed separately.

The rev1018 wrapper's release gate, manifest, and evidence still identify rev1017 and it contains a Python bytecode cache. Only its physical hash and Git-recorded source baseline are used.

One first reconstruction check compared filesystem permission bits produced under different default ACL behavior. The retained proof instead initializes a Git index from the parent archive, applies the binary patch, and requires the resulting Git tree object to equal the final tree exactly.
