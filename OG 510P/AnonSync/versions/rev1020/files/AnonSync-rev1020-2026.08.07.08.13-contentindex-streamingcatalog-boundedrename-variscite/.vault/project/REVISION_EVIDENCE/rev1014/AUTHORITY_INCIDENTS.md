# Rev1014 authority incidents

Several late or orphaned validators used mutable, discarded source trees and consumed CPU, memory, or build paths. One queued cleanup erased an isolated source and build pair after completed results had been recorded. All such trees, binaries, logs, and interrupted commands are excluded.

The final source authority lives in a durable isolated Git directory and reconstructs from the sealed rev1013 parent. GCC and Clang terminal results are bound by exact source lineage and independent log hashes; the known interleaved build log is retained only as excluded forensic evidence.
