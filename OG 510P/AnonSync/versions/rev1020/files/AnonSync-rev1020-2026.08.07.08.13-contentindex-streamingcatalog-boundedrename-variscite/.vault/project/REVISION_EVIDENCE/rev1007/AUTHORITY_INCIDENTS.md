# Rev1007 authority incidents and exclusions

The first bounded source-projection integration closed TLS after every preparing
response. A one-shot source process could therefore lose its process-local
projection before sending any range. That shape and its results are excluded;
the retained implementation collapses bounded preparation turns on the same
authenticated stream while round-trip budget remains.

The first TLS observer also double-counted preparing responses. The service
session retains its direct counter, while the TLS result now counts each emitted
response exactly once in the canonical response observer.

Several aggregate CTest invocations were interrupted by the cloud execution
wrapper. A brief suspicion that a child process retained capture descriptors was
not substantiated and is not claimed. Only detached terminal logs, the fresh
557-edge GCC graph, the fresh 268-edge sanitizer graph, and their completed
replays are release authority. Incremental development objects are excluded.
