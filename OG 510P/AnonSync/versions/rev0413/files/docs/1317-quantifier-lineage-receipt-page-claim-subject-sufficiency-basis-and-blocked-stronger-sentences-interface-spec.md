## Quantifier lineage receipt

### Receipt purpose
Give later operators one place to verify **who the sentence was about, what threshold made it true, and what stronger claim was refused**.

### Receipt fields
- claim family
- subject set
- audience set
- sufficiency rule
- horizon
- evidence basis
- excluded counterpart set
- current strongest honest sentence
- blocked stronger sentence
- reopen conditions

### Minimum examples
- `Fetchable now because at least one online source peer with the needed bytes was witnessed. Not proven on all peers.`
- `Removed from linked devices under this identity. Not proven absent from nonlinked remote peers.`
- `Approved under only-new-peers policy using remembered certificate continuity. Not proven under all-peers policy.`
