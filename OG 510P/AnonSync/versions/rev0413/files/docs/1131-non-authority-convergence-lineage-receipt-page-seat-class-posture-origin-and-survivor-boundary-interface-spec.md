# Non-authority convergence lineage receipt page: seat class, posture origin, purge/heal scope, and survivor boundary interface spec

## Purpose

Every consequential decision about how a non-authority seat converges must leave one durable receipt.
The receipt exists so later operators do not have to reconstruct whether a seat was suspending, healing, purging unknowns, or following a hardwired encrypted posture from memory and screenshots.

## Receipt fields

The receipt must preserve:

- subject identity
- seat identity
- authority class
- posture origin (`subject`, `default`, `seat-class hardwire`, `unknown`)
- requested action
- effective heal posture
- effective purge posture
- divergence classes reviewed
- predicted survivor set
- proof rung
- strongest safe sentence
- blocked stronger sentence
- follow-up proof still missing
- timestamp and operator identity

## Required sentence structure

The primary sentence must read like:

> `For subject <x> on seat <y>, this non-authority posture is <verdict> because of <origin>. Edited / deleted / renamed / added divergence classes have the reviewed fates shown below. Unknown-file purge is <enabled / disabled / ambiguous>. The strongest safe sentence is <...>; the product refuses the stronger sentence <...>.`

## Divergence appendix

The receipt must include a small matrix covering at least:

- edit fate
- delete fate
- rename fate
- add-file fate
- unknown-file fate

## Proof appendix

Include:

- whether the posture was documented only or observed in behavior
- whether the source of posture was subject-specific, default-derived, or seat-class hardwire
- whether the target was declared empty or observed empty
- whether pre-seeded risk remains unresolved

## Rules

### Rule 1 — receipts may not collapse heal and purge

Those must remain distinct fields.

### Rule 2 — receipts must preserve survivor boundaries

`healed` is incomplete without `what remained local-only`.

### Rule 3 — blocked stronger language is mandatory

Examples:

- blocked: `all local divergence is safely reconciled`
- blocked: `this reused target is safe for purge`
- blocked: `encrypted seat can restore everything locally`
