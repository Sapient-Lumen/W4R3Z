## Filesystem-dialect timeline

### Purpose
Show how a path-bearing subject crossed dialect boundaries over time.

### Timeline event types
- **born under dialect**: original case / normalization / symbol / object-kind posture
- **first cross-dialect admission**: first arrival onto a seat with a different filesystem dialect
- **rewrite event**: symbol substitution or other visible-name transformation
- **collapse event**: two formerly distinct names became one destination slot
- **conflict materialization**: `.Conflict` or other split outcome created
- **block event**: arrival rejected because of unsupported symbol, length ceiling, or unsupported object kind
- **link-object projection event**: object synced as link only, with target coverage intentionally absent
- **rebind / remediate event**: move-out, rename, re-add, or safer cohort contraction used to restore clarity

### Timeline rules
- preserve both **what the human saw** and **what the dialect contract actually did**
- keep rewrite events visibly separate from author-intended renames
- keep block events visibly separate from silent absence
- keep link-object events visibly separate from ordinary file or folder arrival

### Why this matters
A later operator should be able to answer:
- when did the name first stop being cohort-stable?
- was the surprising result a rewrite, a conflict split, a hard block, or only a presentational change?
- which stronger path-stability sentence is still blocked now?
