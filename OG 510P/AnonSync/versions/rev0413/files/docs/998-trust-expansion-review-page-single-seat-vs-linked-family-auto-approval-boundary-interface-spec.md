# Trust expansion review page — single seat vs linked family auto-approval boundary

## Purpose

Review the operator decision to widen trust from one reviewed requester to a broader linked family or future-handle reuse policy.

This page is required whenever the system could move from:

- one reviewed requester
- one exact proof bundle
- one current subject

into any broader remembered trust.

## Inputs

- current requester identity contract sheet
- current proof handle page
- any family association evidence
- requested expansion target
- current subject and capability ceiling

## Must show

### 1. Expansion summary

Use explicit language such as:

- `Approve this requester only`
- `Approve future requests matching this exact handle bundle`
- `Approve all linked devices in this reviewed family`

Never collapse these into a single `remember this decision` toggle.

### 2. Basis for widening

Must say what evidence supports any family-wide option:

- explicit linked-family proof presented
- previously reviewed family receipt
- operator assertion only
- unknown / unavailable

### 3. Blast radius preview

Must show what widening would affect:

- this seat only
- future requests from the same handle
- all linked devices in the reviewed family
- future subject arrivals carrying family reuse

### 4. Safer alternatives

Offer reviewed narrower choices first:

1. approve current seat only
2. approve exact handle reuse only
3. defer family expansion until more evidence exists
4. reject widening entirely

### 5. Human-readable warning copy

The warning must say when the operator is crossing from:

- `I trust this requester now`

into:

- `I trust other seats not directly reviewed in this moment`

## Approval barrier

When widening beyond one seat, the operator must confirm against:

- current reviewed seat handle
- target expansion scope
- subject/capability ceiling
- evidence basis for family association

## Receipt obligations

The resulting receipt must preserve:

- chosen trust scope
- evidence basis for widening
- affected audience class
- narrower alternatives declined
- stronger blocked sentence such as `I only approved the requester I saw right now`
