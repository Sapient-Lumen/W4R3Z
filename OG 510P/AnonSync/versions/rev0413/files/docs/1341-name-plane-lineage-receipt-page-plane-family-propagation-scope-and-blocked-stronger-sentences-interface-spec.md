## Name-plane lineage receipt

### Receipt payload
Every serious naming event stores one durable receipt with:

- event class
- active naming plane
- changed text
- unchanged neighboring planes
- authority consequence
- propagation scope
- persistence class
- reset path
- proof basis
- blocked stronger sentence

### Example blocked stronger sentences
- `this UI alias rename changed the folder on disk everywhere`
- `this device rename changed the identity`
- `this new link label changed the share for everyone`
- `this identity text stayed the same so authority continuity is guaranteed`
