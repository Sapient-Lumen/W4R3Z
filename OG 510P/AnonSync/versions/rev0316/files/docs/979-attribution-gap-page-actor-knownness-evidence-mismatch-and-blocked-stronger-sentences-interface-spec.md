# Attribution gap page — actor knownness, evidence mismatch, and blocked stronger sentences

## Purpose

Give the operator one stable place to answer:

> what part of this story is still unknown, and which stronger statement am I not allowed to make?

## Core distinction

The page exists because these are different situations:

- bytes recoverable, actor unknown
- actor likely known, byte witness missing
- chronology plausible, but authority guarded
- mutation visible, but subject identity ambiguous
- notification seen, but durable evidence absent

## Page regions

1. attribution strip
2. known facts card
3. missing facts card
4. blocked-stronger-sentences card
5. safer-language ladder
6. gap receipts

### 1) Attribution strip

Show:

- subject or incident label
- verdict: `actor-known`, `actor-partial`, `actor-unknown`, `source-mismatch`, `expired-attribution`
- one next honest action

### 2) Known facts card

List only facts still supported, such as:

- subject path or cluster
- time window
- byte witness location
- transfer occurrence
- receiving seat
- currently retained event source

### 3) Missing facts card

Explicitly name gaps:

- no retained actor identity
- no durable chronology authority
- no stable subject join
- no byte witness
- no surviving delivery evidence
- evidence family expired

### 4) Blocked stronger sentences card

The page must show examples like:

- `Peer B deleted this file` — blocked because actor attribution expired
- `This restored copy is the exact last good version` — blocked because chronology authority is partial
- `The notification proves the mutation happened` — blocked because notification is signal-grade only

### 5) Safer-language ladder

Offer sentences that remain honest:

- `A recoverable prior version exists on peer C; actor attribution is unavailable.`
- `History still shows a change event in the relevant window, but byte witness has expired.`
- `A transfer occurred, but the available evidence does not prove authorship.`

### 6) Gap receipts

Receipts preserve:

- gap class
- evidence families consulted
- strongest safe sentence
- blocked stronger sentence
- escalation/export recommendation

## Rules

- The page must prefer explicit absence over speculative actor naming.
- Blocked stronger sentences are required, not optional footnotes.
- Compact surfaces may summarize the gap, but must link back here before any blame- or rollback-shaped action.
