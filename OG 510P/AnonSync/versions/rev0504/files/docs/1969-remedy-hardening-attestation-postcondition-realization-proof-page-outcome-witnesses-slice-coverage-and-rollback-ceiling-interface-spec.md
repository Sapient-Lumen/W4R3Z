# Remedy-hardening-attestation postcondition-realization proof page — outcome witnesses, slice coverage, and rollback ceiling

## Purpose

This page is the evidence-heavy proof surface for determining whether an executable mandate has actually produced the target state.
It proves the exact ceiling on any sentence that tries to say a mandate is not merely routed, but now realized for the intended slice.

## Required evidence blocks

### 1. Governing mandate basis

Preserve:

- source executable-mandate receipt
- governing mandate sentence
- target postcondition sentence

### 2. Target-scope ledger

Preserve:

- beneficiary slice
- governed object set
- required world and topology scope
- named-slice-only ceiling if broader realization is unsupported

### 3. Outcome-observation ledger

Preserve:

- route-executed witnesses
- outcome witnesses by surface and witness class
- placeholder-or-metadata-only indicators
- beneficiary-can-act witnesses
- missing quorum details

### 4. Contradiction-and-settlement ledger

Preserve:

- contrary observations
- rollback or survivor hazards
- settlement window start and end basis
- exact blocker for any broader or stronger realization sentence

### 5. Claim ceiling

Render:

- highest honest realization sentence now
- highest honest named-slice-only realization sentence now
- strongest blocked broader sentence and exact blocker
- next witness that would raise the ceiling

## Evidence and realization classes

The page must distinguish at least:

- routed only
- not yet observed
- route-local-only observed
- named-slice-only observed
- placeholder-only or metadata-only observed
- contradicted observation
- settlement window open
- rollback hazard dominates
- governed-slice realized
- broader stronger sentence blocked

## Hard rules

The proof page must never treat:

- route execution as proof of realized effect
- folder appearance as proof of usable object presence
- one beneficiary witness as proof for excluded or unseen beneficiaries
- temporary observation before settlement as stable realization
- rollback possibility as irrelevant once one surface looked correct
