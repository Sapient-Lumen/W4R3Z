# Remedy-hardening-retention lineage receipt page — retained scope, drift, and blocked stronger sentences

## Purpose

This receipt is the portable summary of the strongest honest claim about a case that already claimed recurrence hardening and is now attempting to claim that the hardening stayed retained over time and scope change.
It exists so later operators can answer `did this case harden once, or did it keep that hardening as the world kept moving?` from one durable object.

## Receipt fields

- receipt identifier
- case identifier
- source remedy-hardening receipt identifier
- triggering cause family
- current remedy-hardening-retention posture rung
- current retained-hardening strategy class
- retained-versus-drifted control class
- required retention cohort
- current retained scope
- highest honest current retained-hardening sentence
- strongest blocked stronger recurrence-retained sentence
- drift ceiling
- carry-forward ceiling
- manual-override divergence status
- peer-local rule divergence status
- service or storage-world continuity status
- retention debt class, if any
- next mandatory strengthening trigger
- next automatic weakening trigger

## Mandatory sentence discipline

The receipt must preserve these distinctions:

- recurrence hardening achieved once versus retained now
- original cohort retained versus future carry-forward retained
- default present versus every lane still aligned
- manual override exists versus manual override harmlessly remains within retained scope
- same service uptime versus same hardened world
- narrowed recurrence risk versus recurrence-hardened-and-retained discharge
- honest hardening versus retained hardening

## Example summary sentences

- `Recurrence hardening achieved once, but retained hardening is still blocked by one detached lane.`
- `Original cohort retained; future carry-forward still outside retained-hardening scope.`
- `Peer-local rule divergence reopened retention debt despite otherwise calm settings.`
- `Retained hardening survived overrides, carry-forward, and world continuity checks; recurrence-hardened-and-retained discharge is now honest.`
