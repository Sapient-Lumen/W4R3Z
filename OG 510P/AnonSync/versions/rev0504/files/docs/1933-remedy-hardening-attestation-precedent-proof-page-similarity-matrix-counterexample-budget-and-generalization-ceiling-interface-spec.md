# Remedy-hardening-attestation precedent proof page — similarity matrix, counterexample budget, and generalization ceiling

## Purpose

This page is the evidence-heavy proof surface for portability claims after closure.
It proves the exact ceiling on any sentence that tries to reuse one closed case as a rule, recipe, or policy.

## Required evidence blocks

### 1. Source-case closure basis

Preserve:

- source closure receipt and class
- remaining contest, reopen, or compensation residue
- why the source case is fit or unfit for reuse review

### 2. Similarity matrix

For each claimed target class preserve:

- required invariants
- evidence that each invariant matches
- differences found
- whether the difference is tolerated, narrowing, or blocking

### 3. Pilot reuse ledger

Preserve:

- every attempted reuse of this rule
- target class for that reuse
- outcome class
- downgrade or escalation caused by that reuse

### 4. Counterexample ledger

Preserve:

- every known counterexample or near-miss
- exact axis on which portability failed
- whether the counterexample blocks named scope only or all policy generalization
- current unresolved counterexample budget

### 5. Claim ceiling

Render:

- highest honest case-specific sentence
- highest honest named-class portability sentence
- highest honest policy sentence
- blocked stronger sentence and exact blocker

## Evidence classes

The page must distinguish at least:

- source case closed but reuse-unreviewed
- invariants asserted but unsupported
- named-class match evidenced
- pilot reuse succeeded once
- repeated pilot reuse within named class
- counterexample open
- counterexample resolved by narrowing scope
- ratified policy for named scope only
- review overdue or sunset reached

## Hard rules

The proof page must never treat:

- one closed case as proof of broad portability by itself
- one topology match as proof for every topology
- a workaround article as policy ratification
- absence of a known counterexample as proof of generality
- a current clean UI path as evidence that future versions preserve the same rule
