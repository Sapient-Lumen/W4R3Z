# Remedy-discharge lineage receipt page — quarantine release, normal-lane restoration, and blocked stronger cure sentences

## Purpose

This receipt is the durable compact proof of how a repaired case did or did not return to ordinary mutation and admission policy.
It exists so later readers can see whether the product was honest about the gap between `the cure safely converged` and `the case is now discharged back to normal life`.

## Receipt body

The receipt must record:

- case identifier
- source remedy-convergence receipt identifier
- current remedy-discharge posture rung
- intended authoritative object summary
- current quarantine scope summary
- current write-right restoration summary
- current admission-right restoration summary
- remembered approval surface summary
- linked-device owner-spread summary
- pending or disconnected participant summary
- Standard-folder resharing exposure summary
- rearm condition summary
- strongest honest sentence
- strongest blocked stronger sentence
- exact blocker summary

## Receipt sentence families

The receipt must support concise summaries such as:

- `the cure converged, but remembered approvals still blocked discharge back to ordinary admission policy`
- `write rights were restored for the required cohort while onward-sharing rights remained fenced`
- `linked-device owner spread kept quarantine release blocked even after returner-safe convergence`
- `the case was discharged with rearm conditions and later reclosed when a new admission surface appeared`
- `ordinary life resumed only partially because admission restoration stayed weaker than mutation restoration`

## Invariants

- the receipt never compresses convergence, partial discharge, ordinary mutation restoration, ordinary admission restoration, and quarantine release into one word
- the receipt never hides remembered approvals or owner spread behind calm permissions
- the receipt never lets broad resharing rights disappear from the lineage
- the receipt always preserves the blocker that prevented the stronger discharge sentence
