## Projection-capability proof

### Goal
Prove the strongest honest sentence about whether a pathname and object kind can survive intact across the current cohort.

### Proof rungs

#### Rung 1 — local-only fit
Evidence:
- current seat accepts the visible name and object kind
- no cohort-wide dialect comparison yet

Safe sentence:
- `this path currently fits here`

Blocked sentence:
- `this path will survive the cohort unchanged`

#### Rung 2 — weakest-known ceiling identified
Evidence:
- current review knows the tightest known case / normalization / symbol / length restriction in the cohort
- no contradiction has been observed yet

Safe sentence:
- `this path appears to fit the weakest known current ceiling`

Blocked sentence:
- `all cohort members will preserve it identically`

#### Rung 3 — intact projection proven
Evidence:
- relevant cohort members have accepted the path without conflict, rewrite, or block
- no link-kind mismatch remains
- no path-collapse invalidator is present

Safe sentence:
- `this path and object kind have been witnessed surviving intact across the reviewed cohort`

Blocked sentence:
- `future arrivals and future seats are guaranteed equally safe`

#### Rung 4 — cohort-stable projection contract
Evidence:
- intact projection proven
- all admitted seats share a compatible dialect contract or an explicit transformation contract
- future-admission policy blocks weaker seats from silently joining

Safe sentence:
- `this cohort currently enforces a stable path-projection contract for this subject`

Blocked sentence:
- `human-equal names can never diverge or collapse again`

### Key product rule
**Human-equal appearance never outranks dialect mismatch.**
The product must always prefer proven projection behavior over visual familiarity.
