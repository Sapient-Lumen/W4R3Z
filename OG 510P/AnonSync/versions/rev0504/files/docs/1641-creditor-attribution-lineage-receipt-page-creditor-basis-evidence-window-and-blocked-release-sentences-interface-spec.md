# Creditor attribution lineage receipt page — creditor basis, evidence window, and blocked release sentences

## Purpose

This page is the durable receipt for the full lineage of creditor attribution and dispute handling after burst debt and staged restoration.
A later operator should be able to open one page and answer:

> which creditors were verified, which were contested, what evidence horizon governed the case, what release freeze or reopen happened, and what cleaner sentence the product refused to make?

## Required receipt sections

### A. Origin section

- source burst-debt object
- source restoration waterfall if any
- claimant
- original asserted creditor universe
- authority that opened attribution review

### B. Attribution section

- final verified creditor set
- final contested or unverifiable residue
- evidence sources relied on
- shortest load-bearing evidence horizon
- actor-attribution strength achieved

### C. Dispute-history section

- dispute count
- reopen count
- last ruling
- last freeze or unfreeze action
- absorber or waiver details if used
- residue carried forward if any

### D. Final truth section

- strongest true sentence for claimant
- strongest true sentence for harmed neighbors
- release posture after latest review
- probation posture after latest review
- strongest blocked cleaner sentence
- exact fact required for upgrade
- exact fact that would downgrade the sentence again

## Required receipt badges

- `creditor-review-opened`
- `verified-core`
- `contested-residue`
- `evidence-aging-risk`
- `release-frozen`
- `provisional-relief-used`
- `waiver-used`
- `absorber-named`
- `reopened`
- `final-closure-fixed`

## Receipt obligations

- preserve who was verified separately from who was merely asserted
- preserve evidence horizon as a first-class fairness fact
- preserve contest and reopen history even after later closure
- preserve release freezes as different truths from final release
- preserve harmed-neighbor consequence instead of centering only the claimant's wish to close the case

## Stronger-sentence guard

The receipt may say `verified core cleared with surviving contested residue under frozen release` or `all material creditors verified and final closure fixed`, depending on truth.
It may not say `dispute no longer matters` unless no contested residue, no open reopen window, no waiver consequence, and no frozen release posture remain.
