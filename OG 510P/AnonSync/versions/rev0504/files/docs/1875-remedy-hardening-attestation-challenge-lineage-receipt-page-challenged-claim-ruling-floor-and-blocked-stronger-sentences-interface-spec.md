# Remedy-hardening-attestation-challenge lineage receipt page — challenged claim, ruling floor, and blocked stronger sentences

## Why this receipt exists

Once a strong attestation sentence has been challenged, later operators must not have to reconstruct the story from warning screenshots, support tickets, old logs, or memory.
They need one durable receipt that says what was challenged, what ruled, what survived, and which stronger sentence is still forbidden.

## Receipt fields

- case identifier
- challenged sentence identifier
- exact challenged sentence
- source corroboration receipt identifier
- challenge type
- challenger class
- decisive witness family
- losing witness family set
- provisional floor used during review
- final adjudicated surviving sentence
- strongest blocked stronger sentence
- whether continuity stayed in the same world
- whether rework occurred
- whether reseal occurred
- current appeal or reopen posture
- next evidence that would weaken the receipt
- next evidence that would strengthen the receipt

## Required receipt sentences

The receipt must be able to say things like:

- `this challenge froze the prior strongest sentence on receipt, but a narrower historical sentence remained honest`
- `the challenge was upheld against continuity, so the old world-specific sentence stays blocked even though successor-world repair later succeeded`
- `the challenge was rejected because the winning witnesses outranked stale presentation evidence`
- `the challenge produced only support-lane counterevidence, so final restoration remains blocked`
- `the challenge was resolved only after rework and reseal, so pre-challenge and post-challenge sentences are not interchangeable`

## Blocking rules

The receipt must never let later operators silently say:

- `nothing really changed`
- `it was fixed` without the ruling floor
- `the same sentence still holds` when only a narrower one survived
- `the challenge closed` when appeal or reopen conditions remain active
