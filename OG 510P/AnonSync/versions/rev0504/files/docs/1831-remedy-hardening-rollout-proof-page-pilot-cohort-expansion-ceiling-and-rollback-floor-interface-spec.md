# Remedy-hardening-rollout proof page — pilot cohort, expansion ceiling, and rollback floor

## Purpose

This page is the proof bundle behind the claim that a case which already achieved retained and change-gated recurrence hardening may let an approved change spread without exceeding its intended blast radius.
It exists so later readers can inspect cohort scope, spread surfaces, abort honesty, and reseal evidence instead of inferring them from operational sharing behavior.

## Proof bundle

The proof page must preserve evidence for:

- source remedy-hardening-change-gate result
- triggering cause family
- approved change class
- rollout initiator class
- named pilot cohort
- required rollout cohort
- linked-device auto-spread exposure evidence
- Standard-versus-Advanced onward-share exposure evidence
- share-link approval, expiry, and use-limit evidence
- synchronization-mode participation evidence
- local-share containment evidence, if relevant
- blast-radius ceiling evidence
- expansion threshold evidence
- abort-readiness evidence
- rollback-honesty evidence
- spread debt evidence, if any
- compensation requirement evidence, if any
- required reseal evidence
- highest honest current rollout-bounded sentence
- strongest blocked stronger rollout-bounded sentence

## Proof sentence families

The page must support concise summaries such as:

- `the change is approved, but rollout remains unbounded for this cause family`
- `pilot rollout is limited to the named cohort, yet linked-device spread still blocks a stronger sentence`
- `abort remains honest only for lanes that have not yet landed the change`
- `already-landed non-pilot spread means rollback or compensation now replaces pure abort language`
- `bounded rollout is now proven tightly enough that the stronger rollout sentence is honest`

## Stronger-sentence blockers

The page must explicitly name blockers such as:

- pilot cohort not formally bounded
- required rollout cohort still open
- linked-device auto-spread exposure unresolved
- Standard onward-share exposure unresolved
- share-link exposure unresolved
- local-share containment too weak
- non-pilot lane already landed change
- abort honesty not proven
- reseal still pending
- evidence basis too weak

## Evidence handling rules

The proof page must never let these substitute for stronger proof:

- one approved change record without rollout-scope evidence
- one link expiry or use limit without cohort-bounding proof
- one disconnected or selective icon without semantic non-adoption proof
- one local-share setup without broader spread-surface accounting
- one disconnect action without already-landed-lane unwind proof
