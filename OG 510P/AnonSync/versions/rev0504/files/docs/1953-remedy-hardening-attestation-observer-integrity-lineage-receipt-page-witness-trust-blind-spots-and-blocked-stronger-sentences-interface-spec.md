# Remedy-hardening-attestation observer-integrity lineage receipt page — witness trust, blind spots, and blocked stronger sentences

## Purpose

This page is the durable one-receipt summary for evidence-trust questions after conformance review.
It lets a later operator read one artifact and know exactly whether the current witness set is trustworthy enough to support the present sentence, merely suggestive, or blocked by retention gaps, world ambiguity, blind spots, or tamper concerns.

## Receipt fields

- receipt identifier
- observer-integrity identifier
- source conformance or breach receipt identifier
- current observer-integrity class
- target sentence reviewed
- witness lanes included and absent
- protocol-completeness summary
- world-scope summary
- retention and rotation summary
- blind-spot summary
- tamper and mutation summary
- highest honest evidence-trust sentence
- blocked stronger sentence
- evidence bundle references
- issued-at timestamp

## Primary sentence block

The receipt must begin with exactly two lines:

- **Highest honest evidence-trust sentence**
- **Blocked stronger sentence**

## Required sections

1. **Why this witness set does or does not deserve trust**
2. **Which worlds, surfaces, and horizons are actually covered**
3. **Which blind spots, retention gaps, or protocol failures still matter**
4. **Whether tamper, mutation, or sibling-world ambiguity remains open**
5. **Why the next stronger sentence is blocked**

## Hard rules

The receipt must never let:

- `evidence exists` impersonate `evidence is trustworthy enough`
- `fresh witness somewhere` impersonate `right world and scope observed`
- `log survived` impersonate `retention complete`
- `surface looked calm` impersonate `event would have been seen`
- `manual forensic artifact captured` impersonate `ordinary observer continuity`
