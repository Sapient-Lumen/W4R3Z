# Remedy-hardening-attestation remediation-exposure contract sheet page — self-service path, bearer breadth, and reshare ceiling

## Purpose

This page is the operator-facing contract sheet for deciding whether a late outsider can remediate from the corrected replacement **without widening exposure beyond the reviewed budget**.
It exists to stop `this surface lets them fix themselves` from being mistaken for `this surface lets them fix themselves safely`.

## Core question

The page must answer:

**what is the strongest honest sentence we can make about safe outsider remediation now, and what stronger bounded-exposure sentence is still blocked?**

## Required fields

The contract sheet must capture at least:

- stale artifact identifier
- corrected replacement identifier
- remediation carrier class
- audience breadth class
- onward-reshare class
- permission-widening class
- expiry / click-budget class
- approval posture
- retention-residue class
- exposure budget verdict
- strongest honest safe-remedy sentence
- blocked stronger bounded-exposure sentence

## Remediation carrier classes

The sheet must preserve at least:

- bounded invite only
- approval-gated folder link
- bearer folder link
- one-time file-transfer link
- forwarded local copy
- owner-grant path
- mixed carrier path
- unknown carrier

## Exposure-budget panel

The page must force explicit answers to:

- who can use the carrier if it is forwarded beyond the intended outsider?
- can the carrier be reused without a per-device or per-use ceiling?
- can the outsider share onward, invite others, or widen permissions?
- can already delivered copies survive disconnect, UI removal, or later revocation?
- does the path rely on a narrower carrier in one environment but a bearer carrier in another?

## Residue panel

The sheet must keep separate:

- carrier no longer usable for new connections
- previously delivered bytes still present
- recipient can forward copy further
- recipient can widen authority further
- exposure retired elsewhere

## Hard rules

The page must never allow:

- `outsider can remediate` to silently stand in for `outsider can remediate within budget`
- expiration alone to erase already delivered residue
- approval gates to erase onward-sharing rights once granted
- one narrow carrier to hide that another named path is still bearer-broad
