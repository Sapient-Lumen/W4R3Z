# Remedy-hardening-attestation-corroboration lineage receipt page — plane diversity, corroboration floor, and blocked stronger sentences

## Purpose

This page is the compact durable receipt for the strongest honest corroboration-aware verifier sentence.
It exists so a later verifier can open one page and see whether the case is only fresh and sealed, or also corroborated across the required independent planes.

## Receipt payload

The receipt must preserve at least:

- case identifier
- source attestation-freshness receipt identifier
- attestation bundle identifier
- current attestation-corroboration posture rung
- required evidence-plane set
- satisfied evidence-plane set
- independence floor
- contradiction status
- stale-plane set
- dominant-plane warning status
- highest honest corroborated sentence
- strongest blocked stronger sentence

## Mandatory language rules

The receipt must use scarred language when needed.
Examples:

- `fresh sealed bundle only; corroboration pending`
- `required plane missing; stronger corroborated sentence blocked`
- `same-world corroboration only`
- `contradiction open; strongest sentence degraded`
- `independently corroborated for required verifier cohort`

## Prohibited overstatements

The receipt must never let these overstatements pass unscarred:

- `corroborated` when the operator really means `not yet contradicted`
- `independent planes` when the evidence still traces back to one dominant lane
- `current corroboration` when a required plane is stale
- `verified everywhere` when the product only knows one world and one cohort
- `strongest verifier sentence stands` when contradiction resolution is still pending
