# Action effectivity lineage receipt page — effective state, notice cohort, and supersession boundary

## Purpose

This page is the durable receipt for the strongest lifecycle state honestly in force now.
It exists so future operators can see what exact effect is currently active, what notice cohort completed, what timers were satisfied, what stronger states remain blocked, and what earlier truths survive any supersession or withdrawal.

## Required receipt blocks

### A. Source-state block

- source action enactment contract sheet
- source enactment review
- source action effectivity proof
- source action matrix or authority proof if used
- current lifecycle posture

### B. In-force block

- decisive action family
- highest lifecycle state in force now
- execution time
- effectivity time
- required notice cohort status
- exact stronger lifecycle states still blocked now
- exact weaker sub-truths preserved now

### C. Boundary block

- scope in force now
- scope executed but not yet effective
- scope formerly effective but superseded or withdrawn
- contest or reopen rights still alive
- superseding act if any
- exact event that would narrow or strengthen this receipt next

### D. Fragility block

- remaining notice risk
- remaining cooling or contest assumptions
- exact delivery or timer failure that would narrow this receipt
- exact completion event that would strengthen this receipt
- whether any irreversible claim is still weaker than it appears because effectivity is partial

### E. Audit block

- decisive signatures
- decisive execution record
- decisive notice records
- decisive timer records
- decisive objections preserved
- decisive supersession or withdrawal records

## Sentences this receipt may support

- `executed but not yet effective because required notice cohort is incomplete`
- `protective effect active now; irreversible effect still cooling`
- `undisputed-core finality effective after completed notice and cooling; disputed residue still outside effect`
- `earlier case-wide effect superseded; receipt acknowledgment and provisional settlement lineage survive`
- `effect reopened; stronger sentence withdrawn while narrower history remains valid`

## Failure modes the receipt must prevent

- forgetting whether the current truth is execution or effectivity
- forgetting which recipients were required for notice completion
- overstating case-wide force from a slice-limited effective state
- confusing later supersession with retroactive non-existence
- letting future readers believe that one history row or bell icon proved full finality

## Stronger-sentence guard

The receipt may say `final waiver executed and fully effective for the undisputed core after completed notice and cooling; disputed-residue waiver and full case-wide closure remain blocked, and earlier protective-freeze lineage survives reopen rights`.
It may not say `everything settled` unless that exact stronger state is truly in force.
