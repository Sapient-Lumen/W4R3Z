# Remedy-hardening-attestation-reliance timeline page — registration, consumption expansion, supersession, and revocation-wave events

## Purpose

This page is the chronological spine for what happened after a receipt became speakable and downstream consumers started to register, consume, derive artifacts, or get pulled into a later revocation or revalidation wave.
It exists so a later reader can see whether dependence was narrow, broad, incomplete, stale, or successfully reconciled after the source sentence changed.

## Event classes

The timeline must record at least these events:

- audience scope granted
- consumer class made eligible
- consumer explicitly registered
- observed consumption attached
- dependent artifact created
- dependent artifact published externally
- registry coverage widened
- unknown-consumer risk opened
- new reliance frozen
- source receipt reopened
- source receipt superseded
- revocation wave issued
- consumer notified
- artifact marked stale
- artifact retracted
- dependent decision revalidated
- downstream receipt resealed
- dependency wave completed
- source demoted to historical only

## Timeline behavior

The page must keep these truths separate:

- audience allowed versus consumer registered
- consumer registered versus observed consuming
- observed consuming versus derivative artifact published
- superseded source versus downstream cleanup completed
- freeze-new-reliance versus all stale dependents reconciled
- historical source preserved versus historical source safe to cite without warning

## Operator questions answered by this page

The timeline must let a later operator answer:

- when did the ruling first become eligible for downstream use
- when did each consumer class actually consume it
- when did the first derivative artifact become live
- when was dependency coverage still incomplete
- when did supersession or reopen trigger a revocation wave
- when did each stale artifact get retracted, revalidated, or resealed
- when did the source finally become historical only with downstream cleanup complete
