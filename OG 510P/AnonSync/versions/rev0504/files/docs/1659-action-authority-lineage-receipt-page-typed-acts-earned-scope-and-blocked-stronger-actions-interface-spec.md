# Action authority lineage receipt page — typed acts, earned scope, and blocked stronger actions

## Purpose

This page is the durable receipt for the strongest typed act honestly earned now.
It exists so future operators can see what was actually executed, what exact scope it touched, what stronger acts remained blocked, and which fallback or reopen rights survived.

## Required receipt blocks

### A. Source-case block

- source action authority matrix contract sheet
- source action matrix review
- source action sufficiency proof
- source coalition or authority proof if used
- current case posture

### B. Earned-act block

- decisive action family
- decisively counted coalition
- reversibility class
- exact sentence honestly earned now
- exact stronger actions still blocked now
- exact weaker acts preserved in lineage

### C. Scope-and-consequence block

- creditor slice touched
- residue extinguished
- residue still open
- probation consequence
- future-burst consequence
- surviving reopen or contest rights

### D. Fragility block

- remaining challenge risk
- remaining cooling or ratification assumptions
- exact event that would reopen or narrow this receipt
- exact event that would make this receipt stronger
- whether any irreversible claim is still provisional because contest time remains open

### E. Audit block

- decisive timestamps
- decisive signatures or seats
- decisive cooling evidence
- decisive objections preserved
- decisive withdrawal or reopen reference if any

## Sentences this receipt may support

- `payment was acknowledged only; settlement rights remain open`
- `undisputed core settled; disputed residue and future-burst normalization remain blocked`
- `probation lifted after cooling; final residue waiver still absent`
- `successor appointment recorded; predecessor waiver not yet ratified`
- `reopen executed; earlier final-waiver sentence withdrawn while receipt lineage remains intact`

## Failure modes the receipt must prevent

- forgetting which exact act was earned instead of merely attempted
- forgetting which rights survived because the act was narrower than full closure
- overstating case-wide effect from a slice-limited act
- confusing reversibility class with moral importance or signer prestige
- letting future readers believe that once one irreversible act happened, all weaker lineage disappeared

## Stronger-sentence guard

The receipt may say `case-wide protective freeze executed and funds acknowledged; disputed-residue waiver, probation lift, and future-burst normalization remain blocked`.
It may not say `case closed` unless that exact stronger act was truly earned and preserved.
