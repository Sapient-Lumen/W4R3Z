
# Remedy-hardening-attestation policy-rollout proof page — deployment coverage, drift evidence, and waiver debt

## Purpose

This page is the evidence-heavy proof surface for rollout claims after precedent portability.
It proves the exact ceiling on any sentence that tries to say a portable rule now governs a named estate slice.

## Required evidence blocks

### 1. Source precedent basis

Preserve:

- source precedent receipt and class
- current portability scope
- why rollout review is allowed

### 2. Deployment coverage ledger

For each claimed estate slice preserve:

- intended control lane
- deployment completed, partial, or absent
- verification evidence that the control is effective
- uncovered populations and exact reason they remain uncovered

### 3. Override and drift ledger

Preserve:

- manual per-share or per-surface overrides
- defaults no longer followed because of prior manual changes
- drift discovered after deployment
- downgrade or escalation caused by that drift

### 4. Waiver and grandfather ledger

Preserve:

- every active waiver
- waiver owner and expiry
- grandfathered population and sunset path
- current exception debt versus budget

### 5. Claim ceiling

Render:

- highest honest named-slice rollout sentence
- highest honest enforcement sentence
- highest honest estate-wide sentence
- blocked stronger sentence and exact blocker

## Evidence classes

The page must distinguish at least:

- rollout unstarted
- deployment active but verification incomplete
- named-slice coverage evidenced
- named-slice enforcement with bounded waivers
- grandfathered population still open
- exception debt above budget
- waiver expired or unmanaged
- rollout narrowed or paused
- estate-wide claim still blocked

## Hard rules

The proof page must never treat:

- a config artifact as proof of effective enforcement by itself
- a default as proof that every object still follows that default
- one covered platform as proof for every platform
- a temporary waiver as if it were silent compliance
- absence of a detected drift as proof that no drift exists
