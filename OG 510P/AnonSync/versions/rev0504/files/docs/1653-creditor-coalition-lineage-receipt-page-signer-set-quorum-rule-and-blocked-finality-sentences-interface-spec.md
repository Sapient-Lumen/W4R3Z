# Creditor coalition lineage receipt page — signer set, quorum rule, and blocked finality sentences

## Purpose

This page is the durable receipt for the strongest true closure sentence after coalition review.
It exists so future operators can see which signer set counted, which rule made that set sufficient or insufficient, what successor or conflict facts remained load-bearing, and which stronger finality sentence stayed blocked.

## Required receipt blocks

### A. Source-case block

- source creditor coalition contract sheet
- source creditor coalition review
- source closure sufficiency proof
- source restoration or debt case if present
- current case posture

### B. Counted-signer block

- decisive action reviewed
- coalition model used
- counted seats or signers
- non-counted seats and why they did not count
- whether any silence, timeout, or adjudication path was used
- whether successor ratification mattered

### C. Sufficiency block

- exact sentence honestly earned now
- exact stronger sentence still blocked now
- whether final waiver is fully earned, partially earned, or not earned
- whether probation lift is earned or still frozen
- whether future-burst normalization is earned or still blocked

### D. Fragility block

- remaining conflict risk
- remaining vacancy risk
- remaining succession risk
- exact event that would reopen this receipt
- exact event that would make the receipt more final

### E. Residue block

- open residue still owed or still contestable
- earlier narrower acts preserved
- earlier stronger acts withdrawn if any
- surviving reopen rights if any

## Sentences this receipt may support

- `single principal signer was sufficient for this creditor slice`
- `delegate plus reserve guardian countersigned; full waiver still blocked by absent finance seat`
- `quorum satisfied for staged settlement only; unanimity not met for final release`
- `prior final closure withdrawn because successor never ratified predecessor consent`
- `conflict resolved by adjudicator; finality remains reopenable only on fraud or new disqualifying evidence`

## Failure modes the receipt must prevent

- forgetting whether the decisive threshold was single-signer, countersign, quorum, unanimity, or adjudication
- forgetting which seats were counted and which were merely present
- forgetting whether a successor actually ratified an earlier step
- forgetting that partial truth may survive after stronger finality fails
- allowing future readers to overstate closure because a signature list looked impressive

## Stronger-sentence guard

The receipt may say `two required countersigners present; unanimity still not met, so final release blocked`.
It may not say `case permanently closed` unless that stronger sentence was truly earned and preserved.
