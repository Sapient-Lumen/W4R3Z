# Remedy-hardening-attestation catastrophe-recovery timeline page — loss, corruption, reset, reseed, reconnect, and reissue events

## Purpose

This page is the ordered timeline for understanding how a governed state moved through a catastrophic event and any later recovery path.
It exists so later operators can see whether the world was genuinely reconstituted, partially salvaged, or fully re-founded after the break.

## Required event families

The timeline must be able to render at least these event families:

- pre-catastrophe receipt issued
- corruption or destructive-loss event detected
- `.sync` capsule missing or corrupted
- storage root lost or replaced
- identity compromised or stolen-device response opened
- backup or encrypted-node anchor located
- key, database, or receipt anchor verified
- re-add or re-share required
- identity regenerated
- successor world created
- decrypt or reseed operation started
- reconnect completed
- same-world continuity disproved
- named catastrophe recovery confirmed
- reconstitution ceiling narrowed or upgraded
- post-recovery recertification completed

## Event cards

Every event card must preserve:

- event identifier
- event class
- timestamp
- affected governed slice
- prior class
- resulting class
- anchor-retention effect
- continuity effect
- manual step required
- resulting stronger sentence blocked or unlocked

## Fixed rendering order

Every catastrophe-recovery timeline must render the same sections in the same order:

1. **Pre-catastrophe basis**
2. **Catastrophe and anchor-loss events**
3. **Anchor discovery and recovery-path selection**
4. **Regeneration, rebind, or re-foundation events**
5. **Post-recovery recertification and final sentence**

## Hard rules

- The timeline must never hide a severed world behind a later calm surface.
- The timeline must never hide regenerated identity behind `recovered`.
- The timeline must never hide new synchronization instance creation behind `repaired`.
- The timeline must never let a later successful reconnect erase the destructive break that happened in between.
