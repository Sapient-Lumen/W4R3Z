# Remedy-discharge proof page — release authority, returner fences, and ordinary-lane restoration

## Purpose

This page is the case proof that a repaired case did or did not become safe to release back to ordinary mutation and admission policy.
It exists so later readers can inspect the evidence behind the discharge sentence instead of inferring it from calm permissions, a converged folder, or one apparently quiet linked identity.

## Proof bundle

The proof page must preserve evidence for:

- intended authoritative object and namespace
- source remedy-convergence result
- current quarantine scope
- current write-right restoration scope
- current admission-right restoration scope
- remembered approval surface evidence
- linked-device owner-spread evidence
- pending or auto-connect participant evidence
- disconnected participant evidence
- Standard-folder resharing exposure evidence
- Advanced-folder owner exposure evidence
- current rearm condition set
- strongest honest discharge sentence
- strongest blocked stronger discharge sentence

## Proof sentence families

The page must support concise summaries such as:

- `the cure converged, but remembered approvals still allowed automatic future connection, so discharge remained blocked`
- `ordinary mutation was restored for one named maintenance cohort while onward sharing stayed fenced, so discharge remained partial`
- `linked-device owner spread still widened the ordinary surface faster than the review could safely ratify it`
- `all required writers were restored, but pending participants outside review kept ordinary admission restoration blocked`
- `the case was released with rearm conditions, and any newly widened sharing surface would automatically reclose quarantine`

## Invariants

- the proof never compresses convergence, partial discharge, ordinary mutation restoration, ordinary admission restoration, and quarantine release into one word
- the proof never hides remembered approval or linked-device spread behind calm UI state
- the proof never lets Owner convenience or Standard-folder resharing impersonate case-specific discharge authority
- the proof always preserves the blocker that prevented the stronger discharge sentence
