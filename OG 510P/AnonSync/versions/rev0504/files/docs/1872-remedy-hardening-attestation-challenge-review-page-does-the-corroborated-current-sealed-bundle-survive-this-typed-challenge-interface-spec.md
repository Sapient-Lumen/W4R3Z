# Remedy-hardening-attestation-challenge review page — does the corroborated current sealed bundle survive this typed challenge?

## Review question

Can the product honestly keep, narrow, overturn, or later restore the strongest sealed-current-corroborated sentence after this typed challenge?

## Review panels

### 1) Challenged sentence preservation

Show the exact sentence being challenged, not just a paraphrase.
The review must preserve:

- the challenged sentence text
- the receipt or proof it came from
- the world and cohort it covered
- the exact stronger sentence now frozen
- the weaker sentence still allowed while review remains open

### 2) Challenge classification and burden

Force the operator to classify the challenge before attaching evidence.
The review must distinguish at least:

- freshness-only challenge
- integrity challenge
- chronology challenge
- continuity/world-fork challenge
- stale-presentation challenge
- storage corruption challenge
- source-availability challenge
- contradictory-witness challenge

For each class, publish the burden rule:

- what must be disproved
- what witness class can win
- what weaker sentence survives while that burden is still open

### 3) Witness priority review

Ask which witness families outrank others for this challenge.
Examples of false restorations to reject:

- calm UI restoring the sentence while database or service warnings remain unresolved
- later support logs restoring continuity when the live world may already have forked
- restart-gated evidence outranking the fact that restart itself changed the observed world
- a successful re-add being treated as proof that the challenged prior sentence was always sound

### 4) Provisional freeze review

The review must make temporary consequences explicit:

- which automation is suspended
- which outward sentence is downgraded
- which downstream decisions must wait
- whether the weaker sentence is historical only or still live

### 5) Ruling review

The page must land on explicit ruling branches such as:

- challenge open, stronger sentence frozen
- challenge rejected, stronger sentence restored
- challenge upheld, sentence narrowed
- challenge upheld, prior standing overturned
- challenge answered only for named lanes
- rework required before any stronger sentence returns
- reseal required before restored standing may speak outwardly

## Output states

The page must be able to land on at least these outputs:

- preserved but frozen
- narrowed while challenge open
- partially restored for named lanes only
- overturned pending rework
- restored after decisive counterevidence
- restored only after reseal
- reopened after appeal or later contradiction
