# Creditor attribution proof page — verified creditor set, evidence sufficiency, and release freeze

## Purpose

This page is the durable proof object for the strongest true sentence available when creditor attribution has been reviewed but may still be incomplete or contested.
It exists so the archive can say exactly which creditors are verified, which residue remains disputed or unverifiable, and whether clean restoration or probation lift is still frozen.

## Sentences this page may support

- `protected reserve verified; named harmed claimant still contested`
- `verified core restored; disputed residue blocks clean release`
- `creditor residue waived by authority; claimant remains under narrowed standing`
- `all material creditors verified and cleared; release freeze lifted`
- `case reopened on new evidence; prior release withdrawn`

## Mandatory proof blocks

### A. Attribution basis block

- source creditor claim contract sheet
- source review verdict
- verified creditor set now
- contested creditor set now
- unverifiable residue now
- evidence sufficiency grade per class

### B. Horizon-and-freshness block

- oldest load-bearing evidence still relied on
- earliest expiry or rereview deadline among active creditors
- stale-evidence risk now
- whether clean release is frozen by freshness risk
- whether a later rereview is mandatory even if no new dispute appears

### C. Consequence block

- which creditor classes may already receive restoration credit
- which creditor classes remain blocked from `repaired` sentence
- release freeze posture
- probation posture
- future-burst posture
- exact fact needed to improve the sentence

### D. Reopenability block

- reopen allowed now
- reopen authority class
- new-evidence threshold
- exact event that would re-freeze a previously lifted sentence
- exact event that would make closure final

## Required badges

- `creditor-set-verified`
- `verified-core-only`
- `reserve-only-verified`
- `contested-residue-open`
- `unverifiable-residue`
- `release-freeze-active`
- `probation-lift-frozen`
- `future-burst-frozen`
- `reopened`
- `final-release-eligible`

Badges must stack rather than erase lineage.
For example, `verified-core-only` may coexist with `release-freeze-active` and `future-burst-frozen`.

## Proof obligations

- prove creditor verification separately from debt existence
- prove actor attribution separately from overwritten-state residue
- preserve contested residue even when some creditors are already paid
- preserve release freeze when evidence is insufficient or stale
- preserve reopen capability when policy still allows new material evidence

## Stronger-sentence guard

This page may say `verified creditor core restored; clean release still frozen by contested named-neighbor residue`.
It may not say `all harms settled` or `probation lift honest` until every material creditor is verified and resolved or explicitly absorbed under authority.
