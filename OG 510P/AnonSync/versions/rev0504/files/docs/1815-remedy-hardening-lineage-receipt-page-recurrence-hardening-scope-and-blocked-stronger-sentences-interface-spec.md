# Remedy-hardening lineage receipt page — recurrence hardening, rollout scope, and blocked stronger sentences

## Purpose

This receipt is the portable summary of the strongest honest claim about a case that already re-entered guarded ordinary life and is now attempting to claim recurrence resistance.
It exists so later operators can answer `did this case merely recover, or did it actually harden against the same cause?` from one durable object.

## Receipt fields

- receipt identifier
- case identifier
- source remedy-reaccreditation receipt identifier
- triggering cause family
- current remedy-hardening posture rung
- current hardening strategy class
- durable-versus-temporary control class
- required hardening cohort
- current hardening scope
- highest honest current hardening sentence
- strongest blocked stronger recurrence-safe sentence
- rollout coverage ceiling
- activation-proof ceiling
- future carry-forward surface status
- linked-identity spread exposure status
- permission-topology hardening status
- hardening debt class, if any
- next mandatory strengthening trigger
- next automatic weakening trigger

## Mandatory sentence discipline

The receipt must preserve these distinctions:

- cause remediated once versus durable control deployed
- durable control deployed versus required-cohort rollout complete
- required-cohort rollout complete versus active-lane proof achieved
- active-lane proof achieved versus future carry-forward surface closed
- narrowed risk versus recurrence-hardened discharge
- honest re-entry versus hardened re-entry
- sticky scar retained versus recurrence risk truly guarded by durable policy

## Example summary sentences

- `Honest re-entry survived, but durable recurrence hardening is still local-only.`
- `Required-cohort rollout complete, but carry-forward exposure still blocks the stronger recurrence-safe sentence.`
- `Durable control active in the risky lane and carry-forward surfaces closed; recurrence-hardened discharge is now honest.`
- `One topology path remains open, so hardening debt survives despite otherwise healthy post-reentry behavior.`
