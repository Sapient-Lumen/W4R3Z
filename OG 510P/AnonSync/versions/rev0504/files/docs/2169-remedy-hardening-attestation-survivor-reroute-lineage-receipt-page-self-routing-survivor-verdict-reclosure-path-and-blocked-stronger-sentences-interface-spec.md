# Remedy-hardening-attestation survivor-reroute lineage receipt page — self-routing survivor verdict, re-closure path, and blocked stronger sentences

## Purpose

This receipt is the compact lineage object for later readers who need one portable answer to:

**if stale material resurfaces later, can the rediscovered thing itself route the finder to current truth and help restore closure?**

## Receipt header

The receipt header must show at least:

- governed artifact label
- corrected replacement identifier
- highest-risk survivor carrier
- reroute posture
- re-closure verdict

## Minimum body fields

The receipt body must preserve at least:

- carrier summary
- supersession-explanation summary
- canonical-target summary
- operator-dependency summary
- maximum honest re-closure lag
- strongest honest self-routing sentence
- blocked stronger self-routing sentence

## Verdict classes

The receipt must support at least:

- no survivor-carried reroute
- reroute only for named in-lane users
- self-routing proven for named carriers only
- reroute requires operator intervention
- rediscovery re-opened the claim
- rediscovery self-routed and re-closed
- insufficient self-routing proof

## Hard rules

The receipt must never:

- collapse `rediscovery known` into `rediscovery self-routes`
- omit the highest-risk carrier class
- omit operator dependency if any remains
- omit the blocked stronger sentence
