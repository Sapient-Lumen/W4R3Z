# Remedy-hardening-baseline lineage receipt page — baseline absorption, future-arrival safety, and blocked stronger sentences

## Purpose

This receipt is the portable summary of the strongest honest claim about a case that already achieved bounded rollout and now attempts to claim that the hardened behavior is the ordinary safe baseline.
It exists so later operators can answer `was this merely a successful bounded rollout, or did the new hardening truly become the safe baseline for future arrivals?` from one durable object.

## Mandatory sentence discipline

The receipt must preserve these distinctions:

- bounded rollout versus baseline assimilation
- current protected cohort versus future-arrival cohort
- safe default path versus safe admission semantics
- temporary rollout scaffold versus ordinary baseline lane
- scaffold retired versus scaffold merely forgotten
- remembered approval or convenience inheritance versus honest future-arrival-safe baseline
- recurrence-hardened-retained-change-gated-rollout-bounded discharge versus recurrence-hardened-retained-change-gated-rollout-bounded-and-baseline-assimilated discharge

## Example summary sentences

- `The rollout stayed bounded, but the hardened state is not yet the safe baseline for future arrivals.`
- `Future-arrival safety is honest only for named surfaces; stronger baseline language stays blocked by open admission semantics.`
- `Temporary rollout scaffolds still carry part of the safety story, so ordinary-baseline language remains blocked.`
- `The hardened state is now the safe baseline for the required arrival surfaces, with remaining scars explicitly preserved.`
- `Baseline assimilation collapsed after later drift or a reopened arrival surface.`
