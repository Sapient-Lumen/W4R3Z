# Remedy-convergence proof page — present-cohort adoption, returner exposure, and quarantine validity

## Purpose

This page is the case proof that an authoritative repair did or did not converge safely across the cohorts that matter.
It exists so later readers can inspect the evidence behind the convergence sentence instead of inferring it from one calm active roster or one currently correct live copy.

## Proof bundle

The proof page must preserve evidence for:

- intended authoritative object and namespace
- intended required present cohort
- intended required returning cohort
- intended possible future-joiner cohort
- connected full-sync adoption evidence
- placeholder-only cohort evidence
- disconnected cohort evidence
- pending or auto-connect cohort evidence
- linked-device auto-availability evidence
- offline-writer return-risk evidence
- read-only suspended-divergence evidence
- quarantine and admission-scope evidence
- strongest honest convergence sentence
- strongest blocked stronger convergence sentence

## Proof sentence families

The page must support concise summaries such as:

- `the repair became authoritative for active peers, but one offline writer can still return with higher precedence, so returner-safe convergence remained blocked`
- `present full-sync cohorts converged while selective-sync cohorts remained placeholder-only, keeping the stronger all-required-cohort convergence sentence blocked`
- `a previously approved pending participant could still auto-connect later, so future-joiner-safe convergence was not yet honest`
- `linked-device auto-availability widened the possible participant set faster than the review could safely admit it, so quarantine stayed active`
- `a read-only participant held suspended local divergence, so visible calm did not justify the stronger convergence sentence`

## Invariants

- the proof never compresses cutover, present-cohort convergence, returner-safe convergence, and future-joiner-safe convergence into one word
- the proof never hides placeholder-only, disconnected, or pending cohorts behind visible folder presence
- the proof never lets approval memory or linked-device convenience impersonate reviewed convergence
- the proof always preserves the blocker that prevented the stronger convergence sentence
