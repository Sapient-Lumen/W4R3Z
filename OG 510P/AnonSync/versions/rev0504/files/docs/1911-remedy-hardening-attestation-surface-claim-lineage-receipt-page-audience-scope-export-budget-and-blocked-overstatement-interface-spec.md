# Remedy-hardening-attestation surface-claim lineage receipt page — audience scope, export budget, and blocked overstatement

## Purpose

This page is the durable receipt that captures what each audience and surface was honestly allowed to hear or export for a case at a specific time.
It must survive later review and show not merely the strongest current internal truth, but the precise sentence budget, qualifier set, export policy, and stale-artifact status that governed publication.

## Receipt header

The receipt must print:

- receipt identifier
- case identifier
- source egress-governance receipt identifier
- current governing receipt identifier
- current surface-claim-governance class
- issuance time
- highest audience-safe sentence class in force
- strongest blocked broader sentence

## Receipt body

The receipt must always include:

- strongest speakable internal sentence
- strongest speakable named-operator sentence
- strongest speakable named-recipient sentence
- strongest speakable public sentence
- required qualifier set
- blocked stronger phrase set
- export permission class for each surface family
- stale-artifact recall status summary
- exact reason broader language remains blocked

## Mandatory distinctions preserved by the receipt

The receipt must preserve at least these distinctions:

- internal truth versus audience-safe rendering
- current authority versus historical reference
- visible older artifact versus still-authoritative older artifact
- named-recipient sentence versus public sentence
- export allowed versus on-screen-only rendering
- superseded wording versus recalled wording

## Example speakable sentences

The receipt should support outputs such as:

- `internal ruling stronger than public budget; public surface limited to ceiling-aware minimal sentence`
- `named recipients may receive the qualified sentence; copied outward artifacts must carry supersession pointer`
- `detail pages may render the current sentence with qualifiers; notifications restricted to historical-safe shorthand`
- `older stronger export remains visible only as historical artifact and is no longer authoritative`
- `public language remains blocked above the current floor; stronger operator language is receipt-bound`

## Claim ceilings

The receipt must never let later operators silently say:

- `the UI said it, so it was safe to quote everywhere`
- `older exported wording remained current by default`
- `badge calm and full detail sentence were equivalent`
- `named-recipient wording was safe for public reuse`
- `historical artifact harmless means historical artifact authoritative`
- `all surfaces were automatically synchronized to the strongest sentence`

## Precedence rules

The receipt must make these rules explicit:

- a later stronger sentence only becomes speakable on a surface through a new receipt that explicitly widens that surface budget
- a downgrade automatically narrows later publication even if older artifacts remain visible as history
- stale stronger artifacts require explicit recall, watermark, banner, or export freeze handling; silence is not enough
- public-safe language remains subordinate to permanent blockers such as off-world memory ceiling or other stronger blocked-global-sentence constraints
