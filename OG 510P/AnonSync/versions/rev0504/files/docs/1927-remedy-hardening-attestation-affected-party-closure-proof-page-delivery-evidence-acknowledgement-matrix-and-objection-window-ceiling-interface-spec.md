# Remedy-hardening-attestation affected-party-closure proof page — delivery evidence, acknowledgement matrix, and objection-window ceiling

## Purpose

This page is the evidence-heavy proof surface for closure claims after remediation.
It proves the exact ceiling on any sentence about notice, acknowledgement, acceptance, or uncontested closure.

## Required evidence blocks

### 1. Materiality basis

Preserve:

- why each cohort counts as materially affected
- source receipt or dependency basis that made notice necessary
- any unknown-cohort ceiling

### 2. Delivery evidence matrix

For each required party or cohort preserve:

- required channel or acceptable channel set
- attempts made
- proof of delivery class
- proof timestamp
- unresolved reachability gap

### 3. Acknowledgement matrix

For each required acknowledgement preserve:

- acknowledgement obligation class
- acknowledgement evidence class
- explicit acceptance, explicit contest, or neutral acknowledgement state
- unresolved silence after proven delivery

### 4. Objection-window ledger

Preserve:

- policy that defines the objection window
- open, lapsed, paused, or reopened state
- earliest and latest active deadlines
- event that would reopen closure after lapse

### 5. Claim ceiling

Render:

- highest honest notice sentence
- highest honest acknowledgement sentence
- highest honest acceptance or uncontested-closure sentence
- blocked stronger sentence and exact blocker

## Evidence classes

The page must distinguish at least:

- notice obligation asserted but unsupported
- delivery attempted only
- delivery proven by system evidence
- delivery proven by external receipt
- acknowledgement explicit
- acknowledgement implicit but policy-insufficient
- explicit contest
- silence with open objection window
- silence after lapsed objection window
- reopened after prior acceptance or lapse

## Hard rules

The proof page must never treat:

- UI visibility as delivery proof by itself
- a bell or notification toggle as acknowledgement
- permission change as acceptance
- silence as assent while the objection window remains open
- one successful channel as proof for every materially affected party
