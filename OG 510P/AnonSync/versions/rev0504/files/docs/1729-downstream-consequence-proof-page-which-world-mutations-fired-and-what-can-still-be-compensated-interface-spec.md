# Downstream-consequence proof page — which world mutations fired and what can still be compensated?

## Purpose

This page is the durable proof artifact for any claim about what a sentence version already changed downstream.
It exists so the product can later prove not only that a sentence was used, but what world mutations followed, what repairs were attempted, and what residue still blocks a stronger reversal claim.

## Mandatory proof fields

### 1. Source linkage

- case identifier
- consumer-uptake receipt identifier
- sentence version handle
- rule version for consequence classification
- any superseding or rollback sentence identifiers already known

### 2. Consequence-by-consequence strongest state

For each named consequence cohort or target:

- strongest evidenced consequence rung
- evidence time and trusted time basis
- whether evidence is direct, inferred, or contested
- mutation scope: local, connected cohort, required cohort, external, or public
- whether a halt lane existed and whether it was missed
- whether later reconnect, relink, rescan, or source return could strengthen or reopen the mutation claim

### 3. Repair and debt basis

- whether ordinary rollback remained available at decision time
- whether inverse action was attempted
- whether compensation is owed and to whom
- compensation type and amount or scope
- whether compensation can fully clear the path or only narrow residue
- whether any human or agent executed repair under stale or superseded basis

### 4. Residue statement

- surviving bytes or copies
- surviving access or authority
- surviving public/external effects
- surviving automation side effects
- surviving audit or disclosure obligations
- strongest blocked stronger reversal sentence

## Required proof statements

The page must be able to state sentences like:

- `sentence version S-18 was used for review, but no downstream mutation beyond internal rendering was proven`
- `sentence version S-18 triggered local filesystem mutation for cohort B, but halt occurred before required-cohort propagation`
- `sentence version S-18 produced connected-cohort mutation and later required compensation because direct rollback no longer reached all previously synchronized peers`
- `sentence version S-18 drove an external/public action; compensation can narrow harm but cannot honestly erase residue`
- `a later reconnect re-materialized an earlier mutation path after rollback, so the stronger `fully unwound` sentence is downgraded`

## Proof ceiling

This page may prove what downstream consequences occurred and what repair posture is honest.
It may not by itself prove that a proposed compensation is normatively sufficient unless the relevant compensation policy separately agrees.

## Preservation rules

The proof must preserve:

- the sentence version that triggered the consequence
- the strongest evidenced mutation rung for each cohort
- direct vs inferred mutation evidence
- haltable vs compensable vs irreversible consequence classes
- the strongest blocked stronger reversal sentence
- the next event that would strengthen or weaken the consequence claim
