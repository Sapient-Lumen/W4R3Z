# Remedy-hardening-attestation successor beneficiary-adherence lineage receipt page — adherence summary, relapse budget, and blocked stronger compliance sentences

## Purpose

This receipt compresses the adherence verdict into a portable record without flattening interval truth.
It exists so later readers can see whether the named beneficiary merely adopted once, relapsed and recovered, or actually stayed switched through the governed horizon.

## Minimum receipt fields

The receipt must show at least:

- receipt identifier
- named beneficiary identifier
- governed slice identifier
- canonical correction identifier
- governed horizon identifier
- lapse-budget class
- final adherence standing
- open relapse incident count
- recovered relapse incident count
- strongest honest adherence sentence
- blocked stronger compliance sentence
- supersession state

## Required summary sentence

The receipt must render one sentence in plain language, such as:

- beneficiary adopted corrected working state, but governed-horizon adherence remains unproven
- beneficiary relapsed and later recovered; uninterrupted-adherence sentence remains blocked
- beneficiary stayed switched through the governed horizon for the named slice only

The receipt must always preserve the blocked stronger sentence directly underneath.

## Required badges

Show compact badges for:

- horizon open / closed
- relapse-free / relapsed / recovered
- lapse budget respected / exceeded / unreviewed
- present-state aligned / whole-horizon aligned
- slice-only / broader compliance blocked

## Portable truth requirement

A reader opening only this receipt must still be able to tell:

- whether the claim is point-in-time or interval-wide
- whether any relapse happened
- whether recovery occurred
- whether uninterrupted adherence was actually proven
- whether the result is narrow to one beneficiary and one slice

## Hard rules

The receipt must never allow:

- `currently aligned` to replace `historically aligned`
- `recovered` to replace `uninterrupted`
- an open horizon to read as a closed compliance verdict
- a slice-level adherence result to impersonate broad ecosystem compliance
