# Remedy-surveillance proof page — relapse signals, platform coverage, and re-fence authority

## Purpose

This page is the case proof that a discharged case did or did not remain guarded after release to ordinary life.
It exists so later readers can inspect the evidence behind the surveillance sentence instead of inferring it from one quiet UI, one synced notification, or a short history pane.

## Proof bundle

The proof page must preserve evidence for:

- intended authoritative object and namespace
- source remedy-discharge result
- current ordinary-lane scope
- required surveillance cohort
- actually armed surveillance cohort
- platform coverage evidence
- runtime blind-spot evidence
- signal-family coverage evidence
- notification-delivery evidence
- history-window evidence
- escalation-authority evidence
- automatic re-fence threshold evidence
- strongest honest surveillance sentence
- strongest blocked stronger surveillance sentence

## Proof sentence families

The page must support concise summaries such as:

- `the case was discharged, but surveillance remained armed only for a named desktop cohort, so stronger ordinary-life claims stayed blocked`
- `a relapse signal was visible somewhere, but required re-fence authority or threshold had not yet fired`
- `Android background degradation and Linux in-UI-only visibility kept the honest sentence at platform-blind surveillance rather than fully guarded continuation`
- `the relapse threshold was met and automatic re-fence executed before broader admission resumed`
- `surveillance collapsed because the product could no longer honestly say the required cohorts and signal families were still being watched`

## Invariants

- the proof never compresses discharge, guarded continuation, signal observation, threshold satisfaction, and re-fence into one word
- the proof never hides platform blind spots behind a single quiet UI surface
- the proof never lets synced notifications impersonate case-scoped relapse watch
- the proof always preserves the blocker that prevented the stronger surveillance sentence
