# Remedy-watch-uncertainty lineage receipt page — confidence decay, fail-safe posture, and blocked ordinary-life sentences

## Purpose

This receipt is the portable summary of the strongest honest claim about a discharged case once guard confidence starts to decay.
It exists so later operators can answer `if the guard went uncertain, what happened next?` from one durable object.

## Receipt fields

- receipt identifier
- case identifier
- source remedy-watch-health receipt identifier
- current ordinary-lane scope
- required guarded cohort
- uncertainty-declared cohort
- highest honest uncertainty sentence
- strongest blocked stronger ordinary-life sentence
- current uncertainty budget
- current uncertainty age
- uncertainty start time
- automatic fail-safe policy class
- automatic fail-safe execution status
- manual fail-safe obligation status
- current platform blind spots
- current runtime blind spots
- current detection fallback class
- next mandatory strengthening trigger
- next automatic weakening trigger

## Mandatory sentence discipline

The receipt must preserve these distinctions:

- watch health proven versus uncertainty-bounded ordinary life
- named-cohort uncertainty versus required-cohort uncertainty
- uncertainty inside grace budget versus uncertainty over budget
- fail-safe configured versus fail-safe executed
- automatic narrowing versus automatic re-fence
- unresolved uncertainty versus uncertainty cleared by fresh proof
- discharged ordinary life versus blocked stronger ordinary-life sentence

## Example summary sentences

- `Guard recently healthy, but required-cohort uncertainty declared: grace budget running before automatic fail-safe.`
- `Required-cohort uncertainty exceeded budget; automatic re-fence fired; stronger ordinary-life sentence blocked.`
- `Named-lane uncertainty only; required-cohort guard remains honest under declared blind-lane exclusion.`
- `Service notification loss forced restart-only discovery; manual fail-safe still required before ordinary-life claim can remain honest.`
