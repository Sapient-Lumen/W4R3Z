# Remedy-hardening-change-gate proof page — change scope, approval coverage, and reseal floor

## Purpose

This page is the proof bundle behind the claim that a case which already achieved retained recurrence hardening may safely admit later intentional changes without reopening the original cause family.
It exists so later readers can inspect authority basis, proposed-change scope, regression envelope, and reseal evidence instead of inferring them from operational convenience surfaces.

## Proof bundle

The proof page must preserve evidence for:

- source remedy-hardening-retention result
- triggering cause family
- current retained-hardening baseline
- proposed change class
- change initiator class
- operational authority evidence
- cause-safe change authority evidence
- required review cohort
- approval threshold evidence
- Standard-versus-Advanced sharing exposure, if relevant
- linked-device spread exposure, if relevant
- per-folder preference or manual-override interaction evidence
- peer-local rule divergence interaction evidence
- expected regression budget
- reseal requirement evidence
- highest honest current change-governed sentence
- strongest blocked stronger change-governed sentence

## Proof sentence families

The page must support concise summaries such as:

- `the case remains retained-hardened, but future permission mutations are still ungated for this cause family`
- `the operator has broad share authority, yet this topology change remains outside cause-safe mutation authority`
- `the proposed change may proceed only with required-cohort approval and mandatory reseal`
- `the change went live under temporary regression debt because reseal proof is still pending`
- `future mutation is now governed tightly enough that recurrence-hardened-retained-and-change-gated discharge is honest`

## Stronger-sentence blockers

The page must explicitly name blockers such as:

- change gate unreviewed
- cause-safe authority not proven
- proposed change outside safe envelope
- linked-device or onward-share exposure still open
- manual override interaction unresolved
- peer-local rule divergence still open
- required approval threshold not met
- reseal still pending
- evidence basis too weak

## Evidence handling rules

The proof page must never let these substitute for stronger proof:

- one owner right without cause-family review
- one successful share action without review of carry-forward surface
- one startup config file without post-change reseal evidence
- one calm preference screen without lane-by-lane scope proof
- one retained-hardening receipt without proposed-change-specific evidence
