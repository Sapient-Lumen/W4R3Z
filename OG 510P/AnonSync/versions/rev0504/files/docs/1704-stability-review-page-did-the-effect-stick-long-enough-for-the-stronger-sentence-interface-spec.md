# Stability review page — did the effect stick long enough for the stronger sentence?

## Review question

This page answers one narrow but decisive question:

> did the already-attained effect remain sufficiently clean, across the required horizon and cohort, that the product may now promote from `attained` to a stronger `stable` sentence?

## Required review branches

### Branch 1 — transient attainment

Use this branch when the effect landed but the observation clock has barely started.
The page must show:

- what landed
- when attainment began
- how long the dwell requirement is
- what would reset the clock
- why the stronger sentence is still blocked

### Branch 2 — connected-only calm

Use this branch when connected peers look stable but some required participants remain offline, disconnected, or otherwise unobserved.
The page must show:

- which cohort is currently calm
- which missing participants still matter
- whether those participants retain reopen power
- why green or quiet state is not enough

### Branch 3 — regression-sensitive observation

Use this branch when the act type is especially vulnerable to later overwrite, late conflict, or restore-driven regressions.
The page must show:

- why this act has a higher stability bar
- which regression channels are material
- whether the product is waiting on rescan, reconnect, or archive-related risk to pass
- what narrower truths may still be used meanwhile

### Branch 4 — reopened after drift

Use this branch when a later event weakens an already-attained or already-stable result.
The page must show:

- what earlier rung had been earned
- what reopening event occurred
- whether the earlier attainment remains historically true
- what stronger sentence is now downgraded
- whether compensation, rollback, or renewed observation is required

### Branch 5 — stability earned

Use this branch only when the effect truly survived the required observation horizon for the required cohort.
The page must show:

- exact start and finish of the stability window
- trusted time basis used
- cohort actually covered
- regression budget applied
- residue that was tolerated or cleared
- exact stronger sentence now earned

## Review invariants

The page must always preserve these invariants:

- earlier attainment history is preserved even if stability later fails
- observation windows are typed by act family rather than globally uniform
- unobserved high-power participants keep stronger stable claims blocked
- restore, rescan, reconnect, or late conflict may reopen without forcing the product to deny everything that happened earlier
- stability-earned is still weaker than any stronger sentence the exact row has not authorized

## Required reviewer prompts

- what is the smallest honest sentence right now?
- what stronger sentence is blocked?
- which participant or event still carries reopen power?
- is the missing issue time, cohort coverage, or regression uncertainty?
- what exact event would let the product promote to stable?
- what exact event would force full or narrow reopen?

## Forbidden shortcuts

This page must not let the reviewer conclude stability from any single shortcut such as:

- green check alone
- warning absence alone
- connected peers alone
- quiet history alone
- local manual restore alone
- one successful rescan alone

Those are ingredients.
They are not the stability verdict.
