# Remedy-hardening-attestation successor execution provenance lineage receipt page — attributed run, causal source, and blocked stronger non-repudiation sentences

## Purpose

This page is the portable receipt summarizing what can honestly be claimed about the causal source of one executed run.
Later pages must cite this receipt instead of improvising `the reviewed run fired`, `the controller definitely caused it`, or `the background did not participate` language.

## Receipt header

The header must show:

- receipt identifier
- action identifier
- execution-run identifier
- bound-preview receipt identifier
- current execution-provenance standing
- current strongest safe sentence
- current blocked stronger sentence

## Mandatory receipt fields

- source preview/commit-binding receipt identifier
- source action-envelope receipt identifier
- reviewed actuator summary
- actual actuator summary
- initiating actor summary
- initiating subsystem summary
- execution world summary
- automatic-hazard families checked
- automatic-hazard families still blind
- widening or substitution summary
- first-effect time
- current attribution verdict
- contradiction status
- superseding receipt identifier if any

## Standing states

The receipt must support at least these states:

- bound run exists, execution not yet observed
- execution observed, causal source partial
- initiating actor observed, actual lane still partial
- run attributable to reviewed actor and reviewed lane for named slice only
- run happened with unresolved automatic-behavior ambiguity
- substitute actuator produced the effect
- execution-world ambiguity remains
- later contradiction narrowed or overturned attribution
- receipt superseded

## Primary sentence classes

The receipt must be able to emit at least these classes:

- `bound run exists; execution provenance still unproven`
- `execution observed; actor source partial; stronger attributable-run sentence blocked`
- `manual fire evidenced for named slice only`
- `reviewed actor and reviewed lane matched for named slice only`
- `visible outcome occurred; background or substitute causality still plausible`
- `substitute lane produced comparable effect; reviewed-run sentence withdrawn`
- `execution world ambiguous; stronger non-repudiation sentence blocked`
- `later contradiction narrowed attribution confidence`

## Hard rules

The receipt must never let later pages say:

- this exact reviewed run definitely fired
- the named controller unquestionably caused the effect
- no background automation participated
- the reviewed actuator was the only causal path
- execution provenance is final and non-repudiable

unless the receipt actually carries the corresponding proof state.
