# Remedy-hardening-change-gate lineage receipt page — change authority, regression risk, and blocked stronger sentences

## Purpose

This receipt is the portable summary of the strongest honest claim about a case that already achieved retained recurrence hardening and now attempts to claim that future intentional change is safely governed.
It exists so later operators can answer `did the case merely stay hardened, or did it also earn a trustworthy gate for future change?` from one durable object.

## Receipt fields

- receipt identifier
- case identifier
- source remedy-hardening-retention receipt identifier
- triggering cause family
- current remedy-hardening-change-gate posture rung
- current retained-hardening baseline
- proposed or most recent change class
- change initiator class
- cause-safe change authority class
- required review cohort
- approval threshold class
- regression budget class
- mandatory reseal class, if any
- highest honest current change-governed sentence
- strongest blocked stronger change-governed sentence
- linked-device or onward-share exposure status
- manual-override interaction status
- peer-local rule divergence interaction status
- regression debt class, if any
- next mandatory strengthening trigger
- next automatic weakening trigger

## Mandatory sentence discipline

The receipt must preserve these distinctions:

- retained hardening now versus future change safely governed
- broad owner or read-write authority versus cause-safe mutation authority
- approved change versus applied change
- applied change versus resealed change
- one safe lane versus every required lane safe to mutate
- retained recurrence safety versus recurrence-hardened-retained-and-change-gated discharge

## Example summary sentences

- `Retained hardening stands, but future change governance is still unreviewed for this cause family.`
- `Broad operational authority exists, but the proposed mutation remains outside cause-safe authority.`
- `The change was approved only with mandatory reseal; stronger discharge language stays blocked until reseal completes.`
- `A bypassed or partially reviewed mutation reopened regression debt despite otherwise retained hardening.`
- `Future intentional change is now governed tightly enough that recurrence-hardened-retained-and-change-gated discharge is honest.`
