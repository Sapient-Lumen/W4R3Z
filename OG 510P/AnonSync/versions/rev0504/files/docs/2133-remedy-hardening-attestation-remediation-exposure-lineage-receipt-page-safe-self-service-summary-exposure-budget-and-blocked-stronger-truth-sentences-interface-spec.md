# Remedy-hardening-attestation remediation-exposure lineage receipt page — safe self-service summary, exposure budget, and blocked stronger truth sentences

## Purpose

This page is the portable receipt for carrying the bounded-remediation verdict into later review, audit, or dispute contexts.
It exists so that a later reader can tell, without reopening the whole proof stack, whether a late outsider could remediate stale reliance from the corrected surface **without widening exposure beyond the reviewed budget**.

## Core output

The receipt must answer:

**what is the strongest honest sentence we can carry forward about safe outsider remediation now, and what stronger bounded-exposure sentence remains blocked?**

## Required header fields

Show at least:

- receipt identifier
- action identifier
- stale artifact identifier
- corrected replacement identifier
- proof freshness timestamp
- current remediation-exposure standing

## Mandatory summary block

The summary block must include:

- remediation carrier class
- audience breadth class
- onward-reshare class
- permission-widening class
- expiry / click-budget class
- retention-residue class
- highest-risk open leak-budget exception
- strongest honest safe-remedy sentence
- blocked stronger bounded-exposure sentence

## Mandatory sentence ladder

The receipt must preserve at least these separations:

- outsider can trust the correction only
- outsider can remediate but carrier is bearer-broad
- outsider can remediate under approval gate only
- outsider can remediate and forwarding remains open
- outsider can remediate on one bounded path only
- broader bounded-exposure sentence blocked
- remediation completion still separate

## Mandatory blocker block

For every blocked stronger sentence show:

- blocker name
- blocker class
- affected carrier or surface
- whether the blocker is audience breadth, resharing, permission widening, or residue
- what stronger sentence it prevents

## Mandatory provenance block

The receipt must preserve:

- who assembled the exposure proof
- what evidence sources were used
- which boundedness claims are direct proof
- which boundedness claims are inference only
- when the exposure horizon is considered to end

## Interaction requirements

The receipt must support:

- expanding any blocker into full proof detail
- opening the remediation-carrier map from the summary chip
- comparing this receipt against the earlier actionable-remedy receipt without losing sentence distinctions
- exporting a compact version that still keeps the blocked stronger sentence visible
