## Quantifier-drift timeline

### Purpose
Show how the counterpart set behind a sentence can change even when the surface noun stays the same.

### Drift events that must be recorded
- approval rule change from `only new peers` to `all peers`
- certificate / approval memory reuse on another folder
- peer roster decay after offline timeout
- source-byte loss that invalidates a former `available now` sentence
- self-only local share creation that increases rows without increasing independent holders
- linked-family removal that narrows the visible set without proving remote extinction

### Timeline language
Each event records:

- old subject set
- new subject set
- old sufficiency rule
- new sufficiency rule
- which prior sentence became too strong
- whether the product auto-downgraded that sentence in time
