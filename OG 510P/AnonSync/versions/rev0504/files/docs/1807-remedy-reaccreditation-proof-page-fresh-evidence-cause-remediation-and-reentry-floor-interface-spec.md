# Remedy-reaccreditation proof page — fresh evidence, cause remediation, and re-entry floor

## Purpose

This page is the proof bundle behind the claim that a previously uncertain or re-fenced case has honestly requalified for guarded ordinary life again.
It exists so later readers can inspect remediation, proof refresh, authority, and sticky-scar evidence instead of inferring them from recovery activity alone.

## Proof bundle

The proof page must preserve evidence for:

- source remedy-watch-uncertainty result
- original uncertainty cause family
- cause-remediation evidence
- restored signal-path evidence
- restart, rescan, reconnect, or force-rescan evidence
- required requalification cohort
- required-cohort proof refresh evidence
- end-to-end drill evidence after recovery
- re-entry authority evidence
- automatic re-entry execution evidence
- manual re-entry completion evidence
- sticky-scar assignment evidence
- tightened watch-budget evidence
- strongest honest current re-entry sentence
- strongest blocked stronger ordinary-life sentence

## Proof sentence families

The page must support concise summaries such as:

- `restart and force rescan restored visibility, but re-entry stayed blocked until required-cohort proof and post-recovery drill both passed`
- `the uncertainty cause was remediated, fresh proof covered the required cohort, and guarded ordinary life resumed only under a tighter watch budget`
- `only one lane regained healthy signals, so the case remained fenced despite quiet visible surfaces elsewhere`
- `manual re-entry authority was required because the case had escalated to full re-fence before recovery`
- `re-entry became honest again, but only with a sticky scar that blocks scar-cleared ordinary-life language`

## Stronger-sentence blockers

The page must explicitly name blockers such as:

- uncertainty still active
- cause-remediation evidence missing
- required-cohort proof stale
- post-recovery drill missing
- re-entry authority missing
- manual re-entry incomplete
- sticky scar not assigned
- tighter budget not armed
- evidence basis too weak

## Evidence handling rules

The proof page must never let these substitute for stronger proof:

- one restart without post-recovery verification
- one rescan without required-cohort evidence
- one recovered notification surface without cause remediation
- one log bundle without adjudicated re-entry authority
- one named-lane recovery when the required cohort still lacks fresh proof
