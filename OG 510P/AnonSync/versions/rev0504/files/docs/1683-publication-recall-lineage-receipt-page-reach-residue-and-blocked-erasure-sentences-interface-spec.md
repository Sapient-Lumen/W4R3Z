# Publication-recall lineage receipt page — reach, residue, and blocked erasure sentences

## Purpose

This page is the compact carry-forward receipt for what recall happened, who was actually reached, what residue still survives, and what stronger erasure sentence the product refused to make.
It exists so later operators can answer `what exactly was corrected, for whom, and what is still not safely forgettable?` without reopening the whole case.

## Mandatory receipt fields

- source publication identifier
- recall version identifier
- recall class
- audience class or named audience covered by this receipt
- reach status
- acknowledgement status if relevant
- highest recall sentence earned
- surviving residue class
- strongest blocked erasure or clawback sentence
- next event that could narrow residue further or freeze it in place

## Required compact verdicts

At minimum the receipt must be able to state verdicts like:

- `correction issued; participant reach still partial`
- `all named participants reached; external summary clawback blocked`
- `future reliance withdrawn; audit trace preserved`
- `viewer access removed; prior semantic residue still possible`
- `encrypted custody only; semantic recall not applicable`
- `full erasure blocked; export residue unresolved`

## Required comparisons

The receipt must keep these comparisons explicit:

- `reach attempted` vs `reach proven`
- `future-use withdrawn` vs `past-use extinguished`
- `trace preserved for audit` vs `ordinary publication still live`
- `access removed now` vs `knowledge removed everywhere`
- `semantic residue survives` vs `semantic residue adjudicated away`

## Failure modes the receipt must prevent

- later operators assuming that a retraction automatically reached every audience
- later operators assuming that losing access means forgetting or undoing prior reliance
- losing the reason a stronger erasure sentence stayed blocked
- losing which residue class still survives and for whom
- losing the reason audit-grade visibility persisted after ordinary reliance was narrowed

## Stronger-sentence guard

This receipt may say `future participant reliance withdrawn; named participants reached; public clawback blocked because external residue remains unresolved`.
It may not say `the publication was fully erased` unless that stronger sentence was actually earned.
