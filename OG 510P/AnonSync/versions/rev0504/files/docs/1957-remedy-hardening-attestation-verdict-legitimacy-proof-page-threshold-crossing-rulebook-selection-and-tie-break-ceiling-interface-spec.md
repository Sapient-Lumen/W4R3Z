# Remedy-hardening-attestation verdict-legitimacy proof page — threshold crossing, rulebook selection, and tie-break ceiling

## Purpose

This page is the evidence-heavy proof surface for determining whether the trusted witness set actually satisfies the current adjudication rule.
It proves the exact ceiling on any sentence that tries to say current conformance, current breach, or current still-governing standing is not merely plausible but legitimately adjudicated under the active rulebook.

## Required evidence blocks

### 1. Target-sentence basis

Preserve:

- source observer-integrity receipt
- sentence being supported or refused
- minimum burden required for that sentence

### 2. Rulebook-selection ledger

Preserve:

- selected rulebook identifier and version
- product-version, platform, topology, and world applicability
- prior or sibling rulebooks considered and rejected
- why the current rulebook governs this case

### 3. Authority, burden, and threshold ledger

Preserve:

- authorized adjudicator
- burden class selected
- threshold rule or decision function
- tie-break rule
- override or exception state
- ratification requirement if any

### 4. Evidence-admission ledger

Preserve:

- trusted evidence admitted
- trusted evidence excluded
- rationale for each exclusion
- resulting downgrade or narrowing in verdict scope

### 5. Claim ceiling

Render:

- highest honest sentence under the current rulebook
- highest honest sentence under any deprecated or sibling rulebook
- highest honest named-slice-only sentence
- blocked stronger sentence and exact blocker

## Evidence and verdict classes

The page must distinguish at least:

- trusted evidence only, no burden chosen
- current rulebook ambiguous
- authority disputed
- threshold not met
- threshold met for named slice only
- tie-break unresolved
- exception review open
- deprecated-rulebook-only pass
- verdict ratified under current rulebook
- broader stronger sentence blocked

## Hard rules

The proof page must never treat:

- trusted evidence as self-interpreting by default
- a visible status meaning as universal across all worlds and versions
- queue appearance as proof of operative decision order
- one adjudicator action as authoritative without an authority field
- a deprecated rulebook pass as proof under the current rulebook
