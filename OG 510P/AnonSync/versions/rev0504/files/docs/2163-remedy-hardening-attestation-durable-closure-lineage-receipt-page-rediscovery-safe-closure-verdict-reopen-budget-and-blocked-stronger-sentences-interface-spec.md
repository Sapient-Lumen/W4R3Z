# Remedy-hardening-attestation durable-closure lineage receipt page — rediscovery-safe closure verdict, reopen budget, and blocked stronger sentences

## Purpose

This receipt is the compact lineage object for later readers who need one portable answer to:

**was closure only true at the declared horizon, or is it still honest if stale material resurfaces later?**

## Receipt header

The receipt header must show at least:

- governed audience label
- corrected replacement identifier
- base closure verdict
- durability horizon class
- highest-severity rediscovery surface
- durable-closure verdict

## Minimum body fields

The receipt body must preserve at least:

- rediscovery surface summary
- latent survivor summary
- automatic invalidator summary
- maximum honest re-open lag
- latest durable evidence summary
- strongest honest durable-closure sentence
- blocked stronger durable-closure sentence

## Verdict classes

The receipt must support at least:

- point-in-time closure only
- closure durable for named slices only
- durable closure conditional on invalidator budget
- durable closure blocked by latent survivors
- closure re-opened by late survivor rediscovery
- durable closure re-established after rediscovery
- insufficient durable-closure proof

## Hard rules

The receipt must never:

- collapse `closed once` into `durably closed`
- omit the rediscovery surface set
- omit automatic invalidators
- omit latent survivor classes
- omit the blocked stronger sentence
