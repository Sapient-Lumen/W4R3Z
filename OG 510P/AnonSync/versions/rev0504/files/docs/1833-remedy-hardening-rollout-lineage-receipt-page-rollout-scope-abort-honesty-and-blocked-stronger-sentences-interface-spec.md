# Remedy-hardening-rollout lineage receipt page — rollout scope, abort honesty, and blocked stronger sentences

## Purpose

This receipt is the portable summary of the strongest honest claim about a case that already achieved retained and change-gated recurrence hardening and now attempts to claim that an approved change may safely spread.
It exists so later operators can answer `was the change merely approved, or was its rollout actually bounded tightly enough to trust?` from one durable object.

## Receipt fields

- receipt identifier
- case identifier
- source remedy-hardening-change-gate receipt identifier
- triggering cause family
- current remedy-hardening-rollout posture rung
- approved or most recent change class
- rollout initiator class
- named pilot cohort
- required rollout cohort
- blast-radius ceiling class
- linked-device auto-spread exposure status
- Standard-versus-Advanced onward-share exposure status
- share-link exposure status
- local-share containment status
- synchronization-mode participation summary
- abort-readiness class
- rollback-honesty class
- spread debt class, if any
- compensation requirement class, if any
- required reseal class, if any
- highest honest current rollout-bounded sentence
- strongest blocked stronger rollout-bounded sentence
- next mandatory strengthening trigger
- next automatic weakening trigger

## Mandatory sentence discipline

The receipt must preserve these distinctions:

- approved change versus bounded rollout
- named pilot scope versus required rollout scope
- future spread stoppable versus already-spread change unwindable
- abort armed versus abort still honest
- pilot success versus post-rollout reseal complete
- retained and change-gated hardening versus recurrence-hardened-retained-change-gated-and-rollout-bounded discharge

## Example summary sentences

- `The change is approved, but rollout remains unbounded for this cause family.`
- `Pilot rollout is live for the named cohort only; stronger rollout language stays blocked by open spread surfaces.`
- `Abort can still stop future spread, but already-landed lanes make pure abort language dishonest.`
- `Non-pilot spread opened rollback or compensation debt despite prior approval.`
- `Rollout is now bounded tightly enough that recurrence-hardened-retained-change-gated-and-rollout-bounded discharge is honest.`
