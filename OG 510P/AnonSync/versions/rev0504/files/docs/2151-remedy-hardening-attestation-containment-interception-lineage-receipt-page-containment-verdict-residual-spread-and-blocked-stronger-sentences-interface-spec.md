# Remedy-hardening-attestation containment-interception lineage receipt page — containment verdict, residual spread, and blocked stronger sentences

## Purpose

This receipt is the compact lineage object for later readers who need one portable answer to:

**if relapse begins, is it merely watched, actually intercepted, only narrowed after some spread, or still left to manual containment with residual stale state surviving elsewhere?**

## Receipt header

The receipt header must show at least:

- outsider or audience slice
- corrected replacement identifier
- containment plane class
- highest-severity open channel
- containment verdict

## Minimum body fields

The receipt body must preserve at least:

- interceptable-channel count
- non-interceptable-channel count
- maximum honest spread before interception summary
- residue-after-containment summary
- containment evidence summary
- unresolved residual audience summary
- strongest honest containment sentence
- blocked stronger containment sentence

## Verdict classes

The receipt must support at least:

- watched only
- manually containable only
- narrowed after spread
- intercepted with residual residue
- auditable containment for named channels only
- containment failed / stronger sentence collapsed
- insufficient containment proof

## Hard rules

The receipt must never:

- collapse `watched` into `intercepted`
- collapse `disconnected` into `cleaned up`
- collapse `read-only backflow blocked` into `audience stayed clean`
- omit residual spread or residual stale-state summaries
- omit the blocked stronger sentence
