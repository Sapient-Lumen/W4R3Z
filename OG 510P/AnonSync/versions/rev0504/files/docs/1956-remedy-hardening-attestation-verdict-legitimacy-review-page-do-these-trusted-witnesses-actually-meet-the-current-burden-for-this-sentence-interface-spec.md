# Remedy-hardening-attestation verdict-legitimacy review page — do these trusted witnesses actually meet the current burden for this sentence?

## Purpose

This page is the operator-facing review that answers the practical adjudication question after witness trust is good enough: given the current trusted evidence, is the product actually allowed to publish this sentence under the active rulebook, burden, and threshold?

## Primary review prompts

The review must answer these prompts in order:

1. **Which sentence is the product trying to publish or refuse?**
2. **Which rulebook version governs that sentence here?**
3. **Who is authorized to make or ratify this verdict?**
4. **Which burden and threshold apply to this sentence?**
5. **Which trusted evidence counts, and which trusted evidence is excluded?**
6. **What is the strongest sentence the product may honestly say now?**

## Review sections

### 1. Target-sentence board

Show:

- source observer-integrity receipt
- target sentence under review
- minimum burden required for that sentence

### 2. Rulebook board

Show:

- current rulebook and version
- platform, world, and topology scope
- whether a prior rulebook would yield a different answer

### 3. Authority and threshold board

Show:

- authorized adjudicator
- threshold rule
- tie-break rule
- whether override or exception review is open

### 4. Evidence-admission board

Show:

- trusted evidence admitted to this verdict
- trusted evidence explicitly excluded from this verdict
- exact reason each excluded item is excluded

### 5. Verdict-ceiling board

The review must output one and only one primary sentence class such as:

- trusted witness, burden not yet chosen
- current rulebook ambiguous
- authorized adjudicator missing or disputed
- current rulebook selected, threshold not met
- threshold met for named slice only
- threshold met but tie-break unresolved
- threshold met but override review open
- threshold met under deprecated rulebook only
- verdict ratified under current rulebook
- broader stronger sentence blocked

## Hard rules

The review must never let an operator hide:

- trusted evidence behind `the verdict is obvious`
- version drift behind `this always means the same thing`
- one green icon behind a broader estate-wide sentence
- a queue display behind `true operative priority proved`
- an unresolved override behind `fully ratified verdict`
