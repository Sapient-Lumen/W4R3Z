# Remedy-hardening-attestation downstream-effects review page — what already acted on the stale truth and what still needs undo or compensation?

## Review question

Given that the stale sentence is no longer allowed to be served, what jobs, workflows, file mutations, approvals, exports, or human decisions already acted on it, which ones can still be undone, which ones need compensation instead, and what irreversibility ceiling now blocks stronger restoration language?

## Review panels

### 1) Triggered-action inventory review

Force the operator to enumerate every downstream lane that could already have acted on the stale version.
The review must preserve at least these distinctions:

- queued but not yet applied versus already executed
- automated actuation versus human decision
- governed-world effect versus externalized effect
- named actor versus unknown historical downstream actor
- source-traceable action versus merely suspected consequence

### 2) Reversibility and restore-path review

For each action class require the operator to score:

- whether the effect is fully reversible by product action
- whether reversal needs operator assistance or a governed restore point
- whether the effect is only compensable and not meaningfully restorable
- whether the product can only state an irreversibility ceiling instead of a restoration plan

### 3) Undo, compensation, and queue-drain review

The page must compute and show:

- which queued actions can still be frozen before apply
- which executed actions need direct undo
- which human decisions need correction or replacement
- which externalized effects need compensation instead of rollback
- whether new stale-triggered work is blocked while old work drains

### 4) Residual irreversibility review

The review must preserve and score:

- named cohorts already restored
- named cohorts compensated but not restored
- irreversible downstream effects that still require containment
- unknown historical consequences for which only a ceiling can be stated
- whether any stronger `restored everywhere` sentence is still being considered despite unresolved irreversible effects

## Required outcomes

The page must support outcomes such as:

- `freeze remaining queue, undo reversible automated actions, and reopen human decisions for named cohort`
- `restore governed copies for internal actors, but compensate externalized effects instead of claiming rollback`
- `new triggers blocked; already-started jobs draining; restoration sentence still blocked`
- `named cohort restored from governed copies, unknown historical actors remain under irreversibility ceiling`
- `stale serving closed, but downstream restoration incomplete and broader ordinary-state sentence blocked`

## Mandatory review discipline

The review must reject any path that tries to treat these as equivalent:

- invalidation and remediation
- archive availability and actual rollback coverage
- compensation and restoration
- queue freeze and executed-action undo
- no new triggers and no historical consequences
- named-cohort restoration and global restored-world honesty

## Required warnings

The page must render plain warnings when:

- a downstream actor class has no explicit inventory owner
- a reversible action has no assigned undo owner or target time
- an externalized effect is being described as restored even though only compensation exists
- old versions remain accessible but no restore path has been proven for the affected cohort
- a broader restoration sentence is being considered while unknown historical downstream actors still exist
