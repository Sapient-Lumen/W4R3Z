# Burst debt lineage receipt page — creditor, settlement class, and blocked stronger sentences

## Purpose

This page is the durable receipt for the full lineage of burst debt after an urgent exception.
A later operator should be able to open one page and answer:

> what burst created this debt, who remained owed, what settlement route was chosen, what embargo or consequence survived, and what stronger sentence the product refused to make?

## Required receipt sections

### A. Origin section

- source burst exception
- claimant
- ordinary award and borrowed amount
- exception authority class
- expiry outcome

### B. Debt section

- creditor class
- harmed-claimant set
- debt class
- due window
- overdue class if any
- restoration gate summary

### C. Settlement section

- settlement verdict (`paid`, `staged`, `carried-forward`, `forgiven-with-consequence`, `still-open`)
- settling or forgiving authority
- remaining consequence on future awards or bursts
- embargo posture after settlement verdict

### D. Final truth section

- strongest true sentence for claimant
- strongest true sentence for harmed neighbors
- strongest blocked stronger sentence
- exact fact required for upgrade
- exact fact that would downgrade the current sentence again

## Required receipt badges

- `burst-origin-confirmed`
- `creditor-set-fixed`
- `debt-open`
- `debt-overdue`
- `settlement-plan-active`
- `forgiven-with-consequence`
- `embargo-active`
- `ordinary-standing-restored`
- `future-exception-narrowed`

## Receipt obligations

- preserve debt lineage even after restoration so repeated-burst patterns stay visible
- preserve forgiveness as a different truth from full repayment
- preserve future-exception narrowing as a surviving consequence, not a footnote
- preserve the harmed-neighbor sentence instead of centering only the formerly urgent claimant

## Stronger-sentence guard

The receipt may say `burst debt retired` or `burst debt forgiven with consequence`, depending on truth.
It may not say `the prior burst is now irrelevant` unless no surviving embargo, narrowed eligibility, creditor residue, or recurrence consequence remains.
