# Remedy-hardening-attestation recurrence-watch lineage receipt page — watch horizon summary, recontamination posture, and blocked stronger sentences

## Purpose

This receipt is the compact lineage object for later readers who need one portable answer to:

**was the outsider's clean state only true once, or did it remain trustworthy across the named watch horizon?**

## Receipt header

The receipt header must show at least:

- outsider or audience slice
- corrected replacement identifier
- last confirmed clean-state boundary
- watch horizon class
- recurrence-safe verdict

## Minimum body fields

The receipt body must preserve at least:

- open reopen-channel count
- highest-severity reopen channel
- detection posture summary
- maximum honest lag summary
- automatic containment summary
- observed recurrence summary
- portable proof artifact summary
- strongest honest recurrence-safe sentence
- blocked stronger recurrence-safe sentence

## Verdict classes

The receipt must support at least:

- clean once only
- watched but reopen channels still open
- recurrence-safe for named horizon only
- recurrence occurred and was repaired
- recurrence occurred and stronger sentence collapsed
- insufficient watch proof

## Hard rules

The receipt must never:

- collapse `watched` into `prevented`
- collapse `no incident observed` into `no channel open`
- collapse `horizon-limited safe` into `safe indefinitely`
- omit the blocked stronger sentence
