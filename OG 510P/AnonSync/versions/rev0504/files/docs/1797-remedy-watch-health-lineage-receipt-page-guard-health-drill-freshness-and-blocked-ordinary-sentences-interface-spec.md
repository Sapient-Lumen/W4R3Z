# Remedy-watch-health lineage receipt page — guard health, drill freshness, and blocked ordinary-life sentences

## Purpose

This receipt is the portable summary of the strongest honest claim about a discharged case's current guard credibility.
It exists so later operators can answer `how healthy is the relapse guard right now?` from one durable object.

## Receipt fields

- receipt identifier
- case identifier
- source remedy-surveillance receipt identifier
- current ordinary-lane scope
- required guarded cohort
- actually probed cohort
- actually drilled cohort
- highest honest watch-health sentence
- strongest blocked stronger ordinary-life sentence
- last successful canary-probe time
- last successful end-to-end drill time
- configured freshness ceiling
- configured response-budget ceiling
- last measured response budget
- current platform blind spots
- current runtime blind spots
- current evidence-strength verdict
- next mandatory reprobe time
- next mandatory redrill time
- next automatic weakening trigger

## Mandatory sentence discipline

The receipt must preserve these distinctions:

- surveillance armed versus watch health proven
- probe current versus drill current
- drill passed versus drill passed inside budget
- named-cohort coverage versus required-cohort coverage
- declared blind spots versus clean required-cohort proof
- stale guard versus collapsed guard

## Example summary sentences

- `Guard armed, but watch health stale: required-cohort canary proof expired before redrill.`
- `Probe current for required cohort; end-to-end drill stale; stronger guarded-ordinary-life sentence blocked.`
- `Probe and drill current inside budget for required cohort, with Linux blind lane excluded from stronger sentence.`
- `Response budget exceeded on last drill; case remains discharged only under stale-guard warning.`
