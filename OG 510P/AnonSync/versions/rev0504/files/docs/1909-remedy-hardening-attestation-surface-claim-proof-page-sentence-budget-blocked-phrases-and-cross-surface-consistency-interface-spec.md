# Remedy-hardening-attestation surface-claim proof page — sentence budget, blocked phrases, and cross-surface consistency

## Purpose

This page is the durable proof that every audience-facing surface statement for a case was generated under an explicit sentence budget instead of ad hoc optimism.
It must let a later verifier see not only the current strongest internal sentence, but which narrower sentence each audience and surface was actually allowed to hear, copy, or export.

## Sections

### 1) Surface-governance header

Publish:

- case identifier
- source egress-governance receipt identifier
- current governing receipt identifier
- current surface-claim-governance class
- current strongest internal sentence
- highest audience-safe sentence class in force

### 2) Surface-by-audience matrix

For each supported surface and audience pair print:

- surface class
- audience class
- allowed sentence budget class
- exact template identifier
- mandatory qualifier set
- export permission class
- copy or relay permission class
- historical-only or current authority class

### 3) Blocked-phrase registry

For each surface or audience pair print:

- blocked stronger phrase
- reason blocked
- governing receipt clause that blocks it
- event that would make it speakable later, if any

### 4) Stale-artifact recall block

The proof must score every older visible artifact:

- artifact identifier or surface label
- originally issued sentence class
- current authority status
- recall, banner, watermark, or delete action status
- residual overstatement risk if still encountered

### 5) Cross-surface consistency summary

The page must compute and print:

- strongest internal sentence
- strongest speakable operator sentence
- strongest speakable named-recipient sentence
- strongest speakable public sentence
- strongest blocked broader sentence
- exact reasons the broader sentence remains blocked

## Mandatory proof distinctions

The proof must preserve at least these distinctions:

- internal truth versus exported truth
- current governing sentence versus historical reference sentence
- rich-surface nuance versus compressed-surface shorthand
- named-cohort-safe sentence versus public-safe sentence
- stale artifact still visible versus stale artifact still authoritative
- quoteable sentence versus visible-but-noncopyable status hint

## Claim ceilings

The proof must never permit these sentences without direct support:

- `all surfaces say the same thing`
- `green or calm means globally safe to quote`
- `older export remains valid after supersession`
- `clipboard or link label was harmless metadata only`
- `public audience may hear everything the operator can hear`
- `historical receipt may still be quoted as current`
