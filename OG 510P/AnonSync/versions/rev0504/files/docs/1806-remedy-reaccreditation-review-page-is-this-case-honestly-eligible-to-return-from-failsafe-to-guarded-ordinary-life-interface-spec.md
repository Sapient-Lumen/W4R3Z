# Remedy-reaccreditation review page — is this case honestly eligible to return from fail-safe to guarded ordinary life?

## Purpose

This page is the operator's adjudication surface for whether a previously uncertain or re-fenced case may re-enter guarded ordinary life.
It exists so the operator can answer one typed question instead of reconstructing re-entry truth from restarts, rescans, reconnects, and quiet-looking surfaces.

## Primary review question

`After uncertainty or re-fence, has this case actually requalified enough to return to guarded ordinary life, or are we just seeing weaker recovery signals?`

## Required review panes

### 1. Cause-remediation pane

Show:

- original uncertainty cause family
- remediation actions completed
- unresolved contributing causes
- current cause-remediation verdict
- strongest blocked stronger sentence from unresolved cause

### 2. Proof-refresh pane

Show:

- latest probe freshness
- latest end-to-end drill freshness
- required-cohort proof coverage
- named-cohort-only recovery still present
- current proof ceiling for re-entry

### 3. Re-entry authority pane

Show:

- automatic re-entry allowance
- manual release requirements
- authority still missing
- full re-fence versus soft narrowing history
- strongest honest re-entry verdict ceiling

### 4. Scar-and-budget pane

Show:

- sticky scar class
- tighter watch budget now required
- tighter surveillance or decay settings now required
- re-entry conditions still open
- final honest ordinary-life sentence ceiling

## Required review outcomes

The page must support outcomes such as:

- `recovery actions observed; requalification not started`
- `cause remediated; required-cohort proof still stale`
- `required-cohort proof refreshed; manual re-entry authority pending`
- `required-cohort proof refreshed; re-entry authorized with sticky scar`
- `re-entry allowed only under tighter watch budget`
- `named-lane recovery only; stronger ordinary-life sentence still blocked`
- `requalification collapsed; case remains fenced`

## Review discipline

The review must forbid these shortcuts:

- one restart equals requalification
- one rescan equals cause remediated
- one quiet UI equals required-cohort proof refreshed
- logs collected equals re-entry authority earned
- one lane recovered equals required-cohort reaccreditation
- fail-safe lifted somewhere equals honest return to ordinary life everywhere
