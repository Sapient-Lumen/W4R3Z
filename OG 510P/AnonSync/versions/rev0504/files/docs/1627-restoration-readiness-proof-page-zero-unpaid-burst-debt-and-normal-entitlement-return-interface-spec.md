# Restoration readiness proof page — zero unpaid burst debt and normal-entitlement return

## Purpose

This page is the durable proof object for the strongest true sentence about whether a claimant has actually returned from burst-exception status to ordinary good standing.
It exists so the archive can say exactly whether burst debt is still open, whether any embargo remains, whether reserve and harmed claimants were restored, and whether a normal-entitlement sentence is now honest again.

## Sentences this page may support

- `burst debt still open; no new burst allowed`
- `burst debt open under staged settlement and manual-review-only future exceptions`
- `burst debt forgiven with narrowed future eligibility`
- `reserve restored but claimant relief still open`
- `all burst debt retired and ordinary entitlement restored`
- `ordinary entitlement restored, but renewed exception still blocked by recurrence policy`

## Mandatory proof blocks

### A. Debt closure basis

- source burst-debt object
- settlement verdict
- creditor set
- outstanding balance witness
- overdue or current status witness
- forgiveness or restructuring authority if used

### B. Restoration evidence

- reserve-restoration witness
- harmed-claimant relief witness
- narrowed-future-award witness if carry-forward occurred
- embargo-lift witness
- recurrence-risk witness
- measurement confidence basis

### C. Strongest surviving sentence block

- strongest true sentence for the claimant now
- strongest true sentence for harmed neighbors now
- strongest blocked stronger sentence
- exact fact still needed to upgrade or downgrade the sentence

### D. Continuity and regression block

- prior burst count in the active lineage window
- prior debt recurrence count
- current policy posture for future exceptions
- regression trigger that would reopen the debt question

## Required badges

- `debt-open`
- `debt-overdue`
- `debt-under-plan`
- `debt-forgiven-with-consequence`
- `reserve-restored`
- `neighbor-relief-restored`
- `embargo-active`
- `embargo-lifted`
- `ordinary-entitlement-restored`
- `future-burst-manual-only`

Badges must stack rather than erase lineage.
For example, `reserve-restored` may coexist with `neighbor-relief-open`, and `ordinary-entitlement-restored` may still coexist with `future-burst-manual-only`.

## Proof obligations

- prove settlement separately from the mere end of active urgency
- prove embargo lift separately from lower live consumption
- prove harmed-claimant relief separately from resumed throughput
- preserve forgiveness consequences instead of letting them evaporate after closure
- preserve recurrence risk whenever the same authority or claimant keeps invoking burst borrow

## Stronger-sentence guard

This page may say `ordinary entitlement restored after burst debt retirement`.
It may not say `the prior exception left no surviving consequence` unless the archive also has proof that no tighter future-exception posture, no narrowed follow-on award, and no creditor residue remain.
