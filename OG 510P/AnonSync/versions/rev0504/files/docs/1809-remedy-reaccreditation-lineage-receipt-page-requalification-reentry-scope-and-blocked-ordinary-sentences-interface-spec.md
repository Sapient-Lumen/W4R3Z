# Remedy-reaccreditation lineage receipt page — requalification, re-entry scope, and blocked ordinary sentences

## Purpose

This receipt is the portable summary of the strongest honest claim about a case that was once uncertain or re-fenced and is now attempting to return to guarded ordinary life.
It exists so later operators can answer `did this case truly requalify, and under what surviving scars?` from one durable object.

## Receipt fields

- receipt identifier
- case identifier
- source remedy-watch-uncertainty receipt identifier
- original uncertainty cause family
- current requalification posture rung
- current fence or fail-safe posture
- required requalification cohort
- current re-entry scope
- highest honest current re-entry sentence
- strongest blocked stronger ordinary-life sentence
- latest proof freshness ceiling
- latest post-recovery drill freshness
- re-entry authority class
- automatic re-entry execution status
- manual re-entry completion status
- sticky-scar class
- tightened watch budget, if any
- next mandatory strengthening trigger
- next automatic weakening trigger

## Mandatory sentence discipline

The receipt must preserve these distinctions:

- recovery action observed versus cause remediated
- cause remediated versus required-cohort proof refreshed
- required-cohort proof refreshed versus re-entry authorized
- re-entry authorized versus re-entry completed
- re-entry completed with sticky scar versus scar-cleared ordinary life
- named-cohort recovery versus required-cohort reaccreditation
- fail-safe lifted somewhere versus honest guarded ordinary-life return

## Example summary sentences

- `Recovery visible, but requalification incomplete: required-cohort proof still stale.`
- `Required-cohort proof refreshed; manual re-entry authority pending before guarded ordinary life can return.`
- `Re-entry authorized and completed under tighter watch budget with sticky scar retained.`
- `One lane recovered, but required-cohort reaccreditation still blocked; case remains fenced.`
