# Security

This repository is in an early design state.

## Reporting

Do not file sensitive vulnerability details in public issue trackers once the project has a public development flow. Until a formal process exists, keep sensitive reports private to the maintainers.

## Principles

- no hidden telemetry
- explicit dependency review
- reproducible validation where practical
- separate protocol design from transport assumptions
- minimize metadata leakage
- never treat convenience as proof of safety

## Current caveat

This revision contains scaffolding and notes, not a production security posture.
