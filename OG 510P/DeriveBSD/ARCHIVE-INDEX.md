# DeriveBSD archive index

A small reading surface for the eight selected historical archives recorded in the [complete manifest download](https://raw.githubusercontent.com/Sapient-Lumen/W4R3Z/d81138131e079e14916a7ac8723adfbc84ad896b/OG%20510P/DeriveBSD/ARCHIVE-MANIFEST.json). The 5,570,511-byte manifest remains unchanged and retains every member record; GitHub cannot display it in its file viewer.

The manifest describes itself as a new curatorial reconstruction dated 6 October 2026, made from unchanged source ZIPs after an earlier manifest was lost. It is not the exact missing earlier manifest or a complete development history. This index preserves that distinction.

## What the manifest records

- Eight ZIP identities and extraction roots.
- 18,040 file records with paths, byte counts, SHA-256 values and carried ZIP/Git metadata.
- 190 explicit directory-entry records. Git does not represent empty directories by itself.

Counts below were checked against the records in this manifest. Original ZIP hashes and sizes are reproduced from it; this reading page does not re-download or revalidate every archive member. Dates and revision labels remain carried metadata, not authenticated chronology. The [archival notes](ARCHIVAL-NOTES.md) and [evidence map](ARCHIVAL-EVIDENCE.md) explain the inspection and rights limits. No new license or engineering certification is added.
