2026-06-18r630 host-proof contract refresh; current checked-in host-smoke refusal/proof-bundle examples were regenerated for the repository-snapshot runtime cut without changing the honest no-real-host-proof boundary.

`tools/freebsd/run_removable_media_local_fallback_host_smoke.py` is the guarded FreeBSD-only smoke runner for the removable-media local fallback lane. In this Linux cloudtainer it writes `validation/removable-media-local-freebsd-host-smoke.refusal.json` with `result = refused` and `refusal_reason = non-freebsd-host`; that refusal is intentional evidence, not a skipped test.

On a real FreeBSD host the runner requires root and an explicit `--run-host-smoke` flag. The intended host sequence is: compile `tools/freebsd/rm_post_detach_capsicum_worker.c`, run makefs to create a disposable UFS image, attach it read-only with `mdconfig`, verify it with `fstyp`, mount it with `ro,nosuid,noexec,nosymfollow,untrusted`, perform the shared safe-capture path, run real `umount`, detach the memory disk, then exec the C worker with delegated fd 3 and fd 4 plus a broker non-media fd-5 canary.

Before compile, the checked-in C worker source is admitted as a regular non-symlink repository file, copied into the private work root, and digest-verified. The compile command uses that private worker-source copy rather than the live repository path.

Host commands run with a sanitized host-command environment (`LC_ALL=C` and a fixed `/sbin:/bin:/usr/sbin:/usr/bin` PATH), and `fstyp` output is accepted only as strict fstyp output: a single canonical `ufs` token before mount.

The worker is also launched with an empty environment and a private non-media cwd so a successful host smoke cannot accidentally depend on the repository, mounted media tree, or inherited environment.

The fd-5 canary is not source-media authority. It exists to prove that the worker closes unexpected inherited descriptors before capability entry. The worker report must include `extra_fd_canary_observed_before_closefrom = true`, `extra_fds_closed_before_cap_enter = true`, and `extra_fd_scan_limit = 64`, and the worker-observed input digest must match the preserved CAS capture digest.
