# Host auditing (OpenBSM) as corroboration

DeriveBSD’s primary audit record is its own digest transition ledger.
OpenBSM auditing can corroborate incident timelines.

Useful tools:
- `auditd`, `audit`
- `auditreduce` (slice by time/user/event)
- `praudit` (render)

See RFC-0030.
