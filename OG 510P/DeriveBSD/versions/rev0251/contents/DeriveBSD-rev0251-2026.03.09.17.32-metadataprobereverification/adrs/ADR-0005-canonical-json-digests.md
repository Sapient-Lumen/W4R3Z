# ADR-0005: Canonical JSON digests for runtime manifests

Status: Superseded

## Decision

Runtime manifests and other structured artifacts must use canonical JSON hashing to ensure digest stability.

## Superseded by

This decision is superseded by `adrs/ADR-0022-canonical-json-jcs.md`, which adopts RFC 8785 (JCS) as the canonicalization scheme.

## Notes

This ADR remains only to preserve historical references.
