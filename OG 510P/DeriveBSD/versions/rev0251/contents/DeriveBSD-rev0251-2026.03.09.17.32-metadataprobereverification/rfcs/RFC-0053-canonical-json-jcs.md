# RFC-0053: Canonical JSON hashing via RFC 8785 (JCS)

- Status: draft
- Created: 2026-02-23

## Summary
Adopt JSON Canonicalization Scheme (JCS) for all hashed JSON in DeriveBSD.

## Goals
- stable digests across implementations
- eliminate whitespace/order ambiguities
- constrain JSON to hashable subset

- RFC 8785 (JCS)
