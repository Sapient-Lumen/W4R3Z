# DeriveBSD rev0307: Relay locator grammar

Selected historical snapshot for the W4R3Z / OG 510P showcase. This page is a later editorial guide; the preserved source files retain their original wording and metadata.

## What to notice

Relay locator values are constrained by their declared kind: URI hints remain URI-shaped, while portal-object, object-path and opaque values remain non-URI-shaped. The point is a coherent evidence vocabulary for temporary sharing, with locator text unable to contradict the selected sharing lane.
