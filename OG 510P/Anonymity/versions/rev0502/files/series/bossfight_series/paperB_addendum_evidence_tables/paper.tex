\begin{abstract}
This companion note collects only the supporting evidence packet for the Boss Fight dial sheet (Paper~B).
To keep the main dial sheet referee-readable and compact, we move (i) the compact pattern map to classic AnonDHT designs,
(ii) contact/hop amplification tables under representative Kademlia parameters, and (iii) auxiliary dummy-width requirement tables into this addendum.
The note is intentionally narrow: it provides referee-quotable tables and operator-facing scale checks, not a second certificate, notarization, or release-packaging surface.
All content is pure \LaTeX{} and requires no external artifacts.
\end{abstract}

\paragraph{IPFS lookup mini-spec slice (iterative).}
The spec defines an \emph{iterative} lookup: the initiator maintains a candidate list of peers close to the target identifier, sends queries to up to $\alpha$ unqueried candidates, and expands the list using returned peer sets of size $k$.
Termination is reached once the $\beta$ closest reachable peers to the target have been successfully queried (or the candidate set is exhausted) \cite{ipfs_kad_spec}.
In our Boss Fight framing, each queried peer (and each timeout/abort) is a potential destination-indexed witness.
