\begin{abstract}
Once a release has already produced the narrow maintenance objects---compare report, replay verdict, continuity verdict, and package-closure verdict---later papers still face a smaller but recurring problem: how to reuse one public successor-status sentence without rewording it differently in every note.
This paper isolates that downstream problem.
It standardizes the auditable suffix
\emph{summarize $\to$ support $\to$ cite $\to$ quote $\to$ clause},
and gives one minimal rule: moving rightward may compress wording for readability, but every challenged sentence must resolve deterministically leftward to a narrower checked object.
The result is compact release-note prose without losing referee-grade traceability.
\end{abstract}

\begin{definition}[Downstream normal form]
For one concrete base$\to$successor comparison, a \emph{downstream normal form}
\[
N=(S,U,C,Q,L)
\]
consists of five tiny digest-bound adjuncts:
\begin{enumerate}[leftmargin=*]
\item \textbf{Summary object $S$:} a public successor-status summary, typically a successor-lineage notice that compresses a narrower summary-stage status envelope.
\item \textbf{Support object $U$:} a clause-to-evidence map binding each outward-facing sentence to narrower verdict fields.
\item \textbf{Citation object $C$:} a use-case-to-artifact map naming the smallest sufficient citation target for common downstream needs.
\item \textbf{Quote object $Q$:} an exact-field map telling later notes which field to quote once the citation target is known.
\item \textbf{Clause object $L$:} a short reusable sentence pack whose entries preserve the underlying cite path and field binding.
\end{enumerate}
\end{definition}

\paragraph{Minimality rule.}
Each component should answer one narrower question and nothing more:
summary answers ``what is the public answer?'',
support answers ``why is that sentence justified?'',
citation answers ``what is the smallest sufficient thing to cite?'',
quote answers ``which exact field is worth quoting?'',
and clause answers ``what already-checked sentence can be reused?''
If one object answers several of them at once, later papers lose both compactness and auditability.

\section{Resolution contract}

\begin{definition}[Typed leftward resolution trace]
For one emitted downstream sentence $\sigma$, a \emph{typed leftward resolution trace} is a finite ordered list
\[
T(\sigma)=(t_0,t_1,\dots,t_m)
\]
whose step labels are drawn from
\[
\textsf{emit},\textsf{clause},\textsf{quote},\textsf{cite},\textsf{support},\textsf{narrow},
\]
with the obligations that $t_0$ identifies the emitted sentence itself, some later step identifies the reusable clause entry, some later step identifies the exact quoted field, some later step identifies the smallest sufficient citation target, and the final step lands in a narrower compare/continuity/closure field rather than in the wrapper objects themselves.
\end{definition}

\begin{definition}[Terminal-target set]
For one emitted sentence $\sigma$, its \emph{terminal-target set}
\[
E(\sigma)=\{e_1,\dots,e_r\}
\]
is the nonempty set of narrow compare/continuity/closure fields named by the final \textsf{narrow} step(s) of its typed trace.
These are the exact fields at which audit resolution must stop for the claim families carried by $\sigma$.
\end{definition}

\begin{definition}[Claim-class coverage]
Let $K(\sigma)$ be the finite set of contested claim classes carried by one emitted sentence $\sigma$.
A downstream normal form has \emph{terminal claim-class coverage} for $\sigma$ if every class in $K(\sigma)$ is discharged by at least one target in $E(\sigma)$.
For multi-clause wrapper sentences, this prevents one narrow field from being mistaken for the authority for the whole sentence.
\end{definition}

\begin{definition}[Segmented sentence binding]
For one emitted sentence $\sigma$, a \emph{segmented sentence binding}
\[
G(\sigma)=\{(g_j,A_j,T_j)\}_{j=1}^s
\]
consists of auditable surface spans $g_j$, nonempty claim-class sets $A_j$, and nonempty referenced-target sets $T_j\subseteq E(\sigma)$.
It is valid only if every claim class in $A_j$ is actually discharged by the referenced targets in $T_j$.
\end{definition}

\begin{definition}[Surface-assembly witness]
For one emitted sentence $\sigma$ with segmented binding $G(\sigma)$, a \emph{surface-assembly witness}
\[
A(\sigma)=(a_1,\dots,a_q)
\]
is an ordered list whose entries are either declared segment keys from $G(\sigma)$ or literal glue strings such that concatenating them reconstructs $\sigma$ exactly.
This prevents wrappers from hiding reordered text, dropped punctuation, or extra unaudited phrasing behind an apparently correct segment list.
\end{definition}

\begin{lemma}[Rightward compression, leftward resolution]
Assume every emitted reusable sentence carries a valid typed leftward trace, a nonempty terminal-target set with claim-class coverage, and a valid segmented binding with exact surface assembly.
Then any sentence emitted from the clause layer has a deterministic escalation path back to a narrower checked object.
\end{lemma}

\begin{proof}
Take any emitted clause.
The typed trace fixes the order in which the challenge must be resolved: emitted sentence, clause entry, exact quote target, smallest sufficient citation target, any needed support binding, and finally the narrower maintenance field.
Claim-class coverage removes the common multi-clause failure mode in which one terminal field is cited as if it justified every semantic piece of the emitted sentence.
Segment bindings and the surface assembly then remove ambiguity about which span says what and about how the public sentence is reconstructed exactly.
Thus movement to the right only compresses presentation; it does not create a new unsupported claim.
If the question becomes ``may this exact checked sentence be reused for the current pair and object cut?'', that question leaves this note and is answered by the imported sentence-lock discipline.\cite{series:sentencelocks}
\end{proof}

\section{How later papers should use the suffix}
The practical rule is simple.
Move \emph{rightward} only when the goal is shorter prose; move \emph{leftward} whenever the claim becomes narrower, more numerical, or more contested.
Concretely:
\begin{enumerate}[leftmargin=*]
\item Cite the summary object when one outward-facing successor-status sentence is enough.
\item If the note cares about where a release note, referee, or auditor should begin and how that route escalates, import the audience-keyed challenge routes rather than overloading the citation map.\cite{series:challengeroutes}
\item If the note cares about which semantic pieces a question decomposes into and which exact narrow fields are allowed stopping points for each piece, import the question-keyed challenge stop profiles rather than re-declaring stop fields inline.\cite{series:challengestops}
\item Cite the support object when a referee needs clause-by-clause traceability.
\item Cite the exact quote target or narrower verdict object when the note asserts a token, field value, or numeric delta rather than a wrapper sentence.
\item Keep segmented bindings and exact surface assembly intact for any multi-clause reusable sentence.
\item Reuse clause-pack wording only if the imported sentence lock for that sentence remains valid for the current release pair and shipped object cut.\cite{series:sentencelocks}
\end{enumerate}
This is why the suffix should be small: it gives later papers a stable prose interface without pretending that prose has replaced evidence.

\section{Worked example pointer}
The maintained worked bundle ships \path{example_successor_normal_form.json}, which freezes the suffix
\textsf{summarize} $\to$ \textsf{support} $\to$ \textsf{cite} $\to$ \textsf{quote} $\to$ \textsf{clause}
for the canned Case-B successor.\cite{series:workedexample}
It stores one tiny resolution contract plus two concrete resolution examples: an outward-facing status sentence and a compact numeric diff sentence.
Those examples expose typed trace steps, terminal targets, segmented spans, and exact surface assembly.
The companion \path{example_successor_sentence_locks.json} then owns the pair-locked reuse policy for those same sentences: comparison anchors, recheck-vs-regenerate guards, refresh-in-place boundaries, and visible inline-provenance profiles.\cite{series:workedexample,series:sentencelocks}
The sibling \path{example_successor_challenge_routes.json} separately owns the reader-keyed start-here / escalate-here ladders for those sentences, so audience guidance does not get smuggled into the citation map itself.\cite{series:workedexample,series:challengeroutes}
The newer worked answer-side handoff objects stay separate as well.
\path{example_successor_challenge_answer_capsules.json} owns one audience/question/piece bundle at a time.
\path{example_successor_challenge_answer_sheets.json} groups those capsules into one piece-complete audience/question handoff.
\path{example_successor_challenge_answer_cards.json} then binds that whole-question handoff to one shipped sentence lock and one default inline-provenance mode whenever a later note wants the emitted audience/question answer itself.
That gives later notes one auditable object to cite at piece, whole-question, or emitted-answer granularity without widening the suffix itself; the companion answer-side terminal citation normal form and paired cutover rule then tell later terse papers when they may stop at that checked-answer handoff rather than reopening this suffix.\cite{series:workedexample,series:challengeanswercapsules,series:challengeanswersheets,series:challengeanswercards,series:challengeanswerreviewmenus,series:pairedterminalcitationdiscipline,series:pairedterminalcutoverrules}
The stable stage order that this suffix sits inside is owned separately by Synthesis~32 and instantiated in the same worked bundle via the release-spine and stage-walkthrough adjuncts.\cite{series:releasespine,series:workedexample}

\paragraph{Why this helps the archive.}
The archive is intentionally source-only and brief.
That only works if downstream notes can reuse a stable, auditable public sentence without dragging along every maintenance adjunct in prose.
This note gives that sentence-normalization layer one home, while Synthesis~35 separately keeps sentence-retirement and inline-provenance policy out of the wording note.
