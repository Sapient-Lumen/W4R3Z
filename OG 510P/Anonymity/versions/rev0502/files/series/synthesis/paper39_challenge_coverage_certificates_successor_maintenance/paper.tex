\begin{abstract}
Audience-keyed challenge routes answer where a reader should begin.
Question-keyed stop profiles answer which semantic pieces exist.
Piece-keyed branch maps answer how one contested piece escalates.
One practical ambiguity still remains: when a terse released sentence is reused across audiences, which semantic pieces does that sentence family actually count as covering for each audience, and which challenge hooks must remain available even when they are not surface-realized?
This note isolates that sentence-family coverage layer.
It defines a compact \emph{challenge coverage certificate} that binds one emitted sentence family to audience coverage and support-only hooks, while importing audience-invariant proving cores, exact aggregate proving-key bundles, exact audience-minimal proving bundles, exact surface realization, and exact terminal ownership from companion ledgers.
\end{abstract}

\section{Why the coverage layer should be separate}
A segmented downstream sentence can already say where the sentence breaks.
A companion surface-hook ledger can already say exactly which piece is realized by which span.
A companion terminal-witness ledger can already say which narrow stop fields belong to that piece hook.
But that still does not answer a broader maintenance question: does this sentence family count as the public carrier of a given semantic piece for release notes, referees, auditors, or only some of them?
And if a challenge may escalate to a recomputation witness that never appears in the sentence surface, where is that obligation recorded without pretending the sentence literally says it?
If this information is left implicit, later papers either overclaim what the sentence covers or quietly lose support-only hooks that remain necessary for audit.
So sentence-family coverage deserves one small object of its own, with exact proving-key bundles moved to a companion witness-pack note.

\begin{definition}[Challenge coverage certificate]
Fix one concrete base$\to$successor comparison and one emitted sentence family $f$ from the downstream normal form together with one nonempty audience set $A(f)$.
A \emph{challenge coverage certificate} for $f$ is a finite family
\[
\Gamma(f)=\{(e,p,m)\}
\]
whose entries each contain a coverage-entry key $e$, a semantic piece key $p$, and a coverage mode $m\in\{\textsf{surface},\textsf{support-only}\}$.
The fixed audience set $A(f)$ says which audiences the sentence family certifies.
\end{definition}

\begin{definition}[Support-only rule]
A coverage entry satisfies the \emph{support-only rule} if $m=\textsf{support-only}$ means the sentence family certifies the continued availability of that challenge hook without claiming that the hook appears on the sentence surface.
\end{definition}

\begin{definition}[Family-audience rule]
A challenge coverage certificate satisfies the \emph{family-audience rule} if the fixed audience set $A(f)$ contains exactly the audiences for whom sentence family $f$ is meant to count as a certified carrier.
\end{definition}

\begin{lemma}[Coverage certificates prevent sentence-family drift]
Assume every coverage entry for sentence family $f$ satisfies the support-only rule and the certificate satisfies the family-audience rule.
Then later notes may reuse $f$ across audiences without silently changing which semantic pieces the sentence covers or dropping off-surface challenge hooks.
\end{lemma}

\begin{proof}
The support-only rule prevents an off-surface challenge hook from being mistaken for visible sentence content.
The family-audience rule prevents later notes from silently widening or narrowing the audiences for whom the sentence family counts as certified.
Audience-invariant proving keys are then checked in the companion witness-core ledger, exact aggregate route-and-branch proving keys are checked in the companion coverage-witness packs, and audience-minimal route-and-branch proving keys are checked in the companion witness-slice ledger rather than carried inline here.
So the certificate records exactly what the sentence family covers and for whom, without overloading the semantic object with every certification dependency.
\end{proof}

\paragraph{Why this helps the archive.}
The series can now state, in one narrow certificate, whether a terse sentence family counts as covering a semantic piece for a given audience or merely preserves an off-surface challenge hook, while leaving common proving keys, exact certification dependencies, exact realization, and exact terminal ownership to their own ledgers.
That makes the worked example less decorative and more auditable without lengthening the public wrapper prose.

\paragraph{One tiny challenge-coverage drill.}
For the worked compact diff family, \nolinkurl{compact_numeric_diff} still forces the same coverage certificate only while the same release-note / auditor audience split is certified, the same numeric-delta and changed-family pieces remain \textsf{surface}, and the same recomputation piece remains \textsf{support-only}. If the live question widens from ``does this sentence family still certify the same piece-and-audience coverage claim?'' to ``which fallback spans realize the changed-family piece?'' the honest stop is no longer this note but Synthesis~40.
