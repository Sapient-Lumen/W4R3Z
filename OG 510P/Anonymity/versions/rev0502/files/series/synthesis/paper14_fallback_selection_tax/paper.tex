\begin{abstract}
Tiered deployments are a pragmatic response to the Boss Fight regime:
use a cryptographic or delegated \emph{primary} path for most lookups and treat raw DHT lookups as a budgeted \emph{fallback}.
A subtle failure mode is that \emph{fallback selection} (when, how often, and for which keys/users a system falls back) is itself a witness stream:
if the fallback probability depends on the hidden destination or profile, then the indicator ``used fallback'' is an identification channel even when each path is individually well-equalized.
We formalize this as a simple max-divergence ``path-selection tax'' and record the minimal receipt fields needed to make tiered designs honest and comparable.
\end{abstract}

\paragraph{Scope.}
This note isolates one interface in tiered deployments (Synthesis~10): \emph{path selection}.
It is deliberately narrow: we do not propose a concrete caching or routing policy, only a conservative accounting statement that operators can publish.

\section{Model: two paths and a public indicator}

We model a tiered lookup as follows.
A hidden secret $C\in\mathcal{C}$ indexes the destination/profile to be protected.
The system selects a path $P\in\{\textsf{primary},\textsf{fallback}\}$ and then emits a transcript $Z$ according to the chosen path.
The observer sees $Y=(P,Z)$.

\begin{definition}[Per-path stability (bits)]
For $p\in\{\textsf{primary},\textsf{fallback}\}$, let $\mathcal{L}(Z\mid C,p)$ be the transcript distribution conditioned on using path $p$.
We say path $p$ is $(b_p,\delta_p)$-\emph{stable} for the secret pair $(c_0,c_1)$ if for all events $A$,
\[
\Pp[Z\in A \mid C=c_1,p] \le 2^{b_p}\Pp[Z\in A \mid C=c_0,p] + \delta_p.
\]
The parameter $b_p$ is measured in \emph{bits} and is directly comparable to per-path MaxL line items in receipts.
\end{definition}

Let $\pi_c := \Pp[P=\textsf{fallback}\mid C=c]$ be the (possibly secret-dependent) fallback probability.

\section{A tax for secret-dependent fallback}

\begin{lemma}[Path-selection tax (bits)]\label{lem:path-tax}
Fix two secrets $c_0,c_1$ and let $\pi_c := \Pp[P=\textsf{fallback}\mid C=c]$.
Assume per-path stability for both paths with parameters $(b_{\textsf{primary}},\delta_{\textsf{primary}})$ and $(b_{\textsf{fallback}},\delta_{\textsf{fallback}})$.
Then the combined channel $Y=(P,Z)$ satisfies, for all events $E$,
\[
\Pp[Y\in E \mid C=c_1]
\;\le\;
2^{b^\star}\Pp[Y\in E \mid C=c_0] + \delta^\star,
\]
where
\[
b^\star
=
\max\!\left\{
b_{\textsf{primary}} + \logtwo\!\frac{1-\pi_{c_1}}{1-\pi_{c_0}},
\;
b_{\textsf{fallback}} + \logtwo\!\frac{\pi_{c_1}}{\pi_{c_0}}
\right\},
\qquad
\delta^\star = \delta_{\textsf{primary}}+\delta_{\textsf{fallback}}.
\]
\end{lemma}

\begin{proof}
Decompose the event $E$ by path.
Let $E_p:=\{z:(p,z)\in E\}$.
Then
\[
\Pp[Y\in E\mid c]
=(1-\pi_c)\Pp[Z\in E_{\textsf{primary}}\mid c,\textsf{primary}]
+\pi_c\Pp[Z\in E_{\textsf{fallback}}\mid c,\textsf{fallback}].
\]
Apply per-path stability to each term and factor the path probabilities:
\[
(1-\pi_{c_1})\Pp[Z\in E_{\textsf{primary}}\mid c_1,\textsf{primary}]
\le
2^{b_{\textsf{primary}}}\frac{1-\pi_{c_1}}{1-\pi_{c_0}}
(1-\pi_{c_0})\Pp[Z\in E_{\textsf{primary}}\mid c_0,\textsf{primary}]
+ (1-\pi_{c_1})\delta_{\textsf{primary}},
\]
and similarly for the fallback term:
\[
\pi_{c_1}\Pp[Z\in E_{\textsf{fallback}}\mid c_1,\textsf{fallback}]
\le
2^{b_{\textsf{fallback}}}\frac{\pi_{c_1}}{\pi_{c_0}}
\pi_{c_0}\Pp[Z\in E_{\textsf{fallback}}\mid c_0,\textsf{fallback}]
+ \pi_{c_1}\delta_{\textsf{fallback}}.
\]
Upper-bound $(1-\pi_{c_1})\delta_{\textsf{primary}}\le\delta_{\textsf{primary}}$ and $\pi_{c_1}\delta_{\textsf{fallback}}\le\delta_{\textsf{fallback}}$.
Finally, note that
\[
2^{b_{\textsf{primary}}}\frac{1-\pi_{c_1}}{1-\pi_{c_0}} = 2^{\,b_{\textsf{primary}}+\logtwo\!\frac{1-\pi_{c_1}}{1-\pi_{c_0}}},
\qquad
2^{b_{\textsf{fallback}}}\frac{\pi_{c_1}}{\pi_{c_0}} = 2^{\,b_{\textsf{fallback}}+\logtwo\!\frac{\pi_{c_1}}{\pi_{c_0}}},
\]
and combine the two scaled nonnegative terms using $\max(a,b)(x+y)\ge ax+by$ with $x,y\ge 0$.
\end{proof}

\begin{remark}[Interpretation]
Lemma~\ref{lem:path-tax} says: even if each path is well-budgeted, \emph{secret-dependent} fallback selection adds an unavoidable log-ratio term.
If $\pi_{c_1}\gg \pi_{c_0}$ for some pair, then the single bit ``used fallback'' is already a strong witness.
In tiered anonymity designs, controlling this tax is as important as budgeting the fallback transcript itself.
\end{remark}

\section{Receipt fields for honest tiered deployments}

Synthesis~12 defines a minimal receipt schema for publishing anonymity claims.
For tiered systems, the path-selection tax forces one extra disclosure: a bound on how secret-dependent fallback selection can be.

A minimal, audit-friendly approach is to publish:
\begin{itemize}[leftmargin=*]
\item a \textbf{fallback policy class} (a small machine-checkable description of what triggers fallback: cache miss, rate-limit, indexer unavailability, etc.),
\item an \textbf{estimated fallback rate} $\widehat \pi$ under declared workloads, and
\item a conservative \textbf{secret-dependence bound} of the form
\[
\frac{\pi_{c_1}}{\pi_{c_0}}\le R_{\pi}
\quad\text{and}\quad
\frac{1-\pi_{c_1}}{1-\pi_{c_0}}\le R_{\bar\pi}
\qquad\text{for all declared secret pairs.}
\]
\end{itemize}

Given per-path budgets $(b_p,\delta_p)$ (primary) and $(b_f,\delta_f)$ (fallback),
an auditor can then compute the combined worst-case budget by substituting $R_{\pi},R_{\bar\pi}$ into Lemma~\ref{lem:path-tax}:
\[
b^\star \le \max\{b_p+\logtwo R_{\bar\pi},\ b_f+\logtwo R_{\pi}\},\qquad
\delta^\star=\delta_p+\delta_f.
\]

\paragraph{Operational note.}
Rate limiting interacts with this tax in two ways:
it can reduce the Boss Fight repetition window $Q$ for the fallback path (good), but it can also make fallback selection stateful and secret-correlated (bad) if the rate-limit state depends on content popularity, user cohorts, or cache occupancy.
When in doubt, treat fallback selection as a first-class witness stream and publish a conservative $R_{\pi}$ bound.
