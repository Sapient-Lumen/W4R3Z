\title{Discrete Equalization Audits from Logs:\\
\large Menu-Level Finite-Sample TV Certificates for Receipt-Grade Claims}

\begin{abstract}
Many papers in this archive reduce anonymity claims to an \emph{equalization contract}:
for a declared interface projection $X$, the induced distributions $P_k$ are close across keys/classes/policies $k$.
When only logs are available, deployments need a referee-grade way to \emph{certify} such closeness without rederiving statistics in every mechanism paper.

This note centralizes a conservative, discrete finite-sample audit recipe:
a menu-level bound (with many-testing correction) that upgrades empirical frequencies to a simultaneous
total-variation guarantee, and records the needed parameters in a receipt-facing evidence object.
\end{abstract}

\section{Setup: discrete projections and ``menus'' of claims}
Fix a discrete projection $X\in\{1,\dots,m\}$ (bucketed timings (see Synthesis~27 for bucket design),\cite{series:bucketdesign}  retry-pattern hashes, prefix-length bins, \dots)
that an exposure normal form (ENF) commits to. \cite{series:traceifaces}

A deployment typically audits not one claim but a \emph{menu}:
many keys/policies/classes $k\in\mathcal K$ (and sometimes multiple projections),
often with different sample sizes.
This note treats the menu as a finite index set $\mathcal M$.
For each menu item $\mu\in\mathcal M$ and each class $k\in\mathcal K(\mu)$, collect $n_{k,\mu}$ i.i.d.\ samples of $X$
and form an empirical distribution $\widehat P_{k,\mu}$.

\begin{definition}[Menu-level statistical confidence]
A \emph{menu-level} statistical failure probability is a single parameter $\delta_{\mathrm{stat}}\in(0,1)$
intended to hold \emph{simultaneously} for all $(k,\mu)$ in the declared audit scope.
\end{definition}

\section{A conservative TV radius bound}
The following standard bound (Weissman et al.) controls the $L_1$ deviation of multinomial empirical distributions. \cite{Weissman2003L1}

\begin{lemma}[Weissman $L_1$ deviation $\Rightarrow$ TV radius]\label{lem:weissman}
Let $P$ be a distribution on $\{1,\dots,m\}$ and let $\widehat P$ be the empirical distribution of $n$ i.i.d.\ samples from $P$.
Then for any $\delta\in(0,1)$, with probability at least $1-\delta$,
\[
\|\widehat P-P\|_1 \le r(n,m,\delta)\coloneqq \sqrt{\frac{2}{n}\log\!\left(\frac{2^m-2}{\delta}\right)}.
\]
Equivalently, $\TV(\widehat P,P)\le r(n,m,\delta)/2$.
\end{lemma}

\begin{remark}[Why this is ``conservative'']
The bound is uniform and simple to publish.
Sharper alternatives exist (e.g., profile maximum likelihood, Bernstein-type refinements),
but this note prioritizes a short, receipt-grade certificate that does not depend on opaque tooling.
\end{remark}

\section{Menu-level equalization certificates}
A union bound upgrades Lemma~\ref{lem:weissman} to a simultaneous menu-level certificate.

\begin{corollary}[Simultaneous TV radii over a menu]\label{cor:menu}
Fix $\delta_{\mathrm{stat}}\in(0,1)$.
For each audited pair $(k,\mu)$ define
\[
\delta_{k,\mu}\coloneqq \delta_{\mathrm{stat}} / |\mathcal I|,\qquad
r_{k,\mu}\coloneqq r(n_{k,\mu},m_\mu,\delta_{k,\mu}),
\]
where $|\mathcal I|$ is the number of audited pairs $(k,\mu)$ and $m_\mu$ is the alphabet size of the projection for menu item $\mu$.
Then with probability at least $1-\delta_{\mathrm{stat}}$ we have
$\TV(\widehat P_{k,\mu},P_{k,\mu})\le r_{k,\mu}/2$ simultaneously for all audited $(k,\mu)$.
\end{corollary}

\paragraph{From radii to equalization.}
For two audited classes $(k,\mu)$ and $(k',\mu)$ on the same projection,
\[
\TV(P_{k,\mu},P_{k',\mu})
\le
\TV(\widehat P_{k,\mu},\widehat P_{k',\mu}) + \frac{r_{k,\mu}+r_{k',\mu}}{2}
\]
holds on the same $1-\delta_{\mathrm{stat}}$ event.
This is the simplest log-only route to an equalization contract that can be converted to odds inflation (Anonymity~A) and profiling budgets (Anonymity~B). \cite{series:oddsinflation,series:profiling}

\section{Receipt-facing publication (minimal fields)}
A deployment should not publish the full logs.
Instead, publish a compact \texttt{profiling\_evidence} object that commits to:
\begin{itemize}[leftmargin=*]
\item the projection identifier (ENF-ID or the discrete projection name/hash),
\item the menu scope (which keys/policies/classes were covered),
\item the statistical parameter $\delta_{\mathrm{stat}}$ and the per-item allocation rule (e.g.\ Bonferroni),
\item sample sizes $n_{k,\mu}$ and observed empirical distances $\TV(\widehat P_{k,\mu},\widehat P_{k',\mu})$ (or a derived bound),
\item the resulting certified TV bound(s) used by the receipt line items. \cite{series:receiptitems}
\end{itemize}
For a concrete instantiation with digest-bound bundles and replay hooks, see the worked example receipts in Synthesis~17. \cite{series:workedexample}

\paragraph{How later papers should cite this note.}
This note owns the \emph{menu-level finite-sample certificate}: the simultaneous TV-radius surface, the single published \texttt{delta\_stat} budget, and the minimal \texttt{profiling\_evidence} fields that make those radii receipt-grade. Later terse papers should cite this note when that exact statistical certificate is live. Once a claim has already been carried into the maintained replay/review spine, later terse papers should usually cite the worked example for one concrete bundle instantiation and Synthesis~55 for the stable theorem-to-review bridge, reopening this note only when the exact radius/allocation rule itself is disputed.\cite{series:workedexample,series:seriesspines}

\section{Research warranted (short list)}
\begin{itemize}[leftmargin=*]
\item \textbf{Better finite-sample bounds with the same surface:} replace the uniform Weissman radius with a tighter plug-in bound while keeping a single published $\delta_{\mathrm{stat}}$.
\item \textbf{Adaptive menus (change control over time):} centralize the ``menu grows, audits repeat'' bookkeeping via an anytime spending schedule (Synthesis~26) rather than re-deriving it per paper.\cite{series:anytimespend}
\item \textbf{Large alphabets:} when a projection induces a large alphabet size $m$, coarsening/partition design should be treated as a declared, receipt-facing map rather than an implicit reviewer assumption; see Synthesis~28.\cite{series:coarsening}
\end{itemize}
