\begin{abstract}
Synthesis~25--26 provide conservative, menu-level statistical certificates for \emph{discrete} interface projections audited from logs.
In practice, many attractive projections are high-cardinality: contact-set hashes, retry traces, prefix-length profiles, or timing without bucketing.
Large alphabets make finite-sample certificates vacuous.

This note centralizes one narrow tool: \emph{coarsening} (deterministic partitioning/post-processing) as an explicit, receipt-facing design step.
We record the two properties this series relies on: (i) coarsening cannot \emph{increase} distinguishability (TV and max-divergence contract under post-processing), and (ii) coarsening reduces sample complexity by shrinking the audited alphabet.
The goal is non-redundancy: mechanism and contract papers can cite this note for ``how to make the audit feasible'' without repeating statistics.
\end{abstract}

\section{Setting}
A deployment chooses an interface projection $X=\pi(T)$ of a transcript $T$ and wants to certify (from logs) that the law of $X$ is nearly key-independent (Anonymity~B).\cite{series:profiling}
Synthesis~25 certifies discrete projections via multinomial concentration; Synthesis~27 explains how to discretize continuous timing via buckets.\cite{series:stataudit,series:bucketdesign}
This note treats the remaining gap: what to do when the chosen discrete projection still has an alphabet that is too large to audit.
For a fully wired receipt/evidence instantiation of a coarsening map (contact-set hash coarsened to a small signature), see the optional variant in Synthesis~17.\cite{series:workedexample}


\section{Coarsening as a declared map}
\begin{definition}[Coarsening map]
Let $X$ take values in a finite set $\mathcal X$.
A \emph{coarsening} is a deterministic map
\[c:\mathcal X\to\mathcal Y\]\
with $|\mathcal Y|<|\mathcal X|$.
We write $Y:=c(X)$.
Receipt-grade claims are stated for $Y$ (ENF forbids retaining/exposing $X$ beyond what is needed to compute $Y$).\cite{series:traceifaces}
\end{definition}

\begin{lemma}[Post-processing contracts TV and max-divergence]\label{lem:dataproc}
For any distributions $P,Q$ on $\mathcal X$ and any map $c$, let $P^c,Q^c$ be the induced laws of $Y=c(X)$.
Then
\[\TV(P^c,Q^c)\le \TV(P,Q),\qquad \Dinfty(P^c\|Q^c)\le \Dinfty(P\|Q).\]
\end{lemma}

\begin{proof}
Both are standard data-processing facts.
For TV: for any event $B\subseteq\mathcal Y$, the preimage $c^{-1}(B)\subseteq\mathcal X$ is an event, hence
$|P^c(B)-Q^c(B)|=|P(c^{-1}(B))-Q(c^{-1}(B))|\le \sup_{A\subseteq\mathcal X}|P(A)-Q(A)|$.
For $\Dinfty$: for any $B$ with $Q^c(B)>0$,
$P^c(B)/Q^c(B)=P(c^{-1}(B))/Q(c^{-1}(B))\le \sup_{A:Q(A)>0} P(A)/Q(A)$.
\end{proof}

\begin{remark}[What coarsening does and does not guarantee]
Coarsening is \emph{safe for privacy endpoints}: if a deployment can only certify bounds for $Y=c(X)$, those bounds still upper bound distinguishability on any downstream computation of $Y$.
However, coarsening can hide violations that would be visible at finer resolution.
In this archive, that tradeoff is handled explicitly: the ENF declares what the adversary tier can see, and the contract is only about that declared surface.\cite{series:traceifaces}
\end{remark}

\section{Sample-feasibility: why $|\mathcal Y|$ matters}
Synthesis~25 uses a Weissman-type tail bound of the form
\[\Pr\big[\TV(\widehat P,P) > \tau\big]\;\le\; (2^{m}-2)\,e^{-2n\tau^2},\qquad m:=|\mathcal Y|,\]
which implies the rough budget inequality in Synthesis~27.\cite{series:stataudit,series:bucketdesign}
Rearranging without approximation yields an explicit \emph{alphabet constraint}:
\begin{lemma}[Exact alphabet constraint]\label{lem:alphabet}
Fix $\tau\in(0,1)$ and failure probability $\delta\in(0,1)$.
A sufficient condition for $\Pr[\TV(\widehat P,P)\le \tau]\\ge 1-\delta$ under the Weissman bound is
\[m\;\le\;\log_2\!\bigl(2+\delta\,e^{2n\tau^2}\bigr).\]
\end{lemma}

\paragraph{Interpretation.}
If $m$ is too large for the available $n$, a certificate for $X$ will be too weak to be meaningful.
A declared coarsening $c$ reduces $m$ and restores feasibility, at the cost of claiming only what is visible at the coarsened surface.

\section{Design patterns (receipt-friendly)}
\paragraph{Hierarchical coarsening (coarse\,$\to$\,fine).}
Publish a stable coarse map $c_0$ and certify $Y_0=c_0(X)$ routinely.
Optionally, publish a refined map $c_1$ (or a refinement family) as a \emph{new menu item} when enough samples are available.
This keeps change control explicit: refinement consumes new audit confidence via Synthesis~26.\cite{series:anytimespend}

\paragraph{Hash then bin (large structures).}
When $X$ is a structured object (contact multiset, retry trace), deployments often first hash to a fixed domain.
Audit feasibility still depends on the \emph{effective} alphabet actually used in scope; a receipt-grade coarsening is then a binning of the hash space (e.g., ``top-$m$'' categories plus an \texttt{other} bin).
If the top-$m$ set is data-dependent, apply Synthesis~29: either select via a published witness (state-indexed family) or separate pilot selection from frozen-audit and spend confidence on updates.\cite{series:selectiondiscipline,series:anytimespend,series:menus}

\paragraph{Coarsen by declared invariants (mechanism-first).}
If the mechanism already enforces invariants (deadlines, prefix-length equalization classes, retry ceilings), define $c$ so that $Y$ is exactly the invariant class.
This aligns the audit surface with mechanism feasibility analyses (stop-time normal forms, prefix capacities) and avoids ``creative'' partitions that are hard to review.\cite{pub:stopnormal,pub:prefixcaps}

\section{Receipt-facing declaration checklist}
A coarsened projection should be publishable without re-deriving statistics:
\begin{itemize}[leftmargin=*]
\item Parent projection id (ENF-ID for $X$) and coarsening id (map digest) for $c$.
\item The induced alphabet size $m=|\mathcal Y|$ (or a conservative bound) used in the log-audit certificate.
\item Statement of interface discipline: observers at the declared tier see only $Y$ (not finer $X$).\cite{series:traceifaces}
\item Statistical evidence reference: Synthesis~25 (menu-level certificate) and, if repeated/expanding, Synthesis~26 (spending).\cite{series:stataudit,series:anytimespend}
\end{itemize}

\paragraph{How later papers should cite this note.}
This note owns the \emph{declared coarsening rule}: why a projection may be safely contracted to a smaller alphabet, how sample-feasibility constrains the declared alphabet size, and which coarsening patterns remain receipt-grade. Later terse papers should cite this note when the exact coarsening map, alphabet budget, or mechanism-aligned partition choice is live. If the live question is instead how a chosen coarsened surface is certified, updated, or carried into review, cite Synthesis~25--26 for the audit surface and the worked example / series spine for the maintained replay/review handoff rather than replaying coarsening prose locally.\cite{series:workedexample,series:seriesspines}
