# Paper series umbrella

This directory is the canonical home for the moving paper-family source trees.

Current contents:

- `series/anondht_state_series/`
- `series/anonymity_series/`
- `series/bossfight_series/`
- `series/certified_series/`
- `series/congestion_series/`
- `series/evaluation_series/`
- `series/operational_series/`
- `series/release_and_destination/`
- `series/synthesis/`

Why this exists:

- keep the shipped repo root smaller,
- keep paper families grouped under one parent,
- preserve the slow publication / release-queue surfaces separately from the moving source trees.

The canonical frozen public artifacts still live under `published/`.
The conservative review/control surfaces still live under `publishing/` and `release_queue/`.
