\begin{abstract}
Several ``Boss Fight'' calculations in this series take an explicit \emph{observation model}: how likely is it that an adversary sees a particular hop, contact set, or transcript projection.
This note centralizes a small but repeatedly used fact:
\emph{partial observation is a mixture/subsampling channel that strictly attenuates MaxL/odds-inflation, and receipts should publish the attenuation parameter.}
We give compact bounds (in the exact form needed by dial-sheet tables) and record a deployable interface: a \emph{stub-mix / relay} that reduces observation probability without attempting full mixnet anonymity.
\end{abstract}

\paragraph{Scope.}
This is a short interface note.
It does \emph{not} claim that a stub mix alone solves reader privacy; it only formalizes how \emph{reduced observation} feeds into the series' accounting.

\section{Observation as a channel wrapper}
Many witness surfaces in this archive are not directly exposed to an adversary.
For example: only a corrupted hop sees the next-hop choice; only a surveilled vantage sees packet times with good resolution; only a colluding relay learns contact sets.
We package this as a wrapper channel.

\begin{definition}[Observation thinning]
Let $Y$ be a transcript (or transcript projection) generated by a mechanism under secret $C$.
Fix an ``observation'' probability $p\in[0,1]$ independent of $C$.
Define the \emph{thinned} observation $Z$ by
\[ Z := \begin{cases}
Y, & \text{with probability } p,\\
\bot, & \text{with probability } 1-p,
\end{cases} \]
where $\bot$ denotes ``not observed'' (or an uninformative placeholder).
\end{definition}

This is the simplest model. More detailed models (multiple tiers, partial fields observed, noisy timestamps) reduce to mixtures of such wrappers.

\section{MaxL and odds inflation contract under thinning}
Maximal leakage admits a direct bound under thinning that is convenient for receipts.

\begin{lemma}[Mixture form for MaxL under thinning]\label{lem:thin-maxl}
Let $Y$ be a channel from $C$ with maximal leakage $\MaxL(C\to Y)=b$.
Let $Z$ be the thinned observation with parameter $p$ as above.
Then
\[
\MaxL(C\to Z) \;\le\; \log_2\big((1-p) + p\,2^{b}\big).
\]
\end{lemma}
\begin{proof}
Maximal leakage equals $\log_2\big(\sum_z \max_c P(Z=z\mid C=c)\big)$.
For $z=\bot$, the maximum conditional probability is $1-p$.
For $z\neq\bot$, $P(Z=z\mid c)=p\,P(Y=z\mid c)$, so the contribution is scaled by $p$.
Thus $\sum_z \max_c P(Z=z\mid c) = (1-p) + p\sum_y \max_c P(Y=y\mid c) \le (1-p)+p\,2^{b}$.
\end{proof}

\begin{remark}[Dial-sheet interpretation]
If $b$ is the per-lookup budget for a projection, the thinned budget is approximately $p\,b$ for small $b$ (first-order), but Lemma~\ref{lem:thin-maxl} gives the exact log-sum-exp form used by receipts.
\end{remark}

A companion inequality holds at the TV level.

\begin{lemma}[TV contraction under thinning]\label{lem:thin-tv}
For any two secrets $c,c'$, let $P_c$ and $P_{c'}$ denote the induced laws of $Y$.
Let $Q_c$ and $Q_{c'}$ denote the induced laws of $Z$.
Then
\[ \TV(Q_c,Q_{c'}) = p\,\TV(P_c,P_{c'}). \]
\end{lemma}
\begin{proof}
$Q_c = (1-p)\,\delta_{\bot} + p\,P_c$ and similarly for $c'$.
TV is homogeneous for signed measures and $\delta_{\bot}$ cancels.
\end{proof}

\section{A stub-mix / relay as an observation attenuator}
The Boss Fight calculations show that dummy-only mechanisms can collapse unless $p_{\mathrm{obs}}$ is extremely small.\cite{series:bossfightB}
This motivates a \emph{cheap} architectural lever:
reduce observation probability without attempting full low-latency anonymity.

\paragraph{Interface.}
A \emph{stub mix} is a one-hop (or few-hop) relay layer between the client and the DHT contact set.
The goal is not to hide the query from the relay (that is the job of cryptographic query privacy), but to reduce the probability that a routing-layer adversary links the client to the contact set for any given lookup.
Operationally this can be instantiated as:
\begin{itemize}[leftmargin=1.2em]
\item an OHTTP-style relay for lookup messages,
\item a small anycast/broker set with rotating, audited egress,
\item a short mix/cover network used only for fallback lookups.
\end{itemize}

\paragraph{Receipt parameterization.}
Receipts should treat the stub mix as a change to the observation model:
replace $p_{\mathrm{obs}}$ for the fallback path with a (published) upper bound that reflects relay compromise, egress observation, and correlation risk.
Lemma~\ref{lem:thin-maxl} then converts this attenuation into a bound on the budget actually spent.

\begin{remark}[Honesty requirement]
A stub-mix design is only useful if $p_{\mathrm{obs}}$ is published in the same ABOM/OINL or release receipt that publishes the Boss-Fight budget (as a line item).\cite{series:receiptitems}
Otherwise ``privacy'' can silently degrade when the relay set centralizes or becomes observed.
Closed-view auditing and CPPC receipts are a natural monitoring hook for this parameter.\cite{series:state3}
\end{remark}

\section{How this composes with the tiered pattern}
The tiered primary/fallback pattern note recommends treating the raw DHT as a budgeted residual.\cite{series:tieredpattern}
Observation attenuation is orthogonal: it can be applied to either path, but is particularly valuable for the fallback because it directly loosens the dummy-cover pressure.
