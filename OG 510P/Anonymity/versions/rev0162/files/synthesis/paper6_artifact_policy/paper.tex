\begin{abstract}
This archive is designed for short, referee-grade papers that remain readable and checkable without shipping a large companion repository.
Accordingly, the public release is \emph{source-only} (one \texttt{.tex} file per paper), while artifacts that are useful for deeper auditing
(e.g., scripts, logs, simulations, certificates/keys, measurement traces, and raw data) are distributed on request.
This micro-note standardizes the disclosure language used throughout the series and clarifies what is available, under what conditions, and how it is indexed.
\end{abstract}

\paragraph{Scope.}
Define the disclosure contract for this source-only public release: what is shipped publicly, what is held back, and how on-request artifacts are indexed to the public papers. This is intentionally a one-paragraph policy note plus canonical boilerplate, kept standalone for citation convenience.

\paragraph{Imports.}
None.

\paragraph{Exports.}
Canonical boilerplate and a manifest-indexing rule used by every paper in this archive when referring to artifacts, tooling, certificates, or raw evidence; the note is intentionally a micro-note rather than a full technical paper.

\paragraph{Artifact policy.}
This note \emph{is} the artifact policy; it is the canonical citation target \cite{series:artifactpolicy}.



\section{Policy statement (canonical)}
\paragraph{Public release.}
The public archive contains only referee-facing \LaTeX{} sources (one file per paper) plus a manifest of file hashes.
When a paper refers to paths such as \texttt{tools/}, \texttt{scripts/}, \texttt{evidence/}, or \texttt{certs/}, these refer to an \emph{artifact bundle}
that is not included in the public release.

\paragraph{On-request artifacts.}
On request, we can provide an archive containing the referenced artifacts, including (as applicable):
(i) build scripts and dependency locks;
(ii) raw and processed data;
(iii) simulation code and seeds;
(iv) evaluation harnesses;
(v) certificates/keys for proof-carrying plans and logs;
(vi) transparency-log checkpoints and witnesses; and
(vii) any auxiliary notes needed to reproduce plots or tables.

\paragraph{Disclosure control.}
Each paper may state additional disclosure constraints (e.g., what portions of logs or measurements can be shared publicly).
Absent an explicit restriction, artifacts are available to referees/auditors under a standard confidentiality assumption.

\paragraph{Indexing.}
The artifact bundle is indexed to this public release by the SHA256 manifest included at the archive root.

\section{Recommended boilerplate (non-redundant)}
Papers in this archive may include the following short paragraph:
\begin{quote}
\emph{Artifact policy.} This archive is source-only; supporting artifacts are available on request. See \cite{series:artifactpolicy}.
\end{quote}
