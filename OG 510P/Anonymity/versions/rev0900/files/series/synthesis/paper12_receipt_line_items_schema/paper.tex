\title{Receipt Line Items for Anonymity Claims:\\
\large A Channel-Bound Minimal Tuple for Published Budgets}
\author{}
\date{June 18, 2026 (archive rev0900)}

\begin{document}
\maketitle

\begin{abstract}
A receipt is useful only when it identifies the exact conditional claim that was proved. The former line-item schema allowed \texttt{obs\_model} to be a scalar observation probability or tier vector, even though those values do not determine an observation channel. This revision replaces that shortcut with a compact model-binding record: the secret and public side information, complete observer projection, operational horizon, source/configuration digests, recognized channel-witness mode, assumption evidence, deterministic evaluator, and fail-closed publication result. The result is smaller than the previous routing-heavy schema and makes the scientific trust boundary explicit: arithmetic may be valid under a model digest while deployment privacy remains unproved when the model binding is missing.
\end{abstract}

\paragraph{Scope.}
ABOM/OINL owns the outer claim carrier, threat-window and trace notes own semantic interfaces, and mechanism papers own their channel theorems. This note owns only the minimal per-claim tuple that joins those objects without inventing a new accountant.\cite{series:abomoinl,series:traceifaces,series:threatwindows,series:endpointbridge}

\section{Design rule: bind the channel before the number}\label{sec:rule}
A line item must answer four questions:
\begin{enumerate}[leftmargin=*]
\item \emph{What secret and complete adversary observation are being related?}
\item \emph{Which source-bound theorem or direct channel calculation justifies the metric value?}
\item \emph{How can an auditor deterministically replay that calculation?}
\item \emph{Which changes invalidate the result?}
\end{enumerate}

A scalar \(p_{\mathrm{obs}}\), compromise fraction, contact count, or list of tier rates cannot answer the second question. Equal observation rates can coexist with much larger leakage, and individually harmless tiers can jointly reveal the secret. The receipt therefore validates model binding before budget arithmetic.\cite{series:obsatten,series:tieredobs}

\section{Minimal envelope}\label{sec:envelope}
The outer envelope contains only stable routing identifiers:
\begin{itemize}[leftmargin=*]
\item \texttt{claim\_id}: stable claim-family identifier;
\item \texttt{tw\_id}: threat-window, repetition, and reset declaration;
\item \texttt{state\_decl\_id}: optional digest of long-lived state and monitored surfaces;
\item \texttt{lineage}: predecessor and relation \texttt{same-interface}, \texttt{coarsening}, or \texttt{new-interface}.
\end{itemize}
A human label is non-binding unless its canonical object and digest are also present. Plan and state equivalence rules belong to their owning notes.\cite{series:notation,series:planstateequiv,series:releaseproperty}

\section{Required line-item fields}\label{sec:fields}
Each budgeted claim carries the following fields.

\begin{description}[style=nextline,leftmargin=1.5em]
\item[\texttt{exposure\_nf\_id}] Digest-bound definition of the complete observer projection, including retries, timing, failures, stopping, aborts, and output length where visible.\cite{series:traceifaces}
\item[\texttt{model\_binding\_id}] Digest-bound record for the secret, prior/support convention, public side information, observer, unit, horizon, reset rule, and implementation/configuration that induce the channel.
\item[Channel witness] \texttt{channel\_witness\_id}: digest-bound witness with a recognized mode such as enumerated channel, independent erasure, common mixture, conditional factorization, dominating channel, or direct joint bound.
\item[Assumption evidence] \texttt{assumption\_evidence}: resolvable objects and checker results for every theorem precondition, including independence, support, sampling, or adaptive-history conditions.
\item[\texttt{usage}] The repetition policy, e.g. \(Q\) releases per window. A value \(B/Q\) is an allocation unless a conditional composition witness proves the runtime cap.\cite{series:bossfightB}
\item[\texttt{budget\_type}] The exact endpoint, e.g. maximal leakage in bits, pointwise posterior-mass leakage, true-odds bound with prior cap, or total variation. Labels that conflate these endpoints are invalid.\cite{series:endpointbridge,series:oddsinflation}
\item[\texttt{budget\_value}] Exact value or outward-rounded interval proved for the channel named by the model binding.
\item[\texttt{knobs}] Canonical source/configuration values that affect either mechanism behavior or the observer channel: retries, timeouts, widths, calendars, fallback, logging/extraction, and equalization parameters.\cite{series:mceq}
\item[\texttt{evidence\_id}] Optional additional empirical or mathematical evidence supporting the value; this does not replace the channel witness.\cite{series:condcert}
\item[\texttt{replay\_hook}] Stable plan ID, digest-bound plan specification, model-binding digest, evaluator source digest, canonical input order, arithmetic mode, and resolvable bundle pointer.\cite{series:contractobjects,series:transparencyprimitives}
\item[\texttt{drift\_invalidators}] Explicit list of source, configuration, observer, projection, horizon, evidence, or assumption changes that force replay or recertification.
\item[\texttt{publication\_eligibility}] Boolean plus blocking reasons. Missing model binding, channel witness, assumption evidence, conditional composition, or required external review yields \texttt{false}.
\end{description}

Contacted-service interfaces are semantic inputs. A canonical \texttt{contact\_surface\_id} should digest the method, full path-scoped URL, request-shaping defaults, time budgets, and fallback behavior; changing any of them changes the channel unless equivalence is proved. RFC~8785 canonicalization is one suitable encoding discipline.\cite{rfc8785,series:deployedsurfaces,series:recert}

  source_build_config_sha256

  mode
  channel_witness_id
  channel_witness_sha256
  assumption_evidence[]

  type
  value_or_interval

  plan_id
  plan_spec_id
  evaluator_source_sha256
  arithmetic_mode
  canonical_input_order
  bundle_pointer

blocking_reasons[]
\end{verbatim}

Module-specific data belongs under one \texttt{module\_ext} map. It must not redefine the core semantics or smuggle a scalar observation rate in place of the channel witness.

\section{Verification order and verdict}\label{sec:verification}
The replay process is ordered:
\begin{enumerate}[leftmargin=*]
\item verify canonical serialization and digests;
\item verify source/configuration, observer projection, horizon, retry, stop, and reset bindings;
\item verify the recognized channel-witness mode and all assumption evidence;
\item replay the channel-level metric and any adaptive composition under pinned arithmetic;
\item check the claimed interval or cap;
\item evaluate drift invalidators and publication blockers.
\end{enumerate}

The successful arithmetic verdict is
\[
\texttt{arithmetic\_valid\_under\_model(model\_binding\_id)},
\]
not an unqualified \texttt{private} or \texttt{anonymous}. A model-binding failure cannot be downgraded to a warning because downstream summaries routinely discard warnings.

\section{Evidence, replay, and publication are distinct}\label{sec:separation}
\texttt{evidence\_id} names what supports an input or theorem assumption. \texttt{replay\_hook} names how to recompute the conditional result. \texttt{publication\_eligibility} records whether all scientific and review gates needed for a public claim are present. A dual certificate may make arithmetic replayable while model binding is absent; a signed outer receipt may preserve provenance while the inner theorem is false. None substitutes for the others.

\section{Publication checklist}\label{sec:publish}
A line item is publication-eligible only when:
\begin{enumerate}[leftmargin=*]
\item every required field above resolves and validates;
\item the complete observer projection and model binding are current;
\item the channel witness and assumption evidence pass;
\item replay reproduces the metric using pinned arithmetic;
\item lineage and drift classification are explicit;
\item the outer claim carrier and release receipt bind the exact line item; and
\item any required hostile review or external countersignature is present.
\end{enumerate}
Transparency anchoring and user discovery can make the result findable and tamper-evident, but they do not repair a missing channel theorem.\cite{series:abomoinl,series:releaseproperty,series:transparencyprimitives,series:userminiface}

\section{Takeaways}
\begin{itemize}[leftmargin=*]
\item The minimal receipt is channel-bound, not scalar-bound.
\item Model validation precedes arithmetic replay.
\item The honest machine verdict names the model digest and retains publication blockers.
\item Evidence, replay, provenance, and authorization are separate layers.
\item Shrinking the schema to these fields removes routing bureaucracy while strengthening the actual claim boundary.
\end{itemize}
