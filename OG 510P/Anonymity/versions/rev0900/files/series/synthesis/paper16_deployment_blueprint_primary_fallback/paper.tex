\begin{abstract}
This blueprint turns the repaired primary/fallback architecture into a deployable evidence set. The old version allowed a scalar or tiered observation model in the receipt and concentrated on packaging. The corrected order is scientific first: extract the complete channel, bind it to source and configuration, prove per-path and selector bounds, test correlation and stopping behavior, and only then package the result. A manifest or transparency proof can preserve provenance but cannot rescue a false observer model. The blueprint is intentionally small: six artifacts, a deployer checklist, an auditor checklist, and a hostile-test matrix. Missing channel evidence keeps publication closed.
\end{abstract}

\section{The six-artifact deployment cut}\label{sec:artifacts}
A minimal deployment evidence set contains:
\begin{enumerate}[leftmargin=*]
\item \textbf{Source/configuration manifest.} Canonical digests for client, primary service integration, fallback implementation, selector, extractor/logging code, dependencies, runtime configuration, and contacted-service surfaces.
\item \textbf{Threat and projection declaration.} Secret, public side information, observer, complete output projection, unit, horizon, reset rule, retries, stopping, fallback, and visible errors/length/timing.\cite{series:threatwindows}
\item \textbf{Channel-witness bundle.} One recognized, source-bound channel witness for each path and one selector/joint-dependence witness. Scalar observation or fallback rates may appear only as non-authorizing telemetry or as parameters inside proved wrappers.
\item \textbf{Budget witness.} Deterministic evaluator and exact/outward-rounded arithmetic reproducing per-path and combined metric values under the bound model; plan and model digests are inputs.\cite{series:bossfightdial}
\item \textbf{Hostile-test results.} Correlated contacts, secret-dependent fallback, retry/abort/stop changes, history-dependent support, missing evidence, and source/config drift must fail or trigger recertification.
\item \textbf{Outer receipt and provenance.} The channel-bound line items, claim/nonclaim surface, lineage, append-only anchoring, and publication blockers. These preserve identity and history; they do not substitute for Artifacts 2--5.\cite{series:abomoinl,series:releaseledger,series:transparency}
\end{enumerate}

Every pointer must resolve inside the release or to an explicitly named, retrievable evidence object. ``Available on request'' is not sufficient for an argument-bearing theorem input.

\section{Deployer sequence}\label{sec:deployer}
\begin{enumerate}[leftmargin=*]
\item \textbf{Freeze the semantic target.} Write the secret, public side information, observer, complete projection, horizon, and reset rule before measuring or tuning.
\item \textbf{Extract both path channels.} Include primary errors, fallback trigger, retries, timeouts, aborts, and stop/length behavior.
\item \textbf{Bind implementation bytes.} Digest all source/configuration and contacted-service inputs that can change either mechanism or observation.
\item \textbf{Prove the channel mode.} Use an enumerated/direct joint bound or discharge every precondition of a recognized family such as common mixture. Do not infer the family from a scalar rate.\cite{series:obsatten}
\item \textbf{Prove selector handling.} Demonstrate secret independence conditional on declared state, or budget the selector and full joint release directly.\cite{series:selectiontax}
\item \textbf{Handle tiers jointly.} Supply per-tier witnesses and a conditional-factorization witness, or a direct joint-channel bound.\cite{series:tieredobsvec}
\item \textbf{Budget repeated use.} Use conditional per-history bounds and include release/abort decisions. Treat \(B/Q\) as an allocation, not a measured guarantee.
\item \textbf{Run hostile tests.} Execute the negative cases in Section~\ref{sec:hostile} against the same bytes that the receipt identifies.
\item \textbf{Emit the line item.} Bind model, witness, evidence, evaluator, knobs, drift invalidators, and publication blockers using Synthesis~12.\cite{series:receiptitems}
\item \textbf{Anchor last.} Package and log only after the scientific gates pass; anchoring a failed model merely makes the failure tamper-evident.
\end{enumerate}

\section{Auditor/referee sequence}\label{sec:auditor}
An auditor should work in the opposite direction from the old packaging-first habit:
\begin{enumerate}[leftmargin=*]
\item resolve the exact source/configuration and observer projection from the receipt;
\item reconstruct the channel-witness assumptions and verify their evidence;
\item check that path selection and all released tiers are inside the joint model;
\item independently recompute the channel-level metric and adaptive composition;
\item run or inspect the hostile tests, especially the cyclic-reveal and selector-leak counterexamples;
\item inspect drift invalidators and compare the current source/configuration to the certified bytes;
\item only then verify outer signatures, inclusion proofs, and lineage.
\end{enumerate}

A successful outer provenance check with a failed model-binding gate is a correctly authenticated non-certificate.

\section{Role-specific minimum outputs}\label{sec:roles}
\paragraph{Deployment operator.}
A machine-readable manifest, current model-binding and channel-witness bundles, replayable budget result, hostile-test result, and drift policy.

\paragraph{Referee or independent reviewer.}
An independently reproduced metric, a signed review result bound to source and model digests, and explicit unresolved assumptions/nonclaims.

\paragraph{Client or user.}
A discoverable claim ID, current publication status, model/version digest, headline metric with endpoint name, and visible blockers. A user interface must not collapse \texttt{arithmetic-valid-under-model} into an unqualified anonymity badge.

\section{Change control}\label{sec:change}
Changes are classified by the first semantic object they affect:
\begin{itemize}[leftmargin=*]
\item outer packaging only: refresh lineage;
\item evaluator, evidence, or plan: replay;
\item source/configuration, observer, projection, selector, retry/stop behavior, or theorem assumptions: recertify the channel;
\item endpoint semantics or secret/public-side-information definition: mint a new claim interface.
\end{itemize}
Monitoring can detect drift, but a monitored scalar does not automatically repair or recertify the model.\cite{series:evalnotary,series:advantagecontracts,series:planstateequiv}

\section{Publication gate}\label{sec:publication}
Publication remains closed unless all six artifacts resolve, the hostile tests pass, the replayed arithmetic matches, required external review is bound to the same source/model digests, and the outer receipt carries no contradictory status. The absence of a private signing key affects signature completeness; it is separate from the scientific blockers above.

\section{Takeaways}
\begin{itemize}[leftmargin=*]
\item Extract and prove the channel before building the receipt chain.
\item Bind primary, fallback, selector, tiers, retries, and stopping to the same source/configuration identity.
\item Run counterexamples as release tests, not merely prose warnings.
\item Check provenance last; it authenticates evidence but does not create it.
\item Keep publication closed on missing model evidence or external review.
\end{itemize}
