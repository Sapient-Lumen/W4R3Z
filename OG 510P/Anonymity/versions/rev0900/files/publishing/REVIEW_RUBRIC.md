# Review Rubric

Use this rubric when a future turn reviews one paper conservatively.

## Hard blockers

A paper should **not** move beyond Hold if any of these are true:

1. The paper's main ownership boundary is still moving.
2. The paper depends on multiple still-moving sibling notes just to be intelligible.
3. The current draft mostly records internal routing, bookkeeping, or decomposition choices.
4. The title or scope still looks provisional.
5. The source file is not clearly identified as the freeze target.

## Positive signals

A paper is stronger when several of these are true:

- The abstract states one stable public claim.
- The introduction can be understood without a moving local tail.
- It cites the legacy Mathematics backbone cleanly rather than re-deriving it.
- It has a clear public audience and stable terminology.
- The date/version metadata do not suggest frantic recent refactoring.

## Recommended review output

Every paper-level review should record:

- source `.tex` path,
- provisional public title if eventually released,
- dependencies needed for comprehension,
- churn observations,
- conservative verdict,
- and the single next safest step.

## Allowed conservative verdicts

- `Hold`
- `Candidate`
- `Candidate, but revisit after sibling stabilization`
- `Published-ready queue`

`Published` is not a review verdict; it is a later freeze action.
