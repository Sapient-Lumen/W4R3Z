\section{Non-redundancy policy (gameplan)}
To keep papers brief while referee-grade:
\begin{enumerate}[leftmargin=*]
\item \textbf{Each endpoint metric is ``owned'' once.}
  Posterior-mass/PML composition is owned by \emph{Posterior-Mass Inflation Anonymity} (anonymity series Paper~A).
  TV certificates and duality are owned by the published knapsack/transport paper.
  Congestion witness definitions are owned by \emph{Congestion-EQ}.
\item \textbf{Each new witness tier must export a contract object.}
  If a paper introduces retries, calendars, state evolution, or auditing, it should define (i) the witness family, (ii) the budget metric, and (iii) the accountant for repeats/resets,
  then cite prior papers for everything else.
\item \textbf{Certification is a separate layer.}
  Mechanism papers should avoid re-litigating certificate formats.
  ABOM/OINL, proof-carrying budgets, notarization, and ledger receipts are the canonical certification papers.
\item \textbf{No duplicated ``background'' sections.}
  When background is required, use a single paragraph pointer to the backbone paper and restate only the local notation.
\end{enumerate}

\section{Cross-pollination targets (high leverage)}
This is the shortlist of ``shared lemmas'' / interfaces worth reusing across papers to prevent drift:
\begin{enumerate}[leftmargin=*]
\item \textbf{Trace interfaces / tiers:} name the transcript projection first. Reuse the CCT schema and tier vocabulary (Synthesis~3) whenever a paper budgets ``the transcript''.
\item \textbf{Endpoint metrics bridge:} reuse the distinctions and identities among posterior-mass inflation, PML, MaxL, and true odds, and the standard $\log(\alpha K)$ identification sizing rule (Synthesis~5) rather than re-deriving them locally.

\item \textbf{Release receipts $\leftrightarrow$ anonymity certificates:} both are transparency-log objects with an equivocation threat model.
  Reuse the same log schema and auditor tooling where possible.
\end{enumerate}
