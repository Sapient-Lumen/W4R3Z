## Evidence found

A Published-ready label alone was not enough evidence that a source could be frozen cleanly. The queue needed a compact audit that binds each release-lane item to exactly one `source_tex` path, captures the source hash, and exposes static citation/reference, placeholder, and malformed-bibliography blockers.

A Synthesis~17 bibliography block had lost the leading backslashes on `\bibitem` / `\newblock` fragments. That defect could make local closure appear cleaner than the TeX source really was, so malformed bibliography command fragments are now checked explicitly.

The research-object metadata surfaces existed, but their integrity checker needed to validate the provenance statement shape, external parameters, resolved dependency hashes, and notice revision binding rather than just checking for files.

## Change made

Published-ready items now pass static preflight; Candidate items remain non-release-targets. The next-release recommendation is advisory only and does not authorize publication.
