This revision closes five parser, schema, text, tooling, and decision-ledger trust seams without moving the release queue. First, every shipped JSON file is parsed with duplicate object keys rejected, so a governance surface cannot silently depend on last-key-wins parser behavior. Second, the schema catalog is checked as a catalog: every shipped `*.schema.json` document is validated as a Draft 2020-12 schema, and every schema referenced by `publishing/check_surface_schemas.py` must exist. Third, shipped text surfaces are checked for UTF-8 decoding, LF-only line endings, and NUL-byte absence. Fourth, all `publishing/*.py` tools receive a static integrity pass for syntax, expected script shape, future annotations, and duplicate literal dictionary keys. Fifth, the decision-note ledger is checked directly: every note must be indexed, latest-note pointers must align, no-publication notes must carry a textual non-publication marker, and named `Subject` TeX paths must exist.

The new guards are non-authorizing. They strengthen parser ambiguity control, schema trust, text-byte portability, publishing-tool integrity, and decision-history integrity, but they do not publish a paper, do not create a public Anonymity citation head, and do not move any Candidate, Published-ready, or Hold note.
