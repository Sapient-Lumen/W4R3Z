## Reason
rev0828 made rebuild phases survivable, but the remaining high-risk seam was that the release-lane compile gate still accepted a single-pass TeX smoke result and did not reject final rerun/reference warnings. During this revision, a two-pass trial still produced a final rerun warning for one release-lane paper, so the gate was tightened to a bounded three-pass final-clean witness. The Unicode-control hygiene check was also wasteful in the rebuild tail because it paid per-codepoint Unicode classification on mostly ASCII files.

## Changes accepted
- Upgraded the queue compile-smoke gate to a bounded three-pass runner with final-pass unresolved-reference/citation and rerun-warning rejection.
- Replaced the fragile xargs/timeout TeX loop with the same shell entry point delegating to a sequential Python live runner that redirects logs to files, avoids in-memory log capture, and kills TeX process groups on timeout.
- Regenerated `reports/queue_compile_smoke.json`: 28/28 release-lane targets passed, with zero final unresolved-reference/citation warnings and zero final rerun warnings.
- Refactored `publishing/check_unicode_control_hygiene.py` with an ASCII fast path while preserving the hidden-control/bidi/invisible-control fail-closed policy.
- Kept report/schema counts flat; no publication and no queue movement.

## Follow-up
Keep the live compile gate explicit rather than silently embedding it in every routine verify; next high-value work is reducing large derivable worked-example artifacts or moving them to optional support packs.
