# Rev679 - macro record root previews keep default-slot step counts

Micromax had already converged on one clear default-slot story across the macro surface: idle `macro`, `macro status`, `showmacro`, `macro play`, and exact `last` slot rows all kept `default=last (N step[s])` visible instead of flattening the default replay slot into a nameless summary. But one small archive seam lingered after those fixes landed: some prompt-completion tests and nearby docs still described the older `macro record` / `macro rec` / `macro start` root preview as `idle · default=last · ...`, even though the live code had already been returning step-aware summaries there too.

Rev679 keeps the follow-up deliberately small and archive-friendly. There is no behavior change in the editor core here; instead, the stale tests and docs are brought back into line with the real headless prompt surface. Fresh record-root previews are now pinned as `idle · default=last (0 steps) · 0 macros`, saved-state previews stay pinned as `idle · default=last (1 step) · ...`, and the nearby command-bar docs now describe the same step-aware default-slot witness that completion/runtime already emit. The goal is simple: future humans or LLMs should not have to wonder whether `macro record` is the one macro lane that still hides the default slot's step count.
