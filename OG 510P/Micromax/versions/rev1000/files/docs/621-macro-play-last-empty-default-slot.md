# Rev680 - keep empty `macro play last` paths truthful about the default slot

Micromax had already made the default replay slot explicit almost everywhere around macro playback. Idle `macro`, `macro status`, `showmacro`, and exact saved `last` playback rows all taught that `last` is the default slot, and an empty `showmacro last` path already stayed visible as `0 steps [default] · default replay slot` instead of pretending the name was missing. But one narrow exact-play seam still lagged behind that story: on a fresh editor, typed `macro play last` / `macro run last` rows and runtime failures still flattened the empty default slot back into the generic `missing macro` / `no such macro` wording.

Rev680 keeps the follow-up deliberately small and headless-first. Exact empty playback slot/count rows for `last` now reuse the inspectable `0 steps [default]` label and report `default slot empty`, while missing named slots like `ghost` still say `missing macro` / `no such macro`. Runtime `macro play last`, `macro run last N`, and direct `play_macro('last')` now reuse the same truthful distinction with `default slot is empty`. The goal is simple: the editor should not teach that the default replay slot exists everywhere except the exact moment a user tries to replay it while empty.
