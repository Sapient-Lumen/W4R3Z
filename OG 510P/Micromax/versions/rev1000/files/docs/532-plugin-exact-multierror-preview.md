# Exact broken plugin rows keep multi-error count truth

Rev590 is a tiny trust/legibility follow-up to the recent exact plugin preview cleanup. Micromax already kept count-aware multi-error detail in the narrow `plugin reload NAME` path, and rev589 had just stopped healthy no-description exact rows from going blank. But one exact broken-plugin seam still lingered beside those fixes: when a plugin accumulated more than one recorded load error, exact `showplugin NAME`, `plugin info NAME`, and `plugin errors NAME` completion rows still previewed only the trailing error text even though Micromax already knew the full error count. The fix stays intentionally small: `_plugin_exact_error_info(...)` now centralizes the tiny `N load errors · last: ...` summary, the three exact broken-plugin rows reuse it, grouped plugin picker rows stay compact and unchanged, and focused tests pin the multi-error case so future cleanup does not drift back to countless exact rows.
