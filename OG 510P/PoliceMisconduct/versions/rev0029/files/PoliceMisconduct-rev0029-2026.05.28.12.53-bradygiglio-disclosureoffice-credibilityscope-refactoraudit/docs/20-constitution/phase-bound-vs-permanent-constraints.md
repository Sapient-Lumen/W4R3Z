# Phase-bound vs permanent constraints

The cube must know which rules define the project and which rules define the current safe phase.

## Permanent

Permanent constraints are identity conditions. Violating them changes what the project is.

Examples:

- source-bound claims;
- adjudication precision;
- civilian dignity and privacy;
- officer due process;
- no name-only merges;
- public record is not public display;
- rollback/correction duty;
- no law-enforcement targeting product against civilians.

## Phase-bound

Phase-bound constraints are temporary gates.

Examples:

- no live person records yet;
- no live incident records yet;
- DOJ SLS as active pilot;
- source-inventory pages before officer lookup;
- no payload summaries before capture/privacy;
- no public status banners before proof.

A phase-bound constraint can be relaxed only by naming what was earned.

## Unknown

Unknown constraints are not yet settled. They should become open questions or design tensions, not hidden assumptions.
