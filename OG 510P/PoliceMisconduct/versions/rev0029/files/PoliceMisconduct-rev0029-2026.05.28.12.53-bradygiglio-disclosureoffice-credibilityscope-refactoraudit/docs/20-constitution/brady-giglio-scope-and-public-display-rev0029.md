# Brady/Giglio scope and public display — rev0029

Public record does not mean public display. Brady/Giglio-related information is especially sensitive because it can combine person identity, criminal case context, witness credibility, sealed/protected material, prosecutor duties, defense needs, and officer due process.

Rev0029 keeps all person-specific Brady/Giglio display closed. It allows only definitions, gates, synthetic fixtures, and future route design.
