# Civilian privacy before person records

The cube still has no live person records. Rev0024 explains what must exist before that changes: a civilian role taxonomy, sensitive identity minimization matrix, witness retaliation risk ledger, trauma-media handling rules, consent/preference gates, and publication/access crosswalks.

The strongest default is suppression. Public record availability does not decide display. Display is earned by source custody, privacy review, source voice, minimization, correction routes, access tier, and public-interest justification.
