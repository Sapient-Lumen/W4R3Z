# Source atlas design

The first public surface should be a source atlas, not a misconduct index.

## Source atlas row

A public source atlas row can show:

- agency or matter label;
- state or territory;
- source owner;
- source URL;
- document classes available;
- source-page status label;
- access date;
- current-status verification warning;
- extraction state.

It cannot show:

- claims against named officers;
- incident narrative summaries;
- civilian names;
- settlement-over-guilt statements;
- risk scores;
- rankings.

## Why a source atlas matters

A source atlas is immediately useful to journalists, researchers, oversight bodies, families, and community members because it answers a fundamental question: where are the public accountability records, and what kinds of records are they?

It also creates the correct foundation for later claim extraction. The source atlas forces the cube to preserve provenance before interpretation.

## Display copy

Every row should carry language close to:

> This row lists a public source carrier. It does not assert that misconduct occurred and does not identify any officer or civilian. Status labels are source-scoped and may require current verification.
