# Document role matrix method — rev0009

The document-role matrix classifies source-page labels into triage families such as investigative findings carriers, court-order carriers, motions/requests, agreements/decrees, monitoring/compliance carriers, closure/completion signals, public explainers, and source-entry rows.

This matrix is not a reading of document contents. It is a routing layer. It tells future operators what kind of review is likely required before a document can support a bounded claim.

## Hard stops

- A findings-report label is not a misconduct finding.
- A complaint label is not proof of the complaint’s allegations.
- A consent-decree label is not a current enforcement-status claim.
- A motion-to-terminate label is not a termination order.
- A closing-letter label is not a court order.
- A public PDF URL is not permission to extract names.

## Promotion path

A document role can only advance toward a claim after URL freezing, content hashing or no-bundle receipt, privacy scan, source-text pinning, claim-state assignment, and rollback trigger creation.
