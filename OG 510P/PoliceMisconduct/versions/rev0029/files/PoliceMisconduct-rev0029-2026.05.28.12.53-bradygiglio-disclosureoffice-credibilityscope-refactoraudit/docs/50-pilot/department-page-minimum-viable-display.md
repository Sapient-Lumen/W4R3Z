# Department page minimum viable display

A department page in the first public product should be a source inventory, not a judgment page.

## Allowed early sections

- Department / agency name.
- Jurisdiction type if known: police, sheriff, territory, prosecutor, subunit, mixed, other.
- Public source carriers found.
- DOJ matter labels involving the agency.
- Document classes available.
- Source-page status labels with access date.
- Verification warnings.
- Missing-source prompts.

## Blocked sections

- Officer lists.
- Incident lists.
- “worst officers” or rankings.
- Settlement amounts by officer.
- Narrative summaries of harms.
- Complaint counts extracted from findings reports.
- Risk scores.

## Why this is still useful

A community member, reporter, or researcher can discover that there are findings reports, decrees, monitor reports, technical assistance letters, or closure documents without the cube yet summarizing them. That alone reduces fragmentation.

## Required warnings

- “This page is a source inventory.”
- “This page does not assert misconduct by any named person.”
- “Status labels are source-scoped and may be stale.”
- “Linked documents may contain sensitive person information; extraction is gated.”
