# Current-status candidate model

The cube needs more than two choices: either “make a public current-status claim” or “ignore the signal.” Rev0006 inserts a candidate layer.

## Candidate layer

A candidate may say: “the source family currently points toward termination/completion/closure/motion-pending, but these proof gaps remain.” It must also say why the candidate cannot be public current status.

Required fields:

- candidate ID;
- matter/source row link;
- candidate status value;
- supporting signals;
- conflicting or lagging signals;
- proof still missing;
- rollback triggers;
- explicit `public_current_status_claim_admitted: false`.

## Promotion gate

Promotion to public current-status requires:

1. governing order/docket proof where a court matter is involved;
2. source-family comparison;
3. scope classification;
4. history-retention warning;
5. display copy review;
6. rollback registration.

The model exists to make uncertainty durable rather than invisible.
