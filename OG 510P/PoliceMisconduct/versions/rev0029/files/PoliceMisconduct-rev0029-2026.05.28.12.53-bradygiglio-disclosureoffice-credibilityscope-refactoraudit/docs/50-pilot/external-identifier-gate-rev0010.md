# External identifier gate — rev0010

External identifiers are match evidence, not merges.

The corpus must resist false certainty. ORI, CSLLEA, LEAIC, official agency pages, state POST directories, and government directories each answer different questions. None alone establishes all of: current existence, agency scope, service area, staffing denominator, officer employment roster, source-page status, and public accountability context.

The minimum canonicalization package is: official agency/government source + one identifier or denominator source + jurisdiction/subunit review + signed merge/non-merge receipt + unmerge path.
