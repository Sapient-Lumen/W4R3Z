# No person records yet

This rule is stricter than “be careful.” It is a hard gate.

In rev0003 and the immediate next pilot steps, do not create:

- officer records;
- civilian records;
- witness records;
- victim/survivor records;
- family records;
- incident-person participation records;
- Brady/Giglio records;
- criminal-charge records;
- social-media records.

## Why

The cube is still learning how to hold source custody, document class, status drift, and display gates. A person-level mistake can harm real people, even if the underlying source is public.

## What is allowed

- Agency names.
- Matter labels.
- Source URLs.
- Document class labels.
- Source-page status labels.
- Access times.
- Warnings.
- Synthetic examples.

## When this rule can loosen

Only after a future revision adds identity gates, privacy scans, right-of-reply mechanics, reviewer roles, source-document hashes, and rollback tests for person-level claims.
