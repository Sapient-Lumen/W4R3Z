# WARC/WACZ preservation note — rev0011

The preservation target for web pages is WARC/WACZ-style capture plus extracted metadata, not ad hoc screenshots or copied snippets.

The cube should preserve:

- source page HTML and response metadata;
- link maps from source pages to document targets;
- redirect chains;
- content type and byte-length metadata;
- payload hashes when payload capture is ethically and legally permitted;
- capture timestamps;
- a statement distinguishing archived source state from the live site.

Screenshots can help human review, but they are not sufficient source custody.
