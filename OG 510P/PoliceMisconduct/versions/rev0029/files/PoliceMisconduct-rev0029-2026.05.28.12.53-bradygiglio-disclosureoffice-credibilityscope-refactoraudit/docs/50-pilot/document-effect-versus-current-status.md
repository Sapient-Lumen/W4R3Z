# Document effect versus current status

The cube distinguishes four layers:

1. **Source-page label** — what a page such as DOJ SLS lists beside a matter.
2. **Document event** — that a linked document exists and has a date/family.
3. **Document-stated effect** — what an order, motion, response, agreement, or closing letter says it does or requests.
4. **Current status** — a present-tense public status banner after freshness, rollback, display, and source-family review.

Rev0007 admits layers 2 and 3 for a small DOJ SLS subset. Layer 4 remains closed.

## Critical distinctions

- A motion is not an order.
- Partial termination is not full termination.
- Sustainment is not closure.
- A DOJ closing letter is not a court order.
- Dismissal or closure does not erase prior findings, complaints, agreements, monitor reports, or community history.
