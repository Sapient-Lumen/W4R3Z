# Denominator source bridge method — rev0010

A denominator bridge row records what an external source class may support after matching.

It does not admit the denominator value. It does not admit a public rate. It does not admit a misconduct or status claim.

Bridge classes opened in rev0010:

- DOJ SLS cases/matters page: official matter/document-carrier source, not a denominator source.
- BJS CSLLEA data collection and 2018 statistical tables: state/local agency universe and personnel/function denominator candidates, reference-date bounded.
- BJS CSLLEA 2022 forthcoming watch: freshness reminder, not a dataset claim.
- ICPSR/NACJD LEAIC: identifier crosswalk candidate for ORI/FIPS/GOVID linkage.
- FBI CDE/UCR: reporting-agency/ORI candidate where exposed.
- FBI National Use-of-Force: aggregate/participation context with lawfulness/policy caveat.
- IADLEST NDI: future person-level decertification source class, quarantined from agency denominator use.
