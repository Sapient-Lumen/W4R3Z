# Court-order and source-acquisition queue method

A ticket is created when a status bundle has a consequential unresolved gap. Examples: a DOJ press release says a court terminated a consent decree, but the terminal order is not yet accessioned; or a source page says a matter is closed while the cube has only a motion.

Tickets are not evidence. They are work instructions.

Each ticket must be resolved by one of four outcomes:

- accessioned official order/source;
- documented inability to locate after specified search;
- source-family contradiction requiring quarantine;
- superseding source that changes the target.

No ticket may create a public claim.
