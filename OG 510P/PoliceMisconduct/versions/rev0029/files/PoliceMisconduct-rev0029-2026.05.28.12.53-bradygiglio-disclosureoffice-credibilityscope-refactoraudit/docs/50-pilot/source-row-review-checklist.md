# Source-row review checklist

For every source row, answer these before public display.

## Identity of the source

- Who owns the source?
- Is the source official, court, monitor, local government, civil-society, academic, news, or other?
- What was the access time?
- Does the page give an updated date?
- Is the document locally frozen or only URL-pinned?

## Scope of the row

- Is this a department, sheriff office, prosecutor office, subunit, multi-agency matter, or case-party label?
- Does it involve a territory, tribal agency, campus agency, jail/prison entity, or other edge case?
- Does the row require split rows?

## Status

- What exact source-page status label is shown?
- Is there a linked court order supporting status?
- Are there newer news/status signals?
- Does the row need a status-drift warning?

## Document class

- Findings report or letter?
- Complaint?
- Consent decree?
- Settlement agreement?
- Monitor/compliance report?
- Closing letter?
- Court order?
- Statement of interest?
- Fact sheet?
- Other?

## Display

- Is the row source-inventory-only?
- Does the row accidentally imply person misconduct?
- Are person names blocked from display?
- Is the nonclaim warning present?
