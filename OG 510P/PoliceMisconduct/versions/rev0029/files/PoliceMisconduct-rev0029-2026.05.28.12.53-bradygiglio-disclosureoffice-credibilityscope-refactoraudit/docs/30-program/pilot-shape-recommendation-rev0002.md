# Pilot shape recommendation — rev0002

Rev0002 does not select the first pilot. It narrows the judgment about what a good first pilot must do.

## Criteria for a first pilot

A first pilot should:

1. exercise normalization across several carrier types;
2. minimize person-level public display;
3. use sources whose custody can be pinned and revisited;
4. expose record gaps rather than pretending absence means no misconduct;
5. support rollback if a source is corrected, sealed, or superseded;
6. produce a useful civic artifact even before officer lookup exists.

## Better early pilots

### Consent-decree / monitor-report pilot

Strengths:

- mostly department-level;
- public records are often rich and citable;
- reveals policy, discipline, supervision, and data-quality failures;
- connects naturally to reform timelines.

Risk:

- covers only a small and non-representative set of departments.

### Settlement-ledger pilot

Strengths:

- directly tests money, litigation, disposition, and incident linkage;
- useful to journalists, councils, researchers, and community members;
- can begin with municipal/county totals before officer aggregation.

Risk:

- settlement does not equal admission;
- some settlements are hidden, aggregated, or NDA-constrained;
- officers may be named inconsistently or not at all.

### Policy/union-contract pilot

Strengths:

- low person-level risk;
- creates institutional context;
- useful for explaining discipline, arbitration, record destruction, waiting periods, and oversight friction.

Risk:

- does not yet prove incident/lawsuit identity normalization.

## Worse early pilots

### National officer lookup

Too dangerous before identity, correction, and display rules mature.

### News-first misconduct scraping

High recall but poor adjudication clarity; easy to launder allegations and miss corrections.

### Fully automated docket ingestion

Tempting, but likely to create brittle extraction errors before source and claim gates are mature.

## Provisional path

A strong first pilot could combine:

- 3–5 consent-decree or monitor-history departments;
- their policy and union-contract timelines;
- public settlement ledgers where available;
- a small number of linked lawsuits as source-custody examples;
- synthetic officer/incident examples for identity testing before public person-level display.

This path tests the cube's distinctive strength: connecting source carriers without collapsing their epistemic status.
