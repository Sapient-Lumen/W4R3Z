# Workstreams

## WS-0001 Source carriers and acquisition

Define source carrier types and acquisition protocols for court records, FOIA releases, settlements, POST lists, policies, and news.

## WS-0002 Core schemas

Harden officer, department, incident, lawsuit, settlement, source, evidence claim, and correction schemas. Add synthetic fixtures.

## WS-0003 Privacy and display

Define privacy classes, display classes, public wording, redaction/minimization behavior, and access threat model.

## WS-0004 Entity resolution

Define identity features, confidence bands, review workflow, unmerge receipts, and negative match search.

## WS-0005 Pilot scope

Choose a pilot that tests normalization but avoids avoidable harm.

## WS-0006 Corrections and rollback

Build correction request workflow, rollback propagation, public correction notes, and audit receipts.

## WS-0007 Public language and UI

Define language rules for precise descriptions that do not reproduce euphemisms or overclaim outcomes.
