# Source-row admission and display gates

A source row is safer than a person claim, but it still needs gates.

## Admission gate

A row may enter the source graph when it has:

- source URL or locator;
- source owner;
- access time;
- row label;
- source type;
- nonclaim boundary;
- display class.

## Public display gate

A row may enter public source-inventory display when it has:

- admission gate complete;
- no person-level extraction;
- status label scoped to source and access time;
- warning copy;
- current-status recheck requirement if status is volatile.

## Document summary gate

A linked document may be summarized only after:

- document accession;
- document class;
- privacy precheck;
- claim-state template;
- reviewer signoff;
- rollback trigger.

## Person claim gate

Not available in rev0003.
