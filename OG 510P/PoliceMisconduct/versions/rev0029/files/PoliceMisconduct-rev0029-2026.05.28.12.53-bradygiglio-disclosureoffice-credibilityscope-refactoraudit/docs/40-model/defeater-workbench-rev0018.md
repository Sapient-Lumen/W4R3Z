# Defeater workbench — rev0018

Defeaters are not edge cases. They are part of the normal life of this cube.

A record can be corrected, superseded, sealed, misread, mismerged, overdisplayed, overworded, or ethically unsafe. A public-record carrier can be official and still incomplete. A settlement can be real and still not be an admission. An officer name can match and still be the wrong person. A source can be legal to access and still wrong to display.

Rev0018 defines 30 defeater classes across custody, extraction, adjudication scope, temporal drift, missingness, denominator freshness, agency identity, person identity, incident identity, privacy, due process, Brady/Giglio, display, access misuse, family narrative, and ecosystem duplication.

Future sessions should treat each defeater as a possible rollback edge, not as commentary.
