# Department source inventory model

A department source inventory is a map of public-record carriers involving an agency. It is not a department misconduct page.

## Core fields

- agency name;
- jurisdiction type;
- state/territory;
- source rows;
- linked document classes;
- source-page status labels;
- current-status verification state;
- missing carrier prompts;
- display warnings.

## Edge cases

- Multi-agency rows should be split or marked mixed.
- Subunits should not overwrite parent departments.
- Sheriff offices need elected-office and jail/custody distinctions.
- Prosecutor-office rows should not be folded into police department records.
- Territory rows need federal/territorial status modeling.
