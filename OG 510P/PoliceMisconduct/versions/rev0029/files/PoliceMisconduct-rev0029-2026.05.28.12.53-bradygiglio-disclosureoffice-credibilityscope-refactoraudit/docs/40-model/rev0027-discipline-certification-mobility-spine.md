# rev0027 — Discipline / POST / certification / mobility spine

Rev0027 opens the employment-certification-mobility office as definitions only. It is the first office aimed directly at the seed's wandering-officer dream, but it does **not** create live officer records, employment records, certification records, decertification records, discipline records, or alerts.

The office separates these layers:

1. artifact class — what kind of public record carrier exists;
2. source voice — who is speaking and with what authority;
3. process state — complaint, investigation, discipline, appeal, certification, decertification, reinstatement, or correction;
4. identity bridge — whether a future person/officer record can be linked;
5. mobility path — whether there is a candidate movement between agencies;
6. public display — which remains closed in this revision.

Governing rule: **a credential signal is not a final status; a separation reason is not misconduct; a mobility indicator is not a wandering-officer alert.**
