# Credibility issue taxonomy — rev0029

The credibility taxonomy is vocabulary only. It names categories future reviewers may need, but it does not label any officer, department, prosecutor, case, or source.

The taxonomy is source-voice bound. Future use must preserve whether a basis is a court finding, prosecutor policy, department finding, POST action, civil allegation, settlement/no-admission signal, news report, public defender database row, correction, appeal, or redacted/unknown basis.
