# Claim grammar and source voice — rev0018

The cube must never use grammar to smuggle a stronger claim than the evidence supports. Rev0018 therefore adds a source-voice grammar and modality matrix.

The source voice grammar has 28 frames. The point is not style. The point is epistemic custody.

Bad wording examples the grammar blocks:

- complaint alleges → officer did;
- settlement paid → city admitted;
- motion filed → order entered;
- source page says closed → no obligations remain;
- officer name appears → same officer / culpable officer;
- record unavailable → event did not happen.

Preferred pattern:

`<source class/name> <voice verb> <bounded statement> <date/as-of> <scope caveat> <review state>`

For example, future copy should be able to say “the complaint alleges,” “the court ordered,” “the settlement agreement provides,” “the POST body reports,” “the docket reflects,” or “the record is not yet located,” without collapsing those voices into one corpus assertion.

Rev0018 admits no public copy. It defines copy gates.
