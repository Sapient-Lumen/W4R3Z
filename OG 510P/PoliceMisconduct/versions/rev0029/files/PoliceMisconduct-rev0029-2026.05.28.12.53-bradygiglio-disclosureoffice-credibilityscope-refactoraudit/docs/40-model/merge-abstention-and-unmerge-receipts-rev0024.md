# Merge abstention and unmerge receipts — rev0024

False merges are among the highest-risk failures in this cube. A false officer merge can accuse the wrong person. A false civilian merge can expose a protected person. A false agency merge can attribute a pattern to the wrong legal actor. A false incident merge can collapse separate harms.

Rev0024 treats abstention as a productively recorded state, not as indecision. When proof is insufficient, the correct output is a receipt saying why the merge was not made, which evidence would be needed, and which sources must remain separate.

Unmerge receipts are equally important. Every future merge must be reversible. A future unmerge receipt must preserve source edges, record the false-positive cause, list public surfaces to roll back, explain whether a public correction note is owed, and retain enough lineage that the same false merge is not recreated.
