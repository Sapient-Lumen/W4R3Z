# Incident minimum source-bundle rules — rev0025

The incident office blocks common collapses:

- a news mention is not an incident record;
- a department press release is source voice, not neutral truth;
- a lawsuit complaint is not a finding;
- a settlement is not an admission;
- a motion is not an order;
- a public civilian name elsewhere is not automatic display;
- a public officer name elsewhere is not a canonical identity merge;
- a missing record is not absence.

These are not philosophical niceties. They are survival rules for a corpus that will eventually touch families, named officers, public defenders, journalists, researchers, and courts.
