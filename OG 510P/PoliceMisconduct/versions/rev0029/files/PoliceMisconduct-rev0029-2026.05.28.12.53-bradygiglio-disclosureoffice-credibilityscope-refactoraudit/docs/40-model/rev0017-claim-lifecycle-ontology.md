# Rev0017 claim/nonclaim lifecycle ontology

The cube now has a canonical lifecycle from dream to source observation, preservation, privacy, extraction, claim review, public display, correction, rollback, and retirement.

This is not a bureaucracy layer for its own sake. It is a way to prevent the project from accidentally laundering weaker states into stronger states. A document label is useful, but it is not a document. A URL is useful, but it is not a preserved source. A source-bound evidence atom is useful, but it is not necessarily a public claim. A reviewed private claim is useful, but it is not automatically fit for public display.

The central surfaces are:

- `CLAIM-LIFECYCLE-INDEX.json`
- `CLAIM-LIFECYCLE-STATE-MACHINE.json`
- `CLAIM-LIFECYCLE-CROSSWALK.json`
- `CLAIM-STATE-ANTI-COLLAPSE-LEDGER.json`
- `EARNED-PROMOTION-RECEIPT-TEMPLATE.json`
- `LIFECYCLE-VALIDATION-INDEX.json`

The lifecycle is meant to be portable. It should apply to DOJ SLS source work, PACER/RECAP lawsuit work, settlement ledgers, POST/decertification records, Brady/Giglio surfaces, union contracts, arbitration awards, family incident packets, and future non-US extensions.

Rev0017 admits no live data and no public claims. It earns a safer way to open them later.
