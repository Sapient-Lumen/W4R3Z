# Rev0024 — identity resolution office

Governing rule: **an identity candidate is not an identity claim; abstention is a valid decision; unmerge receipts are first-class.**

The cube is being prepared for the future surfaces the seed explicitly dreams about: officer mobility, wandering detection, lawsuits, settlements, Brady/Giglio, family packets, and department-level accountability. Those futures require identity resolution, but identity resolution is where a public-record cube can do real harm.

Rev0024 therefore opens the office without admitting live identity records. It defines entity classes, identifier types, identity signals, a merge state machine, abstention rules, unmerge templates, risk tiers, source-family identity routes, public identity-display gates, decision receipts, and synthetic fixtures.

The office treats identity as scoped:

- a source URL identifies a carrier, not a person;
- a case number identifies a case, not all roles in it;
- a badge number is local and temporal;
- a POST/certification id can be strong but must be issuer/date/status bounded;
- a name string is a search aid, not merge proof;
- a civilian name in a public document is not permission to create a public civilian identity;
- a family statement is not mineable identity evidence;
- a settlement participant is not an admission;
- an employment edge is not misconduct.

Rev0024 creates **zero live identities**. It makes the future safer by requiring the next identity work to happen through synthetic fixtures and decision receipts first.
