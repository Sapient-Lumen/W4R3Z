# Interoperability contracts — rev0019

The cube should become infrastructure for civic, academic, journalistic, legal, government, and community source ecosystems. That requires import contracts before import.

Rev0019 defines 12 contracts: dataset lineage, source voice, modality, identity merge, privacy minimization, correction propagation, licensing/attribution, missingness, denominator, payload custody, role access, and contribution-back.

These contracts are not legal advice and not import permission. They are gates future import work must satisfy.
