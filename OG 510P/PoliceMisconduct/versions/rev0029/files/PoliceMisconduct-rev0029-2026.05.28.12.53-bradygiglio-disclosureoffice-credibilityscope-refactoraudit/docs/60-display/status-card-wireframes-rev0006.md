# Status-card wireframes — rev0006

These are copy candidates for a future no-person department/source inventory. They are not approved public display.

## Design rule

When status is unresolved, show the conflict itself.

Bad: “New Orleans consent decree: active.”
Bad: “New Orleans consent decree: terminated.”
Better: “DOJ cases page says Enforcement; later official/local sources report termination; terminal order not yet frozen.”

## Required warnings

- status candidate only;
- order/docket proof pending;
- history retained;
- no person or incident extraction;
- source page may lag.

The goal is to make uncertainty legible without making users do PACER archaeology.
