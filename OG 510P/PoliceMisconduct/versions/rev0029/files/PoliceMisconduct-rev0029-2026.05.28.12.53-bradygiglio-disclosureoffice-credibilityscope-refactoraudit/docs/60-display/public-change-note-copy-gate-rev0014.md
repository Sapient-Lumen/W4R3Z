# Public change-note copy gate — rev0014

Public change notes must describe source movement without turning source movement into accusations or current-status assertions.

Allowed shape once gates are satisfied:

> The DOJ source page changed on a later observation. The cube records the prior and later source-page labels and preserves the earlier source memory. This note is about source-page movement, not a finding about misconduct or current legal status.

Forbidden shape:

> This department was proven to have misconduct because a document label was added.

> This matter is over because the page says Closed.

> This historical source no longer matters because a label disappeared.

Rev0014 drafts copy candidates only. It admits zero public change notes.
