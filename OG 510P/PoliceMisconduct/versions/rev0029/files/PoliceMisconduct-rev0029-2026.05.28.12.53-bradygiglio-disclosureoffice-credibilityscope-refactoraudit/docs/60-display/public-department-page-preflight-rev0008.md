# Public department page preflight

Rev0008 defines the safest first public department page shape.

Allowed before live records:

- source inventory;
- source-document timeline with noncurrent labels;
- missingness and freshness warnings;
- source-family conflict notes;
- correction/contact route.

Blocked before later gates:

- current legal-status banner;
- officer lookup;
- named civilian/person display;
- incident allegations;
- lawsuit-merits or settlement-amount claims;
- score, ranking, or risk label.

The page must say what the cube does not know as plainly as what it has observed.
