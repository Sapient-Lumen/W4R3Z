# Bulk export and API gates — rev0023

Bulk/API access is blocked in rev0023. Future release requires lineage, deidentification attack review, small-cell suppression, purpose statement, license terms blocking resale and targeting, correction propagation, raw-payload blocks, sensitive-media blocks, audit logging, and revocation paths.

The cube should be open civic infrastructure, but openness does not mean unrestricted person-level export.
