# Private versus public source custody — rev0013

A source can be public on the web and still be unsafe to republish in a cube release.

The cube therefore separates:

- public existence of a source;
- private capture for fixity;
- private privacy scan;
- bounded internal summary;
- public citation badge;
- public payload display.

Rev0013 opens only planning surfaces for the first three states. It does not open public payload display, document summaries, person display, incident display, or current-status banners.
