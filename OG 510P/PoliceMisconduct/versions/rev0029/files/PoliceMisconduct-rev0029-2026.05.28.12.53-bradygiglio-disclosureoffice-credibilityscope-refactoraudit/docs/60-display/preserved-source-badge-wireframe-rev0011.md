# Preserved-source badge wireframe — rev0011

A future public source-inventory page may display preservation state without displaying content.

Example module:

> Source preservation state: document labels observed, link targets partially resolved, payload hashes pending. Some linked public documents may contain personal information and are not mirrored here.

Allowed badges before claim review:

- `label observed on official source page`;
- `target URL resolved`;
- `payload hash pending`;
- `privacy scan pending`;
- `source changed / recheck pending`;
- `missingness warning required`.

Forbidden badges:

- `misconduct found`;
- `department cleared`;
- `consent decree active/ended`;
- `officer involved`;
- `settlement amount`;
- `repeat defendant`.
