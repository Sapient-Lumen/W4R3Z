# Missingness banner copy rule — rev0009

Every source-inventory page shell must show missingness before it shows document labels.

Minimum banner facts:

- how many document labels are inventoried;
- how many official URLs are frozen or accessioned;
- how many content summaries exist;
- how many privacy scans exist;
- whether any person or incident records have been created;
- whether any public current-status claim has been admitted.

The banner must use plain language and must not imply that missing records mean absence of misconduct, absence of reform, absence of discipline, or absence of litigation.
