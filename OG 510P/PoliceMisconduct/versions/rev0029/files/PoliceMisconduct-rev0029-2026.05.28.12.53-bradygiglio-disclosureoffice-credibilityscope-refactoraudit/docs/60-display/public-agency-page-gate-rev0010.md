# Public agency page gate — rev0010

A source-inventory stub can exist before a department page. A department page cannot.

Allowed for internal/preflight display:

- source inventory stub;
- identity-under-review badge;
- linked DOJ matter label with caveat;
- missingness/blocked-module banner.

Blocked:

- current status banner;
- officer roster;
- incident list;
- misconduct summary;
- settlement totals;
- per-capita rates;
- map boundary;
- employment timeline;
- wandering-officer indicator.

Reason: those modules require canonical agency identity, status proof, denominator proof, privacy review, and rollback/unmerge machinery.
