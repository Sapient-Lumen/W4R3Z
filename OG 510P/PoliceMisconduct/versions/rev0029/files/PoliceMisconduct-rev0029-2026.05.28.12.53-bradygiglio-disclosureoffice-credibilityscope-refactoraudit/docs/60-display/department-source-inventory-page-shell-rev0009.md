# Department/source inventory page shell — rev0009

A source-inventory page shell is the safest first public-facing shape for the PoliceMisconduct cube. It is designed to be useful without being accusatory.

Allowed modules in rev0009 preflight:

- source-inventory header;
- document-label table;
- document-role count table;
- missingness banner.

Allowed only with strong warning copy:

- DOJ source-page status observation;
- noncurrent source-document timeline candidate.

Blocked modules:

- current legal-status banner;
- document-content summaries;
- raw PDF/full-document display before privacy scan;
- officer lookup;
- civilian/witness display;
- incident list;
- lawsuit merits;
- settlement amount ledger.

The design principle is: useful public memory first; person-level power later, after stronger gates.
