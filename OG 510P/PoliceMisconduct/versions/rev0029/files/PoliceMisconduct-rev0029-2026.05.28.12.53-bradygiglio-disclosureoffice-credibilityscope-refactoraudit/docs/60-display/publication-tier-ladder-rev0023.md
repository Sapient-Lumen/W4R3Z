# Publication tier ladder — rev0023

The publication ladder separates private custody, source-carrier citation, source inventory, document metadata, bounded summaries, aggregate metrics, role-gated workbenches, family dignity packets, adjudicated public claim cards, future person pages, deidentified exports, correction notes, and denied/no-publication states.

A tier describes a possible display posture. It does not publish anything. A public claim still requires the claim lifecycle office, review packet office, correction/right-of-reply office, and access/publication office to agree.
