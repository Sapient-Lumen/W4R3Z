## Migration rule

Do not move legacy files merely because the factor map exists. First create a migration receipt, redirect index, and validator check. The factor map is a compass, not yet a filesystem migration.

## Design reading

The current cube is not one thing. It is a telos layer, source layer, preservation layer, status/legal-effect layer, identity layer, claim lifecycle layer, harm/privacy layer, public-view layer, operations office, schemas/tooling layer, DOJ pilot, seed/prior-art context, and synthetic fixture layer.
