# Sample promotion receipts — rev0017

These are examples, not used receipts.

A future agency canonicalization receipt would need external identifiers, alias review, subunit/parent split review, merge blockers, and an unmerge path before moving an agency candidate to a private canonical record.

A future officer identity receipt would need more than a name: employment dates, department, badge or POST identifier where available, court/source corroboration, identity uncertainty, and right-of-reply routing.

A future public display receipt would need public-interest rationale, display minimization, privacy classification, freshness check, correction route, rollback dependencies, and role/access decision.

Rev0017 adds the templates so future sessions do not improvise these gates under pressure.
