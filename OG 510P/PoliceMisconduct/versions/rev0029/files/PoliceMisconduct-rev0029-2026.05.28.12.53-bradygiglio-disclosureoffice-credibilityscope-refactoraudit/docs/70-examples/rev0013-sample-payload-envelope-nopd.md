# Sample payload envelope — New Orleans order target

This is a model of the kind of object rev0013 now supports.

- Target: DOJ-linked New Orleans order/sustainment document.
- Envelope: private custody only.
- Expected class: official legal PDF or attachment.
- Risk: legal document privacy preflight required.
- Required sidecars: HTTP transaction, redirect chain, SHA-256 digest, archive metadata, privacy preflight, rollback dependency.
- Allowed in rev0013: operator planning.
- Blocked in rev0013: raw payload bundle, full summary, person extraction, incident extraction, current-status claim.

The envelope says the source needs capture. It does not say what the source proves.
