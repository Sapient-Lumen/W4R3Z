# Rev0017 route selection note

Selected route: `ROUTE-REV0016-004` — claim/nonclaim lifecycle ontology.

Rev0016 asked future sessions to choose one route rather than blindly continue the DOJ pilot. Rev0017 chooses the lifecycle route because the cube had accumulated many correct but scattered gates: source rows are not claims, status signals are not status claims, URL targets are not preserved sources, payload envelopes are not payloads, public records are not public display, and no-person is phase-bound rather than permanent.

Rev0017 turns that repeated discipline into a state machine. It does not ingest new live records. It does not move legacy files. It does not promote any claim. It gives future revisions a shared vocabulary for promotion, rollback, and display review.

The rule is simple: **a later lifecycle state is never implied by an earlier state.** Every move requires a receipt.
