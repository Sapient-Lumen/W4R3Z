# Rev0016 office reentry canon

A future session should resume from an office, not from a pile.

## Read order

1. **Start with the telos, not the latest pilot.** — Ask what capability the next turn is trying to earn. Read: docs/00-meta/rev0015-mile-high-telos-charter.md, TELOS-CHARTER-LEDGER.json, DREAM-REGISTER.json
2. **Separate permanent constraints from phase-bound gates.** — Do not inherit no-people/no-DOJ/no-status as theology. Read: docs/20-constitution/phase-bound-vs-permanent-constraints.md, OVERCONSTRAINT-AUDIT-LEDGER.json
3. **Use the factor map before editing ledgers.** — Know the module you are touching. Read: CUBE-FACTOR-MAP-LEDGER.json, data/audit/rev0016_factor_assignments.json
4. **Read audit findings and debts.** — Do not add new surfaces where a consolidation surface is already due. Read: AUDIT-FINDINGS-LEDGER.json, FOUNDATION-DEBT-LEDGER.json
5. **Choose exactly one route for the next revision.** — Name the route and why it is safe. Read: OPEN-ROUTE-REGISTER.json, frontier-ticket.json
6. **Keep no-live-data counters explicit.** — If opening any live data lane, add an earned capability receipt first. Read: RELEASE-MANIFEST.json, SURFACE-STATUS.json, CLAIM-SURFACE.json
7. **When in doubt, add a receipt, not a claim.** — Receipts preserve options; premature claims narrow them. Read: NONCLAIMS.json, CLAIM-PROMOTION-GATE-LEDGER.json, EVIDENCE-LADDER.json
8. **Remember the seed’s breadth.** — Wandering, settlements, Brady/Giglio, union contracts, FOIA, families, and small agencies are core, not extras. Read: seed/02_police_misconduct.md, docs/30-program/what-we-are-trying-to-earn.md

## Office rule

Read the telos before the frontier. Read the factor map before editing ledgers. Read the overconstraint audit before treating old gates as destiny.
