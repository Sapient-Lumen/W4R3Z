# Archive policy

## Scaffold before data

Rev0001 intentionally admits no live person or incident records. The archive first needs source custody, privacy, adjudication, entity-resolution,
and correction machinery.

## Canon and derivative surfaces

Top-level ledgers are canon for their domains. Compact surfaces such as `context-pack.json` and `frontier-ticket.json` help reentry but do not override canon.

## No bulky evidence by default

The archive should not grow by dumping PDFs, videos, or large files into the bundle. Future revisions should pin source locations, digests, and extraction notes.
If a record must be preserved because it is disappearing, add a custody receipt explaining why.

## Rejected paths matter

Rejected pilots, sources, merges, and wording choices should be logged. A corpus of this kind will waste enormous time if it remembers only accepted entries.

## Public wording

Public-facing wording must be more precise than source jargon when source jargon obscures the event. If a source says “officer-involved shooting,” the corpus
should preserve the quote/source term but code the actor, weapon, civilian injury/death, and known uncertainties separately.
