# Policy reviewer playbook — rev0028

Before live policy work, run synthetic fixtures through review packets. For each policy or contract source candidate, record source voice, source owner, URL/citation, payload envelope state, version chain, effective dates, supersession, agency/bargaining-unit scope, privacy scan, and rollback path.

Never promote a clause to a policy-in-effect claim, a department score, or a person/incident inference without a decision receipt.
