# Agency unmerge receipt method — rev0010

Every agency merge must be reversible.

An unmerge receipt should record:

- merged record ID;
- all source labels affected;
- external identifiers used;
- evidence that caused unmerge;
- downstream surfaces to rollback;
- page modules to hide while re-resolving;
- person, incident, settlement, and denominator claims affected.

Rev0010 creates no merge receipts because it creates no canonical agency records. It creates the requirement so future revisions cannot forget it.
