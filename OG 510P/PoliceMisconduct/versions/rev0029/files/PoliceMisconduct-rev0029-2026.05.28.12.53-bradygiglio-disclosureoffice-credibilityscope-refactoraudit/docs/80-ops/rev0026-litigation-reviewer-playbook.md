# rev0026 litigation reviewer playbook

Before opening any future live litigation or settlement intake, route the candidate through:

1. source family route;
2. artifact type;
3. custody/fixity/privacy preflight;
4. party-role extraction gate;
5. source voice and modality;
6. claim-type and disposition scope;
7. settlement/no-admission guardrail if any payout or settlement signal appears;
8. incident bridge gate;
9. identity merge-abstention gate for named officers;
10. access/publication gate;
11. correction/right-of-reply route.

Synthetic fixtures must pass before live case records are admitted.
