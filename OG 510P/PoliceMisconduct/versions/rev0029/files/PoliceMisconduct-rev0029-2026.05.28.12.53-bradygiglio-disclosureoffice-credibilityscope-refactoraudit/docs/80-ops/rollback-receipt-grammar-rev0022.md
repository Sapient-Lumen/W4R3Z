# Rollback receipt grammar

Rollback receipts keep correction from becoming silent erasure. When a correction changes source locators, status wording, agency splits, person merges, incident boundaries, lawsuit dispositions, settlement terms, discipline outcomes, Brady/Giglio scope, civilian display, public correction notes, or validator/schema logic, the cube must record what changed, why, which source supports it, what dependencies were touched, and what remains unresolved.

Rev0022 defines templates only. It performs no live rollback.
