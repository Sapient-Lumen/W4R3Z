# Rollback dependency graph method

Every public-facing phrase must know what would force it to change. Rev0008 starts this graph at the status-signal layer.

Dependency pattern:

source-page resnapshot → status proof bundle → claim-promotion triage → public page preflight

and

official news event → acquisition ticket → status proof bundle → public page preflight

Rollback triggers include DOJ page updates, corrected PDF links, new docket orders, later appeals, source conflicts, and document privacy failures. Because no public claims are admitted in rev0008, all rollback edges are pre-publication dependencies.
