# Rev0023 access / publication office

Governing rule: **an access route is not access, and publication eligibility is not publication.**

This office defines roles, publication tiers, role-feature permission states, misuse threats, minimization gates, bulk-export rules, sensitive-media rules, and law-enforcement access boundaries. It does not create live accounts, credentials, exports, payload releases, public adverse claims, or role-gated data access.

The office exists because the corpus is meant to be democratic public-record infrastructure, not a surveillance product. The seed explicitly imagines journalists, litigators, public defenders, prosecutors for Brady/Giglio purposes, researchers, community members, accountability boards, oversight legislators, and federal monitors as audiences, while also warning that access models matter and that police use against individuals must be prevented.

## Safe chain

source / claim workbench → review packet → risk tier → access office → publication tier → minimization gates → misuse scan → decision receipt → correction/rollback path → only then display or access.

## Definition-only state

Rev0023 has no live data access. All role-gated or elevated states are future request routes, not permissions.
