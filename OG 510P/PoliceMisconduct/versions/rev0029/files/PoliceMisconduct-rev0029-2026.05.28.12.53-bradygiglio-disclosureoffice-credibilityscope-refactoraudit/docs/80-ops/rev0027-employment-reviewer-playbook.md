# Employment / certification reviewer playbook — rev0027

Reviewer sequence:

1. Classify artifact type.
2. Identify source owner and source voice.
3. Check publicness, fixity, and payload custody state.
4. Classify process state without promoting to a claim.
5. Check appeal/finality status.
6. Run identity bridge gates; abstain if only weak signals exist.
7. Record missingness and record-destruction clauses.
8. Route through correction/right-of-reply office.
9. Deny public person-level display by default.
10. Only then consider future private evidence atoms.

Do not create live officers, employment histories, certification histories, discipline records, or public alerts in this revision.
