# Rev0013 redaction operator checklist

Before any source moves toward public display, check:

- Are raw payload bytes excluded from the public release?
- Are officer, civilian, witness, family, survivor, minor, attorney, judge, and official names blocked from entity creation?
- Are addresses, contact data, birthdates, signatures, and case-party identifiers blocked?
- Is status language still signal-only unless the status-proof bundle has passed?
- Is every public-facing statement tied to a preserved source digest or explicitly marked as source-label-only?
- Is a rollback trigger recorded for every future public display candidate?

Passing this checklist does not itself authorize publication. It only means the next review gate can begin.
