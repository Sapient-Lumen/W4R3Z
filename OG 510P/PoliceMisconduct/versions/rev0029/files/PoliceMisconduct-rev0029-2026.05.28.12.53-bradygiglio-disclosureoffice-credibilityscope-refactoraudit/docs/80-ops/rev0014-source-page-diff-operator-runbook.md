# Source-page diff operator runbook — rev0014

1. Re-observe the source page and record the observation time.
2. Locate the law-enforcement-agencies section.
3. Compare each matter row against the latest baseline:
   - matter label;
   - page status label;
   - document labels;
   - document years;
   - link target count;
   - added/removed/moved labels.
4. If a difference appears, create a diff event; do not publish it.
5. Capture or mark preservation debt for the relevant source page/section.
6. Recheck official news and docket/order carriers when status could be affected.
7. Add rollback edges and public-copy gates before any public delta note.

Never infer current legal status from page-label movement alone.
