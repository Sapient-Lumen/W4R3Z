# Identity reviewer playbook — rev0024

Before any future live identity review, a session should:

1. Classify the entity class.
2. Inventory identifier types and source voices.
3. Run privacy and due-process screens.
4. Check abstention rules before looking for merge support.
5. Look for defeaters: conflicting DOB, conflicting POST id, impossible employment overlap, badge reuse, subunit/parent ambiguity, source correction, sealed/expunged source, or civilian-protected context.
6. Open a review packet and identity decision receipt before any canonical candidate.
7. Prepare unmerge and rollback receipts before public display is considered.

The safe default is: split, abstain, or hold private until a receipt closes the gate.
