# Rev0018 reviewer playbook

Before any future source extraction becomes a claim candidate, reviewers should fill the following minimum checklist:

1. Locate the source/custody pointer.
2. Assign an evidence atom type.
3. Assign a source-voice frame.
4. Assign a modality.
5. Write the narrowest bounded text.
6. Check forbidden wording tests.
7. Scan defeaters.
8. Assign adverse-claim severity.
9. Run privacy interlocks.
10. Run due-process checks for adverse person claims.
11. Attach rollback dependencies.
12. Confirm correction/right-of-reply route before display.

Rev0018 itself stops before step 1 on live records. It prepares the checklist.
