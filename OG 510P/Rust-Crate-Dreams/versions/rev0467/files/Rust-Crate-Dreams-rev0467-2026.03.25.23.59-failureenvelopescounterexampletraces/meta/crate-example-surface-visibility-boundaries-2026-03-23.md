# Crate Example Surface visibility boundaries — 2026-03-23

When the archive next touches **P-0524** or adjacent example/onboarding lanes, keep these truths separate:

1. **official-start authority** — what blessed the path;
2. **entrypoint viability** — what command/feature/env lane actually works;
3. **hosted visibility** — what rustdoc/docs.rs exposes;
4. **success witness** — what proof of life was actually observed;
5. **support level** — official quickstart vs reference example vs docs-only example.

Do not let any of the following stand in for an honest answer:

- “the snippet is in the README,”
- “cargo test built the examples,”
- “required features were documented somewhere,”
- “docs.rs shows it on the landing page,”
- “scraped examples are on,”
- or “a guide exists.”

A crate can have all of those truths and still leave officiality, viability lane, hosted visibility basis, or witnessed success unresolved.
