# Quiet release stream has lights-on coverage but review-capacity gap

This fixture protects two truths at once:

- a crate can publish infrequently yet still have honest coverage for issue triage, CI breakage, security response, and dependency upkeep;
- that same crate can still lack explicit review bandwidth, contributor mentoring, or refactor capacity.

The goal is to stop “quiet but supported” from silently becoming “broadly maintained in every way that matters.”
