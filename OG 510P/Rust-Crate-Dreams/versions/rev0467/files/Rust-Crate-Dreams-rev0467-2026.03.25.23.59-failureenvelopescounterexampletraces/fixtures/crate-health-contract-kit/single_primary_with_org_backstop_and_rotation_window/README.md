# Scenario: single primary maintainer with org backstop and rotation window

This fixture protects the boundary that a crate can rely on one obvious primary maintainer
without being a pure no-backstop bus-factor story.

The point is to make visible:

- who is primary,
- what the organization backstop is,
- how long degraded response is admitted,
- and why that is still different from broad multi-maintainer redundancy.
