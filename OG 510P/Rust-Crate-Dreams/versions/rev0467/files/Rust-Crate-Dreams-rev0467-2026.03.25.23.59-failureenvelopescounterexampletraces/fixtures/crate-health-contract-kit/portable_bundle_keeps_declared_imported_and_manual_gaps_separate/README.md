# Portable bundle keeps declared, imported, and manual gaps separate

This scenario shows the receiver-facing deliverable for the lane.

A downstream reviewer should be able to inspect one portable bundle and answer:
- which stewardship facts were maintainer-declared,
- which were imported from crates.io or GitHub,
- and which work classes still require manual review.

The point is not to claim everything is known.
The point is to avoid making the receiver reconstruct stewardship posture from scattered host surfaces.
