# Scenario — same-author self-review blocks freeze without explicit deviation

A pack may be richly evidenced and already useful as a **candidate**, but a same-author self-review should not silently read as the review posture for a frozen public contract.

This scenario keeps the problem visible:

- the pack still has only maker-authored review provenance,
- the readiness surface is still `hold`,
- and the consistency surface fails if anyone tries to market that pack as independently frozen anyway.
