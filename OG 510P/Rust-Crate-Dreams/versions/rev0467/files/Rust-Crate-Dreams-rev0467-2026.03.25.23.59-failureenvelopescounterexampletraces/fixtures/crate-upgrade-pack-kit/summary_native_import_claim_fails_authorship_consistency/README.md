# Scenario — summary marked native import fails when evidence is maintainer-authored guidance

A summary sentence should not claim `authoring_mode: native_import` if the evidence it points at is actually maintainer-authored guidance.

This scenario keeps the mismatch visible:

- the authorship report says the referenced guide is maintainer-authored,
- the summary claim still markets itself as a native import,
- and the consistency surface fails until the claim is downgraded to maintainer-authored or mixed synthesis.
