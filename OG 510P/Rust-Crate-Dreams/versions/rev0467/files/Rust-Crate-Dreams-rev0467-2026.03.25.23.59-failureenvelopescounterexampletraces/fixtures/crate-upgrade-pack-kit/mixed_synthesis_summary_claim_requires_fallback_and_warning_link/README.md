# Scenario — mixed-synthesis summary claim requires fallback and warning link

A candidate public pack can already be useful while still carrying a mixed synthesis: a maintainer-written sentence may summarize hazard authority, scope limits, freshness warnings, and a manual-review boundary at once.

This scenario demonstrates that such mixed claims should not travel as free-floating prose. They should carry an explicit authoring mode, exact evidence refs, active warning links, and one fallback ref that tells the reader where to go when the sentence is too compressed to act on safely.
