# Scenario: blocking public warning requires a durable summary cue

This scenario captures a pack that already exports a warning register and exact public receipts.
What is still missing is one compact proof that the decisive public warning is not trapped only in machine-readable registers or compact labels.

The example shows the good posture:

- the blocking warning still exists in the warning register,
- the publication surface still carries compact labels,
- and the same controlling meaning also appears on a durable exported summary/banner surface a reader can keep in view.

The point is not louder prose.
The point is to keep public-blocking meaning durably visible instead of hoping readers infer it from bundle internals.
