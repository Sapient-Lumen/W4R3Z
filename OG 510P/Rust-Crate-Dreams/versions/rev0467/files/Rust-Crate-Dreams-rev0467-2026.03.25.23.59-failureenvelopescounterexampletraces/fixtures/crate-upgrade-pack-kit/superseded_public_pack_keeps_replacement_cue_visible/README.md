# Scenario: superseded public pack keeps replacement cue visible

This scenario captures a pack that remains publicly reachable after a newer reviewed pack supersedes it.
Freshness and supersession reports can already say this machine-readably, but a reader still needs one durable visible cue on the exported surface so the old pack does not keep sounding current.

The example shows the good posture:

- the governing freshness/supersession state stays machine-readable,
- the public summary/export still points at the replacement pack,
- and the superseded status remains visible as a durable replacement notice instead of only a register entry.

The point is to stop an older exported pack from competing silently with the newer reviewed contract.
