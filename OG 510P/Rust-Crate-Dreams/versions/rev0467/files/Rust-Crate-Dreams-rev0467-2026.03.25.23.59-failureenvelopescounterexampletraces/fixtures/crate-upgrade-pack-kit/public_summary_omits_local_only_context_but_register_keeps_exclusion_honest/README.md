# Scenario — public summary omits local-only context but omission register keeps the exclusion honest

This scenario captures a pack that is honestly exportable and traceable, but still leaves some known local-only workspace context off the public entry surface.

It proves that:
- omission for non-redaction reasons should be reviewable rather than silent,
- the public summary can stay compact without pretending to be exhaustive,
- and a reader should still be told what kind of thing was left out, why, and where the nearest safe fallback lives.
