
# Scenario — teaching default and production default diverge but both are legitimate

This scenario exists to show that **P-0509** should not force one universal winner.
A pathfinder pack should be allowed to say:

- one stack is the better **teaching** default because it minimizes hidden concepts,
- another is the better **production** default because it minimizes long-term lock-in or offers a stronger interop story,
- and the honest output is a **scope split**, not a fake tie-break.
