# Scenario: portable bundle keeps freeze timebox, replay, and current choice separate

This scenario proves the bundle can travel with:

- the original task profile,
- the original decision pack,
- the frozen starter-set lock,
- the timebox that bounded what was knowable,
- and the later replay report that explains why review reopened.

The goal is to keep the historical decision basis reviewable without collapsing it into today's crate ranking or current public docs surfaces.
