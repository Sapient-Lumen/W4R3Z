# menu_focus_traversal_cross_platform

This scenario captures the same menu-open / arrow-traverse / activate / dismiss flow on two platform lanes.

What it is trying to prove:

- top-level menu items expose specific roles and names,
- focus moves in a predictable order after menu open,
- submenu items remain reachable by keyboard traversal,
- and platform-specific differences are called out as extension-lane drift rather than hidden.
