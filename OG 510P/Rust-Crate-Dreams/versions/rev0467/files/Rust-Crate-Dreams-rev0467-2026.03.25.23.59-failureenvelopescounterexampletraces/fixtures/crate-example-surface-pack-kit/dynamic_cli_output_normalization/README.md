# Dynamic CLI output normalization

Use this fixture family to express:
- timestamps, UUIDs, temp paths, and dynamic ports in stdout/stderr,
- which placeholders are acceptable for an official quickstart,
- where normalization preserves reviewability versus hiding semantic drift,
- and when a path should be downgraded instead of over-normalized.


Concrete example artifact in this archive:
- `example-normalization.profile.example.json`
