# IPP Everywhere interop bundle sketch

Suggested contents for a `*.ippbundle.zip`:

- `printer.json` — canonical capability report
- `profile.toml` — IPP Everywhere / fleet policy profile
- `job.ir.json` — normalized job description
- `document.hashes.json` — document fingerprints or subsets
- `events.jsonl` — request/response lifecycle
- `verdicts.json`
- `notes.md`
