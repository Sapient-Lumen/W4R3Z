# R Package Native ShipKit fixtures

These fixtures exist to keep the archive honest about what the R-package shipkit is actually checking.

The core review objects are:
- **registration posture**
- **DLL load contract**
- **install posture**

They exist so the archive does not flatten:
- “the wrappers exist”,
- “the package compiled once”,
- and “a user installed it on one machine”

into one fake “R support” result.
