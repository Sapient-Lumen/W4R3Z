# Scenario — shallow snapshot keeps state but weakens history claims

This scenario exists because modern local-first engines can keep current state while narrowing older-history reach.

The important review question is not merely “did the current document load?”
It is also:

- whether older history is still available,
- whether branch/time-travel claims still hold,
- whether historical comparison is still directly possible,
- and what a support bundle may honestly export.

The example receipt uses a shallow-snapshot posture where current state survives but older-history comparability is intentionally narrower.
