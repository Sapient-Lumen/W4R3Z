# Entry 93 — cost normalization, linked-context semantics, RF capture receipts, identifier transforms, and profile evidence

Added five proposals after a pass aimed at ecosystems where the missing Rust value is **not another dashboard, broker, runtime, translator, or profiler**, but a boring default for **version locks, semantic diffs, transport/context receipts, loss reports, and replayable evidence** above already-real external contracts.

New proposals:

- P-0417 OpenCost + FOCUS FinOps Portability & Evidence Kit
- P-0418 NGSI-LD + Smart Data Models Context Interop Workbench Kit
- P-0419 SigMF + VITA-49 + SoapySDR Replay & Evidence Kit
- P-0420 GS1 Digital Link + EPC URI Translation Workbench Kit
- P-0421 pprof + OpenTelemetry Profiling + Parca Interop Workbench Kit

Pass notes:

- **OpenCost + FOCUS** rose because cloud-cost work is now mature enough that the sharper gap is a **portable normalization/allocation receipt**, not another billing dashboard.
- **NGSI-LD + Smart Data Models** made the cut because the real failures are usually **semantic-context and broker-behavior drift**, not mere JSON parsing.
- **SigMF + VITA-49 + SoapySDR** rose because RF debugging still suffers from **capture-interpretation and transport/file boundary loss**, not lack of another DSP runtime.
- **GS1 Digital Link + EPC URI** made the cut because barcode/web interoperability pain is still mostly **identifier-family translation and resolver evidence**, not image generation.
- **pprof + OTel Profiling + Parca** rose because profiling is becoming a shared interop surface, but Rust still lacks a **symbolization- and cross-signal evidence core**.

Archive hygiene added in this pass:

- Added a reminder that some of the best crate opportunities sit at the boundary between a **mature external contract and intentionally thin Rust substrate**, where the right move is a lock/diff/receipt core rather than a full native stack.
- Strengthened the archive’s memory that many “single standards” are really **contract stacks** mixing payloads, remote contexts, transport layers, resolvers, allocation overlays, or symbolization state.
