# 2026-03-06 (71) — AS4/Peppol / EPCIS / ONVIF / DLMS / SIP frontier pass

This pass intentionally widened the search radius across **e-invoicing networks, supply-chain traceability, physical-security video, smart metering, and real-time communications**.

## Added

- **P-0307** AS4 + Peppol eDelivery Interop & Evidence Kit (`as4bundle.zip`)
  - Medium-High salience: the big gap is not raw XML or signing primitives, but discovery-aware onboarding, receipt diagnostics, and partner-safe evidence bundles.
- **P-0308** GS1 EPCIS 2.0 + CBV Conformance & Evidence Kit (`epcisbundle.zip`)
  - High salience: traceability mandates and recall pressure make canonical event validation, vocabulary lockfiles, and lineage diffs unusually leverageable.
- **P-0309** ONVIF + RTSP Interop & Evidence Kit (`cambundle.zip`)
  - Medium-High salience: Rust camera substrate exists, but profile-aware discovery/control/streaming diagnostics are still fragmented.
- **P-0310** DLMS/COSEM Smart Meter Interop & Evidence Kit (`dlmsbundle.zip`)
  - Medium-High salience: smart-meter interoperability is profile-heavy and operationally costly, while Rust still lacks a field-safe replay/evidence workbench.
- **P-0311** SIP + SDP + RTP Interop & Evidence Kit (`sipbundle.zip`)
  - High salience: fresh Rust SIP activity is real, but the missing value remains canonical call evidence, profile pinning, and replayable negotiation diagnostics.

## Synthesis / pruning notes

- **Promoted** AS4/Peppol because the leverage point is discovery + trust + partner-profile reproducibility, not “yet another SOAP/XML crate”.
- **Promoted** EPCIS as a semantics-first traceability problem rather than a serialization/parser race.
- **Framed** ONVIF as a profile-aware **camera compatibility and supportability** opportunity rather than a new media stack.
- **Framed** DLMS/COSEM as a **utility-profile + object-model evidence** gap, not a head-end product rewrite.
- **Promoted** SIP because new Rust substrate exists, but the missing ecosystem default is still a **call-flow + media-negotiation evidence bundle**.

## Meta-engineering added

- Added fixture sketch directories for the new bundle families so later passes retain artifact-shape assumptions.
- Extended the research ledger with a new false-gap reminder: **“existing parser/stack activity” is often a reason to build evidence-grade interoperability tooling, not a reason to drop the domain.**
