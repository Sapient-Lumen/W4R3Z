# Entry 146 — native dependency mode truth matters as much as probing

This pass again did **not** add another top-level proposal.

Instead, it sharpened **P-0058 native-deps-kit** where the archive still had the most leverage left: the crate now has a clearer plan for **mode locks and policy reports** around system vs vendored vs override resolution.

## Main judgment

The important missing crate is not a better probe wrapper.
It is a **receiver-facing mode and policy bundle** that can tell another person:

- which native contract was declared,
- whether system libraries, internal builds, or overrides were allowed,
- which inputs requested that mode (features, env, config, policy),
- what probing or handoff actually happened,
- and where the answer is exact versus manual-review-required.
