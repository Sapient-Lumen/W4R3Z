# 2026-03-05 (09): Policy workbench + profiling evidence bundles + telemetry schema lint

This update pushes further into **artifact-first dev tooling**: crates that don’t just “do a thing”, but standardize a *portable bundle* that maintainers can ask for, reproduce, and diff in CI.

## Added proposals

- **P-0116** Policy-as-Code Workbench Kit (Rego in-process)  
  Rust-native Rego evaluation exists (e.g., Regorus), but teams still lack a coherent workbench for **testing, coverage, explain traces, and safe policy bundles**.

- **P-0117** Profiling Evidence Bundle Kit (CPU + heap + async)  
  A standard `*.profbundle.zip` makes profiling results reproducible, shareable, and CI-diffable (bridging `pprof`, flamegraph workflows, allocator profiles, and tracing-derived stacks).

- **P-0118** Telemetry Schema Lint & Semantic Conventions Kit (OTel + tracing)  
  Make telemetry governance portable: a schema file + capture harness + linter that enforces semantic conventions and correlation across logs/traces/metrics.

- Added new fixture schemas for `policy-report.json`, `profbundle` manifests, and `telemetry-report.json`.
