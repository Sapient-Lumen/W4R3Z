# Entry 184 — resolver explanation promoted into a fixture-first proof-carrying lane

This pass did not add a new proposal.
It upgraded **P-0468 Cargo Resolver Explanation Kit** into a more implementation-shaped lane with schema files, scenario packs, and a sharper explanation of what the crate should actually hand other people.

## Why this moved now

Several official signals now line up unusually well.

### 1. The Rust/Cargo project is explicitly aiming at complete resolver output

The PubGrub-in-Cargo goal does not just talk about swapping algorithms.
It names **complete output** as a design axiom and says the output should contain enough associated information to determine that the resolver made the right decision.

That is a direct clue that the ecosystem is missing a receiver-facing artifact layer above Cargo’s resolver substrate.

### 2. Current resolver docs still describe a two-stage world that ordinary humans and tools blur together

Cargo still resolves the lockfile graph as if all workspace features are enabled, and then resolves compile-time features again for the selected build.
A worthy crate needs to freeze which pass a report is talking about instead of silently mixing them.

### 3. Current feature-unification policy is concrete enough to encode, not just discuss

Cargo’s unstable docs now define `selected`, `workspace`, and `package` unification modes with meaningful behavioral differences.
That makes participant-scope and duplicate-build preference first-class report inputs.

### 4. The human investigative surface still explicitly stops short of exact truth

`cargo tree` still says it is only *pretty close* to the actual build plan.
That is a strong reason for a crate to ship **exactness / conservative / manual-review-required** receipts instead of pretending the tree is the truth.

## Current judgment

The worthy crate here is not:

- another dependency graph parser,
- another resolver rewrite,
- or another tree formatter.

The worthy crate is the boring shared layer that can hand other people:

1. a **capture lock**,
2. a **small vocabulary of reason/report schemas**,
3. an **exactness and evidence-source receipt**,
4. and a **scenario corpus** that keeps Cargo policy, participant scope, and investigative-surface blur reviewable.
