# Entry 182 — rustc_public analysis workbench promoted into a fixture-first lane

This pass did not add a new proposal.
It upgraded **P-0429 rustc_public Analysis Workbench Kit** into a much more concrete lane with fixtures, boundary notes, and a sharper implementation plan.

## Why this moved now

Several official signals now line up unusually well.

### 1. The compiler project is no longer at the “maybe someday” stage

The accepted StableMIR / `rustc_public` goal was explicitly about publishing a SemVer-shaped compiler interface for tool developers.
That already made the area important.

### 2. The hard refactoring and maintenance substrate now exists

The 2025 GSoC report says the `rustc_public` / `rustc_public_bridge` refactor, dual-maintenance setup, and compatibility tooling work were completed.
That means the ecosystem no longer lacks the compiler-team groundwork.
It lacks the shared adoption artifacts above it.

### 3. The publication model is now explicit enough to reason about

The compiler-team MCP now describes:

- a SemVer-compliant `rustc_public` crate,
- a split with `rustc_public_bridge`,
- and a multi-compiler-version support story.

That makes “tool compatibility lock + fixture + evidence bundle” a much sharper crate concept than before.

### 4. The current docs reveal an important boundary that ordinary tools will need help with

The nightly `rustc_public` docs already expose modules such as `rustc_internal` and `unstable` that are not counted toward SemVer.
That is a big clue about what the missing crate should provide:
not just snapshots, but a **reviewable report about semver-exempt surface usage**.

## Current judgment

The worthy crate here is not:

- another public-compiler-interface implementation,
- another `rustc_private` shim,
- or a giant “all compiler tooling” abstraction.

The worthy crate is the boring layer above the new compiler substrate:

1. **a compatibility lock**,
2. **a minimized analyzer-fixture format**,
3. **a capability matrix and analysis receipt**,
4. and **an unstable-surface quarantine report** that tells people whether a result really stayed inside the intended SemVer-shaped lane.
