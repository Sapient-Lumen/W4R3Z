# Entry 123 — RubyGems native ship contracts and concrete crate-provision planning

This pass promoted one more foreign-package ecosystem seam and tightened the archive’s planning language around **what a crate should provide other people**.

New proposal:

- P-0501 RubyGems Native Extension ShipKit

Why it rose:

- The archive already had a convincing pattern for Python wheels, Apple XCFrameworks, Node/npm prebuilds, NuGet native assets, and JAR/JNI shipping.
- Ruby now fits that same pattern more clearly than before.
- RubyGems already has real substrate for extension builds, gem platforms, and even rebuild workflows; `rb-sys`, `magnus`, `rake-compiler`, `rake-compiler-dock`, and Rust-specific cross-gem helpers mean the raw authoring/build surface is no longer the sharp question.
- The sharper question is: **which gems did we ship, for which Ruby implementations and platforms, with what source-build versus binary-gem posture, and can we prove the package/load contract honestly?**

What changed in archive judgment:

- The archive now treats **Rust-backed Ruby gem shipping** as a package-contract problem, not just as another language-binding problem.
- A worthy crate here is a **platform-gem matrix + Ruby-implementation support report + build/load receipt + rebuild/support bundle**, not a new wrapper DSL.
- This pass also made the planning standard a bit stricter: strong proposals should say not only what the crate *is*, but what concrete review artifact, promise, or workflow it gives to **other people**.

Archive hygiene added in this pass:

- Added a `known-existing` note warning future revisions not to confuse `rb-sys`, `magnus`, or cross-build helpers with a boring RubyGems release contract.
- Added an `llm-hygiene` reminder that Ruby-implementation support, gem platform, install-time build posture, and RubyGems rebuild facts are all part of the real shipping contract.
- Added a fresh salience scan (`meta/frontier-salience-2026-03-08-2.md`) that ranks Ruby lower than the biggest Cargo pain points, but high enough to stay in the serious frontier rather than the speculative queue.
