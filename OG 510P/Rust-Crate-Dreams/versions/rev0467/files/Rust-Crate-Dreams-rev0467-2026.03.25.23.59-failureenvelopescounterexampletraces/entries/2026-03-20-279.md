# Entry 279 — crate upgrade support sharpened around durable public cues and visible blocker/supersession meaning

This pass came from noticing that the upgrade pack had become honest about export posture, publication surface, summary-claim traceability, public trace paths, warning provenance, freshness, and supersession while still carrying one quiet bluff:

> decisive public meaning could still survive only as a label, register entry, or supporting receipt instead of staying durably visible on the exported entry surface that real readers actually scan.

## What moved this time

Two donor patterns kept surviving scrutiny:

- **The Election Stack** kept insisting that controlling meaning should not live only in transient or compact cues; if the state matters, the reader needs a durable visible equivalent.
- **EvidenceVault** kept insisting that a frozen public surface is not honest unless the exported entry surface itself carries the governing state clearly enough to stand on its own.

## Main planning move

The previous passes already established:

- exact public export posture and publication-surface manifests,
- exact warning/deviation/freshness provenance,
- exact summary-claim traceability and public trace routes.

This pass adds one sharper review object above them:

1. **durable public-cue truth** — each public-blocking warning, manual-review boundary, supersession notice, or similar governing meaning can now say where it remains durably visible on the exported entry surface rather than merely discoverable elsewhere in the bundle.

## Why this matters

Without **durable public-cue truth**, the lane still permits an ordinary lie:

- a pack can be technically exportable, traceable, and warning-complete while a real downstream reader still misses the controlling blocker or replacement notice because it only survives in a machine-readable file or compact label.

That is not cosmetic.
It is the difference between “the public bundle contains the right state somewhere” and “the public bundle keeps the governing state visibly present where readers naturally begin.”

## Main judgment after the pass

A worthy upgrade-support crate should now provide more than exact public routes and exact supporting receipts.
It should also provide:

- one compact **durable-cue report** for what public readers must keep in view,
- one bounded distinction between **traceable** and **durably visible** meaning,
- and one explicit failure state for blockers/replacement notices that still survive only as labels or machine-readable registers.

That keeps the lane from quietly turning exact public provenance into visibility theater.
