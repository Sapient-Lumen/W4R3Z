# 2026-03-05 (63) — SSH / ActivityPub federation / NATS+JetStream evidence kits

Added three new “missing-middle” proposals that follow the archive’s **bundle-first** pattern, targeting *high-friction interop domains* where bug reports are currently non-portable and hard to diff:

- **P-0277** SSH Interop & Evidence Kit (`*.sshbundle.zip`) — canonical transport/auth/channel transcripts + semantic diff to pinpoint the first divergence.
  - https://datatracker.ietf.org/doc/html/rfc4253
  - https://datatracker.ietf.org/doc/html/rfc4254
  - https://crates.io/crates/russh
- **P-0278** ActivityPub Federation Interop & Evidence Kit (`*.apubbundle.zip`) — canonical federation traces + privacy-safe bundles for cross-implementation debugging.
  - https://www.w3.org/TR/activitypub/
  - https://github.com/w3c/activitypub
  - https://crates.io/crates/activitypub-federation
- **P-0279** NATS + JetStream Interop & Evidence Kit (`*.natsbundle.zip`) — capture/replay/diff for JetStream management and streaming behaviors across clients and server configs.
  - https://docs.nats.io/nats-concepts/jetstream
  - https://beta-docs.nats.io/ref/protocols/jetstream
  - https://crates.io/crates/async-nats
