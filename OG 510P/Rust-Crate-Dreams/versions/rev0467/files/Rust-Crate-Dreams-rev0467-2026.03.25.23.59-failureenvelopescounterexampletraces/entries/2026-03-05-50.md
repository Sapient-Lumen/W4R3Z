# 2026-03-05 (50): Determinism trace spec + hermetic sandbox testkit + formal witness connector

This update extends the archive’s pattern of **bundle-first, evidence-driven** crate proposals.

## New proposals

### P-0239 Determinism Trace & Cassette Spec Kit

**Gap:** deterministic testing is becoming real in Rust, but artifacts are tool-siloed.

**Evidence:**
- FrankenLab positions itself as a deterministic record/replay/minimization harness for async Rust. https://docs.rs/crate/frankenlab/
- Sturgeon records async streams with timing and replays deterministically, illustrating adjacent-but-different recording slices. https://github.com/synoet/sturgeon

**Proposed contribution:** a shared, versioned `*.dettracebundle.zip` format + canonicalization/diff + adapters.

### P-0240 Hermetic Sandbox TestKit

**Gap:** Rust has sandboxing pieces, but lacks a cohesive, developer-friendly **policy → sandbox → explain → evidence bundle** kit that slots into tests/CI.

**Evidence:**
- `sandbox-rs` positions itself as a library + CLI for lightweight Linux sandboxes. https://crates.io/crates/sandbox-rs
- `seccompiler` and `seccomp` are building blocks for syscall filtering. https://crates.io/crates/seccompiler , https://crates.io/crates/seccomp
- `syd` positions itself as a Linux sandbox kernel, in the space of Bubblewrap/Firejail/minijail. https://crates.io/crates/syd

**Proposed contribution:** a high-level policy language with compilation to backends, an “explain” mode, and `*.sandboxbundle.zip` repro artifacts.

### P-0241 Formal Trace Connector

**Gap:** formal tools exist, but Rust projects still struggle to turn specs and counterexamples into **repeatable, CI-friendly witnesses**.

**Evidence:**
- `tla-checker` (Rust TLA+ model checker) and its community announcement. https://crates.io/crates/tla-checker and https://users.rust-lang.org/t/tla-checker-tla-model-checker-in-rust/138086
- `tla-connect` aims to integrate TLA+/Apalache into Rust tests. https://lib.rs/crates/tla-connect
- tree-sitter grammar for TLA+ published as a Rust crate. https://github.com/tlaplus-community/tree-sitter-tlaplus
- Stateright comparison material shows how model-checking approaches can map to runnable systems. https://www.stateright.rs/comparison-with-tlaplus.html

**Proposed contribution:** a witness bundle format (`*.formalwitness.zip`) + adapters (start with `tla-checker`) + replay/validation harness.
