# 2026-03-05 (00): confidential attestation kit + UI accessibility kit + columnar data interop kit

This update focuses on three “foundational glue” areas where Rust has strong components but lacks **shared, reusable, conformance-tested kits**.

## 1) P-0086 — Confidential Attestation Kit

**Goal:** make enclave/TEE attestation *boring* for Rust teams by providing a stable abstraction, policy UX, and conformance vectors.

- Proposal: `proposals/confidential-attestation-kit.md`
- Why now: Nitro-style attestation is mainstream and crate-level building blocks exist, but the ecosystem still lacks a unified, audit-friendly foundation for verification + key binding.

## 2) P-0087 — UI Accessibility Kit (AccessKit conformance + doctor)

**Goal:** make “a11y doesn’t regress” achievable for Rust GUI stacks.

- Proposal: `proposals/ui-accessibility-kit.md`
- Why now: AccessKit provides the right low-level abstraction, but the missing piece is shared testing, diagnostics, and CI gating.

## 3) P-0088 — Columnar Data Interop Kit (Arrow/Parquet subset + adapters)

**Goal:** make columnar interop stable and dependency-light for libraries and apps.

- Proposal: `proposals/columnar-data-interop-kit.md`
- Why now: Arrow/Parquet tooling is strong, but version + ecosystem friction remains; many users want a small stable interop shim with conformance vectors.

## Repo hygiene/meta improvements (small)

- Added these proposals with explicit “What it provides”, MVP, v1 path, and risks.
- Kept evidence links in frontmatter (no large downloads).
