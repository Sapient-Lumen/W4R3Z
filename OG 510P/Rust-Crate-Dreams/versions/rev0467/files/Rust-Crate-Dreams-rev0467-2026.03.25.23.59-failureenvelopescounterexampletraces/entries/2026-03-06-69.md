# 2026-03-06 (69) — FIX / XBRL / IPP / SECS-GEM / EBICS frontier pass

This pass intentionally widened the search radius across **capital-markets connectivity, regulatory reporting, driverless printing, semiconductor equipment automation, and European corporate banking**.

## Added

- **P-0297** FIX + FIXT + Orchestra Interop Workbench Kit (`fixbundle.zip`)
  - High salience: Rust FIX crates now exist across bindings and native engines, but onboarding and incident-debugging still lack a shared Orchestra-aware evidence layer.
- **P-0298** XBRL + Inline XBRL Conformance & Evidence Kit (`xbrlbundle.zip`)
  - Medium-High salience: Rust parsing momentum is real, but conformance-first validation, canonical fact diffs, and Arelle-comparable evidence workflows are still missing.
- **P-0299** IPP Everywhere Interop & Conformance Kit (`ippbundle.zip`)
  - Medium salience: Rust can speak IPP already, but there is no driverless-printing certification and replay workbench for real device fleets.
- **P-0300** SECS-II + HSMS + GEM Interop & Evidence Kit (`secsbundle.zip`)
  - Medium-High salience: native Rust protocol substrate exists, yet the hard operational gap is still state-machine replay, scenario coverage, and fab-safe incident bundles.
- **P-0301** EBICS Banking Interop & Evidence Kit (`ebicsbundle.zip`)
  - Medium salience: operationally important and under-served in Rust; the missing crate value is profile pinning, signature-aware diagnostics, and replayable exchange bundles.

## Synthesis / pruning notes

- **Promoted** FIX because the important missing layer is no longer a parser/engine alone, but a venue/counterparty **Rules-of-Engagement + replay + diff** workbench.
- **Promoted** XBRL as a conformance/evidence problem rather than a raw-parser race.
- **Framed** IPP as a **driverless-printing profile/certification** opportunity, not merely an HTTP+attribute client.
- **Framed** SECS/GEM as a **state-machine and scenario replay** gap around emerging Rust protocol crates.
- **Kept** EBICS scoped to bank-profile reproducibility and evidence shipping rather than trying to solve all payment processing.

## Meta-engineering added

- Added fixture sketch directories for the new bundle families so future passes preserve artifact-shape assumptions instead of rediscovering them.
- Extended the research ledger with false-gap notes for domains where parsers or codecs exist but **evidence-grade interop layers** do not.
