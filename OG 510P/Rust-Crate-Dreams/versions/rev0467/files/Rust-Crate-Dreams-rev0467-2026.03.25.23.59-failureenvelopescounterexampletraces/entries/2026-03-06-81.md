# Entry 81 — frontier pass: linked-data validation, enterprise data APIs, open lakehouse catalogs, variant-exchange semantics, and semi-structured query/data interchange

Added five proposals after a fresh pass focused on ecosystems where the standards surface is active or current, Rust already has meaningful substrate, and the real missing value still looks like the **boring middle layer**: lockfiles, semantic diffs, replay, validator normalization, and portable evidence bundles.

New proposals:

- P-0357 RDF 1.2 + SPARQL 1.2 + SHACL 1.2 Conformance & Evidence Kit
- P-0358 OData 4.01/4.02 + CSDL Conformance & Replay Kit
- P-0359 Apache Iceberg REST Catalog + Delta Kernel / UniForm Interop & Evidence Kit
- P-0360 VCF 4.5 + BCF 2.2 + CSI/Tabix Interop & Evidence Kit
- P-0361 Amazon Ion + PartiQL Canonicalization & Evidence Kit

Pass notes:

- **RDF / SPARQL / SHACL** rose because Rust now has enough real graph/query substrate that the sharper missing crate is a **canonicalization + evidence workbench**, not another triplestore.
- **OData** rose because metadata drift and query-surface mismatches are still the real failure mode, and Rust lacks a boring default artifact for that seam.
- **Iceberg / Delta / UniForm** was promoted because the operational pain is now clearly at the **catalog API ↔ metadata ↔ feature-compatibility** boundary, not in raw format access alone.
- **VCF / BCF / CSI** rose because Rust already handles the formats well enough that header/index/query semantics are now the sharper interoperability gap.
- **Ion / PartiQL** made the cut because Rust has fresh substrate, but there is still no neutral artifact for **encoding-aware semantic replay** across host subsets.
