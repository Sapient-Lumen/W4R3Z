# Entry 112 — Cargo global-cache policy receipts and doctest runner profiles

This pass kept the repo in the “boring workflow contract above new substrate” mode, but shifted away from pure artifact/report surfaces and toward two underbuilt operations seams:
**storage hygiene for Cargo home** and **cross-target documentation-example execution**.

New proposals:

- P-0480 Cargo Global Cache Policy & GC Receipt Kit
- P-0481 Doctest Runtool Profile Kit

Why these rose:

- **P-0480** rose because Cargo finally has real cache-GC substrate — automatic global-cache GC is stable, `cache.auto-clean-frequency` is real, and manual GC controls are documented on nightly — yet ordinary teams still lack a durable **inventory / dry-run cleanup / exemption / receipt** workflow for Cargo home.
- **P-0481** rose because rustdoc and Cargo now make cross-target docs execution much more real — stable `--test-runtool`, target-specific `ignore-*` annotations, and doctests honoring `--target` — but maintainers still lack a boring **runner profile / target matrix / ignore audit / execution receipt** layer above that substrate.

What changed in archive judgment:

- The archive now treats **Cargo-home storage hygiene** as distinct from blunt cleanup tools. A worthy crate contribution here may be a **cache inventory**, **GC plan**, **exemption ledger**, or **cleanup receipt** rather than another deleter.
- The archive now treats **cross-target doctest support** as distinct from nightly extraction work or general test execution. A worthy crate contribution here may be a **runner profile**, **ignore-target audit**, **support matrix**, or **doctest run receipt** rather than another docs portal or emulator manager.
- The repo keeps converging on a sharper heuristic: when Rust makes an operational surface newly real, the next missing crate is often the **team-readable policy artifact** above it.

Archive hygiene added in this pass:

- Added an amnesia resistor warning future revisions not to confuse Cargo’s built-in cache GC with a boring inventory/policy/receipt workflow.
- Added an amnesia resistor warning future revisions not to confuse stable doctest runner flags with a real maintainer-facing support matrix and ignore-audit workflow.
