# Entry 72 — frontier pass: industrial pubsub, transit realtime, geospatial APIs, digital trade, and CTI exchange

Added five proposals after a new standards-heavy pass emphasizing domains where Rust already has at least some substrate, but still lacks the higher-value layer: **profile pinning, replay, semantic diffing, and small portable evidence bundles**.

New proposals:

- P-0312 OPC UA PubSub + UAFX Interop & Evidence Kit
- P-0313 GTFS + GTFS Realtime Conformance & Replay Kit
- P-0314 OGC API Features + CQL2 Conformance & Evidence Kit
- P-0315 DCSA eBL + PINT Interop & Evidence Kit
- P-0316 STIX 2.1 + TAXII 2.1 Interop & Evidence Kit

Pass notes:

- **OPC UA** was narrowed from “industrial deployment in general” to the more missing **PubSub/UAFX** edge where timing, metadata drift, and deployment profiles create expensive field failures.
- **GTFS Realtime** was framed as a **schedule-aware semantics** problem, not just protobuf parsing.
- **OGC API** was promoted because GeoRust now has real building blocks, making a **conformance/evidence** layer more plausible than another standalone server.
- **DCSA eBL/PINT** was added because live interoperable production milestones make portable handoff/dispute artifacts much more urgent.
- **STIX/TAXII** was added because OASIS already publishes interop-oriented resources and Rust now has enough substrate to justify a shared workbench.
