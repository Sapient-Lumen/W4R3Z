# 2026-03-05 (53): CalDAV/CardDAV evidence shipkit + SAML2 federation/XMLSec diagnostics + LDAPv3 interop bundles

This update adds three proposals aimed at making common-but-brittle enterprise protocols **portable to test and easy to debug** via canonical traces and replayable evidence bundles:

- **P-0248 CalDAV/CardDAV Interop & Evidence ShipKit** — `*.davbundle.zip` with canonical DAV traces and sync scenario runner (RFC 4791 / RFC 6352).
- **P-0249 SAML2 Federation Interop & XML Security Evidence Kit** — `*.samlbundle.zip` for metadata validation and explainable signed/encrypted assertion failures (SAML2 + W3C XMLDSig/XMLENC).
- **P-0250 LDAPv3 Interop & Schema/Control Conformance Kit** — `*.ldapbundle.zip` with canonical operation traces and server capability matrices (RFC 4511).
