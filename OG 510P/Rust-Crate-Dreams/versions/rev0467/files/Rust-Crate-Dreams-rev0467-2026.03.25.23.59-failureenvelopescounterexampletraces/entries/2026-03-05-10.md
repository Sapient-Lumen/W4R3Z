# 2026-03-05 (10) — Supply-chain delivery + unsafe evidence + FFI conformance

This update adds three “epic” crate proposals that emphasize **artifact-first workflows** (shareable bundles, deterministic reports, conformance suites):

- **P-0119 Supply-Chain Delivery Kit** — TUF update verification plus optional in-toto attestations and policy bundles.
- **P-0120 Unsafe Contract Auditor Kit** — operationalizes unsafe contracts into machine-checkable evidence (Miri + bundles).
- **P-0121 FFI Boundary & Bindings Conformance Kit** — adapters around UniFFI + CI binding diffs + release ergonomics.

## Notes
