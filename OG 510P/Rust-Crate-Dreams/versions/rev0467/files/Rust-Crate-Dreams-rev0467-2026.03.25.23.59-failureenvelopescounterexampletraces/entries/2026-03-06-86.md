Added five proposals after a pass aimed at **high downstream utility per crate** rather than sheer protocol count. The common thesis sharpened again: a lot of the highest-value missing Rust crates are **evidence, replay, lockfile, and semantic-diff layers** above real substrate.

Pass notes:

- **AT Protocol** made the cut because Rust now has meaningful AT substrate, but the sharper missing crate is still a **repo-sync / backfill / migration evidence layer** rather than another PDS or feed product.
- **OCPI** rose because EV roaming pain is no longer just “implement the JSON”. The high-leverage missing artifact is **partner onboarding evidence plus explainable tariff/session/CDR receipts**.
- **Substrait + Flight SQL + ADBC** made the cut because Rust’s analytics stack is strong enough that the real gap is **query portability locks, capability diffs, and result proofs**, not another engine.
- **PDF/A + PAdES** rose because Rust has enough PDF substrate to benefit from a **validator-normalization and signature-scope evidence layer** above `lopdf` and external tools.
- **MCTP + PLDM** made the cut because the new Rust substrate is real, but the sharp missing crate is still a **topology / package / trace evidence kit** for firmware and datacenter management work.
