# 2026-03-05 (51): Reproducible build evidence + fuzz corpus bundles + stable API diff artifacts

This update continues the archive’s emphasis on **portable evidence artifacts**—turning common but messy workflows into shareable bundles.

## New proposals

### P-0242 Reproducible Build Evidence Kit

**Gap:** reproducibility checking in Rust is still bespoke and hard to share.

**Evidence:**
- The reproducible-builds project collects comparison tools and positions **diffoscope** as a key “what differs?” engine. https://reproducible-builds.org/tools/ and https://diffoscope.org/
- `.buildinfo` files are framed as a compact recipe to reproduce a build state. https://reproducible-builds.org/events/berlin2016/buildinfofiles/

**Proposed contribution:** a Cargo-native workflow that emits `*.reprobuildbundle.zip` with build recipe(s), normalized artifacts (or hashes), and diffoscope reports.

### P-0243 Fuzz Corpus & Coverage Interop Kit

**Gap:** Rust fuzzing workflows exist, but corpora/crashes/coverage are not packaged in a portable, replayable standard.

**Evidence:**
- The Rust Fuzz Book positions cargo-fuzz as the recommended Rust fuzzing tool and documents corpus-first workflows. https://rust-fuzz.github.io/book/cargo-fuzz.html
- cargo-fuzz exposes corpus minimization (`cmin`) and coverage features suitable for automation. https://crates.io/crates/cargo-fuzz

**Proposed contribution:** `*.fuzzbundle.zip` artifact spec + adapters (cargo-fuzz first) + minimization and replay tooling.

### P-0244 SemVer API Diff Evidence Kit

**Gap:** semver checks are important but can be toolchain-fragile; there’s no stable “public API IR” that other tools can depend on.

**Evidence:**
- cargo-semver-checks notes rustdoc JSON is not stable and can have breaking changes across Rust versions. https://github.com/obi1kenobi/cargo-semver-checks
- Rust project goals track work to unblock merging cargo-semver-checks into Cargo, underscoring the ecosystem need. https://rust-lang.github.io/rust-project-goals/2024h2/cargo-semver-checks.html
- Cargo documents conventional semver compatibility rules used in publishing workflows. https://doc.rust-lang.org/cargo/reference/semver.html

**Proposed contribution:** a stable API IR + explainable rule engine + `*.apibundle.zip` for replayable proofs of “what changed and why it’s breaking.”
