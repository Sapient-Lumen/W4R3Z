# Entry 283 — crate upgrade support sharpened around replay bridges and copy-versus-rerender provenance

This pass came from noticing that the upgrade pack had become exact about source lineage, capture context, lane selection, coverage matrices, session honesty, export posture, public traceability, durable cues, redaction, freshness, and review provenance while still leaving one ordinary bluff available:

> a lane could still sound replayable even when the bundle only shipped a copied snapshot or a replay posture label rather than one reviewable route back to the evidence.

## What moved this time

One donor pattern kept surviving scrutiny:

- **Rust-Needs-and-Dreams** kept treating replay-versus-copy provenance as its own seam rather than burying it inside import metadata or session ids.

## Main planning move

The previous passes already established:

- exact source/head/import truth,
- exact capture/scope/matrix/session truth,
- and exact readiness/export/public-surface/traceability truth.

This pass adds one sharper review object above them:

1. **replay-bridge truth** — the pack can now say whether imported evidence is reached by direct rerun, native-storage rerender, copied attachment inspection, manual reconstruction, or not replayable at all.

## Why this matters

Without **replay-bridge truth**, the lane still permits an ordinary lie:

- a capture context can advertise `native_storage_replayable` or `copied_attachment_only`,
- yet the bundle can still omit the actual route, copy provenance, and fidelity boundary that tell a reviewer what they can really do.

That is not cosmetic.
It is the difference between “this evidence has a posture label” and “this evidence has one reviewable reconstruction contract.”

## Main judgment after the pass

A worthy upgrade-support crate should now provide more than exact import truth and exact session truth.
It should also provide:

- one compact **replay bridge** for how a reviewer gets back to the imported evidence,
- one explicit distinction between **native-storage rerender**, **copied attachment**, and **manual-only reconstruction**,
- and one consistency failure when the pack advertises replay posture without shipping any actual replay route.

That keeps the lane from quietly turning replayability into another polished but ungrounded vibe.
