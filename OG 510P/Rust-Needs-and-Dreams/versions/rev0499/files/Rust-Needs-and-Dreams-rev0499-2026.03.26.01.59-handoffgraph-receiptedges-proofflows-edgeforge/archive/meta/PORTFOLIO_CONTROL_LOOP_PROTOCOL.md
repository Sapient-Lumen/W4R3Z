# Portfolio control-loop protocol

Use this protocol when the repo is no longer asking only **what is worthy** or **what should be built**, but also:
- what kind of change just occurred;
- which layer should absorb it;
- what artifact should be refreshed;
- and how to keep hot drift, current verdicts, stewardship, canon, and hygiene from collapsing into one blended update.

## Layer discipline
Keep these layers visibly separate:
1. **hot substrate watch** — fast operational or substrate drift;
2. **decision-packet loop** — current `advance` / `deepen` / `hold` / `fold` / `kill` posture;
3. **charter / stewardship loop** — owner shape, host shape, funding mode, graduation path;
4. **canon / territory loop** — broad ladder or frontier change;
5. **archive hygiene loop** — continuity, fileset, source-atlas, and doctor work.

## Default procedure
1. Identify which loop or loops were actually triggered.
2. Name the dominant loop explicitly in the revision note.
3. Emit the artifact family that belongs to that loop.
4. State what did **not** change.
5. Refresh front-door files and continuity rails when the repo learned a new drift mode.

## Allowed outputs by loop
### Hot substrate watch
Prefer:
- research-log delta;
- source-atlas refresh when a source becomes recurrently authoritative;
- packet caveat change;
- renewal receipt.

Do not use a hot change by itself to rerank the broad ladder.

### Decision-packet loop
Prefer:
- review packet refresh;
- scorecard delta;
- proving-ground / proof-budget update.

Do not let packet refresh silently rewrite residency or canon.

### Charter / stewardship loop
Prefer:
- charter delta;
- stewardship/graduation delta;
- owner/host/funding update.

Do not let host-shape adjustments silently rerank the seam.

### Canon / territory loop
Prefer:
- broad synthesis / frontier / priorities refresh.

Require more than one hot signal unless the old canon is clearly contradicted.

### Archive hygiene loop
Always prefer:
- refreshed routing files;
- refreshed latest-fileset note;
- refreshed continuity / amnesia rails when needed;
- manifest regeneration;
- hygiene + doctor runs.

Do not pretend hygiene-only work changed the strategic map.

## Source discipline
- Use official Rust / Cargo / rust-lang / docs.rs / Rust Foundation sources for current-loop judgments whenever possible.
- If a source is repeatedly load-bearing for a loop, add or refresh it in `atlases/portfolio-source-atlas-v0/sources.json`.
- Keep annual survey truth, service-behavior truth, unstable-substrate truth, and stewardship/funding truth distinct.

## Trigger hints
- security advisory, service policy change, unstable-command motion → usually **hot substrate watch**
- pilot result, new proving-ground evidence, tuple acceptance change → usually **decision-packet loop**
- new host, champion, funding lane, institutional home, optional-component path → usually **charter / stewardship loop**
- multiple independent official signals changing the broad story → **canon / territory loop**
- continuity failure, routing drift, manifest mismatch, stale source-atlas coverage → **archive hygiene loop**

## Refusal rules
- Do not rerank from one post when a packet or charter refresh would suffice.
- Do not let a hot caveat sit unreflected because the broad seam still sounds right.
- Do not let one artifact pretend to do packet, charter, canon, and hygiene work all at once.
- Do not let later summaries forget which loop the archive believed it was serving.
