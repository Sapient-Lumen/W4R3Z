# Portfolio anchor corpus v0

This is the archive's first thin representative-case corpus.

It sits beneath the shared scenario matrix.
It is intentionally small.
It does **not** try to maintain a giant public benchmark zoo or a mandatory suite of sample repositories.
It exists to force explicit answers to:
- which scenario card a case profile binds to,
- what traits make a pilot representative for that case,
- what must stay constant for fair comparison,
- and what the case still does **not** prove.

Primary file:
- `anchors.json`

Typical use:
1. choose one or more anchor IDs for a pilot after choosing scenario IDs;
2. state what traits in the anchor were satisfied;
3. state what was held constant and what was allowed to vary;
4. keep anchor coverage separate from seam ranking and freshness renewal.
