# Portfolio exemplar federation v0

This directory holds the archive's first thin set of maintained proving-world cards.

Each exemplar card names:
- which shared scenario(s) it exercises;
- which anchor profile(s) it maps to;
- whether it is public, shadow/private, or mixed;
- which artifact roles a serious rerun must leave behind;
- and what can stay constant versus vary during comparison.

This corpus is deliberately smaller than a benchmark zoo.
Its job is to keep future pilots from proving themselves only on improvised demos.
