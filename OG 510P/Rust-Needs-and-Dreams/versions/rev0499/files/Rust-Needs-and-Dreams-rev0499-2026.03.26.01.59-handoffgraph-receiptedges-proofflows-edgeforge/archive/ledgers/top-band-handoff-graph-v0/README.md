# Top-band handoff graph (v0)

This ledger keeps a compact machine-readable map of the archive's **currently endorsed receipt-bearing edges** between its strongest seams.

It does not replace the prose journey or shipset notes.
It makes their cross-seam composition easier to validate, compare, and refresh without reconstructing it from memory.

Current coverage:
- Cargo raw facts → Build-State Pack
- Build-State Pack → Debug Acceptance Matrix
- Registry/security truth → Intake Review Kit
- Structured API facts → Release-Boundary Review
- Intake + compatibility receipts → Safety Readiness Cards
- Reviewed receipts → Conservative defaults / atlas guidance
