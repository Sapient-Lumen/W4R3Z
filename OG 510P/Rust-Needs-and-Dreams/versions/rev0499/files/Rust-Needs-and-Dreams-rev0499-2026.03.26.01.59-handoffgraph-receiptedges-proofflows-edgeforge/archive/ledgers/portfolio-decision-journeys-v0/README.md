# Portfolio decision journeys v0

This ledger keeps a thin machine-readable map of the archive's current **core repeated decision moments**.

It is for questions like:
- what real workflow should several top seams compose inside;
- what artifact enters that workflow first;
- what proof ends the workflow honestly; and
- what larger product temptation should still be refused.

It is not a workflow engine, not a reranking note, and not a substitute for seam-local contracts.
