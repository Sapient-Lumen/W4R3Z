# Portfolio Source Atlas v0

This atlas is the archive's first thin maintained map of recurring upstream sources.

It exists so future revisions can answer:
- which source family should support this claim,
- what caveat must travel with that source,
- and when the archive should prefer a different authority lane instead of stretching one source too far.

Files:
- `sources.json` — first shared set of source-atlas cards

Non-goals:
- not a complete bibliography for the repo
- not a proof that a cited claim is true right now
- not a replacement for evidence renewal
