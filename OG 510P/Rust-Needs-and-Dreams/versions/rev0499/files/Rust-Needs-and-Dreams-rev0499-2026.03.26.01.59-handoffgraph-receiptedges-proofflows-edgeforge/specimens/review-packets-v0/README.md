# Review-packet specimen corpus (rev0480)

This directory holds the archive's **reference review-packet specimens**.
They are not live portfolio verdicts.
They are examples of how a filled-out packet should separate:
- imported evidence,
- archive inference,
- requested verdict,
- missing proof,
- negative states,
- and refused larger forms.

Current specimen set:
- `build-state-evidence.advance.example.md`
- `debug-acceptance.deepen.example.md`
- `navigation-defaults.hold.example.md`
- `package-intake.advance.example.md`

Why these four:
- they cover two distinct `advance` postures (`local build evidence` and `operator/boundary review`),
- one `deepen` posture (`cross-tool acceptance without enough results yet`),
- and one `hold` posture (`important but renewal-heavy recommendation layers`).

Read with:
- `design/epic-contribution-review-packet-specimens-2026Q1.md`
- `meta/REVIEW_PACKET_SPECIMEN_PROTOCOL.md`
- `meta/PROGRAM_REVIEW_PACKET_PROTOCOL.md`

Non-goals:
- this is not a scoreboard of every top candidate;
- it is not a substitute for current-issue packet writing;
- and it is not permission to reuse a specimen's verdict without fresh research.
