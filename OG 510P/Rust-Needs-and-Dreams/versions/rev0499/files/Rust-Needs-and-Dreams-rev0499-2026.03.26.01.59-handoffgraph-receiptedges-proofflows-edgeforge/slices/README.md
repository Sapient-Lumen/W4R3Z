# Kernel slices (rev0484)

This corpus holds the archive's **first bounded implementation milestones** for top-band kernels.
These are thinner than kernel briefs.
They answer “what should land first?” rather than only “what should the v0 repo contain?”

Current slice corpus:
- `build-state-pack.slice0.md`
- `debug-acceptance-matrix.slice0.md`
- `package-intake-review-kit.slice0.md`
- `safety-critical-readiness-cards.slice0.md`

Intentionally absent for now:
- **Navigation / Defaults / Claims Commons** — still `hold`; the blocker is renewal burden, not slice planning.

Default use:
- start here when a kernel already exists and the next question is “what is the first milestone?”;
- return to the kernel brief when the question is broader than one milestone;
- return to live packets when verdict posture changes.
