# Lacuna

A Python/SQLite kernel for keeping observations, testimony, beliefs, possible worlds, commitments and consequences distinct in adaptive fiction and simulations. It records and checks proposed state; the supplied README says it does not itself call a model or choose a winning world. Its existing MIT license is retained with the archive.
