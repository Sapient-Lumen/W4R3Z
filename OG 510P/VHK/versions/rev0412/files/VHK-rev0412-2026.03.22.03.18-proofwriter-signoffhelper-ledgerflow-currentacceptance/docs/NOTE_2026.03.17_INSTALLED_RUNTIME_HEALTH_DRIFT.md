# Installed runtime-health drift

Runtime health is a different question from startup ownership.

A lane can have one correct startup owner and still spend its life churning,
failing, or recovering. VHK now keeps a short installed-lane history of
runtime-health verdicts so operators can see whether a host is stable,
recovering, drifting away from healthy, chronically degraded, or flapping.

This is especially helpful for Linux-native service/session support because the
most visible systemd counters can be reset during ordinary operator recovery,
while VHK's bounded local history keeps one reviewable story across repeated
status captures.
