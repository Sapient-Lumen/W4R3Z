# Installed incident-signature drift

Linux support often needs two adjacent truths at once:

1. **What kind of incident happened most recently?**
2. **Has that incident class been stable, chronic, or already recovering?**

VHK already answered the first question in REV0312 with the installed
incident-signature verdict. REV0313 answers the second with a bounded local
history and one compact drift verdict.

This keeps support/rehearsal/dossier lanes honest about whether the current host
really looks recovered or whether the same incident class keeps returning.
