# Vault policy — revision 0325

The vault is for work that is still valuable, but no longer part of the active
product center.

A document or subsystem is a good vault candidate when it is:

- real work worth preserving,
- not currently aligned with the flagship i3/X11 lane,
- likely to distract roadmap attention if left in the active story,
- still useful as historical context or future optionality.

In this revision, the main vault themes are:

- Wayland and portal-first activation surfaces
- compositor-specific side lanes outside i3/X11
- app-native adapter packs
