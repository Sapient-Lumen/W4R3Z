# WM Include / Source Export

VHK can now export **include-ready** WM snippets, not just raw config fragments.

This is useful when you already keep your i3 / sway / Hyprland config split into
small files and want VHK to drop launcher bindings or launcher modes into a
conventional XDG config subtree.

## What it does

`export-wm-include` wraps two existing surfaces:

- `--kind binding`
  - a single top-level launcher bind
- `--kind launcher-mode`
  - an i3/sway mode or a Hyprland submap

It also tells you the **one line** to add once to the parent config:

- i3 / sway: `include ...`
- Hyprland: `source = ...`

## CLI

```bash
vhk export-wm-include ./my-project --wm sway --kind binding --install
vhk export-wm-include ./my-project --wm i3 --kind launcher-mode \
  --mode-enter '$mod+Shift+o' --install
vhk export-wm-include ./my-project --wm hyprland --kind launcher-mode \
  --mode-enter 'Mod4+Shift+o' --install --uwsm-app
```

## Default install directories

- i3: `~/.config/i3/vhk/`
- sway: `~/.config/sway/vhk/`
- Hyprland: `~/.config/hypr/vhk/`

When `XDG_CONFIG_HOME` is set, VHK installs beneath that base instead.

## Example output

```text
Wrote WM include snippet: /home/me/.config/sway/vhk/vhk-my-project-binding.conf
Add this once to ~/.config/sway/config:
include /home/me/.config/sway/vhk/*.conf
```

## Notes

- The snippet itself is still generated by the existing WM exporters, so all the
  launcher quoting fixes and launcher-surface options still apply.
- This command does **not** edit your main WM config automatically.
- For Hyprland, the bootstrap line uses `source = ...` because Hyprland’s config
  uses `source` instead of `include`.
