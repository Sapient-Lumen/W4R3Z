# Note — installed-lane readiness status

Rehearsal and dossier output are important, but they are not the only places
where Linux session truth matters.

A real operator will often ask a simpler question first:

- what does the installed lane think is happening right now?
- did the readiness probe say “ready” or “not ready”?
- is the user unit inactive because startup was skipped cleanly, or because the
  lane is actually broken?

This revision teaches the installed launcher’s status surface to answer those
questions directly, and teaches the support pack to ask for that lighter-weight
status bridge before it asks for a heavier support packet.
