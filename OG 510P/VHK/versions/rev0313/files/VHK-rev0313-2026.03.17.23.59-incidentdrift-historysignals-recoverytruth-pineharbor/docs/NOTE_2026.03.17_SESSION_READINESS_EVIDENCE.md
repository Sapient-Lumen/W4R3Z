# Note — session readiness evidence

A readiness guard is only half the story.

If VHK can skip startup cleanly when the session is not ready, the operator also
needs a compact answer to a second question:

- was the lane actually ready?
- if not, which probe said so?
- did systemd see a skipped/inactive lane or a more ordinary runtime fault?

This revision teaches rehearsal and dossier output to answer those questions
with one reviewable evidence lane instead of leaving them trapped in ad-hoc log
inspection.
