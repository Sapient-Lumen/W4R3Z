# OG 510P

Selected older work of sandpeople, organized by project. Original ZIPs and separate extracted snapshots preserve each contribution’s evolution.

- [DelayBasin](DelayBasin/): seven selected historical archives of a human–LLM method project.

- [bzip4](bzip4/): two historical C++20 compression snapshots, from a compatibility baseline to bounded operational profiles.

Each project has its own reading guide and provenance. Existing license notices remain applicable; no new blanket license is granted here.
