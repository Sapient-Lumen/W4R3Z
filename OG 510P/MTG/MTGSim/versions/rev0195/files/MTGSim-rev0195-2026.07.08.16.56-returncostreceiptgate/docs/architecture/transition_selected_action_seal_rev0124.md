# rev0124 — Transition selected-action seal

rev0124 audits the handoff after rev0123's causal receipt hash. The transition result could name the receipt index, expose the receipt row hash, and prove staged adoption, but an immediate caller still had to retain the original `LegalAction` object to replay or independently verify which canonical choice was committed. That left a small but important gap between “this receipt row was adopted” and “this transition result carries the selected action as typed evidence.”

This revision makes the selected action first-class on `TransitionResult` via its canonical `LegalAction action` field. `commit_action_transition(...)` now canonicalizes the caller's `LegalAction` before preflight, staging, hashing, and receipt append: UI/display labels are stripped, target vectors are normalized, and `result.action_hash` is computed from the canonical `result.action`. Rejected preflight results also carry the canonical attempted action while continuing to reject without StateCore, journal, receipt, or event-sequence mutation.

The public verifier `transition_result_matches_receipt(result, receipt)` exposes the same typed receipt/result guard that the staged adoption path uses internally. It verifies the receipt index, canonical selected-action fields, action hash, choice-page proof, APNAP queue-location proof, StateCore hashes, post-action/pre-receipt journal seal, event-sequence bounds, legality, and applied status. This lets replay/search/agent code validate a returned `TransitionResult` against the adopted `ActionReceiptRecord` without depending on private engine internals or a retained caller-side action object.

`test_commit_action_transition_carries_canonical_selected_action` proves that display labels do not become transition evidence, that the result's canonical action hash equals the causal receipt projection, that the public verifier accepts label-only drift, and that it rejects semantic selected-action or receipt-hash drift. The datacube audit now probes the type, API, reducer path, regression, architecture note, audit notes, and rules ledger for this selected-action seal.
