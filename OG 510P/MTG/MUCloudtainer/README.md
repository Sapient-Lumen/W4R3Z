# MUCloudtainer

## A long game can refuse a tidy verdict

MUCloudtainer’s selected revision concentrates on a stubborn strategy-evaluation problem: a counter-control/Jace-control game that remains unfinished as the decision cap increases. The archive does not solve that uncertainty by quietly treating a diagnostic picture as a win.

This makes the snapshot a useful small study of experimental judgment. A favorable mean, a confidence interval and an unresolved stopping condition can coexist. The last of those may still block the claim the experiment was designed to earn.

## The unresolved question belongs in the exhibit

The note considers whether the model should retain its half-point treatment of cap games, define a formal repetition/draw rule or change the agent objective. These alternatives are not equivalent repairs, because they change what the experiment measures or how its outcomes are interpreted.

The supplied revision explicitly makes no strategic promotion and does not replace terminal scoring with heuristic adjudication. Its stored observations should not be read as a general recommendation for competitive play.

No match, simulator or strategy search was run for this edition. Read beside [MTGSim](../MTGSim/README.md): one asks whether an action has been represented faithfully, while this work asks what can be concluded from a bounded run.
