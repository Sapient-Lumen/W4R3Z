# Population power-floor reanalysis — rev0071

rev0071 avoids another named duel and asks a narrower question: can the complete, seed-disjoint rev0069 and rev0070 population panels be pooled enough to distinguish imprecision from a genuinely low conservative floor?

## Method

The source panels are:

```text
rev0069 population frontier: 144 games, 24,533 C++-checked transitions, complete 2×3 matrix
rev0070 precision panel:     288 games, 30,000 sampled C++-checked transitions, complete 2×3 matrix
combined source evidence:    432 games, 54,533 C++-checked transitions
```

`aggregate_population_summary_rows` now pools arm-summary rows by caller-selected context axes and recomputes Hoeffding intervals from total weighted draw-half games. This prevents the old failure mode where duplicate rows could overwrite each other when size axes were intentionally removed from context.

rev0071 evaluates two conservative pooled views:

```text
pooled_across_size_by_life:   2 population cells, 36 games per counter/threat entry
pooled_across_size_and_life:  1 population cell, 72 games per counter/threat entry
```

This is a power-floor reanalysis, not a size-specific promotion run. Pooling across size axes is appropriate for a broad negative screen, but it is too coarse to certify a policy for every individual size/life cell.

## Result

```text
pooled gate rows:                   3
minimum games per matrix entry:     36
maximum observed CI width:          0.4527005052
precision-target failures:          0
candidate-promotable cells:         0
quarantined low-security-floor rows: 3
worst conservative pure LCB:         0.1069830807
best conservative pure LCB:          0.2982795348
```

The important change is the failure reason. rev0070 could only say the fine-grained cells were too imprecise. rev0071's pooled reanalysis reaches the precision target and still fails every pooled cell because the conservative security floor is far below 0.50.

## Interpretation

`public_counter_guard` remains the mean best pure row in the pooled views, but that is not enough. Once enough seed-disjoint evidence is combined to satisfy the precision gate, the result is a quarantine, not a promotion. The next scientific move should be either a genuinely faster outcome runner for fine-grained cells or a new policy population generated by systematic search, not another hand-written duel repair.
