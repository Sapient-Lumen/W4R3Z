# rev0078 priority reconsideration

The next highest risk was not more rollout volume. The cube had already established that the complete broad pool does not promote, that adaptive rows are excluded, and that target-seat score orientation is clean.

The higher leverage change was to harden the statistical decision rule itself. A promotion gate is matrix-level evidence. Therefore, matrix-level simultaneous uncertainty should be available before any future candidate can be declared promotable.

After rev0078, the next substantive priorities are:

1. Use the familywise gate as the default for promotion-sensitive population decisions.
2. Add an exact or certified fallback for larger-than-two-row empirical games before expanding the policy population.
3. Materialize cold evidence only when a historical row-level consumer must be rerun.
