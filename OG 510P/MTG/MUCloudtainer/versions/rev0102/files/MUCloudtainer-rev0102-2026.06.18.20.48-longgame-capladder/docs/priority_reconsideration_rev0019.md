# rev0019 priority reconsideration

Previous priority was:

```text
C++ batch recorded-trace checker
```

rev0019 implements that. The new priority order is:

```text
1. Decide and implement Jace ultimate RNG/shuffle transport for C++ transition checks.
2. Add trace-check coverage tables by action kind, frame, pending-choice kind, and support status.
3. Start a tiny imitation/action-ranker dataset using DecisionFrame features and promoted public policies.
4. Use meta-rank/statgate to pick deeper candidate panels instead of broad shallow tournaments.
5. Delay full C++ rollout until C++ can consume or reproduce complete recorded traces without unsupported strategic actions.
```

The major priority correction is that C++ speed should not outrun auditability. The current C++ subset is close enough that the remaining gaps are now specific and attackable rather than vague.
