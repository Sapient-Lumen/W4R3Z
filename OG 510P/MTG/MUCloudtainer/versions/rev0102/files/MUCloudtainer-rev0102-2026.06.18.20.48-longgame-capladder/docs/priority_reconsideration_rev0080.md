3. **Next technical risk:** policy-population breadth is still small.  The exact solver can now handle a third row, but adding a policy should be justified by a concrete adversarial hypothesis, not by registry completion.
4. **Process risk:** future broad panels must be explicitly classified as complete panels; adaptive challenges remain ineligible for broad promotion unless a separate preregistration says otherwise.

The next useful work should either add a genuinely different counter policy to the exact small-game path or improve opponent coverage.  Simply adding more games to the same two-row matrix is now lower priority unless a threshold or variance target changes.
