# Witness Lantern

Witness Lantern is an executable, source-carrying research work about external observations of physical changes to enterprise hardware. It asks what a sensor can actually establish, how a record can be checked, and how an operator should respond without turning an anomaly into an accusation.

The initial work compares facility-monitoring controls, a documented native server event, firmware resilience and a published radio-sensing experiment. It separates measurement, record integrity, physical inference and authorization to act. Its proposed evaluation covers monitor health, normal variation, missing data, proportionate response and privacy. No local hardware experiment, production deployment, independent audit or detection rate is claimed.

This is an independent descendant built from the supplied Datacube MAIN rev1227. It was started before the separate [Witness Plane](../Witness-Plane/README.md) archive arrived and does not incorporate or claim to continue that work. The parent project and source are carried as historical foundation; the current research entrance is `witness-lantern/OPERATIVE.md`. The runtime is reused from the verified parent, while the paired carrier is newly constructed with the revised project tree. Exact preservation of the original is separate from this descendant.
