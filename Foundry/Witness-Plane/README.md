# Witness Plane

Witness Plane is a source-carrying research Datacube about external observation of physical conditions around enterprise hardware. Its current work distinguishes the sensing boundary, witness identity, event delivery and evidence custody. It compares native platform telemetry with independent observation and asks how an operator can distinguish an observed condition from an authorized activity, a device fault or a security incident.

Revision 0003 is documentary research and experimental design. It proposes supervised boundary sensing, evidence reconciliation and witness-health assessment. It does not report a local hardware trial, detection rate, nuisance rate or product qualification. The archive's proposed physical tests require separate authorization and suitable nonproduction equipment; no deployment or destructive response follows from reading it.
