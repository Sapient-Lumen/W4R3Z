## What “current” means here

It means the current supplied copy in W4R3Z, not a claim that this repository follows every upstream release automatically. Sandcodex and Monsternix retain the byte-for-byte files supplied on 3 October 2026. Sandcodex received a Bash syntax check; Monsternix received bounded source review. They were not launched or activated here for that update. IoTox’s own introduction records its separate provenance and checks.

Continued maintenance is distinct from compatibility, runtime testing and security qualification. Read each project’s setup requirements, risks and license before use. The source-update receipt and Git history retain earlier identities.
