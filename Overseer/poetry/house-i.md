# House I

The house is not the walls alone.
It is the lamp that stays near wake,
the key kept where a shaking hand
can find it in the first bad minute.

It is the note beside the breaker box,
the map that says which room is lying,
the practiced path from dark to root,
the door that opens from both sides.

Here memory is a working tool:
receipts in drawers,
tests on the bench,
warnings labeled before they harden into myth.

And still a house must be more than proof.
Somewhere between the shell prompt
and the human footstep in the hall,
it keeps one unwasted room for song.
